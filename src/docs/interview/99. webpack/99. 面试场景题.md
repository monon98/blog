# 面试场景题

## 1. Webpack 核心概念

::: details
**问题**：Webpack 的核心概念有哪些？

### 核心概念

- Entry：入口文件
- Output：输出配置
- Loader：文件转换器
- Plugin：插件扩展
- Mode：开发/生产模式

### 执行流程

1. 读取配置，初始化 Compiler
2. 从 Entry 开始递归构建模块依赖图
3. 对每个模块使用对应的 Loader 转换
4. 使用 Plugin 执行任务
5. 根据 Entry 输出 Bundle

:::

## 2. Loader 与 Plugin 区别

::: details
**问题**：Loader 和 Plugin 有什么区别？

### Loader

- 转换文件内容
- 链式调用
- 输入源码，输出转换后的代码
- 配置在 module.rules

### Plugin

- 扩展构建能力
- 钩子机制
- 在整个生命周期执行
- 配置在 plugins 数组

### 常用 Loader

- babel-loader：JS 转译
- css-loader：处理 CSS
- file-loader：处理文件
- ts-loader：处理 TypeScript

### 常用 Plugin

- HtmlWebpackPlugin：生成 HTML
- MiniCssExtractPlugin：提取 CSS
- CleanWebpackPlugin：清理目录
- DefinePlugin：定义环境变量

:::

## 3. 模块热更新（HMR）

::: details
**问题**：Webpack HMR 如何实现？

### HMR 原理

1. Webpack 监听文件变化
2. 通过 WebSocket 通知浏览器
3. 浏览器请求更新的模块
4. 替换旧模块，保留状态

### 配置方式

- devServer.hot: true
- 添加 HotModuleReplacementPlugin

### 限制

- 不支持所有场景
- 需要正确的模块导出
- 样式更新需要额外配置

:::

## 4. 代码分割

::: details
**问题**：Webpack 如何实现代码分割？

### 分割方式

- 入口分割：多个 Entry
- 动态导入：import()
- 提取公共代码：SplitChunksPlugin

### 配置要点

- chunks：同步/异步/全部
- minSize：最小体积
- maxSize：最大体积
- cacheGroups：缓存组

### 优化目标

- 减少初始加载体积
- 利用浏览器缓存
- 避免重复打包

:::

## 5. Tree Shaking

::: details
**问题**：Webpack Tree Shaking 如何工作？

### 工作原理

- 基于 ES Module 静态分析
- 标记未使用的导出
- 删除死代码

### 使用条件

- 使用 ES Module 语法
- 启用 optimization.usedExports
- package.json 设置 sideEffects

### 注意事项

- 不支持 CommonJS
- 副作用处理
- 动态导入不生效

:::

## 6. 缓存优化

::: details
**问题**：Webpack 如何利用缓存？

### 缓存类型

- 文件缓存：contenthash
- 模块缓存：babel-loader cache
- 构建缓存：hard-source-webpack-plugin

### 配置要点

- output.filename：使用 contenthash
- babel-loader：cacheDirectory: true
- optimization.runtimeChunk

### 注意事项

- hash 变化导致缓存失效
- 合理配置缓存策略
- 定期清理缓存

:::

## 7. 性能优化

::: details
**问题**：Webpack 构建性能如何优化？

### 构建优化

- 使用 include/exclude 缩小 Loader 范围
- 使用缓存

### 打包优化

- 压缩代码

### 监控优化

- 使用 webpack-bundle-analyzer
- 分析构建耗时

:::

## 8. Source Map

::: details
**问题**：Webpack Source Map 如何配置？

### Source Map 作用

- 映射编译后代码到源码
- 方便调试
- 不影响生产代码

### 配置选项

- devtool: 'source-map'
- devtool: 'cheap-module-source-map'
- devtool: 'eval-source-map'

### 选择原则

- 开发环境：eval-source-map
- 生产环境：hidden-source-map
- 调试环境：source-map

:::

## 10. Webpack vs Vite

::: details
**问题**：Webpack 和 Vite 如何选择？

### 对比

| 特性 | Webpack | Vite |
|------|---------|------|
| 启动速度 | 慢 | 快 |
| HMR 速度 | 慢 | 快 |
| 生产打包 | 成熟 | Rollup |
| 生态 | 丰富 | 成长中 |
| 配置复杂度 | 高 | 低 |

### 选择原则

- 新项目：优先 Vite
- 老项目：保持 Webpack
- 需要成熟生态：Webpack
- 追求开发体验：Vite

### 迁移策略

- 渐进式迁移
- 验证兼容性
- 处理差异

:::
