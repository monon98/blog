# CSS 现代特性面试题

## 1. 什么是 CSS 自定义属性（CSS 变量）？如何使用？

::: details
CSS 自定义属性（也称为 CSS 变量）允许在样式表中定义可重用的值。

### 基本语法

```css
/* 定义变量 */
:root {
  --primary-color: #3498db;
  --secondary-color: #2ecc71;
  --font-size-base: 16px;
  --spacing-unit: 8px;
}

/* 使用变量 */
.button {
  background-color: var(--primary-color);
  font-size: var(--font-size-base);
  padding: var(--spacing-unit) calc(var(--spacing-unit) * 2);
}

/* 带默认值 */
.card {
  color: var(--text-color, #333);
}
```

### 变量作用域

```css
/* 全局变量 */
:root {
  --global-color: red;
}

/* 组件级变量 */
.card {
  --card-bg: white;
  background-color: var(--card-bg);
}

/* 局部变量 */
.item {
  --item-color: blue;
  color: var(--item-color);
}

/* 子元素可以继承父元素的变量 */
.parent {
  --parent-color: green;
}

.child {
  color: var(--parent-color); /* ✅ 可以使用 */
}
```

### 实际应用

```css
/* 1. 主题切换 */
:root {
  --bg-color: white;
  --text-color: black;
  --border-color: #ccc;
}

[data-theme="dark"] {
  --bg-color: #1a1a1a;
  --text-color: white;
  --border-color: #444;
}

body {
  background-color: var(--bg-color);
  color: var(--text-color);
}

/* 2. 响应式设计 */
:root {
  --spacing-xs: 4px;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --spacing-xl: 32px;
}

@media (min-width: 768px) {
  :root {
    --spacing-md: 24px;
    --spacing-lg: 32px;
    --spacing-xl: 48px;
  }
}

/* 3. 组件库 */
.button {
  --button-primary: #3498db;
  --button-secondary: #95a5a6;
  --button-radius: 4px;
}

.button--primary {
  background-color: var(--button-primary);
  border-radius: var(--button-radius);
}

.button--secondary {
  background-color: var(--button-secondary);
  border-radius: var(--button-radius);
}
```

## 2. 什么是 CSS 容器查询（Container Queries）？

::: details
容器查询允许根据父容器的大小而不是视口大小来调整样式。

### 基本语法

```css
/* 定义容器 */
.card-container {
  container-type: inline-size;
  container-name: card;
}

/* 使用容器查询 */
@container card (min-width: 400px) {
  .card {
    display: flex;
    flex-direction: row;
  }
  
  .card-image {
    width: 50%;
  }
  
  .card-content {
    width: 50%;
  }
}

@container card (max-width: 399px) {
  .card {
    display: flex;
    flex-direction: column;
  }
  
  .card-image {
    width: 100%;
  }
  
  .card-content {
    width: 100%;
  }
}
```

### 容器类型

```css
/* inline-size：只查询内联尺寸（宽度） */
.container {
  container-type: inline-size;
}

/* size：查询所有尺寸（宽度和高度） */
.container {
  container-type: size;
}

/* normal：不是容器 */
.container {
  container-type: normal;
}
```

### 实际应用

```css
/* 响应式卡片布局 */
.card-wrapper {
  container-type: inline-size;
  container-name: card-wrapper;
}

.card {
  padding: 1rem;
  border: 1px solid #ccc;
  border-radius: 8px;
}

@container card-wrapper (min-width: 500px) {
  .card {
    display: grid;
    grid-template-columns: 200px 1fr;
    gap: 1rem;
  }
}

@container card-wrapper (min-width: 800px) {
  .card {
    grid-template-columns: 300px 1fr;
  }
  
  .card-title {
    font-size: 1.5rem;
  }
}

/* 侧边栏布局 */
.sidebar-layout {
  container-type: inline-size;
  container-name: sidebar;
}

.main-content {
  padding: 1rem;
}

@container sidebar (min-width: 768px) {
  .sidebar-layout {
    display: grid;
    grid-template-columns: 250px 1fr;
  }
  
  .sidebar {
    position: sticky;
    top: 0;
    height: 100vh;
  }
}
```

## 3. 什么是 CSS 层叠层（@layer）？

::: details
CSS 层叠层允许你控制不同来源样式的优先级，解决样式冲突问题。

### 基本语法

```css
/* 定义层叠层 */
@layer base, components, utilities;

/* 在层叠层中定义样式 */
@layer base {
  h1 {
    font-size: 2rem;
  }
  
  p {
    line-height: 1.5;
  }
}

@layer components {
  .card {
    border: 1px solid #ccc;
    padding: 1rem;
  }
  
  .button {
    background-color: #3498db;
    color: white;
  }
}

@layer utilities {
  .hidden {
    display: none;
  }
  
  .text-center {
    text-align: center;
  }
}
```

### 层叠层的优先级

```css
/* 后定义的层叠层优先级更高 */
@layer first {
  .element {
    color: red; /* 优先级较低 */
  }
}

@layer second {
  .element {
    color: blue; /* 优先级较高 */
  }
}

/* 未在层叠层中的样式优先级最高 */
.element {
  color: green; /* 优先级最高 */
}
```

### 实际应用

```css
/* 1. 框架样式 */
@layer framework {
  .button {
    padding: 0.5rem 1rem;
    border-radius: 4px;
  }
}

/* 2. 组件样式 */
@layer components {
  .primary-button {
    background-color: #3498db;
    color: white;
  }
}

/* 3. 工具类样式 */
@layer utilities {
  .mt-4 {
    margin-top: 1rem;
  }
}

/* 4. 自定义样式（最高优先级） */
.primary-button {
  background-color: #2ecc71; /* 覆盖框架和组件样式 */
}
```

### 处理第三方库样式

```css
/* 定义层叠层 */
@layer reset, third-party, custom;

/* 重置样式 */
@layer reset {
  * {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
  }
}

/* 第三方库样式 */
@import url('bootstrap.css') layer(third-party);

/* 自定义样式（最高优先级） */
@layer custom {
  .container {
    max-width: 1200px;
    margin: 0 auto;
  }
}
```

## 4. 什么是 CSS 嵌套（Native Nesting）？

::: details
CSS 嵌套允许你在 CSS 中使用嵌套语法，类似于 Sass。

### 基本语法

```css
/* 传统写法 */
.card {
  padding: 1rem;
  border: 1px solid #ccc;
}

.card .title {
  font-size: 1.5rem;
  font-weight: bold;
}

.card .content {
  line-height: 1.5;
  color: #666;
}

/* CSS 嵌套写法 */
.card {
  padding: 1rem;
  border: 1px solid #ccc;
  
  .title {
    font-size: 1.5rem;
    font-weight: bold;
  }
  
  .content {
    line-height: 1.5;
    color: #666;
  }
}
```

### 使用 & 选择器

```css
/* & 代表父选择器 */
.button {
  background-color: #3498db;
  color: white;
  
  &:hover {
    background-color: #2980b9;
  }
  
  &:active {
    background-color: #21618c;
  }
  
  &:disabled {
    background-color: #95a5a6;
    cursor: not-allowed;
  }
}

/* & 用于拼接类名 */
.card {
  padding: 1rem;
  
  &-header {
    border-bottom: 1px solid #ccc;
    padding-bottom: 0.5rem;
  }
  
  &-body {
    padding: 1rem 0;
  }
  
  &-footer {
    border-top: 1px solid #ccc;
    padding-top: 0.5rem;
  }
}
```

### 媒体查询嵌套

```css
/* 媒体查询可以嵌套在选择器中 */
.container {
  max-width: 1200px;
  margin: 0 auto;
  
  @media (min-width: 768px) {
    padding: 2rem;
  }
  
  @media (min-width: 1024px) {
    padding: 3rem;
  }
}

/* 等同于 */
.container {
  max-width: 1200px;
  margin: 0 auto;
}

@media (min-width: 768px) {
  .container {
    padding: 2rem;
  }
}

@media (min-width: 1024px) {
  .container {
    padding: 3rem;
  }
}
```

### 实际应用

```css
/* 组件样式 */
.component {
  --component-color: #3498db;
  
  color: var(--component-color);
  
  .header {
    font-size: 1.5rem;
    font-weight: bold;
    border-bottom: 2px solid currentColor;
    padding-bottom: 0.5rem;
  }
  
  .body {
    padding: 1rem 0;
    line-height: 1.6;
  }
  
  .footer {
    display: flex;
    justify-content: space-between;
    padding-top: 0.5rem;
    border-top: 1px solid #ccc;
    
    .button {
      background-color: var(--component-color);
      color: white;
      padding: 0.5rem 1rem;
      
      &:hover {
        opacity: 0.9;
      }
    }
  }
}
```

## 5. Tailwind CSS 和 CSS-in-JS 有什么优缺点？

::: details
Tailwind CSS 和 CSS-in-JS 是两种流行的 CSS 解决方案，各有优缺点。

### Tailwind CSS

```javascript
// Tailwind CSS：实用优先的 CSS 框架
// 优点：
// 1. 快速开发：使用预定义的工具类
// 2. 一致性：统一的设计系统
// 3. 小文件大小：生产环境只包含使用的类
// 4. 响应式设计：内置响应式工具类

// 缺点：
// 1. 学习曲线：需要记忆大量工具类
// 2. HTML 冗长：类名可能很长
// 3. 可读性：HTML 结构可能难以理解
// 4. 定制化：需要配置文件

// 使用示例
<div class="flex items-center justify-between p-4 bg-white rounded-lg shadow-md">
  <h2 class="text-xl font-bold text-gray-800">标题</h2>
  <button class="px-4 py-2 text-white bg-blue-500 rounded hover:bg-blue-600">
    按钮
  </button>
</div>
```

### CSS-in-JS

```javascript
// CSS-in-JS：将 CSS 写在 JavaScript 中
// 优点：
// 1. 作用域隔离：样式不会冲突
// 2. 动态样式：可以根据 props 动态生成样式
// 3. 类型安全：支持 TypeScript
// 4. 同构渲染：支持 SSR

// 缺点：
// 1. 性能开销：运行时生成样式
// 2. 学习曲线：需要学习新的 API
// 3. 调试困难：样式分散在 JS 中
// 4. 文件大小：增加了 JS 包大小

// 使用示例（styled-components）
import styled from 'styled-components';

const Card = styled.div`
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 1rem;
  background-color: white;
  border-radius: 0.5rem;
  box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
`;

const Title = styled.h2`
  font-size: 1.25rem;
  font-weight: bold;
  color: #1a202c;
`;

const Button = styled.button`
  padding: 0.5rem 1rem;
  color: white;
  background-color: #3182ce;
  border-radius: 0.25rem;
  
  &:hover {
    background-color: #2b6cb0;
  }
`;

function MyComponent() {
  return (
    <Card>
      <Title>标题</Title>
      <Button>按钮</Button>
    </Card>
  );
}
```

### 对比

```javascript

```

### 选择建议

```javascript
// 选择 Tailwind CSS 当：
// 1. 团队熟悉实用优先的 CSS
// 2. 需要快速开发
// 3. 项目规模中小
// 4. 需要一致的设计系统

// 选择 CSS-in-JS 当：
// 1. 需要动态样式
// 2. 项目规模大
// 3. 需要类型安全
// 4. 需要同构渲染
```
