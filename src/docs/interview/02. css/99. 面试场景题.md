# 面试场景题

## 1. 水平垂直居中

::: details
**问题**：实现一个元素在父容器中水平垂直居中，至少写出 5 种方法。

### Flexbox

```
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

### Grid

```
.parent {
  display: grid;
  place-items: center;
}
```

### 绝对定位 + transform

```
.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

### 绝对定位 + margin auto

```
.child {
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  margin: auto;
}
```

### 绝对定位 + 负 margin

```
.child {
  position: absolute;
  top: 50%;
  left: 50%;
  margin-top: -50px;
  margin-left: -50px;
}
```

:::

## 2. CSS 三角形

::: details
**问题**：用 CSS 画一个三角形。

### 实现原理

- 设置元素宽高为 0
- 使用 border 控制四条边
- 将不需要的边设为 transparent

### 等腰三角形

```
.triangle {
  width: 0;
  height: 0;
  border-left: 50px solid transparent;
  border-right: 50px solid transparent;
  border-bottom: 100px solid red;
}
```

:::

## 3. 响应式布局方案

::: details
**问题**：如何实现一个响应式布局？

### 方案一：媒体查询

- 根据屏幕宽度应用不同样式
- 适合复杂的布局变化

### 方案二：Flexbox

- 使用 flex-wrap 自动换行
- 使用 flex-grow 控制比例

### 方案三：CSS Grid

- 使用 fr 单位分配空间
- 使用 auto-fill/auto-fit 自适应

### 方案四：rem + vw

- 使用 vw 设置根字体大小
- 使用 rem 进行布局
- 需要处理最小/最大宽度

:::

## 4. CSS 动画性能优化

::: details
**问题**：如何优化 CSS 动画性能？

### 原则

- 只使用 transform 和 opacity
- 避免触发重排
- 使用 will-change 提示浏览器

### 对比

| 属性 | 触发重排 | 触发重绘 | 合成层 |
|------|----------|----------|--------|
| width/height | 是 | 是 | 否 |
| top/left | 是 | 是 | 否 |
| transform | 否 | 否 | 是 |
| opacity | 否 | 是 | 是 |

### 最佳实践

- 动画元素提升为独立图层
- 使用 will-change 提示浏览器
- 避免在动画中读取布局属性
- JavaScript 动画使用 requestAnimationFrame 控制

:::

## 5. BFC 触发条件

::: details
**问题**：如何触发 BFC？BFC 有什么作用？

### 触发条件

- overflow 不为 visible（如 hidden、auto）
- display 为 flex、grid、inline-block 等
- position 为 absolute、fixed
- float 不为 none
- 根元素 html

### 作用

- 防止 margin 重叠
- 清除浮动
- 防止元素被浮动元素覆盖
- 包含浮动子元素

:::

## 6. 圣杯布局和双飞翼布局

::: details
**问题**：实现圣杯布局和双飞翼布局。

### 圣杯布局

- 三栏布局，中间列最先渲染
- 使用 float + 负 margin
- 使用 padding 和相对定位

### 双飞翼布局

- 与圣杯布局类似
- 中间列使用 margin 而非 padding
- 避免了布局问题

### 现代方案

- 使用 Flexbox：order 属性控制顺序
- 使用 Grid：grid-area 控制位置

:::

## 7. CSS 选择器优先级

::: details
**问题**：CSS 选择器优先级如何计算？

### 优先级计算

- 内联样式：1000
- ID 选择器：100
- 类/伪类选择器：10
- 元素选择器：1
- 通配符：0

### 计算规则

- 按位比较，高位大的优先
- 同位相加，不需要进位
- !important 最高优先级

### 特殊情况

- 继承的样式优先级最低
- 后定义的样式覆盖先定义的
- 相同优先级后定义的优先

:::

## 8. CSS 模块化方案

::: details
**问题**：如何实现 CSS 模块化？

### 方案对比

| 方案 | 优点 | 缺点 |
|------|------|------|
| BEM | 简单直接 | 类名冗长 |
| CSS Modules | 局部作用域 | 构建依赖 |
| CSS-in-JS | 动态样式 | 运行时开销 |
| Tailwind | 原子化 | HTML 冗余 |

### 选择原则

- 小项目：BEM
- 中型项目：CSS Modules
- 大型项目：CSS-in-JS 或 Tailwind

:::

## 9. 移动端适配方案

::: details
**问题**：如何实现移动端适配？

### 方案一：rem 适配

- 使用 rem 单位
- 根据屏幕宽度设置根字体大小
- 使用 postcss-pxtorem 自动转换

### 方案二：vw 适配

- 使用 vw 单位
- 100vw 等于屏幕宽度
- 使用 postcss-px-to-viewport 自动转换

### 方案三：媒体查询

- 根据屏幕宽度应用不同样式
- 适合简单的布局调整

### 最佳实践

- 使用 vw 作为基础单位
- 设置最小/最大宽度限制
- 使用 Flexbox/Grid 进行布局

:::

## 10. CSS 变量使用

::: details
**问题**：CSS 变量有哪些应用场景？

### 基本用法

```
:root {
  --primary-color: #1890ff;
  --font-size: 14px;
}

.button {
  color: var(--primary-color);
  font-size: var(--font-size);
}
```

### 应用场景

- 主题切换
- 响应式设计
- 组件样式复用
- 动态样式计算

### 与预处理器对比

- CSS 变量是原生支持
- 可以动态修改
- 可以在 JavaScript 中操作
- 不需要编译

:::
