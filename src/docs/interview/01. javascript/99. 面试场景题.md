# 面试场景题

## 1. 手写 Promise

::: details
**问题**：实现一个符合 A+ 规范的 Promise。

### 核心要点

- Promise 有三种状态：pending、fulfilled、rejected
- 状态一旦改变就不能再变
- then 方法支持链式调用
- 支持 resolve 和 reject
- 支持 catch 和 finally

### 实现思路

- 使用闭包管理状态和值
- then 方法返回新的 Promise
- 使用微任务队列模拟异步
- 处理循环引用问题

:::

## 2. 手写深拷贝

::: details
**问题**：实现一个深拷贝函数，处理循环引用、特殊对象类型。

### 基本实现

- 递归遍历对象
- 判断类型，分别处理
- 处理数组和对象

### 进阶处理

- **循环引用**：使用 WeakMap 存储已拷贝的对象
- **特殊对象**：Date、RegExp、Map、Set、Symbol
- **性能优化**：使用循环代替递归

### 注意事项

- Symbol 属性不能用 Object.keys 获取
- Map 和 Set 需要特殊处理
- 函数和 undefined 的处理

:::

## 3. 手写防抖和节流

::: details
**问题**：实现防抖和节流函数，支持取消和立即执行。

### 防抖实现

- 基本版本：使用闭包和 setTimeout
- 支持取消：clearTimeout
- 支持立即执行：trailing 参数
- 支持返回值：使用 Promise 包装

### 节流实现

- 时间戳版：第一次立即执行，之后每隔一段时间执行
- 定时器版：第一次延迟执行，之后每隔一段时间执行
- 组合版：第一次立即执行，最后一次也执行

:::

## 4. 手写发布订阅

::: details
**问题**：实现一个事件发布订阅系统，支持 once、off、emit。

### 核心功能

- on：添加事件监听
- off：移除事件监听
- emit：触发事件
- once：只触发一次

### 实现要点

- 使用对象存储事件列表
- off 需要支持移除指定回调
- once 内部调用 on，触发后自动 off
- 支持传递参数

:::

## 5. 手写 call、apply、bind

::: details
**问题**：实现 call、apply、bind 方法。

### call 实现

- 将函数挂载到对象上
- 执行函数并删除
- 处理 this 为 null 或 undefined 的情况

### apply 实现

- 与 call 类似，参数为数组
- 处理参数为空数组的情况

### bind 实现

- 返回一个新函数
- 支持预设参数
- 支持 new 操作符
- 处理 this 绑定

:::

## 6. 手写 Promise.all

::: details
**问题**：实现 Promise.all 方法。

### 核心要点

- 接收 Promise 数组
- 所有 Promise 都成功才返回成功
- 任意一个失败就返回失败
- 保持结果顺序

### 实现思路

- 使用计数器跟踪完成数量
- 结果数组按顺序存储
- 使用 resolve 和 reject 控制最终状态
- 处理空数组的情况

:::

## 7. 手写 instanceof

::: details
**问题**：实现 instanceof 操作符。

### 实现思路

- 获取构造函数的 prototype
- 获取对象的 __proto__
- 循环向上查找原型链
- 找到返回 true，找不到返回 false

### 注意事项

- 处理 null 和 undefined
- 处理基本类型
- 处理循环引用

:::

## 8. 手写柯里化函数

::: details
**问题**：实现一个通用的柯里化函数。

### 实现思路

- 判断参数数量是否足够
- 足够则执行函数
- 不足则返回新函数继续收集参数
- 使用闭包保存已收集的参数

### 使用场景

- 日志函数
- 地址生成函数
- 验证函数

:::

## 9. 手写异步调度器

::: details
**问题**：实现一个异步任务调度器，控制并发数量。

### 核心功能

- 控制同时执行的任务数量
- 任务完成后自动执行下一个
- 保证所有任务都能执行

### 实现思路

- 使用队列存储待执行任务
- 维护当前执行数量
- 任务完成后递归调用

:::

## 10. 手写模板字符串解析

::: details
**问题**：实现一个函数，将模板字符串解析为值。

### 示例

- 模板：'你好，${name}，今年${age}岁'
- 数据：{ name: '张三', age: 25 }
- 结果：'你好，张三，今年25岁'

### 实现思路

- 使用正则匹配 ${} 表达式
- 替换为对应的值
- 处理嵌套表达式
- 处理不存在的值

:::
