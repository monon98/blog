# 浏览器渲染原地面试题

## 1. 浏览器从输入 URL 到页面显示经历了哪些过程？

::: details
从输入 URL 到页面显示是一个复杂的过程，涉及网络、解析、渲染等多个阶段。

### 完整流程

```
1. URL 解析
2. DNS 解析
3. TCP 连接
4. 发送 HTTP 请求
5. 服务器处理并返回响应
6. 浏览器解析响应
7. 构建 DOM 树
8. 构建 CSSOM 树
9. 生成渲染树
10. 布局（Layout）
11. 绘制（Paint）
12. 合成（Composite）
```

### 详细步骤

```javascript
// 1. URL 解析
// 浏览器解析 URL，提取协议、域名、端口、路径等信息
// http://example.com:80/path?query=value#fragment

// 2. DNS 解析
// 将域名转换为 IP 地址
// 先查浏览器缓存 → 系统缓存 → 路由器缓存 → DNS 服务器

// 3. TCP 连接
// 三次握手建立连接
// SYN → SYN+ACK → ACK

// 4. 发送 HTTP 请求
// 构建请求报文（请求行、请求头、请求体）

// 5. 服务器处理
// 服务器接收请求，处理业务逻辑，返回响应

// 6. 浏览器解析
// 解析 HTML、CSS、JavaScript
// 构建 DOM 树和 CSSOM 树

// 7. 渲染
// 合并 DOM 和 CSSOM 生成渲染树
// 计算布局、绘制、合成
```

### 关键优化点

```javascript
// 1. DNS 预解析
<link rel="dns-prefetch" href="//example.com">

// 2. TCP 预连接
<link rel="preconnect" href="https://example.com">

// 3. 资源预加载
<link rel="preload" href="font.woff" as="font">

// 4. DNS 缓存
// 浏览器会缓存 DNS 解析结果
// TTL 通常为几分钟到几小时
```

## 2. 什么是重排（Reflow）和重绘（Repaint）？如何优化？

::: details
重排和重绘是浏览器渲染过程中的两个重要概念，理解它们有助于优化页面性能。

### 重排（Reflow）

```javascript
// 重排：元素的几何属性发生变化，需要重新计算布局
// 触发重排的操作：
element.style.width = '100px';      // 修改宽度
element.style.height = '100px';     // 修改高度
element.style.margin = '10px';      // 修改外边距
element.style.padding = '10px';     // 修改内边距
element.style.border = '1px solid'; // 修改边框
element.style.position = 'absolute'; // 修改定位
element.offsetHeight;                // 读取布局属性
element.offsetWidth;                 // 读取布局属性
element.getBoundingClientRect();     // 获取元素位置
window.innerWidth;                   // 获取窗口大小
window.innerHeight;                  // 获取窗口大小
```

### 重绘（Repaint）

```javascript
// 重绘：元素的外观发生变化，但不影响布局
// 触发重绘的操作：
element.style.color = 'red';        // 修改文字颜色
element.style.backgroundColor = '#fff'; // 修改背景色
element.style.visibility = 'hidden'; // 修改可见性
element.style.textDecoration = 'none'; // 修改文字装饰
```

### 优化策略

```javascript
// 1. 批量修改 DOM
// ❌ 不好的做法：多次触发重排
function addElements() {
  for (let i = 0; i < 100; i++) {
    const div = document.createElement('div');
    div.style.width = '100px';
    div.style.height = '100px';
    document.body.appendChild(div);
  }
}

// ✅ 好的做法：使用 DocumentFragment
function addElements() {
  const fragment = document.createDocumentFragment();
  for (let i = 0; i < 100; i++) {
    const div = document.createElement('div');
    div.style.width = '100px';
    div.style.height = '100px';
    fragment.appendChild(div);
  }
  document.body.appendChild(fragment);
}

// 2. 使用 CSS 类批量修改
// ❌ 不好的做法
element.style.width = '100px';
element.style.height = '100px';
element.style.margin = '10px';

// ✅ 好的做法
element.classList.add('new-class');

// 3. 使用 transform 替代布局属性
// ❌ 不好的做法：触发重排
element.style.left = '100px';
element.style.top = '100px';

// ✅ 好的做法：只触发重绘
element.style.transform = 'translate(100px, 100px)';

// 4. 使用 requestAnimationFrame
function animate() {
  element.style.transform = 'translate(100px, 100px)';
  requestAnimationFrame(animate);
}

// 5. 使用 will-change 提示浏览器
element.style.willChange = 'transform';
```

## 3. 什么是事件循环（Event Loop）？宏任务和微任务的区别是什么？

::: details
事件循环是 JavaScript 处理异步操作的核心机制。

### 事件循环的工作原理

```javascript
// 事件循环的基本流程
// 1. 执行同步代码（调用栈）
// 2. 调用栈为空时，检查微任务队列
// 3. 执行所有微任务
// 4. 执行一个宏任务
// 5. 重复步骤 2-4

// 示例
console.log('1'); // 同步

setTimeout(() => {
  console.log('2'); // 宏任务
}, 0);

Promise.resolve().then(() => {
  console.log('3'); // 微任务
});

console.log('4'); // 同步

// 输出顺序：1 → 4 → 3 → 2
```

### 宏任务（Macrotask）

```javascript
// 宏任务包括：
// 1. setTimeout
// 2. setInterval
// 3. setImmediate（Node.js）
// 4. I/O
// 5. UI 渲染
// 6. requestAnimationFrame

// 示例
setTimeout(() => {
  console.log('setTimeout'); // 宏任务
}, 0);

setInterval(() => {
  console.log('setInterval'); // 宏任务
}, 1000);

requestAnimationFrame(() => {
  console.log('requestAnimationFrame'); // 宏任务
});
```

### 微任务（Microtask）

```javascript
// 微任务包括：
// 1. Promise.then/catch/finally
// 2. async/await
// 3. MutationObserver
// 4. queueMicrotask

// 示例
Promise.resolve().then(() => {
  console.log('Promise.then'); // 微任务
});

async function asyncFn() {
  console.log('async'); // 同步
  await Promise.resolve();
  console.log('await'); // 微任务
}

queueMicrotask(() => {
  console.log('queueMicrotask'); // 微任务
});
```

### 执行顺序示例

```javascript
console.log('script start'); // 同步

setTimeout(() => {
  console.log('setTimeout'); // 宏任务
}, 0);

Promise.resolve()
  .then(() => {
    console.log('promise1'); // 微任务
  })
  .then(() => {
    console.log('promise2'); // 微任务
  });

console.log('script end'); // 同步

// 输出顺序：
// script start
// script end
// promise1
// promise2
// setTimeout
```

## 4. 什么是浏览器的同源策略？如何实现跨域？

::: details
同源策略是浏览器的安全机制，限制不同源之间的交互。

### 同源的定义

```javascript
// 同源：协议、域名、端口都相同
// https://example.com:443/path

// 同源示例
https://example.com/path1  ✅ 同源
https://example.com/path2  ✅ 同源

// 不同源示例
https://example.com   ❌ 协议不同
http://example.com    ❌ 协议不同
https://www.example.com ❌ 域名不同
https://example.com:8080 ❌ 端口不同
```

### 同源策略的限制

```javascript
// 1. Cookie、LocalStorage、IndexedDB 无法读取
// 2. DOM 无法获取
// 3. Ajax 请求无法发送
```

### 跨域解决方案

```javascript
// 1. CORS（跨域资源共享）
// 服务端设置响应头
Access-Control-Allow-Origin: https://example.com
Access-Control-Allow-Methods: GET, POST, PUT, DELETE
Access-Control-Allow-Headers: Content-Type

// 2. JSONP
function handleResponse(data) {
  console.log(data);
}

const script = document.createElement('script');
script.src = 'https://api.example.com/data?callback=handleResponse';
document.body.appendChild(script);

// 3. 代理服务器
// 前端请求同源服务器，服务器转发请求
fetch('/api/proxy?url=https://api.example.com/data')

// 4. postMessage
// 窗口之间通信
window.postMessage(data, 'https://target-origin.com');

// 5. WebSocket
const ws = new WebSocket('wss://api.example.com');
```

## 5. 浏览器的存储机制有哪些？它们的区别是什么？

::: details
浏览器提供了多种存储机制，适用于不同的场景。

### Cookie

```javascript
// Cookie：存储在客户端的小型文本数据
// 大小：4KB 左右
// 有效期：可设置过期时间
// 发送：每次请求自动发送到服务器

// 设置 Cookie
document.cookie = "username=alice; expires=Fri, 31 Dec 2025 23:59:59 GMT; path=/";

// 读取 Cookie
console.log(document.cookie); // "username=alice"

// 删除 Cookie
document.cookie = "username=; expires=Thu, 01 Jan 1970 00:00:00 GMT; path=/";
```

### LocalStorage

```javascript
// LocalStorage：持久化存储，关闭浏览器后仍然存在
// 大小：5MB 左右
// 有效期：永久
// 作用域：同源

// 设置
localStorage.setItem('user', JSON.stringify({ name: 'alice' }));

// 读取
const user = JSON.parse(localStorage.getItem('user'));
console.log(user.name); // "alice"

// 删除
localStorage.removeItem('user');

// 清空
localStorage.clear();
```

### SessionStorage

```javascript
// SessionStorage：会话存储，关闭标签页后清除
// 大小：5MB 左右
// 有效期：会话期间
// 作用域：同源 + 同标签页

// 设置
sessionStorage.setItem('token', 'abc123');

// 读取
const token = sessionStorage.getItem('token');
console.log(token); // "abc123"

// 删除
sessionStorage.removeItem('token');
```

### IndexedDB

```javascript
// IndexedDB：客户端的数据库存储
// 大小：无限制（通常为磁盘空间的 50%）
// 有效期：永久
// 作用域：同源
// 支持索引和事务

// 打开数据库
const request = indexedDB.open('myDatabase', 1);

request.onupgradeneeded = (event) => {
  const db = event.target.result;
  const store = db.createObjectStore('users', { keyPath: 'id' });
  store.createIndex('name', 'name', { unique: false });
};

request.onsuccess = (event) => {
  const db = event.target.result;
  
  // 添加数据
  const transaction = db.transaction(['users'], 'readwrite');
  const store = transaction.objectStore('users');
  store.add({ id: 1, name: 'alice', age: 25 });
  
  // 查询数据
  const getRequest = store.get(1);
  getRequest.onsuccess = () => {
    console.log(getRequest.result); // { id: 1, name: 'alice', age: 25 }
  };
};
```

### 存储对比

```javascript
// 对比表
const storageComparison = {
  cookie: {
    size: '4KB',
   有效期: '可设置',
    发送: '每次请求',

  },
  localStorage: {
    size: '5MB',
    有效期: '永久',
    发送: '不发送',
    用途: '客户端数据持久化'
  },
  sessionStorage: {
    size: '5MB',
    有效期: '会话',
    发送: '不发送',
    用途: '临时数据存储'
  },
  indexedDB: {
    size: '无限制',
    有效期: '永久',
    发送: '不发送',
    用途: '大量结构化数据'
  }
};
```
