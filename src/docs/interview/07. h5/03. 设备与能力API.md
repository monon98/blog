# 设备与能力 API

## 1. 地理定位

::: details
**问题**：Geolocation API 如何使用？有哪些限制？

### 基本使用

```
navigator.geolocation.getCurrentPosition(success, error, {
  enableHighAccuracy: true,
  timeout: 5000,
  maximumAge: 0
})
```

- success：position.coords.latitude / longitude
- watchPosition：持续监听位置变化，clearWatch 停止

### 限制

- 必须用户授权，且仅在 HTTPS（或 localhost）下可用
- 移动端精度依赖 GPS/WiFi/基站
- 耗电敏感，watchPosition 用完及时 clearWatch

:::

## 2. Web Workers 概要

::: details
**问题**：Web Workers 解决什么问题？

### 定位

- 在后台线程执行 JS，避免复杂计算阻塞 UI 渲染
- 通过 postMessage 结构化克隆通信

### 类型

- Dedicated Worker：专用，一对一
- Shared Worker：多页面共享
- Service Worker：代理网络请求，PWA 核心（见浏览器专题）

### 限制

- 不能访问 DOM/window/document
- 通信异步且有数据拷贝开销（可用 Transferable 零拷贝转移）

详细展开见：[JavaScript - Web Workers与多线程](../01.%20javascript/20.%20Web%20Workers与多线程)
:::

## 3. 其他常用能力 API

::: details
**问题**：HTML5 时代还有哪些常用的设备/浏览器能力 API？

| API | 能力 | 典型场景 |
|-----|------|----------|
| Fullscreen | 全屏控制 | 视频播放器 |
| Notification | 系统级通知 | 消息提醒 |
| Clipboard | 剪贴板读写 | 复制邀请码 |
| Vibration | 设备震动 | 游戏反馈 |
| DeviceOrientation | 重力感应 | 摇一摇、赛车游戏 |
| Page Visibility | 页面可见性 | 切后台暂停轮询/视频 |
| Network Information | 网络类型 | 弱网降清晰度 |

注：Battery Status API 因隐私争议已被 Firefox/Safari 移除，不建议依赖。

### Page Visibility 实用示例

```
document.addEventListener('visibilitychange', () => {
  if (document.hidden) video.pause();
  else video.play();
});
```

## 4. postMessage 跨窗口通信

::: details
**问题**：iframe 与父页面如何安全通信？

### 使用方式

```
// 子 → 父
window.parent.postMessage({ type: 'resize', h: 300 }, 'https://parent.com')

// 父监听
window.addEventListener('message', (e) => {
  if (e.origin !== 'https://child.com') return // 校验来源
  console.log(e.data)
})
```

### 要点

- 第二个参数指定目标 origin，'*' 存在安全隐患
- 接收端必须校验 e.origin 防止恶意消息
- 应用：第三方登录弹窗、iframe 自适应高度、微前端通信

:::
