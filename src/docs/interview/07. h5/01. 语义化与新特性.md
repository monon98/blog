## 2. 什么是语义化？有什么好处？

::: details
语义化指使用能清晰描述内容含义的标签组织页面，而非全部用 div/span 堆砌。

### 常用语义化标签

- `<header>`：页面或区块头部
- `<nav>`：导航
- `<main>`：主要内容（每页唯一）
- `<article>`：独立完整的内容单元
- `<section>`：主题性区块
- `<aside>`：侧边栏/附属信息
- `<figure>` / `<figcaption>`：图片及说明
- `<time>`：时间日期

### 好处

1. **SEO 友好**：爬虫更准确理解页面结构与权重
2. **无障碍访问**：屏幕阅读器依赖地标角色导航
3. **可读性与维护性**：结构一目了然
4. **设备兼容**：读屏器、搜索引擎、翻译工具解析一致

### 无障碍延伸：ARIA

- role 属性补充语义：role="button"
- aria-label / aria-hidden 等属性
- 优先用原生语义标签，ARIA 兜底

:::

## 3. HTML 文档结构的演进

::: details
**问题**：HTML5 相比 HTML4 的文档声明有什么变化？

### DOCTYPE 简化

```
<!-- HTML4 冗长声明 -->
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://...">

<!-- HTML5 -->
<!DOCTYPE html>
```

### 其他简化

- 字符集：<meta charset="utf-8">
- 样式/脚本默认 type 可省略（CSS 默认 text/css，JS 默认 text/javascript）
- 允许省略部分闭合标签（但不推荐）

### meta 常用配置

```
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="referrer" content="no-referrer">
<!-- 遗留项：仅当仍需支持旧版 IE 时使用 -->
<meta http-equiv="X-UA-Compatible" content="IE=edge">
```

:::

## 4. script 标签的加载策略

::: details
**问题**：script 标签的 defer 和 async 有什么区别？

### 三种加载行为

| 写法 | 下载时机 | 执行时机 | 执行顺序 |
|------|----------|----------|----------|
| 普通 script | 解析到即阻塞解析并同步下载 | 下载完立即执行 | 按文档顺序 |
| async | 异步下载，不阻塞解析 | 下载完立即执行 | 不保证顺序 |
| defer | 异步下载，不阻塞解析 | DOMContentLoaded 前 | 按文档顺序 |

### 选择原则

- 独立统计类脚本 → async
- 有依赖关系的应用脚本 → defer
- 立即执行且不依赖 DOM → head 内普通 script（少用）

### module 脚本

- `<script type="module">` 默认 defer 行为
- ES Module 自动严格模式

:::

## 5. 前端路由基础：History API

::: details
**问题**：HTML5 History API 提供了哪些能力？

### 核心 API

```
history.pushState(state, title, url)   // 新增历史记录，不刷新页面
history.replaceState(state, title, url) // 替换当前记录
window.onpopstate                       // 监听前进后退
```

### 与 hash 路由对比

- hash：改变 # 后内容，天然不触发请求，兼容好但丑
- history：URL 干净，需服务端配置 fallback 到 index.html

### 应用

- Vue Router / React Router 的两种模式底层实现
- 单页应用的视图切换不刷新页面

详细对比见：[其他面试难题汇总 - history vs hash](../99.%20其他面试难题汇总)
:::
