# 表单与多媒体

## 1. HTML5 表单增强

::: details
**问题**：HTML5 在表单方面有哪些增强？

### 新增输入类型

- email、tel、url：格式提示与校验
- number / range：数值输入与滑块
- date / time / datetime-local：原生日期时间选择
- color：颜色选择器
- search：搜索框（可清除）

### 新增属性

| 属性 | 作用 |
|------|------|
| placeholder | 占位提示 |
| required | 必填 |
| pattern | 正则校验 |
| min/max/step | 数值范围 |
| autocomplete | 自动填充 |
| autofocus | 自动聚焦 |

:::

## 2. 表单验证 API

::: details
**问题**：如何使用原生表单验证 API？

### 声明式验证

```
<form>
  <input type="email" required
         pattern="[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}$">
  <input type="password" required minlength="8">
</form>
```

### JS 控制

- form.checkValidity()：整体是否通过
- input.validity：ValidityState 对象（valueMissing、typeMismatch、patternMismatch 等）
- input.setCustomValidity(msg)：自定义错误信息，传空字符串表示通过
- novalidate 属性禁用浏览器默认气泡，改用自定义 UI

### 局限性

- 错误气泡样式无法定制 → 通常 novalidate + 自行展示错误
- 复杂联动验证仍需 JS 方案（React Hook Form / VeeValidate 等）

:::

## 3. 音视频标签

::: details
**问题**：audio 和 video 有哪些常用配置？

### 基本用法

```
<video controls width="320" poster="cover.jpg">
  <source src="video.mp4" type="video/mp4">
  <track src="subs.vtt" kind="subtitles" srclang="zh">
</video>
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>
```

### 常用属性

- controls / autoplay / loop / muted
- preload：auto、metadata、none（流量敏感场景用 none/metadata）
- poster：视频封面图

### JS 控制与事件

```
video.play() / video.pause()
video.currentTime = 30
video.volume = 0.5
// 常用事件：play、pause、ended、timeupdate、canplay
```

### 自动播放限制

- 现代浏览器禁止有声自动播放
- 必须 muted + autoplay 组合或用户交互后调用 play()

:::

## 4. 拖放 API

::: details
**问题**：HTML5 原生拖放如何实现？

### 实现步骤

1. 源元素设置 draggable="true"
2. dragstart 中 e.dataTransfer.setData 存入数据
3. 目标元素 dragover 中必须 e.preventDefault()（否则 drop 不触发）
4. drop 中 getData 取出数据处理

### 事件流

- 源元素：dragstart → drag → dragend
- 目标元素：dragenter → dragover → dragleave / drop

### dataTransfer 关键点

- setData/getData(type)：传输数据
- effectAllowed / dropEffect：控制拖放视觉反馈（copy/move/link）
- 文件拖拽上传：e.dataTransfer.files 获取 FileList

:::
