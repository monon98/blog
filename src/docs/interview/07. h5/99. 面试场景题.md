# 面试场景题

## 1. 微信 H5 分享卡片不生效排查

::: details
**问题**：接手的老项目在微信里分享出去没有自定义卡片，如何排查？

### 排查清单

1. 签名相关
   - access_token / jsapi_ticket 是否过期（有效期 7200s，需集中缓存）
   - 签名用的 URL 是否与当前页一致
   - iOS SPA 的坑：签名必须用首次进入的 URL，路由切换后 iOS 不更新
2. 域名配置：JS 安全域名是否包含当前域名
3. 权限验证：wx.config 返回 checkResult 是否全 ok，监听 wx.error 捕获失败原因
4. 时机问题：分享接口调用过早，SDK 未 ready → 放入 wx.ready 回调

### 标准流程

```
后端签名 → wx.config → wx.ready 中设置分享内容 → wx.error 兜底上报
```

:::

## 2. H5 页面唤起 App

::: details
**问题**：如何实现从 H5 页面跳转到自家 App？未安装时引导下载？

### 方案演进

1. **URL Scheme**
   - location.href = 'appname://page?id=1'
   - 未安装时页面报错/无反应，需 setTimeout 兜底跳下载页
2. **Universal Link（iOS）/ App Links（Android）**
   - 普通 https 链接关联 App，已安装直接进 App 内对应页
   - 未安装正常打开网页，体验最好；需要域名配置关联文件（apple-app-site-association）
3. **微信内限制**
   - 微信屏蔽 Scheme 直接唤起，需接入开放标签 wx-open-launch-app 或走应用宝中转

### 判断是否安装成功

- visibilitychange / pagehide 触发视为唤起成功，取消下载兜底定时器

:::

## 3. 软键盘遮挡输入框

::: details
**问题**：表单页在手机上输入时，底部输入框被键盘挡住怎么办？

### 处理方案

```
// 聚焦时滚动到可视区
input.addEventListener('focus', () => {
  setTimeout(() => {
    input.scrollIntoView({ block: 'center', behavior: 'smooth' })
  }, 300) // 等键盘弹起动画结束
})

// iOS 收起时页面残留偏移
input.addEventListener('blur', () => {
  window.scrollTo(0, 0)
})
```

### 键盘弹出检测

- Android：window resize 监听（视口被压缩）
- iOS：visualViewport API 监听高度与 offsetTop
- focusin/focusout 事件辅助判断

### 布局建议

- 聊天类页面用 flex 布局让输入栏贴底，键盘弹起自然上移
- 避免 fixed 元素与键盘同时出现（iOS fixed 失真）

:::

## 4. 移动端视频自动播放被拦截

::: details
**问题**：H5 页面的宣传视频无法自动播放，如何解决？

### 原因

- 浏览器策略：非静音的自动播放被禁止，节省流量与打扰用户
- 低电量模式更严格

### 解决方案

1. muted + autoplay + playsinline 组合（iOS 内联播放必需 playsinline）
2. 监听首次触摸事件后调用 video.play()
3. WeChat 环境：监听 WeixinJSBridgeReady 后 play()
4. 引导式：封面图 + 播放按钮（体验最可控）

```
<video autoplay muted loop playsinline webkit-playsinline></video>
```

:::

## 5. 长列表滑动卡顿与白屏

::: details
**问题**：H5 长列表在低端机上滑动掉帧、快速滑动出现白屏，怎么优化？

### 白屏原因

- 图片懒加载来不及加载可视区新出现的项
- DOM 数量过大导致渲染跟不上滚动

### 解决方案

1. **虚拟列表**：只渲染可视区 ±缓冲区的条目（react-window / vue-virtual-scroller）
2. **图片占位**：固定宽高容器 + 模糊缩略图/LQIP 占位
3. **预加载缓冲区**：提前渲染视口外一屏数据
4. **减少每项开销**：简化节点层级、避免深层组件嵌套
5. **scroll 监听 passive 化**，或改用 IntersectionObserver 触发加载

:::

## 6. 横竖屏切换处理

::: details
**问题**：横屏活动页如何适配竖屏切换？

### 检测方式

```
window.matchMedia('(orientation: portrait)')
  .addEventListener('change', e => {
    e.matches ? showPortraitUI() : showLandscapeUI()
  })
```

- 或比较 window.innerWidth / innerHeight

### 适配手段

- CSS 媒体查询 @media (orientation: landscape) 切换布局
- 强制横屏需求：竖屏下用 transform rotate(90deg) 整体旋转模拟（游戏类 H5）
- resize 后重新计算 canvas 尺寸与 rem 根字号

:::

## 7. 图片选择与上传兼容性

::: details
**问题**：移动端 H5 上传头像/图片有哪些兼容细节？

### input 能力配置

```
<!-- 相册 -->
<input type="file" accept="image/*">
<!-- 仅拍照 -->
<input type="file" accept="image/*" capture="camera">
```

### 常见问题

- **iOS HEIC 格式**：部分场景读取失败 → 统一 canvas 重绘转 jpeg/png 再上传
- **大图内存溢出**：exif 方向信息丢失导致旋转 → 读取 EXIF Orientation 校正
- **多选**：multiple 属性
- **压缩上传**：canvas 缩放绘制后 toBlob('image/jpeg', 0.8)，控制体积与方向一次解决

:::

## 8. H5 首屏秒开方案

::: details
**问题**：运营活动 H5 要求"秒开"，有哪些技术手段？

### 加载链路优化

1. **离线包**：App 内置静态资源包，拦截请求本地命中（Hybrid 场景杀手锏）
2. **SSR/直出**：服务端渲染首屏 HTML，配合 CDN 边缘缓存
3. **资源精简**：首屏代码分割、关键 CSS 内联、图片 WebP/AVIF
4. **预热**：App WebView 预创建 + DNS 预解析 + 关键资源 preload

### 渲染体验

- 骨架屏消除白屏感知
- 数据预取：App 启动时并行请求首屏接口，Webview 就绪后注入数据

### 度量标准

- FCP < 1.8s、LCP < 2.5s（Google Web Vitals 口径）作为秒开基线持续监控

:::
