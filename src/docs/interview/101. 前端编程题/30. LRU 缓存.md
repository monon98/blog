# LRU 缓存

> 难度：中等 | 标签：设计、Map、缓存策略

## 题目描述

实现 LRU（Least Recently Used，最近最少使用）缓存类 `LRUCache`：

- 构造时指定容量 `capacity`
- `get(key)`：存在则返回值并**将该键提升为最近使用**；不存在返回 -1
- `put(key, value)`：写入键值并标记为最近使用；容量已满时淘汰「最久未使用」的键
- get 和 put 都要求 O(1) 时间复杂度

**示例：**

```javascript
const cache = new LRUCache(2);
cache.put(1, 1);
cache.put(2, 2);
cache.get(1); // 1，此时 1 变为最近使用
cache.put(3, 3); // 容量满，淘汰最久未用的 2
cache.get(2); // -1
```

## 题解

::: details 点击查看题解

### 思路

利用 JS `Map` 的两个特性把经典「哈希表 + 双向链表」结构简化掉：

1. Map 迭代顺序 = 插入顺序
2. 删除再插入 = 移动到末尾

于是：get/put 命中时先 delete 再 set 实现「提到最新」；put 超容时用 `map.keys().next().value` 拿到队头（最旧）删除。所有操作均摊 O(1)。

面试若被要求手写双向链表版本，需实现 head/tail 哨兵 + prev/next 指针维护。

### 代码实现

```javascript
class LRUCache {
  constructor(capacity) {
    if (capacity <= 0) throw new Error("capacity must be positive");
    this.capacity = capacity;
    this.map = new Map();
  }

  get(key) {
    if (!this.map.has(key)) return -1;
    const value = this.map.get(key);
    this.map.delete(key);
    this.map.set(key, value);
    return value;
  }

  put(key, value) {
    if (this.map.has(key)) {
      this.map.delete(key);
    } else if (this.map.size >= this.capacity) {
      const oldestKey = this.map.keys().next().value;
      this.map.delete(oldestKey);
    }
    this.map.set(key, value);
  }
}
```

### 考察点

- LRU 的语义：get 和 put 都算一次「使用」
- Map 有序性是 JS 特有的捷径；通用语言解法为 哈希表 + 双向链表（O(1) 定位 + O(1) 移动）
- 应用：Vue keep-alive 的 include/exclude 与 max 策略、HTTP 缓存、React 虚拟列表缓存
- 变体追问：LFU（按频率淘汰）如何改造、带过期时间的 TTL 缓存
