# 深比较 isEqual

> 难度：简单 | 标签：递归、对象比较

## 题目描述

实现 `isEqual(a, b)`，深度比较两个值是否相等：

- 原始值用严格相等（===）
- 对象与数组需逐键递归比较，键集合与每个键的值都相同才算相等
- 键顺序不影响结果：`{a:1,b:2}` 与 `{b:2,a:1}` 相等
- 处理 NaN（NaN 应视为相等）、null、undefined 的组合

**示例：**

```javascript
isEqual({ a: [1, { b: 2 }] }, { a: [1, { b: 2 }] }); // true
isEqual(NaN, NaN); // true
isEqual({ a: undefined }, {}); // false（键数不同）
```

## 题解

::: details 点击查看题解

### 思路

递归三段式：

1. 全等命中直接 true——覆盖原始值与同一引用，同时借助 `Object.is` 让 NaN 相等
2. 非同类型对象直接 false（可用 `Object.prototype.toString` 精确区分数组/普通对象/日期等）
3. 比较 Object.keys 集合长度后逐键递归

进阶可加 WeakSet 循环引用保护，思路与深拷贝一致。

### 代码实现

```javascript
function isEqual(a, b) {
  if (Object.is(a, b)) return true;

  if (
    typeof a !== "object" ||
    typeof b !== "object" ||
    a === null ||
    b === null
  ) {
    return false;
  }

  const typeA = Object.prototype.toString.call(a);
  const typeB = Object.prototype.toString.call(b);
  if (typeA !== typeB) return false;
  if (typeA === "[object Date]") return +a === +b;
  if (typeA === "[object RegExp]") return String(a) === String(b);

  const keysA = Object.keys(a);
  const keysB = Object.keys(b);
  if (keysA.length !== keysB.length) return false;

  return keysA.every((key) =>
    Object.prototype.hasOwnProperty.call(b, key) && isEqual(a[key], b[key])
  );
}
```

### 考察点

- Object.is 解决 NaN !== NaN 的比较陷阱
- 「先比键数再逐键」的双重剪枝
- toString.call 精确类型判定优于 instanceof（跨 iframe 场景失效问题）
- 应用：React memo/useMemo 浅比较不够时的深比较方案、测试断言库核心
