# 数组去重

> 难度：入门 | 标签：Set、Map、数组

## 题目描述

实现数组去重函数 `unique(arr)`，要求：

- 基础版：去除原始值（数字、字符串、布尔等）中的重复项
- 进阶：说明 `NaN`、对象引用的处理差异
- 扩展版：支持对象数组按指定 key 去重

**示例：**

```javascript
unique([1, 2, 2, 3, "a", "a", NaN, NaN]);
// [1, 2, 3, "a", NaN]
```

## 题解

::: details 点击查看题解

### 思路

按场景给四种方案：

1. `new Set(arr)` 一行解决，且能正确识别 `NaN`（SameValueZero 算法）
2. `filter + indexOf`：利用「首次出现位置等于当前下标」过滤；缺点是 `indexOf` 认为 `NaN !== NaN` 会保留多个 NaN
3. 排序后比较相邻元素：O(n log n)，适合不能使用额外结构的场合
4. 对象数组按 key 去重：用 Map 以 key 值为键收集唯一项

### 代码实现

```javascript
const uniqueBySet = (arr) => [...new Set(arr)];

const uniqueByFilter = (arr) =>
  arr.filter((item, index) => arr.indexOf(item) === index);

function uniqueObjectsByKey(arr, key) {
  return [...new Map(arr.map((item) => [item[key], item])).values()];
}
```

### 考察点

- Set 的去重依据是 SameValueZero：`NaN` 视为相同，`+0` 与 `-0` 视为相同——比 `===` 更适合去重
- `indexOf` 方案的 NaN 缺陷是高频追问点
- 对象数组去重的本质是把比较维度从「引用」换成「业务键」
- 时间复杂度对比：Set 版 O(n)；双重循环版 O(n²) 应避免
