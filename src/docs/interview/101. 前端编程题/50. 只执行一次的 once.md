# 只执行一次的 once

> 难度：入门 | 标签：闭包、高阶函数

## 题目描述

实现 `once(fn)`：

- 返回的新函数无论调用多少次，原函数只执行第一次
- 后续调用返回第一次的执行结果（缓存结果而非 undefined）
- 保留 `this` 与参数（以首次调用为准）
- 提供手动重置能力可作为扩展

**示例：**

```javascript
let count = 0;
const init = once(() => ++count);

init(); // 1
init(); // 1，count 不再增加
init(); // 1
```

## 题解

::: details 点击查看题解

### 思路

最经典的闭包应用之一：外部变量记录「是否已执行」与首次结果。注意两点：

1. 结果必须缓存——支付提交、初始化脚本等场景重复调用要拿到一致结果
2. 用 `fn.apply(this, args)` 保留调用上下文；once 包装的函数常作事件处理器

### 代码实现

```javascript
function once(fn) {
  let called = false;
  let result;

  function onceFn(...args) {
    if (!called) {
      called = true;
      result = fn.apply(this, args);
    }
    return result;
  }

  onceFn.reset = () => {
    called = false;
    result = undefined;
  };

  return onceFn;
}
```

### 考察点

- 闭包保存执行状态与结果缓存
- 与防抖/节流的区别：once 关心「次数上限」，不关心时间
- 应用：表单防重复提交、单例初始化、DOM 一次性事件绑定
- 变体追问：并发场景下多个 await 同时触达时只发一次请求（Promise 缓存版 once）
