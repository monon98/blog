# 手写 Promise（简化 A+ 版）

> 难度：困难 | 标签：Promise、异步、状态机

## 题目描述

实现一个符合 Promise/A+ 核心语义的 `MyPromise` 类：

- 三种状态 `pending / fulfilled / rejected`，且只能从 pending 单向变更一次
- 构造函数接收 executor，同步抛错自动转为 reject
- `then` 支持链式调用，返回新 Promise；回调可选（值穿透）
- 回调必须异步执行；`onFulfilled` 的返回值若为 thenable 要继续展开
- 实现静态方法 `resolve` 与 `reject`

**示例：**

```javascript
new MyPromise((resolve) => resolve(1))
  .then((v) => v + 1)
  .then((v) => MyPromise.resolve(v * 2))
  .then(console.log); // 4
```

### 思路

四块拼图：

1. **状态机**：pending 下缓存成功/失败回调队列，resolve/reject 时批量刷新——这解决了「then 注册时异步还没完成」的问题
2. **异步化**：用 `setTimeout` 模拟微任务时序（真实引擎用 microtask）
3. **链式核心 resolvePromise**：处理 then 返回值 x——x 是 MyPromise 就取其结果递归 resolve；是带 then 方法的对象就调用并递归；普通值直接 resolve。这是 A+ 规范 2.3 节的精髓
4. **值穿透**：非函数回调替换为透传函数 `(v) => v` / `(e) => { throw e }`

### 代码实现

```javascript
class MyPromise {
  constructor(executor) {
    this.state = "pending";
    this.value = undefined;
    this.reason = undefined;
    this.onFulfilledCallbacks = [];
    this.onRejectedCallbacks = [];

    const resolve = (value) => {
      if (this.state === "pending") {
        this.state = "fulfilled";
        this.value = value;
        this.onFulfilledCallbacks.forEach((fn) => fn());
      }
    };
    const reject = (reason) => {
      if (this.state === "pending") {
        this.state = "rejected";
        this.value = reason;
        this.onRejectedCallbacks.forEach((fn) => fn());
      }
    };
    try {
      executor(resolve, reject);
    } catch (error) {
      reject(error);
    }
  }

  static resolve(value) {
    return value instanceof MyPromise ? value : new MyPromise((r) => r(value));
  }

  static reject(reason) {
    return new MyPromise((_, r) => r(reason));
  }

  then(onFulfilled, onRejected) {
    onFulfilled =
      typeof onFulfilled === "function" ? onFulfilled : (value) => value;
    onRejected =
      typeof onRejected === "function"
        ? onRejected
        : (reason) => {
            throw reason;
          };

    const promise2 = new MyPromise((resolve, reject) => {
      const handleFulfilled = () => {
        setTimeout(() => {
          try {
            const x = onFulfilled(this.value);
            resolvePromise(promise2, x, resolve, reject);
          } catch (error) {
            reject(error);
          }
        });
      };
      const handleRejected = () => {
        setTimeout(() => {
          try {
            const x = onRejected(this.value);
            resolvePromise(promise2, x, resolve, reject);
          } catch (error) {
            reject(error);
          }
        });
      };

      if (this.state === "fulfilled") handleFulfilled();
      else if (this.state === "rejected") handleRejected();
      else {
        this.onFulfilledCallbacks.push(handleFulfilled);
        this.onRejectedCallbacks.push(handleRejected);
      }
    });

    return promise2;
  }

  catch(onRejected) {
    return this.then(null, onRejected);
  }

  finally(callback) {
    return this.then(
      (value) => MyPromise.resolve(callback()).then(() => value),
      (reason) =>
        MyPromise.resolve(callback()).then(() => {
          throw reason;
        })
    );
  }
}

function resolvePromise(promise2, x, resolve, reject) {
  if (promise2 === x) {
    return reject(new TypeError("Chaining cycle detected for promise"));
  }
  if (x instanceof MyPromise) {
    x.then(resolve, reject);
    return;
  }
  if (x !== null && (typeof x === "object" || typeof x === "function")) {
    let called = false;
    try {
      const then = x.then;
      if (typeof then === "function") {
        then.call(
          x,
          (y) => {
            if (called) return;
            called = true;
            resolvePromise(promise2, y, resolve, reject);
          },
          (r) => {
            if (called) return;
            called = true;
            reject(r);
          }
        );
      } else {
        resolve(x);
      }
    } catch (error) {
      if (!called) {
        called = true;
        reject(error);
      }
    }
    return;
  }
  resolve(x);
}
```

### 考察点

- 为什么 then 里要 new 一个 promise2 并把控制权交给 resolvePromise——链式与 thenable 展开的关键
- 回调入队而非立即执行：兼容注册早于状态变更的时序
- `called` 标志防止 thenable 多次回调导致的重复 settle
- 通过 promises-aplus-tests 全量用例还需补充更多防御分支（如 getter 抛错），面试写清主干即可
