# 手写 Object.assign

> 难度：简单 | 标签：对象 API、浅拷贝

## 题目描述

实现一个 `myAssign(target, ...sources)` 函数，模拟 `Object.assign` 的合并行为：

- 把任意多个源对象的可枚举自有属性复制到目标对象并返回它
- 后面的源对象属性覆盖前面的同名属性
- `source` 为 `null` 或 `undefined` 时跳过不报错；`target` 为原始值时先包装成对象
- 注意是**浅拷贝**：嵌套对象只复制引用

**示例：**

```javascript
myAssign({ a: 1 }, { b: 2 }, { b: 3, c: 4 });
// { a: 1, b: 3, c: 4 }
```

## 题解

::: details 点击查看题解

### 思路

遍历每个源对象的 `Object.keys`（恰好对应「可枚举自有属性」，不含 Symbol 键时可再补 `Reflect.ownKeys`），用赋值语句拷贝到目标。要点：

1. `target == null` 抛 TypeError，与原生一致；否则 `Object(target)` 包装
2. 源对象为空值时静默跳过
3. 返回的就是被修改后的 target 本身（引用）

### 代码实现

```javascript
function myAssign(target, ...sources) {
  if (target === null || target === undefined) {
    throw new TypeError("Cannot convert undefined or null to object");
  }
  const to = Object(target);
  for (const source of sources) {
    if (source !== null && source !== undefined) {
      for (const key of Object.keys(source)) {
        to[key] = source[key];
      }
    }
  }
  return to;
}
```

### 考察点

- 「可枚举自有属性」的含义：`Object.keys` 不含继承属性与不可枚举属性
- 浅拷贝陷阱：嵌套引用类型共享内存，修改会互相影响
- 与展开运算符 `{...a, ...b}` 的关系：语义近似但 assign 可触发源对象 setter
- 原生实现通过 `Object.defineProperty(Object, "assign", {...})` 挂载到构造器上
