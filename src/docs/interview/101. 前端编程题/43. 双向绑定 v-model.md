# 双向绑定 v-model

> 难度：中等 | 标签：Vue、双向绑定、DOM

## 题目描述

不依赖 Vue，用原生 JavaScript 实现 `v-model` 的双向绑定效果：

- 数据变化自动同步到输入框（数据 → 视图）
- 用户输入自动更新数据（视图 → 数据）
- 提供一个极简的 `createVModel(container, state)` API：容器内所有带 `v-model="key"` 属性的 input 双向绑定到 state 对应字段
- 说明 Vue 中 v-model 是 `:value` 与 `@input` 的语法糖

**示例：**

```html
<div id="app">
  <input v-model="name" />
  <p>你好，<span v-text="name"></span></p>
</div>
```

```javascript
createVModel(document.getElementById("app"), { name: "Tom" });
// 修改输入框 → span 实时更新；JS 改 state.name → 输入框与 span 同步
```

## 题解

::: details 点击查看题解

### 思路

双向 = 单向数据流 ×2：

1. **视图 → 数据**：监听 input 事件，把 e.target.value 写回 state 对应路径
2. **数据 → 视图**：提供 updateView 函数遍历所有绑定节点刷新；配合 Proxy set 拦截让「直接改 state」也能触发刷新
3. 文本插值 v-text 用同样的 Proxy 拦截统一驱动

Vue3 的 v-model 编译后正是 `:value="x"` + `@input="x = $event.target.value"`；自定义组件上则变为 modelValue prop 与 update:modelValue 事件。

### 代码实现

```javascript
function createVModel(root, state) {
  const proxy = new Proxy(state, {
    set(target, key, value) {
      const success = Reflect.set(target, key, value);
      syncView();
      return success;
    }
  });

  const bindings = root.querySelectorAll("[v-model]");

  bindings.forEach((el) => {
    el.value = proxy[el.getAttribute("v-model")] ?? "";
    el.addEventListener("input", (e) => {
      proxy[el.getAttribute("v-model")] = e.target.value;
    });
  });

  function syncView() {
    bindings.forEach((el) => {
      const key = el.getAttribute("v-model");
      if (el.value !== proxy[key]) {
        el.value = proxy[key] ?? "";
      }
    });
    root.querySelectorAll("[v-text]").forEach((el) => {
      el.textContent = proxy[el.getAttribute("v-text")] ?? "";
    });
  }

  syncView();
  return proxy;
}
```

### 考察点

- 「双向绑定不是魔法」：本质是 value 绑定 + 事件回写的组合
- Proxy set 拦截把「改数据」变成可观察行为，替代手动调 update
- 追问：checkbox/radio/select 的 v-model 差异、修饰符 .lazy/.number/.trim 各做了什么、组件上的 v-model 参数
