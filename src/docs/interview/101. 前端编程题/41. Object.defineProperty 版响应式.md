# Object.defineProperty 版响应式

> 难度：困难 | 标签：Vue2、defineProperty、观察者模式

## 题目描述

用 `Object.defineProperty` 实现一个迷你响应式系统，模拟 Vue2 的核心机制：

- 遍历 data 的所有属性，将每个属性改写为 getter/setter
- 依赖收集：读取属性时记录「谁在用我」（Watcher），修改属性时通知所有 Watcher 更新
- 支持多层嵌套对象的递归劫持；说明数组与新增属性的局限

**示例：**

```javascript
const state = reactive({ count: 0, user: { name: "Tom" } });

new Watcher(state, "count", (val) => console.log("count 变为", val));
new Watcher(state, "user.name", (val) => console.log("name 变为", val));

state.count = 1; // "count 变为 1"
state.user.name = "Jerry"; // "name 变为 Jerry"
```

## 题解

::: details 点击查看题解

### 思路

三件套：Observer（递归劫持）、Dep（依赖容器）、Watcher（订阅者）。

1. **observe**：遍历对象每个键调 defineReactive；属性值是对象就继续 observe（深层响应）
2. **defineReactive**：闭包保存 val 与 dep。get 时若当前有活跃 Watcher 则 dep.depend() 收集；set 时更新值并 dep.notify()
3. **Dep 与 Watcher**：静态属性 Dep.target 指向当前正在求值的 Watcher——Watcher 构造时先把自己挂到 target 再读取一次属性值触发 getter 完成收集，随后清空 target

### 代码实现

```javascript
let activeWatcher = null;

class Dep {
  constructor() {
    this.subscribers = new Set();
  }
  depend() {
    if (activeWatcher) {
      this.subscribers.add(activeWatcher);
    }
  }
  notify() {
    this.subscribers.forEach((watcher) => watcher.update());
  }
}

function defineReactive(obj, key, val) {
  const dep = new Dep();

  if (typeof val === "object" && val !== null) {
    observe(val);
  }

  Object.defineProperty(obj, key, {
    enumerable: true,
    configurable: true,
    get() {
      dep.depend();
      return val;
    },
    set(newVal) {
      if (newVal === val) return;
      val = newVal;
      if (typeof newVal === "object" && newVal !== null) {
        observe(newVal);
      }
      dep.notify();
    }
  });
}

function observe(obj) {
  if (typeof obj !== "object" || obj === null) return;
  for (const key of Object.keys(obj)) {
    defineReactive(obj, key, obj[key]);
  }
  return obj;
}

function reactive(data) {
  return observe(data);
}

class Watcher {
  constructor(data, key, callback) {
    this.callback = callback;
    const get = () =>
      key.split(".").reduce((o, k) => (o == null ? o : o[k]), data);

    activeWatcher = this;
    this.value = get();
    activeWatcher = null;
    this._get = get;
  }

  update() {
    const newValue = this._get();
    if (newValue !== this.value) {
      const oldValue = this.value;
      this.value = newValue;
      this.callback(newValue, oldValue);
    }
  }
}
```

### 考察点

- getter 里收集、setter 里通知的双向配合是响应式的灵魂
- Dep.target 全局单例 + Watcher 求值自注册的技巧
- 三大局限：新增/删除属性无法侦测（需 $set/$delete）、数组下标与 length 无法劫持、初始化时递归全量转换的性能成本
- 这三点正是 Vue3 改用 Proxy 的动机
