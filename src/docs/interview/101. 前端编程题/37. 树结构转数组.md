# 树结构转数组

> 难度：简单 | 标签：递归、DFS、数据转换

## 题目描述

实现 `treeToList(tree)`，把树形结构打平为节点数组（数组转树的逆操作）：

- 保留每个节点的全部字段，去掉 `children` 或保留 `parentId` 视需求而定
- 支持多棵根的森林结构
- 给出递归 DFS 与迭代栈两种实现

**示例：**

```javascript
treeToList([
  {
    id: 1,
    children: [
      { id: 2, children: [] },
      { id: 3, children: [] }
    ]
  }
]);
// [{ id: 1 }, { id: 2 }, { id: 3 }]（顺序为前序遍历）
```

## 题解

::: details 点击查看题解

### 思路

本质是树的前序遍历收集：

1. **递归版**：访问节点 → 解构掉 children 存入结果 → 对每个 child 递归。若需要 parentId，把父节点作为参数传下去
2. **迭代版**：栈存待处理节点，pop 后拆 children 再逆序压栈以维持先序；天然避免深层递归爆栈

### 代码实现

```javascript
function treeToList(tree) {
  const result = [];

  const dfs = (nodes, parentId = null) => {
    for (const node of nodes) {
      const { children, ...rest } = node;
      result.push({ ...rest, parentId });
      if (children && children.length) {
        dfs(children, node.id);
      }
    }
  };

  dfs(tree);
  return result;
}

function treeToListIterative(tree) {
  const result = [];
  const stack = tree.map((node) => ({ node, parentId: null }));

  while (stack.length) {
    const { node, parentId } = stack.pop();
    const { children = [], ...rest } = node;
    result.push({ ...rest, parentId });
    for (let i = children.length - 1; i >= 0; i--) {
      stack.push({ node: children[i], parentId: node.id });
    }
  }
  return result;
}
```

### 考察点

- 解构 `const { children, ...rest }` 剥离嵌套字段是关键技巧
- 迭代版「子节点逆序入栈」保证输出顺序与递归前序一致
- 与数组转树互为逆操作，两者结合可实现树结构的持久化与还原
- 追问：按层序（BFS）输出的写法、只取部分字段的投影裁剪
