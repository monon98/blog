# 简版 JSON.stringify

> 难度：中等 | 标签：递归、序列化、类型判断

## 题目描述

实现一个 `jsonStringify(data)` 函数，模拟 `JSON.stringify` 的核心行为：

- 支持字符串、数字、布尔、null、数组、普通对象的序列化
- 字符串需转义双引号和反斜杠
- 对象/数组中的 `undefined`、函数、Symbol 属性应被**跳过**；顶层传入时序列化为 `undefined`
- 数字为 NaN / Infinity 时输出 `null`
- 处理循环引用：抛出 TypeError（与原生行为一致）

**示例：**

```javascript
jsonStringify({ a: 1, b: undefined, c: [1, "x", null] });
// '{"a":1,"c":[1,"x",null]}'
jsonStringify(NaN); // "null"
```

## 题解

::: details 点击查看题解

### 思路

按 typeof 分支递归处理：

1. 原始值各自映射成字面量；数字需过滤非有限值
2. 字符串转义：`"` 和 `\` 加反斜杠前缀（完整版还要处理控制字符 `\n` 等）
3. 数组遍历拼接 `[...]`；对象遍历自有可枚举键拼 `"key":value`
4. 循环引用用 WeakSet 记录路径上的对象，重复出现即抛错——注意必须在进入子级前 add、离开后 delete（回溯），否则兄弟节点共享引用会误判

### 代码实现

```javascript
function jsonStringify(data) {
  const type = typeof data;

  if (data === null) return "null";
  if (type === "number") {
    return Number.isFinite(data) ? String(data) : "null";
  }
  if (type === "boolean") return String(data);
  if (type === "string") {
    return `"${data.replace(/["\\]/g, (m) => "\\" + m)}"`;
  }
  if (type === "function" || type === "symbol" || data === undefined) {
    return undefined;
  }

  const seen = jsonStringify._seen || (jsonStringify._seen = new WeakSet());

  if (Array.isArray(data)) {
    if (seen.has(data)) throw new TypeError("Converting circular structure to JSON");
    seen.add(data);
    const items = data.map((item) => {
      const s = jsonStringify(item);
      return s === undefined ? "null" : s;
    });
    seen.delete(data);
    return `[${items.join(",")}]`;
  }

  if (type === "object") {
    if (seen.has(data)) throw new TypeError("Converting circular structure to JSON");
    seen.add(data);
    const pairs = [];
    for (const key of Object.keys(data)) {
      const value = jsonStringify(data[key]);
      if (value !== undefined) pairs.push(`"${key}":${value}`);
    }
    seen.delete(data);
    return `{${pairs.join(",")}}`;
  }
}
```

使用完毕记得清理挂载的状态：

```javascript
jsonStringify._seen = null;
```

更工程化的做法是把 `seen` 作为内部参数传递而不是挂在函数属性上：

```javascript
function stringify(data, seen = new WeakSet()) { /* 同上逻辑 */ }
```

### 考察点

- 「跳过」语义的三个层级：数组中变 `null`、对象属性被删除、顶层变 undefined
- 循环检测必须配合回溯（delete）而非只增不减
- 键名也要走字符串转义逻辑
- 追问方向：toJSON 方法、replacer 参数、BigInt 抛错等原生扩展行为
