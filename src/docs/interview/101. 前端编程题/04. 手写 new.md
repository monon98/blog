# 手写 new 操作符

> 难度：简单 | 标签：原型链、构造函数

## 题目描述

实现一个 `myNew` 函数，模拟 `new Ctor(...args)` 的完整过程。要求覆盖 `new` 的四个步骤：

1. 创建一个全新的空对象
2. 把该对象的 `[[Prototype]]` 指向构造函数的 `prototype`
3. 以新对象为 `this` 执行构造函数
4. 构造函数若显式返回一个对象则使用它，否则返回新对象

**示例：**

```javascript
function Animal(name) {
  this.name = name;
}
Animal.prototype.speak = function () {
  return `${this.name} makes a sound`;
};

const dog = myNew(Animal, "Dog");
dog.name; // "Dog"
dog.speak(); // "Dog makes a sound"
dog instanceof Animal; // true
```

## 题解

::: details 点击查看题解

### 思路

核心是用 `Object.create(Ctor.prototype)` 一步完成「建对象 + 挂原型」，然后 `apply` 执行构造函数，最后按「显式返回对象优先」的规则决定结果。注意判断条件必须是「返回值是对象」——构造函数返回数字、字符串等原始值时会被忽略，仍返回新对象。

不用 `Object.create` 时可手动 `obj.__proto__ = Ctor.prototype`，但生产代码推荐标准 API。

### 代码实现

```javascript
function myNew(Ctor, ...args) {
  if (typeof Ctor !== "function") {
    throw new TypeError("myNew expects a constructor function");
  }
  const obj = Object.create(Ctor.prototype);
  const result = Ctor.apply(obj, args);
  return result instanceof Object ? result : obj;
}
```

### 考察点

- `new` 四步流程：创建 → 绑定原型 → 绑定 `this` 执行 → 决定返回值
- `Object.create(proto)` 与 `__proto__` 赋值的等价性
- 构造函数返回原始值被忽略、返回对象被采用的细节规则
- `instanceof` 能通过的原因正是第 2 步建立了原型链

:::
