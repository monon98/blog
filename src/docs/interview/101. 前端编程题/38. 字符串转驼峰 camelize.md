# 字符串转驼峰 camelize

> 难度：入门 | 标签：正则、字符串处理

## 题目描述

实现命名风格互转函数：

- `camelize(str)`：kebab-case / snake_case 转 camelCase，如 `"font-size" → "fontSize"`、`"background_color" → "backgroundColor"`
- `hyphenate(str)`：反向转换 camelCase 转 kebab-case，如 `"WebkitTransform" → "-webkit-transform"`（首字母大写的浏览器前缀属性要加连字符开头）

**示例：**

```javascript
camelize("data-user-id"); // "dataUserId"
camelize("margin_top"); // "marginTop"
hyphenate("backgroundColor"); // "background-color"
hyphenate("WebkitTransition"); // "-webkit-transition"
```

## 题解

::: details 点击查看题解

### 思路

1. **camelize**：正则 `/[-_](\w)/g` 匹配「分隔符+单个字符」，replace 回调里把捕获组转大写
2. **hyphenate**：在大写字母前插入 `-` 再整体转小写；用 `$1$2` 捕获组保留原字母。首字母大写的浏览器前缀场景需额外在串首补 `-`

这类函数在 CSS-in-JS 库、DOM style 操作、模板引擎属性处理中出现频率极高。

### 代码实现

```javascript
function camelize(str) {
  return str.replace(/[-_](\w)/g, (_, char) => char.toUpperCase());
}

function hyphenate(str) {
  return str
    .replace(/([A-Z])/g, "-$1")
    .toLowerCase()
    .replace(/^-/, "");
}
```

带浏览器前缀识别的完整版：

```javascript
function hyphenateStyleName(str) {
  if (/^(Webkit|Moz|O|Ms)[A-Z]/.test(str)) {
    str = `-${str}`;
  }
  return hyphenate(str);
}
```

### 考察点

- replace 第二参数传回调时对捕获组的灵活运用
- 全局匹配标志 g 的必要性
- 变体追问： PascalCase（首字母也大写）、常量 SNAKE_CASE 转换、批量处理对象键名（style 对象预处理）
