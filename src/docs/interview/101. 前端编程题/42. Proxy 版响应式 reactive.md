# Proxy 版响应式 reactive

> 难度：中等 | 标签：Vue3、Proxy、Reflect

## 题目描述

用 `Proxy` 实现一个迷你响应式系统，模拟 Vue3 的 `reactive` 与 `effect`：

- `reactive(obj)` 返回代理对象，get 时依赖收集、set 时触发更新
- 支持嵌套对象（惰性代理：访问子对象时才递归转换）
- 支持 deleteProperty 拦截与新增属性响应
- 提供 `effect(fn)`：首次立即执行，期间读取的属性变更时自动重新执行

**示例：**

```javascript
const state = reactive({ count: 0, user: { name: "Tom" } });

effect(() => {
  console.log("render:", state.count, state.user.name);
});

state.count++; // "render: 1 Tom"
state.user.name = "Jerry"; // "render: 1 Jerry"
```

## 题解

::: details 点击查看题解

### 思路

与 defineProperty 版的对应关系：

1. **track（收集）**：双层 WeakMap 索引 `targetMap: target → key → Set<effect>`。Proxy 是对整个对象的拦截，天然覆盖新增/删除属性
2. **trigger（触发）**：set/deleteProperty 中取出对应 effect 集合执行
3. **嵌套**：get 返回值是对象时再包一层 reactive 并缓存（WeakMap 去重），实现惰性深层代理
4. effect 执行前把自身压入栈支持嵌套 effect，结束后弹出恢复外层

### 代码实现

```javascript
const targetMap = new WeakMap();
let activeEffect = null;
const effectStack = [];
const reactiveMap = new WeakMap();

function track(target, key) {
  if (!activeEffect) return;
  let depsMap = targetMap.get(target);
  if (!depsMap) {
    targetMap.set(target, (depsMap = new Map()));
  }
  let deps = depsMap.get(key);
  if (!deps) {
    depsMap.set(key, (deps = new Set()));
  }
  deps.add(activeEffect);
}

function trigger(target, key) {
  const depsMap = targetMap.get(target);
  if (!depsMap) return;
  const effects = depsMap.get(key);
  if (effects) {
    [...effects].forEach((fn) => fn());
  }
}

function reactive(obj) {
  const existing = reactiveMap.get(obj);
  if (existing) return existing;

  const proxy = new Proxy(obj, {
    get(target, key, receiver) {
      track(target, key);
      const result = Reflect.get(target, key, receiver);
      if (typeof result === "object" && result !== null) {
        return reactive(result);
      }
      return result;
    },
    set(target, key, value, receiver) {
      const oldValue = target[key];
      const success = Reflect.set(target, key, value, receiver);
      if (!Object.is(oldValue, value)) {
        trigger(target, key);
      }
      return success;
    },
    deleteProperty(target, key) {
      const hadKey = key in target;
      const result = Reflect.deleteProperty(target, key);
      if (hadKey && result) {
        trigger(target, key);
      }
      return result;
    }
  });

  reactiveMap.set(obj, proxy);
  return proxy;
}

function effect(fn) {
  function runEffect() {
    try {
      activeEffect = runEffect;
      effectStack.push(runEffect);
      return fn();
    } finally {
      effectStack.pop();
      activeEffect = effectStack[effectStack.length - 1] || null;
    }
  }
  runEffect();
  return runEffect;
}
```

### 考察点

- Proxy 十三种拦截中响应式最常用的四种：get/set/deleteProperty/has
- Reflect 的意义：保证 receiver 正确传递，配合继承场景
- 惰性代理 + WeakMap 缓存避免重复包装与内存泄漏
- 与 defineProperty 版对比：无需 $set、数组原生可用、按需初始化性能更好；代价是不兼容 IE11
