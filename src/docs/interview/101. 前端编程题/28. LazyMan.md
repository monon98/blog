# LazyMan

> 难度：中等 | 标签：链式调用、任务队列、闭包

## 题目描述

实现 `LazyMan(name)`，满足以下调用规则：

```javascript
LazyMan("Tony");
// Hi I am Tony

LazyMan("Tony").sleep(2).eat("lunch");
// Hi I am Tony
// （等待 2 秒）
// 等待了2秒...
// I am eating lunch

LazyMan("Tony").sleepFirst(3).eat("dinner");
// （等待 3 秒）
// 等待了3秒...
// Hi I am Tony
// I am eating dinner
```

- `sleep(n)`：后续动作延迟 n 秒
- `sleepFirst(n)`：插队到所有已排队任务之前
- 所有方法支持链式继续调用

## 题解

::: details 点击查看题解

### 思路

任务队列 + 自动调度两件套：

1. 构造时把「打招呼」和后续操作都推入队列；构造函数里用 `setTimeout(..., 0)` 把调度启动推迟到当前宏任务结束——这样 sleepFirst 的 unshift 插队能赶在调度开始前完成
2. 每个方法只负责入队并返回 this 维持链式
3. 调度器 `next()` 取队首执行，任务内部完成后手动调 next 驱动下一个——典型的「接力」控制流

### 代码实现

```javascript
class LazyManClass {
  constructor(name) {
    this.name = name;
    this.tasks = [];
    this.tasks.push(() => {
      console.log(`Hi I am ${name}`);
      this.next();
    });
    setTimeout(() => this.next());
  }

  next() {
    const task = this.tasks.shift();
    task && task();
  }

  sleep(seconds) {
    this.tasks.push(() => this._pause(seconds));
    return this;
  }

  sleepFirst(seconds) {
    this.tasks.unshift(() => this._pause(seconds));
    return this;
  }

  eat(food) {
    this.tasks.push(() => {
      console.log(`I am eating ${food}`);
      this.next();
    });
    return this;
  }

  _pause(seconds) {
    setTimeout(() => {
      console.log(`等待了${seconds}秒...`);
      this.next();
    }, seconds * 1000);
  }
}

function LazyMan(name) {
  return new LazyManClass(name);
}
```

### 考察点

- 「先收集后执行」的管道思想与 setTimeout 启动时机
- unshift 插队实现优先级
- 变体追问：把 sleep 改成 Promise 化（返回 Promise 支持 await）、加入错误中断机制
