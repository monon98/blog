# 手写 React 的 useState

> 难度：中等 | 标签：React、Hooks、闭包

## 题目描述

用普通 JavaScript 模拟 React 函数组件的 useState Hook：

- `useState(initialValue)` 返回 `[state, setState]`
- 多次调用时各 state 相互独立（按调用顺序索引）
- setState 支持传入新值或函数（函数式更新，拿到上一次的值）
- 更新后触发组件重新渲染，且渲染间 state 保持

**示例：**

```javascript
function App() {
  const [count, setCount] = useState(0);
  const [name, setName] = useState("Tom");

  setCount(1);
  setCount((prev) => prev + 1);
  // 渲染结果中 count === 2
}
```

## 题解

::: details 点击查看题解

### 思路

Hooks 的魔法本质是「模块级变量 + 调用顺序索引」：

1. 用外部数组 `states` 存所有状态值，`stateIndex` 记录当前取到第几个
2. 每次 render 开始前把 index 归零——因为函数组件每次执行都会按相同顺序调用 Hooks，第 n 个 useState 就对应槽位 n。这就是「不能在条件/循环里调 Hooks」的原因
3. setState 是闭包，捕获自己创建时的 currentIndex；更新后重置 index 并触发重新渲染
4. 函数式更新：新值为函数时以旧值调用

### 代码实现

```javascript
let states = [];
let stateIndex = 0;
let renderCallback = null;

function useState(initialValue) {
  const currentIndex = stateIndex;
  states[currentIndex] =
    states[currentIndex] !== undefined ? states[currentIndex] : initialValue;

  function setState(newValue) {
    states[currentIndex] =
      typeof newValue === "function"
        ? newValue(states[currentIndex])
        : newValue;
    render();
  }

  stateIndex++;
  return [states[currentIndex], setState];
}

function render() {
  if (!renderCallback) return;
  stateIndex = 0;
  renderCallback();
}

function mount(App) {
  renderCallback = App;
  render();
}
```

使用演示：

```javascript
function App() {
  const [count, setCount] = useState(0);
  const [name, setName] = useState("Tom");
  console.log(count, name);
}

mount(App);
```

### 考察点

- 「链表/数组 + 游标」是所有 Hook 实现的公共骨架（React 内部为 fiber.memoizedState 链表）
- 为什么 Hooks 不能放在条件分支——顺序索引会错位
- 函数式更新的意义：连续多次 setState 基于最新值计算
- 追问：批处理如何实现（收集变更统一 render）、跨组件状态如何提升到 store
