# 手写 call

> 难度：入门 | 标签：this、原型、Function

## 题目描述

实现 `Function.prototype.myCall`，模拟原生 `call` 方法：

- 第一个参数为要绑定的 `this` 值，后续参数逐个作为函数实参
- `context` 为 `null` 或 `undefined` 时，非严格模式下应指向全局对象（浏览器中的 `window`）
- 立即执行函数并返回其结果，且不能在调用后残留对 `context` 的修改

**示例：**

```javascript
function greet(greeting, punctuation) {
  return `${greeting}, ${this.name}${punctuation}`;
}

greet.myCall({ name: "Alice" }, "Hello", "!");
// "Hello, Alice!"
```

## 题解

::: details 点击查看题解

### 思路

核心技巧：**把函数临时挂到目标对象的一个属性上再调用**——方法调用时 `this` 自然指向宿主对象。要点：

1. 用 `Symbol` 作属性名，避免与对象已有属性冲突、不可枚举更安全
2. 调用完立刻 `delete`，保证不污染原对象
3. `context` 为空时兜底到 `globalThis`（兼容浏览器 window 与 Node 全局）

### 代码实现

```javascript
Function.prototype.myCall = function (context, ...args) {
  if (typeof this !== "function") {
    throw new TypeError("myCall must be called on a function");
  }
  context = context ?? globalThis;
  const key = Symbol();
  context[key] = this;
  const result = context[key](...args);
  delete context[key];
  return result;
};
```

### 考察点

- 「属性挂载」是模拟隐式绑定的经典手法，面试常要求解释原理
- `Symbol` 避免属性名冲突；用完即删保持无副作用
- ES3 时代写法用 `context.fn = this` + `eval("context.fn(" + args + ")")`，现代写法用剩余参数展开即可
- 与 `apply` 的区别只在参数收集方式（见下一篇）
