# 手写 bind

> 难度：简单 | 标签：this、闭包、new

## 题目描述

实现 `Function.prototype.myBind`，要求满足原生 `bind` 的全部关键特性：

- 返回一个新函数，其 `this` 永久绑定到第一个参数
- 支持参数预设：调用新函数时把 bind 时的参数与新参数拼接后传给原函数
- 用 `new` 调用绑定后的函数时，`new` 的优先级高于 `bind`——`this` 指向新创建的对象，且新函数的原型应与原函数关联（`instanceof` 判定成立）

**示例：**

```javascript
function Person(name, age) {
  this.name = name;
  this.age = age;
}

const BoundPerson = Person.myBind(null, "默认名");
const p = new BoundPerson(18);
p.name; // "默认名"
p instanceof Person; // true
```

## 题解

::: details 点击查看题解

### 思路

三个要点：

1. **闭包保存原函数和预设参数**，返回的新函数内部用 `apply(thisArg, [...args, ...rest])` 合并两次参数
2. **`new` 优先级**：通过 `this instanceof fBound` 判断新函数是否被 `new` 调用——是则忽略绑定的 `context`，让 `this` 保持为实例本身
3. **原型修正**：不能直接 `fBound.prototype = fn.prototype`（会互相影响），要用 `Object.create` 建立中间层，既保证 `instanceof` 成立又隔离修改

### 代码实现

```javascript
Function.prototype.myBind = function (context, ...presetArgs) {
  const self = this;
  function fBound(...restArgs) {
    return self.apply(
      this instanceof fBound ? this : context,
      presetArgs.concat(restArgs)
    );
  }
  fBound.prototype = Object.create(self.prototype);
  return fBound;
};
```

### 考察点

- `bind` 与 `call/apply` 的本质区别：不立即执行，返回永久绑定的新函数
- `new` 操作符会以新函数为构造器创建对象，此时 `this instanceof fBound` 为真
- `Object.create(fn.prototype)` 维护原型链且避免共享引用
- 进阶：ES5 时代常用中间空函数 `F` 继承原型，思路一致

:::
