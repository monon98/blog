# 手写 Promise.race

> 难度：入门 | 标签：Promise、异步

## 题目描述

实现 `myRace(promises)`：

- 多个任务赛跑，第一个 settle（无论成功失败）的结果决定整体状态
- 其余任务的结果被忽略
- 空数组时永远 pending

**示例：**

```javascript
myRace([timeout(5000), fetch(url)]).then(render, showError);
// fetch 先返回则渲染，5 秒超时先到则报错
```

## 题解

::: details 点击查看题解

### 思路

最简单的聚合器：每个元素都挂上同一组 resolve/reject，外层 Promise 的状态只可能被第一个到达者改变一次（内部状态机保证后续变更无效）。无需任何计数。

空数组时没有任何回调触发，返回的 Promise 将永久 pending——这与原生行为一致，可作为加分细节指出。

### 代码实现

```javascript
MyPromise.race = function (promises) {
  return new MyPromise((resolve, reject) => {
    for (const item of promises) {
      MyPromise.resolve(item).then(resolve, reject);
    }
  });
};
```

### 考察点

- Promise 状态不可逆特性是 race 得以成立的根基
- 典型应用：接口超时控制（race 一个 setTimeout reject）、多 CDN 竞速取最快
- 与 any 的区别：race 对成功失败一视同仁，any 只认第一个成功
- 追问：如何给 race 版超时加上「取消底层请求」——引出 AbortController

:::
