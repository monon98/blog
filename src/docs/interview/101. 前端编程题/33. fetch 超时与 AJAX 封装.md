# fetch 超时与 AJAX 封装

> 难度：中等 | 标签：网络、Promise、AbortController

## 题目描述

封装一个带超时控制的请求函数 `request(url, options)`：

- 基于 fetch 实现：超时未响应则中止请求并 reject 超时错误
- 使用 AbortController 真正取消底层连接（而非仅忽略结果）
- 附带 XMLHttpRequest 的 Promise 化版本，展示无 fetch 环境的等价实现
- 统一处理非 2xx 状态码为 reject

**示例：**

```javascript
request("/api/user", { timeout: 5000 })
  .then((data) => console.log(data))
  .catch((e) => {
    if (e.name === "AbortError") console.log("请求超时");
  });
```

## 题解

::: details 点击查看题解

### 思路

fetch 本身没有 timeout 参数，标准做法是 race + AbortController：

1. 创建 controller，把 `controller.signal` 传给 fetch
2. 定时器到点调 `controller.abort()`——fetch 立即以 AbortError reject，连接真正被取消
3. 成功后 clearTimeout 清理；race 的败者定时器也要清理避免悬挂

XHR 版本在回调里手动 resolve/reject，`xhr.timeout` 与 `ontimeout` 是原生能力。

### 代码实现

```javascript
function request(url, { timeout = 10000, ...options } = {}) {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), timeout);

  return fetch(url, { ...options, signal: controller.signal })
    .then((response) => {
      if (!response.ok) {
        throw new Error(`HTTP ${response.status}: ${response.statusText}`);
      }
      return response.json();
    })
    .finally(() => clearTimeout(timer));
}

function requestWithXHR(url, { timeout = 10000, method = "GET" } = {}) {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    xhr.open(method, url);
    xhr.timeout = timeout;
    xhr.onload = () => {
      if (xhr.status >= 200 && xhr.status < 300) {
        try {
          resolve(JSON.parse(xhr.responseText));
        } catch (error) {
          reject(error);
        }
      } else {
        reject(new Error(`HTTP ${xhr.status}`));
      }
    };
    xhr.onerror = () => reject(new Error("Network Error"));
    xhr.ontimeout = () => reject(new Error("timeout"));
    xhr.send();
  });
}
```

### 考察点

- AbortController 是唯一能真正取消 fetch 的方式；「race 掉结果」不等于取消请求
- finally 里清理定时器防止泄漏与误 abort 后续复用的 controller
- 非 2xx 不走 reject 是 fetch 的著名设计争议点，必须手动检查 response.ok
- 追问：重试（见 retry 一题）、请求去重、并发上限如何叠加在这层封装之上
