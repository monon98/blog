# 手写深拷贝

> 难度：中等 | 标签：递归、WeakMap、引用类型

## 题目描述

实现一个 `deepClone(value)` 函数，完成任意 JavaScript 值的深拷贝，要求：

- 正确拷贝普通对象、数组、`Map`、`Set`、`Date`、`RegExp`
- 处理**循环引用**（对象内部互相引用不能死循环）
- 保留原型链之外的基本要求：不丢失嵌套层级、修改副本不影响原数据
- `undefined`、函数等不可序列化值按原样返回或跳过即可

**示例：**

```javascript
const obj = { a: 1, nested: { b: [1, 2] } };
obj.self = obj;
const clone = deepClone(obj);
clone.nested.b.push(3);
obj.nested.b; // [1, 2]，不受影响
clone.self === clone; // true，循环结构被保留
```

## 题解

::: details 点击查看题解

### 思路

递归 + 缓存表两件套：

1. **递归拆解**：原始值直接返回；特殊类型（Date/RegExp）调用对应构造器；Map/Set 单独处理键值与成员的深拷贝
2. **循环引用检测**：用 `WeakMap` 记录「原对象 → 副本」映射。进入递归前先查缓存，命中说明已克隆过，直接复用——同时解决死循环与引用一致性两个问题
3. 选 `WeakMap` 而非 `Map`：键为弱引用，不影响垃圾回收

### 代码实现

```javascript
function deepClone(value, map = new WeakMap()) {
  if (value === null || typeof value !== "object") return value;

  if (value instanceof Date) return new Date(value);
  if (value instanceof RegExp) return new RegExp(value.source, value.flags);

  if (value instanceof Map) {
    if (map.has(value)) return map.get(value);
    const clone = new Map();
    map.set(value, clone);
    value.forEach((v, k) => clone.set(deepClone(k, map), deepClone(v, map)));
    return clone;
  }
  if (value instanceof Set) {
    if (map.has(value)) return map.get(value);
    const clone = new Set();
    map.set(value, clone);
    value.forEach((v) => clone.add(deepClone(v, map)));
    return clone;
  }

  if (map.has(value)) return map.get(value);
  const clone = Array.isArray(value) ? [] : Object.create(Object.getPrototypeOf(value));
  map.set(value, clone);

  Reflect.ownKeys(value).forEach((key) => {
    clone[key] = deepClone(value[key], map);
  });
  return clone;
}
```

### 考察点

- 为什么 `JSON.parse(JSON.stringify())` 不合格：丢函数/undefined/Symbol、Date 变字符串、不支持 Map/Set、循环引用直接报错
- 循环引用必须用缓存表在「递归前」检查，而不是克隆完再存
- 进阶方向：structuredClone API 的能力边界；如何用栈把递归改成迭代避免爆栈；Symbol 键与访问器属性的处理策略
