# 数组扁平化 flat

> 难度：简单 | 标签：递归、reduce、数组

## 题目描述

实现一个 `flatten(arr, depth)` 函数，把多层嵌套数组拍平：

- 默认拍平一层（与原生 `Array.prototype.flat(1)` 一致）
- `depth` 指定拍平层数；传 `Infinity` 时完全拍平
- 不修改原数组，返回新数组

**示例：**

```javascript
flatten([1, [2, [3, [4]]]]); // [1, 2, [3, [4]]]
flatten([1, [2, [3, [4]]]], Infinity); // [1, 2, 3, 4]
```

## 题解

::: details 点击查看题解

### 思路

两种主流实现：

1. **递归 + reduce**：遍历元素，是数组且层数未用尽就递归展开后 concat，否则原样放入。代码最直观
2. **迭代 + 栈**：用 while 循环反复「展开一层」直到没有嵌套或达到深度，避免深数组的递归栈开销

面试建议先写递归版，再口头给出迭代优化思路。

### 代码实现

```javascript
function flatten(arr, depth = 1) {
  if (depth <= 0) return arr.slice();
  return arr.reduce(
    (acc, item) =>
      acc.concat(Array.isArray(item) ? flatten(item, depth - 1) : item),
    []
  );
}
```

迭代版（利用原生 flat 每次拍一层的特性模拟）：

```javascript
function flattenIterative(arr, depth = 1) {
  let result = arr.slice();
  for (let d = 0; d < depth; d++) {
    let hasNested = false;
    result = result.reduce((acc, item) => {
      if (Array.isArray(item)) {
        hasNested = true;
        acc.push(...item);
      } else {
        acc.push(item);
      }
      return acc;
    }, []);
    if (!hasNested) break;
  }
  return result;
}
```

### 考察点

- reduce 是「累积构建新数组」场景的首选工具
- `depth <= 0` 直接浅拷贝返回，保证与原生语义一致
- 迭代版的意义：极端深层嵌套时规避调用栈溢出
- 相关变体：拍平的同时去重、按条件过滤空位（原生 flat 会移除 empty slots）
