# 数字千分位格式化

> 难度：入门 | 标签：正则、字符串、Intl

## 题目描述

实现数字千分位格式化 `formatNumber(num)`：

- 每 3 位插入一个逗号：`1234567 → "1,234,567"`
- 正确处理小数部分（小数不加逗号）、负数、0
- 给出正则与循环两种实现，并说明如何用内置 API 直接完成

**示例：**

```javascript
formatNumber(1234567.89); // "1,234,567.89"
formatNumber(-9876543); // "-9,876,543"
```

## 题解

::: details 点击查看题解

### 思路

三种方案：

1. **正则前瞻**：`/\B(?=(\d{3})+(?!\d))/g` 在「非单词边界且后面是 3n 位数字」处插逗号。先 split 小数点只处理整数部分，避免小数位被误分组
2. **循环取模**：从末尾每 3 位切片拼接，逻辑最直白，面试手写不易出错
3. **内置 API**：`new Intl.NumberFormat().format()` 或 `toLocaleString()`，生产代码首选

### 代码实现

```javascript
function formatNumber(num) {
  const [intPart, decimalPart] = String(num).split(".");
  const sign = intPart.startsWith("-") ? "-" : "";
  const digits = intPart.replace(/^-/, "");
  const grouped = digits.replace(/\B(?=(\d{3})+(?!\d))/g, ",");
  return sign + grouped + (decimalPart ? "." + decimalPart : "");
}

function formatNumberLoop(num) {
  const [intPart, decimalPart] = String(num).split(".");
  let result = "";
  let count = 0;
  for (let i = intPart.length - 1; i >= 0; i--) {
    result = intPart[i] + result;
    if (++count % 3 === 0 && i > 0 && intPart[i - 1] !== "-") {
      result = "," + result;
    }
  }
  return result + (decimalPart ? "." + decimalPart : "");
}

const formatNumberNative = (num) =>
  new Intl.NumberFormat("en-US").format(num);
```

### 考察点

- 零宽度断言 `(?=...)` 与 `\B` 的配合是正则考点核心
- 负号与小数点的边界保护
- Intl.NumberFormat 支持本地化货币/百分比，工程上应优先使用而非自造轮子
