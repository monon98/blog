# 防抖函数 debounce

> 难度：简单 | 标签：闭包、定时器、性能优化

## 题目描述

实现防抖函数 `debounce(fn, wait, immediate)`：

- 在连续触发期间只执行最后一次：每次触发都重置等待计时器
- 距上次调用超过 `wait` 毫秒后才真正执行原函数
- 可选参数 `immediate = true` 时改为「首次立即执行，后续触发在静默期结束后才允许再次立即执行」
- 正确保留 `this` 与参数透传

**示例：**

```javascript
const onInput = debounce((e) => search(e.target.value), 500);
input.addEventListener("input", onInput);
```

## 题解

::: details 点击查看题解

### 思路

闭包持有 `timer` 变量：每次触发先 `clearTimeout` 取消上一次计划，再安排新的延迟调用——只有停止触发满 `wait` 后回调才会真正跑起来。

immediate 版本的关键是区分「冷却期」：立即执行后置一个标记，直到定时器到期才清除标记，期间的触发只做重置不做执行。

典型应用：搜索框输入联想、窗口 resize 结束后的重算、按钮防连点。

### 代码实现

```javascript
function debounce(fn, wait = 300, immediate = false) {
  let timer = null;

  function debounced(...args) {
    if (timer) clearTimeout(timer);

    if (immediate && !timer) {
      fn.apply(this, args);
    }

    timer = setTimeout(() => {
      timer = null;
      if (!immediate) {
        fn.apply(this, args);
      }
    }, wait);
  }

  debounced.cancel = () => {
    clearTimeout(timer);
    timer = null;
  };

  return debounced;
}
```

### 考察点

- 防抖 vs 节流的语义区别：重置计时（等安静）vs 固定频率（限流）
- `fn.apply(this, args)` 保证事件处理器中 this 与参数正确传递
- cancel 方法用于组件卸载时清理，避免内存泄漏与迟到回调
- 追问方向：带返回值版本（用 Promise 包装结果）、lodash 的 maxWait 参数思想
