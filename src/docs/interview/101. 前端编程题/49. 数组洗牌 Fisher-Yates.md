# 数组洗牌 Fisher-Yates

> 难度：入门 | 标签：算法、随机、数组

## 题目描述

实现 `shuffle(arr)`，将数组元素随机打乱：

- 要求每个排列出现的概率完全相等（均匀分布），不能使用 `sort(() => Math.random() - 0.5)` 这种错误方案
- 不修改原数组（返回新数组）
- 说明 Fisher-Yates 算法的正确性证明思路

**示例：**

```javascript
shuffle([1, 2, 3, 4, 5]); // 例如 [3,1,5,2,4]
```

## 题解

::: details 点击查看题解

### 思路

Fisher-Yates（Knuth 洗牌）：从最后一个位置开始，每次从未处理的「前 i+1 个元素」中随机取一个与当前位置交换，然后 i 减一。

正确性：第 k 轮时剩余 n-k+1 个候选，每个被选中概率 1/(n-k+1)，逐位相乘得任意排列概率 = 1/n!，均匀分布成立。

`sort(random)` 错误原因：比较函数不满足一致性与传递性，排序结果依赖引擎实现，分布严重偏斜且不同浏览器结果不同。

### 代码实现

```javascript
function shuffle(arr) {
  const result = [...arr];
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [result[i], result[j]] = [result[j], result[i]];
  }
  return result;
}
```

### 考察点

- 「随机交换范围随进度收缩」是不重复抽样的关键
- 为什么不能 sort(Math.random)：非一致比较器 + 引擎排序实现差异
- 应用：抽奖、随机出题、歌单乱播
- 变体追问：部分洗牌（只取 m 个不重复随机样本——蓄水池抽样）、密码学安全场景换用 crypto.getRandomValues
