# 简版模板引擎

> 难度：中等 | 标签：正则、字符串模板、插值

## 题目描述

实现一个迷你模板引擎 `render(template, data)`，支持：

::: v-pre
- 插值语法 `{{ name }}`：替换为 data 中对应值（容忍多余空格）
- 嵌套路径取值：`{{ user.name }}`、`{{ list[0].title }}`
:::

- 变量不存在时替换为空字符串
- 列表语法 `{each items as item}...{/each}` 可作为进阶扩展口头说明思路

**示例：**

```javascript
render("你好，{{ user.name }}！你有 {{ count }} 条消息", {
  user: { name: "小明" },
  count: 3
});
// "你好，小明！你有 3 条消息"
```

## 题解

::: details 点击查看题解

### 思路

一次 replace 搞定主干：正则捕获花括号内的路径表达式，回调里复用 deepGet 取值，nullish 时兜底空串。

进阶的 each / if 语法则不能再用单次 replace——需要「编译」思想：先把模板解析成 token 序列（文本、变量、指令），再遍历 token 拼接结果；Vue 的 Mustache 编译期就是这一思路的完整版。

### 代码实现

```javascript
function render(template, data = {}) {
  return template.replace(
    /\{\{\s*([\w$.[\]]+)\s*\}\}/g,
    (_, expr) => {
      const value = deepGet(data, expr);
      return value == null ? "" : String(value);
    }
  );
}
```

XSS 防护提示：若渲染 HTML 场景需先转义实体：

```javascript
const escapeHtml = (str) =>
  str.replace(/[&<>"']/g, (m) => ({
    "&": "&amp;",
    "<": "&lt;",
    ">": "&gt;",
    '"': "&quot;",
    "'": "&#39;"
  })[m]);
```

### 考察点

- 正则捕获组 + replace 回调的组合是模板替换类需求的标准解法
- 与 deepGet 一题联动，体现工具函数复用意识
- 安全意识追问：为什么插值必须考虑转义、v-html 的风险
- 进阶方向：token 化编译、动态求值的原理与 CSP 限制
