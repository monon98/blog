# 手写 Object.create

> 难度：简单 | 标签：原型、继承

## 题目描述

实现一个 `create(proto, propertiesObject)` 函数，模拟 `Object.create`：

- 创建一个新对象，使其 `[[Prototype]]` 指向传入的 `proto`
- 支持 `proto` 为 `null`（创建无原型的纯净对象）
- 第二个参数可选，语义同 `Object.defineProperties`，用于定义属性描述符

**示例：**

```javascript
const base = { greet() { return "hi"; } };
const child = create(base);
child.greet(); // "hi"
Object.getPrototypeOf(child) === base; // true
```

## 题解

::: details 点击查看题解

### 思路

经典「借用构造函数」技巧：定义临时函数 `F`，把它的 `prototype` 设为 `proto`，再 `new F()`——实例的原型自然就是 `proto`。

两个细节：`proto` 为 `null` 时 `F.prototype = null` 会让浏览器回退到默认原型，必须用 `Object.setPrototypeOf(obj, null)` 显式修正；第二个参数存在时调用 `Object.defineProperties` 完成属性定义。

参数校验规则与原生一致：`proto` 只能是对象、函数或 `null`。

### 代码实现

```javascript
function create(proto, propertiesObject) {
  if (
    proto !== null &&
    typeof proto !== "object" &&
    typeof proto !== "function"
  ) {
    throw new TypeError("Object prototype may only be an Object or null");
  }

  function F() {}
  F.prototype = proto;
  const obj = new F();

  if (proto === null) {
    Object.setPrototypeOf(obj, null);
  }
  if (propertiesObject !== undefined) {
    Object.defineProperties(obj, propertiesObject);
  }
  return obj;
}
```

更简洁的现代写法可以完全绕过 `F`：

```javascript
function create(proto, propertiesObject) {
  const obj = {};
  Object.setPrototypeOf(obj, proto);
  if (propertiesObject !== undefined) {
    Object.defineProperties(obj, propertiesObject);
  }
  return obj;
}
```

### 考察点

- 「原型式继承」的底层实现原理
- `new F()` 时若 `F.prototype` 为 `null` 会回退到 `Object.prototype`，需二次修正
- `Object.create(null)` 创建的对象没有 `toString` / `hasOwnProperty` 等方法，适合做纯字典
- 该实现是理解手写 `bind` 原型修正的共同基础
