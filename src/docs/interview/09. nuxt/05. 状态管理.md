# 状态管理

## 1. useState

::: details
Nuxt 内置的全局响应式状态管理。

### 基本使用

```vue
<script setup>
// 全局响应式状态
const count = useState('counter', () => 0);

const increment = () => count.value++;
</script>
```

### 服务端渲染安全

```vue
<script setup>
// useState 在服务端和客户端之间共享状态
// 避免 hydration mismatch
const user = useState('user', () => null);

// 仅在客户端执行
onMounted(async () => {
  user.value = await fetchUser();
});
</script>
```

### 重置状态

```vue
<script setup>
const counter = useState('counter', () => 0);

// 重置为初始值
const reset = () => {
  useState('counter', () => 0);
};
</script>
```

### 总结

`useState` 是 Nuxt 内置的轻量级状态管理，适用于简单的全局状态。

:::

## 2. useAsyncData

::: details
`useAsyncData` 用于异步数据获取，支持 SSR。

### 基本使用

```vue
<script setup>
const { data, pending, error, refresh } = await useAsyncData('posts', () => {
  return $fetch('/api/posts');
});
</script>

<template>
  <div v-if="pending">加载中...</div>
  <div v-else-if="error">错误: {{ error.message }}</div>
  <ul v-else>
    <li v-for="post in data" :key="post.id">{{ post.title }}</li>
  </ul>
</template>
```

### 带选项

```vue
<script setup>
const { data } = await useAsyncData('posts', () => {
  return $fetch('/api/posts');
}, {
  transform: (data) => data.filter(p => p.published),
  default: () => []
});
</script>
```

### 组合使用

```vue
<script setup>
// 组合多个异步数据
const { data: posts } = await useAsyncData('posts', () => $fetch('/api/posts'));
const { data: categories } = await useAsyncData('categories', () => $fetch('/api/categories'));
</script>
```

### 总结

`useAsyncData` 是 Nuxt 中获取异步数据的主要方式，支持 SSR 和缓存。

:::

## 3. useFetch

::: details
`useFetch` 是 `useAsyncData` + `$fetch` 的简化版本。

### 基本使用

```vue
<script setup>
// 简化的数据获取
const { data: posts } = await useFetch('/api/posts');
</script>

<template>
  <ul>
    <li v-for="post in posts" :key="post.id">{{ post.title }}</li>
  </ul>
</template>
```

### 响应式参数

```vue
<script setup>
const page = ref(1);

const { data } = await useFetch('/api/posts', {
  query: { page }
});

// 当 page 变化时会自动重新请求
</script>
```

### 监听变化

```vue
<script setup>
const { data, refresh } = await useFetch('/api/posts', {
  watch: [someRef]
});
</script>
```

### useFetch vs useAsyncData

| 特性 | useFetch | useAsyncData |
|------|----------|--------------|
| 简洁性 | 更简洁 | 更灵活 |
| 自定义请求 | 不支持 | 支持 |
| 适用场景 | 简单 GET 请求 | 复杂请求逻辑 |

### 总结

`useFetch` 适用于简单的数据获取场景，复杂场景推荐使用 `useAsyncData`。

:::

## 4. Pinia 集成

::: details
Nuxt 完美支持 Pinia 状态管理。

### 安装配置

```bash
npm install @pinia/nuxt
```

```javascript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@pinia/nuxt']
});
```

::: tip
Pinia 的基础用法（定义 Store、State、Getters、Actions）详见 [Vue 状态管理](../05.%20vue/06.%20路由与状态管理#vuex-与-pinia)。
:::

### Nuxt 中使用

```vue
<script setup>
const counter = useCounterStore();
</script>

<template>
  <div>
    <p>计数: {{ counter.count }}</p>
    <button @click="counter.increment">+1</button>
  </div>
</template>
```

### SSR 安全

```typescript
// stores/counter.ts
export const useCounterStore = defineStore('counter', {
  state: () => ({
    count: 0
  }),
  
  actions: {
    // 在服务端和客户端都能正常工作
    async fetchData() {
      const data = await $fetch('/api/data');
      this.count = data.count;
    }
  }
});
```

### 总结

Pinia 适用于复杂的状态管理场景，Nuxt 通过 `@pinia/nuxt` 模块提供完美支持。

:::
