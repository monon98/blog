# 路由与目录

## 1. 文件路由

::: details
Nuxt 基于文件系统自动生成路由。

### 基础路由

```
pages/
├── index.vue      → /
├── about.vue      → /about
└── blog/
    ├── index.vue  → /blog
    └── [id].vue   → /blog/:id
```

### 动态路由

```vue
<!-- pages/blog/[id].vue -->
<template>
  <div>文章 ID: {{ $route.params.id }}</div>
</template>

<script setup>
const route = useRoute();
console.log(route.params.id);
</script>
```

### 可选动态路由

```vue
<!-- pages/product/[[id]].vue -->
<!-- 匹配 /product 和 /product/123 -->
<script setup>
const route = useRoute();
const id = route.params.id;  // 可能为 undefined
</script>
```

### 嵌套路由

```
pages/
├── user/
│   ├── [id]/
│   │   ├── index.vue  → /user/:id
│   │   └── posts.vue  → /user/:id/posts
│   └── index.vue      → /user
```

```vue
<!-- pages/user/[id].vue -->
<template>
  <div>
    <NuxtPage />  <!-- 渲染子路由 -->
  </div>
</template>
```

### 总结

Nuxt 的路由系统基于文件系统，支持动态路由和嵌套路由。

:::

## 2. 路由中间件

::: details
路由中间件可以在路由跳转前后执行逻辑。

### 全局中间件

```typescript
// middleware/auth.ts
export default defineNuxtRouteMiddleware((to, from) => {
  const auth = useAuth();
  
  if (to.path !== '/login' && !auth.isLoggedIn) {
    return navigateTo('/login');
  }
});
```

### 页面级中间件

```vue
<!-- pages/dashboard.vue -->
<script setup>
definePageMeta({
  middleware: 'auth'
});
```

### 匿名中间件

```vue
<script setup>
definePageMeta({
  middleware: (to, from) => {
    console.log('路由变化');
  }
});
</script>
```

### 中间件顺序

```vue
<script setup>
definePageMeta({
  middleware: ['auth', 'log']  // 按顺序执行
});
</script>
```

### 总结

路由中间件是处理权限验证、日志记录等逻辑的常用方式。

:::

## 3. 路由导航

::: details
Nuxt 提供多种路由导航方式。

### 模板内导航

```vue
<template>
  <!-- 声明式 -->
  <NuxtLink to="/about">关于</NuxtLink>
  
  <!-- 带查询参数 -->
  <NuxtLink :to="{ path: '/blog', query: { page: 1 } }">博客</NuxtLink>
</template>
```

### 编程式导航

```vue
<script setup>
const router = useRouter();

// 基本跳转
router.push('/about');

// 带参数
router.push({ path: '/blog', query: { page: 1 } });

// 替换当前页面
router.replace('/login');

// 返回
router.back();
</script>
```

### 导航守卫

```vue
<script setup>
// 页面离开前确认
onBeforeRouteLeave((to, from) => {
  if (hasUnsavedChanges.value) {
    return confirm('有未保存的更改，确定离开吗？');
  }
});
</script>
```

### 总结

Nuxt 提供了声明式和编程式两种导航方式。

:::

## 4. 布局系统

::: details
Nuxt 支持布局组件，实现页面布局复用。

### 默认布局

```vue
<!-- layouts/default.vue -->
<template>
  <div>
    <header>导航栏</header>
    <main>
      <slot />  <!-- 页面内容 -->
    </main>
    <footer>页脚</footer>
  </div>
</template>
```

### 使用布局

```vue
<!-- pages/about.vue -->
<script setup>
definePageMeta({
  layout: 'default'
});
</script>
```

### 布局嵌套

```vue
<!-- layouts/admin.vue -->
<template>
  <div class="admin">
    <AdminSidebar />
    <div class="content">
      <NuxtLayout name="default">
        <slot />
      </NuxtLayout>
    </div>
  </div>
</template>
```

### 禁用布局

```vue
<script setup>
definePageMeta({
  layout: false
});
</script>
```

### 总结

布局系统可以实现页面结构的复用和嵌套。

:::
