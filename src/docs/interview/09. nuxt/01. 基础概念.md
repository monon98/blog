# 基础概念

## 1. 什么是 Nuxt

::: details
Nuxt 是一个基于 Vue.js 的服务端渲染框架，支持 SSR、SSG 和混合渲染模式。

### 核心特性

| 特性 | 说明 |
|------|------|
| SSR | 服务端渲染，提升首屏性能和 SEO |
| SSG | 静态站点生成，构建时预渲染 |
| 混合渲染 | 同一应用中不同页面使用不同渲染模式 |
| 自动路由 | 基于文件系统自动生成路由 |
| 自动导入 | 自动导入 Vue/Nuxt 组件和组合式函数 |

### 版本对比

| 版本 | 基于 | 状态 | 特点 |
|------|------|------|------|
| Nuxt 2 | Vue 2 | 维护模式 | Options API |
| Nuxt 3 | Vue 3 | EOL (2026.07) | Composition API，Nitro v2 |
| Nuxt 4 | Vue 3 | 当前稳定版 | `compatibilityVersion: 4`，`app/` 目录 |

::: warning
Nuxt 3 已于 2026 年 7 月 31 日停止维护（EOL），建议新项目使用 Nuxt 4。
:::

### 总结

Nuxt 是 Vue.js 的全栈框架，通过约定式配置简化 SSR/SSG 开发。

:::

## 2. 目录结构

::: details
Nuxt 采用约定式目录结构。

### Nuxt 3 目录结构

```
nuxt-app/
├── pages/              # 页面组件（自动生成路由）
├── components/         # 组件（自动导入）
├── composables/        # 组合式函数（自动导入）
├── layouts/            # 布局组件
├── middleware/          # 路由中间件
├── plugins/            # 插件
├── server/             # 服务端 API
│   └── api/
│       └── hello.ts    # /api/hello
├── public/             # 静态资源
├── assets/             # 需构建的资源
├── nuxt.config.ts      # Nuxt 配置
└── app.vue             # 应用入口
```

### 关键文件

| 文件 | 作用 |
|------|------|
| `nuxt.config.ts` | 应用配置 |
| `app.vue` | 根组件 |
| `error.vue` | 错误页面 |

### 总结

Nuxt 通过约定式目录结构，让框架自动处理路由、导入等配置。

:::

## 3. 自动导入

::: details
Nuxt 自动导入组件、组合式函数和工具函数。

### 组件自动导入

```vue
<template>
  <!-- 无需手动导入 -->
  <MyComponent />
</template>

<!-- 会自动导入 components/ 目录下的所有组件 -->
```

### 组合式函数自动导入

```javascript
// composables/useCounter.ts
export const useCounter = () => {
  const count = ref(0);
  const increment = () => count.value++;
  return { count, increment };
};
```

```vue
<script setup>
// 无需手动导入
const { count, increment } = useCounter();
</script>
```

### 配置自动导入

```javascript
// nuxt.config.ts
export default defineNuxtConfig({
  imports: {
    dirs: ['utils', 'composables']
  }
});
```

### 总结

自动导入减少了样板代码，让开发更专注业务逻辑。

:::

## 4. 常见问题

::: details
Nuxt 开发中的常见问题。

### hydration mismatch

**问题**：服务端和客户端渲染结果不一致

**解决方案**：
```vue
<script setup>
// 使用 onMounted 确保只在客户端执行
onMounted(() => {
  // 客户端逻辑
});
</script>
```

### SEO 优化

**问题**：如何优化 SEO

**解决方案**：
```vue
<script setup>
useHead({
  title: '页面标题',
  meta: [
    { name: 'description', content: '页面描述' }
  ]
});

useSeoMeta({
  title: '页面标题',
  ogTitle: '页面标题',
  description: '页面描述',
  ogDescription: '页面描述'
});
</script>
```

### 环境变量

**问题**：如何使用环境变量

**解决方案**：
```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  runtimeConfig: {
    apiSecret: process.env.API_SECRET,
    public: {
      apiBase: process.env.API_BASE || '/api'
    }
  }
});
```

```typescript
// 使用
const config = useRuntimeConfig();
console.log(config.public.apiBase);  // 客户端可用
console.log(config.apiSecret);       // 仅服务端可用
```

### 总结

Nuxt 开发中需要注意 hydration、SEO 和环境变量等问题。

:::
