# 服务端 API

## 1. Nitro 引擎

::: details
Nuxt 3 内置 Nitro 引擎，支持在 `server/` 目录下编写 API。

### 目录结构

```
server/
├── api/              # API 路由
│   ├── hello.ts      # /api/hello
│   └── user/
│       └── [id].ts   # /api/user/:id
├── middleware/        # 服务端中间件
├── utils/            # 服务端工具函数
└── plugins/          # 服务端插件
```

### 支持的运行时

| 运行时 | 说明 |
|--------|------|
| Node.js | 传统 Node.js 服务器 |
| Cloudflare Workers | 边缘运行时 |
| Vercel Edge | Vercel 边缘函数 |
| Netlify Edge | Netlify 边缘函数 |

### 总结

Nitro 引擎提供了轻量级的服务端能力，支持多种运行时。

:::

## 2. API 路由

::: details
在 `server/api/` 目录下创建 API 路由。

### 基本 API

```typescript
// server/api/hello.ts
export default defineEventHandler((event) => {
  return { message: 'Hello World' };
});
```

### 动态路由

```typescript
// server/api/user/[id].ts
export default defineEventHandler((event) => {
  const id = getRouterParam(event, 'id');
  return { id, name: '张三' };
});
```

### 查询参数

```typescript
// server/api/search.ts
export default defineEventHandler((event) => {
  const query = getQuery(event);
  return { keyword: query.keyword };
});
```

### 请求方法

```typescript
// server/api/user.post.ts（仅 POST 请求）
export default defineEventHandler((event) => {
  return { method: 'POST' };
});
```

### 总结

API 路由支持动态参数、查询参数和请求方法过滤。

:::

## 3. 请求处理

::: details
处理请求体、文件上传等场景。

### 读取请求体

```typescript
// server/api/login.post.ts
export default defineEventHandler(async (event) => {
  const body = await readBody(event);
  const { username, password } = body;
  
  if (username === 'admin' && password === '123456') {
    return { success: true, token: 'xxx' };
  }
  
  throw createError({ statusCode: 401, message: '认证失败' });
});
```

### 文件上传

```typescript
// server/api/upload.post.ts
export default defineEventHandler(async (event) => {
  const form = await readMultipartFormData(event);
  
  // 处理文件
  const file = form.find(f => f.name === 'file');
  if (file) {
    // 保存文件
    return { success: true, filename: file.filename };
  }
  
  throw createError({ statusCode: 400, message: '未上传文件' });
});
```

### 请求头

```typescript
// server/api/whoami.ts
export default defineEventHandler((event) => {
  const userAgent = getHeader(event, 'user-agent');
  const token = getHeader(event, 'authorization');
  
  return { userAgent, token };
});
```

### 总结

请求处理支持读取请求体、文件上传和请求头。

:::

## 4. 服务端中间件

::: details
服务端中间件可以在所有 API 请求前后执行逻辑。

### 全局中间件

```typescript
// server/middleware/log.ts
export default defineEventHandler((event) => {
  console.log(`${event.method} ${event.path}`);
});
```

### 认证中间件

```typescript
// server/middleware/auth.ts
export default defineEventHandler((event) => {
  // 排除登录接口
  if (event.path === '/api/login') return;
  
  const token = getHeader(event, 'authorization');
  
  if (!token) {
    throw createError({ statusCode: 401, message: '未登录' });
  }
  
  // 验证 token
  const user = verifyToken(token);
  event.context.user = user;
});
```

### 总结

服务端中间件适用于日志记录、认证验证等全局逻辑。

:::

## 5. 服务端工具

::: details
在 `server/utils/` 目录下创建可复用的工具函数。

### 工具函数

```typescript
// server/utils/db.ts
export const db = {
  users: [
    { id: 1, name: '张三' },
    { id: 2, name: '李四' }
  ],
  
  getUser(id: number) {
    return this.users.find(u => u.id === id);
  }
};
```

### 使用工具

```typescript
// server/api/user/[id].ts
export default defineEventHandler((event) => {
  const id = Number(getRouterParam(event, 'id'));
  const user = db.getUser(id);
  
  if (!user) {
    throw createError({ statusCode: 404, message: '用户不存在' });
  }
  
  return user;
});
```

### 总结

服务端工具函数可以复用数据库查询、验证等逻辑。

:::
