# 插件与错误处理

## 1. 插件系统

::: details
Nuxt 3 的插件系统用于扩展应用功能。

### 基本插件

```typescript
// plugins/my-plugin.ts
export default defineNuxtPlugin((nuxtApp) => {
  // 提供全局方法
  nuxtApp.provide('hello', (name) => `Hello ${name}!`);
});
```

```vue
<script setup>
const { $hello } = useNuxtApp();
console.log($hello('World'));  // Hello World!
</script>
```

### 客户端插件

```typescript
// plugins/client-only.client.ts
// 仅在客户端执行
export default defineNuxtPlugin((nuxtApp) => {
  // 只在浏览器中运行的代码
  console.log('客户端环境');
});
```

### 服务端插件

```typescript
// plugins/server-only.server.ts
// 仅在服务端执行
export default defineNuxtPlugin((nuxtApp) => {
  // 只在服务端运行的代码
  console.log('服务端环境');
});
```

### 插件顺序

```typescript
// plugins/01-first.ts（先执行）
export default defineNuxtPlugin(() => {
  console.log('第一个插件');
});

// plugins/02-second.ts（后执行）
export default defineNuxtPlugin(() => {
  console.log('第二个插件');
});
```

### 常用内置插件

| 插件 | 说明 |
|------|------|
| `@pinia/nuxt` | Pinia 状态管理 |
| `@nuxt/image` | 图片优化 |
| `@nuxtjs/google-fonts` | Google Fonts |
| `@vueuse/nuxt` | VueUse 工具函数 |

### 总结

插件系统是扩展 Nuxt 应用功能的核心机制。

:::

## 2. 错误处理

::: details
Nuxt 3 提供了完整的错误处理体系。

### 错误页面

```vue
<!-- error.vue -->
<template>
  <div>
    <h1>出错了</h1>
    <p>{{ error.message }}</p>
    <button @click="handleError">返回首页</button>
  </div>
</template>

<script setup lang="ts">
import type { NuxtError } from '#app';

const props = defineProps({
  error: Object as () => NuxtError
});

const handleError = () => clearNuxtError({ redirect: '/' });
</script>
```

### 抛出错误

```typescript
// 在组件或 composable 中
throw createError({
  statusCode: 404,
  message: '页面不存在'
});

// 在服务端 API 中
throw createError({
  statusCode: 401,
  message: '未登录'
});
```

### 显示错误

```vue
<script setup>
// 显示错误页面
const showError = () => {
  showError({
    statusCode: 500,
    message: '服务器错误'
  });
};
</script>
```

### 错误边界

```vue
<template>
  <NuxtErrorBoundary @error="onError">
    <template #error="{ error }">
      <p>组件出错: {{ error.message }}</p>
    </template>
    
    <MyComponent />
  </NuxtErrorBoundary>
</template>

<script setup>
const onError = (error) => {
  console.error('错误捕获:', error);
};
</script>
```

### 错误中间件

```typescript
// server/middleware/error.ts
export default defineEventHandler((event) => {
  // 全局错误处理
  event.context.onError = (error) => {
    console.error('服务端错误:', error);
  };
});
```

### 总结

Nuxt 3 提供了错误页面、错误边界、错误中间件等完整的错误处理机制。

:::

## 3. 常用 Composable

::: details
Nuxt 3 提供了丰富的内置 composable。

### useCookie

```vue
<script setup>
// SSR 安全的 Cookie 管理
const token = useCookie('token', {
  maxAge: 60 * 60 * 24 * 7,  // 7 天
  httpOnly: true,
  secure: true
});

// 设置值
token.value = 'abc123';

// 删除
token.value = null;
</script>
```

### useRequestURL

```vue
<script setup>
// 获取当前请求的 URL
const url = useRequestURL();
console.log(url.href);  // https://example.com/page
</script>
```

### useRequestHeaders

```vue
<script setup>
// 获取请求头
const headers = useRequestHeaders();
console.log(headers.authorization);
</script>
```

### useAppConfig

```vue
<script setup>
// 获取应用配置
const appConfig = useAppConfig();
console.log(appConfig.siteName);

// 更新配置
updateAppConfig({ siteName: '新名称' });
</script>
```

### callOnce

```vue
<script setup>
// 只执行一次（避免 SSR 重复执行）
await callOnce(async () => {
  await fetchInitialData();
});
</script>
```

### 总结

这些 composable 提供了 SSR 安全的常用功能。

:::

## 4. 导航工具

::: details
Nuxt 3 提供了多种导航相关工具。

### navigateTo

```vue
<script setup>
// 编程式导航
const navigate = () => {
  navigateTo('/about');
  
  // 带查询参数
  navigateTo({ path: '/blog', query: { page: 1 } });
  
  // 外部链接
  navigateTo('https://example.com', { external: true });
};
</script>
```

### abortNavigation

```vue
<script setup>
// 在中间件中中止导航
defineNuxtRouteMiddleware((to, from) => {
  if (!isAuthenticated) {
    abortNavigation({
      statusCode: 401,
      message: '未登录'
    });
  }
});
</script>
```

### prefetchComponents

```vue
<script setup>
// 预加载组件
await prefetchComponents('MyHeavyComponent');
</script>
```

### reloadNuxtApp

```vue
<script setup>
// 重新加载应用
const reload = () => {
  reloadNuxtApp({
    path: '/current-page',
    force: true
  });
};
</script>
```

### 总结

导航工具提供了灵活的路由控制能力。

:::
