# 渲染模式

## 1. SSR（服务端渲染）

::: details
SSR 在服务端渲染页面为 HTML，提升首屏性能和 SEO。

### 基本配置

```javascript
// nuxt.config.ts
export default defineNuxtConfig({
  ssr: true  // 默认开启
});
```

### 工作原理

```
用户请求 → Node.js 服务器渲染 HTML → 返回完整页面 → 客户端激活
```

### 优点

- 首屏加载速度快
- SEO 友好
- 社交媒体分享效果好

### 缺点

- 需要 Node.js 服务器
- 服务器压力较大
- 部署相对复杂

### 总结

SSR 适用于需要 SEO 和首屏性能的应用。

:::

## 2. SSG（静态站点生成）

::: details
SSG 在构建时预渲染所有页面为静态 HTML。

### 基本配置

```bash
# 构建静态站点
npm run generate
```

### 输出结构

```
.output/
├── public/         # 静态文件
│   ├── index.html
│   └── about/
│       └── index.html
└── server/         # 服务端（可选）
```

### 优点

- 性能最好（CDN 分发）
- 无需服务器
- 安全性高

### 缺点

- 内容更新需重新构建
- 不适合动态内容

### 总结

SSG 适用于内容不常变化的站点，如博客、文档站。

:::

## 3. ISR（增量静态再生）

::: details
ISR 结合了 SSG 和 SSR 的优点，支持按需重新生成页面。

### 基本配置

```javascript
// pages/blog/[id].vue
defineRouteRules({
  isr: 60  // 60 秒后重新生成
});
```

### 工作原理

```
首次请求 → 返回缓存的静态页面 → 超过有效期 → 重新生成并缓存
```

### 使用场景

| 场景 | 缓存时间 |
|------|----------|
| 博客文章 | 1 小时 |
| 商品页面 | 5 分钟 |
| 新闻页面 | 1 分钟 |

### 总结

ISR 兼顾了性能和内容更新，适用于内容频繁变化的静态页面。

:::

## 4. 混合渲染

::: details
混合渲染允许在同一应用中对不同页面使用不同的渲染模式。

### 路由规则配置

```javascript
// nuxt.config.ts
export default defineNuxtConfig({
  routeRules: {
    '/': { prerender: true },           // 静态生成
    '/blog/**': { isr: 3600 },          // ISR
    '/dashboard/**': { ssr: false },    // 客户端渲染
    '/api/**': { cors: true }
  }
});
```

### 页面级配置

```javascript
// pages/about.vue
defineRouteRules({
  prerender: true
});
```

### 常用规则

| 规则 | 说明 |
|------|------|
| `prerender` | 静态生成 |
| `ssr` | 是否启用 SSR |
| `isr` | 增量静态再生（秒） |
| `cors` | 启用 CORS |
| `headers` | 自定义响应头 |

### 总结

混合渲染让开发者可以根据页面特点选择最合适的渲染模式。

:::

## 5. 渲染模式对比

::: details
不同渲染模式的对比和选择建议。

### 对比表

| 模式 | 首屏性能 | SEO | 内容更新 | 部署 | 适用场景 |
|------|----------|-----|----------|------|----------|
| SSR | 好 | 好 | 实时 | Node.js | 需要 SEO 的动态页面 |
| SSG | 最好 | 好 | 需重新构建 | CDN | 内容固定的页面 |
| ISR | 最好 | 好 | 按需更新 | CDN | 需要更新的静态页面 |
| SPA | 一般 | 差 | 实时 | CDN | 不需要 SEO 的后台 |

### 选择建议

```
需要 SEO？
├── 是 → 需要实时更新？
│       ├── 是 → SSR
│       └── 否 → ISR 或 SSG
└── 否 → SPA
```

### 总结

选择渲染模式需要综合考虑 SEO、性能和内容更新需求。

:::
