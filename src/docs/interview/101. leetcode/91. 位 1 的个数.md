# 位 1 的个数

> 难度：简单 | 标签：位运算、分治 | [LeetCode 原题](https://leetcode.cn/problems/number-of-1-bits/description/)

## 题目描述

给定一个表示无符号整数的 32 位二进制数 `n`，返回其二进制表达式中数字位为 `'1'` 的个数（也被称为汉明重量）。

**示例 1：**

```
输入：n = 00000000000000000000000000001011
输出：3
解释：输入的二进制串中，共有三位为 '1'。
```

**示例 2：**

```
输入：n = 11111111111111111111111111111101
输出：31
```

**提示：**

- 输入必须是长度为 32 的二进制串

**进阶：** 如果多次调用这个函数，你将如何优化你的算法？（答案：查表法或按字节分组计算。）

## 题解

::: details 点击查看题解

### 思路

Brian Kernighan 算法：`n & (n - 1)` 会消除 n 二进制中最低位的 1。每执行一次计数加一，直到 n 变为 0。循环次数恰好等于 1 的个数，优于逐位检查的固定 32 次。

JavaScript 位运算是 32 位有符号整数语义，本题输入按无符号处理时该算法依然正确（负数形式的位模式同样会被逐步消 1）。

### 代码实现

```javascript
var hammingWeight = function(n) {
  let count = 0;
  while (n !== 0) {
    n &= n - 1;
    count++;
  }
  return count;
};
```

### 复杂度分析

- 时间复杂度：O(k)，k 为二进制中 1 的个数。
- 空间复杂度：O(1)。
