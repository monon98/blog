# N 叉树的最大深度

> 难度：简单 | 标签：树、深度优先搜索、广度优先搜索 | [LeetCode 原题](https://leetcode.cn/problems/maximum-depth-of-n-ary-tree/description/)

## 题目描述

给定一个 N 叉树，找到其最大深度。该树的每个节点存储一个整数值和其所有子节点引用（指针）。N 叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点总数。

**示例 1：**

```
输入：root = [1,null,3,2,4,null,5,6]
输出：3
```

**示例 2：**

```
输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出：5
```

**提示：**

- 树的深度不超过 `1000`
- 树的节点数目位于 `[0, 10^4]` 之间

## 题解

::: details 点击查看题解

### 思路

与二叉树版本完全同构，区别只是「两个孩子」推广为「遍历 children 数组取最大」。空树返回 0，非空返回 `1 + max(各子树深度)`。

### 代码实现

```javascript
var maxDepth = function(root) {
  if (!root) return 0;
  let depth = 0;
  for (const child of root.children) {
    depth = Math.max(depth, maxDepth(child));
  }
  return 1 + depth;
};
```

### 复杂度分析

- 时间复杂度：O(n)，n 为节点总数。
- 空间复杂度：O(h)，递归栈深度为树高。

:::
