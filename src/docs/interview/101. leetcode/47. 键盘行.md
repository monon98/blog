# 键盘行

> 难度：简单 | 标签：数组、哈希表、字符串 | [LeetCode 原题](https://leetcode.cn/problems/keyboard-row/description/)

## 题目描述

给你一个字符串数组 `words`，只返回可以使用在美式键盘同一行的字母打出来的单词。键盘布局如下所示：

- 第一行由字符 `"qwertyuiop"` 组成
- 第二行由字符 `"asdfghjkl"` 组成
- 第三行由字符 `"zxcvbnm"` 组成

**示例 1：**

```
输入：words = ["Hello","Alaska","Dad","Peace"]
输出：["Alaska","Dad"]
```

**示例 2：**

```
输入：words = ["omk"]
输出：[]
```

**提示：**

- `1 <= words.length <= 20`
- `1 <= words[i].length <= 100`
- `words[i]` 由英文字母（小写和大写）组成

## 题解

::: details 点击查看题解

### 思路

预处理一张「字符 → 所在行号」的映射表。对每个单词转小写后，检查它的所有字符是否都属于第一个字符所在的行，全部满足才保留。

### 代码实现

```javascript
var findWords = function(words) {
  const rows = ["qwertyuiop", "asdfghjkl", "zxcvbnm"];
  const charRow = {};
  rows.forEach((row, i) => {
    for (const ch of row) charRow[ch] = i;
  });
  return words.filter((word) => {
    const lower = word.toLowerCase();
    const target = charRow[lower[0]];
    return [...lower].every((ch) => charRow[ch] === target);
  });
};
```

### 复杂度分析

- 时间复杂度：O(S)，S 为所有单词的字符总数。
- 空间复杂度：O(1)，映射表大小固定为 26。
