# 移除链表元素

> 难度：简单 | 标签：递归、链表 | [LeetCode 原题](https://leetcode.cn/problems/remove-linked-list-elements/description/)

## 题目描述

给你一个链表的头节点 `head` 和一个整数 `val`，请你删除链表中所有满足 `Node.val == val` 的节点，并返回新的头节点。

**示例 1：**

```
输入：head = [1,2,6,3,4,5,6], val = 6
输出：[1,2,3,4,5]
```

**示例 2：**

```
输入：head = [], val = 1
输出：[]
```

**示例 3：**

```
输入：head = [7,7,7,7], val = 7
输出：[]
```

**提示：**

- 列表中的节点数目在范围 `[0, 10^4]` 内
- `1 <= Node.val <= 50`
- `0 <= val <= 50`

## 题解

::: details 点击查看题解

### 思路

虚拟头节点（dummy node）统一处理「头节点本身需要被删」的边界情况。`cur` 从 dummy 出发检查 `cur.next`：值等于 val 就跳过，否则前进。

### 代码实现

```javascript
var removeElements = function(head, val) {
  const dummy = new ListNode(0, head);
  let cur = dummy;
  while (cur.next) {
    if (cur.next.val === val) {
      cur.next = cur.next.next;
    } else {
      cur = cur.next;
    }
  }
  return dummy.next;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)；递归解法为 O(n) 栈空间。

:::
