# 赎金信

> 难度：简单 | 标签：哈希表、字符串、计数 | [LeetCode 原题](https://leetcode.cn/problems/ransom-note/description/)

## 题目描述

给你两个字符串：`ransomNote` 和 `magazine`，判断 `ransomNote` 能不能由 `magazine` 里面的字符构成。如果可以，返回 `true`；否则返回 `false`。`magazine` 中的每个字符只能在 `ransomNote` 中使用一次。

**示例 1：**

```
输入：ransomNote = "a", magazine = "b"
输出：false
```

**示例 2：**

```
输入：ransomNote = "aa", magazine = "ab"
输出：false
```

**示例 3：**

```
输入：ransomNote = "aa", magazine = "aab"
输出：true
```

**提示：**

- `1 <= ransomNote.length, magazine.length <= 10^5`
- 两个字符串均只包含小写字母

## 题解

::: details 点击查看题解

### 思路

字符计数问题。先统计 `magazine` 中每个字符的数量，再遍历 `ransomNote` 消耗计数，任何一种字符不够用就返回 false。

与「有效的字母异位词」同源，区别在于这里不要求完全用完 `magazine` 的字符。

### 代码实现

```javascript
var canConstruct = function(ransomNote, magazine) {
  const cnt = new Array(26).fill(0);
  for (const ch of magazine) {
    cnt[ch.charCodeAt(0) - 97]++;
  }
  for (const ch of ransomNote) {
    if (--cnt[ch.charCodeAt(0) - 97] < 0) return false;
  }
  return true;
};
```

### 复杂度分析

- 时间复杂度：O(m + n)，m、n 为两串长度。
- 空间复杂度：O(1)，固定 26 个计数器。

:::
