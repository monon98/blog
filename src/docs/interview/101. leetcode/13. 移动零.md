# 移动零

> 难度：简单 | 标签：数组、双指针 | [LeetCode 原题](https://leetcode.cn/problems/move-zeroes/description/)

## 题目描述

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。请注意必须在不复制数组的情况下原地对数组进行操作。

**示例 1：**

```
输入：nums = [0,1,0,3,12]
输出：[1,3,12,0,0]
```

**示例 2：**

```
输入：nums = [0]
输出：[0]
```

**提示：**

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 题解

::: details 点击查看题解

### 思路

快慢双指针：`slow` 左侧全部是非零元素且保持原有相对顺序，快指针 `i` 扫描数组。遇到非零元素就与 `nums[slow]` 交换并把 `slow` 右移。这样零元素自然被「挤」到数组末尾。

也可以先写非零再补零（两次遍历），但交换法一次遍历即可完成且写法简洁。

### 代码实现

```javascript
var moveZeroes = function(nums) {
  let slow = 0;
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] !== 0) {
      const t = nums[slow];
      nums[slow] = nums[i];
      nums[i] = t;
      slow++;
    }
  }
};
```

### 复杂度分析

- 时间复杂度：O(n)，单次遍历。
- 空间复杂度：O(1)，原地交换。
