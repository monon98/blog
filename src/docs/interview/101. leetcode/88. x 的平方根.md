# x 的平方根

> 难度：简单 | 标签：数学、二分查找 | [LeetCode 原题](https://leetcode.cn/problems/sqrtx/description/)

## 题目描述

给你一个非负整数 `x`，计算并返回 `x` 的算术平方根。由于返回类型是整数，结果只保留整数部分，小数部分将被舍去。注意：不允许使用任何内置指数函数和算符，例如 `pow(x, 0.5)` 或者 `x ** 0.5`。

**示例 1：**

```
输入：x = 4
输出：2
```

**示例 2：**

```
输入：x = 8
输出：2
解释：8 的算术平方根是 2.82842...，由于返回类型是整数，小数部分将被舍去。
```

**提示：**

- `0 <= x <= 2^31 - 1`

## 题解

::: details 点击查看题解

### 思路

在 `[0, x]` 上二分查找最大的 `mid` 使 `mid * mid <= x`：满足条件时记录答案并右移左边界，否则收缩右边界。循环结束时 `ans` 就是整数平方根（向下取整）。

另一种思路是牛顿迭代法 `r = (r + x / r) / 2` 收敛更快，但二分写法更不容易出错。

### 代码实现

```javascript
var mySqrt = function(x) {
  if (x === 0) return 0;
  let l = 1;
  let r = x;
  let ans = 0;
  while (l <= r) {
    const mid = Math.floor((l + r) / 2);
    if (mid <= x / mid) {
      ans = mid;
      l = mid + 1;
    } else {
      r = mid - 1;
    }
  }
  return ans;
};
```

### 复杂度分析

- 时间复杂度：O(log x)。
- 空间复杂度：O(1)。
