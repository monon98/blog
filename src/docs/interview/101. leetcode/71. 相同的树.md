# 相同的树

> 难度：简单 | 标签：树、深度优先搜索、广度优先搜索、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/same-tree/description/)

## 题目描述

给你两棵二叉树的根节点 `p` 和 `q`，编写一个函数来检验这两棵树是否相同。如果两个树在结构上相同，并且节点具有相同的值，则认为它们是相同的。

**示例 1：**

```
输入：p = [1,2,3], q = [1,2,3]
输出：true
```

**示例 2：**

```
输入：p = [1,2], q = [1,null,2]
输出：false
```

**提示：**

- 两棵树上的节点数目都在范围 `[0, 100]` 内
- `-10^4 <= Node.val <= 10^4`

## 题解

::: details 点击查看题解

### 思路

递归三段式判断：两节点都为空则相同；一空一非空则不同；都非空时要求值相等且左子树、右子树分别相同。结构差异（如 `[1,2]` 与 `[1,null,2]`）会在空与非空的分支中被正确识别。

### 代码实现

```javascript
var isSameTree = function(p, q) {
  if (!p && !q) return true;
  if (!p || !q) return false;
  return (
    p.val === q.val &&
    isSameTree(p.left, q.left) &&
    isSameTree(p.right, q.right)
  );
};
```

### 复杂度分析

- 时间复杂度：O(min(m, n))，m、n 为两树节点数。
- 空间复杂度：O(h)，递归栈深度为较小的树高。

:::
