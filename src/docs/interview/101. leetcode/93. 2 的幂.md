# 2 的幂

> 难度：简单 | 标签：位运算、数学 | [LeetCode 原题](https://leetcode.cn/problems/power-of-two/description/)

## 题目描述

给你一个整数 `n`，请你判断该整数是否是 2 的幂次方。如果是，返回 `true`；否则，返回 `false`。如果存在一个整数 `x` 使得 `n == 2^x`，则认为 `n` 是 2 的幂次方。

**示例 1：**

```
输入：n = 1
输出：true
解释：2^0 = 1。
```

**示例 2：**

```
输入：n = 16
输出：true
```

**示例 3：**

```
输入：n = 3
输出：false
```

**提示：**

- `-2^31 <= n <= 2^31 - 1`

**进阶：** 你能够不使用循环/递归解决此问题吗？

## 题解

::: details 点击查看题解

### 思路

位运算一行解：2 的幂的二进制形如 `100...0`（只有一个 1），减一后变成 `011...1`。两者按位与必为 0。非 2 的幂的数至少有两个连续位不同，与运算结果非零。注意先排除 `n <= 0`。

进阶不使用循环的要求正是指向这个 O(1) 判定。

### 代码实现

```javascript
var isPowerOfTwo = function(n) {
  return n > 0 && (n & (n - 1)) === 0;
};
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
