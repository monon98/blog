# 基础概念

## 1. React 简介

::: details
React 是 Facebook 开发的用于构建用户界面的 JavaScript 库。

### 核心特点

- 声明式：描述 UI 应该是什么样子
- 组件化：将 UI 拆分为独立、可复用的组件
- 单向数据流：数据自上而下流动
- 虚拟 DOM：通过 diff 算法最小化真实 DOM 操作

### React 19 新特性

- Server Components：服务端组件，减少客户端 JS 体积
- Server Actions：服务端操作，简化表单处理
- use() Hook：在组件中读取 Promise 或 Context
- ref 作为属性：不再需要 forwardRef
- 文档元数据：原生支持 title、meta 标签

### 总结

React 是前端最流行的库之一，生态系统完善。

:::

## 2. JSX

::: details
JSX 是 JavaScript 的语法扩展，用于描述 UI 结构。

### JSX 与 HTML 的区别

- 类名：JSX 使用 className，HTML 使用 class
- 行内样式：JSX 使用对象形式，HTML 使用字符串
- 自闭合标签：JSX 必须闭合，HTML 可省略
- 事件处理：JSX 使用驼峰命名如 onClick

### 条件渲染

- 短路运算符：condition 加上 React.createElement
- 三元表达式：condition ? React.createElement : React.createElement
- 提前返回：在函数中 if 判断后 return

### 总结

JSX 让你在 JavaScript 中编写类似 HTML 的代码。

:::

## 3. 组件

::: details
组件是 React 应用的基本构建块。

### 函数组件

- 接收 props 参数，返回 UI 描述
- 使用 Hooks 实现状态和副作用
- 现代 React 推荐的组件写法

### 类组件（已过时）

- 继承 React.Component
- 使用 this.state 和 this.setState
- React 16+ 已不推荐使用

### Props

- 父组件向子组件传递数据的方式
- Props 是只读的，子组件不能修改
- 可以设置默认值
- children 是特殊的 prop，代表子元素

### 总结

函数组件加 Hooks 是现代 React 的主流写法。

:::

## 4. 虚拟 DOM

::: details
虚拟 DOM 是 React 性能优化的核心机制。

### 工作原理

1. 状态变化时，创建新的虚拟 DOM 树
2. Diff 算法比较新旧虚拟 DOM，找出变化部分
3. 将最小变更应用到真实 DOM

### Diff 算法

- 类型不同：直接替换整个子树
- 同类型元素：只更新变化的属性
- 列表对比：使用 key 标识唯一元素

### key 的作用

- 错误：使用数组 index 作为 key
- 正确：使用唯一 ID 作为 key

### 总结

虚拟 DOM 通过最小化 DOM 操作提升性能。

:::

## 5. 事件处理

::: details
React 事件使用合成事件，兼容所有浏览器。

### 基本用法

- 使用 onClick、onChange 等驼峰命名
- 事件处理器接收合成事件对象
- 调用 e.preventDefault 阻止默认行为
- 调用 e.stopPropagation 阻止冒泡

### 事件参数

- e.target.value：获取输入值
- e.target.name：获取元素名称
- e.type：事件类型

### 事件委托

- React 将所有事件委托到根节点
- 好处：减少内存占用，动态元素也能响应事件

### 总结

合成事件提供了跨浏览器兼容性和更好的性能。

:::
