# 高级特性

## 1. 性能优化

::: details
React 提供了多种性能优化手段。

### React.memo

- 包裹组件，跳过未变化的 props 重渲染
- 可自定义比较函数
- 配合 useCallback 使用效果更佳

### useMemo

- 缓存计算结果
- 依赖变化时才重新计算
- 适合昂贵的计算或复杂对象

### useCallback

- 缓存函数引用
- 配合 React.memo 使用
- 避免子组件因回调变化而重渲染

### 虚拟列表

- 只渲染可视区域的元素
- 使用 react-window 或 react-virtuoso
- 适合长列表场景

### 总结

合理使用优化手段，避免过度优化。

:::

## 2. 错误处理

::: details
React 提供了错误边界机制。

### 错误边界

- 类组件实现 componentDidCatch 和 getDerivedStateFromError
- 捕获子组件的渲染错误
- 显示备用 UI，防止整个应用崩溃

### 使用场景

- 页面级错误处理
- 组件级错误降级
- 配合 Sentry 等监控工具

### 总结

错误边界可以防止整个应用崩溃。

:::

## 3. Server Components

::: details
Server Components 是 React 19 正式引入的特性（React 18 中为实验性功能）。

### 服务端组件 vs 客户端组件

- 运行环境：服务端组件在服务器，客户端组件在浏览器
- 访问 API：服务端组件直接访问，客户端组件需要 API
- 使用 Hook：服务端组件不支持，客户端组件支持
- 使用交互：服务端组件不支持，客户端组件支持
- 减少 JS 体积：服务端组件是，客户端组件否

### 使用方式

- 默认为服务端组件
- 添加 use client 指令标记为客户端组件
- 服务端组件可以导入客户端组件

### 总结

Server Components 减少了客户端 JS 体积。

:::

## 4. Suspense

::: details
Suspense 用于处理异步操作。

### 懒加载

- lazy(() => import('./Component')) 动态导入
- 配合 Suspense 显示加载状态
- 减少初始包体积

### 数据获取

- 配合 use() Hook 使用
- 在 Suspense 边界内处理 Promise
- 显示 fallback 直到数据加载完成

### 嵌套 Suspense

- 不同区域可以有独立的加载状态
- 细粒度的用户体验控制

### 总结

Suspense 让异步操作更加优雅。

:::

## 5. Refs

::: details
Refs 用于访问 DOM 元素和组件实例。

### 创建 Refs

- useRef(null) 创建 ref 对象
- 通过 ref 属性绑定到元素
- 通过 ref.current 访问

### forwardRef

- React 19 不再需要，ref 直接作为 prop
- 旧版本需要 forwardRef 包装

### useImperativeHandle

- 自定义 ref 暴露的方法
- 限制子组件暴露的接口
- 提供更清晰的组件 API

### 总结

Refs 适合访问 DOM 元素和调用组件方法。

:::

## 6. 渲染优化

::: details
React 提供了多种渲染优化方式。

### 协调（Reconciliation）

React 使用 Diff 算法比较新旧虚拟 DOM：

- 类型不同：替换整个子树
- 同类型：只更新变化的属性
- 列表：使用 key 标识唯一元素

### 并发模式

React 18+ 自动启用并发模式：

- 可中断渲染
- 优先级调度
- 自动批处理

### 自动批处理

- 多个状态更新合并为一次渲染
- setTimeout 中也自动批处理
- 显式使用 flushSync 强制同步更新

### 总结

理解 React 渲染机制有助于写出高性能代码。

:::
