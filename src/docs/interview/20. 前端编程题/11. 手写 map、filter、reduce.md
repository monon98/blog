# 手写 map、filter、reduce

> 难度：简单 | 标签：高阶函数、原型链、Array

## 题目描述

在 `Array.prototype` 上实现三个高阶方法，行为对齐原生版本：

- `myMap(fn, thisArg)`：返回映射后的新数组
- `myFilter(fn, thisArg)`：返回满足条件的元素组成的新数组
- `myReduce(fn, initialValue)`：从左到右累积；未提供初始值时以第一个元素起步，空数组且无初始值时抛 TypeError
- 三者都应跳过稀疏数组的空洞位

**示例：**

```javascript
[1, 2, 3].myMap((x) => x * 2); // [2, 4, 6]
[1, 2, 3, 4].myFilter((x) => x % 2 === 0); // [2, 4]
[1, 2, 3].myReduce((sum, x) => sum + x, 10); // 16
```

## 题解

::: details 点击查看题解

### 思路

共同骨架：遍历原数组 → 调用回调（绑定 `thisArg`）→ 按各自语义收集结果。两个易漏细节：

1. **回调参数完整**：`(element, index, array)` 三元组都要传
2. **稀疏数组**：用 `i in this` 判断是否存在该槽位。原生 map/filter 保持空洞、reduce 跳过空洞，实现里要体现这一差异

### 代码实现

```javascript
Array.prototype.myMap = function (fn, thisArg) {
  if (typeof fn !== "function") throw new TypeError(`${fn} is not a function`);
  const result = [];
  for (let i = 0; i < this.length; i++) {
    if (i in this) result[i] = fn.call(thisArg, this[i], i, this);
  }
  return result;
};

Array.prototype.myFilter = function (fn, thisArg) {
  const result = [];
  for (let i = 0; i < this.length; i++) {
    if (i in this && fn.call(thisArg, this[i], i, this)) {
      result.push(this[i]);
    }
  }
  return result;
};

Array.prototype.myReduce = function (fn, initialValue) {
  let acc = initialValue;
  let start = 0;
  if (arguments.length < 2) {
    while (start < this.length && !(start in this)) start++;
    if (start === this.length) {
      throw new TypeError("Reduce of empty array with no initial value");
    }
    acc = this[start++];
  }
  for (let i = start; i < this.length; i++) {
    if (i in this) acc = fn(acc, this[i], i, this);
  }
  return acc;
};
```

### 考察点

- 高阶函数三要素：回调签名、this 绑定、返回值语义
- reduce 无初始值时的「找第一个非空洞元素起步」逻辑是最常被写错的分支
- 直接修改 `Array.prototype` 在工程中有污染风险，面试可补充 Symbol 或独立函数式的替代方案
