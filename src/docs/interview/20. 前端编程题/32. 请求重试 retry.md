# 请求重试 retry

> 难度：中等 | 标签：Promise、容错、递归

## 题目描述

实现请求重试函数 `retry(fn, times, delay)`：

- `fn` 是返回 Promise 的异步任务工厂
- 失败后自动重试，最多 `times` 次（不含首次）；重试间隔 `delay` 毫秒
- 全部尝试都失败时，reject 最后一次的错误
- 支持指数退避（每次间隔翻倍）作为进阶选项

**示例：**

```javascript
retry(() => fetch("/api/list"), 3, 500)
  .then(render)
  .catch(showError);
```

## 题解

::: details 点击查看题解

### 思路

递归消耗剩余次数：成功直接透传 resolve；失败时若还有余量就 setTimeout 后再调 attempt，否则 reject。要点：

1. fn 必须是**工厂**——每次重试都要发起新请求，复用同一个 Promise 实例没有意义
2. delay 为 0 时可省略定时器直呼
3. 指数退避：`delay * backoff ** (已重试次数)`，缓解服务端压力

### 代码实现

```javascript
function retry(fn, times = 3, delay = 0, backoff = 1) {
  return new Promise((resolve, reject) => {
    const attempt = (remaining, currentDelay) => {
      fn()
        .then(resolve)
        .catch((error) => {
          if (remaining <= 0) {
            return reject(error);
          }
          if (currentDelay > 0) {
            setTimeout(() => attempt(remaining - 1, currentDelay * backoff), currentDelay);
          } else {
            attempt(remaining - 1, currentDelay);
          }
        });
    };
    attempt(times, delay);
  });
}
```

带超时与重试组合的常见封装：

```javascript
function withTimeout(promiseFactory, ms) {
  return () => {
    const timeout = new Promise((_, reject) =>
      setTimeout(() => reject(new Error("timeout")), ms)
    );
    return Promise.race([promiseFactory(), timeout]);
  };
}

retry(withTimeout(() => fetch(url), 3000), 2, 1000, 2);
```

### 考察点

- 工厂函数 vs Promise 实例的辨析（同并发控制题）
- 递归 + 剩余次数参数是重试类问题的通用骨架
- 指数退避与抖动（jitter）在真实系统中的意义
- 追问：哪些错误不该重试（4xx 业务错误）、如何做幂等保障
