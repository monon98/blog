# 节流函数 throttle

> 难度：简单 | 标签：闭包、定时器、性能优化

## 题目描述

实现节流函数 `throttle(fn, interval)`：

- 无论触发多密集，原函数最多每 `interval` 毫秒执行一次
- 停止触发后，最后一次触发若落在冷却期内，冷却结束时仍应补发一次（保证首尾都有响应）
- 保留 `this` 与参数透传

**示例：**

```javascript
const onScroll = throttle(() => updatePosition(), 200);
window.addEventListener("scroll", onScroll);
```

## 题解

::: details 点击查看题解

### 思路

时间戳 + 定时器双保险方案：

1. **时间戳判断**：距上次执行已超过 `interval` 就立即执行（保证首响应）
2. **尾随定时器**：剩余冷却期内只挂一个 setTimeout 到点补发（保证尾响应），期间重复触发不重复挂
3. 立即执行前要顺手清掉未触发的补发定时器，避免双发

纯时间戳版（无尾随）和纯定时器版（有固定延迟）也可作为简化答案口头给出。

### 代码实现

```javascript
function throttle(fn, interval = 300) {
  let lastTime = 0;
  let timer = null;

  function throttled(...args) {
    const now = Date.now();
    const remaining = interval - (now - lastTime);

    if (remaining <= 0) {
      if (timer) {
        clearTimeout(timer);
        timer = null;
      }
      lastTime = now;
      fn.apply(this, args);
    } else if (!timer) {
      timer = setTimeout(() => {
        lastTime = Date.now();
        timer = null;
        fn.apply(this, args);
      }, remaining);
    }
  }

  throttled.cancel = () => {
    clearTimeout(timer);
    timer = null;
    lastTime = 0;
  };

  return throttled;
}
```

### 考察点

- 防抖「以最后一次为准」、节流「按固定节奏」的本质差异与各自适用场景
- 双保险实现同时满足 leading 与 trailing 两个语义
- 定时器回调里 `this` 已丢失，需在闭包外先捕获或用箭头函数
- 应用：scroll/resize/mousemove 高频事件、游戏按键、拖拽跟随
