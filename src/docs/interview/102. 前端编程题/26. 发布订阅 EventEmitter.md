# 发布订阅 EventEmitter

> 难度：中等 | 标签：设计模式、闭包、事件系统

## 题目描述

实现一个事件发布订阅类 `EventEmitter`，支持以下 API：

- `on(event, cb)`：订阅事件
- `once(event, cb)`：订阅一次，触发后自动移除
- `off(event, cb)`：取消订阅（要能正确移除 once 包装后的原始回调）
- `emit(event, ...args)`：触发事件并按注册顺序执行全部回调
- 支持链式调用、无监听者时 emit 安全返回

**示例：**

```javascript
const bus = new EventEmitter();
const log = (msg) => console.log(msg);

bus.on("msg", log).emit("msg", "hello"); // "hello"
bus.once("once", log);
bus.off("msg", log);
bus.emit("msg"); // 无输出，不报错
```

## 题解

::: details 点击查看题解

### 思路

核心数据结构：`Map<event, Set<callback>>` 或普通对象 + 数组。

三个易错细节：

1. **once 的实现**：包一层 wrapper，首次执行后自动 off。若直接 off(cb) 会因传入的是 wrapper 而失败——所以要在 wrapper 上记录原始回调引用 `_origin`，off 时同时比对两者
2. **emit 时遍历快照问题**：回调内再注册/注销同事件会修改正在遍历的数组，复制一份再遍历更安全
3. 所有方法返回 this 以支持链式调用

### 代码实现

```javascript
class EventEmitter {
  constructor() {
    this.events = new Map();
  }

  on(event, cb) {
    if (!this.events.has(event)) {
      this.events.set(event, []);
    }
    this.events.get(event).push(cb);
    return this;
  }

  once(event, cb) {
    const wrapper = (...args) => {
      cb(...args);
      this.off(event, cb);
    };
    wrapper._origin = cb;
    this.on(event, wrapper);
    return this;
  }

  off(event, cb) {
    if (!this.events.has(event)) return this;
    const next = this.events
      .get(event)
      .filter((fn) => fn !== cb && fn._origin !== cb);
    if (next.length) {
      this.events.set(event, next);
    } else {
      this.events.delete(event);
    }
    return this;
  }

  emit(event, ...args) {
    const cbs = this.events.get(event);
    if (!cbs || cbs.length === 0) return false;
    [...cbs].forEach((cb) => cb(...args));
    return true;
  }
}
```

### 考察点

- 发布订阅 vs 观察者的结构差异：有无调度中心
- Vue2 的事件总线 `$bus`、Node 的 events 模块都是该模式的直接应用
- 追问：如何实现通配符订阅（`on("*")`）、最大监听数告警（模仿 Node 的 MaxListenersExceededWarning）
