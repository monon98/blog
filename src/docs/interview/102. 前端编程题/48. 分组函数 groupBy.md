# 分组函数 groupBy

> 难度：入门 | 标签：数组、reduce、高阶函数

## 题目描述

实现 `groupBy(list, iteratee)`：

- iteratee 可以是函数（返回分组键），也可以是字符串属性名
- 返回以分组键为 key、元素数组为 value 的对象
- 保持元素在各自组内的原始顺序

**示例：**

```javascript
groupBy([6.1, 4.2, 6.3], Math.floor);
// { 4: [4.2], 6: [6.1, 6.3] }

groupBy(users, "dept");
// { 前端: [{...}, {...}], 后端: [{...}] }
```

## 题解

::: details 点击查看题解

### 思路

reduce 单遍聚合：对每个元素求出键，向对应桶 push。键不存在时初始化空数组——`(acc[key] ||= []).push(item)` 利用逻辑空赋值一行完成「懒初始化」。

iteratee 双形态通过 typeof 分流；返回值用 Object.create(null) 或普通对象均可，注意数字键会被隐式转成字符串。

### 代码实现

```javascript
function groupBy(list, iteratee) {
  return list.reduce((acc, item, index) => {
    const key =
      typeof iteratee === "function"
        ? iteratee(item, index)
        : item[iteratee];
    (acc[key] ??= []).push(item);
    return acc;
  }, {});
}
```

### 考察点

- reduce 做「分类归集」的模式
- `??=` / `||=` 懒初始化写法（ES2021）
- 键类型注意点：数字键变字符串、undefined/null 作键的表现
- 变体追问：Map 版本（保留任意类型键）、countBy 统计数量版、多级嵌套分组
