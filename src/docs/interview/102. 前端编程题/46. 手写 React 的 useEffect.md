# 手写 React 的 useEffect

> 难度：中等 | 标签：React、Hooks、副作用

## 题目描述

在 useState 模拟框架上继续实现 `useEffect(callback, deps)`：

- 首次渲染后执行 callback
- 依赖数组 deps 变化时再次执行；deps 为 undefined 时每次渲染都执行；deps 为空数组时只执行一次
- 支持清理函数：callback 返回的函数在下一次执行前或组件卸载时调用
- 使用 `Object.is` 比较依赖

**示例：**

```javascript
function App() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `点击了 ${count} 次`;
    return () => console.log("cleanup");
  }, [count]);
}
```

## 题解

::: details 点击查看题解

### 思路

与 useState 同款索引机制，额外维护「每个 effect 上一次的 deps 快照」：

1. 取出旧 deps；无旧记录视为首次执行
2. `Object.is` 逐项比较（NaN 安全），任一不同即判定变化
3. 变化时先跑上一次的 cleanup 再执行新 callback 并保存其返回的清理函数
4. deps 缺省每次都执行；空数组则永远比较结果相同

真实 React 中 cleanup 与 effect 在 commit 阶段异步调度（passive effects），模拟版简化为渲染内同步。

### 代码实现

```javascript
let effectDeps = [];
let cleanupFns = [];
let effectIndex = 0;

function useEffect(callback, deps) {
  const currentIndex = effectIndex++;
  const oldDeps = effectDeps[currentIndex];

  const hasChanged =
    !oldDeps ||
    deps === undefined ||
    deps.some((dep, i) => !Object.is(dep, oldDeps[i]));

  if (hasChanged) {
    const oldCleanup = cleanupFns[currentIndex];
    if (typeof oldCleanup === "function") {
      oldCleanup();
    }
    cleanupFns[currentIndex] = callback() || null;
  }

  effectDeps[currentIndex] = deps;
}

function render() {
  if (!renderCallback) return;
  stateIndex = 0;
  effectIndex = 0;
  renderCallback();
}
```

卸载时统一清理：

```javascript
function unmount() {
  cleanupFns.forEach((fn) => typeof fn === "function" && fn());
}
```

### 考察点

- 三种 deps 形态的语义矩阵：undefined / [] / [a, b]
- cleanup 的触发时机：下一次 effect 前 + 卸载——防内存泄漏的核心设计
- Object.is 而非 === 比较：正确处理 NaN 与 ±0
- 追问：useEffect vs useLayoutEffect 执行时机、闭包陈旧值问题及 useRef 解法
