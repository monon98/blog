# 回调转 Promise 的 promisify

> 难度：简单 | 标签：Promise、高阶函数、Node.js

## 题目描述

实现 `promisify(fn)`，把 Node.js 风格的错误优先回调函数转换为返回 Promise 的函数：

- 原函数最后一个参数是回调 `(err, data) => void`
- 包装后的函数接收原参数并返回 Promise：err 存在则 reject，否则 resolve data
- 保留原函数的 `this` 绑定

**示例：**

```javascript
const readFileAsync = promisify(fs.readFile);
readFileAsync("./config.json", "utf8").then(console.log, console.error);
```

## 题解

::: details 点击查看题解

### 思路

返回一个新函数：内部 new Promise，把原函数的调用包进去，注入一个自定义回调作为最后一个参数——回调里 err 非空走 reject，否则 resolve。`fn.call(this, ...)` 保证调用方上下文不丢。

Node 内置的 `util.promisify` 还支持自定义符号 `util.promisify.custom` 定制转换行为，可作为加分项提及。

### 代码实现

```javascript
function promisify(fn) {
  if (typeof fn !== "function") {
    throw new TypeError("promisify expects a function");
  }
  return function (...args) {
    return new Promise((resolve, reject) => {
      fn.call(this, ...args, (err, data) => {
        if (err) reject(err);
        else resolve(data);
      });
    });
  };
}
```

### 考察点

- 错误优先回调约定是 Node 生态的历史包袱，理解它才能理解 promisify 的形态
- 高阶函数 + 闭包注入回调参数的模式
- 追问：多结果回调（如 child_process.exec 的 stdout/stderr）如何处理——需要 promisify 的变体收集多个非 err 参数
- 对比 async/await 时代直接使用 fs/promises 的现状
