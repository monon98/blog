# 组合函数 compose 与 pipe

> 难度：简单 | 标签：函数式、高阶函数、reduce

## 题目描述

实现两个函数组合工具：

- `compose(...fns)`：从右向左依次执行，后一个函数的返回值是前一个的入参，即 `compose(f, g)(x) === f(g(x))`
- `pipe(...fns)`：从左向右执行，即 `pipe(f, g)(x) === g(f(x))`
- 空函数列表时返回恒等函数；支持传递多个初始参数给最内层函数

**示例：**

```javascript
const toUpper = (s) => s.toUpperCase();
const trim = (s) => s.trim();
const exclaim = (s) => `${s}!`;

compose(exclaim, toUpper)("hello"); // "HELLO!"
pipe(trim, toUpper)(" hi "); // "HI"
```

## 题解

::: details 点击查看题解

### 思路

用 reduce 把函数数组折叠成一个新函数：

- compose 从右往左折叠：`reduce` 时让「先累积的 a」包住「当前函数 b」，保证 b 先执行
- pipe 只需反转方向：让 b 包住 a
- 边界处理空数组返回恒等 `(v) => v`

Redux 中间件、Express 中间件洋葱模型的思想源头都是这个模式。

### 代码实现

```javascript
function compose(...fns) {
  if (fns.length === 0) return (v) => v;
  return fns.reduce(
    (a, b) =>
      (...args) =>
        a(b(...args))
  );
}

function pipe(...fns) {
  if (fns.length === 0) return (v) => v;
  return fns.reduceRight(
    (a, b) =>
      (...args) =>
        b(a(...args))
  );
}
```

### 考察点

- reduce 折叠方向与执行方向的对应关系是最易混淆处
- `...args` 展开使最内层函数可以接收多参，外层保持单值流动
- 进阶变体：异步版 composeAsync（用 Promise.then 串联）、带调试日志的组合器
- 与柯里化的配合是函数式代码组织的常见套路
