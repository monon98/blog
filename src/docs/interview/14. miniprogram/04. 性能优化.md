# 性能优化

## 1. 渲染优化

::: details
小程序渲染优化是提升用户体验的关键。

### 减少 setData

```javascript
// 不推荐：频繁调用
for (let i = 0; i < 100; i++) {
  this.setData({
    [`list[${i}].value`]: i
  });
}

// 推荐：一次性更新
const list = this.data.list.map((item, i) => ({
  ...item,
  value: i
}));
this.setData({ list });
```

### 合并 setData

```javascript
// 使用 this.setData 合并更新
this.setData({
  'a.x': 1,
  'b.y': 2,
  'c.z': 3
}, () => {
  // 更新完成回调
});
```

### 使用虚拟列表

```javascript
// 虚拟列表实现
Page({
  data: {
    list: [],        // 总数据
    displayList: [], // 显示数据
    startIndex: 0,
    itemHeight: 50,
    viewHeight: 500
  },
  
  onPageScroll(e) {
    const scrollTop = e.scrollTop;
    const startIndex = Math.floor(scrollTop / this.data.itemHeight);
    
    if (startIndex !== this.data.startIndex) {
      this.setData({
        startIndex,
        displayList: this.data.list.slice(startIndex, startIndex + 10)
      });
    }
  }
});
```

### 总结

减少 setData 次数和数据量是小程序渲染优化的核心。

## 2. 加载优化

::: details
小程序加载优化可以减少用户等待时间。

### 分包加载

```json
// app.json
{
  "pages": [
    "pages/index/index"
  ],
  "subpackages": [
    {
      "root": "packageA",
      "pages": [
        "pages/detail/detail"
      ]
    }
  ]
}
```

### 预加载

```javascript
// 预加载分包
wx.preloadPackage({
  packages: ['packageA'],
  success() {
    console.log('预加载完成');
  }
});
```

### 图片懒加载

```html
<!-- 图片懒加载 -->
<image 
  src="{{item.image}}" 
  lazy-load 
  mode="aspectFill"
/>
```

### 总结

分包加载和懒加载可以显著提升小程序加载速度。

## 3. 内存优化

::: details
小程序内存优化可以防止应用崩溃。

### 及时清理

```javascript
Page({
  timer: null,
  
  onLoad() {
    this.timer = setInterval(() => {
      // 定时任务
    }, 1000);
  },
  
  onUnload() {
    // 清理定时器
    if (this.timer) {
      clearInterval(this.timer);
      this.timer = null;
    }
  }
});
```

### 数据清理

```javascript
// 清理不必要的数据
this.setData({
  list: [],
  detail: null
});

// 使用完缓存后清理
wx.removeStorage({ key: 'cacheKey' });
```

### 总结

内存优化需要及时清理资源，避免内存泄漏。

:::

## 4. 网络优化

::: details
小程序网络优化可以提升数据加载速度。

### 请求合并

```javascript
// 不推荐：多次请求
wx.request({ url: 'api/user' });
wx.request({ url: 'api/orders' });
wx.request({ url: 'api/products' });

// 推荐：批量请求
wx.request({
  url: 'api/batch',
  data: {
    apis: ['user', 'orders', 'products']
  }
});
```

### 缓存策略

```javascript
// 先展示缓存，再更新
const cached = wx.getStorageSync('data');
if (cached) {
  this.setData({ list: cached });
}

// 请求最新数据
wx.request({
  url: 'api/data',
  success: (res) => {
    this.setData({ list: res.data });
    wx.setStorageSync('data', res.data);
  }
});
```

### 总结

网络优化包括请求合并、缓存策略等。

:::
