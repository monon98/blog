# 常见问题

## 1. 开发问题

::: details
小程序开发中的常见问题。

### setData 问题

**问题**：setData 更新视图不及时

**解决方案**：
```javascript
// 使用 setTimeout 异步更新
setTimeout(() => {
  this.setData({ list: newList });
}, 0);

// 合并多次 setData 为一次
this.setData({
  'a.x': 1,
  'b.y': 2
});
```

### 页面通信

**问题**：页面间数据传递

**解决方案**：
```javascript
// 方式 1：URL 参数
wx.navigateTo({
  url: `/pages/detail/detail?id=${id}&name=${name}`
});

// 方式 2：全局变量
const app = getApp();
app.globalData.tempData = data;

// 方式 3：EventChannel
wx.navigateTo({
  url: '/pages/detail/detail',
  success: (res) => {
    res.eventChannel.emit('sendData', data);
  }
});
```

### 总结

开发问题需要根据具体情况选择合适的解决方案。

:::

## 2. 兼容性问题

::: details
小程序兼容性问题和解决方案。

### API 兼容性

**问题**：某些 API 不支持

**解决方案**：
```javascript
// 检查 API 是否可用
if (wx.canIUse('wx.chooseImage')) {
  wx.chooseImage({ ... });
} else {
  // 降级方案
  console.log('API 不支持');
}

// 运行时判断平台
const systemInfo = wx.getSystemInfoSync();
console.log('平台:', systemInfo.platform);
```

### 总结

兼容性问题需要通过特性检测来解决。

:::

## 3. 调试问题

::: details
小程序调试技巧和工具。

### 真机调试

```javascript
// 使用 remoteDebug
// 开发者工具 → 真机调试 → 开启

// 或使用 vConsole
App({
  config: {
    debug: true
  }
});
```

### 性能监控

```javascript
// 监控页面性能
Page({
  onShow() {
    const startTime = Date.now();
    
    this.setData({}, () => {
      const cost = Date.now() - startTime;
      console.log(`setData 耗时: ${cost}ms`);
    });
  }
});
```

### 总结

小程序调试需要使用真机调试和性能监控工具。
