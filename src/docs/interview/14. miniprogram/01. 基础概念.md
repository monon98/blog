# 基础概念

## 1. 什么是小程序

::: details
小程序是一种不需要下载安装即可使用的应用，实现了"触手可及"的梦想。

### 主流小程序平台

| 平台 | 开发框架 | 特点 |
|------|----------|------|
| 微信小程序 | WXML/WXSS | 最大用户基数 |
| 支付宝小程序 | AXML/ACSS | 金融生态 |
| 百度小程序 | Swan/CSS | 搜索生态 |
| 字节跳动小程序 | TTML/TTSS | 抖音生态 |
| QQ 小程序 | QML/QSS | 年轻用户 |

### 小程序架构

```
┌─────────────────────────────────┐
│         视图层                   │
│    WXML + WXSS + 组件            │
├─────────────────────────────────┤
│         逻辑层                   │
│    JavaScript + API              │
├─────────────────────────────────┤
│         Native 层                │
│    渲染引擎 + 原生能力            │
└─────────────────────────────────┘
```

### 双线程模型

```javascript
// 渲染线程（WebView）
// 负责渲染页面

// 逻辑线程（JsCore）
// 负责处理业务逻辑

// 通信通过 Native 层
// 例如：setData 触发渲染更新
```

### 总结

小程序是一种轻量级应用，采用双线程模型，实现了跨平台运行。

:::

## 2. 项目结构

::: details
小程序项目具有标准的目录结构。

### 目录结构

```
miniprogram/
├── pages/              # 页面目录
│   ├── index/          # 首页
│   │   ├── index.js    # 页面逻辑
│   │   ├── index.json  # 页面配置
│   │   ├── index.wxml  # 页面模板
│   │   └── index.wxss  # 页面样式
│   └── logs/
├── components/         # 组件目录
├── utils/              # 工具函数
├── app.js              # 应用入口
├── app.json            # 应用配置
├── app.wxss            # 全局样式
└── project.config.json # 项目配置
```

### 全局配置

```json
// app.json
{
  "pages": [
    "pages/index/index",
    "pages/logs/logs"
  ],
  "window": {
    "backgroundTextStyle": "light",
    "navigationBarBackgroundColor": "#fff",
    "navigationBarTitleText": "小程序",
    "navigationBarTextStyle": "black"
  },
  "tabBar": {
    "list": [
      {
        "pagePath": "pages/index/index",
        "text": "首页",
        "iconPath": "images/home.png",
        "selectedIconPath": "images/home-active.png"
      }
    ]
  }
}
```

### 页面配置

```json
// pages/index/index.json
{
  "usingComponents": {
    "my-component": "/components/my-component/my-component"
  },
  "navigationBarTitleText": "首页"
}
```

### 总结

小程序采用标准的目录结构，通过全局配置和页面配置管理应用。

:::

## 3. 数据绑定

::: details
小程序使用 WXML 进行数据绑定，语法与 Vue 类似。

### 基本绑定

```html
<!-- 页面结构 -->
<view>{{message}}</view>
<view>{{count}}</view>
<view>{{user.name}}</view>
```

```javascript
// 页面逻辑
Page({
  data: {
    message: 'Hello',
    count: 0,
    user: { name: '张三' }
  },
  
  onLoad() {
    // 更新数据
    this.setData({
      message: 'World',
      count: 1
    });
  }
});
```

### 列表渲染

```html
<!-- 列表渲染 -->
<view wx:for="{{items}}" wx:key="id">
  {{index}}: {{item.name}}
</view>

<!-- 条件渲染 -->
<view wx:if="{{show}}">显示内容</view>
<view wx:else>隐藏内容</view>
```

### 事件绑定

```html
<!-- 事件绑定 -->
<button bindtap="handleClick" data-id="{{123}}">点击</button>
<button catchtap="handleCatch">阻止冒泡</button>
```

```javascript
Page({
  handleClick(e) {
    const id = e.currentTarget.dataset.id;
    console.log('点击了:', id);
  },
  
  handleCatch(e) {
    // 阻止事件冒泡
  }
});
```

### 总结

小程序使用 WXML 进行数据绑定，支持列表渲染、条件渲染和事件绑定。

:::

## 4. 生命周期

::: details
小程序页面和组件都有完整的生命周期。

::: tip
生命周期的详细说明见 [02. 生命周期.md](./02.%20生命周期)。
:::

### 常用钩子速览

| 钩子 | 触发时机 |
|------|----------|
| onLoad | 页面加载 |
| onShow | 页面显示 |
| onReady | 初次渲染完成 |
| onHide | 页面隐藏 |
| onUnload | 页面卸载 |

### 总结

小程序提供了完整的生命周期钩子，可以精确控制页面和组件的行为。

:::
