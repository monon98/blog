# 生命周期

## 1. 页面生命周期

::: details
小程序页面有完整的生命周期钩子。

### 生命周期流程

```
onLoad → onShow → onReady → onHide → onUnload
```

### 详细说明

| 钩子 | 触发时机 | 典型用途 |
|------|----------|----------|
| onLoad | 页面加载 | 获取初始化数据 |
| onShow | 页面显示 | 刷新数据 |
| onReady | 初次渲染完成 | 操作 DOM |
| onHide | 页面隐藏 | 暂停动画 |
| onUnload | 页面卸载 | 清理资源 |

### 使用示例

```javascript
Page({
  data: {
    list: []
  },
  
  onLoad(options) {
    // 接收页面参数
    const { id } = options;
    this.loadData(id);
  },
  
  onShow() {
    // 每次显示都刷新数据
    this.refreshData();
  },
  
  onReady() {
    // 可以操作 DOM
    const query = wx.createSelectorQuery();
    query.select('#my-element').boundingClientRect();
  },
  
  onHide() {
    // 暂停定时器等
    clearInterval(this.timer);
  },
  
  onUnload() {
    // 清理资源
    this.timer = null;
  }
});
```

### 总结

页面生命周期钩子可以帮助我们精确控制页面行为。

:::

## 2. 组件生命周期

::: details
组件有独立的生命周期，同时可以监听页面生命周期。

### 组件生命周期

| 钩子 | 触发时机 |
|------|----------|
| created | 组件实例创建 |
| attached | 进入页面节点树 |
| ready | 组件渲染完成 |
| detached | 从节点树移除 |

### 页面生命周期

| 钩子 | 触发时机 |
|------|----------|
| show | 所在页面显示 |
| hide | 所在页面隐藏 |

### 使用示例

```javascript
Component({
  lifetimes: {
    created() {
      console.log('组件创建');
    },
    
    attached() {
      console.log('进入页面');
      // 初始化数据
    },
    
    ready() {
      console.log('渲染完成');
      // 操作 DOM
    },
    
    detached() {
      console.log('组件销毁');
      // 清理资源
    }
  },
  
  pageLifetimes: {
    show() {
      console.log('页面显示');
      // 刷新数据
    },
    
    hide() {
      console.log('页面隐藏');
      // 暂停任务
    }
  }
});
```

### 总结

组件生命周期提供了更细粒度的控制能力。

:::

## 3. 应用生命周期

::: details
小程序应用也有自己的生命周期。

### 应用生命周期

```javascript
// app.js
App({
  onLaunch(options) {
    // 小程序初始化
    console.log('场景值:', options.scene);
  },
  
  onShow(options) {
    // 小程序显示
    console.log('小程序显示');
  },
  
  onHide() {
    // 小程序隐藏
    console.log('小程序隐藏');
  },
  
  onError(error) {
    // 小程序错误
    console.error('错误:', error);
  },
  
  onUnhandledRejection(res) {
    // 未处理的 Promise 拒绝
    console.error('未处理的拒绝:', res.reason);
  },
  
  globalData: {
    userInfo: null,
    token: null
  }
});
```

### 页面级回调函数

```javascript
Page({
  // 分享给朋友
  onShareAppMessage() {
    return {
      title: '分享标题',
      path: '/pages/index/index'
    };
  },
  
  // 分享到朋友圈
  onShareTimeline() {
    return {
      title: '分享标题'
    };
  },
  
  // 下拉刷新
  onPullDownRefresh() {
    // 刷新数据
    wx.stopPullDownRefresh();
  },
  
  // 上拉加载
  onReachBottom() {
    // 加载更多
  }
});
```

### 场景值

| 场景值 | 说明 |
|--------|------|
| 1001 | 发现页进入 |
| 1007 | 单人聊天会话 |
| 1011 | 扫描二维码 |
| 1025 | 扫描小程序码 |

### 总结

应用生命周期可以帮助我们处理小程序级别的逻辑。

:::

## 4. 页面栈管理

::: details
小程序通过页面栈管理页面跳转。

### 页面栈 API

```javascript
// 保留当前页面，跳转
wx.navigateTo({
  url: '/pages/detail/detail?id=1'
});

// 关闭当前页面，跳转
wx.redirectTo({
  url: '/pages/detail/detail'
});

// 关闭所有页面，跳转
wx.reLaunch({
  url: '/pages/index/index'
});

// 返回上一页
wx.navigateBack({
  delta: 1
});
```

### 页面栈限制

```javascript
// 页面栈最大深度为 10
// 超过时会调用 redirectTo

// 获取页面栈
const pages = getCurrentPages();
const currentPage = pages[pages.length - 1];
const previousPage = pages[pages.length - 2];
```

### 总结

页面栈管理是小程序导航的核心，需要注意页面栈深度限制。

:::
