# 事件循环

## 1. 浏览器事件循环

::: details
浏览器事件循环是 JavaScript 运行时的核心机制，它负责处理异步操作、事件和回调函数。

### 基本概念

- **单线程**：JavaScript 是单线程的，同一时间只能执行一个任务
- **异步操作**：JavaScript 通过事件循环处理异步操作
- **任务队列**：异步操作完成后，会将回调函数放入任务队列中

### 任务队列

#### 宏任务（Macro Task）

- **定义**：宏任务是指需要执行的主要任务，如 script 标签、setTimeout、setInterval、I/O 操作、DOM 事件等
- **执行时机**：宏任务在事件循环的每一轮中执行一次

#### 微任务（Micro Task）

- **定义**：微任务是指需要在当前任务执行完成后立即执行的任务
- **示例**：Promise.then、queueMicrotask、MutationObserver
- **执行时机**：微任务在每个宏任务执行完成后、下一个宏任务开始前执行

### 执行过程

1. 执行全局脚本（第一个宏任务）
2. 执行当前宏任务产生的所有微任务
3. 从宏任务队列中取出一个任务执行
4. 执行完成后，执行当前宏任务产生的所有微任务
5. 重复这个过程

:::

## 2. 宏任务与微任务对比

::: details

| 类型 | 示例 | 执行时机 |
|------|------|----------|
| 宏任务 | setTimeout、setInterval、I/O、DOM 事件 | 事件循环的每一轮 |
| 微任务 | Promise.then、MutationObserver | 当前宏任务完成后 |

### 注意事项

- 微任务会在当前宏任务完成后立即执行
- Promise 的 then 方法会被放入微任务队列，而不是立即执行
- 避免阻塞主线程，长时间运行的同步代码会影响用户体验

:::
