# 内存管理

## 1. 内存管理和垃圾回收

::: details
内存管理是 JavaScript 中一个重要的概念，它涉及到如何分配、使用和释放内存。JavaScript 具有自动垃圾回收机制，帮助开发者管理内存。

### 内存生命周期

JavaScript 的内存生命周期通常包括以下三个阶段：

1. **分配内存**：JavaScript 引擎自动为变量、对象等分配内存
2. **使用内存**：通过读写变量、调用函数等操作使用内存
3. **释放内存**：当内存不再需要时，由垃圾回收器自动释放

### 垃圾回收机制

JavaScript 使用自动垃圾回收机制来管理内存，主要有两种垃圾回收算法：

#### 标记-清除算法

**工作原理**：
1. 垃圾回收器从根对象开始，标记所有可达的对象
2. 清除所有未被标记的对象
3. 压缩内存，减少内存碎片

**优点**：实现简单，能够处理循环引用
**缺点**：可能会导致内存碎片

#### 引用计数算法

**工作原理**：
1. 为每个对象维护一个引用计数器
2. 当对象被引用时，计数器加 1
3. 当引用被移除时，计数器减 1
4. 当计数器为 0 时，释放对象内存

**优点**：实时性好，内存可以立即被释放
**缺点**：无法处理循环引用

### 常见的内存泄漏场景

1. **全局变量**：全局变量不会被垃圾回收，除非显式设置为 `null`
2. **闭包**：闭包会持有对外部变量的引用，导致这些变量不会被垃圾回收
3. **DOM 引用**：当 DOM 元素被移除但仍被 JavaScript 引用时，不会被垃圾回收
4. **定时器**：未清除的定时器会导致回调函数及其引用的变量不会被垃圾回收

### 内存管理最佳实践

1. **减少全局变量的使用**：尽量使用局部变量
2. **及时释放不再使用的引用**：当变量不再需要时，将其设置为 `null`
3. **避免创建过多的闭包**
4. **及时清除定时器**
5. **使用 WeakMap 和 WeakSet**：它们不会阻止垃圾回收
