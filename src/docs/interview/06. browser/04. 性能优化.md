# 性能优化

## 1. 浏览器性能优化

::: details
浏览器性能优化是前端开发中的重要课题，它直接影响用户体验和网站的可用性。

### 网络优化

- **减少 HTTP 请求**：合并文件、使用 CSS Sprites、使用字体图标
- **优化资源加载**：使用 CDN、启用 Brotli/Gzip 压缩、使用 HTTP/2
- **预加载和预连接**：使用 `preconnect`、`preload`；使用 Speculation Rules API 进行预渲染

### 渲染优化

- **减少重排和重绘**：使用 CSS transforms、避免频繁操作 DOM
- **优化 CSS**：使用简洁的选择器、避免使用 `@import`
- **优化 JavaScript**：使用 defer 或 async 延迟加载、使用事件委托

### 资源优化

- **图片优化**：使用适当的格式、压缩图片、使用响应式图片
- **字体优化**：使用 font-display、子集化字体
- **代码优化**：压缩代码、树摇、代码分割

:::

## 2. Web Vitals

::: details
Web Vitals 是 Google 提出的用于衡量用户体验的核心指标。

### 核心指标

| 指标 | 全称 | 说明 | 目标值 |
|------|------|------|--------|
| LCP | Largest Contentful Paint | 最大内容绘制 | 小于 2.5 秒 |
| INP | Interaction to Next Paint | 交互到下次绘制 | 小于 200 毫秒 |
| CLS | Cumulative Layout Shift | 累积布局偏移 | 小于 0.1 |

### LCP（最大内容绘制）

- 衡量加载性能
- 表示可视区域中最大内容元素的渲染时间
- 优化方向：优化服务器响应时间、使用 CDN、优化图片加载

### INP（交互到下次绘制）

- 衡量交互响应速度
- 表示用户交互到页面实际响应的时间
- 优化方向：减少主线程阻塞、优化事件处理

### CLS（累积布局偏移）

- 衡量视觉稳定性
- 表示页面内容意外移动的程度
- 优化方向：设置图片和视频尺寸、避免动态插入内容

### 监测方法

- Chrome DevTools 的 Performance 面板
- Lighthouse
- web-vitals 库
- PageSpeed Insights

:::

## 3. 防抖和节流

::: details
防抖和节流是 JavaScript 中用于优化性能的两种技术。

### 防抖（Debounce）

**定义**：在事件触发后，延迟一段时间再执行回调函数，如果在延迟期间事件再次触发，则重新计时。

**应用场景**：搜索输入、窗口 resize 等。

### 节流（Throttle）

**定义**：在一段时间内，只执行一次回调函数，无论事件触发多少次。

**应用场景**：滚动事件、鼠标移动事件等。

### 区别

- 防抖：在事件触发后延迟执行，如果期间事件再次触发则重新计时
- 节流：在一段时间内只执行一次，无论事件触发多少次

:::

## 4. JavaScript 性能优化

::: details
JavaScript 性能优化是提高网页加载速度和运行效率的重要手段。

### 代码优化

- **减少 DOM 操作**：DOM 操作是昂贵的，应尽量减少
- **使用事件委托**：可以减少事件监听器的数量
- **避免使用 eval**：`eval` 会执行字符串形式的代码，性能较差且存在安全风险
- **使用防抖和节流**：减少频繁触发的事件处理函数的执行次数

### 资源优化

- **压缩代码**：使用工具压缩 JavaScript 代码
- **减少 HTTP 请求**：合并 JavaScript 文件
- **使用 CDN**：使用 CDN 加载第三方库
- **延迟加载**：对于非关键 JavaScript 代码，可以使用延迟加载

### 运行时优化

- **使用 requestAnimationFrame**：对于动画效果，使用 `requestAnimationFrame` 而不是 `setTimeout` 或 `setInterval`
- **使用 Web Workers**：将复杂计算移到 Web Workers 中，避免阻塞主线程

:::
