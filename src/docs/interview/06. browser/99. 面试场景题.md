# 面试场景题

## 1. 从 URL 输入到页面渲染

::: details
**问题**：描述从输入 URL 到页面渲染完成的全过程。

### 完整流程

1. **URL 解析**：浏览器解析 URL，提取协议、域名、端口、路径
2. **DNS 解析**：将域名解析为 IP 地址
3. **TCP 三次握手**：建立可靠的 TCP 连接
4. **TLS 握手**（HTTPS）：建立安全连接
5. **HTTP 请求/响应**：发送请求并接收响应
6. **HTML 解析**：构建 DOM 树
7. **CSS 解析**：构建 CSSOM 树
8. **JavaScript 执行**：下载并执行 JS，可能修改 DOM
9. **构建渲染树**：合并 DOM 和 CSSOM
10. **布局（Layout）**：计算元素位置和大小
11. **绘制（Paint）**：将布局转换为像素
12. **合成（Composite）**：将图层合成到屏幕

### 优化点

- DNS 预解析
- HTTP/2 多路复用
- 代码分割和懒加载
- 关键渲染路径优化

:::

## 2. 浏览器缓存策略

::: details
**问题**：如何设计一个完整的缓存策略？

### 强缓存

- Cache-Control：max-age、no-cache、no-store
- Expires：绝对过期时间
- 优先级：Cache-Control > Expires

### 协商缓存

- ETag / If-None-Match：资源唯一标识
- Last-Modified / If-Modified-Since：最后修改时间
- 优先级：ETag > Last-Modified

### 缓存策略

| 资源类型 | 策略 |
|----------|------|
| HTML | no-cache + 协商缓存 |
| CSS/JS | max-age=31536000 + 文件名哈希 |
| 图片 | max-age=31536000 |
| API | no-store |

### 最佳实践

- 静态资源使用文件名哈希
- HTML 使用协商缓存
- API 数据不缓存
- 使用 CDN 加速

:::

## 3. 跨域解决方案

::: details
**问题**：如何解决跨域问题？有哪些方案？

### CORS（推荐）

- 简单请求：直接发送
- 预检请求：OPTIONS 预检
- 配置：Access-Control-Allow-Origin

### JSONP

- 利用 script 标签不受同源策略限制
- 只支持 GET 请求
- 安全性差

### 代理服务器

- 正向代理：代理客户端
- 反向代理：代理服务器
- 配置：Nginx 或开发服务器

### WebSocket

- 不受同源策略限制
- 支持双向通信
- 适合实时应用

:::

## 4. XSS 和 CSRF 防护

::: details
**问题**：如何防止 XSS 和 CSRF 攻击？

### XSS 防护

- 输入过滤：过滤危险字符
- 输出编码：HTML 实体编码
- CSP：内容安全策略
- HttpOnly：Cookie 不可访问

### CSRF 防护

- CSRF Token：服务器生成的令牌
- SameSite Cookie：限制跨站请求
- 验证 Referer：检查请求来源
- 双重 Cookie：Cookie 和表单双重验证

### 安全最佳实践

- 使用 HTTPS
- 设置安全响应头
- 输入验证
- 输出编码

:::

## 6. 浏览器存储方案

::: details
**问题**：如何选择合适的存储方案？

### 存储方案对比

| 方案 | 容量 | 有效期 | 用途 |
|------|------|--------|------|
| Cookie | 4KB | 可设置 | 认证信息 |
| localStorage | 5MB | 永久 | 本地设置 |
| sessionStorage | 5MB | 会话 | 临时数据 |
| IndexedDB | 无限制 | 永久 | 大量数据 |
| Cache API | 无限制 | 可设置 | 离线缓存 |

### 选择原则

- 小量数据：Cookie 或 localStorage
- 大量数据：IndexedDB
- 离线应用：Cache API
- 服务端数据：数据库

:::

## 7. 事件循环机制

::: details
**问题**：详细描述浏览器的事件循环机制。

### 执行模型

1. 执行同步代码（调用栈）
2. 执行微任务队列
3. 执行宏任务队列
4. 重复步骤 2-3

### 宏任务

- setTimeout/setInterval
- I/O 操作
- UI 渲染
- requestAnimationFrame

### 微任务

- Promise.then/catch/finally
- MutationObserver
- queueMicrotask

### 注意事项

- 微任务优先于宏任务
- 微任务在当前任务结束后立即执行
- 一个任务中产生的微任务会全部执行完

:::

## 8. 内存泄漏排查

::: details
**问题**：如何排查和解决内存泄漏？

### 常见原因

- 未清理的定时器
- 未移除的事件监听器
- 闭包引用
- 未清理的 DOM 引用

### 排查工具

- Chrome DevTools Memory 面板
- Heap Snapshot
- Allocation Timeline
- Performance Monitor

### 解决方案

- 及时清理定时器
- 移除事件监听器
- 避免不必要的闭包
- 使用 WeakMap/WeakRef

:::

## 9. Service Worker 应用

::: details
**问题**：如何使用 Service Worker 实现离线应用？

### 核心功能

- 拦截网络请求
- 缓存资源
- 离线访问
- 后台同步

### 缓存策略

- Cache First：缓存优先
- Network First：网络优先
- Stale While Revalidate：先返回缓存，后台更新

### 使用场景

- PWA 应用
- 离线文档
- 消息推送
- 后台同步

:::

## 10. Web Worker 使用

::: details
**问题**：如何使用 Web Worker 优化性能？

### 使用场景

- 大量计算任务
- 数据处理
- 图像处理
- 加密解密

### 通信方式

- postMessage：发送消息
- onmessage：监听消息
- Transferable：转移所有权

### 注意事项

- 不能访问 DOM
- 不能访问 window 对象
- 使用 URL 或 Blob 创建
- 通信是异步的

:::
