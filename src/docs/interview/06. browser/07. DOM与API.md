# DOM与API

## 1. DOM 操作

::: details
DOM（Document Object Model）是 HTML 和 XML 文档的编程接口，它将文档表示为树结构，允许 JavaScript 操作文档的结构、样式和内容。

### DOM 选择方法

- **getElementById()**：通过 ID 选择元素
- **querySelector()**：通过 CSS 选择器选择第一个匹配的元素
- **querySelectorAll()**：通过 CSS 选择器选择所有匹配的元素

### DOM 修改方法

- **innerHTML**：设置或获取元素的 HTML 内容
- **textContent**：设置或获取元素的文本内容
- **setAttribute()**：设置元素的属性
- **classList**：操作元素的类名

### DOM 创建和删除

- **createElement()**：创建元素节点
- **appendChild()**：将元素添加到父元素的末尾
- **removeChild()**：删除子元素
- **remove()**：删除元素自身

:::

## 2. 浏览器 API

::: details
浏览器 API 是浏览器提供的一组接口，允许 JavaScript 与浏览器和用户交互。

### 常用 API

- **Fetch API**：用于发送 HTTP 请求
- **Geolocation API**：用于获取用户的地理位置
- **Canvas API**：用于在网页上绘制图形
- **WebSocket API**：用于建立双向通信的 WebSocket 连接
- **Service Worker API**：用于创建离线体验、推送通知和后台同步

:::

## 3. 事件委托

::: details
事件委托是 JavaScript 中一种优化事件处理的技术，它利用事件冒泡的特性，将多个子元素的事件处理委托给父元素。

### 优点

1. **减少事件监听器的数量**：不需要为每个子元素添加事件监听器
2. **动态元素支持**：新添加的子元素会自动继承事件处理
3. **代码简洁**：减少重复代码，提高代码可维护性

### 适用场景

1. **列表项点击事件**：当列表项很多时
2. **动态生成的元素**：当元素是动态生成的时
3. **表单元素**：当表单中有多个输入元素时

:::

## 4. Intersection Observer

::: details
Intersection Observer API 提供了一种异步监听目标元素与祖先元素或视口交叉状态变化的方法。

### 基本用法

- 创建观察器：`new IntersectionObserver(callback, options)`
- 开始观察：`observer.observe(element)`
- 停止观察：`observer.unobserve(element)`

### 配置选项

- **root**：观察区域的根元素，默认为视口
- **rootMargin**：根元素的边距
- **threshold**：触发回调的交叉比例

### 应用场景

- 懒加载：当元素进入视口时加载图片或内容
- 无限滚动：当滚动到底部时加载更多内容
- 广告曝光：检测广告是否可见
- 动画触发：当元素进入视口时触发动画

:::

## 5. Mutation Observer

::: details
Mutation Observer API 用于监听 DOM 树的变化。

### 基本用法

- 创建观察器：`new MutationObserver(callback)`
- 开始观察：`observer.observe(target, options)`
- 停止观察：`observer.disconnect()`

### 配置选项

- **childList**：监听子节点的添加或删除
- **attributes**：监听属性的变化
- **characterData**：监听文本内容的变化
- **subtree**：监听所有后代节点的变化

### 应用场景

- 动态内容检测：监听 DOM 内容的变化
- 框架实现：Vue、React 等框架的底层实现
- 性能监控：检测 DOM 操作的频率

:::

## 6. Resize Observer

::: details
Resize Observer API 用于监听元素尺寸的变化。

### 基本用法

- 创建观察器：`new ResizeObserver(callback)`
- 开始观察：`observer.observe(element)`
- 停止观察：`observer.disconnect()`

### 应用场景

- 响应式布局：监听容器尺寸变化并调整布局
- 图片自适应：监听图片容器尺寸变化并调整图片大小
- 图表自适应：监听图表容器尺寸变化并调整图表

:::

## 7. Performance Observer

::: details
Performance Observer API 用于监听性能度量事件。

### 基本用法

- 创建观察器：`new PerformanceObserver(callback)`
- 开始观察：`observer.observe({ entryTypes: ['navigation'] })`
- 停止观察：`observer.disconnect()`

### 监听类型

- **navigation**：页面导航信息
- **resource**：资源加载信息
- **paint**：绘制信息（first-paint、first-contentful-paint）
- **largest-contentful-paint**：最大内容绘制
- **layout-shift**：布局偏移

### 应用场景

- 性能监控：收集页面性能数据
- Web Vitals：监测 LCP、CLS 等指标
- 用户体验分析：了解用户感知的加载速度

:::
