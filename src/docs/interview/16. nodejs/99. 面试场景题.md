# 面试场景题

## 1. 手写 Promise.all

::: details
**问题**：实现一个 Promise.all 方法，支持取消和超时。

### 核心要点

- 接收 Promise 数组
- 所有 Promise 都成功才返回成功
- 任意一个失败就返回失败
- 保持结果顺序

### 进阶功能

- 支持取消：使用 AbortController
- 支持超时：设置最大等待时间
- 支持并发控制：限制同时执行数量

:::

## 2. 手写 EventEmitter

::: details
**问题**：实现一个 Node.js EventEmitter 类。

### 核心功能

- on：添加事件监听
- off：移除事件监听
- emit：触发事件
- once：只触发一次
- prependListener：在监听器列表开头添加

### 实现要点

- 使用对象存储事件列表
- 支持多个参数传递
- 支持移除所有监听器
- 支持获取监听器数量

:::

## 3. 手写 Stream

::: details
**问题**：实现一个可读流（Readable Stream）。

### 核心概念

- 流是处理大量数据的有效方式
- 支持背压处理
- 支持 pipe 操作

### 实现要点

- 继承 EventEmitter
- 实现 _read 方法
- 实现 push 方法
- 处理 highWaterMark

:::

## 4. 手写 Worker Threads

::: details
**问题**：使用 Worker Threads 实现多线程计算。

### 核心概念

- 主线程与工作线程通信
- 共享内存（SharedArrayBuffer）
- 任务分发与结果收集

### 实现要点

- 使用 parentPort 进行消息传递
- 使用 SharedArrayBuffer 共享数据
- 使用 Atomics 进行原子操作
- 处理线程池管理

### 使用场景

- CPU 密集型计算
- 图像/视频处理
- 加密解密
- 数据分析

:::
