# 文件系统与流

## 1. 文件操作

::: details
Node.js 提供了同步和异步两种文件操作方式。

### 同步操作

```javascript
const fs = require('fs');

// 读取文件
const data = fs.readFileSync('file.txt', 'utf8');
console.log(data);

// 写入文件
fs.writeFileSync('output.txt', 'Hello World');

// 追加内容
fs.appendFileSync('log.txt', '新内容\n');

// 删除文件
fs.unlinkSync('temp.txt');

// 检查文件是否存在
const exists = fs.existsSync('file.txt');
```

### 异步操作

```javascript
const fs = require('fs');

// 读取文件
fs.readFile('file.txt', 'utf8', (err, data) => {
  if (err) {
    console.error(err);
    return;
  }
  console.log(data);
});

// 写入文件
fs.writeFile('output.txt', 'Hello World', (err) => {
  if (err) {
    console.error(err);
  }
});

// Promise 版本
const fsPromises = require('fs').promises;

async function readFile(path) {
  try {
    const data = await fsPromises.readFile(path, 'utf8');
    return data;
  } catch (error) {
    console.error(error);
  }
}
```

### 文件信息

```javascript
const fs = require('fs');

fs.stat('file.txt', (err, stats) => {
  console.log(stats.isFile());      // 是否是文件
  console.log(stats.isDirectory()); // 是否是目录
  console.log(stats.size);          // 文件大小
  console.log(stats.mtime);         // 修改时间
});
```

### 总结

文件操作是 Node.js 的基础功能，推荐使用异步方式避免阻塞。

:::

## 2. 目录操作

::: details
Node.js 提供了目录创建、读取和删除的方法。

### 创建目录

```javascript
const fs = require('fs');

// 同步创建
fs.mkdirSync('new-dir');

// 异步创建
fs.mkdir('new-dir', (err) => {
  if (err) throw err;
});

// 递归创建
fs.mkdirSync('a/b/c', { recursive: true });
```

### 读取目录

```javascript
// 同步读取
const files = fs.readdirSync('dir');
console.log(files);

// 异步读取
fs.readdir('dir', (err, files) => {
  console.log(files);
});

// 递归读取
const glob = require('glob');
glob('**/*.js', (err, files) => {
  console.log(files);
});
```

### 删除目录

```javascript
// 删除空目录
fs.rmdirSync('empty-dir');

// 删除目录及其内容
fs.rmSync('dir', { recursive: true });

// 异步版本
fs.rm('dir', { recursive: true }, (err) => {
  if (err) throw err;
});
```

### 总结

目录操作常用于构建工具、脚本等场景。

:::

## 3. 流

::: details
流是处理大量数据的有效方式。

### 流的类型

| 类型 | 说明 |
|------|------|
| Readable | 可读流，如 `fs.createReadStream` |
| Writable | 可写流，如 `fs.createWriteStream` |
| Duplex | 双工流，可读可写 |
| Transform | 转换流，修改数据 |

### 读取流

```javascript
const fs = require('fs');

const readStream = fs.createReadStream('large-file.txt', {
  encoding: 'utf8',
  highWaterMark: 1024  // 每次读取 1KB
});

readStream.on('data', (chunk) => {
  console.log(`收到 ${chunk.length} 字节`);
});

readStream.on('end', () => {
  console.log('读取完成');
});

readStream.on('error', (err) => {
  console.error(err);
});
```

### 写入流

```javascript
const fs = require('fs');

const writeStream = fs.createWriteStream('output.txt');

writeStream.write('第一行\n');
writeStream.write('第二行\n');
writeStream.end('最后一行\n');

writeStream.on('finish', () => {
  console.log('写入完成');
});
```

### 管道流

```javascript
const fs = require('fs');
const zlib = require('zlib');

// 文件压缩
fs.createReadStream('input.txt')
  .pipe(zlib.createGzip())
  .pipe(fs.createWriteStream('input.txt.gz'));

// 文件复制
fs.createReadStream('source.txt')
  .pipe(fs.createWriteStream('dest.txt'));
```

### 总结

流适合处理大文件，可以有效减少内存使用。

:::

## 4. 文件监视

::: details
Node.js 可以监视文件变化。

### fs.watch

```javascript
const fs = require('fs');

// 监视文件变化
fs.watch('file.txt', (eventType, filename) => {
  console.log(`${eventType}: ${filename}`);
});

// 监视目录
fs.watch('dir', { recursive: true }, (eventType, filename) => {
  console.log(`${eventType}: ${filename}`);
});
```

### fs.watchFile

```javascript
// 轮询方式监视
fs.watchFile('file.txt', { interval: 1000 }, (curr, prev) => {
  console.log(`文件变化: ${prev.mtime} -> ${curr.mtime}`);
});
```

### 第三方库

```javascript
// chokidar（推荐）
const chokidar = require('chokidar');

chokidar.watch('src/**/*.js').on('change', (path) => {
  console.log(`文件变化: ${path}`);
});
```

### 总结

文件监视常用于开发工具、热重载等场景。

:::
