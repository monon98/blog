# 基础概念

## 1. 什么是 Node.js

::: details
Node.js 是一个基于 Chrome V8 引擎的 JavaScript 运行时环境。

### 核心特点

| 特点 | 说明 |
|------|------|
| 事件驱动 | 基于事件循环的异步 I/O 模型 |
| 非阻塞 I/O | 单线程处理并发连接 |
| 跨平台 | 支持 Windows、Linux、macOS |
| npm 生态 | 拥有最大的 JavaScript 包管理生态 |

### 版本历史

| 版本 | 发布时间 | 特性 |
|------|----------|------|
| Node.js 18 | 2022 | Fetch API、Web Crypto、test runner |
| Node.js 20 | 2023 | 权限模型、单文件可执行程序、`--watch` |
| Node.js 22 | 2024 | WebSocket 客户端、`require(esm)`、`fs.glob`、TypeScript 类型剥离 |

### Node.js 22 新特性

| 特性 | 说明 |
|------|------|
| WebSocket 客户端 | 全局可用，无需第三方库 |
| `require(esm)` | CommonJS 模块中可直接 require ESM |
| `fs.glob` | 内置文件匹配，无需第三方 `glob` 库 |
| TypeScript 支持 | 类型剥离，可直接运行 .ts 文件 |
| `--watch` 模式 | 标记为稳定，支持文件变化自动重启 |
| 权限模型 | 更细粒度的文件系统访问控制 |

### 总结

Node.js 是服务端 JavaScript 运行时，适用于 I/O 密集型应用。

:::

## 2. 事件循环

::: details
事件循环是 Node.js 处理异步操作的核心机制。

### 事件循环阶段

```
   ┌───────────────────────────┐
┌─>│        timers             │  ← setTimeout, setInterval
│  └─────────────┬─────────────┘
│  ┌─────────────┴─────────────┐
│  │     pending callbacks     │  ← 系统操作回调
│  └─────────────┬─────────────┘
│  ┌─────────────┴─────────────┐
│  │       idle, prepare       │  ← 内部使用
│  └─────────────┬─────────────┘      │
│  ┌─────────────┴─────────────┐      │
│  │         poll              │  ← I/O 回调，处理新连接
│  └─────────────┬─────────────┘      │
│  ┌─────────────┴─────────────┐      │
│  │         check             │  ← setImmediate
│  └─────────────┬─────────────┘      │
│  ┌─────────────┴─────────────┐      │
│  │     close callbacks       │  ← socket.on('close')
│  └─────────────┬─────────────┘      │
└────────────────┘
```

### 微任务队列

```javascript
// 微任务（优先级最高）
Promise.resolve().then(() => console.log('promise'));
process.nextTick(() => console.log('nextTick'));

// 输出顺序：
// nextTick
// promise
```

### 宏任务对比

```javascript
setTimeout(() => console.log('setTimeout'), 0);
setImmediate(() => console.log('setImmediate'));

// 输出顺序不确定，取决于系统时钟
```

### 总结

事件循环分为多个阶段，微任务优先于宏任务执行。

:::

## 3. 全局对象

::: details
Node.js 提供了多个全局对象。

### 常用全局对象

| 对象 | 说明 |
|------|------|
| `global` | Node.js 全局对象（类似浏览器的 `window`） |
| `process` | 当前进程信息 |
| `__dirname` | 当前文件所在目录 |
| `__filename` | 当前文件完整路径 |
| `Buffer` | 二进制数据处理 |
| `console` | 控制台输出 |

### process 常用方法

```javascript
// 环境变量
console.log(process.env.NODE_ENV);

// 命令行参数
console.log(process.argv);

// 当前工作目录
console.log(process.cwd());

// 内存使用
console.log(process.memoryUsage());

// 退出进程
process.exit(0);  // 0 表示成功
```

### 总结

全局对象提供了访问系统资源和进程信息的能力。

:::

## 4. 错误处理

::: details
Node.js 的错误处理机制。

### 错误类型

```javascript
// 同步错误
try {
  JSON.parse('invalid json');
} catch (error) {
  console.error('解析错误:', error.message);
}

// 异步错误（回调）
fs.readFile('file.txt', (err, data) => {
  if (err) {
    console.error('读取错误:', err);
    return;
  }
  console.log(data);
});

// Promise 错误
promise
  .then(data => console.log(data))
  .catch(error => console.error(error));

// async/await 错误
async function fetchData() {
  try {
    const data = await readFile('file.txt');
  } catch (error) {
    console.error(error);
  }
}
```

### 错误传播

```javascript
// 未捕获的异常
process.on('uncaughtException', (error) => {
  console.error('未捕获异常:', error);
  process.exit(1);
});

// 未处理的 Promise 拒绝
process.on('unhandledRejection', (reason, promise) => {
  console.error('未处理的 Promise 拒绝:', reason);
});
```

### 总结

正确处理错误是保证 Node.js 应用稳定性的关键。

:::
