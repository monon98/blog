# 模块系统

## 1. CommonJS

::: details
CommonJS 是 Node.js 传统的模块系统。

### 导出模块

```javascript
// math.js
function add(a, b) {
  return a + b;
}

function subtract(a, b) {
  return a - b;
}

// 导出
module.exports = { add, subtract };
// 或
exports.add = add;
exports.subtract = subtract;
```

### 导入模块

```javascript
// app.js
const math = require('./math');
console.log(math.add(1, 2));  // 3

// 解构导入
const { add, subtract } = require('./math');
```

### 缓存机制

```javascript
// CommonJS 会缓存模块，只执行一次
// a.js
console.log('模块 A 加载');
exports.value = 1;

// b.js
const a1 = require('./a');  // 输出 '模块 A 加载'
const a2 = require('./a');  // 不输出，直接返回缓存
console.log(a1 === a2);    // true
```

### 总结

CommonJS 是同步加载的模块系统，适合服务端使用。

:::

## 2. ES Modules

::: details
ES Modules 是 JavaScript 官方的模块系统。

### 导出模块

```javascript
// math.mjs
export function add(a, b) {
  return a + b;
}

export function subtract(a, b) {
  return a - b;
}

export default class Calculator {
  // ...
}
```

### 导入模块

```javascript
// app.mjs
import Calculator, { add, subtract } from './math.mjs';

// 重命名导入
import { add as sum } from './math.mjs';

// 动态导入
const module = await import('./math.mjs');
```

### package.json 配置

```json
{
  "name": "my-app",
  "type": "module",
  "scripts": {
    "start": "node app.mjs"
  }
}
```

### CommonJS 与 ESM 互操作

```javascript
// ESM 中导入 CommonJS
import pkg from './commonjs-module.cjs';
const { something } = pkg;

// CommonJS 中导入 ESM（需要动态导入）
async function loadESM() {
  const { something } = await import('./esm-module.mjs');
}
```

### 总结

ES Modules 是官方推荐的模块系统，支持静态分析和 tree-shaking。

:::

## 3. npm 与包管理

::: details
npm 是 Node.js 的包管理器。

### 常用命令

```bash
# 初始化项目
npm init -y

# 安装依赖
npm install express

# 安装开发依赖
npm install --save-dev jest

# 全局安装
npm install -g typescript

# 查看包信息
npm view express version

# 运行脚本
npm run dev
```

### 依赖版本管理

```json
{
  "dependencies": {
    "express": "^4.18.0",  // 主版本不变，允许补丁更新
    "lodash": "~4.17.21"   // 仅允许补丁更新
  }
}
```

| 符号 | 说明 |
|------|------|
| `^` | 允许主版本更新（推荐） |
| `~` | 仅允许补丁更新 |
| 无符号 | 锁定精确版本 |

### npx 使用

```bash
# 运行本地包
npx jest

# 运行远程包
npx create-react-app my-app

# 临时安装运行
npx -p typescript tsc --init
```

### 总结

npm 是 Node.js 生态的核心，掌握包管理是必备技能。

:::

## 4. 模块解析

::: details
Node.js 如何解析模块路径。

### 解析顺序

```javascript
// require('./foo')
// 1. 精确匹配文件
//    ./foo
//    ./foo.js
//    ./foo.json
//    ./foo.node

// 2. 目录解析
//    ./foo/index.js
//    ./foo/index.json
//    ./foo/index.node
```

### node_modules 查找

```javascript
// require('lodash')
// 从当前目录向上查找 node_modules
// ./node_modules/lodash
// ../node_modules/lodash
// ../../node_modules/lodash
// ...
```

### 路径别名

```json
// package.json
{
  "name": "my-app",
  "_moduleAliases": {
    "@root": ".",
    "@components": "./src/components"
  }
}
```

### 总结

理解模块解析机制有助于排查依赖问题。

:::
