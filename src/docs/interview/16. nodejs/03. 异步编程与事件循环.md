# 异步编程与事件循环

## 1. 回调函数

::: details
回调函数是 Node.js 最早的异步编程方式。

### 基本回调

```javascript
// 回调风格
function fetchData(callback) {
  setTimeout(() => {
    callback(null, { name: '张三' });
  }, 1000);
}

fetchData((err, data) => {
  if (err) {
    console.error(err);
    return;
  }
  console.log(data);
});
```

### 回调地狱

```javascript
// 回调地狱示例
getUser(userId, (err, user) => {
  getOrders(user.id, (err, orders) => {
    getOrderDetails(orders[0].id, (err, detail) => {
      getProducts(detail.productId, (err, products) => {
        // 嵌套过深，难以维护
      });
    });
  });
});
```

### 错误优先回调

```javascript
// Node.js 约定：回调第一个参数是 error
function readFile(path, callback) {
  fs.readFile(path, 'utf8', (err, data) => {
    if (err) {
      return callback(err);
    }
    callback(null, data);
  });
}
```

### 总结

回调函数简单但容易导致回调地狱，现代开发推荐使用 Promise 或 async/await。

:::

## 2. Promise

::: details
Promise 是异步编程的解决方案之一。

### 创建 Promise

```javascript
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    const success = true;
    if (success) {
      resolve({ name: '张三' });
    } else {
      reject(new Error('失败'));
    }
  }, 1000);
});
```

### 链式调用

```javascript
fetchUser(userId)
  .then(user => fetchOrders(user.id))
  .then(orders => fetchDetails(orders[0].id))
  .then(detail => console.log(detail))
  .catch(error => console.error(error))
  .finally(() => console.log('完成'));
```

### Promise 方法

```javascript
// Promise.all - 全部成功才成功
const results = await Promise.all([
  fetch('/api/user'),
  fetch('/api/posts'),
  fetch('/api/comments')
]);

// Promise.allSettled - 等待所有完成
const results = await Promise.allSettled([
  promise1,
  promise2,
  promise3
]);

// Promise.race - 第一个完成的结果
const result = await Promise.race([
  fetch('/api/fast'),
  fetch('/api/slow')
]);

// Promise.any - 第一个成功的结果
const result = await Promise.any([
  fetch('/api/server1'),
  fetch('/api/server2')
]);
```

### 总结

Promise 解决了回调地狱问题，支持链式调用和错误处理。

:::

## 3. async/await

::: details
async/await 是 Promise 的语法糖，让异步代码看起来像同步代码。

### 基本用法

```javascript
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    return data;
  } catch (error) {
    console.error('请求失败:', error);
    throw error;
  }
}
```

### 并发执行

```javascript
// 顺序执行（慢）
async function sequential() {
  const user = await fetchUser();
  const orders = await fetchOrders(user.id);
  return { user, orders };
}

// 并发执行（快）
async function parallel() {
  const [user, posts] = await Promise.all([
    fetchUser(),
    fetchPosts()
  ]);
  return { user, posts };
}
```

### 错误处理

```javascript
// try/catch 捕获
async function riskyOperation() {
  try {
    const data = await fetch('/api/data');
    return data;
  } catch (error) {
    console.error(error);
    return null;
  }
}

// 统一错误处理
async function withErrorHandling(fn) {
  try {
    return await fn();
  } catch (error) {
    console.error('操作失败:', error);
    throw error;
  }
}
```

### 总结

async/await 让异步代码更易读和维护，是现代 Node.js 开发的首选方式。

:::

## 4. 事件触发器

::: details
Node.js 的 EventEmitter 是事件驱动编程的核心。

### 基本使用

```javascript
const EventEmitter = require('events');

class MyEmitter extends EventEmitter {}

const emitter = new MyEmitter();

// 监听事件
emitter.on('data', (chunk) => {
  console.log('收到数据:', chunk);
});

// 触发事件
emitter.emit('data', 'Hello');
emitter.emit('data', 'World');
```

### 常用方法

```javascript
// 添加监听器
emitter.on('event', handler);
emitter.addListener('event', handler);

// 一次性监听器
emitter.once('event', handler);

// 移除监听器
emitter.removeListener('event', handler);
emitter.off('event', handler);

// 获取监听器数量
const count = emitter.listenerCount('event');

// 获取事件名
const events = emitter.eventNames();
```

### 错误事件

```javascript
emitter.on('error', (error) => {
  console.error('错误:', error);
});

// 触发错误
emitter.emit('error', new Error('出错了'));
```

### 实际应用

```javascript
// HTTP 服务器
const server = http.createServer();

server.on('request', (req, res) => {
  res.end('Hello');
});

server.on('listening', () => {
  console.log('服务器启动');
});

server.on('error', (err) => {
  console.error(err);
});
```

### 总结

EventEmitter 是 Node.js 事件驱动架构的基础，广泛用于各种核心模块。

:::
