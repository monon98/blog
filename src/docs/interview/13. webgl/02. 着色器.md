# 着色器

## 1. 着色器基础

::: details
着色器是 WebGL 渲染的核心，运行在 GPU 上。

### 着色器类型

| 类型 | 作用 | 语言 |
|------|------|------|
| 顶点着色器 | 处理顶点位置 | GLSL ES |
| 片元着色器 | 处理像素颜色 | GLSL ES |

### 顶点着色器

```glsl
// 顶点着色器
attribute vec4 a_position;  // 顶点位置
uniform mat4 u_matrix;      // 变换矩阵

void main() {
  gl_Position = u_matrix * a_position;
}
```

### 片元着色器

```glsl
// 片元着色器
precision mediump float;
uniform vec4 u_color;  // 颜色

void main() {
  gl_FragColor = u_color;
}
```

### 着色器编译

```javascript
function createShader(gl, type, source) {
  const shader = gl.createShader(type);
  gl.shaderSource(shader, source);
  gl.compileShader(shader);
  
  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    console.error('着色器编译错误:', gl.getShaderInfoLog(shader));
    gl.deleteShader(shader);
    return null;
  }
  
  return shader;
}
```

### 总结

着色器是 WebGL 渲染的核心，分为顶点着色器和片元着色器。

:::

## 2. 着色器变量

::: details
着色器使用不同类型的变量传递数据。

### Attribute 变量（GLSL ES 1.0 / WebGL1）

```glsl
// 顶点着色器中的 attribute 变量
attribute vec3 a_position;  // 声明为 vec3
attribute vec2 a_texCoord;
attribute vec3 a_normal;

void main() {
  gl_Position = vec4(a_position, 1.0);  // vec3 -> vec4
}
```

```javascript
// JavaScript 中设置 attribute 变量
const positionLocation = gl.getAttribLocation(program, 'a_position');
gl.enableVertexAttribArray(positionLocation);
gl.vertexAttribPointer(positionLocation, 3, gl.FLOAT, false, 0, 0);
```

### Attribute 变量（GLSL ES 3.0 / WebGL2）

```glsl
#version 300 es
// attribute 关键字在 GLSL ES 3.0 中被 in 替代
in vec3 a_position;
in vec2 a_texCoord;
in vec3 a_normal;

void main() {
  gl_Position = vec4(a_position, 1.0);
}
```

### Uniform 变量（GLSL ES 1.0 / WebGL1）

```glsl
// 着色器中的 uniform 变量
uniform mat4 u_modelViewMatrix;
uniform mat4 u_projectionMatrix;
uniform vec4 u_color;

void main() {
  gl_FragColor = u_color;
}
```

### Uniform 变量（GLSL ES 3.0 / WebGL2）

```glsl
#version 300 es
precision mediump float;
uniform mat4 u_modelViewMatrix;
uniform mat4 u_projectionMatrix;
uniform vec4 u_color;

out vec4 fragColor;  // gl_FragColor 已移除，需声明输出变量
void main() {
  fragColor = u_color;
}
```

```javascript
// JavaScript 中设置 uniform 变量
const colorLocation = gl.getUniformLocation(program, 'u_color');
gl.uniform4f(colorLocation, 1.0, 0.0, 0.0, 1.0);

const matrixLocation = gl.getUniformLocation(program, 'u_modelViewMatrix');
gl.uniformMatrix4fv(matrixLocation, false, matrix);
```

### Varying 变量（GLSL ES 1.0 / WebGL1）

```glsl
// 顶点着色器
attribute vec4 a_position;
varying vec2 v_texCoord;

void main() {
  gl_Position = a_position;
  v_texCoord = a_position.xy * 0.5 + 0.5;
}

// 片元着色器
precision mediump float;
varying vec2 v_texCoord;
uniform sampler2D u_texture;

void main() {
  gl_FragColor = texture2D(u_texture, v_texCoord);
}
```

### Varying 变量（GLSL ES 3.0 / WebGL2）

```glsl
#version 300 es
// 顶点着色器
in vec4 a_position;        // attribute -> in
out vec2 v_texCoord;       // varying -> out

void main() {
  gl_Position = a_position;
  v_texCoord = a_position.xy * 0.5 + 0.5;
}

// 片元着色器
precision mediump float;
in vec2 v_texCoord;        // varying -> in
out vec4 fragColor;        // gl_FragColor -> out 变量
uniform sampler2D u_texture;

void main() {
  fragColor = texture(u_texture, v_texCoord);  // texture2D -> texture
}
```

### 总结

着色器使用 attribute、uniform、varying 等变量类型传递数据。

## 3. GLSL 语言

::: details
GLSL（OpenGL Shading Language）是着色器的编程语言。

### 数据类型

```glsl
// 基本类型
float f = 1.0;
int i = 1;
bool b = true;

// 向量类型
vec2 v2 = vec2(1.0, 2.0);
vec3 v3 = vec3(1.0, 2.0, 3.0);
vec4 v4 = vec4(1.0, 2.0, 3.0, 4.0);

// 矩阵类型
mat2 m2 = mat2(1.0);
mat3 m3 = mat3(1.0);
mat4 m4 = mat4(1.0);

// 采样器
sampler2D tex2D;
samplerCube texCube;
```

### 内置函数

```glsl
// 数学函数
float sin(float x);
float cos(float x);
float tan(float x);
float pow(float x, float y);
float sqrt(float x);
float abs(float x);
float min(float x, float y);
float max(float x, float y);

// 向量函数
float dot(vec3 x, vec3 y);
vec3 cross(vec3 x, vec3 y);
vec3 normalize(vec3 x);
float length(vec3 x);

// 纹理采样
vec4 texture2D(sampler2D sampler, vec2 coord);
```

### 控制结构

```glsl
// 条件语句
if (condition) {
  // ...
} else {
  // ...
}

// 循环语句
for (int i = 0; i < 10; i++) {
  // ...
}

// 函数
vec4 calculateColor(vec4 color) {
  return color * 2.0;
}
```

### 总结

GLSL 是着色器的编程语言，提供了丰富的数据类型和内置函数。

:::

## 4. 着色器优化

::: details
着色器优化可以提升渲染性能。

### 减少计算

```glsl
// 不推荐：每帧计算
void main() {
  float x = sin(u_time) * 10.0;
  gl_Position = vec4(x, 0.0, 0.0, 1.0);
}

// 推荐：在 JavaScript 中计算
uniform float u_x;
void main() {
  gl_Position = vec4(u_x, 0.0, 0.0, 1.0);
}
```

### 使用低精度

```glsl
// 使用低精度
precision lowp float;

// 只在需要时使用高精度
highp vec4 position;
```

### 减少纹理采样

```glsl
// 不推荐：多次采样
vec4 color1 = texture2D(u_texture1, v_texCoord);
vec4 color2 = texture2D(u_texture2, v_texCoord);

// 推荐：使用纹理图集
vec4 color = texture2D(u_textureAtlas, v_texCoord);
```

### 总结

着色器优化包括减少计算、使用低精度、减少纹理采样等。

:::
