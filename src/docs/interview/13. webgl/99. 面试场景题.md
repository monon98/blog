# 面试场景题

## 1. WebGL 基础概念

::: details
**问题**：WebGL 的渲染管线是什么？

### 渲染管线流程

1. 顶点着色器：处理顶点位置
2. 图元装配：组装几何图元
3. 光栅化：转换为像素
4. 片段着色器：处理像素颜色
5. 逐像素操作：深度测试、混合

### 核心概念

- Buffer：存储顶点数据
- Shader：顶点和片段着色器
- Program：着色器程序
- Texture：纹理贴图

### 使用场景

- 3D 图形渲染
- 数据可视化
- 图像处理
- 游戏开发

:::

## 2. 着色器编写

::: details
**问题**：如何编写 WebGL 着色器？

### 顶点着色器（WebGL 1.0）

```
attribute vec3 aPosition;
uniform mat4 uModelViewMatrix;
uniform mat4 uProjectionMatrix;
void main() {
  gl_Position = uProjectionMatrix * uModelViewMatrix * vec4(aPosition, 1.0);
}
```

### 顶点着色器（WebGL 2.0）

```
in vec3 aPosition;
uniform mat4 uModelViewMatrix;
uniform mat4 uProjectionMatrix;
void main() {
  gl_Position = uProjectionMatrix * uModelViewMatrix * vec4(aPosition, 1.0);
}
```

### 片段着色器（WebGL 1.0）

```
precision mediump float;
uniform vec4 uColor;
void main() {
  gl_FragColor = uColor;
}
```

### 片段着色器（WebGL 2.0）

```
precision mediump float;
uniform vec4 uColor;
out vec4 fragColor;
void main() {
  fragColor = uColor;
}
```

### Uniform 和 Attribute

- Attribute/in：逐顶点数据
- Uniform：全局统一数据
- Varying/out：顶点着色器传递到片段着色器

:::

## 10. WebGPU 发展

::: details
**问题**：WebGPU 与 WebGL 有什么区别？

### WebGPU 特点

- 更现代的 API 设计
- 支持计算着色器
- 更好的性能
- 更低的开销

### 与 WebGL 区别

| 特性 | WebGL | WebGPU |
|------|-------|--------|
| 设计 | OpenGL ES 风格 | Vulkan/Metal 风格 |
| 计算着色器 | 不支持 | 支持 |
| 管线状态 | 状态机 | 显式管线 |
| 错误处理 | 静默 | 显式验证 |

### 迁移建议

- 新项目可考虑 WebGPU
- 现有项目渐进式迁移
- 保持 WebGL 兼容性
- 关注浏览器支持情况

:::
