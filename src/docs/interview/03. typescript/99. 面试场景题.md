# 面试场景题

## 1. TypeScript 类型体操

::: details
**问题**：实现 DeepPartial 类型，让对象的所有属性都可以递归地变为可选。

### 实现

```
type DeepPartial<T> = {
  [P in keyof T]?: T[P] extends object ? DeepPartial<T[P]> : T[P];
}
```

### 应用场景

- 配置对象的部分更新
- 测试数据的构造
- API 响应的类型定义

:::

## 2. 条件类型推断

::: details
**问题**：实现一个类型，提取函数的返回值类型。

### 实现

```
type ReturnType<T> = T extends (...args: any[]) => infer R ? R : never;
```

### 扩展

- 提取函数参数类型：Parameters
- 提取构造函数实例类型：InstanceType
- 提取 Promise 内部类型：Awaited

:::

## 4. 模板字面量类型

::: details
**问题**：实现一个类型，将字符串类型转为联合类型。

### 实现

```
type StrToUnion<T extends string> = T extends `${infer First}${infer Rest}`
  ? First | StrToUnion<Rest>
  : never;

// 示例
type Result = StrToUnion<'abc'>; // 'a' | 'b' | 'c'
```

### 应用场景

- 路由参数类型提取
- CSS 属性值类型
- 事件名称类型

:::

## 6. TypeScript 高级类型

::: details
**问题**：实现 Exclude、Extract、Omit、Pick 等工具类型。

### Exclude

```
type Exclude<T, U> = T extends U ? never : T;
```

### Extract

```
type Extract<T, U> = T extends U ? T : never;
```

### Omit

```
type Omit<T, K extends keyof T> = Pick<T, Exclude<keyof T, K>>;
```

### Pick

```
type Pick<T, K extends keyof T> = {
  [P in K]: T[P];
};
```

## 7. 泛型约束技巧

::: details
**问题**：如何约束泛型必须是对象的某个路径？

### 实现

```
type Get<T, K extends string> = K extends `${infer First}.${infer Rest}`
  ? First extends keyof T
    ? Get<T[First], Rest>
    : never
  : K extends keyof T
    ? T[K]
    : never;

// 示例
type Result = Get<{ a: { b: { c: 1 } } }, 'a.b.c'>; // 1
```

### 应用场景

- 链式访问对象属性
- 路径字符串类型推断
- 表单字段路径类型

:::

## 8. 条件类型分发

::: details
**问题**：解释条件类型的分发行为，如何避免？

### 分发行为

```
type ToArray<T> = T extends any ? T[] : never;

// 分发
type Result = ToArray<string | number>; // string[] | number[]

// 不分发
type ToArrayNonDist<T> = [T] extends [any] ? T[] : never;
type Result2 = ToArrayNonDist<string | number>; // (string | number)[]
```

### 应用场景

- 联合类型的转换
- 类型过滤
- 类型映射

## 9. TypeScript 装饰器

::: details
**问题**：如何使用 TypeScript 装饰器实现日志记录？

### TC39 Stage 3 装饰器（TypeScript 5.0+）

```
function logged<T extends (...args: any[]) => any>(
  target: T,
  context: ClassMethodDecoratorContext
) {
  const methodName = String(context.name);
  return function (this: any, ...args: any[]) {
    console.log(`Calling ${methodName} with`, args);
    const result = target.call(this, ...args);
    console.log(`Result:`, result);
    return result;
  };
}

class Calculator {
  @logged
  add(a: number, b: number) {
    return a + b;
  }
}
```

### 与旧版装饰器的区别

- 旧版：使用 `descriptor.value` 修改方法
- 新版：返回新的函数替换原方法
- 新版更简单、更符合标准

### 应用场景

- 日志记录
- 权限验证
- 性能监控
- 缓存处理

:::

## 10. TypeScript 与 React

::: details
**问题**：如何为 React 组件编写类型安全的 Props？

### 组件 Props 类型（React 18+）

```
interface ButtonProps {
  variant: 'primary' | 'secondary';
  size?: 'sm' | 'md' | 'lg';
  onClick?: () => void;
  children: React.ReactNode;
}

function Button({ variant, size, onClick, children }: ButtonProps) {
  return (
    <button className={`btn btn-${variant} btn-${size}`} onClick={onClick}>
      {children}
    </button>
  );
}
```

### 泛型组件

```
interface ListProps<T> {
  items: T[];
  renderItem: (item: T) => React.ReactNode;
}

function List<T>({ items, renderItem }: ListProps<T>) {
  return <div>{items.map(renderItem)}</div>;
}
```

### 注意事项

- React 18+ 已移除 FC 的 children 类型
- 推荐直接定义函数签名
- 使用 ReactNode 表示可渲染内容

:::
