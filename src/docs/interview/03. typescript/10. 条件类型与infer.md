# TypeScript 条件类型与 infer 面试题

## 1. 什么是条件类型？如何使用？

::: details
条件类型是 TypeScript 中的一种高级类型，它根据条件来选择不同的类型。语法类似于三元运算符。

### 基本语法

```typescript
type IsString<T> = T extends string ? "yes" : "no";

type A = IsString<string>;  // "yes"
type B = IsString<number>;  // "no"
type C = IsString<"hello">; // "yes"
```

### 条件类型的使用场景

```typescript
// 1. 类型检查
type IsArray<T> = T extends any[] ? true : false;

type D = IsArray<number[]>;  // true
type E = IsArray<string>;    // false

// 2. 类型过滤
type FilterStrings<T extends any[]> = T extends (infer U)[]
  ? U extends string
    ? U
    : never
  : never;

type F = FilterStrings<[string, number, string, boolean]>; // string | string = string

// 3. 类型提取
type FirstElement<T extends any[]> = T extends [infer First, ...any[]]
  ? First
  : never;

type G = FirstElement<[string, number]>; // string
type H = FirstElement<[]>;               // never
```

### 分布式条件类型

当条件类型作用于泛型类型参数时，如果该参数是联合类型，则条件类型会分发到联合类型的每个成员。

```typescript
type ToArray<T> = T extends any ? T[] : never;

// 分布式行为
type Result1 = ToArray<string | number>;
// 等同于 ToArray<string> | ToArray<number>
// 即 string[] | number[]

// 非分布式行为（通过方括号包裹）
type ToArrayNonDist<T> = [T] extends [any] ? T[] : never;

type Result2 = ToArrayNonDist<string | number>;
// (string | number)[]
```

## 2. 什么是 infer 关键字？如何使用？

::: details
`infer` 关键字用于在条件类型中推断类型变量。它只能在 `extends` 子句的 `true` 分支中使用。

### 基本用法

```typescript
// 推断函数返回类型
type ReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

type Fn = () => string;
type Result = ReturnType<Fn>; // string

// 推断函数参数类型
type Parameters<T> = T extends (...args: infer P) => any ? P : never;

type Fn2 = (a: string, b: number) => void;
type Params = Parameters<Fn2>; // [a: string, b: number]
```

### 实际应用示例

```typescript
// 1. 获取 Promise 解析类型
type Awaited<T> = T extends Promise<infer U> ? Awaited<U> : T;

type A1 = Awaited<Promise<string>>;           // string
type A2 = Awaited<Promise<Promise<number>>>;  // number
type A3 = Awaited<string>;                     // string

// 2. 获取数组元素类型
type ElementOf<T> = T extends (infer E)[] ? E : never;

type E1 = ElementOf<string[]>;  // string
type E2 = ElementOf<number[]>;  // number

// 3. 获取对象属性值类型
type ValueOf<T> = T extends { [key: string]: infer V } ? V : never;

type Obj = { a: string; b: number; c: boolean };
type V1 = ValueOf<Obj>; // string | number | boolean

// 4. 获取构造函数实例类型
type InstanceOf<T> = T extends new (...args: any[]) => infer I ? I : never;

class Person {
  name: string;
  constructor(name: string) {
    this.name = name;
  }
}

type I1 = InstanceOf<typeof Person>; // Person
```

### infer 在联合类型中的行为

```typescript
// infer 在联合类型中会推断为联合类型
type UnpackPromise<T> = T extends Promise<infer U> ? U : T;

type U1 = UnpackPromise<Promise<string | number>>; // string | number
type U2 = UnpackPromise<Promise<string> | Promise<number>>; // string | number

// infer 在交叉类型中会推断为交叉类型
type GetProps<T> = T extends { props: infer P } ? P : never;

type T1 = GetProps<{ props: { a: string } } & { props: { b: number } }>;
// { a: string } & { b: number }
```

## 3. 如何使用 infer 提取函数重载的返回类型？

::: details
函数重载的类型提取需要特别处理，因为重载签名有多个。

```typescript
// 函数重载
function process(value: string): string;
function process(value: number): number;
function process(value: string | number): string | number {
  if (typeof value === "string") {
    return value.toUpperCase();
  }
  return value * 2;
}

// 提取所有重载的返回类型
type OverloadReturnType<T> = T extends {
  (...args: any[]): infer R;
  (...args: any[]): infer R;
  (...args: any[]): infer R;
}
  ? R
  : never;

// 更通用的方式：提取最后一个重载的返回类型
type LastReturnType<T> = T extends {
  (...args: any[]): infer R;
  (...args: any[]): infer R;
  (...args: any[]): infer R;
}
  ? R
  : never;

// 使用示例
type Result = LastReturnType<typeof process>; // string | number
```

### 提取所有重载参数类型的联合

```typescript
// 提取所有重载的参数类型
type OverloadParameters<T> = T extends {
  (...args: infer P1): any;
  (...args: infer P2): any;
  (...args: infer P3): any;
}
  ? P1 | P2 | P3
  : never;

type Params = OverloadParameters<typeof process>;
// [value: string] | [value: number]
```

## 4. 如何使用条件类型实现类型安全的 API 响应处理？

::: details
结合条件类型和 infer，可以实现类型安全的 API 响应处理。

```typescript
// API 路由定义
type ApiRoutes = {
  "/users": {
    GET: { response: User[]; params: never };
    POST: { response: User; params: CreateUserInput };
  };
  "/users/:id": {
    GET: { response: User; params: { id: string } };
    PUT: { response: User; params: { id: string; data: Partial<User> } };
    DELETE: { response: void; params: { id: string } };
  };
};

// 类型安全的 fetch 函数
type ExtractParams<T extends string> =
  T extends `${string}:${infer Param}/${infer Rest}`
    ? { [K in Param | keyof ExtractParams<Rest>]: string }
    : T extends `${string}:${infer Param}`
    ? { [K in Param]: string }
    : {};

async function apiFetch<
  Path extends keyof ApiRoutes,
  Method extends keyof ApiRoutes[Path]
>(
  path: Path,
  method: Method,
  options?: { params?: ExtractParams<Path & string>; body?: any }
): Promise<(ApiRoutes[Path][Method] & { response: any })["response"]> {
  // 实现省略
  return {} as any;
}

// 使用示例
async function example() {
  const users = await apiFetch("/users", "GET");
  // users 的类型为 User[]

  const user = await apiFetch("/users/:id", "GET", {
    params: { id: "123" },
  });
  // user 的类型为 User

  const newUser = await apiFetch("/users", "POST", {
    body: { name: "Alice", age: 30 },
  });
  // newUser 的类型为 User
}
```

## 5. 条件类型的 distribute 陷阱是什么？如何避免？

::: details
分布式条件类型是 TypeScript 的一个特性，当条件类型作用于联合类型时，会分发到每个成员。这有时会导致意外结果。

### 问题示例

```typescript
// 预期：检查 T 是否是 string[]
// 实际：分布式行为导致意外结果
type IsStringArray<T> = T extends string[] ? true : false;

type A = IsStringArray<string[]>;           // true
type B = IsStringArray<number[]>;           // false
type C = IsStringArray<string[] | number[]>; // true | false = boolean

// 问题：C 的类型是 boolean，而不是我们期望的 boolean
```

### 解决方案：使用方括号包裹

```typescript
// 避免分布式行为
type IsStringArrayNonDist<T> = [T] extends [string[]] ? true : false;

type A2 = IsStringArrayNonDist<string[]>;           // true
type B2 = IsStringArrayNonDist<number[]>;           // false
type C2 = IsStringArrayNonDist<string[] | number[]>; // false

// 因为 [string[] | number[]] 不 extends [string[]]
```

### 实际应用：类型安全的类型检查

```typescript
// 检查类型是否为联合类型
type IsUnion<T, C = T> = T extends T
  ? [C] extends [T]
    ? false
    : true
  : never;

type A3 = IsUnion<string>;           // false
type B3 = IsUnion<string | number>;  // true

// 检查类型是否为 any
type IsAny<T> = 0 extends (1 & T) ? true : false;

type A4 = IsAny<any>;      // true
type B4 = IsAny<string>;   // false
type C4 = IsAny<unknown>;  // false
```
