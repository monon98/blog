# TypeScript 模板字面量类型面试题

## 1. 什么是模板字面量类型？

::: details
模板字面量类型是 TypeScript 4.1 引入的特性，允许你使用字符串字面量类型来创建新的字符串字面量类型。

### 基本语法

```typescript
type Name = "Alice";
type Greeting = `Hello, ${Name}`;
// "Hello, Alice"

// 联合类型
type Color = "red" | "blue";
type Size = "small" | "large";
type ColorSize = `${Color}-${Size}`;
// "red-small" | "red-large" | "blue-small" | "blue-large"
```

### 字符串操作类型

```typescript
// Uppercase
type Upper = Uppercase<"hello">;
// "HELLO"

// Lowercase
type Lower = Lowercase<"HELLO">;
// "hello"

// Capitalize
type Cap = Capitalize<"hello">;
// "Hello"

// Uncapitalize
type UnCap = Uncapitalize<"Hello">;
// "hello"
```

### 实际应用示例

```typescript
// 1. CSS 属性类型
type CSSProperty = "margin" | "padding";
type CSSDirection = "top" | "right" | "bottom" | "left";
type CSSSpacing = `${CSSProperty}-${CSSDirection}`;
// "margin-top" | "margin-right" | ... | "padding-left"

// 2. 事件名称类型
type Component = "Button" | "Input" | "Select";
type ComponentEvent = `${Lowercase<Component>}Click` | `${Lowercase<Component>}Change`;
// "buttonClick" | "buttonChange" | "inputClick" | ...

// 3. API 端点类型
type HTTPMethod = "GET" | "POST" | "PUT" | "DELETE";
type Resource = "users" | "posts" | "comments";
type APIEndpoint = `/${Resource}` | `/${Resource}/:id`;
// "/users" | "/posts" | "/comments" | "/users/:id" | ...
```

## 2. 如何使用模板字面量类型解析字符串？

::: details
模板字面量类型可以结合条件类型和 infer 来解析字符串。

```typescript
// 解析路由参数
type ExtractParams<T extends string> =
  T extends `${string}:${infer Param}/${infer Rest}`
    ? { [K in Param | keyof ExtractParams<Rest>]: string }
    : T extends `${string}:${infer Param}`
    ? { [K in Param]: string }
    : {};

type Route = "/users/:userId/posts/:postId";
type Params = ExtractParams<Route>;
// { userId: string; postId: string }

// 解析查询字符串
type ParseQueryString<T extends string> =
  T extends `${infer Key}=${infer Value}&${infer Rest}`
    ? { [K in Key]: Value } & ParseQueryString<Rest>
    : T extends `${infer Key}=${infer Value}`
    ? { [K in Key]: Value }
    : {};

type Query = "name=alice&age=30&active=true";
type QueryParams = ParseQueryString<Query>;
// { name: "alice"; age: "30"; active: "true" }
```

## 3. 如何使用模板字面量类型实现类型安全的 CSS-in-JS？

::: details
模板字面量类型可以用来定义类型安全的 CSS 属性。

```typescript
// CSS 属性类型
type CSSUnit = "px" | "em" | "rem" | "%" | "vh" | "vw";
type CSSValue = `${number}${CSSUnit}`;
type CSSProperty = "width" | "height" | "margin" | "padding";
type CSSDirection = "top" | "right" | "bottom" | "left";

// 类型安全的样式对象
type CSSStyles = {
  [K in CSSProperty]?: CSSValue | `${CSSDirection} ${CSSValue}`;
};

const styles: CSSStyles = {
  width: "100px",        // ✅
  height: "50vh",        // ✅
  margin: "10px",        // ✅
  padding: "top 5px",    // ✅
  // fontSize: "16px",   // ❌ 不是有效的 CSS 属性
};

// 驼峰命名转换
type CamelToKebab<T extends string> = T extends `${infer First}${infer Rest}`
  ? First extends Uppercase<First>
    ? `-${Lowercase<First>}${CamelToKebab<Rest>}`
    : `${First}${CamelToKebab<Rest>}`
  : T;

type KebabProperty = CamelToKebab<"backgroundColor">;
// "background-color"

type KebabStyle = {
  [K in keyof CSSStyles as CamelToKebab<string & K>]: CSSStyles[K];
};
```

## 4. 如何使用模板字面量类型实现类型安全的 SQL 查询？

::: details
模板字面量类型可以用来定义类型安全的 SQL 查询构建器。

```typescript
// SQL 关键字
type SQLKeyword = "SELECT" | "FROM" | "WHERE" | "AND" | "OR" | "ORDER BY" | "LIMIT";

// 表名和列名
type Table = "users" | "posts" | "comments";
type UserColumn = "id" | "name" | "email" | "age";
type PostColumn = "id" | "title" | "content" | "authorId";

// 类型安全的查询构建器
type SQLQuery<T extends string> = string;

function select<T extends Table>(
  table: T
): {
  from: <C extends T extends "users" ? UserColumn : PostColumn>(
    column: C
  ) => {
    where: (condition: string) => SQLQuery<string>;
  };
} {
  return {} as any;
}

// 使用示例
const query = select("users")
  .from("name")
  .where("age > 18");

// 类型安全的查询构建器（更高级）
type BuildQuery<
  Select extends string,
  From extends string,
  Where extends string = ""
> = `SELECT ${Select} FROM ${From}${Where extends "" ? "" : ` WHERE ${Where}`}`;

type Q1 = BuildQuery<"name, email", "users", "age > 18">;
// "SELECT name, email FROM users WHERE age > 18"

type Q2 = BuildQuery<"*", "posts">;
// "SELECT * FROM posts"
```

## 5. 模板字面量类型的限制是什么？

::: details
模板字面量类型有一些限制，了解这些限制可以帮助你更好地使用它。

### 限制1：不能使用运行时值

```typescript
const name = "Alice";
type Greeting = `Hello, ${name}`; // ❌ 错误：不能使用运行时值

// 正确做法
type Name = "Alice";
type Greeting2 = `Hello, ${Name}`; // ✅
```

### 限制2：不能使用非常量泛型

```typescript
type CreateRoute<T extends string> = `/api/${T}`;

// 正确：T 是字符串字面量类型
type R1 = CreateRoute<"users">; // "/api/users"

// 错误：T 不是字符串字面量类型
type R2 = CreateRoute<string>; // "/api/${string}" - 不够精确
```

### 限制3：复杂模板可能导致类型爆炸

```typescript
// 警告：这可能产生大量类型组合
type A = "a" | "b" | "c";
type B = "1" | "2" | "3";
type C = "x" | "y" | "z";

// 27 种组合
type Combinations = `${A}${B}${C}`;
// "a1x" | "a1y" | ... | "c3z"
```

### 限制4：性能考虑

```typescript
// 复杂的模板字面量类型可能影响编译性能
type DeepTemplate<T extends string> = T extends `${infer First}${infer Rest}`
  ? `${Uppercase<First>}${DeepTemplate<Rest>}`
  : T;

// 对于很长的字符串，编译时间可能较长
type Result = DeepTemplate<"hello world">; // "HELLO WORLD"
```
