# TypeScript 协变与逆变面试题

## 1. 什么是协变（Covariance）和逆变（Contravariance）？

::: details
协变和逆变是类型系统中描述类型之间关系的重要概念，特别是在处理函数类型和泛型时。

### 基本概念

```typescript
// 协变：子类型可以赋值给父类型
type Animal = { name: string };
type Dog = { name: string; breed: string };

// 协变：Dog 可以赋值给 Animal
const animal: Animal = { name: "Rex" };
const dog: Dog = { name: "Rex", breed: "Golden Retriever" };

const a: Animal = dog; // ✅ 协变，Dog 是 Animal 的子类型

// 逆变：父类型可以赋值给子类型（在函数参数中）
type Handler<T> = (data: T) => void;

// 逆变：Handler<Animal> 可以赋值给 Handler<Dog>
const animalHandler: Handler<Animal> = (animal) => console.log(animal.name);
const dogHandler: Handler<Dog> = animalHandler; // ✅ 逆变
```

### 协变的实际例子

```typescript
// 数组是协变的
type Animal = { name: string };
type Dog = { name: string; breed: string };

const dogs: Dog[] = [
  { name: "Rex", breed: "Golden Retriever" },
  { name: "Buddy", breed: "Labrador" },
];

// Dog[] 可以赋值给 Animal[]
const animals: Animal[] = dogs; // ✅ 协变，但不安全

// 协变导致的不安全性：
// animals.push() 允许推入 Animal 类型的对象（因为 Animal[] 允许 Animal）
animals.push({ name: "Tom" }); // TypeScript 类型检查通过

// 但 dogs[2] 现在是一个没有 breed 的对象
console.log(dogs[2].breed); // 运行时: undefined（而非编译时错误）
```

### 逆变的实际例子

```typescript
// 函数参数是逆变的
type Animal = { name: string };
type Dog = { name: string; breed: string };

type AnimalHandler = (animal: Animal) => void;
type DogHandler = (dog: Dog) => void;

// 逆变：AnimalHandler 可以赋值给 DogHandler
const animalHandler: AnimalHandler = (animal) => console.log(animal.name);
const dogHandler: DogHandler = animalHandler; // ✅ 逆变

// 这是安全的，因为 AnimalHandler 可以处理任何 Animal
dogHandler({ name: "Rex", breed: "Golden Retriever" }); // ✅
```

## 2. TypeScript 中的严格函数类型检查是什么？

::: details
TypeScript 有一个 `strictFunctionTypes` 选项，用于启用严格的函数类型检查。

### 严格函数类型检查的作用

```typescript
// 关闭 strictFunctionTypes
// {
//   "compilerOptions": {
//     "strictFunctionTypes": false
//   }
// }

type Animal = { name: string };
type Dog = { name: string; breed: string };

type AnimalHandler = (animal: Animal) => void;
type DogHandler = (dog: Dog) => void;

// 关闭时：允许协变（不安全）
const animalHandler: AnimalHandler = (animal) => console.log(animal.name);
const dogHandler: DogHandler = animalHandler; // ✅ 允许

// 开启时：强制逆变（安全）
// const dogHandler2: DogHandler = animalHandler; // ❌ 错误
```

### 为什么函数参数是逆变的

```typescript
// 考虑这个场景
type Animal = { name: string };
type Dog = { name: string; breed: string };

type AnimalHandler = (animal: Animal) => void;
type DogHandler = (dog: Dog) => void;

// 如果允许协变（不安全）：
const animalHandler: AnimalHandler = (animal) => {
  // 这里 animal 可能只有 name 属性
  console.log(animal.name);
  // console.log(animal.breed); // ❌ 如果 animal 只有 Animal 类型，breed 不存在
};

// 如果允许这个赋值：
const dogHandler: DogHandler = animalHandler; // ❌ 不安全

// 当我们调用 dogHandler 时：
dogHandler({ name: "Rex", breed: "Golden Retriever" }); // ✅ 看起来没问题

// 但问题是：animalHandler 可能访问了 breed 属性
// 如果 animalHandler 被设计为只处理 Animal（不保证有 breed），
// 那么它就不应该被赋值给需要 Dog 类型的 dogHandler

// 逆变的安全性：函数参数类型越宽泛（父类型），函数越通用
// 可以安全地替代需要更窄参数类型的函数
```

## 3. 泛型中的协变和逆变是什么？

::: details
泛型中的协变和逆变取决于泛型参数的使用位置。

### 协变泛型

```typescript
// 协变泛型：泛型参数只在输出位置使用
type Box<T> = {
  value: T;
};

type Animal = { name: string };
type Dog = { name: string; breed: string };

// Box<Dog> 可以赋值给 Box<Animal>
const dogBox: Box<Dog> = { value: { name: "Rex", breed: "Golden Retriever" } };
const animalBox: Box<Animal> = dogBox; // ✅ 协变

// 这是安全的，因为 Dog 有 Animal 的所有属性
```

### 逆变泛型

```typescript
// 逆变泛型：泛型参数只在输入位置使用
type Processor<T> = (input: T) => void;

type Animal = { name: string };
type Dog = { name: string; breed: string };

// Processor<Animal> 可以赋值给 Processor<Dog>
const animalProcessor: Processor<Animal> = (animal) => console.log(animal.name);
const dogProcessor: Processor<Dog> = animalProcessor; // ✅ 逆变

// 这是安全的，因为 AnimalProcessor 可以处理任何 Animal
```

### 双变泛型

```typescript
// 双变泛型：泛型参数在输入和输出位置都使用
type Container<T> = {
  value: T;
  process: (input: T) => T;
};

type Animal = { name: string };
type Dog = { name: string; breed: string };

// 双变：既允许协变也允许逆变
const animalContainer: Container<Animal> = {
  value: { name: "Rex" },
  process: (animal) => animal,
};

const dogContainer: Container<Dog> = {
  value: { name: "Rex", breed: "Golden Retriever" },
  process: (dog) => dog,
};

// 这两种赋值都不安全
// const animalContainer2: Container<Animal> = dogContainer; // ❌ 不安全
// const dogContainer2: Container<Dog> = animalContainer; // ❌ 不安全
```

## 4. 协变和逆变在实际开发中的应用是什么？

::: details
理解协变和逆变可以帮助你编写更安全、更灵活的代码。

### 事件系统

```typescript
// 逆变：事件处理器
type EventData = {
  type: string;
  timestamp: number;
};

type MouseEventData = EventData & {
  x: number;
  y: number;
};

type KeyboardEventData = EventData & {
  key: string;
};

// EventHandler<T> 中 T 用在函数参数位置，所以是逆变
type EventHandler<T extends EventData> = (event: T) => void;

const generalHandler: EventHandler<EventData> = (event) => {
  console.log(`Event: ${event.type} at ${event.timestamp}`);
};

// 逆变：EventHandler<EventData> 可以赋值给 EventHandler<MouseEventData>
// 因为 EventHandler<EventData> 可以处理任何事件类型，包括 MouseEventData
const mouseHandler: EventHandler<MouseEventData> = generalHandler; // ✅ 逆变
```

### 回调函数

```typescript
// 逆变：回调参数
type Callback<T> = (data: T) => void;

type User = { id: string; name: string };
type Admin = User & { role: "admin" };

// Callback<User> 可以赋值给 Callback<Admin>
const userCallback: Callback<User> = (user) => console.log(user.name);
const adminCallback: Callback<Admin> = userCallback; // ✅ 逆变

// 这是安全的，因为 userCallback 可以处理任何 User
function processAdmin(admin: Admin, callback: Callback<Admin>) {
  callback(admin);
}

processAdmin(
  { id: "1", name: "Alice", role: "admin" },
  adminCallback // ✅ 安全
);
```

### 数组和映射

```typescript
// 协变：数组
type Animal = { name: string };
type Dog = { name: string; breed: string };

const dogs: Dog[] = [
  { name: "Rex", breed: "Golden Retriever" },
  { name: "Buddy", breed: "Labrador" },
];

// Dog[] 可以赋值给 Animal[]（协变）
const animals: Animal[] = dogs;

// 但是要注意：协变是不安全的
animals.push({ name: "Tom" }); // TypeScript 允许，因为 Animal[] 允许 Animal
// 但 dogs[2] 现在是一个没有 breed 的对象

// 解决方案：使用只读数组
const readonlyDogs: readonly Dog[] = dogs;
const readonlyAnimals: readonly Animal[] = readonlyDogs; // ✅ 安全，无法 push
```

## 5. 如何理解 TypeScript 中的类型兼容性？

::: details
TypeScript 的类型兼容性是基于结构类型系统的，它决定了一个类型是否可以赋值给另一个类型。

### 结构类型系统

```typescript
// 结构类型：基于属性而不是名称
type Animal = { name: string };
type Dog = { name: string; breed: string };

// Dog 有 Animal 的所有属性
const dog: Dog = { name: "Rex", breed: "Golden Retriever" };
const animal: Animal = dog; // ✅ 结构兼容

// Animal 缺少 breed 属性
const animal2: Animal = { name: "Tom" };
// const dog2: Dog = animal2; // ❌ 缺少 breed 属性
```

### 类型兼容性的规则

```typescript
// 1. 基本类型
let x: number = 10;
let y: any = x; // ✅ any 兼容任何类型

// 2. 对象类型
type A = { a: string; b: number };
type B = { a: string; b: number; c: boolean };

const b: B = { a: "hello", b: 123, c: true };
const a: A = b; // ✅ B 有 A 的所有属性

// 3. 函数类型
type Fn1 = (x: number) => void;
type Fn2 = (x: number, y?: string) => void;

const fn2: Fn2 = (x, y) => console.log(x, y);
const fn1: Fn1 = fn2; // ✅ Fn2 有可选参数

// 4. 泛型类型
type Box<T> = { value: T };
type Animal = { name: string };
type Dog = { name: string; breed: string };

const dogBox: Box<Dog> = { value: { name: "Rex", breed: "Golden Retriever" } };
const animalBox: Box<Animal> = dogBox; // ✅ 协变
```

### 类型兼容性和协变/逆变

```typescript
// 协变：子类型可以赋值给父类型
type Animal = { name: string };
type Dog = { name: string; breed: string };

const dog: Dog = { name: "Rex", breed: "Golden Retriever" };
const animal: Animal = dog; // ✅ 协变

// 逆变：函数参数是逆变的
type Handler<T> = (data: T) => void;

const animalHandler: Handler<Animal> = (animal) => console.log(animal.name);
const dogHandler: Handler<Dog> = animalHandler; // ✅ 逆变

// 注意：数组是协变的，但函数参数是逆变的
const dogs: Dog[] = [{ name: "Rex", breed: "Golden Retriever" }];
const animals: Animal[] = dogs; // ✅ 协变

// 但是函数参数是逆变的
function processDogs(handler: Handler<Dog>) {
  dogs.forEach(handler);
}

function processAnimals(handler: Handler<Animal>) {
  animals.forEach(handler);
}

// processDogs(processAnimals); // ❌ 不安全
// processAnimals(processDogs); // ✅ 安全
```
