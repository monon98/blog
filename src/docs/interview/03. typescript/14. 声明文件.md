# TypeScript 声明文件面试题

## 1. 什么是声明文件（.d.ts）？

::: details
声明文件是 TypeScript 中用于描述 JavaScript 库类型的文件。它不包含任何实现代码，只包含类型定义。

### 声明文件的作用

```typescript
// 1. 为 JavaScript 库提供类型定义
// lodash.d.ts
declare module "lodash" {
  export function debounce<T extends (...args: any[]) => any>(
    func: T,
    wait?: number
  ): T;
  
  export function throttle<T extends (...args: any[]) => any>(
    func: T,
    wait?: number
  ): T;
}

// 2. 为全局变量提供类型定义
// global.d.ts
declare const API_URL: string;
declare function fetchData(url: string): Promise<any>;

// 3. 为模块扩展提供类型定义
// extend-module.d.ts
declare module "express" {
  interface Request {
    user?: {
      id: string;
      name: string;
    };
  }
}
```

### 声明文件的基本语法

```typescript
// 1. 声明变量
declare const myVar: string;
declare let myLet: number;
declare var myVar2: boolean;

// 2. 声明函数
declare function myFunc(arg: string): number;
declare function myFunc(arg: number): string;

// 3. 声明类
declare class MyClass {
  constructor(arg: string);
  method(): void;
  static staticMethod(): void;
}

// 4. 声明接口
interface MyInterface {
  prop: string;
  method(): void;
}

// 5. 声明类型
type MyType = string | number;

// 6. 声明模块
declare module "my-module" {
  export function myExport(): void;
  export default function myDefault(): void;
}

// 7. 声明命名空间
declare namespace MyNamespace {
  function helper(): void;
  interface Config {
    debug: boolean;
  }
}
```

## 2. 如何编写声明文件？

::: details
编写声明文件需要了解 TypeScript 的类型系统和声明文件的语法。

### 基本结构

```typescript
// types/my-lib/index.d.ts

// 1. 声明模块
declare module "my-lib" {
  // 导出接口
  export interface Options {
    timeout?: number;
    retries?: number;
  }

  // 导出类
  export class Client {
    constructor(options?: Options);
    connect(): Promise<void>;
    disconnect(): void;
    send(data: string): Promise<string>;
  }

  // 导出函数
  export function createClient(options?: Options): Client;

  // 导出常量
  export const VERSION: string;
}

// 2. 声明全局类型
interface GlobalConfig {
  debug: boolean;
  apiUrl: string;
}

declare const config: GlobalConfig;

// 3. 扩展已有模块
declare module "express" {
  interface Request {
    user?: {
      id: string;
      name: string;
    };
  }
}
```

### 处理复杂的 JavaScript 库

```typescript
// types/lodash/index.d.ts
declare module "lodash" {
  // 函数重载
  export function map<T, U>(array: T[], iteratee: (value: T) => U): U[];
  export function map<T>(array: T[]): T[];
  export function map<T, U>(object: Record<string, T>, iteratee: (value: T) => U): U[];

  // 泛型函数
  export function filter<T>(array: T[], predicate: (value: T) => boolean): T[];
  
  // 链式调用
  export function chain<T>(value: T): Chain<T>;
  
  interface Chain<T> {
    map<U>(iteratee: (value: T) => U): Chain<U>;
    filter(predicate: (value: T) => boolean): Chain<T>;
    value(): T[];
  }

  // 工具函数
  export function debounce<T extends (...args: any[]) => any>(
    func: T,
    wait?: number
  ): T;

  export function throttle<T extends (...args: any[]) => any>(
    func: T,
    wait?: number
  ): T;
}
```

## 3. 什么是 .d.ts 文件的查找规则？

::: details
TypeScript 有一套规则来查找和加载声明文件。

### 查找规则

```typescript
// 1. node_modules/@types
// TypeScript 会自动查找 node_modules/@types 目录下的声明文件
// 例如：node_modules/@types/lodash/index.d.ts

// 2. tsconfig.json 中的 paths
// {
//   "compilerOptions": {
//     "paths": {
//       "my-lib": ["./types/my-lib"]
//     }
//   }
// }

// 3. typeRoots 配置
// {
//   "compilerOptions": {
//     "typeRoots": ["./types", "./node_modules/@types"]
//   }
// }

// 4. types 配置
// {
//   "compilerOptions": {
//     "types": ["node", "jest"]
//   }
// }
```

### 模块解析

```typescript
// 1. 相对路径
/// <reference path="./my-types.d.ts" />

// 2. 非相对路径
/// <reference types="node" />

// 3. 在模块中引用
import { something } from "my-lib";
// TypeScript 会查找 my-lib 的声明文件

// 4. 全局声明
// 在声明文件中使用 declare global
declare global {
  interface Window {
    myCustomProperty: string;
  }
}
```

## 4. 如何为没有类型的 JavaScript 库编写声明文件？

::: details
为没有类型的 JavaScript 库编写声明文件是 TypeScript 开发中的常见任务。

### 步骤1：分析库的 API

```javascript
// 假设有一个名为 "my-lib" 的 JavaScript 库
// 它的 API 如下：
// - createClient(options) - 创建客户端
// - client.connect() - 连接
// - client.send(data) - 发送数据
// - client.disconnect() - 断开连接
```

### 步骤2：编写声明文件

```typescript
// types/my-lib/index.d.ts
declare module "my-lib" {
  export interface ClientOptions {
    timeout?: number;
    retries?: number;
    debug?: boolean;
  }

  export interface Client {
    connect(): Promise<void>;
    send(data: string): Promise<string>;
    disconnect(): void;
  }

  export function createClient(options?: ClientOptions): Client;
  export const VERSION: string;
}
```

### 步骤3：使用声明文件

```typescript
// 在项目中使用
import { createClient, Client } from "my-lib";

const client = createClient({
  timeout: 5000,
  debug: true,
});

async function main() {
  await client.connect();
  const response = await client.send("hello");
  console.log(response);
  await client.disconnect();
}
```

### 步骤4：发布声明文件

```json
// package.json
{
  "name": "my-lib",
  "types": "types/index.d.ts",
  "files": ["types"]
}
```

## 5. 声明文件中的 declare 和 module 的区别是什么？

::: details
`declare` 和 `module` 是声明文件中常用的两个关键字，它们有不同的用途。

### declare 关键字

```typescript
// declare 用于声明全局变量、函数、类等
declare const API_URL: string;
declare function fetchData(url: string): Promise<any>;
declare class MyClass {
  constructor(arg: string);
  method(): void;
}

// declare global 用于扩展全局类型
declare global {
  interface Window {
    myCustomProperty: string;
  }
}

// declare module 用于声明模块
declare module "my-lib" {
  export function myExport(): void;
}
```

### module 关键字

```typescript
// module 用于定义模块的类型
declare module "my-lib" {
  // 这里的类型定义只在 my-lib 模块内有效
  export interface Options {
    timeout?: number;
  }

  export function createClient(options?: Options): void;
}

// 嵌套模块
declare module "my-lib" {
  namespace utils {
    function formatDate(date: Date): string;
  }
}
```

### 主要区别

```typescript
// 1. declare 用于声明
declare const myVar: string; // 声明一个全局变量

// 2. module 用于定义模块
declare module "my-lib" {
  export const myVar: string; // 定义 my-lib 模块中的 myVar
}

// 3. declare module 组合使用
declare module "my-lib" {
  // 声明 my-lib 模块的类型
  export function myFunc(): void;
}

// 4. 扩展已有模块
declare module "express" {
  interface Request {
    user?: any;
  }
}
```
