# TypeScript 枚举深入面试题

## 1. TypeScript 中有哪些类型的枚举？

::: details
TypeScript 支持多种类型的枚举，包括数字枚举、字符串枚举、异构枚举和常量枚举。

### 数字枚举

```typescript
// 数字枚举：默认从 0 开始
enum Direction {
  Up,      // 0
  Down,    // 1
  Left,    // 2
  Right,   // 3
}

// 指定初始值
enum Status {
  Active = 1,
  Inactive,  // 2
  Deleted,   // 3
}

// 使用
const dir: Direction = Direction.Up;
console.log(dir); // 0
console.log(Direction[0]); // "Up"（反向映射）
```

### 字符串枚举

```typescript
// 字符串枚举：每个成员必须初始化
enum Color {
  Red = "RED",
  Green = "GREEN",
  Blue = "BLUE",
}

// 使用
const color: Color = Color.Red;
console.log(color); // "RED"

// 注意：字符串枚举没有反向映射
// console.log(Color["RED"]); // undefined
```

### 异构枚举

```typescript
// 异构枚举：混合数字和字符串
enum Mixed {
  No = 0,
  Yes = "YES",
}

// 使用
const answer: Mixed = Mixed.Yes;
console.log(answer); // "YES"
```

### 常量枚举

```typescript
// 常量枚举：编译时会被完全移除
const enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT",
}

// 使用
const dir: Direction = Direction.Up;
console.log(dir); // "UP"

// 编译后会被替换为
// const dir = "UP";
```

## 2. 枚举的反向映射是什么？如何使用？

::: details
反向映射允许你通过值来获取枚举成员的名称。

### 数字枚举的反向映射

```typescript
enum Direction {
  Up,    // 0
  Down,  // 1
  Left,  // 2
  Right, // 3
}

// 正向映射：名称 → 值
console.log(Direction.Up); // 0
console.log(Direction.Down); // 1

// 反向映射：值 → 名称
console.log(Direction[0]); // "Up"
console.log(Direction[1]); // "Down"

// 遍历枚举
Object.entries(Direction).forEach(([key, value]) => {
  console.log(`${key}: ${value}`);
});
// 输出：
// 0: Up
// 1: Down
// 2: Left
// 3: Right
// Up: 0
// Down: 1
// Left: 2
// Right: 3
```

### 字符串枚举没有反向映射

```typescript
enum Color {
  Red = "RED",
  Green = "GREEN",
  Blue = "BLUE",
}

// 正向映射：名称 → 值
console.log(Color.Red); // "RED"

// 字符串枚举没有反向映射
console.log(Color["RED"]); // undefined

// 遍历枚举
Object.entries(Color).forEach(([key, value]) => {
  console.log(`${key}: ${value}`);
});
// 输出：
// Red: RED
// Green: GREEN
// Blue: BLUE
```

### 实际应用

```typescript
// 1. 获取枚举值的名称
function getEnumName<T extends Record<string, any>>(
  enumObj: T,
  value: T[keyof T]
): string | undefined {
  return enumObj[value] as string;
}

enum Status {
  Active = 1,
  Inactive = 2,
  Deleted = 3,
}

console.log(getEnumName(Status, 1)); // "Active"
console.log(getEnumName(Status, 2)); // "Inactive"

// 2. 将数字转换为枚举
function numberToEnum<T extends Record<string, any>>(
  enumObj: T,
  value: number
): T[keyof T] | undefined {
  return enumObj[value] as T[keyof T] | undefined;
}

console.log(numberToEnum(Status, 1)); // Status.Active
console.log(numberToEnum(Status, 4)); // undefined
```

## 3. const enum 和普通 enum 的区别是什么？

::: details
const enum 和普通 enum 在编译行为和使用方式上有重要区别。

### 编译行为

```typescript
// 普通 enum：编译后保留
enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT",
}

const dir = Direction.Up;

// 编译后：
// var Direction;
// (function (Direction) {
//     Direction["Up"] = "UP";
//     Direction["Down"] = "DOWN";
//     Direction["Left"] = "LEFT";
//     Direction["Right"] = "RIGHT";
// })(Direction || (Direction = {}));
// var dir = Direction.Up;
```

### const enum 的编译行为

```typescript
// const enum：编译时完全移除
const enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT",
}

const dir = Direction.Up;

// 编译后：
// const dir = "UP";
```

### 使用限制

```typescript
// 普通 enum 的使用
enum Direction {
  Up,
  Down,
  Left,
  Right,
}

// 1. 作为类型
const dir: Direction = Direction.Up;

// 2. 作为值
console.log(Direction.Up);

// 3. 反向映射
console.log(Direction[0]); // "Up"

// 4. 动态访问
const key = "Up";
console.log(Direction[key as keyof typeof Direction]); // 0
```

### const enum 的使用限制

```typescript
// const enum 的限制
const enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT",
}

// 1. 作为类型 ✅
const dir: Direction = Direction.Up;

// 2. 作为值 ✅（编译时替换）
console.log(Direction.Up); // "UP"

// 3. 反向映射 ❌
// console.log(Direction[0]); // 错误

// 4. 动态访问 ❌
// const key = "Up";
// console.log(Direction[key]); // 错误

// 5. 不能在运行时遍历 ❌
// console.log(Direction); // 错误
```

### 选择建议

```typescript
// 1. 使用普通 enum 当需要：
// - 反向映射
// - 运行时遍历
// - 动态访问

// 2. 使用 const enum 当需要：
// - 最小的运行时开销
// - 编译时替换
// - 不需要反向映射
```

## 4. 枚举和联合类型的区别是什么？

::: details
枚举和联合类型都可以用来表示一组命名的值，但它们有不同的特点和使用场景。

### 联合类型

```typescript
// 联合类型：更轻量级
type Direction = "up" | "down" | "left" | "right";
type Status = "active" | "inactive" | "deleted";

// 使用
const dir: Direction = "up";
const status: Status = "active";

// 优点：
// 1. 更轻量级，没有运行时开销
// 2. 更灵活，可以用于任何类型
// 3. 更容易与字符串操作配合

// 缺点：
// 1. 没有反向映射
// 2. 不能遍历
// 3. 不能作为命名空间使用
```

### 枚举

```typescript
// 枚举：更强大
enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT",
}

// 使用
const dir: Direction = Direction.Up;

// 优点：
// 1. 有反向映射
// 2. 可以遍历
// 3. 可以作为命名空间使用
// 4. 有更好的 IDE 支持

// 缺点：
// 1. 有运行时开销
// 2. 编译后代码更多
// 3. 不够灵活
```

### 实际应用对比

```typescript
// 1. 联合类型更适合简单场景
type Color = "red" | "green" | "blue";

function getColor(color: Color): string {
  return color;
}

getColor("red"); // ✅
getColor("blue"); // ✅

// 2. 枚举更适合复杂场景
enum HTTPStatus {
  OK = 200,
  NotFound = 404,
  ServerError = 500,
}

function getStatusText(status: HTTPStatus): string {
  switch (status) {
    case HTTPStatus.OK:
      return "OK";
    case HTTPStatus.NotFound:
      return "Not Found";
    case HTTPStatus.ServerError:
      return "Server Error";
    default:
      return "Unknown";
  }
}

getStatusText(HTTPStatus.OK); // "OK"
```

### 选择建议

```typescript
// 1. 使用联合类型当：
// - 值是简单的字符串或数字
// - 不需要反向映射
// - 不需要遍历
// - 追求最小的运行时开销

// 2. 使用枚举当：
// - 需要反向映射
// - 需要遍历
// - 需要作为命名空间使用
// - 需要更好的 IDE 支持
```

## 5. 如何实现一个类型安全的枚举？

::: details
TypeScript 的枚举有一些类型安全问题，可以通过一些技巧来解决。

### 问题1：数字枚举的类型不安全

```typescript
// 数字枚举的问题
enum Status {
  Active = 1,
  Inactive = 2,
  Deleted = 3,
}

// 任何数字都可以赋值给 Status 类型
const status: Status = 42; // ✅ 类型检查通过，但运行时有问题
console.log(Status[42]); // undefined

// 解决方案1：使用字符串枚举
enum SafeStatus {
  Active = "ACTIVE",
  Inactive = "INACTIVE",
  Deleted = "DELETED",
}

const safeStatus: SafeStatus = SafeStatus.Active; // ✅
// const unsafeStatus: SafeStatus = "UNKNOWN"; // ❌ 类型错误

// 解决方案2：使用联合类型
type SafeStatus2 = "active" | "inactive" | "deleted";
const safeStatus2: SafeStatus2 = "active"; // ✅
// const unsafeStatus2: SafeStatus2 = "unknown"; // ❌ 类型错误
```

### 问题2：枚举的运行时行为

```typescript
// 枚举的运行时行为
enum Direction {
  Up,
  Down,
  Left,
  Right,
}

// 枚举在运行时是一个对象
console.log(Direction); // { 0: "Up", 1: "Down", 2: "Left", 3: "Right", Up: 0, Down: 1, Left: 2, Right: 3 }

// 解决方案：使用 const enum
const enum SafeDirection {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT",
}

// const enum 在运行时不存在
// console.log(SafeDirection); // 编译错误
```

### 问题3：枚举的遍历

```typescript
// 枚举的遍历问题
enum Direction {
  Up,
  Down,
  Left,
  Right,
}

// 遍历枚举会得到双向映射
Object.entries(Direction).forEach(([key, value]) => {
  console.log(`${key}: ${value}`);
});
// 输出：
// 0: Up
// 1: Down
// 2: Left
// 3: Right
// Up: 0
// Down: 1
// Left: 2
// Right: 3

// 解决方案：只遍历字符串值
function getEnumValues<T extends Record<string, any>>(
  enumObj: T
): T[keyof T][] {
  return Object.values(enumObj).filter(
    (value) => typeof value === "string"
  ) as T[keyof T][];
}

console.log(getEnumValues(Direction)); // ["Up", "Down", "Left", "Right"]
```

### 最佳实践

```typescript
// 1. 优先使用联合类型
type Direction = "up" | "down" | "left" | "right";

// 2. 如果需要枚举，使用字符串枚举
enum DirectionEnum {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT",
}

// 3. 如果需要最小的运行时开销，使用 const enum
const enum SafeDirection {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT",
}

// 4. 使用类型守卫确保类型安全
function isDirection(value: string): value is Direction {
  return ["up", "down", "left", "right"].includes(value);
}
```
