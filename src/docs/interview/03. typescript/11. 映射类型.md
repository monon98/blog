# TypeScript 映射类型面试题

## 1. 什么是映射类型？如何使用？

::: details
映射类型允许你基于已有类型创建新类型，通过遍历类型的键来生成新的属性。

### 基本语法

```typescript
type MapType<T> = {
  [K in keyof T]: T[K];
};

// 使用示例
interface User {
  name: string;
  age: number;
}

type ReadonlyUser = {
  readonly [K in keyof User]: User[K];
};
// 等同于：
// {
//   readonly name: string;
//   readonly age: number;
// }
```

### 常用映射修饰符

```typescript
// readonly 修饰符
type Mutable<T> = {
  -readonly [K in keyof T]: T[K];
};

// ? 修饰符
type Concrete<T> = {
  [K in keyof T]-?: T[K];
};

// 组合使用
type MutableOptional<T> = {
  -readonly [K in keyof T]?: T[K];
};
```

### 实际应用示例

```typescript
// 1. 将所有属性变为可选
type Partial<T> = {
  [K in keyof T]?: T[K];
};

// 2. 将所有属性变为必选
type Required<T> = {
  [K in keyof T]-?: T[K];
};

// 3. 将所有属性变为只读
type Readonly<T> = {
  readonly [K in keyof T]: T[K];
};

// 4. 将所有属性变为可写
type Mutable<T> = {
  -readonly [K in keyof T]: T[K];
};
```

## 2. 如何使用映射类型实现属性名转换？

::: details
映射类型可以结合模板字面量类型实现属性名转换。

```typescript
// 将属性名转换为 getter/setter 格式
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

type Setters<T> = {
  [K in keyof T as `set${Capitalize<string & K>}`]: (value: T[K]) => void;
};

interface User {
  name: string;
  age: number;
}

type UserGetters = Getters<User>;
// {
//   getName: () => string;
//   getAge: () => number;
// }

type UserSetters = Setters<User>;
// {
//   setName: (value: string) => void;
//   setAge: (value: number) => void;
// }

// 过滤特定类型的属性
type StringKeys<T> = {
  [K in keyof T as T[K] extends string ? K : never]: T[K];
};

type UserStrings = StringKeys<User>;
// { name: string }

// 过滤特定属性
type OmitByType<T, ValueType> = {
  [K in keyof T as T[K] extends ValueType ? never : K]: T[K];
};

type UserWithoutNumbers = OmitByType<User, number>;
// { name: string }
```

## 3. 如何使用映射类型实现深层属性修改？

::: details
结合递归和映射类型，可以实现深层属性的修改。

```typescript
// 深层只读
type DeepReadonly<T> = {
  readonly [K in keyof T]: T[K] extends object ? DeepReadonly<T[K]> : T[K];
};

// 深层可选
type DeepPartial<T> = {
  [K in keyof T]?: T[K] extends object ? DeepPartial<T[K]> : T[K];
};

// 深层必需
type DeepRequired<T> = {
  [K in keyof T]-?: T[K] extends object ? DeepRequired<T[K]> : T[K];
};

// 使用示例
interface Config {
  database: {
    host: string;
    port: number;
    credentials: {
      username: string;
      password: string;
    };
  };
}

type ReadonlyConfig = DeepReadonly<Config>;
// 所有属性及其嵌套属性都变为只读

type PartialConfig = DeepPartial<Config>;
// 所有属性及其嵌套属性都变为可选
```

## 4. 如何使用映射类型实现类型安全的事件系统？

::: details
映射类型可以用来定义类型安全的事件处理器。

```typescript
// 事件映射
type EventMap = {
  userCreated: { id: string; name: string };
  userDeleted: { id: string };
  settingsChanged: { key: string; value: any };
};

// 类型安全的事件处理器
type EventHandler<T> = (data: T) => void;

type EventHandlers<Events extends Record<string, any>> = {
  [K in keyof Events]: EventHandler<Events[K]>;
};

// 使用示例
const handlers: EventHandlers<EventMap> = {
  userCreated: (data) => {
    console.log(`User created: ${data.name}`);
  },
  userDeleted: (data) => {
    console.log(`User deleted: ${data.id}`);
  },
  settingsChanged: (data) => {
    console.log(`Setting ${data.key} changed`);
  },
};

// 类型安全的事件发射器
class TypedEmitter<Events extends Record<string, any>> {
  private handlers: Partial<EventHandlers<Events>> = {};

  on<K extends keyof Events>(event: K, handler: EventHandler<Events[K]>) {
    this.handlers[event] = handler;
  }

  emit<K extends keyof Events>(event: K, data: Events[K]) {
    this.handlers[event]?.(data);
  }
}

const emitter = new TypedEmitter<EventMap>();
emitter.on("userCreated", (data) => console.log(data.name)); // ✅
// emitter.emit("userCreated", { id: "1" }); // ❌ 缺少 name
```

## 5. 映射类型中的键重映射（as）有什么用？

::: details
键重映射允许你在映射类型中修改属性名，这是 TypeScript 4.1 引入的特性。

```typescript
// 基本语法
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

// 过滤属性
type PickByType<T, ValueType> = {
  [K in keyof T as T[K] extends ValueType ? K : never]: T[K];
};

interface User {
  name: string;
  age: number;
  email: string;
  isActive: boolean;
}

type StringProperties = PickByType<User, string>;
// { name: string; email: string }

// 移除特定属性
type RemoveId<T> = {
  [K in keyof T as K extends "id" ? never : K]: T[K];
};

// 重命名属性
type RenameId<T> = {
  [K in keyof T as K extends "id" ? "key" : K]: T[K];
};

// 条件键重映射
type EventHandlers<T> = {
  [K in keyof T as K extends `${string}Event` ? K : never]: (data: T[K]) => void;
};

interface AppEvents {
  clickEvent: { x: number; y: number };
  hoverEvent: { element: string };
  scrollEvent: { top: number };
  name: string; // 不会被包含，因为不以 "Event" 结尾
}

type Handlers = EventHandlers<AppEvents>;
// {
//   clickEvent: (data: { x: number; y: number }) => void;
//   hoverEvent: (data: { element: string }) => void;
//   scrollEvent: (data: { top: number }) => void;
// }
```
