# 事件处理

## 1. 基本事件

::: details
Canvas 2D 支持各种鼠标和触摸事件。

### 鼠标事件

```javascript
// 点击事件
canvas.addEventListener('click', (e) => {
  const rect = canvas.getBoundingClientRect();
  const x = e.clientX - rect.left;
  const y = e.clientY - rect.top;
  console.log(`点击位置: ${x}, ${y}`);
});

// 移动事件
canvas.addEventListener('mousemove', (e) => {
  const rect = canvas.getBoundingClientRect();
  const x = e.clientX - rect.left;
  const y = e.clientY - rect.top;
});

// 按下事件
canvas.addEventListener('mousedown', (e) => {
  console.log('鼠标按下');
});

// 释放事件
canvas.addEventListener('mouseup', (e) => {
  console.log('鼠标释放');
});
```

### 触摸事件

```javascript
// 触摸开始
canvas.addEventListener('touchstart', (e) => {
  e.preventDefault();
  const touch = e.touches[0];
  const rect = canvas.getBoundingClientRect();
  const x = touch.clientX - rect.left;
  const y = touch.clientY - rect.top;
});

// 触摸移动
canvas.addEventListener('touchmove', (e) => {
  e.preventDefault();
  const touch = e.touches[0];
  const rect = canvas.getBoundingClientRect();
  const x = touch.clientX - rect.left;
  const y = touch.clientY - rect.top;
});

// 触摸结束
canvas.addEventListener('touchend', (e) => {
  e.preventDefault();
});
```

### 总结

Canvas 2D 支持鼠标和触摸事件，可以实现各种交互效果。

:::

## 2. 碰撞检测

::: details
碰撞检测是 Canvas 2D 游戏和交互应用的核心。

### 矩形碰撞

```javascript
function rectCollision(rect1, rect2) {
  return rect1.x < rect2.x + rect2.width &&
         rect1.x + rect1.width > rect2.x &&
         rect1.y < rect2.y + rect2.height &&
         rect1.y + rect1.height > rect2.y;
}
```

### 圆形碰撞

```javascript
function circleCollision(circle1, circle2) {
  const dx = circle1.x - circle2.x;
  const dy = circle1.y - circle2.y;
  const distance = Math.sqrt(dx * dx + dy * dy);
  
  return distance < circle1.radius + circle2.radius;
}
```

### 点击检测

```javascript
function isPointInRect(point, rect) {
  return point.x >= rect.x &&
         point.x <= rect.x + rect.width &&
         point.y >= rect.y &&
         point.y <= rect.y + rect.height;
}

function isPointInCircle(point, circle) {
  const dx = point.x - circle.x;
  const dy = point.y - circle.y;
  return dx * dx + dy * dy <= circle.radius * circle.radius;
}
```

### 总结

碰撞检测是 Canvas 2D 交互应用的核心，包括矩形碰撞、圆形碰撞、点击检测等。

:::

## 3. 拖拽交互

::: details
拖拽是常见的 Canvas 2D 交互方式。

### 基本拖拽

```javascript
let isDragging = false;
let dragOffset = { x: 0, y: 0 };

canvas.addEventListener('mousedown', (e) => {
  const rect = canvas.getBoundingClientRect();
  const x = e.clientX - rect.left;
  const y = e.clientY - rect.top;
  
  if (isPointInRect({ x, y }, rect1)) {
    isDragging = true;
    dragOffset.x = x - rect1.x;
    dragOffset.y = y - rect1.y;
  }
});

canvas.addEventListener('mousemove', (e) => {
  if (isDragging) {
    const rect = canvas.getBoundingClientRect();
    const x = e.clientX - rect.left;
    const y = e.clientY - rect.top;
    
    rect1.x = x - dragOffset.x;
    rect1.y = y - dragOffset.y;
  }
});

canvas.addEventListener('mouseup', () => {
  isDragging = false;
});
```

### 拖拽多个对象

```javascript
let selectedObject = null;

canvas.addEventListener('mousedown', (e) => {
  const rect = canvas.getBoundingClientRect();
  const x = e.clientX - rect.left;
  const y = e.clientY - rect.top;
  
  // 从后往前检测（后绘制的在上面）
  for (let i = objects.length - 1; i >= 0; i--) {
    if (isPointInRect({ x, y }, objects[i])) {
      selectedObject = objects[i];
      dragOffset.x = x - objects[i].x;
      dragOffset.y = y - objects[i].y;
      break;
    }
  }
});

canvas.addEventListener('mousemove', (e) => {
  if (selectedObject) {
    const rect = canvas.getBoundingClientRect();
    const x = e.clientX - rect.left;
    const y = e.clientY - rect.top;
    
    selectedObject.x = x - dragOffset.x;
    selectedObject.y = y - dragOffset.y;
  }
});

canvas.addEventListener('mouseup', () => {
  selectedObject = null;
});
```

### 总结

拖拽交互是 Canvas 2D 的常见交互方式，可以实现对象的移动和操作。

## 4. 键盘事件

::: details
Canvas 2D 应用也支持键盘事件。

### 基本键盘事件

```javascript
// 按下按键
window.addEventListener('keydown', (e) => {
  console.log(`按下: ${e.key}`);
  
  switch (e.key) {
    case 'ArrowUp':
      y -= 10;
      break;
    case 'ArrowDown':
      y += 10;
      break;
    case 'ArrowLeft':
      x -= 10;
      break;
    case 'ArrowRight':
      x += 10;
      break;
  }
});

// 释放按键
window.addEventListener('keyup', (e) => {
  console.log(`释放: ${e.key}`);
});
```

### 按键状态跟踪

```javascript
const keys = {};

window.addEventListener('keydown', (e) => {
  keys[e.key] = true;
});

window.addEventListener('keyup', (e) => {
  keys[e.key] = false;
});

// 在动画循环中检查按键状态
function animate() {
  if (keys['ArrowUp']) y -= 5;
  if (keys['ArrowDown']) y += 5;
  if (keys['ArrowLeft']) x -= 5;
  if (keys['ArrowRight']) x += 5;
  
  requestAnimationFrame(animate);
}
```

### 总结

键盘事件可以实现复杂的交互控制，常用于游戏开发。

:::
