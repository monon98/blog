# 2D 绑定

## 1. 基本图形

::: details
Canvas 2D 可以绘制各种基本图形。

### 线条

```javascript
// 绘制线条
ctx.beginPath();
ctx.moveTo(0, 0);
ctx.lineTo(100, 100);
ctx.strokeStyle = 'black';
ctx.lineWidth = 2;
ctx.stroke();
```

### 圆形

```javascript
// 绘制圆形
ctx.beginPath();
ctx.arc(100, 100, 50, 0, Math.PI * 2);
ctx.fillStyle = 'red';
ctx.fill();

// 绘制弧线
ctx.beginPath();
ctx.arc(100, 100, 50, 0, Math.PI);
ctx.stroke();
```

### 矩形

```javascript
// 圆角矩形（现代浏览器内置方法）
ctx.beginPath();
ctx.roundRect(10, 10, 100, 50, 10);
ctx.fill();

// 圆角矩形（兼容旧浏览器的 polyfill）
if (!ctx.roundRect) {
  CanvasRenderingContext2D.prototype.roundRect = function(x, y, w, h, r) {
    this.beginPath();
    this.moveTo(x + r, y);
    this.lineTo(x + w - r, y);
    this.arcTo(x + w, y, x + w, y + r, r);
    this.lineTo(x + w, y + h - r);
    this.arcTo(x + w, y + h, x + w - r, y + h, r);
    this.lineTo(x + r, y + h);
    this.arcTo(x, y + h, x, y + h - r, r);
    this.lineTo(x, y + r);
    this.arcTo(x, y, x + r, y, r);
    this.closePath();
    return this;
  };
}

ctx.beginPath();
ctx.roundRect(10, 10, 100, 50, 10);
ctx.fill();
```

### 多边形

```javascript
// 绘制多边形
function drawPolygon(ctx, x, y, radius, sides) {
  ctx.beginPath();
  
  for (let i = 0; i < sides; i++) {
    const angle = (i * 2 * Math.PI) / sides - Math.PI / 2;
    const px = x + radius * Math.cos(angle);
    const py = y + radius * Math.sin(angle);
    
    if (i === 0) {
      ctx.moveTo(px, py);
    } else {
      ctx.lineTo(px, py);
    }
  }
  
  ctx.closePath();
}

drawPolygon(ctx, 100, 100, 50, 6);
ctx.fill();
```

### 总结

Canvas 2D 提供了丰富的基本图形 API，可以绘制各种形状。

:::

## 2. 渐变与图案

::: details
Canvas 2D 支持渐变和图案填充。

### 线性渐变

```javascript
// 创建线性渐变
const gradient = ctx.createLinearGradient(x0, y0, x1, y1);

// 添加颜色停止
gradient.addColorStop(0, 'red');
gradient.addColorStop(0.5, 'yellow');
gradient.addColorStop(1, 'green');

// 使用渐变
ctx.fillStyle = gradient;
ctx.fillRect(10, 10, 200, 100);
```

### 径向渐变

```javascript
// 创建径向渐变
const gradient = ctx.createRadialGradient(
  x0, y0, r0,  // 内圆
  x1, y1, r1   // 外圆
);

gradient.addColorStop(0, 'white');
gradient.addColorStop(1, 'black');

ctx.fillStyle = gradient;
ctx.fillRect(0, 0, canvas.width, canvas.height);
```

### 图案

```javascript
// 创建图案
const img = new Image();
img.src = 'pattern.png';
img.onload = () => {
  const pattern = ctx.createPattern(img, 'repeat');
  
  ctx.fillStyle = pattern;
  ctx.fillRect(0, 0, canvas.width, canvas.height);
};
```

### 阴影

```javascript
// 设置阴影
ctx.shadowColor = 'rgba(0, 0, 0, 0.5)';
ctx.shadowBlur = 10;
ctx.shadowOffsetX = 5;
ctx.shadowOffsetY = 5;

// 绘制带阴影的图形
ctx.fillStyle = 'red';
ctx.fillRect(10, 10, 100, 50);
```

### 总结

渐变和图案可以创建丰富的视觉效果，阴影可以增加立体感。

:::

## 3. 裁剪与合成

::: details
Canvas 2D 支持裁剪和合成操作。

### 裁剪

```javascript
// 创建裁剪区域
ctx.beginPath();
ctx.arc(100, 100, 50, 0, Math.PI * 2);
ctx.clip();

// 绘制的内容会被裁剪
ctx.fillStyle = 'red';
ctx.fillRect(0, 0, 200, 200);
```

### 合成模式

```javascript
// 设置合成模式
ctx.globalCompositeOperation = 'source-over';  // 默认

// 其他合成模式
// source-over: 新图形覆盖旧图形
// source-in: 新图形与旧图形相交
// source-out: 新图形减去旧图形
// source-atop: 新图形在旧图形上方
// destination-over: 旧图形覆盖新图形
// lighter: 叠加颜色
// multiply: 正片叠底
// screen: 滤色
```

### 图像处理

```javascript
// 获取图像数据
const imageData = ctx.getImageData(x, y, width, height);
const data = imageData.data;

// 处理像素
for (let i = 0; i < data.length; i += 4) {
  // 灰度
  const gray = (data[i] + data[i + 1] + data[i + 2]) / 3;
  data[i] = gray;     // R
  data[i + 1] = gray; // G
  data[i + 2] = gray; // B
}

// 放回图像数据
ctx.putImageData(imageData, x, y);
```

### 总结

裁剪和合成是 Canvas 2D 的高级功能，可以实现复杂的视觉效果。

:::

## 4. 文本渲染

::: details
Canvas 2D 提供了强大的文本渲染功能。

### 基本文本

```javascript
// 设置字体
ctx.font = '24px Arial';

// 填充文本
ctx.fillStyle = 'black';
ctx.fillText('Hello World', x, y);

// 描边文本
ctx.strokeStyle = 'blue';
ctx.lineWidth = 1;
ctx.strokeText('Hello World', x, y);
```

### 文本对齐

```javascript
// 水平对齐
ctx.textAlign = 'left';    // 左对齐
ctx.textAlign = 'center';  // 居中
ctx.textAlign = 'right';   // 右对齐

// 垂直对齐
ctx.textBaseline = 'top';      // 顶部
ctx.textBaseline = 'middle';   // 中间
ctx.textBaseline = 'bottom';   // 底部
```

### 文本测量

```javascript
// 获取文本宽度
const metrics = ctx.measureText('Hello World');
console.log('宽度:', metrics.width);
console.log('实际边界:', metrics.actualBoundingBox);
```

### 文本换行

```javascript
function wrapText(ctx, text, x, y, maxWidth, lineHeight) {
  const words = text.split(' ');
  let line = '';
  
  for (let word of words) {
    const testLine = line + word + ' ';
    const metrics = ctx.measureText(testLine);
    
    if (metrics.width > maxWidth && line !== '') {
      ctx.fillText(line, x, y);
      line = word + ' ';
      y += lineHeight;
    } else {
      line = testLine;
    }
  }
  
  ctx.fillText(line, x, y);
}

wrapText(ctx, '这是一段很长的文本需要换行', 10, 30, 200, 24);
```

### 总结

Canvas 2D 的文本渲染功能可以满足各种文本显示需求。

:::
