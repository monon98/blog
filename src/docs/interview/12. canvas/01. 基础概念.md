# Canvas 基础概念

## 1. 什么是 Canvas

::: details
Canvas 是 HTML5 提供的 2D 绑定 API，可以通过 JavaScript 在网页上绘制图形。

### 核心特点

- **即时模式**：绘制后不保留图形信息，需要重绘时必须重新绘制
- **像素级控制**：可以直接操作像素
- **高性能**：适合动态图形和动画
- **跨平台**：所有现代浏览器都支持

### Canvas vs SVG

| 特性 | Canvas | SVG |
|------|--------|-----|
| 渲染模式 | 即时模式 | 保留模式 |
| 分辨率 | 像素级 | 矢量级 |
| 性能 | 大量图形时更好 | 少量图形时更好 |
| 交互 | 需要手动实现 | 原生支持 |
| 缩放 | 会失真 | 不会失真 |
| 适用场景 | 游戏、动画、图表 | 图标、图表、UI |

### 基本使用

```html
<canvas id="myCanvas" width="400" height="300"></canvas>

<script>
const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');

// 绘制矩形
ctx.fillStyle = 'red';
ctx.fillRect(10, 10, 100, 50);
</script>
```

### 总结

Canvas 是 HTML5 提供的 2D 绑定 API，适合需要高性能绘图的场景。

:::

## 2. Canvas 基本 API

::: details
Canvas 提供了丰富的绑图 API。

### 矩形

```javascript
// 填充矩形
ctx.fillStyle = 'blue';
ctx.fillRect(x, y, width, height);

// 描边矩形
ctx.strokeStyle = 'black';
ctx.lineWidth = 2;
ctx.strokeRect(x, y, width, height);

// 清除矩形
ctx.clearRect(x, y, width, height);
```

### 路径

```javascript
// 开始路径
ctx.beginPath();

// 移动到起点
ctx.moveTo(x, y);

// 画直线
ctx.lineTo(x, y);

// 画弧线
ctx.arc(x, y, radius, startAngle, endAngle, anticlockwise);

// 画贝塞尔曲线
ctx.bezierCurveTo(cp1x, cp1y, cp2x, cp2y, x, y);

// 闭合路径
ctx.closePath();

// 填充
ctx.fill();

// 描边
ctx.stroke();
```

### 文本

```javascript
// 填充文本
ctx.fillStyle = 'black';
ctx.font = '24px Arial';
ctx.fillText('Hello', x, y);

// 描边文本
ctx.strokeText('Hello', x, y);

// 获取文本宽度
const width = ctx.measureText('Hello').width;
```

### 图像

```javascript
// 绘制图像
const img = new Image();
img.src = 'image.jpg';
img.onload = () => {
  ctx.drawImage(img, x, y);
  ctx.drawImage(img, x, y, width, height);
  ctx.drawImage(img, sx, sy, sw, sh, dx, dy, dw, dh);
};
```

### 总结

Canvas 提供了丰富的绑图 API，可以绘制各种图形、文本和图像。

:::

## 3. Canvas 状态管理

::: details
Canvas 提供了状态管理功能，可以保存和恢复绘图状态。

### 保存和恢复状态

```javascript
// 保存状态
ctx.save();

// 修改状态
ctx.fillStyle = 'red';
ctx.lineWidth = 3;

// 绘制
ctx.fillRect(10, 10, 100, 50);

// 恢复状态
ctx.restore();

// 此时恢复到之前的颜色和线宽
```

### 变换

```javascript
// 平移
ctx.translate(x, y);

// 旋转
ctx.rotate(angle);

// 缩放
ctx.scale(x, y);

// 重置变换
ctx.setTransform(1, 0, 0, 1, 0, 0);
```

### 样式

```javascript
// 填充样式
ctx.fillStyle = 'red';
ctx.fillStyle = '#ff0000';
ctx.fillStyle = 'rgb(255, 0, 0)';
ctx.fillStyle = 'rgba(255, 0, 0, 0.5)';

// 描边样式
ctx.strokeStyle = 'blue';
ctx.lineWidth = 2;
ctx.lineCap = 'round';
ctx.lineJoin = 'round';
ctx.setLineDash([5, 15]);
```

### 总结

Canvas 的状态管理功能可以简化绘图代码，避免重复设置样式。

:::

## 4. Canvas 与 WebGL

::: details
Canvas 是 WebGL 的基础，WebGL 在 Canvas 上进行 3D 渲染。

### 2D vs WebGL

```javascript
// 2D 上下文
const ctx2d = canvas.getContext('2d');

// WebGL 上下文
const gl = canvas.getContext('webgl');
```

### 选择建议

| 场景 | 推荐 |
|------|------|
| 简单 2D 图形 | Canvas 2D |
| 复杂 2D 动画 | Canvas 2D + requestAnimationFrame |
| 3D 图形 | WebGL |
| 3D 游戏 | Three.js（基于 WebGL） |

### 总结

Canvas 是 WebGL 的基础，选择 2D 还是 WebGL 取决于项目需求。详见 [13. webgl/01. 基础概念.md](../13.%20webgl/01.%20基础概念#webgl-与-canvas-2d)。

:::
