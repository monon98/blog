# 性能优化

## 1. 渲染优化

::: details
Canvas 2D 渲染优化是提升性能的关键。

### 减少绘制操作

```javascript
// 不推荐：频繁设置样式
for (let i = 0; i < 1000; i++) {
  ctx.fillStyle = `rgb(${i % 255}, 0, 0)`;
  ctx.fillRect(i * 10, 0, 10, 10);
}

// 推荐：批量绘制相同样式
ctx.fillStyle = 'red';
for (let i = 0; i < 1000; i++) {
  ctx.fillRect(i * 10, 0, 10, 10);
}
```

### 使用离屏 Canvas

```javascript
// 创建离屏 Canvas 用于预渲染
const offscreen = document.createElement('canvas');
offscreen.width = 100;
offscreen.height = 100;
const offCtx = offscreen.getContext('2d');

// 预渲染复杂图形
offCtx.fillStyle = 'red';
offCtx.beginPath();
offCtx.arc(50, 50, 40, 0, Math.PI * 2);
offCtx.fill();

// 主 Canvas 直接绘制离屏 Canvas
function draw() {
  ctx.drawImage(offscreen, 0, 0);
}
```

### 减少状态切换

```javascript
// 不推荐：频繁切换状态
for (let i = 0; i < 100; i++) {
  ctx.fillStyle = colors[i];
  ctx.fillRect(x, y, w, h);
}

// 推荐：按颜色分组绘制
const groups = {};
items.forEach(item => {
  if (!groups[item.color]) groups[item.color] = [];
  groups[item.color].push(item);
});

Object.entries(groups).forEach(([color, items]) => {
  ctx.fillStyle = color;
  items.forEach(item => {
    ctx.fillRect(item.x, item.y, item.w, item.h);
  });
});
```

### 总结

渲染优化包括减少绘制操作、使用离屏 Canvas、减少状态切换等。

## 2. OffscreenCanvas

::: details
OffscreenCanvas 允许在 Worker 中进行 Canvas 渲染，避免阻塞主线程。

### 基本使用

```javascript
// 主线程
const canvas = document.getElementById('canvas');
const offscreen = canvas.transferControlToOffscreen();

// 创建 Worker
const worker = new Worker('canvas-worker.js');
worker.postMessage({ canvas: offscreen }, [offscreen]);
```

```javascript
// canvas-worker.js
self.onmessage = (e) => {
  const canvas = e.data.canvas;
  const ctx = canvas.getContext('2d');
  
  // 在 Worker 中渲染
  function draw() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    ctx.fillStyle = 'red';
    ctx.fillRect(0, 0, 100, 100);
    
    requestAnimationFrame(draw);
  }
  
  draw();
};
```

### 与 Worker 结合

```javascript
// 主线程
const canvas = document.getElementById('canvas');
const offscreen = canvas.transferControlToOffscreen();

const worker = new Worker('renderer.js');
worker.postMessage({ canvas: offscreen, width: 800, height: 600 }, [offscreen]);

// 接收 Worker 渲染结果
worker.onmessage = (e) => {
  console.log('渲染完成');
};
```

### 适用场景

| 场景 | 是否推荐 |
|------|----------|
| 复杂动画 | 推荐 |
| 数据可视化 | 推荐 |
| 简单图形 | 不推荐 |
| 需要 DOM 交互 | 不推荐 |

## 3. 内存优化

::: details
Canvas 2D 应用的内存优化技巧。

### 及时释放资源

```javascript
// 清除画布
ctx.clearRect(0, 0, canvas.width, canvas.height);

// 释放图像
img.src = '';

// 释放 Canvas
canvas.width = 0;
canvas.height = 0;
```

### 使用对象池

```javascript
class ObjectPool {
  constructor(createFn) {
    this.pool = [];
    this.createFn = createFn;
  }
  
  get() {
    if (this.pool.length > 0) {
      return this.pool.pop();
    }
    return this.createFn();
  }
  
  release(obj) {
    this.pool.push(obj);
  }
}

// 使用
const bulletPool = new ObjectPool(() => ({
  x: 0, y: 0, vx: 0, vy: 0
}));

const bullet = bulletPool.get();
// 使用后释放
bulletPool.release(bullet);
```

### 减少内存分配

```javascript
// 不推荐：每帧创建新对象
function animate() {
  const pos = { x: Math.random() * 100, y: Math.random() * 100 };
  // ...
}

// 推荐：复用对象
const pos = { x: 0, y: 0 };
function animate() {
  pos.x = Math.random() * 100;
  pos.y = Math.random() * 100;
  // ...
}
```

### 总结

内存优化包括及时释放资源、使用对象池、减少内存分配等。

## 3. 计算优化

::: details
Canvas 2D 应用的计算优化技巧。

### 减少数学计算

```javascript
// 不推荐：每帧计算三角函数
function animate() {
  const x = Math.cos(angle) * radius;
  const y = Math.sin(angle) * radius;
  // ...
}

// 推荐：预计算
const cosTable = [];
const sinTable = [];
for (let i = 0; i < 360; i++) {
  cosTable[i] = Math.cos(i * Math.PI / 180);
  sinTable[i] = Math.sin(i * Math.PI / 180);
}

function animate() {
  const x = cosTable[angle] * radius;
  const y = sinTable[angle] * radius;
  // ...
}
```

### 使用位运算

```javascript
// 不推荐
const index = Math.floor(x / cellSize);

// 推荐：使用位运算
const index = x >> cellSizeLog2;
```

### 减少条件判断

```javascript
// 不推荐
if (type === 'circle') {
  drawCircle();
} else if (type === 'rect') {
  drawRect();
}

// 推荐：使用函数映射
const drawFunctions = {
  circle: drawCircle,
  rect: drawRect
};
drawFunctions[type]();
```

### 总结

计算优化包括减少数学计算、使用位运算、减少条件判断等。

## 4. 监控与调试

::: details
Canvas 2D 应用的性能监控和调试方法。

### 帧率监控

```javascript
let frameCount = 0;
let lastTime = performance.now();

function monitorFPS() {
  frameCount++;
  const currentTime = performance.now();
  
  if (currentTime - lastTime >= 1000) {
    const fps = frameCount;
    console.log(`FPS: ${fps}`);
    
    if (fps < 30) {
      console.warn('帧率过低');
    }
    
    frameCount = 0;
    lastTime = currentTime;
  }
  
  requestAnimationFrame(monitorFPS);
}

monitorFPS();
```

### 内存监控

```javascript
function monitorMemory() {
  if (performance.memory) {
    console.log(`内存使用: ${performance.memory.usedJSHeapSize / 1024 / 1024} MB`);
  }
}

setInterval(monitorMemory, 5000);
```

### 绘制统计

```javascript
let drawCalls = 0;

// 包装绘制方法
const originalFillRect = ctx.fillRect.bind(ctx);
ctx.fillRect = function(...args) {
  drawCalls++;
  return originalFillRect(...args);
};

// 定期输出
setInterval(() => {
  console.log(`绘制调用: ${drawCalls}`);
  drawCalls = 0;
}, 1000);
```

### 总结

性能监控可以帮助发现瓶颈，包括帧率监控、内存监控、绘制统计等。

:::
