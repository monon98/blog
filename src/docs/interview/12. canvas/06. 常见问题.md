### 闪烁问题

**问题**：Canvas 动画闪烁

**解决方案**：
```javascript
// 使用双缓冲
const offscreen = document.createElement('canvas');
offscreen.width = canvas.width;
offscreen.height = canvas.height;
const offCtx = offscreen.getContext('2d');

function animate() {
  // 在离屏 Canvas 上绘制
  offCtx.clearRect(0, 0, offscreen.width, offscreen.height);
  drawScene(offCtx);
  
  // 一次性绘制到主 Canvas
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.drawImage(offscreen, 0, 0);
  
  requestAnimationFrame(animate);
}
```

### 总结

渲染问题通常与像素比、缓冲策略有关，需要针对性处理。

::: details
Canvas 2D 应用的兼容性问题和解决方案。

**问题**：某些 API 不支持

**解决方案**：

```javascript
  alert('无法获取 2D 上下文');
}
```

### 移动端兼容性

**问题**：移动端触摸事件不正常

**解决方案**：
```javascript
// 阻止默认行为
canvas.addEventListener('touchstart', (e) => {
  e.preventDefault();
});

// 使用 passive: false
canvas.addEventListener('touchmove', (e) => {
  e.preventDefault();
}, { passive: false });
```

### 高 DPI 屏幕

**问题**：高 DPI 屏幕显示模糊

**解决方案**：
```javascript
function setupCanvas(canvas) {
  const dpr = window.devicePixelRatio || 1;
  const rect = canvas.getBoundingClientRect();
  
  // 先获取尺寸，再设置（避免尺寸变化）
  const width = rect.width;
  const height = rect.height;
  
  canvas.width = width * dpr;
  canvas.height = height * dpr;
  
  const ctx = canvas.getContext('2d');
  ctx.scale(dpr, dpr);
  
  // 设置样式尺寸
  canvas.style.width = width + 'px';
  canvas.style.height = height + 'px';
  
  return ctx;
}
```

### 总结

兼容性问题需要考虑浏览器支持、移动端适配、高 DPI 屏幕等因素。

## 4. 交互问题

::: details
Canvas 2D 交互相关的常见问题。

### 点击检测不准确

**问题**：点击位置与实际位置有偏差

**解决方案**：
```javascript
function getCanvasPosition(canvas, event) {
  const rect = canvas.getBoundingClientRect();
  const scaleX = canvas.width / rect.width;
  const scaleY = canvas.height / rect.height;
  
  return {
    x: (event.clientX - rect.left) * scaleX,
    y: (event.clientY - rect.top) * scaleY
  };
}

canvas.addEventListener('click', (e) => {
  const pos = getCanvasPosition(canvas, e);
  // 使用 pos.x 和 pos.y 进行检测
});
```

### 拖拽不流畅

**问题**：拖拽时对象抖动

**解决方案**：
```javascript
let isDragging = false;
let dragOffset = { x: 0, y: 0 };

canvas.addEventListener('mousedown', (e) => {
  const pos = getCanvasPosition(canvas, e);
  
  if (isPointInRect(pos, rect)) {
    isDragging = true;
    dragOffset.x = pos.x - rect.x;
    dragOffset.y = pos.y - rect.y;
  }
});

canvas.addEventListener('mousemove', (e) => {
  if (isDragging) {
    const pos = getCanvasPosition(canvas, e);
    rect.x = pos.x - dragOffset.x;
    rect.y = pos.y - dragOffset.y;
  }
});
```

### 总结

交互问题通常与坐标计算、事件处理有关，需要精确处理。
