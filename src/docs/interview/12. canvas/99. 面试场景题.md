## 5. Canvas 与 WebGL

::: details
**问题**：Canvas 2D 和 WebGL 如何选择？

### Canvas 2D

- API 简单易用
- 适合 2D 图形
- 性能一般
- 不支持 3D

### WebGL

- 性能强大
- 支持 3D 图形
- API 复杂
- 需要着色器知识

### 选择原则

| 场景 | 推荐 |
|------|------|
| 简单 2D 图形 | Canvas 2D |
| 复杂 2D 图形 | Canvas 2D + 优化 |
| 3D 图形 | WebGL |
| 大量粒子 | WebGL |

### 迁移策略

- 从 Canvas 2D 迁移到 WebGL
- 使用 PixiJS 等库简化开发
- 渐进式升级

:::
