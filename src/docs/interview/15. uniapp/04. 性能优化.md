# 性能优化

## 1. 渲染优化

::: details
UniApp 渲染优化是提升用户体验的关键。

### 减少 setData

```vue
<script>
export default {
  methods: {
    // 不推荐：频繁调用
    updateList() {
      for (let i = 0; i < 100; i++) {
        this.list[i].value = i;
        this.$forceUpdate();
      }
    },
    
    // 推荐：一次性更新
    updateList() {
      const list = this.list.map((item, i) => ({
        ...item,
        value: i
      }));
      this.list = list;
    }
  }
};
</script>
```

### 使用虚拟列表

```vue
<template>
  <scroll-view 
    scroll-y 
    @scroll="onScroll"
    :style="{ height: '500px' }"
  >
    <view 
      v-for="(item, index) in displayList" 
      :key="index"
      :style="{ height: '50px' }"
    >
      {{ item.name }}
    </view>
  </scroll-view>
</template>

<script>
export default {
  data() {
    return {
      list: [],
      displayList: [],
      startIndex: 0,
      itemHeight: 50,
      viewHeight: 500
    };
  },
  
  methods: {
    onScroll(e) {
      const scrollTop = e.detail.scrollTop;
      const startIndex = Math.floor(scrollTop / this.itemHeight);
      
      if (startIndex !== this.startIndex) {
        this.startIndex = startIndex;
        this.displayList = this.list.slice(startIndex, startIndex + 10);
      }
    }
  }
};
</script>
```

### 总结

减少渲染次数和数据量是性能优化的核心。

## 3. 内存优化

::: details
UniApp 内存优化可以防止应用崩溃。

### 及时清理

```vue
<script>
export default {
  data() {
    return {
      timer: null
    };
  },
  
  onLoad() {
    this.timer = setInterval(() => {
      // 定时任务
    }, 1000);
  },
  
  onUnload() {
    if (this.timer) {
      clearInterval(this.timer);
      this.timer = null;
    }
  }
};
</script>
```

### 数据清理

```javascript
// 清理缓存
uni.removeStorageSync('cacheKey');

// 清理所有缓存
uni.clearStorageSync();
```

### 总结

内存优化需要及时清理资源，避免内存泄漏。

## 4. 网络优化

::: details
UniApp 网络优化可以提升数据加载速度。

### 请求封装

```javascript
// utils/request.js
const BASE_URL = 'https://api.example.com';

export function request(options) {
  return new Promise((resolve, reject) => {
    // 检查缓存
    const cacheKey = options.url + JSON.stringify(options.data);
    const cached = uni.getStorageSync(cacheKey);
    
    if (cached && !options.noCache) {
      resolve(cached);
      return;
    }
    
    uni.request({
      url: BASE_URL + options.url,
      method: options.method || 'GET',
      data: options.data,
      success: (res) => {
        if (res.statusCode === 200) {
          // 缓存数据
          uni.setStorageSync(cacheKey, res.data);
          resolve(res.data);
        } else {
          reject(res);
        }
      },
      fail: reject
    });
  });
}
```

### 总结

网络优化包括缓存策略、请求合并等。
