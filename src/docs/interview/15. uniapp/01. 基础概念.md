# 基础概念

## 1. 什么是 UniApp

::: details
UniApp 是一个使用 Vue.js 开发所有前端应用的框架，一套代码可以编译到多个平台。

### 支持平台

| 平台 | 说明 |
|------|------|
| H5 | 浏览器 |
| 微信小程序 | 微信生态 |
| 支付宝小程序 | 支付宝生态 |
| 百度小程序 | 百度生态 |
| 字节跳动小程序 | 抖音生态 |
| App | iOS / Android |
| 鸿蒙 | HarmonyOS |

### 核心特点

- **跨平台**：一套代码，多端运行
- **基于 Vue**：支持 Vue 2 和 Vue 3
- **条件编译**：针对不同平台编写特定代码
- **原生渲染**：小程序和 App 使用原生渲染

### Vue 2 vs Vue 3

| 特性 | Vue 2 | Vue 3 |
|------|-------|-------|
| API 风格 | Options API | Composition API |
| 响应式 | defineProperty | Proxy |
| 生命周期 | beforeCreate/created | setup/onMounted |
| 状态管理 | Vuex | Pinia |
| 性能 | 一般 | 更好 |

### 总结

UniApp 是一个跨平台开发框架，支持 Vue 2 和 Vue 3，推荐使用 Vue 3。

:::

## 2. 项目结构

::: details
UniApp 项目具有标准的目录结构。

### 目录结构

```
uniapp/
├── pages/              # 页面目录
│   ├── index/
│   │   ├── index.vue   # 页面组件
│   │   └── index.scss  # 页面样式
│   └── detail/
├── components/         # 组件目录
├── static/             # 静态资源
├── store/              # Vuex 状态
├── utils/              # 工具函数
├── pages.json          # 页面配置
├── manifest.json       # 应用配置
├── App.vue             # 应用入口
├── main.js             # 入口文件
└── uni.scss            # 全局样式
```

### 页面配置

```json
// pages.json
{
  "pages": [
    {
      "path": "pages/index/index",
      "style": {
        "navigationBarTitleText": "首页"
      }
    },
    {
      "path": "pages/detail/detail",
      "style": {
        "navigationBarTitleText": "详情"
      }
    }
  ],
  "globalStyle": {
    "navigationBarTextStyle": "black",
    "navigationBarTitleText": "UniApp",
    "navigationBarBackgroundColor": "#F8F8F8"
  },
  "tabBar": {
    "list": [
      {
        "pagePath": "pages/index/index",
        "text": "首页",
        "iconPath": "static/home.png",
        "selectedIconPath": "static/home-active.png"
      }
    ]
  }
}
```

### 总结

UniApp 采用标准的目录结构，通过 pages.json 管理页面配置。

:::

## 3. 条件编译

::: details
条件编译是 UniApp 的核心特性，可以针对不同平台编写特定代码。

### 语法

```html
<!-- 模板条件编译 -->
<!-- #ifdef MP-WEIXIN -->
<view>微信小程序专用</view>
<!-- #endif -->

<!-- #ifdef H5 -->
<view>H5 专用</view>
<!-- #endif -->
```

```javascript
// JS 条件编译
// #ifdef MP-WEIXIN
wx.login({
  success: (res) => {
    console.log('微信登录');
  }
});
// #endif

// #ifdef APP-PLUS
plus.runtime.openURL('weixin://');
// #endif
```

```css
/* CSS 条件编译 */
/* #ifdef MP-WEIXIN */
.container {
  padding: 20rpx;
}
/* #endif */

/* #ifdef H5 */
.container {
  padding: 10px;
}
/* #endif */
```

### 平台标识

| 标识 | 说明 |
|------|------|
| H5 | 浏览器 |
| MP-WEIXIN | 微信小程序 |
| MP-ALIPAY | 支付宝小程序 |
| MP-BAIDU | 百度小程序 |
| APP-PLUS | App |

### 总结

条件编译允许我们在同一套代码中针对不同平台编写特定逻辑。

:::

## 4. 生命周期

::: details
UniApp 的生命周期与 Vue 类似，同时支持小程序生命周期。

### 应用生命周期

```javascript
// App.vue
export default {
  onLaunch(options) {
    console.log('应用启动:', options);
  },
  
  onShow(options) {
    console.log('应用显示');
  },
  
  onHide() {
    console.log('应用隐藏');
  },
  
  onError(error) {
    console.error('应用错误:', error);
  }
};
```

### 页面生命周期

```javascript
// pages/index/index.vue
export default {
  data() {
    return {
      list: []
    };
  },
  
  onLoad(options) {
    // 页面加载
    console.log('页面参数:', options);
  },
  
  onShow() {
    // 页面显示
    this.refreshData();
  },
  
  onReady() {
    // 页面渲染完成
  },
  
  onHide() {
    // 页面隐藏
  },
  
  onUnload() {
    // 页面卸载
  },
  
  onPullDownRefresh() {
    // 下拉刷新
    setTimeout(() => {
      uni.stopPullDownRefresh();
    }, 1000);
  },
  
  onReachBottom() {
    // 上拉加载
    this.loadMore();
  }
};
```

### 总结

UniApp 提供了完整的生命周期钩子，支持应用、页面级别。

:::
