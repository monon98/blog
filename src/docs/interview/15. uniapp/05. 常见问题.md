# 常见问题

## 1. 开发问题

::: details
UniApp 开发中的常见问题。

### 条件编译问题

**问题**：条件编译不生效

**解决方案**：
```javascript
// 正确语法
// #ifdef MP-WEIXIN
console.log('微信小程序');
// #endif

// 错误语法（不要有空格）
// #ifdef MP-WEIXIN
console.log('微信小程序');
// #endif
```

### 样式问题

**问题**：样式在不同平台表现不一致

**解决方案**：
```css
/* 使用 rpx 作为单位 */
.container {
  padding: 20rpx;
  font-size: 28rpx;
}

/* 使用条件编译处理差异 */
/* #ifdef MP-WEIXIN */
.container {
  padding: 20rpx;
}
/* #endif */

/* #ifdef H5 */
.container {
  padding: 10px;
}
/* #endif */
```

### 总结

开发问题需要仔细阅读文档，注意平台差异。

:::

## 2. 兼容性问题

::: details
UniApp 兼容性问题和解决方案。

### API 兼容性

**问题**：某些 API 不支持

**解决方案**：
```javascript
// 检查 API 是否可用
if (uni.canIUse('chooseImage')) {
  uni.chooseImage({ ... });
} else {
  // 降级方案
  console.log('API 不支持');
}
```

### 平台兼容性

**问题**：功能在某些平台不可用

**解决方案**：
```javascript
// 条件编译
// #ifdef MP-WEIXIN
// 微信小程序代码
// #endif

// #ifdef APP-PLUS
// App 代码
// #endif

// 获取平台信息
const platform = uni.getSystemInfoSync().platform;
console.log('平台:', platform);
```

### 总结

兼容性问题需要通过特性检测和条件编译来解决。

:::

## 3. 调试问题

::: details
UniApp 调试技巧和工具。

### 真机调试

```javascript
// 使用真机调试
// 开发者工具 → 真机调试 → 开启

// 或使用 vConsole
// main.js
import App from './App';

// #ifdef H5
import Vconsole from 'vconsole';
new Vconsole();
// #endif

App.mpType = 'app';
const app = new Vue({ ...App });
app.$mount();
```

### 性能监控

```javascript
// 监控页面性能
export default {
  onShow() {
    const startTime = Date.now();
    
    this.$nextTick(() => {
      const cost = Date.now() - startTime;
      console.log(`渲染耗时: ${cost}ms`);
    });
  }
};
```

### 总结

调试需要使用真机调试和性能监控工具。

:::

## 4. 发布问题

::: details
UniApp 发布流程和注意事项。

### 发布流程

```bash
# 1. 打包
# H5
npm run build:h5

# 微信小程序
npm run build:mp-weixin

# App
npm run build:app
```

### 发布配置

```json
// manifest.json
{
  "name": "应用名称",
  "appid": "应用 ID",
  "description": "应用描述",
  "versionName": "1.0.0",
  "versionCode": "100",
  "h5": {
    "title": "H5 应用"
  },
  "mp-weixin": {
    "appid": "微信小程序 AppID"
  }
}
```

### 注意事项

| 事项 | 说明 |
|------|------|
| AppID | 填写正确的 AppID |
| 类目 | 选择正确的服务类目 |
| 隐私 | 遵守隐私协议 |
| 内容 | 不含违规内容 |

### 总结

发布前需要仔细检查配置和内容。

:::
