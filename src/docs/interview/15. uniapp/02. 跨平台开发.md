# 跨平台开发

## 1. 平台差异处理

::: details
不同平台存在 API 和表现差异，需要适配处理。

### API 差异

```javascript
// 微信小程序
// #ifdef MP-WEIXIN
wx.login({
  success: (res) => {
    console.log('code:', res.code);
  }
});
// #endif

// 支付宝小程序
// #ifdef MP-ALIPAY
my.getAuthCode({
  scopes: 'auth_base',
  success: (res) => {
    console.log('code:', res.authCode);
  }
});
// #endif

// App
// #ifdef APP-PLUS
uni.login({
  provider: 'weixin',
  success: (res) => {
    console.log('登录成功');
  }
});
// #endif
```

### 样式差异

```css
/* 微信小程序使用 rpx */
/* #ifdef MP-WEIXIN */
.container {
  padding: 20rpx;
  font-size: 28rpx;
}
/* #endif */

/* H5 使用 px */
/* #ifdef H5 */
.container {
  padding: 10px;
  font-size: 14px;
}
/* #endif */

/* App 使用 px */
/* #ifdef APP-PLUS */
.container {
  padding: 10px;
  font-size: 14px;
}
/* #endif */
```

### 总结

平台差异需要通过条件编译来处理。

:::

## 2. 路由管理

::: details
UniApp 的路由管理与小程序类似。

### 路由跳转

```javascript
// 保留当前页面，跳转
uni.navigateTo({
  url: '/pages/detail/detail?id=1',
  success: (res) => {
    console.log('跳转成功');
  },
  fail: (err) => {
    console.error('跳转失败:', err);
  }
});

// 关闭当前页面，跳转
uni.redirectTo({
  url: '/pages/detail/detail'
});

// 关闭所有页面，跳转
uni.reLaunch({
  url: '/pages/index/index'
});

// 返回上一页
uni.navigateBack({
  delta: 1
});
```

### 路由参数

```javascript
// 传递参数
uni.navigateTo({
  url: '/pages/detail/detail?id=1&name=test'
});

// 接收参数
onLoad(options) {
  const { id, name } = options;
  console.log('参数:', id, name);
}
```

### 路由守卫

```javascript
// 页面拦截器
// pages.json
{
  "globalStyle": {
    "navigationBarTextStyle": "black"
  },
  "pages": [
    {
      "path": "pages/index/index",
      "style": {
        "navigationBarTitleText": "首页"
      },
      "styleAppPlus": {
        "titleNView": false
      }
    }
  ]
}
```

### 总结

路由管理是 UniApp 应用的核心功能。

## 3. 网络请求

::: details
UniApp 提供统一的网络请求 API。

### 基本请求

```javascript
// GET 请求
uni.request({
  url: 'https://api.example.com/user',
  method: 'GET',
  data: { id: 1 },
  success: (res) => {
    console.log('数据:', res.data);
  },
  fail: (err) => {
    console.error('请求失败:', err);
  }
});

// POST 请求
uni.request({
  url: 'https://api.example.com/user',
  method: 'POST',
  header: {
    'Content-Type': 'application/json'
  },
  data: { name: '张三' },
  success: (res) => {
    console.log('成功:', res.data);
  }
});
```

### 封装请求

```javascript
// utils/request.js
const BASE_URL = 'https://api.example.com';

export function request(options) {
  return new Promise((resolve, reject) => {
    uni.request({
      url: BASE_URL + options.url,
      method: options.method || 'GET',
      data: options.data,
      header: {
        'Authorization': uni.getStorageSync('token'),
        ...options.header
      },
      success: (res) => {
        if (res.statusCode === 200) {
          resolve(res.data);
        } else {
          reject(res);
        }
      },
      fail: reject
    });
  });
}

// 使用
import { request } from '@/utils/request';

const data = await request({
  url: '/user',
  method: 'GET',
  data: { id: 1 }
});
```

### 总结

网络请求需要统一封装，便于维护和管理。

:::

## 4. 数据存储

::: details
UniApp 提供本地存储 API。

### 基本操作

```javascript
// 存储
uni.setStorageSync('key', 'value');

// 读取
const value = uni.getStorageSync('key');

// 删除
uni.removeStorageSync('key');

// 清空
uni.clearStorageSync();
```

### 异步操作

```javascript
// 存储
uni.setStorage({
  key: 'userInfo',
  data: { name: '张三' },
  success: () => {
    console.log('存储成功');
  }
});

// 读取
uni.getStorage({
  key: 'userInfo',
  success: (res) => {
    console.log('数据:', res.data);
  }
});
```

### 总结

本地存储可以用于缓存数据和用户偏好设置。

:::
