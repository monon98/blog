# 窗口管理

## 1. BrowserWindow 基础

::: details
BrowserWindow 是 Electron 中创建和管理窗口的核心 API。

### 创建窗口

```javascript
const { BrowserWindow } = require('electron');
const path = require('path');

// 基本窗口
const win = new BrowserWindow({
  width: 800,
  height: 600,
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true
  }
});

win.loadFile('index.html');
```

### 窗口配置

```javascript
const win = new BrowserWindow({
  // 尺寸和位置
  width: 800,
  height: 600,
  minWidth: 400,
  minHeight: 300,
  x: 100,
  y: 100,
  
  // 外观
  title: 'My App',
  icon: path.join(__dirname, 'icon.png'),
  backgroundColor: '#ffffff',
  titleBarStyle: 'hiddenInset',  // macOS
  frame: true,
  
  // 行为
  show: false,           // 创建时不显示
  hideOnMouseLeave: false,
  alwaysOnTop: false,
  skipTaskbar: false,
  resizable: true,
  fullscreenable: true,
  minimizable: true,
  maximizable: true,
  closable: true,
  
  // Web 配置
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true,
    preload: path.join(__dirname, 'preload.js')
  }
});
```

### 窗口事件

```javascript
win.on('ready-to-show', () => {
  win.show();
});

win.on('show', () => {
  console.log('窗口显示');
});

win.on('hide', () => {
  console.log('窗口隐藏');
});

win.on('close', (event) => {
  // 阻止窗口关闭
  event.preventDefault();
});

win.on('closed', () => {
  console.log('窗口已关闭');
});

win.on('resize', () => {
  const [width, height] = win.getSize();
  console.log(`窗口大小: ${width}x${height}`);
});

win.on('move', () => {
  const [x, y] = win.getPosition();
  console.log(`窗口位置: ${x}, ${y}`);
});
```

### 总结

BrowserWindow 是 Electron 窗口管理的核心，通过配置可以创建各种类型的窗口，并通过事件监听窗口状态变化。

:::

## 2. 窗口类型与样式

::: details
Electron 支持多种窗口类型和样式，适用于不同的应用场景。

### 窗口类型

```javascript

const win = new BrowserWindow({ width: 800, height: 600 });

  width: 800,
  height: 600
});

// 3. 透明窗口
const win = new BrowserWindow({
  transparent: true,
  frame: false,
  width: 800,
  height: 600
});

// 4. 工具窗口
const win = new BrowserWindow({
  type: 'toolbar',
  width: 300,
  height: 200
});

// 5. 模态窗口
const win = new BrowserWindow({
  parent: mainWindow,
  modal: true,
  width: 400,
  height: 300

```

### macOS 标题栏样式

```javascript
// 隐藏标题栏
```

```javascript
// 控制窗口按钮
const { ipcRenderer } = require('electron');

document.getElementById('minimize').addEventListener('click', () => {
  ipcRenderer.send('window-minimize');
});

document.getElementById('maximize').addEventListener('click', () => {
  ipcRenderer.send('window-maximize');
});

document.getElementById('close').addEventListener('click', () => {
  ipcRenderer.send('window-close');
});

// main.js
ipcMain.on('window-minimize', (event) => {
  BrowserWindow.fromWebContents(event.sender).minimize();
});

ipcMain.on('window-maximize', (event) => {
  const win = BrowserWindow.fromWebContents(event.sender);
  if (win.isMaximized()) {
    win.unmaximize();
  } else {
    win.maximize();
  }
});

ipcMain.on('window-close', (event) => {
  BrowserWindow.fromWebContents(event.sender).close();
});
```

## 3. 多窗口管理

::: details
在实际应用中，通常需要管理多个窗口，以下是一些最佳实践。

### 窗口管理器

```javascript
// WindowManager.js
class WindowManager {
  constructor() {
    this.windows = new Map();
  }
  
  createWindow(id, options) {
    if (this.windows.has(id)) {
      this.windows.get(id).focus();
      return this.windows.get(id);
    }
    
    const win = new BrowserWindow(options);
    this.windows.set(id, win);
    
    win.on('closed', () => {
      this.windows.delete(id);
    });
    
    return win;
  }
  
  getWindow(id) {
    return this.windows.get(id);
  }
  
  closeWindow(id) {
    const win = this.windows.get(id);
    if (win) {
      win.close();
    }
  }
  
  closeAll() {
    this.windows.forEach(win => win.close());
  }
  
  getWindows() {
    return Array.from(this.windows.values());
  }
}

module.exports = WindowManager;
```

### 使用示例

```javascript
// main.js
const WindowManager = require('./WindowManager');

const manager = new WindowManager();

// 创建窗口
const mainWindow = manager.createWindow('main', {
  width: 800,
  height: 600,
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true
  }
});

const settingsWindow = manager.createWindow('settings', {
  width: 400,
  height: 300,
  parent: mainWindow,
  modal: true,
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true
  }
});
```

### 窗口间通信

```javascript
// 方式1：通过主进程中转
// 窗口A -> 主进程 -> 窗口B

// main.js
ipcMain.on('message-to-window-b', (event, data) => {
  const winB = manager.getWindow('windowB');
  if (winB) {
    winB.webContents.send('message-from-window-a', data);
  }
});

// 窗口A
ipcRenderer.send('message-to-window-b', { text: 'Hello' });

// 窗口B
ipcRenderer.on('message-from-window-a', (event, data) => {
  console.log(data.text); // 'Hello'
});

// 方式2：使用 MessageChannel
// main.js
ipcMain.handle('create-channel', () => {
  const { port1, port2 } = new MessageChannelMain();
  
  const winA = manager.getWindow('windowA');
  const winB = manager.getWindow('windowB');
  
  winA.webContents.postMessage('port', null, [port1]);
  winB.webContents.postMessage('port', null, [port2]);
  
  return 'channel created';
});
```

### 窗口状态持久化

```javascript
// main.js
const Store = require('electron-store');

const store = new Store();

function createWindow() {
  const windowState = store.get('windowState', {
    width: 800,
    height: 600,
    x: undefined,
    y: undefined
  });
  
  const win = new BrowserWindow({
    width: windowState.width,
    height: windowState.height,
    x: windowState.x,
    y: windowState.y
  });
  
  // 保存窗口状态
  win.on('resize', () => {
    const [width, height] = win.getSize();
    store.set('windowState', { ...store.get('windowState'), width, height });
  });
  
  win.on('move', () => {
    const [x, y] = win.getPosition();
    store.set('windowState', { ...store.get('windowState'), x, y });
  });
  
  return win;
}
```

### 总结

多窗口管理需要考虑窗口的创建、销毁、通信和状态持久化，使用窗口管理器可以简化多窗口应用的开发。

:::

## 4. 模态窗口与对话框

::: details
模态窗口和对话框是用户交互的重要组成部分。

### 模态窗口

```javascript
// 主窗口
const mainWindow = new BrowserWindow({
  width: 800,
  height: 600
});

// 模态窗口
const modalWindow = new BrowserWindow({
  parent: mainWindow,
  modal: true,
  width: 400,
  height: 300,
  show: false,
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true
  }
});

modalWindow.loadFile('modal.html');
modalWindow.once('ready-to-show', () => {
  modalWindow.show();
});
```

### 系统对话框

```javascript
const { dialog } = require('electron');

// 打开文件对话框
async function openFileDialog() {
  const result = await dialog.showOpenDialog(mainWindow, {
    title: '选择文件',
    defaultPath: app.getPath('documents'),
    filters: [
      { name: 'Images', extensions: ['jpg', 'png', 'gif'] },
      { name: 'All Files', extensions: ['*'] }
    ],
    properties: ['openFile', 'multiSelections']
  });
  
  if (!result.canceled) {
    return result.filePaths;
  }
  return null;
}

// 保存文件对话框
async function saveFileDialog() {
  const result = await dialog.showSaveDialog(mainWindow, {
    title: '保存文件',
    defaultPath: app.getPath('documents'),
    filters: [
      { name: 'JSON', extensions: ['json'] },
      { name: 'All Files', extensions: ['*'] }
    ]
  });
  
  if (!result.canceled) {
    return result.filePath;
  }
  return null;
}

// 消息对话框
async function showMessageBox() {
  const result = await dialog.showMessageBox(mainWindow, {
    type: 'question',
    title: '确认',
    message: '确定要删除吗？',
    buttons: ['确定', '取消'],
    defaultId: 0,
    cancelId: 1
  });
  
  return result.response === 0;
}

// 警告对话框
async function showWarningBox() {
  await dialog.showMessageBox(mainWindow, {
    type: 'warning',
    title: '警告',
    message: '此操作不可逆',
    buttons: ['确定']
  });
}
```

### 自定义对话框组件

```javascript
// DialogManager.js
class DialogManager {
  static async showConfirm(message, options = {}) {
    return new Promise((resolve) => {
      const win = new BrowserWindow({
        width: 300,
        height: 200,
        parent: options.parent,
        modal: true,
        show: false,
        webPreferences: {
          nodeIntegration: false,
          contextIsolation: true
        }
      });
      
      win.loadFile('confirm-dialog.html');
      
      win.webContents.on('did-finish-load', () => {
        win.webContents.send('dialog-message', message);
      });
      
      ipcMain.once('dialog-response', (event, response) => {
        resolve(response);
        win.close();
      });
      
      win.once('ready-to-show', () => {
        win.show();
      });
    });
  }
}

// 使用
const confirmed = await DialogManager.showConfirm('确定要删除吗？', {
  parent: mainWindow
});
```

### 总结

模态窗口和对话框是用户交互的重要方式，Electron 提供了系统对话框 API，也可以创建自定义对话框组件。

:::

## 5. 窗口性能优化

::: details
窗口性能优化可以提升用户体验，以下是一些优化建议。

### 延迟创建窗口

```javascript
// 不推荐：立即创建
app.whenReady().then(() => {
  createWindow();
});

// 推荐：延迟创建
app.whenReady().then(() => {
  // 等待应用完全初始化后再创建窗口
  setTimeout(() => {
    createWindow();
  }, 100);
});
```

### 窗口复用

```javascript
// 不推荐：每次都创建新窗口
function openSettings() {
  const win = new BrowserWindow({
    width: 400,
    height: 300
  });
  win.loadFile('settings.html');
}

// 推荐：复用窗口
let settingsWindow = null;

function openSettings() {
  if (settingsWindow) {
    settingsWindow.focus();
    return;
  }
  
  settingsWindow = new BrowserWindow({
    width: 400,
    height: 300
  });
  
  settingsWindow.loadFile('settings.html');
  
  settingsWindow.on('closed', () => {
    settingsWindow = null;
  });
}
```

### 预加载页面

```javascript
// 预加载常用页面
const preloadPages = ['settings', 'about'];

preloadPages.forEach(page => {
  const win = new BrowserWindow({
    show: false,
    webPreferences: {
      nodeIntegration: false,
      contextIsolation: true
    }
  });
  
  win.loadFile(`${page}.html`);
  win.once('ready-to-show', () => {
    win.hide();
  });
});

// 需要时直接显示
function showPage(pageName) {
  const win = BrowserWindow.getAllWindows().find(w => 
    w.getTitle() === pageName
  );
  
  if (win) {
    win.show();
  }
}
```

### 使用 webContents 的 backgroundThrottling

```javascript
// 当窗口不可见时降低渲染频率
win.webContents.setBackgroundThrottling(true);

// 当窗口最小化时暂停渲染
win.on('minimize', () => {
  win.webContents.setBackgroundThrottling(true);
});

win.on('restore', () => {
  win.webContents.setBackgroundThrottling(false);
});
```

### 总结

窗口性能优化包括延迟创建、窗口复用、预加载页面、降低后台渲染频率等，这些优化可以显著提升应用的响应速度和资源利用率。

:::
