# 打包与分发

## 1. 打包工具选择

::: details
Electron 提供了多种打包工具，选择合适的工具可以简化打包流程。

### 主流打包工具

| 工具 | 特点 | 适用场景 |
|------|------|----------|
| electron-builder | 功能丰富、配置灵活 | 大多数项目 |
| electron-forge | 官方推荐、易于使用 | 新项目 |
| electron-packager | 轻量级、简单 | 小型项目 |

### electron-builder

```json
// package.json
{
  "name": "my-electron-app",
  "version": "1.0.0",
  "build": {
    "appId": "com.example.myapp",
    "productName": "My App",
    "directories": {
      "output": "dist"
    },
    "files": [
      "dist/**/*",
      "package.json"
    ],
    "mac": {
      "category": "public.app-category.developer-tools",
      "icon": "build/icon.icns",
      "target": ["dmg", "zip"]
    },
    "win": {
      "icon": "build/icon.ico",
      "target": ["nsis", "portable"]
    },
    "linux": {
      "icon": "build/icons",
      "target": ["AppImage", "deb"]
    }
  }
}
```

```bash
# 安装
npm install electron-builder --save-dev

# 打包
npm run build

# 打包特定平台
npx electron-builder --mac
npx electron-builder --win
npx electron-builder --linux
```

### electron-forge

```bash
# 初始化项目
npx create-electron-app my-app --template=webpack-typescript

# 打包
npm run make
```

```javascript
// forge.config.js
module.exports = {
  packagerConfig: {
    asar: true,
    icon: './src/assets/icon'
  },
  makers: [
    {
      name: '@electron-forge/maker-squirrel',
      config: {
        name: 'my_app',
        setupIcon: './src/assets/icon.ico'
      }
    },
    {
      name: '@electron-forge/maker-zip',
      platforms: ['darwin']
    },
    {
      name: '@electron-forge/maker-deb',
      config: {
        options: {
          maintainer: 'Your Name',
          homepage: 'https://example.com'
        }
      }
    }
  ]
};
```

### 总结

electron-builder 功能丰富，适合大多数项目；electron-forge 是官方推荐，适合新项目；electron-packager 轻量级，适合小型项目。

:::

## 2. 打包配置详解

::: details
正确的打包配置是成功打包的基础。

### 基本配置

```json
{
  "build": {
    "appId": "com.example.myapp",
    "productName": "My App",
    "copyright": "Copyright © 2024 Example",
    "directories": {
      "output": "dist",
      "buildResources": "build"
    },
    "files": [
      "dist/**/*",
      "package.json",
      "node_modules/**/*"
    ],
    "extraResources": [
      {
        "from": "resources",
        "to": "resources"
      }
    ]
  }
}
```

### 平台特定配置

```json
{
  "build": {
    "mac": {
      "category": "public.app-category.developer-tools",
      "icon": "build/icon.icns",
      "target": ["dmg", "zip"],
      "hardenedRuntime": true,
      "gatekeeperAssess": false,
      "entitlements": "build/entitlements.mac.plist",
      "entitlementsInherit": "build/entitlements.mac.plist"
    },
    "win": {
      "icon": "build/icon.ico",
      "target": ["nsis", "portable"],
      "requestedExecutionLevel": "asInvoker"
    },
    "linux": {
      "icon": "build/icons",
      "target": ["AppImage", "deb"],
      "category": "Development",
      "desktop": {
        "StartupNotify": "true",
        "Terminal": "false"
      }
    }
  }
}
```

### NSIS 配置（Windows 安装程序）

```json
{
  "build": {
    "win": {
      "target": ["nsis"]
    },
    "nsis": {
      "oneClick": false,
      "allowToChangeInstallationDirectory": true,
      "perMachine": true,
      "installerIcon": "build/icon.ico",
      "uninstallerIcon": "build/icon.ico",
      "installerHeaderIcon": "build/icon.ico",
      "createDesktopShortcut": true,
      "createStartMenuShortcut": true,
      "shortcutName": "My App"
    }
  }
}
```

### DMG 配置（macOS 安装程序）

```json
{
  "build": {
    "mac": {
      "target": ["dmg"]
    },
    "dmg": {
      "contents": [
        { "x": 130, "y": 220 },
        { "x": 410, "y": 220, "type": "link", "path": "/Applications" }
      ],
      "window": {
        "width": 540,
        "height": 380
      }
    }
  }
}
```

### AppImage 配置（Linux）

```json
{
  "build": {
    "linux": {
      "target": ["AppImage"],
      "category": "Development"
    },
    "appImage": {
      "systemIntegration": "ask"
    }
  }
}
```

### 总结

打包配置需要根据目标平台进行调整，包括基本配置、平台特定配置、安装程序配置等，正确的配置可以确保打包成功。

:::

## 3. 自动更新

::: details
自动更新是桌面应用的重要功能，Electron 提供了多种自动更新方案。

### electron-updater

```javascript
// main.js
const { autoUpdater } = require('electron-updater');
const { app } = require('electron');

// 配置更新源
autoUpdater.autoDownload = true;
autoUpdater.autoInstallOnAppQuit = true;

// 检查更新
autoUpdater.checkForUpdatesAndNotify();

// 监听更新事件
autoUpdater.on('checking-for-update', () => {
  console.log('检查更新...');
});

autoUpdater.on('update-available', (info) => {
  console.log('有新版本可用:', info.version);
});

autoUpdater.on('update-not-available', () => {
  console.log('当前已是最新版本');
});

autoUpdater.on('download-progress', (progress) => {
  console.log(`下载进度: ${progress.percent}%`);
});

autoUpdater.on('update-downloaded', (info) => {
  console.log('更新下载完成:', info.version);
  
  // 提示用户安装
  dialog.showMessageBox({
    type: 'info',
    title: '更新可用',
    message: `新版本 ${info.version} 已下载完成，是否立即安装？`,
    buttons: ['立即安装', '稍后']
  }).then(({ response }) => {
    if (response === 0) {
      autoUpdater.quitAndInstall();
    }
  });
});

autoUpdater.on('error', (error) => {
  console.error('更新错误:', error);
});
```

### 更新服务器配置

```javascript
// package.json
{
  "build": {
    "publish": {
      "provider": "github",
      "owner": "username",
      "repo": "repository"
    }
  }
}

// 或使用自定义服务器
{
  "build": {
    "publish": {
      "provider": "generic",
      "url": "https://example.com/updates/"
    }
  }
}
```

### 发布版本

```bash
# 安装 electron-builder
npm install electron-builder --save-dev

# 发布到 GitHub
npx electron-builder --publish always

# 发布到自定义服务器
npx electron-builder --publish always --config.publish.url=https://example.com/updates/
```

### 更新流程

```
┌─────────────────────────────────────┐
│           应用启动                   │
└─────────────────────────────────────┘
                    │
                    ↓
┌─────────────────────────────────────┐
│         检查更新                    │
│  autoUpdater.checkForUpdates()      │
└─────────────────────────────────────┘
                    │
                    ↓
┌─────────────────────────────────────┐
│      有新版本？                     │
│  update-available 事件              │
└─────────────────────────────────────┘
                    │
                    ↓
┌─────────────────────────────────────┐
│         下载更新                    │
│  download-progress 事件             │
└─────────────────────────────────────┘
                    │
                    ↓
┌─────────────────────────────────────┐
│         安装更新                    │
│  quitAndInstall()                   │
└─────────────────────────────────────┘
```

### 总结

自动更新可以提升用户体验，electron-updater 是最常用的自动更新方案，支持 GitHub Releases 和自定义服务器。

:::

## 4. 代码签名

::: details
代码签名是确保应用安全性的重要步骤，可以防止应用被篡改。

### macOS 代码签名

```json
{
  "build": {
    "mac": {
      "hardenedRuntime": true,
      "gatekeeperAssess": false,
      "entitlements": "build/entitlements.mac.plist",
      "entitlementsInherit": "build/entitlements.mac.plist",
      "identity": "Developer ID Application: Your Name (TEAM_ID)"
    }
  }
}
```

```xml
<!-- entitlements.mac.plist -->
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>com.apple.security.cs.allow-jit</key>
    <true/>
    <key>com.apple.security.cs.allow-unsigned-executable-memory</key>
    <true/>
    <key>com.apple.security.cs.allow-dyld-environment-variables</key>
    <true/>
</dict>
</plist>
```

### Windows 代码签名

```json
{
  "build": {
    "win": {
      "certificateFile": "cert.pfx",
      "certificatePassword": "password",
      "signingHashAlgorithms": ["sha256"],
      "sign": true
    },
    "nsis": {
      "sign": false
    }
  }
}
```

### 代码签名流程

```bash
# 1. 获取代码签名证书
# macOS: Apple Developer 账号
# Windows: 购买代码签名证书

# 2. 配置环境变量
export CSC_LINK="path/to/cert.pfx"
export CSC_KEY_PASSWORD="password"

# 3. 打包并签名
npx electron-builder --mac --win
```

### 验证签名

```bash
# macOS
codesign --verify --deep --strict "dist/mac/My App.app"

# Windows
signtool verify /pa "dist/My App Setup.exe"
```

### 公证（macOS）

```json
{
  "build": {
    "mac": {
      "notarize": {
        "teamId": "TEAM_ID"
      }
    }
  }
}
```

```bash
# 手动公证
xcrun notarytool submit "dist/MyApp.dmg" --apple-id "apple@example.com" --team-id "TEAM_ID" --wait
```

### 总结

代码签名是确保应用安全性的重要步骤，macOS 和 Windows 都需要代码签名，macOS 还需要公证。

:::

## 5. 打包优化

::: details
打包优化可以减小应用体积，提升下载和安装速度。

### 减小打包体积

```json
{
  "build": {
    "files": [
      "dist/**/*",
      "package.json",
      "!node_modules/**/*",
      "!src/**/*",
      "!test/**/*",
      "!docs/**/*"
    ],
    "asar": true,
    "asarUnpack": [
      "**/*.node"
    ]
  }
}
```

### 依赖优化

```javascript
// package.json
{
  "scripts": {
    "build": "electron-builder",
    "postinstall": "electron-builder install-app-deps"
  },
  "dependencies": {
    "electron-updater": "^6.0.0"
  },
  "devDependencies": {
    "electron": "^43.0.0",
    "electron-builder": "^26.15.0"
  }
}
```

### 树摇优化

```javascript
// webpack.config.js
module.exports = {
  mode: 'production',
  optimization: {
    usedExports: true,
    minimize: true
  }
};
```

### 使用 asar

```json
{
  "build": {
    "asar": true,
    "asarUnpack": [
      "**/*.node",
      "**/*.dll"
    ]
  }
}
```

### 分块打包

```javascript
// main.js
const { app } = require('electron');

// 延迟加载模块
let mainWindow;

app.whenReady().then(() => {
  // 只在需要时加载
  const { BrowserWindow } = require('electron');
  
  mainWindow = new BrowserWindow({
    width: 800,
    height: 600
  });
});
```

### 压缩资源

```bash
# 压缩图片
npm install imagemin-cli -g
imagemin src/assets/**/* --out-dir=dist/assets

# 压缩 JSON
npm install jsonminify -g
jsonminify src/**/*.json > dist/**/*.json
```

### 分析打包体积

```bash
# 安装分析工具
npm install webpack-bundle-analyzer --save-dev

# 分析打包结果
npx webpack-bundle-analyzer dist/stats.json
```

### 总结

打包优化包括减小打包体积、依赖优化、树摇优化、使用 asar、分块打包、压缩资源等，这些优化可以显著减小应用体积。

:::
