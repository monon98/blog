# Electron 安全性

## 1. 安全威胁与风险

::: details
了解 Electron 应用的安全威胁是构建安全应用的第一步。

### 常见安全威胁

| 威胁 | 说明 | 风险等级 |
|------|------|----------|
| 代码注入 | 恶意代码通过用户输入注入 | 高 |
| XSS 攻击 | 跨站脚本攻击 | 高 |
| 远程代码执行 | 攻击者执行任意代码 | 极高 |
| 数据泄露 | 敏感数据被窃取 | 高 |
| 权限提升 | 获取不必要的系统权限 | 中 |

### 攻击向量

```javascript
// 1. 通过 webview 注入
<webview src="untrusted-site.com"></webview>

// 2. 通过 IPC 通信
ipcRenderer.send('execute-code', userInput);

// 3. 通过外部链接
shell.openExternal('malicious-protocol://...');

// 4. 通过文件操作
fs.readFile(userProvidedPath);
```

### 安全原则

1. **最小权限原则**：只授予必要的权限
2. **输入验证**：验证所有用户输入
3. **输出编码**：对输出进行编码处理
4. **深度防御**：多层安全防护

### 总结

Electron 应用面临多种安全威胁，需要采用多层防御策略来保护应用和用户数据。

:::

## 2. 安全配置

::: details
正确的配置是 Electron 应用安全的基础。

### BrowserWindow 安全配置

```javascript
const win = new BrowserWindow({
  webPreferences: {
    // 安全配置
    nodeIntegration: false,        // 禁用 Node.js 集成
    contextIsolation: true,        // 启用上下文隔离
    sandbox: true,                 // 启用沙箱
    webSecurity: true,             // 启用 Web 安全
    allowRunningInsecureContent: false,  // 禁止不安全内容
    experimentalFeatures: false,   // 禁用实验性功能
    webviewTag: false,             // 禁用 webview 标签（如需使用请评估安全风险）
    
    // 预加载脚本
    preload: path.join(__dirname, 'preload.js')
  }
});

// 注意：内置 remote 模块已移除。如需使用请安装 @electron/remote，但官方强烈不推荐
```

### CSP 配置

```html
<!-- index.html -->
<meta http-equiv="Content-Security-Policy" content="
  default-src 'self';
  script-src 'self';
  style-src 'self' 'unsafe-inline';
  img-src 'self' data:;
  font-src 'self';
  connect-src 'self' https://api.example.com;
  frame-src 'none';
  object-src 'none';
">
```

### 动态 CSP

```javascript
// main.js
const { session } = require('electron');

session.defaultSession.webRequest.onHeadersReceived((details, callback) => {
  callback({
    responseHeaders: {
      ...details.responseHeaders,
      'Content-Security-Policy': ["default-src 'self'; script-src 'self'"]
    }
  });
});
```

### 禁用危险功能

```javascript
// 禁用 Web 视图
webPreferences: {
  webviewTag: false
}

// 禁用导航
win.webContents.on('will-navigate', (event) => {
  event.preventDefault();
});

// 禁用新窗口
win.webContents.setWindowOpenHandler(() => {
  return { action: 'deny' };
});
```

### 总结

安全配置是 Electron 应用安全的基础，应该始终遵循安全最佳实践，禁用不必要的功能，启用必要的安全特性。

:::

## 3. 预加载脚本安全

::: details
预加载脚本是 Electron 安全架构的核心，正确编写预加载脚本至关重要。

### 安全暴露 API

```javascript
// preload.js
const { contextBridge, ipcRenderer } = require('electron');

// 白名单通道
const allowedChannels = {
  send: ['to-main'],
  invoke: ['get-data', 'save-data'],
  receive: ['from-main']
};

contextBridge.exposeInMainWorld('electronAPI', {
  // 安全的发送函数
  send: (channel, data) => {
    if (!allowedChannels.send.includes(channel)) {
      throw new Error(`Invalid channel: ${channel}`);
    }
    
    // 验证数据类型
    if (typeof data !== 'object' || data === null) {
      throw new Error('Data must be an object');
    }
    
    ipcRenderer.send(channel, data);
  },
  
  // 安全的调用函数
  invoke: async (channel, data) => {
    if (!allowedChannels.invoke.includes(channel)) {
      throw new Error(`Invalid channel: ${channel}`);
    }
    
    return await ipcRenderer.invoke(channel, data);
  },
  
  // 安全的接收函数
  receive: (channel, callback) => {
    if (!allowedChannels.receive.includes(channel)) {
      throw new Error(`Invalid channel: ${channel}`);
    }
    
    const subscription = (event, ...args) => callback(...args);
    ipcRenderer.on(channel, subscription);
    
    return () => {
      ipcRenderer.removeListener(channel, subscription);
    };
  }
});
```

### 数据验证

```javascript
// preload.js
const { contextBridge, ipcRenderer } = require('electron');

// 验证函数
const validators = {
  'get-data': (data) => {
    if (!data || typeof data !== 'object') {
      throw new Error('Invalid data');
    }
    if (typeof data.id !== 'number') {
      throw new Error('ID must be a number');
    }
    return true;
  }
};

contextBridge.exposeInMainWorld('electronAPI', {
  invoke: async (channel, data) => {
    // 验证通道
    if (!['get-data'].includes(channel)) {
      throw new Error('Invalid channel');
    }
    
    // 验证数据
    if (validators[channel]) {
      validators[channel](data);
    }
    
    return await ipcRenderer.invoke(channel, data);
  }
});
```

### 防止原型污染

```javascript
// preload.js
function sanitize(data) {
  if (typeof data !== 'object' || data === null) {
    return data;
  }
  
  // 移除危险属性
  const dangerousKeys = ['__proto__', 'constructor', 'prototype'];
  const sanitized = {};
  
  for (const key of Object.keys(data)) {
    if (!dangerousKeys.includes(key)) {
      sanitized[key] = sanitize(data[key]);
    }
  }
  
  return sanitized;
}

contextBridge.exposeInMainWorld('electronAPI', {
  invoke: async (channel, data) => {
    const sanitizedData = sanitize(data);
    return await ipcRenderer.invoke(channel, sanitizedData);
  }
});
```

### 总结

预加载脚本安全是 Electron 应用安全的核心，应该使用白名单机制、数据验证、防止原型污染等技术来确保预加载脚本的安全性。

:::

## 4. IPC 通信安全

::: details
IPC 通信是 Electron 应用安全的关键环节，需要采取多种措施确保通信安全。

### 通道验证

```javascript
// main.js
const { ipcMain } = require('electron');

// 验证通道名
const allowedChannels = new Set(['get-data', 'save-data']);

ipcMain.handle('secure-channel', async (event, data) => {
  // 验证发送者
  const senderWebContents = event.sender;
  const senderUrl = senderWebContents.getURL();
  
  if (!senderUrl.startsWith('file://')) {
    throw new Error('Invalid sender');
  }
  
  return { success: true };
});
```

### 数据验证

```javascript
// main.js
ipcMain.handle('process-data', async (event, data) => {
  // 验证数据类型
  if (typeof data !== 'object' || data === null) {
    throw new Error('Invalid data type');
  }
  
  // 验证必需字段
  if (!data.id || typeof data.id !== 'number') {
    throw new Error('Invalid ID');
  }
  
  // 验证数据范围
  if (data.id < 1 || data.id > 1000) {
    throw new Error('ID out of range');
  }
  
  // 处理数据
  return await processData(data);
});
```

### 防止重放攻击

```javascript
// preload.js
let nonce = 0;

contextBridge.exposeInMainWorld('electronAPI', {
  invoke: async (channel, data) => {
    const message = {
      ...data,
      nonce: nonce++,
      timestamp: Date.now()
    };
    
    return await ipcRenderer.invoke(channel, message);
  }
});

// main.js
ipcMain.handle('secure-operation', async (event, data) => {
  // 验证时间戳（5分钟有效期）
  if (Date.now() - data.timestamp > 5 * 60 * 1000) {
    throw new Error('Message expired');
  }
  
  // 验证 nonce（防止重放）
  if (usedNonces.has(data.nonce)) {
    throw new Error('Nonce already used');
  }
  usedNonces.add(data.nonce);
  
  return { success: true };
});
```

### 速率限制

```javascript
// main.js
const rateLimiter = new Map();

ipcMain.handle('rate-limited-operation', async (event, data) => {
  const senderId = event.sender.id;
  const now = Date.now();
  
  // 检查速率限制
  if (!rateLimiter.has(senderId)) {
    rateLimiter.set(senderId, { count: 1, resetTime: now + 60000 });
  } else {
    const limiter = rateLimiter.get(senderId);
    
    if (now > limiter.resetTime) {
      limiter.count = 1;
      limiter.resetTime = now + 60000;
    } else if (limiter.count >= 100) {
      throw new Error('Rate limit exceeded');
    } else {
      limiter.count++;
    }
  }
  
  return { success: true };
});
```

### 总结

IPC 通信安全需要验证通道、验证数据、防止重放攻击、限制速率等措施，确保通信的安全性和可靠性。

:::

## 5. 安全审计与检测

::: details
定期进行安全审计和检测可以帮助发现和修复潜在的安全问题。

### 自动化安全检测

```javascript
// scripts/security-audit.js
const { ESLint } = require('eslint');

async function runSecurityAudit() {
  const eslint = new ESLint({
    overrideConfig: {
      rules: {
        'no-eval': 'error',
        'no-implied-eval': 'error',
        'no-new-func': 'error',
        'no-script-url': 'error'
      }
    }
  });
  
  const results = await eslint.lintFiles(['src/**/*.js']);
  console.log(results);
}
```

### 运行时安全检测

```javascript
// main.js
const { app } = require('electron');

// 检测调试模式
if (app.isPackaged === false) {
  console.warn('Application is running in development mode');
}

// 检测安全配置
function checkSecurityConfig() {
  const warnings = [];
  
  if (process.env.NODE_ENV !== 'production') {
    warnings.push('Not running in production mode');
  }
  
  return warnings;
}

// 定期检查
setInterval(() => {
  const warnings = checkSecurityConfig();
  if (warnings.length > 0) {
    console.warn('Security warnings:', warnings);
  }
}, 60000);
```
