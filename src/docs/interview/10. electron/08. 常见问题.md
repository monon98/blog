# 常见问题

## 1. 开发环境问题

::: details
开发环境问题是 Electron 开发中最常见的问题之一。

### 1. Electron 安装失败

**问题**：`npm install electron` 失败

**解决方案**：
```bash
# 使用镜像源
npm config set electron_mirror https://npmmirror.com/mirrors/electron/

# 清除缓存
npm cache clean --force

# 重新安装
npm install electron
```

### 2. 白屏问题

**问题**：应用启动后显示白屏

**解决方案**：
```javascript
// 检查路径
console.log(__dirname);
console.log(path.join(__dirname, 'index.html'));

// 检查 webPreferences
const win = new BrowserWindow({
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true
  }
});

// 打开开发者工具调试
win.webContents.openDevTools();
```

### 3. 开发者工具无法打开

**问题**：`win.webContents.openDevTools()` 不生效

**解决方案**：
```javascript
// 确保在 ready-to-show 之后打开
win.once('ready-to-show', () => {
  win.webContents.openDevTools();
});

// 或使用快捷键
globalShortcut.register('F12', () => {
  win.webContents.openDevTools();
});
```

### 4. 热重载不工作

**问题**：代码修改后应用不自动更新

**解决方案**：
```javascript
// 安装 electron-reload
npm install electron-reload

// 在 main.js 中引入
require('electron-reload')(__dirname, {
  electron: require(path.join(__dirname, 'node_modules', 'electron'))
});
```

### 总结

开发环境问题通常与配置、路径、依赖相关，通过检查配置、使用镜像源、打开开发者工具等方法可以解决大部分问题。

:::

## 2. 打包问题

::: details
打包问题通常与配置、依赖、平台相关。

### 1. 打包失败

**问题**：`electron-builder` 打包失败

**解决方案**：
```bash
# 清除缓存
rm -rf node_modules
rm -rf dist
npm install

# 检查配置
npx electron-builder --dir

# 使用详细日志
DEBUG=electron-builder npx electron-builder
```

### 2. 打包后应用无法运行

**问题**：打包后的应用无法启动

**解决方案**：
```javascript
// 检查文件路径
console.log(app.getPath('exe'));

// 检查资源路径
const resourcesPath = app.isPackaged
  ? path.join(process.resourcesPath)
  : __dirname;

// 检查 preload 脚本路径
const preloadPath = app.isPackaged
  ? path.join(process.resourcesPath, 'preload.js')
  : path.join(__dirname, 'preload.js');
```

### 3. 图标问题

**问题**：打包后应用图标不显示

**解决方案**：
```json
// macOS
{
  "build": {
    "mac": {
      "icon": "build/icon.icns"
    }
  }
}

// Windows
{
  "build": {
    "win": {
      "icon": "build/icon.ico"
    }
  }
}

// Linux
{
  "build": {
    "linux": {
      "icon": "build/icons"
    }
  }
}
```

### 4. 依赖问题

**问题**：打包后缺少依赖

**解决方案**：
```json
// 检查 files 配置
{
  "build": {
    "files": [
      "dist/**/*",
      "package.json",
      "!node_modules/**/*"
    ]
  }
}

// 使用 extraResources
{
  "build": {
    "extraResources": [
      {
        "from": "resources",
        "to": "resources"
      }
    ]
  }
}
```

### 总结

打包问题通常与配置、依赖、平台相关，通过检查配置、清除缓存、使用详细日志等方法可以解决大部分问题。

:::

## 3. 安全问题

::: details
安全问题是 Electron 应用开发中需要特别关注的问题。

### 1. XSS 攻击

**问题**：渲染进程中存在 XSS 漏洞

**解决方案**：
```javascript
// 使用 CSP
// index.html
<meta http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self'">

// 验证用户输入
function sanitize(input) {
  return input.replace(/[<>'"&]/g, (match) => {
    const entities = {
      '<': '&lt;',
      '>': '&gt;',
      '"': '&quot;',
      "'": '&#39;',
      '&': '&amp;'
    };
    return entities[match];
  });
}
```

### 2. 远程代码执行

**问题**：渲染进程中可以执行任意代码

**解决方案**：
```javascript
// 禁用 nodeIntegration
const win = new BrowserWindow({
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true
  }
});

// 使用预加载脚本暴露安全的 API
contextBridge.exposeInMainWorld('myAPI', {
  readFile: (path) => ipcRenderer.invoke('read-file', path)
});
```

### 3. 数据泄露

**问题**：敏感数据被泄露

**解决方案**：
```javascript
// 不在日志中输出敏感数据
console.log('用户登录成功');

// 使用安全的存储
const Store = require('electron-store');
const store = new Store({
  encryptionKey: 'your-secret-key'
});

// 加密敏感数据
const crypto = require('crypto');

function encrypt(data) {
  const key = crypto.scryptSync('secret-key', 'salt', 32);
  const iv = crypto.randomBytes(16);
  const cipher = crypto.createCipheriv('aes-256-cbc', key, iv);
  let encrypted = cipher.update(JSON.stringify(data), 'utf8', 'hex');
  encrypted += cipher.final('hex');
  return { iv: iv.toString('hex'), encrypted };
}
```

### 4. 权限提升

**问题**：应用请求了不必要的权限

**解决方案**：
```javascript
// 最小权限原则
const win = new BrowserWindow({
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true,
    sandbox: true
  }
});

// 验证 IPC 通信
ipcMain.handle('risky-operation', async (event, data) => {
  // 验证发送者
  const senderUrl = event.sender.getURL();
  if (!senderUrl.startsWith('file://')) {
    throw new Error('Invalid sender');
  }
  
  return { success: true };
});
```

### 总结

安全问题需要从多个层面考虑，包括 XSS 攻击、远程代码执行、数据泄露、权限提升等，通过正确的配置和编码实践可以有效防止安全问题。

:::

## 4. 性能问题

::: details
性能问题是 Electron 应用开发中需要关注的重要问题。

### 1. 启动速度慢

**问题**：应用启动时间过长

**解决方案**：
```javascript
// 延迟加载模块
app.whenReady().then(() => {
  // 只在需要时加载
  const { BrowserWindow } = require('electron');
  
  const win = new BrowserWindow({
    width: 800,
    height: 600
  });
  
  win.loadFile('index.html');
});

// 使用 V8 缓存
app.commandLine.appendSwitch('v8-cache');
```

### 2. 内存占用高

**问题**：应用内存占用过高

**解决方案**：
```javascript
// 监控内存使用
setInterval(() => {
  const memory = process.memoryUsage();
  console.log(`内存使用: ${memory.heapUsed / 1024 / 1024} MB`);
}, 60000);

// 释放未使用的资源
function cleanup() {
  // 清理事件监听器
  // 清理定时器
  // 清理缓存
}

// 定期清理
setInterval(cleanup, 300000);
```

### 3. 渲染卡顿

**问题**：页面渲染卡顿

**解决方案**：
```javascript
// 使用虚拟滚动
// 使用 Web Workers
// 使用 Canvas 替代 DOM

// 检查重绘
win.webContents.on('paint', (event, dirty, image) => {
  console.log('重绘区域:', dirty);
});
```

### 4. IPC 通信慢

**问题**：IPC 通信延迟高

**解决方案**：
```javascript
// 减少通信频率
// 使用 SharedArrayBuffer
// 使用 MessageChannel

// 使用结构化克隆
const data = { /* 大量数据 */ };
ipcRenderer.send('data', data);
// Electron 内部使用结构化克隆，比 JSON 更高效
```

### 总结

性能问题需要从多个方面考虑，包括启动速度、内存占用、渲染卡顿、IPC 通信等，通过延迟加载、监控内存、优化渲染、减少通信等方法可以有效提升性能。

## 5. 跨平台问题

::: details
跨平台问题是 Electron 应用开发中需要特别关注的问题。

### 1. 路径问题

**问题**：不同平台的路径分隔符不同

**解决方案**：
```javascript
// 使用 path 模块
const path = require('path');

const filePath = path.join(__dirname, 'data', 'file.txt');

// 使用 app.getPath
const userDataPath = app.getPath('userData');
```

### 2. 快捷键问题

**问题**：不同平台的快捷键不同

**解决方案**：
```javascript
// 使用条件判断
const modifier = process.platform === 'darwin' ? 'Cmd' : 'Ctrl';

globalShortcut.register(`${modifier}+S`, () => {
  // 保存
});

// 或使用 electron-localshortcut
const localShortcut = require('electron-localshortcut');

localShortcut.register(win, 'CmdOrCtrl+S', () => {
  // 保存
});
```

### 3. 菜单问题

**问题**：不同平台的菜单样式不同

**解决方案**：
```javascript
// 使用条件判断
const template = [
  ...(process.platform === 'darwin' ? [
    {
      label: app.name,
      submenu: [
        { role: 'about' },
        { type: 'separator' },
        { role: 'services' },
        { type: 'separator' },
        { role: 'hide' },
        { role: 'hideOthers' },
        { role: 'unhide' },
        { type: 'separator' },
        { role: 'quit' }
      ]
    }
  ] : []),
  // 其他菜单项
];

const menu = Menu.buildFromTemplate(template);
Menu.setApplicationMenu(menu);
```

### 4. 窗口样式问题

**问题**：不同平台的窗口样式不同

**解决方案**：
```javascript
// 使用条件判断
const win = new BrowserWindow({
  titleBarStyle: process.platform === 'darwin' ? 'hiddenInset' : 'default',
  frame: process.platform !== 'win32' || true
});
```

### 5. 打包问题

**问题**：不同平台的打包配置不同

**解决方案**：
```json
{
  "build": {
    "mac": {
      "icon": "build/icon.icns",
      "target": ["dmg", "zip"]
    },
    "win": {
      "icon": "build/icon.ico",
      "target": ["nsis", "portable"]
    },
    "linux": {
      "icon": "build/icons",
      "target": ["AppImage", "deb"]
    }
  }
}
```

### 总结

跨平台问题需要针对不同平台进行适配，通过使用 path 模块、条件判断、平台特定配置等方法可以解决大部分跨平台问题。

:::
