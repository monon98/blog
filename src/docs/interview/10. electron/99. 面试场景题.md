# 面试场景题

## 1. 主进程与渲染进程通信

::: details
**问题**：Electron 中主进程和渲染进程如何通信？

### IPC 通信方式

- ipcMain.handle：渲染进程调用主进程方法
- ipcMain.on：渲染进程发送消息到主进程
- webContents.send：主进程发送消息到渲染进程

### 使用场景

- 文件操作：渲染进程请求主进程读写文件
- 系统信息：获取系统信息
- 窗口管理：控制窗口行为
- 托盘操作：托盘菜单交互

### 安全建议

- 使用 contextBridge 暴露 API
- 禁用 nodeIntegration
- 启用 contextIsolation

:::

## 2. 窗口管理

::: details
**问题**：如何管理多个窗口？

### 窗口类型

- BrowserWindow：主窗口
- WebContentsView：嵌入式视图（推荐）
- BrowserView：嵌入式视图（Electron 33+ 已废弃）

### 窗口管理

- 创建窗口：new BrowserWindow()
- 关闭窗口：win.close()
- 最小化/最大化：win.minimize()/win.maximize()
- 窗口间通信：通过主进程中转

### 最佳实践

- 使用单例模式管理窗口
- 保存窗口状态
- 处理窗口关闭事件

:::

## 6. 安全配置

::: details
**问题**：如何提高 Electron 应用的安全性？

### 安全配置

- 禁用 nodeIntegration
- 启用 contextIsolation
- 使用 preload 脚本
- 启用 CSP（内容安全策略）

### 权限管理

- 禁用不必要的 API
- 限制远程模块
- 验证加载的 URL
- 处理协议请求

### 最小权限原则

- 只暴露必要的 API
- 验证所有输入
- 使用 HTTPS
- 定期更新依赖
