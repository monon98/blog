# 面试场景题

## 1. 手写 Koa 中间件

::: details
**问题**：实现一个类似 Koa 的洋葱模型中间件机制。

### 核心概念

- 中间件是处理请求的函数
- 支持洋葱模型（先进后出）
- 支持 async/await

### 实现思路

- 使用数组存储中间件
- 实现 compose 函数组合中间件
- 支持 next 调用下一个中间件
- 支持 ctx 上下文传递

### 执行顺序

```
请求 → 中间件1 → 中间件2 → 中间件3 → 响应
```

:::

## 4. 手写 JWT 验证

::: details
**问题**：实现一个 JWT（JSON Web Token）验证机制。

### JWT 结构

- Header：算法和类型
- Payload：数据
- Signature：签名

### 实现要点

- 使用 crypto 模块
- 支持 HS256 算法
- 支持验证签名
- 支持检查过期时间

### 使用场景

- 用户认证
- API 授权
- 单点登录

:::

## 5. 手写限流器

::: details
**问题**：实现一个 API 限流器。

### 限流算法

- 固定窗口：简单但有边界问题
- 滑动窗口：更平滑
- 令牌桶：允许突发流量
- 漏桶：平滑流量

### 实现要点

- 使用内存存储计数
- 支持配置窗口大小
- 支持配置限制次数
- 支持 Redis 存储（生产环境）

:::
