# 错误处理与安全

## 1. 错误处理

::: details
Express 提供了灵活的错误处理机制。

### 同步错误处理

```javascript
app.get('/user/:id', (req, res) => {
  const user = findUser(req.params.id);
  if (!user) {
    const error = new Error('用户不存在');
    error.status = 404;
    throw error;  // Express 会自动捕获
  }
  res.json(user);
});
```

### 异步错误处理

```javascript
// Express 5 支持自动捕获异步错误
app.get('/user/:id', async (req, res) => {
  const user = await findUser(req.params.id);
  if (!user) {
    throw new AppError('用户不存在', 404);
  }
  res.json(user);
});

// Express 4 需要手动捕获
app.get('/user/:id', async (req, res, next) => {
  try {
    const user = await findUser(req.params.id);
    if (!user) {
      throw new AppError('用户不存在', 404);
    }
    res.json(user);
  } catch (error) {
    next(error);
  }
});
```

### 错误分类

| 类型 | 状态码 | 示例 |
|------|--------|------|
| 客户端错误 | 4xx | 请求参数错误、未授权 |
| 服务器错误 | 5xx | 数据库连接失败、内部错误 |

### 总结

正确的错误处理可以提高应用的稳定性和用户体验。

## 2. 安全实践

::: details
Web 应用需要关注多种安全问题。

### HTTPS

```javascript
const https = require('https');
const fs = require('fs');

const options = {
  key: fs.readFileSync('private-key.pem'),
  cert: fs.readFileSync('certificate.pem')
};

https.createServer(options, app).listen(443);
```

### 安全头

```javascript
const helmet = require('helmet');

app.use(helmet());

// 等效于
app.use(helmet.contentSecurityPolicy());
app.use(helmet.hsts());
app.use(helmet.noSniff());
// ... 等多个安全头
```

### CORS 配置

```javascript
const cors = require('cors');

// 限制来源
app.use(cors({
  origin: ['https://example.com', 'https://admin.example.com'],
  methods: ['GET', 'POST'],
  allowedHeaders: ['Content-Type', 'Authorization'],
  credentials: true,
  maxAge: 86400  // 预检请求缓存 1 天
}));
```

### 总结

安全是 Web 应用开发的重要环节。

## 3. 常见攻击防护

::: details
常见的 Web 攻击及防护措施。

### SQL 注入

```javascript
// 不安全
const query = `SELECT * FROM users WHERE id = ${req.params.id}`;

// 安全（使用参数化查询）
const query = 'SELECT * FROM users WHERE id = ?';
db.query(query, [req.params.id]);
```

### XSS 攻击

```javascript
// 使用 helmet 防护
app.use(helmet());

// 输入过滤
const sanitize = require('sanitize-html');

const clean = sanitize(userInput, {
  allowedTags: ['b', 'i', 'em', 'strong'],
  allowedAttributes: {}
});
```

### CSRF 攻击

```javascript
// 使用 csrf-csrf（现代方案，替代已废弃的 csurf）
const { csrfSync } = require('csrf-csrf');
const { doubleCsrf } = csrfSync({
  getSecret: () => 'your-secret-key',
  cookieName: 'csrf-token'
});

app.use(doubleCsrf);

app.get('/form', (req, res) => {
  res.render('form', { csrfToken: req.csrfToken() });
});

app.post('/form', (req, res) => {
  // CSRF 令牌验证自动完成
});
```

::: warning
`csurf` 包已被 Express 团队废弃，推荐使用 `csrf-csrf` 或 `csrf-sync`。
:::

### 限流

```javascript
const rateLimit = require('express-rate-limit');

// 全局限流
app.use(rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100
}));

// 登录限流（更严格）
const loginLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 5,
  message: '登录尝试过多，请稍后再试'
});

app.post('/login', loginLimiter, loginHandler);
```

### 总结

了解常见攻击并采取防护措施是必要的。

## 4. 环境配置

::: details
不同环境的配置管理。

### 环境变量

```javascript
// config/index.js
require('dotenv').config();

module.exports = {
  development: {
    port: 3000,
    database: 'mongodb://localhost/dev'
  },
  production: {
    port: process.env.PORT,
    database: process.env.DATABASE_URL
  }
};

const env = process.env.NODE_ENV || 'development';
module.exports = module.exports[env];
```

### .env 文件

```bash
# .env
PORT=3000
DATABASE_URL=mongodb://localhost/myapp
JWT_SECRET=your-secret-key

# .env.production
PORT=80
DATABASE_URL=mongodb://production/db
JWT_SECRET=production-secret
```

### 环境管理

```javascript

// 生产环境

// 或使用 pm2
pm2 start ecosystem.config.js --env production
```

### 总结

环境配置管理是部署和运维的基础。

## 5. 测试

## 6. Cookie 与 Session

::: details
Cookie 和 Session 是 Web 应用状态管理的基础。

### Cookie

```javascript
const cookieParser = require('cookie-parser');

app.use(cookieParser());

// 设置 Cookie
app.get('/set-cookie', (req, res) => {
  res.cookie('token', 'abc123', {
    httpOnly: true,    // 禁止 JavaScript 访问
    secure: true,      // 仅 HTTPS
    maxAge: 3600000,   // 过期时间 1 小时
    sameSite: 'strict' // 防 CSRF
  });
  res.send('Cookie 已设置');
});

// 读取 Cookie
app.get('/get-cookie', (req, res) => {
  const token = req.cookies.token;
  res.json({ token });
});

// 清除 Cookie
app.get('/clear-cookie', (req, res) => {
  res.clearCookie('token');
  res.send('Cookie 已清除');
});
```

### Session

```javascript
const session = require('express-session');

app.use(session({
  secret: process.env.SESSION_SECRET,
  resave: false,
  saveUninitialized: false,
  cookie: {
    secure: process.env.NODE_ENV === 'production',
    httpOnly: true,
    maxAge: 24 * 60 * 60 * 1000  // 1 天
  }
}));

// 使用 Session
app.post('/login', (req, res) => {
  req.session.user = { id: 1, name: '张三' };
  res.json({ success: true });
});

app.get('/profile', (req, res) => {
  if (!req.session.user) {
    return res.status(401).json({ error: '未登录' });
  }
  res.json(req.session.user);
});

// Session 存储（生产环境）
const RedisStore = require('connect-redis').default;

app.use(session({
  store: new RedisStore({ client: redisClient }),
  secret: 'your-secret'
}));
```

### JWT vs Session

| 特性 | JWT | Session |
|------|-----|---------|
| 存储位置 | 客户端 | 服务端 |
| 扩展性 | 天然支持分布式 | 需要共享存储 |
| 安全性 | 可被窃取 | 服务端可控 |
| 适用场景 | API、微服务 | 传统 Web 应用 |

## 7. 优雅关闭

::: details
生产环境必须实现优雅关闭。

### 基本实现

```javascript
const gracefulShutdown = (server) => {
  const shutdown = (signal) => {
    console.log(`收到 ${signal}，开始优雅关闭`);
    
    server.close(() => {
      console.log('服务器已关闭');
      process.exit(0);
    });
    
    setTimeout(() => {
      console.error('关闭超时，强制退出');
      process.exit(1);
    }, 10000);
  };
  
  process.on('SIGTERM', () => shutdown('SIGTERM'));
  process.on('SIGINT', () => shutdown('SIGINT'));
};
```

### 使用方式

```javascript
const app = require('./app');
const server = app.listen(3000);

gracefulShutdown(server);
```

### 清理资源

```javascript
const gracefulShutdown = async (server) => {
  // 1. 停止接受新连接
  server.close();
  
  // 2. 关闭数据库连接
  await mongoose.disconnect();
  
  // 3. 关闭 Redis 连接
  await redis.quit();
  
  // 4. 清理定时器等
  clearInterval(heartbeatTimer);
  
  console.log('资源清理完成，服务器关闭');
  process.exit(0);
};
```
