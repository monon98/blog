# 中间件

## 1. 中间件基础

::: details
中间件是 Express 的核心概念，在请求和响应之间执行。

### 中间件函数

```javascript
// 基本中间件
const logger = (req, res, next) => {
  console.log(`${req.method} ${req.url}`);
  next();  // 必须调用 next() 继续执行
};

app.use(logger);
```

### 执行顺序

```javascript
app.use((req, res, next) => {
  console.log('中间件 1');
  next();
});

app.use((req, res, next) => {
  console.log('中间件 2');
  next();
});

app.get('/', (req, res) => {
  console.log('路由处理');
  res.send('OK');
});

// 输出顺序：中间件 1 → 中间件 2 → 路由处理
```

### 中间件类型

| 类型 | 说明 |
|------|------|
| 应用级 | `app.use()` |
| 路由级 | `router.use()` |
| 错误处理 | 4 个参数的函数 |
| 第三方 | `helmet`、`cors` 等 |

### 总结

中间件是 Express 处理请求的核心机制。

:::

## 2. 内置中间件

::: details
Express 提供了几个内置中间件。

### express.json()

```javascript
// 解析 JSON 请求体
app.use(express.json());

// 支持自定义限制
app.use(express.json({ limit: '10mb' }));
```

### express.urlencoded()

```javascript
// 解析 URL 编码的请求体
app.use(express.urlencoded({ extended: true }));

// extended: true 使用 qs 库解析
// extended: false 使用 querystring 库解析
```

### express.static()

```javascript
// 托管静态文件
app.use(express.static('public'));
```

### 总结

内置中间件满足了常见的基本需求。

:::

## 3. 第三方中间件

::: details
Express 生态提供了丰富的第三方中间件。

### 常用中间件

```javascript
// helmet - 安全头
const helmet = require('helmet');
app.use(helmet());

// cors - 跨域
const cors = require('cors');
app.use(cors());

// morgan - 日志
const morgan = require('morgan');
app.use(morgan('combined'));

// express-rate-limit - 限流
const rateLimit = require('express-rate-limit');
app.use(rateLimit({
  windowMs: 15 * 60 * 1000,  // 15 分钟
  max: 100  // 限制 100 次
}));
```

### 中间件配置

```javascript
// CORS 配置
app.use(cors({
  origin: 'http://localhost:3000',
  methods: ['GET', 'POST', 'PUT', 'DELETE'],
  allowedHeaders: ['Content-Type', 'Authorization']
}));

// 限流配置
const apiLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100,
  message: '请求过于频繁'
});

app.use('/api/', apiLimiter);
```

### 总结

第三方中间件扩展了 Express 的功能，选择合适的中间件很重要。

:::

## 4. 自定义中间件

::: details
根据业务需求创建自定义中间件。

### 认证中间件

```javascript
const jwt = require('jsonwebtoken');

const auth = (req, res, next) => {
  const token = req.header('Authorization')?.replace('Bearer ', '');
  
  if (!token) {
    return res.status(401).json({ error: '未登录' });
  }
  
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;
    next();
  } catch (error) {
    res.status(401).json({ error: 'token 无效' });
  }
};

// 使用
app.get('/api/profile', auth, (req, res) => {
  res.json(req.user);
});
```

### 权限中间件

```javascript
const authorize = (...roles) => {
  return (req, res, next) => {
    if (!roles.includes(req.user.role)) {
      return res.status(403).json({ error: '无权限' });
    }
    next();
  };
};

// 使用
app.delete('/api/users/:id',
  auth,
  authorize('admin'),
  (req, res) => {
    // 只有管理员可以删除用户
  }
);
```

### 验证中间件

```javascript
const { body, validationResult } = require('express-validator');

const validateUser = [
  body('name').notEmpty().withMessage('名称不能为空'),
  body('email').isEmail().withMessage('邮箱格式不正确'),
  body('password').isLength({ min: 6 }).withMessage('密码至少 6 位'),
  
  (req, res, next) => {
    const errors = validationResult(req);
    if (!errors.isEmpty()) {
      return res.status(400).json({ errors: errors.array() });
    }
    next();
  }
];

// 使用
app.post('/api/users', validateUser, (req, res) => {
  // 验证通过
});
```

### 日志中间件

```javascript
const fs = require('fs');

const accessLogStream = fs.createWriteStream(
  path.join(__dirname, 'access.log'),
  { flags: 'a' }
);

const morgan = require('morgan');
app.use(morgan('combined', { stream: accessLogStream }));
```

### 总结

自定义中间件可以实现认证、授权、验证等业务逻辑。

:::

## 5. 错误处理中间件

::: details
Express 有专门的错误处理中间件。

### 错误处理中间件

```javascript
// 4 个参数的函数
app.use((err, req, res, next) => {
  console.error(err.stack);
  
  res.status(err.status || 500).json({
    error: {
      message: err.message || '服务器错误',
      status: err.status || 500
    }
  });
});
```

### 自定义错误类

```javascript
class AppError extends Error {
  constructor(message, statusCode) {
    super(message);
    this.statusCode = statusCode;
    this.status = `${statusCode}`.startsWith('4') ? 'fail' : 'error';
  }
}

// 使用
app.get('/api/users/:id', async (req, res, next) => {
  try {
    const user = await User.findById(req.params.id);
    if (!user) {
      throw new AppError('用户不存在', 404);
    }
    res.json(user);
  } catch (error) {
    next(error);
  }
});
```

### 异步错误处理

```javascript
// 封装异步函数，自动捕获错误
const asyncHandler = (fn) => (req, res, next) => {
  Promise.resolve(fn(req, res, next)).catch(next);
};

// 使用
app.get('/api/users', asyncHandler(async (req, res) => {
  const users = await User.find();
  res.json(users);
}));
```

### 总结

错误处理中间件是保证应用稳定性的关键。

:::
