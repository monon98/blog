# 基础概念

## 1. 什么是 Express

::: details
Express 是基于 Node.js 的轻量级 Web 应用框架。

### 核心特点

| 特点 | 说明 |
|------|------|
| 轻量 | 核心代码精简，无强制依赖 |
| 灵活 | 中间件架构，高度可扩展 |
| 流行 | Node.js 最流行的 Web 框架 |
| 生态 | 丰富的中间件和工具库 |

### 基本使用

```javascript
const express = require('express');
const app = express();

// 基本路由
app.get('/', (req, res) => {
  res.send('Hello World');
});

// 启动服务器
app.listen(3000, () => {
  console.log('服务器启动: http://localhost:3000');
});
```

### 与 Koa 对比

| 特性 | Express | Koa |
|------|---------|-----|
| 版本 | 5.x（当前最新） | 2.x |
| 中间件 | 基于回调 | 基于 async/await |
| 上下文 | `req`/`res` | `ctx` |
| 错误处理 | Express 5 自动捕获异步错误 | 自动捕获 |

::: tip
Express 5.0 于 2024 年 9 月发布，2025 年 3 月成为 npm 默认版本。主要变化：路径匹配变更、async 错误自动捕获、废弃 API 移除。
:::

### 总结

Express 是 Node.js Web 开发的事实标准，适合快速构建 API 和网站。

:::

## 2. 项目结构

::: details
Express 项目的推荐目录结构。

### 基本结构

```
project/
├── controllers/      # 控制器
│   └── user.js
├── models/           # 数据模型
│   └── user.js
├── routes/           # 路由
│   └── user.js
├── middleware/        # 中间件
│   └── auth.js
├── services/         # 业务逻辑
│   └── user.js
├── config/           # 配置
│   └── index.js
├── utils/            # 工具函数
├── app.js            # Express 应用
└── server.js         # 服务器入口
```

### 应用配置

```javascript
// app.js
const express = require('express');
const cors = require('cors');
const helmet = require('helmet');

const app = express();

// 中间件
app.use(helmet());        // 安全头
app.use(cors());          // 跨域
app.use(express.json());  // JSON 解析
app.use(express.urlencoded({ extended: true }));

// 路由
app.use('/api/users', require('./routes/user'));

// 错误处理
app.use(require('./middleware/errorHandler'));

module.exports = app;
```

### 服务器入口

```javascript
// server.js
const app = require('./app');

const PORT = process.env.PORT || 3000;

app.listen(PORT, () => {
  console.log(`服务器启动: http://localhost:${PORT}`);
});
```

### 总结

良好的项目结构有助于代码维护和团队协作。

:::

## 3. 请求与响应

::: details
Express 对 Node.js 原生 `req`/`res` 进行了增强。

### 请求对象

```javascript
app.get('/user/:id', (req, res) => {
  // 路由参数
  console.log(req.params.id);
  
  // 查询参数
  console.log(req.query.page);
  
  // 请求头
  console.log(req.headers.authorization);
  
  // 请求方法和路径
  console.log(req.method, req.path);
  
  // 请求体（需要 body-parser）
  console.log(req.body);
});
```

### 响应对象

```javascript
app.get('/user/:id', (req, res) => {
  // 发送文本
  res.send('Hello');
  
  // 发送 JSON
  res.json({ name: '张三' });
  
  // 发送状态码
  res.status(201).json({ created: true });
  
  // 发送文件
  res.sendFile(path.join(__dirname, 'file.txt'));
  
  // 重定向
  res.redirect('/login');
  
  // 设置响应头
  res.set('X-Custom-Header', 'value');
});
```

### 链式调用

```javascript
// Express 支持链式调用
res.status(200).json({ success: true }).end();

// 或者
res.status(200).send('OK');
```

### 总结

Express 增强了请求和响应对象，提供了更便捷的 API。

:::

## 4. 静态文件

::: details
Express 可以托管静态文件。

### 基本用法

```javascript
// 托管 public 目录下的静态文件
app.use(express.static('public'));

// 访问 public/index.html
// GET http://localhost:3000/index.html
```

### 虚拟路径

```javascript
// 添加 /static 前缀
app.use('/static', express.static('public'));

// 访问 public/images/logo.png
// GET http://localhost:3000/static/images/logo.png
```

### 缓存控制

```javascript
app.use(express.static('public', {
  maxAge: '1d',  // 缓存 1 天
  etag: true,    // 启用 ETag
  lastModified: true  // 启用 Last-Modified
}));
```

### 总结

静态文件托管是 Web 应用的基本需求，Express 提供了简单的方式。

:::
