# 常见问题

## 1. 加载问题

::: details
Three.js 应用常见的加载问题和解决方案。

### 模型不显示

**问题**：加载模型后不显示

**解决方案**：
```javascript
// 检查模型位置
const box = new THREE.Box3().setFromObject(model);
console.log('模型边界盒:', box);

// 调整相机位置
const center = box.getCenter(new THREE.Vector3());
const size = box.getSize(new THREE.Vector3());
const maxDim = Math.max(size.x, size.y, size.z);
const fov = camera.fov * (Math.PI / 180);
let cameraZ = Math.abs(maxDim / (2 * Math.tan(fov / 2)));
cameraZ *= 1.5;

camera.position.set(center.x, center.y, center.z + cameraZ);
camera.lookAt(center);
```

### 纹理不显示

**问题**：纹理加载后不显示

**解决方案**：
```javascript
// 检查 UV 坐标
console.log('UV:', geometry.attributes.uv);

// 确保纹理正确加载
textureLoader.load('texture.jpg', (texture) => {
  console.log('纹理加载成功');
  material.map = texture;
  material.needsUpdate = true;
});

// 检查材质
material.needsUpdate = true;
```

### 总结

加载问题通常与路径、坐标、材质配置有关，需要仔细检查各个参数。

:::

## 2. 渲染问题

::: details
Three.js 渲染相关的常见问题。

### 闪烁问题

**问题**：模型渲染时出现闪烁

**解决方案**：
```javascript
// 启用抗锯齿
const renderer = new THREE.WebGLRenderer({ antialias: true });

// 调整相机近裁剪面
camera.near = 0.1;

// 启用深度测试
material.depthTest = true;

// 调整 polygon offset
material.polygonOffset = true;
material.polygonOffsetFactor = 1;
material.polygonOffsetUnits = 1;
```

### 透明度问题

**问题**：透明对象渲染不正确

**解决方案**：
```javascript
// 设置渲染顺序
mesh.renderOrder = 1;

// 调整透明度设置
material.transparent = true;
material.opacity = 0.5;
material.depthWrite = false;

// 按距离排序
scene.traverse((child) => {
  if (child.isMesh) {
    child.renderOrder = -child.position.distanceTo(camera.position);
  }
});
```

### 阴影问题

**问题**：阴影显示不正确

**解决方案**：
```javascript
// 检查阴影投射
directionalLight.castShadow = true;
mesh.castShadow = true;
mesh.receiveShadow = true;

// 调整阴影相机
directionalLight.shadow.camera.left = -10;
directionalLight.shadow.camera.right = 10;
directionalLight.shadow.camera.top = 10;
directionalLight.shadow.camera.bottom = -10;

// 调整阴影偏移
directionalLight.shadow.bias = -0.001;
```

### 总结

渲染问题通常与材质配置、相机设置、阴影设置有关，需要逐一排查。

:::

## 4. 兼容性问题

::: details
Three.js 应用的兼容性问题和解决方案。

### 浏览器兼容性

**问题**：某些浏览器不支持 WebGL

**解决方案**：
```javascript
// 检查 WebGL 支持
function checkWebGLSupport() {
  try {
    const canvas = document.createElement('canvas');
    return !!(window.WebGLRenderingContext && 
      (canvas.getContext('webgl') || canvas.getContext('experimental-webgl')));
  } catch (e) {
    return false;
  }
}

if (!checkWebGLSupport()) {
  alert('您的浏览器不支持 WebGL');
}
```

### 移动端兼容性

**问题**：移动端渲染效果差

**解决方案**：
```javascript
// 检测移动设备
const isMobile = /Android|webOS|iPhone|iPad|iPod|BlackBerry|IEMobile|Opera Mini/i.test(navigator.userAgent);

// 根据设备调整设置
if (isMobile) {
  renderer.setPixelRatio(1);
  renderer.setSize(window.innerWidth / 2, window.innerHeight / 2);
} else {
  renderer.setPixelRatio(window.devicePixelRatio);
  renderer.setSize(window.innerWidth, window.innerHeight);
}
```

### 总结

兼容性问题需要考虑浏览器支持、设备性能等因素，提供降级方案。

:::
