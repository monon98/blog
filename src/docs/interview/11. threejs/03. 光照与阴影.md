# 光照与阴影

## 1. 光照类型

::: details
Three.js 提供了多种光源类型，模拟不同的光照效果。

### 环境光

```javascript
// 环境光：均匀照亮所有物体
const ambientLight = new THREE.AmbientLight(0xffffff, 0.5);
scene.add(ambientLight);
```

### 方向光

```javascript
// 方向光：平行光线，类似太阳
const directionalLight = new THREE.DirectionalLight(0xffffff, 1);
directionalLight.position.set(5, 10, 5);
directionalLight.target.position.set(0, 0, 0);
scene.add(directionalLight);
scene.add(directionalLight.target);
```

### 点光源

```javascript
// 点光源：从一个点向四周发射光线
const pointLight = new THREE.PointLight(0xffffff, 1, 100);
pointLight.position.set(0, 5, 0);
scene.add(pointLight);
```

### 聚光灯

```javascript
// 聚光灯：锥形光线
const spotLight = new THREE.SpotLight(0xffffff, 1);
spotLight.position.set(0, 10, 0);
spotLight.angle = Math.PI / 6;      // 锥形角度
spotLight.penumbra = 0.1;           // 半影（边缘柔和度）
spotLight.decay = 1;                // 衰减
spotLight.distance = 50;            // 距离
scene.add(spotLight);
```

### 半球光

```javascript
// 半球光：模拟天空和地面的光照
const hemisphereLight = new THREE.HemisphereLight(
  0xffffbb,  // 天空颜色
  0x080820,  // 地面颜色
  1          // 强度
);
scene.add(hemisphereLight);
```

### 光照对比

| 光源类型 | 特点 | 适用场景 |
|----------|------|----------|
| AmbientLight | 均匀照亮，无方向 | 基础照明 |
| DirectionalLight | 平行光线，无衰减 | 太阳光 |
| PointLight | 点光源，有衰减 | 灯泡、火把 |
| SpotLight | 锥形光线，有方向 | 手电筒、聚光灯 |
| HemisphereLight | 天空地面光照 | 户外场景 |

### 总结

选择合适的光源类型可以实现不同的光照效果，通常需要多种光源组合使用。

:::

## 2. 阴影

::: details
Three.js 支持阴影效果，可以增加场景的真实感。

### 开启阴影

```javascript
// 渲染器开启阴影
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;  // 柔和阴影
```

### 光源投射阴影

```javascript
const directionalLight = new THREE.DirectionalLight(0xffffff, 1);
directionalLight.castShadow = true;

// 配置阴影参数
directionalLight.shadow.mapSize.width = 2048;
directionalLight.shadow.mapSize.height = 2048;
directionalLight.shadow.camera.near = 0.5;
directionalLight.shadow.camera.far = 50;
directionalLight.shadow.camera.left = -10;
directionalLight.shadow.camera.right = 10;
directionalLight.shadow.camera.top = 10;
directionalLight.shadow.camera.bottom = -10;
directionalLight.shadow.bias = -0.0001;
```

### 对象接收/投射阴影

```javascript
// 投射阴影
cube.castShadow = true;

// 接收阴影
plane.receiveShadow = true;
```

### 阴影类型

```javascript
// 基本阴影
renderer.shadowMap.type = THREE.BasicShadowMap;

// PCF 阴影（较柔和）
renderer.shadowMap.type = THREE.PCFShadowMap;

// PCF 软阴影（最柔和）
renderer.shadowMap.type = THREE.PCFSoftShadowMap;

// VSM 阴影
renderer.shadowMap.type = THREE.VSMShadowMap;
```

### 阴影优化

```javascript
// 只更新需要的阴影
directionalLight.shadow.camera.updateProjectionMatrix();

// 使用阴影裁剪
directionalLight.shadow.camera.left = -5;
directionalLight.shadow.camera.right = 5;
directionalLight.shadow.camera.top = 5;
directionalLight.shadow.camera.bottom = -5;

// 降低阴影贴图分辨率
directionalLight.shadow.mapSize.width = 1024;
directionalLight.shadow.mapSize.height = 1024;
```

### 总结

阴影可以大大增加场景的真实感，但需要合理配置以平衡效果和性能。

:::

## 3. 光照模型

::: details
不同的材质使用不同的光照模型，了解这些模型有助于选择合适的材质。

### Phong 光照模型

```javascript
// Phong 模型：环境光 + 漫反射 + 镜面反射
const phongMaterial = new THREE.MeshPhongMaterial({
  color: 0x00ff00,
  specular: 0xffffff,  // 镜面反射颜色
  shininess: 100      // 高光大小
});
```

### Lambert 光照模型

```javascript
// Lambert 模型：环境光 + 漫反射（无高光）
const lambertMaterial = new THREE.MeshLambertMaterial({
  color: 0x00ff00
});
```

### Standard 光照模型（PBR）

```javascript
// Standard 模型：基于物理的渲染
const standardMaterial = new THREE.MeshStandardMaterial({
  color: 0x00ff00,
  roughness: 0.5,  // 粗糙度
  metalness: 0.5   // 金属度
});
```

### 物理材质

```javascript
// Physical 材质：Standard 的扩展
const physicalMaterial = new THREE.MeshPhysicalMaterial({
  color: 0x00ff00,
  roughness: 0.5,
  metalness: 0.5,
  clearcoat: 1.0,        // 清漆层
  clearcoatRoughness: 0.1,
  transmission: 0.9,     // 透射（玻璃效果）
  thickness: 0.5
});
```

### 光照模型对比

| 模型 | 特点 | 性能 |
|------|------|------|
| Basic | 无光照 | 最快 |
| Lambert | 漫反射 | 快 |
| Phong | 漫反射 + 高光 | 中等 |
| Standard | PBR | 较慢 |
| Physical | PBR 扩展 | 最慢 |

### 总结

选择合适的光照模型可以在视觉效果和性能之间取得平衡。

:::

## 4. 环境光遮蔽

::: details
环境光遮蔽（AO）可以增加物体角落和缝隙的阴影效果，提升真实感。

### SSAO（屏幕空间环境光遮蔽）

```javascript
import { EffectComposer } from 'three/examples/jsm/postprocessing/EffectComposer';
import { SSAOPass } from 'three/examples/jsm/postprocessing/SSAOPass';

const composer = new EffectComposer(renderer);
const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

const ssaoPass = new SSAOPass(scene, camera);
ssaoPass.kernelRadius = 8;
ssaoPass.minDistance = 0.005;
ssaoPass.maxDistance = 0.1;
composer.addPass(ssaoPass);

// 渲染循环
function animate() {
  requestAnimationFrame(animate);
  composer.render();
}
```

### AO 贴图

```javascript
// 使用 AO 贴图
const aoTexture = textureLoader.load('ao.jpg');

const material = new THREE.MeshStandardMaterial({
  map: texture,
  aoMap: aoTexture,
  aoMapIntensity: 1  // AO 强度
});

// 需要设置 UV2
geometry.setAttribute('uv2', geometry.getAttribute('uv'));
```

### 总结

环境光遮蔽可以增加物体的立体感和真实感，是提升画面质量的重要手段。

:::
