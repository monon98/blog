# 动画与渲染循环

## 1. 基本动画

::: details
Three.js 中的动画通常基于 requestAnimationFrame 实现。

### 基本旋转动画

```javascript
function animate() {
  requestAnimationFrame(animate);

  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;

  renderer.render(scene, camera);
}

animate();
```

### 基于时间的动画

```javascript
const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();
  const elapsed = clock.getElapsedTime();

  // 匀速旋转
  cube.rotation.x += delta * 2;

  // 正弦波动画
  cube.position.y = Math.sin(elapsed * 2) * 2;

  renderer.render(scene, camera);
}

animate();
```

### 缓动动画

```javascript
// 线性插值
function lerp(start, end, t) {
  return start + (end - start) * t;
}

// 使用
const targetX = 5;
cube.position.x = lerp(cube.position.x, targetX, 0.05);
```

### 总结

基本动画可以通过直接修改对象属性实现，配合时间可以实现平滑的动画效果。

:::

## 2. TWEEN 动画

::: details
TWEEN 是一个轻量级的动画库，可以创建各种缓动效果。

### 安装

```bash
npm install @tweenjs/tween.js
```

### 基本使用

```javascript
import * as TWEEN from '@tweenjs/tween.js';

// 创建动画
new TWEEN.Tween(cube.position)
  .to({ x: 5, y: 3 }, 2000)
  .easing(TWEEN.Easing.Quadratic.InOut)
  .start();

// 渲染循环中更新
function animate() {
  requestAnimationFrame(animate);

  TWEEN.update();

  renderer.render(scene, camera);
}

animate();
```

### 缓动函数

```javascript
// 线性
TWEEN.Easing.Linear.None

// 二次
TWEEN.Easing.Quadratic.In
TWEEN.Easing.Quadratic.Out
TWEEN.Easing.Quadratic.InOut

// 三次
TWEEN.Easing.Cubic.In
TWEEN.Easing.Cubic.Out
TWEEN.Easing.Cubic.InOut

// 弹性
TWEEN.Easing.Elastic.In
TWEEN.Easing.Elastic.Out
TWEEN.Easing.Elastic.InOut

// 回弹
TWEEN.Easing.Bounce.In
TWEEN.Easing.Bounce.Out
TWEEN.Easing.Bounce.InOut
```

### 链式动画

```javascript
const tween1 = new TWEEN.Tween(cube.position)
  .to({ x: 5 }, 1000)
  .easing(TWEEN.Easing.Quadratic.InOut);

const tween2 = new TWEEN.Tween(cube.position)
  .to({ y: 3 }, 1000)
  .easing(TWEEN.Easing.Quadratic.InOut);

const tween3 = new TWEEN.Tween(cube.position)
  .to({ x: 0, y: 0 }, 1000)
  .easing(TWEEN.Easing.Quadratic.InOut);

tween1.chain(tween2);
tween2.chain(tween3);
tween1.start();
```

### 总结

TWEEN 库提供了丰富的缓动效果和链式动画，可以轻松创建复杂的动画序列。

:::

## 3.骨骼动画

::: details
骨骼动画用于角色动画，通过骨骼系统控制模型变形。

### 加载骨骼模型

```javascript
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader';

const loader = new GLTFLoader();
loader.load('model.gltf', (gltf) => {
  const model = gltf.scene;
  scene.add(model);

  // 获取动画混合器
  const mixer = new THREE.AnimationMixer(model);

  // 播放第一个动画
  const animation = gltf.animations[0];
  const action = mixer.clipAction(animation);
  action.play();
});

// 渲染循环中更新
function animate() {
  requestAnimationFrame(animate);

  const delta = clock.getDelta();
  mixer.update(delta);

  renderer.render(scene, camera);
}
```

### 动画混合器

```javascript
// 创建混合器
const mixer = new THREE.AnimationMixer(model);

// 播放动画
const action = mixer.clipAction(clip);
action.play();

// 暂停
action.pause();

// 停止
action.stop();

// 混合多个动画
const action1 = mixer.clipAction(clip1);
const action2 = mixer.clipAction(clip2);

action1.weight = 0.5;
action2.weight = 0.5;
```

### 动画过渡

```javascript
// 平滑过渡到新动画
action.crossFadeTo(newAction, 0.5, true);

// 设置动画循环模式
action.setLoop(THREE.LoopRepeat, Infinity);
action.setLoop(THREE.LoopOnce, 1);
action.clampWhenFinished = true;
```

### 总结

骨骼动画是角色动画的核心，Three.js 提供了完整的动画系统支持。

:::

## 4. 粒子系统

::: details
粒子系统用于模拟大量小物体的效果，如火焰、烟雾、星星等。

### 基本粒子系统

```javascript
// 创建粒子几何体
const particleCount = 1000;
const positions = new Float32Array(particleCount * 3);

for (let i = 0; i < particleCount * 3; i += 3) {
  positions[i] = (Math.random() - 0.5) * 10;
  positions[i + 1] = (Math.random() - 0.5) * 10;
  positions[i + 2] = (Math.random() - 0.5) * 10;
}

const geometry = new THREE.BufferGeometry();
geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));

// 创建粒子材质
const material = new THREE.PointsMaterial({
  color: 0xffffff,
  size: 0.1,
  transparent: true,
  opacity: 0.8
});

// 创建粒子系统
const particles = new THREE.Points(geometry, material);
scene.add(particles);
```

### 粒子动画

```javascript
function animate() {
  requestAnimationFrame(animate);

  const positions = particles.geometry.attributes.position.array;

  for (let i = 0; i < positions.length; i += 3) {
    positions[i + 1] += 0.01;  // 向上移动
  }

  particles.geometry.attributes.position.needsUpdate = true;

  renderer.render(scene, camera);
}
```

### 纹理粒子

```javascript
const textureLoader = new THREE.TextureLoader();
const sprite = textureLoader.load('particle.png');

const material = new THREE.PointsMaterial({
  map: sprite,
  size: 0.5,
  transparent: true,
  opacity: 0.8,
  blending: THREE.AdditiveBlending,
  depthWrite: false
});
```

### 总结

粒子系统可以实现各种视觉效果，Three.js 的 PointsMaterial 提供了灵活的粒子配置。

:::
