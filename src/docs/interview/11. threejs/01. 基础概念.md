# Three.js 基础概念

## 1. 什么是 Three.js

::: details
Three.js 是一个基于 WebGL 的 JavaScript 3D 图形库，它简化了 WebGL 的复杂 API，提供了简洁的接口来创建和显示 3D 图形。

### 核心特点

- **简化 API**：将复杂的 WebGL API 封装为简洁的 JavaScript 接口
- **跨平台**：支持所有现代浏览器
- **丰富的功能**：几何体、材质、光照、动画、加载器等
- **活跃的社区**：大量的示例和文档

### 技术栈关系

```
┌─────────────────────────────────┐
│         Three.js                │
│    (3D 图形库)                  │
├─────────────────────────────────┤
│         WebGL                   │
│    (浏览器 3D API)              │
├─────────────────────────────────┤
│         OpenGL ES               │
│    (图形渲染 API)               │
├─────────────────────────────────┤
│         GPU                     │
│    (图形处理器)                  │
└─────────────────────────────────┘
```

### 与其他方案对比

| 方案 | 特点 | 适用场景 |
|------|------|----------|
| Three.js | 简洁易用、功能丰富 | 大多数 3D 项目 |
| Babylon.js | 游戏引擎风格、物理引擎 | 游戏开发 |
| PlayCanvas | 在线协作、轻量级 | 小型项目 |
| A-Frame | 声明式语法、VR/AR | WebXR 项目 |
| 原生 WebGL | 底层控制、性能最优 | 需要极致性能 |

### 总结

Three.js 是最流行的 WebGL 封装库，它大大降低了 3D 图形开发的门槛，适合快速开发各种 3D 应用。

:::

## 2. Three.js 核心三要素

::: details
Three.js 的核心由三个要素组成：场景（Scene）、相机（Camera）、渲染器（Renderer）。

### 场景（Scene）

场景是所有 3D 对象的容器，类似于一个虚拟的 3D 世界。

```javascript
import * as THREE from 'three';

// 创建场景
const scene = new THREE.Scene();

// 设置背景色
scene.background = new THREE.Color(0x000000);

// 添加雾效
scene.fog = new THREE.Fog(0xffffff, 0, 50);

// 添加对象到场景
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);
```

### 相机（Camera）

相机决定了从哪个角度观察场景，类似于人的眼睛或摄像机。

```javascript
// 透视相机（最常用）
const camera = new THREE.PerspectiveCamera(
  75,                    // 视野角度（FOV）
  window.innerWidth / window.innerHeight,  // 宽高比
  0.1,                   // 近裁剪面
  1000                   // 远裁剪面
);

camera.position.z = 5;

// 正交相机（无透视效果）
const orthoCamera = new THREE.OrthographicCamera(
  -10,  // left
  10,   // right
  10,   // top
  -10,  // bottom
  0.1,  // near
  1000  // far
);
```

### 渲染器（Renderer）

渲染器负责将场景和相机的信息渲染到屏幕上。

```javascript
// 创建渲染器
const renderer = new THREE.WebGLRenderer({
  antialias: true,  // 抗锯齿
  alpha: true       // 透明背景
});

// 设置渲染器大小
renderer.setSize(window.innerWidth, window.innerHeight);

// 设置像素比（适配高DPI屏幕）
renderer.setPixelRatio(window.devicePixelRatio);

// 开启阴影
renderer.shadowMap.enabled = true;

// 添加到 DOM
document.body.appendChild(renderer.domElement);
```

### 完整示例

```javascript
import * as THREE from 'three';

// 场景
const scene = new THREE.Scene();

// 相机
const camera = new THREE.PerspectiveCamera(
  75,
  window.innerWidth / window.innerHeight,
  0.1,
  1000
);

// 渲染器
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

// 创建立方体
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

camera.position.z = 5;

// 渲染循环
function animate() {
  requestAnimationFrame(animate);

  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;

  renderer.render(scene, camera);
}

animate();
```

### 总结

场景、相机、渲染器是 Three.js 的核心三要素，理解它们的关系是学习 Three.js 的基础。

:::

## 3. 坐标系与变换

::: details
Three.js 使用右手坐标系，理解坐标系和变换是 3D 开发的基础。

### 坐标系

```
        Y
        |
        |
        |
        +------- X
       /
      /
     /
    Z
```

- **X 轴**：水平方向，向右为正
- **Y 轴**：垂直方向，向上为正
- **Z 轴**：深度方向，向外为正

### 位置（Position）

```javascript
// 设置位置
cube.position.x = 1;
cube.position.y = 2;
cube.position.z = 3;

// 或者使用 set
cube.position.set(1, 2, 3);

// 获取位置
console.log(cube.position); // Vector3 {x: 1, y: 2, z: 3}
```

### 旋转（Rotation）

```javascript
// 设置旋转（弧度制）
cube.rotation.x = Math.PI / 4;  // 绕 X 轴旋转 45 度
cube.rotation.y = Math.PI / 2;  // 绕 Y 轴旋转 90 度
cube.rotation.z = Math.PI;      // 绕 Z 轴旋转 180 度

// 使用欧拉角
cube.rotation.set(Math.PI / 4, Math.PI / 2, 0);

// 使用四元数（避免万向锁）
const quaternion = new THREE.Quaternion();
quaternion.setFromAxisAngle(new THREE.Vector3(0, 1, 0), Math.PI / 2);
cube.quaternion.copy(quaternion);
```

### 缩放（Scale）

```javascript
// 设置缩放
cube.scale.x = 2;  // X 轴放大 2 倍
cube.scale.y = 0.5;  // Y 轴缩小一半
cube.scale.z = 1;

// 或者使用 set
cube.scale.set(2, 0.5, 1);
```

### 变换顺序

变换的顺序会影响最终结果，默认顺序是：缩放 → 旋转 → 平移（SRT）

```javascript
// 使用矩阵控制变换顺序
const matrix = new THREE.Matrix4();

// 先平移
matrix.makeTranslation(1, 0, 0);

// 再旋转
matrix.multiply(new THREE.Matrix4().makeRotationY(Math.PI / 4));

// 应用到对象
cube.applyMatrix4(matrix);
```

### 总结

理解坐标系和变换（位置、旋转、缩放）是 3D 开发的基础，Three.js 提供了丰富的 API 来控制对象的变换。

:::

## 4. 渲染循环与时间

::: details
Three.js 使用 requestAnimationFrame 实现渲染循环，配合时间管理实现流畅的动画。

### 基本渲染循环

```javascript
function animate() {
  requestAnimationFrame(animate);

  // 更新逻辑
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;

  // 渲染
  renderer.render(scene, camera);
}

animate();
```

### 使用时钟（Clock）

```javascript
const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  // 获取时间差
  const delta = clock.getDelta();
  
  // 获取总时间
  const elapsed = clock.getElapsedTime();

  // 基于时间更新
  cube.rotation.x += delta * 2;  // 每秒旋转 2 弧度
  cube.position.x = Math.sin(elapsed) * 2;

  renderer.render(scene, camera);
}

animate();
```

### 帧率控制

```javascript
// 帧率控制的完整实现见 04. 动画与渲染循环.md
const clock = new THREE.Clock();
let lastTime = 0;
const targetFPS = 60;
const frameInterval = 1000 / targetFPS;

function animate(currentTime) {
  requestAnimationFrame(animate);
  
  const deltaTime = currentTime - lastTime;
  
  if (deltaTime >= frameInterval) {
    lastTime = currentTime - (deltaTime % frameInterval);
    
    const delta = clock.getDelta();
    cube.rotation.x += delta * 2;
    
    renderer.render(scene, camera);
  }
}

requestAnimationFrame(animate);
```

### 窗口大小调整

```javascript
function onWindowResize() {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
}

window.addEventListener('resize', onWindowResize);
```

### 总结

渲染循环是 Three.js 动画的核心，使用 requestAnimationFrame 实现平滑的动画效果，配合时钟可以实现基于时间的动画。

:::
