## 2. 材质和纹理

::: details
**问题**：Three.js 中如何选择和优化材质？

### 材质类型

| 材质 | 用途 | 性能 |
|------|------|------|
| MeshBasicMaterial | 基础材质 | 高 |
| MeshPhongMaterial | 光照材质 | 中 |
| MeshStandardMaterial | PBR 材质 | 中 |
| MeshPhysicalMaterial | 高级 PBR | 低 |
| ShaderMaterial | 自定义着色器 | 灵活 |

### 纹理优化

- 使用 Mipmap
- 使用纹理压缩
- 合理设置纹理尺寸
- 使用纹理图集

### 最佳实践

- 根据需求选择材质
- 使用材质共享
- 避免频繁创建材质
- 使用 BufferGeometry

:::
