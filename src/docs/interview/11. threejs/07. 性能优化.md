# 性能优化

## 1. 渲染优化

::: details
渲染优化是 Three.js 性能优化的关键。

### 减少绘制调用

```javascript
// 使用合并几何体（多个几何体合并为一个）
import { mergeGeometries } from 'three/examples/jsm/utils/BufferGeometryUtils.js';

const geometry1 = new THREE.BoxGeometry(1, 1, 1);
const geometry2 = new THREE.SphereGeometry(0.5, 16, 16);

// 合并几何体
const mergedGeometry = mergeGeometries([geometry1, geometry2]);
const mergedMesh = new THREE.Mesh(mergedGeometry, material);

// 使用实例化（相同几何体多次绘制）
const instancedMesh = new THREE.InstancedMesh(
  geometry,
  material,
  count  // 实例数量
);

const matrix = new THREE.Matrix4();
for (let i = 0; i < count; i++) {
  matrix.setPosition(
    Math.random() * 10 - 5,
    Math.random() * 10 - 5,
    Math.random() * 10 - 5
  );
  instancedMesh.setMatrixAt(i, matrix);
}
instancedMesh.instanceMatrix.needsUpdate = true;
scene.add(instancedMesh);
```

### 使用 LOD（细节层次）

```javascript
import { LOD } from 'three';

const lod = new LOD();

// 高细节模型
const highDetail = new THREE.Mesh(highGeometry, material);
lod.addLevel(highDetail, 0);

// 中细节模型
const mediumDetail = new THREE.Mesh(mediumGeometry, material);
lod.addLevel(mediumDetail, 10);

// 低细节模型
const lowDetail = new THREE.Mesh(lowGeometry, material);
lod.addLevel(lowDetail, 20);

scene.add(lod);
```

### 视锥体裁剪

```javascript
// Three.js 默认自动进行视锥体裁剪
// object.frustumCulled 默认为 true，无需手动处理

// 禁用自动裁剪（特殊情况需要）
object.frustumCulled = false;

// 手动检测（仅用于自定义裁剪逻辑）
const frustum = new THREE.Frustum();
const cameraViewProjectionMatrix = new THREE.Matrix4();

function checkObjectInFrustum(object) {
  cameraViewProjectionMatrix.multiplyMatrices(
    camera.projectionMatrix,
    camera.matrixWorldInverse
  );
  frustum.setFromProjectionMatrix(cameraViewProjectionMatrix);
  
  return frustum.intersectsObject(object);
}
```

### 总结

渲染优化包括减少绘制调用、使用 LOD、视锥体裁剪等技术。

## 2. 内存优化

::: details
内存优化可以防止内存泄漏，提升应用稳定性。

### 及时释放资源

```javascript
// 释放几何体
geometry.dispose();

// 释放材质
material.dispose();

// 释放纹理
texture.dispose();

// 释放整个模型
function disposeModel(model) {
  model.traverse((child) => {
    if (child.isMesh) {
      child.geometry.dispose();
      
      if (Array.isArray(child.material)) {
        child.material.forEach(material => material.dispose());
      } else {
        child.material.dispose();
      }
    }
  });
}

// 从场景中移除
scene.remove(model);
```

### 复用资源

```javascript
// 复用材质
const sharedMaterial = new THREE.MeshStandardMaterial({ color: 0xff0000 });

const mesh1 = new THREE.Mesh(geometry1, sharedMaterial);
const mesh2 = new THREE.Mesh(geometry2, sharedMaterial);

// 复用几何体
const sharedGeometry = new THREE.BoxGeometry(1, 1, 1);

const mesh1 = new THREE.Mesh(sharedGeometry, material1);
const mesh2 = new THREE.Mesh(sharedGeometry, material2);
```

### 使用对象池

```javascript
class ObjectPool {
  constructor(createFn, resetFn) {
    this.pool = [];
    this.createFn = createFn;
    this.resetFn = resetFn;
  }
  
  get() {
    if (this.pool.length > 0) {
      return this.pool.pop();
    }
    return this.createFn();
  }
  
  release(object) {
    this.resetFn(object);
    this.pool.push(object);
  }
}

// 使用
const bulletPool = new ObjectPool(
  () => new THREE.Mesh(bulletGeometry, bulletMaterial),
  (bullet) => {
    bullet.position.set(0, 0, 0);
    bullet.visible = false;
  }
);
```

### 总结

内存优化包括及时释放资源、复用资源、使用对象池等技术。

## 4. 渲染优化技巧

::: details
以下是一些实用的渲染优化技巧。

### 使用后处理

```javascript
import { EffectComposer } from 'three/examples/jsm/postprocessing/EffectComposer';
import { RenderPass } from 'three/examples/jsm/postprocessing/RenderPass';
import { UnrealBloomPass } from 'three/examples/jsm/postprocessing/UnrealBloomPass';

const composer = new EffectComposer(renderer);

const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

const bloomPass = new UnrealBloomPass(
  new THREE.Vector2(window.innerWidth, window.innerHeight),
  0.5,  // 强度
  0.4,  // 半径
  0.85  // 阈值
);
composer.addPass(bloomPass);

function animate() {
  requestAnimationFrame(animate);
  composer.render();
}
```

### 使用遮挡查询

```javascript
// Three.js 默认自动执行视锥体裁剪（见第 1 节）
// 遮挡查询可用于自定义裁剪逻辑，复用视锥体检测方法
const frustum = new THREE.Frustum();
const cameraViewProjectionMatrix = new THREE.Matrix4();

function isObjectVisible(object, camera) {
  cameraViewProjectionMatrix.multiplyMatrices(
    camera.projectionMatrix,
    camera.matrixWorldInverse
  );
  frustum.setFromProjectionMatrix(cameraViewProjectionMatrix);
  return frustum.intersectsObject(object);
}
```

### 优化着色器

```javascript
// 使用 WebGL2 的特性
const renderer = new THREE.WebGLRenderer({
  powerPreference: 'high-performance',
  antialias: false
});

// 减少纹理采样
material.map.minFilter = THREE.LinearFilter;
material.map.magFilter = THREE.LinearFilter;
material.map.generateMipmaps = false;
```

### 总结

渲染优化技巧包括使用后处理、遮挡查询、优化着色器等，可以显著提升渲染性能。
