# 计数质数

> 难度：简单 | 标签：数组、数学、枚举、数论 | [LeetCode 原题](https://leetcode.cn/problems/count-primes/description/)

## 题目描述

给定整数 `n`，返回所有小于非负整数 `n` 的质数的数量。

**示例 1：**

```
输入：n = 10
输出：4
解释：小于 10 的质数一共有 4 个，它们是 2、3、5、7。
```

**示例 2：**

```
输入：n = 1
输出：0
```

**提示：**

- `0 <= n <= 5 * 10^6`

## 题解

::: details 点击查看题解

### 思路

埃拉托斯特尼筛法（埃氏筛）：初始化布尔数组全部为 true，从 2 开始，每遇到一个质数就把它的倍数全部标记为合数。优化点有两个——外层只需枚举到 √n；内层标记从 `i * i` 开始（更小的倍数已被之前的质数处理过）。

逐个数试除的暴力写法是 O(n·√n)，在 n 为百万级时会超时。

### 代码实现

```javascript
var countPrimes = function(n) {
  const isPrime = new Array(n).fill(true);
  let count = 0;
  for (let i = 2; i < n; i++) {
    if (isPrime[i]) {
      count++;
      for (let j = i * i; j < n; j += i) {
        isPrime[j] = false;
      }
    }
  }
  return count;
};
```

### 复杂度分析

- 时间复杂度：O(n log log n)。
- 空间复杂度：O(n)，筛表。
