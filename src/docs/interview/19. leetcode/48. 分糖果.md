# 分糖果

> 难度：简单 | 标签：数组、哈希表、贪心 | [LeetCode 原题](https://leetcode.cn/problems/distribute-candies/description/)

## 题目描述

Alice 有 `n` 枚糖，其中第 `i` 枚糖的类型为 `candyType[i]`。Alice 注意到她的体重正在增长，所以前去拜访了一位医生。医生建议 Alice 只需吃掉 `n / 2` 枚糖（`n` 总是偶数）。Alice 非常喜欢这些糖，她想要在遵循医生建议的情况下，尽可能吃到最多不同类型的糖。返回 Alice 在只吃掉 `n / 2` 枚糖的条件下，可以吃到糖的最多种类数。

**示例 1：**

```
输入：candyType = [1,1,2,2,3,3]
输出：3
解释：Alice 只能吃 6 / 2 = 3 枚糖，可以吃三种不同类型的糖。
```

**示例 2：**

```
输入：candyType = [1,1,2,3]
输出：2
解释：只能吃 2 枚糖，种类数受数量限制。
```

**提示：**

- `n == candyType.length`
- `2 <= n <= 10^4`
- `n` 是一个偶数
- `-10^5 <= candyType[i] <= 10^5`

## 题解

::: details 点击查看题解

### 思路

答案是「种类数」与「允许吃的颗数 n/2」二者的较小值：若种类多，吃满 n/2 也拿不到全部种类；若种类少，能吃到的最大种类数就是全部种类。

用 Set 去重统计种类即可。

### 代码实现

```javascript
var distributeCandies = function(candyType) {
  return Math.min(new Set(candyType).size, candyType.length / 2);
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(n)，最坏情况所有糖类型都不同。

:::
