# 下一个更大元素 I

> 难度：简单 | 标签：栈、数组、哈希表、单调栈 | [LeetCode 原题](https://leetcode.cn/problems/next-greater-element-i/description/)

## 题目描述

`nums1` 中数字 `x` 的下一个更大元素是指 `x` 在 `nums2` 中对应位置右侧的第一个比 `x` 大的元素。给你两个没有重复元素的数组 `nums1` 和 `nums2`，下标从 0 开始计数，其中 `nums1` 是 `nums2` 的子集。对于每个 `0 <= i < nums1.length`，找出满足 `nums1[i] == nums2[j]` 的下标 `j`，并且在 `nums2` 确定 `nums1[i]` 的下一个更大元素。如果不存在，则输出 `-1`。

**示例 1：**

```
输入：nums1 = [4,1,2], nums2 = [1,3,4,2]
输出：[-1,3,-1]
```

**示例 2：**

```
输入：nums1 = [2,4], nums2 = [1,2,3,4]
输出：[3,-1]
```

**提示：**

- `1 <= nums1.length <= nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 10^4`
- `nums1` 和 `nums2` 中所有整数互不相同

## 题解

::: details 点击查看题解

### 思路

对 `nums2` 跑一遍单调递减栈：元素入栈前，把所有比它小的栈顶元素弹出——此时该元素正是这些弹出元素的「下一个更大元素」，记录到哈希表。最后用 `nums1` 逐个查表，查不到就是 -1。

暴力法对每个 x 向右扫描是 O(m · n)；单调栈把整个求「下一个更大元素」的过程压缩到 O(n)，这是该技巧最重要的应用模板（后续「每日温度」等题同源）。

### 代码实现

```javascript
var nextGreaterElement = function(nums1, nums2) {
  const map = {};
  const stack = [];
  for (const x of nums2) {
    while (stack.length && x > stack[stack.length - 1]) {
      map[stack.pop()] = x;
    }
    stack.push(x);
  }
  return nums1.map((x) => (x in map ? map[x] : -1));
};
```

### 复杂度分析

- 时间复杂度：O(m + n)，每个元素最多进出栈各一次。
- 空间复杂度：O(n)，栈与哈希表。

:::
