# 比较含退格的字符串

> 难度：简单 | 标签：栈、双指针、字符串、模拟 | [LeetCode 原题](https://leetcode.cn/problems/backspace-string-compare/description/)

## 题目描述

给定 `s` 和 `t` 两个字符串，当它们分别被输入到空白的文本编辑器后，如果二者相等，返回 `true`。`#` 代表退格字符。注意：如果对空文本输入退格字符，文本继续为空。

**示例 1：**

```
输入：s = "ab#c", t = "ad#c"
输出：true
解释：s 和 t 都会变成 "ac"。
```

**示例 2：**

```
输入：s = "ab##", t = "c#d#"
输出：true
解释：s 和 t 都会变成 ""。
```

**提示：**

- `1 <= s.length, t.length <= 200`
- `s` 和 `t` 只含有小写字母以及字符 `'#'`

**进阶：** 你可以用 O(n) 的时间复杂度和 O(1) 的空间复杂度解决该问题吗？（答案：从右往左扫描，逐段跳过被退格抵消的字符再逐个比较。）

## 题解

::: details 点击查看题解

### 思路

用栈模拟打字过程：普通字符入栈，遇到 `#` 弹出栈顶（栈空则忽略）。两个串各自构建最终结果后直接比较。

进阶的 O(1) 空间做法是从后往前双指针：维护「还需跳过多少个字符」的计数器，遇到 `#` 计数加一，遇到普通字符且计数大于零就跳过；两边各取下一个有效字符比较。

### 代码实现

```javascript
var backspaceCompare = function(s, t) {
  const build = (str) => {
    const stack = [];
    for (const ch of str) {
      if (ch === "#") {
        stack.pop();
      } else {
        stack.push(ch);
      }
    }
    return stack.join("");
  };
  return build(s) === build(t);
};
```

### 复杂度分析

- 时间复杂度：O(m + n)。
- 空间复杂度：O(m + n)，两个结果栈。

:::
