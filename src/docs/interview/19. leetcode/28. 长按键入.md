# 长按键入

> 难度：简单 | 标签：双指针、字符串 | [LeetCode 原题](https://leetcode.cn/problems/long-pressed-name/description/)

## 题目描述

你的朋友正在使用键盘输入他的名字 `name`。偶尔在键入字符 `c` 时，按键可能会被长按，而字符可能被输入一次或多次。你将会检查键盘输入的字符 `typed`。如果它对应的可能是你的朋友的名字（其中一些字符可能被长按），那么就返回 `true`。

**示例 1：**

```
输入：name = "alex", typed = "aaleex"
输出：true
解释："alex" 中的 "a" 被长按了，"e" 也被长按了。
```

**示例 2：**

```
输入：name = "saeed", typed = "ssaaedd"
输出：false
解释："e" 一定需要被键入两次，但在 typed 的输出中没有这样。
```

**提示：**

- `1 <= name.length, typed.length <= 1000`
- `name` 和 `typed` 的字符都是小写字母

## 题解

::: details 点击查看题解

### 思路

双指针匹配：`i` 指向 `name` 待匹配的位置，遍历 `typed` 每个字符——若与 `name[i]` 相同则 `i` 前进；否则它必须是「前一个已匹配字符的长按重复」（即等于 `name[i-1]`），否则返回 false。遍历结束后 `i` 必须走完整个 `name`。

### 代码实现

```javascript
var isLongPressedName = function(name, typed) {
  let i = 0;
  for (const ch of typed) {
    if (i < name.length && name[i] === ch) {
      i++;
    } else if (i === 0 || name[i - 1] !== ch) {
      return false;
    }
  }
  return i === name.length;
};
```

### 复杂度分析

- 时间复杂度：O(m + n)，m、n 为两串长度。
- 空间复杂度：O(1)。
