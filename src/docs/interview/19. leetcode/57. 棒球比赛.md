# 棒球比赛

> 难度：简单 | 标签：栈、数组、模拟 | [LeetCode 原题](https://leetcode.cn/problems/baseball-game/description/)

## 题目描述

你现在是一场采用特殊赛制棒球比赛的记录员。这场比赛由若干回合组成，过去几回合的得分可能会影响以后几回合的得分。比赛开始时，记录是空白的：

- 整数 `x`：本回合新获得得分 `x`
- `"+"`：本回合新获得的得分是前两次得分的总和（保证此操作前面总是有两个有效的分数）
- `"D"`：本回合新获得的得分是前一次得分的两倍
- `"C"`：表示前一次得分无效，将其从记录中移除

给你一个字符串列表 `ops` 作为操作列表，返回记录中所有得分的总和。

**示例 1：**

```
输入：ops = ["5","2","C","D","+"]
输出：30
解释："5" 得 5；"2" 得 2；"C" 移除 2，剩 [5]；"D" 得 10，[5,10]；"+" 得 15，[5,10,15]。总分 5 + 10 + 15 = 30。
```

**示例 2：**

```
输入：ops = ["5","-2","4","C","D","9","+","+"]
输出：27
```

**提示：**

- `1 <= ops.length <= 1000`
- 题目保证记录操作总是有效的

## 题解

::: details 点击查看题解

### 思路

用栈保存历史得分：数字直接入栈；`"C"` 弹出栈顶；`"D"` 压入栈顶的两倍；`"+"` 压入栈顶两个元素之和。最后对栈内元素求和即可。

### 代码实现

```javascript
var calPoints = function(operations) {
  const stack = [];
  for (const op of operations) {
    if (op === "+") {
      stack.push(stack[stack.length - 1] + stack[stack.length - 2]);
    } else if (op === "D") {
      stack.push(stack[stack.length - 1] * 2);
    } else if (op === "C") {
      stack.pop();
    } else {
      stack.push(Number(op));
    }
  }
  return stack.reduce((a, b) => a + b, 0);
};
```

### 复杂度分析

- 时间复杂度：O(n)，每个操作 O(1) 处理。
- 空间复杂度：O(n)，最多 n 个分数在栈中。
