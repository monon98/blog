# 杨辉三角 II

> 难度：简单 | 标签：数组、动态规划 | [LeetCode 原题](https://leetcode.cn/problems/pascals-triangle-ii/description/)

## 题目描述

给定一个非负索引 `rowIndex`（0 开始），返回「杨辉三角」的第 `rowIndex` 行。在「杨辉三角」中，每个数是它左上方和右上方的数的和。

**示例 1：**

```
输入：rowIndex = 3
输出：[1,3,3,1]
```

**示例 2：**

```
输入：rowIndex = 0
输出：[1]
```

**提示：**

- `0 <= rowIndex <= 33`

**进阶：** 你可以优化你的算法到 O(rowIndex) 空间复杂度吗？

## 题解

::: details 点击查看题解

### 思路

只维护一行结果，用滚动数组原地更新：从右往左计算 `row[j] += row[j-1]`，这样 `row[j-1]` 还是上一行的旧值，不会互相覆盖。从第 2 行开始迭代到 `rowIndex` 行即可。

### 代码实现

```javascript
var getRow = function(rowIndex) {
  const row = new Array(rowIndex + 1).fill(1);
  for (let i = 2; i <= rowIndex; i++) {
    for (let j = i - 1; j > 0; j--) {
      row[j] += row[j - 1];
    }
  }
  return row;
};
```

### 复杂度分析

- 时间复杂度：O(rowIndex²)。
- 空间复杂度：O(1)（不计返回数组），只用一个长度为 rowIndex + 1 的数组。
