# 最后一块石头的重量

> 难度：简单 | 标签：数组、堆（优先队列） | [LeetCode 原题](https://leetcode.cn/problems/last-stone-weight/description/)

## 题目描述

有一堆石头，每块石头的重量都是正整数。每一回合，从中选出两块最重的石头，然后将它们一起粉碎。假设石头的重量分别为 `x` 和 `y`，且 `x <= y`：如果 `x == y`，那么两块石头都会被完全粉碎；否则重量为 `x` 的石头完全粉碎，而重量为 `y` 的石头新重量为 `y - x`。最后，最多只会剩下一块石头。返回此石头的重量；如果没有石头剩下，就返回 `0`。

**示例 1：**

```
输入：[2,7,4,1,8,1]
输出：1
解释：7 和 8 粉碎得 1 → [2,4,1,1,1]；2 和 4 粉碎得 2 → [2,1,1,2]；2 和 2 同归于尽 → [1,1,1]；最终剩余 1。
```

**提示：**

- `1 <= stones.length <= 10^4`
- `1 <= stones[i] <= 10^4`

## 题解

::: details 点击查看题解

### 思路

每一步都要取「最重的两块」，这正是优先队列（最大堆）的典型场景。JavaScript 没有内置堆，这里用「降序排序 + shift」简化实现：每次取前两个比较，差值不为零则放回并重新排序。

数据规模小（n ≤ 10⁴）时该写法完全够用；面试中建议口头说明可用二叉堆把单次操作优化到 O(log n)。

### 代码实现

```javascript
var lastStoneWeight = function(stones) {
  const heap = [...stones].sort((a, b) => b - a);
  while (heap.length > 1) {
    const y = heap.shift();
    const x = heap.shift();
    if (y > x) {
      heap.push(y - x);
      heap.sort((a, b) => b - a);
    }
  }
  return heap.length ? heap[0] : 0;
};
```

### 复杂度分析

- 时间复杂度：O(n² log n)，排序版；用真堆为 O(n log n)。
- 空间复杂度：O(n)。

:::
