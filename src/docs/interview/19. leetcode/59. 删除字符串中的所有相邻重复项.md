# 删除字符串中的所有相邻重复项

> 难度：简单 | 标签：栈、字符串 | [LeetCode 原题](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/description/)

## 题目描述

给出由小写字母组成的字符串 `s`，重复项删除操作会选择两个相邻且相同的字母，并删除它们。在 `s` 上反复执行删除项操作，直到无法继续删除。在完成所有删除操作后，返回最终字符串。答案保证唯一。

**示例 1：**

```
输入："abbaca"
输出："ca"
解释：先删除 "bb"，得到 "aaca"；再删除 "aa"，得到 "ca"。
```

**示例 2：**

```
输入："azxxzy"
输出："ay"
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 仅由小写英文字母组成

## 题解

::: details 点击查看题解

### 思路

栈天然匹配「消除相邻对」的语义：遍历字符，若与栈顶相同则弹出（完成一次消除），否则入栈。新字符与刚弹出的位置重新相邻，后续消除自动被处理，无需真的回退扫描。

结束后把栈内元素拼成字符串即为答案。

### 代码实现

```javascript
var removeDuplicates = function(s) {
  const stack = [];
  for (const ch of s) {
    if (stack[stack.length - 1] === ch) {
      stack.pop();
    } else {
      stack.push(ch);
    }
  }
  return stack.join("");
};
```

### 复杂度分析

- 时间复杂度：O(n)，每个字符最多进出栈各一次。
- 空间复杂度：O(n)。
