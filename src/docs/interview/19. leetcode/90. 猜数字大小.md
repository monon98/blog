# 猜数字大小

> 难度：简单 | 标签：二分查找、交互 | [LeetCode 原题](https://leetcode.cn/problems/guess-number-higher-or-lower/description/)

## 题目描述

我们正在玩猜数字游戏。游戏规则如下：我从 1 到 n 选择一个数字。你需要猜出我选了哪个号码。每次你猜错了，我会告诉你这个数字比你最终要猜的数字分别是大还是小。你可以调用一个预先定义好的接口 `guess(int num)`，它会返回 3 个可能的结果：`-1`（我选出的数字比你猜的数字小 `pick < num`）、`1`（我选出的数字比你猜的数字大 `pick > num`）、`0`（你猜的数字就是正确答案）。

**示例 1：**

```
输入：n = 10, pick = 6
输出：6
```

**示例 2：**

```
输入：n = 2, pick = 1
输出：1
```

**提示：**

- `1 <= n <= 2^31 - 1`
- `1 <= pick <= n`

## 题解

::: details 点击查看题解

### 思路

最基础的交互式二分：根据 `guess(mid)` 的反馈收缩区间——返回 -1 说明答案在左侧（`r = mid - 1`），返回 1 在右侧（`l = mid + 1`），返回 0 即命中。

与「第一个错误的版本」一起构成二分两类模板：闭区间精确命中 vs 左边界收敛。

### 代码实现

```javascript
var guessNumber = function(n) {
  let l = 1;
  let r = n;
  while (l <= r) {
    const mid = Math.floor((l + r) / 2);
    const res = guess(mid);
    if (res === 0) return mid;
    if (res === -1) {
      r = mid - 1;
    } else {
      l = mid + 1;
    }
  }
  return -1;
};
```

### 复杂度分析

- 时间复杂度：O(log n)。
- 空间复杂度：O(1)。
