# 增减字符串匹配

> 难度：简单 | 标签：贪心、数组、双指针、数学 | [LeetCode 原题](https://leetcode.cn/problems/di-string-match/description/)

## 题目描述

由范围 `[0,n]` 内所有整数组成的 `n + 1` 个整数的排列序列可以表示为长度为 `n` 的字符串 `s`，其中：如果 `perm[i] < perm[i + 1]`，那么 `s[i] == 'I'`（递增）；如果 `perm[i] > perm[i + 1]`，那么 `s[i] == 'D'`（递减）。给定一个字符串 `s`，重构出它的任意一个有效排列并返回。

**示例 1：**

```
输入：s = "IDID"
输出：[0,4,1,3,2]
```

**示例 2：**

```
输入：s = "III"
输出：[0,1,2,3]
```

**示例 3：**

```
输入：s = "DDI"
输出：[3,2,0,1]
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 只包含字符 `"I"` 或 `"D"`

## 题解

::: details 点击查看题解

### 思路

贪心构造：维护可用数字区间的两端 `low = 0`、`high = n`。遇到 `'I'` 就放当前最小的数（保证下一个比它大），遇到 `'D'` 就放当前最大的数（保证下一个比它小）。每放一个数区间收缩一格，最后剩下的一个数直接放到末尾。

### 代码实现

```javascript
var diStringMatch = function(s) {
  let low = 0;
  let high = s.length;
  const res = [];
  for (const ch of s) {
    if (ch === "I") {
      res.push(low++);
    } else {
      res.push(high--);
    }
  }
  res.push(low);
  return res;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)（不计返回数组）。
