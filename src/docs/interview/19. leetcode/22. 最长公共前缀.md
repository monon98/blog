# 最长公共前缀

> 难度：简单 | 标签：字符串、字典树 | [LeetCode 原题](https://leetcode.cn/problems/longest-common-prefix/description/)

## 题目描述

编写一个函数来查找字符串数组中的最长公共前缀。如果不存在公共前缀，返回空字符串 `""`。

**示例 1：**

```
输入：strs = ["flower","flow","flight"]
输出："fl"
```

**示例 2：**

```
输入：strs = ["dog","racecar","car"]
输出：""
解释：输入不存在公共前缀。
```

**提示：**

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 仅由小写英文字母组成

## 题解

::: details 点击查看题解

### 思路

以第一个字符串为初始前缀，逐个与后续字符串比较：只要当前字符串不是以该前缀开头，就不断把前缀缩短一位，直到匹配或前缀为空。所有字符串处理完后剩下的就是最长公共前缀。

也可以纵向扫描：按列逐字符比较所有字符串同一位置的字符，遇到不同立即返回。

### 代码实现

```javascript
var longestCommonPrefix = function(strs) {
  let prefix = strs[0];
  for (let i = 1; i < strs.length; i++) {
    while (!strs[i].startsWith(prefix)) {
      prefix = prefix.slice(0, -1);
      if (!prefix) return "";
    }
  }
  return prefix;
};
```

### 复杂度分析

- 时间复杂度：O(S)，S 为所有字符总数（最坏情况）。
- 空间复杂度：O(1)，只维护一个前缀引用。
