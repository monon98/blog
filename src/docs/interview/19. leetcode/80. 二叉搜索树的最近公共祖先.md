# 二叉搜索树的最近公共祖先

> 难度：简单 | 标签：树、深度优先搜索、二叉搜索树、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/description/)

## 题目描述

给定一个二叉搜索树，找到该树中两个指定节点的最近公共祖先（LCA）。最近公共祖先的定义为：对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。

**示例 1：**

```
输入：root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8
输出：6
解释：节点 2 和节点 8 的最近公共祖先是 6。
```

**示例 2：**

```
输入：root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 4
输出：2
解释：节点 2 和节点 4 的最近公共祖先是 2，因为根据定义最近公共祖先节点可以为节点本身。
```

**提示：**

- 树中节点数在 `[2, 10^5]` 内
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` 互不相同
- `p != q`，p 和 q 均存在于给定的 BST 中

## 题解

::: details 点击查看题解

### 思路

利用 BST 的有序性：从根向下走——若 p、q 都小于当前节点，公共祖先在左子树；都大于则在右子树；一旦出现「一左一右」（或等于当前值），当前节点就是分叉点，即最近公共祖先。无需递归回溯，一次迭代即可。

普通二叉树的 LCA 需要递归查找两侧再汇合，而 BST 版本靠大小关系直接导航。

### 代码实现

```javascript
var lowestCommonAncestor = function(root, p, q) {
  while (root) {
    if (p.val < root.val && q.val < root.val) {
      root = root.left;
    } else if (p.val > root.val && q.val > root.val) {
      root = root.right;
    } else {
      return root;
    }
  }
};
```

### 复杂度分析

- 时间复杂度：O(h)，h 为树高。
- 空间复杂度：O(1)。
