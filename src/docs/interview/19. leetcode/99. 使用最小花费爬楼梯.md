# 使用最小花费爬楼梯

> 难度：简单 | 标签：数组、动态规划 | [LeetCode 原题](https://leetcode.cn/problems/min-cost-climbing-stairs/description/)

## 题目描述

给你一个整数数组 `cost`，其中 `cost[i]` 是从楼梯第 `i` 个台阶向上爬需要支付的费用。一旦你支付此费用，即可选择向上爬一个或者两个台阶。你可以选择从下标为 0 或下标为 1 的台阶开始爬楼梯。请你计算并返回达到楼梯顶部的最低花费（楼顶不在数组内，是最后一个台阶的上一级）。

**示例 1：**

```
输入：cost = [10,15,20]
输出：15
解释：从 cost[1] 开始，支付 15，走两步到楼顶。
```

**示例 2：**

```
输入：cost = [1,100,1,1,1,100,1,1,100,1]
输出：6
解释：最低花费方式是从 cost[0] 开始，逐个经过那些花 1 的台阶。
```

**提示：**

- `2 <= cost.length <= 1000`
- `0 <= cost[i] <= 999`

## 题解

::: details 点击查看题解

### 思路

设 `dp[i]` 为到达第 i 级台阶的最低花费，则 `dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`——可以从 i-1 级跨一步或 i-2 级跨两步上来，各付对应台阶的费用。起点 dp[0] = dp[1] = 0（可免费站在前两级）。答案是 `dp[n]`。

用两个滚动变量代替数组即可把空间降到 O(1)。

### 代码实现

```javascript
var minCostClimbingStairs = function(cost) {
  const n = cost.length;
  let prev = 0;
  let cur = 0;
  for (let i = 2; i <= n; i++) {
    const next = Math.min(cur + cost[i - 1], prev + cost[i - 2]);
    prev = cur;
    cur = next;
  }
  return cur;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。

:::
