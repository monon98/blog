# 仅仅反转字母

> 难度：简单 | 标签：双指针、字符串 | [LeetCode 原题](https://leetcode.cn/problems/reverse-only-letters/description/)

## 题目描述

给你一个字符串 `s`，根据下述规则反转它：所有英文字母反转位置，非英文字母的位置保持不变。返回反转后的结果。

**示例 1：**

```
输入：s = "ab-cd"
输出："dc-ba"
```

**示例 2：**

```
输入：s = "a-bC-dEf-ghIj"
输出："j-Ih-gfE-dCba"
```

**示例 3：**

```
输入：s = "Test1ng-Leet=code-Q!"
输出："Qedo1ct-eeLg=ntse-T!"
```

**提示：**

- `0 <= s.length <= 100`
- `s` 包含 ASCII 字符，其中字母为英文字母（大小写）

## 题解

::: details 点击查看题解

### 思路

首尾双指针 + 字母判断。左右指针分别跳过非字母字符，遇到两个字母就交换并继续向中间推进。非字母字符始终留在原位。

### 代码实现

```javascript
var reverseOnlyLetters = function(s) {
  const isLetter = (c) => (c >= "a" && c <= "z") || (c >= "A" && c <= "Z");
  const arr = s.split("");
  let l = 0;
  let r = arr.length - 1;
  while (l < r) {
    if (!isLetter(arr[l])) {
      l++;
    } else if (!isLetter(arr[r])) {
      r--;
    } else {
      const t = arr[l];
      arr[l] = arr[r];
      arr[r] = t;
      l++;
      r--;
    }
  }
  return arr.join("");
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(n)，字符数组（字符串不可变）。
