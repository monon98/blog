# 反转字符串中的元音字母

> 难度：简单 | 标签：双指针、字符串 | [LeetCode 原题](https://leetcode.cn/problems/reverse-vowels-of-a-string/description/)

## 题目描述

给你一个字符串 `s`，仅反转字符串中的所有元音字母，并返回结果字符串。元音字母包括 `'a'`、`'e'`、`'i'`、`'o'`、`'u'`，且可能以大小写两种形式出现不止一次。

**示例 1：**

```
输入：s = "hello"
输出："holle"
```

**示例 2：**

```
输入：s = "leetcode"
输出："leotcede"
```

**提示：**

- `1 <= s.length <= 3 * 10^5`
- 由可打印的 ASCII 字符组成

## 题解

::: details 点击查看题解

### 思路

与「仅仅反转字母」同款套路：首尾双指针分别跳过非元音字符，两个指针都停在元音上时交换。用 `Set` 存放十个元音字符做 O(1) 查询。

### 代码实现

```javascript
var reverseVowels = function(s) {
  const vowels = new Set(["a", "e", "i", "o", "u", "A", "E", "I", "O", "U"]);
  const arr = s.split("");
  let l = 0;
  let r = arr.length - 1;
  while (l < r) {
    if (!vowels.has(arr[l])) {
      l++;
    } else if (!vowels.has(arr[r])) {
      r--;
    } else {
      const t = arr[l];
      arr[l] = arr[r];
      arr[r] = t;
      l++;
      r--;
    }
  }
  return arr.join("");
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(n) 字符数组 + O(1) 元音集合。
