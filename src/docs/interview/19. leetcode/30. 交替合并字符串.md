# 交替合并字符串

> 难度：简单 | 标签：双指针、字符串 | [LeetCode 原题](https://leetcode.cn/problems/merge-strings-alternately/description/)

## 题目描述

给你两个字符串 `word1` 和 `word2`，从 `word1` 开始通过交替添加字母来合并字符串。如果一个字符串比另一个字符串长，请把多出来的字母追加到合并字符串的末尾。返回合并后的字符串。

**示例 1：**

```
输入：word1 = "abc", word2 = "pqr"
输出："apbqcr"
```

**示例 2：**

```
输入：word1 = "ab", word2 = "pqrs"
输出："apbqrs"
解释：注意 "rs" 被追加到末尾。
```

**示例 3：**

```
输入：word1 = "abcd", word2 = "pq"
输出："apbqcd"
```

**提示：**

- `1 <= word1.length, word2.length <= 100`

## 题解

::: details 点击查看题解

### 思路

按最大长度循环，每轮先取 `word1[i]`（若存在）再取 `word2[i]`（若存在），超出长度的自动被跳过，最后多出的尾部自然追加。

### 代码实现

```javascript
var mergeAlternately = function(word1, word2) {
  let res = "";
  const n = Math.max(word1.length, word2.length);
  for (let i = 0; i < n; i++) {
    if (i < word1.length) res += word1[i];
    if (i < word2.length) res += word2[i];
  }
  return res;
};
```

### 复杂度分析

- 时间复杂度：O(m + n)。
- 空间复杂度：O(1)（不计结果字符串）。
