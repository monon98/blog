# 验证回文串 II

> 难度：简单 | 标签：贪心、双指针、字符串 | [LeetCode 原题](https://leetcode.cn/problems/valid-palindrome-ii/description/)

## 题目描述

给你一个字符串 `s`，最多可以从中删除一个字符。判断是否能成为回文字符串，如果能返回 `true`，否则返回 `false`。

**示例 1：**

```
输入：s = "aba"
输出：true
```

**示例 2：**

```
输入：s = "abca"
输出：true
解释：可以删除 "c" 字符。
```

**示例 3：**

```
输入：s = "abc"
输出：false
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 由小写英文字母组成

## 题解

::: details 点击查看题解

### 思路

首尾双指针向中间比较，遇到第一处不匹配时面临两种选择：删掉左字符或删掉右字符。分别检查跳过左指针或跳过右指针后剩余区间是否为回文，任意一种成立即可。由于只允许删一个字符，后续区间必须严格回文，不能再出现不匹配。

### 代码实现

```javascript
var validPalindrome = function(s) {
  const isPalindromeRange = (l, r) => {
    while (l < r) {
      if (s[l] !== s[r]) return false;
      l++;
      r--;
    }
    return true;
  };

  let l = 0;
  let r = s.length - 1;
  while (l < r) {
    if (s[l] !== s[r]) {
      return isPalindromeRange(l + 1, r) || isPalindromeRange(l, r - 1);
    }
    l++;
    r--;
  }
  return true;
};
```

### 复杂度分析

- 时间复杂度：O(n)，主扫描最多 n 步，两次额外检查各 O(n)。
- 空间复杂度：O(1)。

:::
