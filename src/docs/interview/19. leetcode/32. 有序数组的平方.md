# 有序数组的平方

> 难度：简单 | 标签：数组、双指针、排序 | [LeetCode 原题](https://leetcode.cn/problems/squares-of-a-sorted-array/description/)

## 题目描述

给你一个按非递减顺序排序的整数数组 `nums`，返回每个数字的平方组成的新数组，要求也按非递减顺序排序。请设计时间复杂度为 O(n) 的算法解决本问题。

**示例 1：**

```
输入：nums = [-4,-1,0,3,10]
输出：[0,1,9,16,100]
解释：平方后为 [16,1,0,9,100]，排序后为 [0,1,9,16,100]。
```

**示例 2：**

```
输入：nums = [-7,-3,2,3,11]
输出：[4,9,9,49,121]
```

**提示：**

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 已按非递减顺序排序

## 题解

::: details 点击查看题解

### 思路

平方后最大的数一定出现在原数组的两端（负数绝对值大或正数大）。首尾双指针比较两端平方值，把较大者放入结果数组的末尾，对应指针向中间收缩。

从结果末尾向前填充是本题的关键技巧，避免了找「最小值」的困难。直接平方后排序是 O(n log n)，不满足进阶要求。

### 代码实现

```javascript
var sortedSquares = function(nums) {
  const n = nums.length;
  const res = new Array(n);
  let l = 0;
  let r = n - 1;
  let pos = n - 1;
  while (l <= r) {
    const left = nums[l] * nums[l];
    const right = nums[r] * nums[r];
    if (left > right) {
      res[pos--] = left;
      l++;
    } else {
      res[pos--] = right;
      r--;
    }
  }
  return res;
};
```

### 复杂度分析

- 时间复杂度：O(n)，单次双指针扫描。
- 空间复杂度：O(n)（不计返回数组则为 O(1)）。
