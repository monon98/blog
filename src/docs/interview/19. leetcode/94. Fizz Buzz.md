# Fizz Buzz

> 难度：简单 | 标签：数学、字符串、模拟 | [LeetCode 原题](https://leetcode.cn/problems/fizz-buzz/description/)

## 题目描述

给你一个整数 `n`，返回一个字符串数组 `answer`（下标从 1 开始），其中：

- `answer[i] == "FizzBuzz"`：如果 `i` 同时是 3 和 5 的倍数
- `answer[i] == "Fizz"`：如果 `i` 是 3 的倍数
- `answer[i] == "Buzz"`：如果 `i` 是 5 的倍数
- `answer[i] == i`（字符串形式）：上述条件都不满足

**示例 1：**

```
输入：n = 3
输出：["1","2","Fizz"]
```

**示例 2：**

```
输入：n = 15
输出：["1","2","Fizz","4","Buzz","Fizz","7","8","Fizz","Buzz","11","Fizz","13","14","FizzBuzz"]
```

**提示：**

- `1 <= n <= 10^4`

## 题解

::: details 点击查看题解

### 思路

按条件分支拼接。注意「同时是 3 和 5 的倍数」要最先判断（等价于 15 的倍数），否则会被单条件提前命中。

进阶写法可以维护一个空串，能整除 3 就加 "Fizz"、能整除 5 就加 "Buzz"，最后为空就放数字本身——这种写法在扩展更多规则时改动最小。

### 代码实现

```javascript
var fizzBuzz = function(n) {
  const res = [];
  for (let i = 1; i <= n; i++) {
    let item = "";
    if (i % 3 === 0) item += "Fizz";
    if (i % 5 === 0) item += "Buzz";
    res.push(item || String(i));
  }
  return res;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)（不计结果数组）。
