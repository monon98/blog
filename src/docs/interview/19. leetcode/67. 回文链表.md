# 回文链表

> 难度：简单 | 标签：栈、递归、链表、双指针 | [LeetCode 原题](https://leetcode.cn/problems/palindrome-linked-list/description/)

## 题目描述

给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。如果是，返回 `true`；否则，返回 `false`。

**示例 1：**

```
输入：head = [1,2,2,1]
输出：true
```

**示例 2：**

```
输入：head = [1,2]
输出：false
```

**提示：**

- 链表中节点数目在范围 `[1, 10^5]` 内
- `0 <= Node.val <= 9`

**进阶：** 你能否用 O(n) 时间复杂度和 O(1) 空间复杂度解决此题？

## 题解

::: details 点击查看题解

### 思路

最直观的做法是把值拷进数组后用双指针首尾比较。

进阶 O(1) 空间做法分三步：快慢指针找中点（快两倍速，慢指针停在中间）→ 反转后半段链表 → 前半段与反转后的后半段逐节点比较。比较完可以选择把后半段再反转回去还原结构。核心子步骤「找中点」「反转链表」都是高频面试考点。

### 代码实现

```javascript
var isPalindrome = function(head) {
  const values = [];
  while (head) {
    values.push(head.val);
    head = head.next;
  }
  let l = 0;
  let r = values.length - 1;
  while (l < r) {
    if (values[l] !== values[r]) return false;
    l++;
    r--;
  }
  return true;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(n)；快慢指针 + 原地反转法可优化至 O(1)。
