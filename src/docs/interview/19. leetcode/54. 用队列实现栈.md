# 用队列实现栈

> 难度：简单 | 标签：栈、设计、队列 | [LeetCode 原题](https://leetcode.cn/problems/implement-stack-using-queues/description/)

## 题目描述

请你仅使用两个（或一个）队列实现一个后入先出（LIFO）的栈，并支持普通栈的全部四种操作：`push`、`pop`、`top` 和 `empty`。你必须仅使用队列的标准操作——即只能 `push to back`、`peek/pop from front`、`size` 和 `is empty`。

**示例 1：**

```
输入：
["MyStack", "push", "push", "top", "pop", "empty"]
[[], [1], [2], [], [], []]

输出：[null, null, null, 2, 2, false]
```

**提示：**

- `1 <= x <= 9`
- 最多调用 `100` 次 `push`、`pop`、`top` 和 `empty`
- 每次调用 `pop` 和 `top` 都保证栈不为空

## 题解

::: details 点击查看题解

### 思路

单队列 + 入队时旋转：push 新元素后，把前面 size - 1 个元素依次出队再重新入队，这样新元素就排到了队头，与栈顶语义一致。此后 pop 直接从队头取出，top 直接读队头。

JavaScript 数组用 `push` 模拟入队、`shift` 模拟出队。旋转使 push 变为 O(n)，其余操作 O(1)；也可以让 pop/top 时旋转，把开销挪到出栈操作上。

### 代码实现

```javascript
var MyStack = function () {
  this.queue = [];
};

MyStack.prototype.push = function (x) {
  this.queue.push(x);
  for (let i = 1; i < this.queue.length; i++) {
    this.queue.push(this.queue.shift());
  }
};

MyStack.prototype.pop = function () {
  return this.queue.shift();
};

MyStack.prototype.top = function () {
  return this.queue[0];
};

MyStack.prototype.empty = function () {
  return this.queue.length === 0;
};
```

### 复杂度分析

- 时间复杂度：push 为 O(n)，pop / top / empty 为 O(1)。
- 空间复杂度：O(n)。
