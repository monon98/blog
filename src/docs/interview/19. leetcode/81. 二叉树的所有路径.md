# 二叉树的所有路径

> 难度：简单 | 标签：树、深度优先搜索、字符串、回溯、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/binary-tree-paths/description/)

## 题目描述

给你一个二叉树的根节点 `root`，按任意顺序返回所有从根节点到叶子节点的路径。叶子节点是指没有子节点的节点。

**示例 1：**

```
输入：root = [1,2,3,null,5]
输出：["1->2->5","1->3"]
```

**示例 2：**

```
输入：root = [1]
输出：["1"]
```

**提示：**

- 树中节点的数目在范围 `[1, 100]` 内
- `-100 <= Node.val <= 100`

## 题解

::: details 点击查看题解

### 思路

DFS + 回溯：维护当前路径数组，进入节点时 push 值；到达叶子时把路径用 `->` 拼接存入结果；离开时 pop 回退（回溯），保证兄弟分支拿到的是干净路径。

也可以让递归函数直接携带拼接好的字符串（`path + "->" + val`），省去显式回溯，代价是产生更多临时字符串。

### 代码实现

```javascript
var binaryTreePaths = function(root) {
  const res = [];
  const dfs = (node, path) => {
    if (!node) return;
    path.push(node.val);
    if (!node.left && !node.right) {
      res.push(path.join("->"));
    } else {
      dfs(node.left, path);
      dfs(node.right, path);
    }
    path.pop();
  };
  dfs(root, []);
  return res;
};
```

### 复杂度分析

- 时间复杂度：O(n · h)，n 为节点数、h 为树高（每条路径的拼接开销）。
- 空间复杂度：O(h) 递归与路径数组（不计结果）。
