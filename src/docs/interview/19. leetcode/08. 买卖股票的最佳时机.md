# 买卖股票的最佳时机

> 难度：简单 | 标签：数组、动态规划、贪心 | [LeetCode 原题](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/description/)

## 题目描述

给定一个数组 `prices`，它的第 `i` 个元素表示某支股票第 `i` 天的价格。你只能选择某一天买入这只股票，并选择在未来的某一个不同的日子卖出该股票。设计一个算法计算你能获取的最大利润，若不能获取任何利润返回 0。

**示例 1：**

```
输入：prices = [7,1,5,3,6,4]
输出：5
解释：在第 2 天（价格 = 1）买入，第 5 天（价格 = 6）卖出，利润 = 6 - 1 = 5。
```

**示例 2：**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：价格持续下跌，不交易利润为 0。
```

**提示：**

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

## 题解

::: details 点击查看题解

### 思路

一次遍历维护两个量：历史最低价 `minPrice` 和当前最大利润 `profit`。每天先尝试更新最低价，再用「今天价格 − 历史最低价」更新最大利润。这样保证卖出的日子一定在买入的日子之后。

暴力双重循环 O(n²) 会超时，本写法只需 O(n)。

### 代码实现

```javascript
var maxProfit = function(prices) {
  let minPrice = Infinity;
  let profit = 0;
  for (const p of prices) {
    if (p < minPrice) {
      minPrice = p;
    } else if (p - minPrice > profit) {
      profit = p - minPrice;
    }
  }
  return profit;
};
```

### 复杂度分析

- 时间复杂度：O(n)，单次遍历。
- 空间复杂度：O(1)，只用了两个变量。
