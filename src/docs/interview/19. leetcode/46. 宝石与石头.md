# 宝石与石头

> 难度：简单 | 标签：哈希表、字符串 | [LeetCode 原题](https://leetcode.cn/problems/jewels-and-stones/description/)

## 题目描述

给你一个字符串 `jewels` 代表石头中宝石的类型，另有一个字符串 `stones` 代表你拥有的石头。`stones` 中每个字符代表一种你拥有的石头的类型，你想知道你拥有多少颗宝石。字母区分大小写，因此 `"a"` 和 `"A"` 是不同类型的石头。

**示例 1：**

```
输入：jewels = "aA", stones = "aAAbbbb"
输出：3
```

**示例 2：**

```
输入：jewels = "z", stones = "ZZ"
输出：0
```

**提示：**

- `1 <= jewels.length, stones.length <= 50`
- `jewels` 和 `stones` 仅由英文字母组成
- `jewels` 中的所有字符都是唯一的

## 题解

::: details 点击查看题解

### 思路

把宝石类型放进 Set（O(1) 查询），再遍历石头统计命中次数。暴力双重循环是 O(m · n)，用集合把查询降到 O(1)。

### 代码实现

```javascript
var numJewelsInStones = function(jewels, stones) {
  const set = new Set(jewels);
  let count = 0;
  for (const ch of stones) {
    if (set.has(ch)) count++;
  }
  return count;
};
```

### 复杂度分析

- 时间复杂度：O(m + n)。
- 空间复杂度：O(1)，字符集大小固定为 ASCII 字母。
