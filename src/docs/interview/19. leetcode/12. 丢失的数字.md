# 丢失的数字

> 难度：简单 | 标签：位运算、数组、数学 | [LeetCode 原题](https://leetcode.cn/problems/missing-number/description/)

## 题目描述

给定一个包含 `[0, n]` 中 `n` 个数的数组 `nums`，找出 `[0, n]` 范围内没有出现在数组中的那个数。

**示例 1：**

```
输入：nums = [3,0,1]
输出：2
解释：n = 3，因为有 3 个数字，所以所有的数字都在范围 [0,3] 内。2 是丢失的数字。
```

**示例 2：**

```
输入：nums = [9,6,4,2,3,5,7,0,1]
输出：8
```

**提示：**

- `n == nums.length`
- `1 <= n <= 10^4`
- `0 <= nums[i] <= n`
- `nums` 中的所有数字都互不相同

**进阶：** 你能否实现线性时间复杂度、仅使用额外常数空间来解决此问题？

## 题解

::: details 点击查看题解

### 思路

高斯求和法：`[0, n]` 的完整和为 `n * (n + 1) / 2`，用这个理论总和减去数组实际元素之和，差值就是缺失的数。一次遍历即可，无需额外空间。

异或法同样优秀：把下标 0..n 与所有元素一起异或，成对的值抵消，剩下缺失的数，且不存在求和溢出问题。

### 代码实现

```javascript
var missingNumber = function(nums) {
  const n = nums.length;
  let sum = (n * (n + 1)) / 2;
  for (const x of nums) {
    sum -= x;
  }
  return sum;
};
```

```javascript
var missingNumber = function(nums) {
  let res = nums.length;
  for (let i = 0; i < nums.length; i++) {
    res ^= i ^ nums[i];
  }
  return res;
};
```

### 复杂度分析

- 时间复杂度：O(n)，单次遍历。
- 空间复杂度：O(1)。
