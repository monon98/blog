# 在长度 2N 的数组中找出重复 N 次的元素

> 难度：简单 | 标签：数组、哈希表 | [LeetCode 原题](https://leetcode.cn/problems/n-repeated-element-in-size-2n-array/description/)

## 题目描述

给你一个整数数组 `nums`，该数组具有以下属性：数组长度为 `2n`，其中包含 `n + 1` 个不同的元素；其中恰有一个元素重复了 `n` 次。找出并返回重复了 `n` 次的那个元素。

**示例 1：**

```
输入：nums = [1,2,3,3]
输出：3
```

**示例 2：**

```
输入：nums = [2,1,2,5,3,2]
输出：2
```

**示例 3：**

```
输入：nums = [5,1,5,2,5,3,5,4]
输出：5
```

**提示：**

- `2 <= n <= 5000`
- `nums.length == 2 * n`
- `0 <= nums[i] <= 10^4`
- `nums` 由 `n + 1` 个不同的元素组成，且其中一个元素恰好重复 `n` 次

## 题解

::: details 点击查看题解

### 思路

用 Set 边遍历边检测，第一次遇到已存在的元素就是答案——因为其余 n 个元素各不相同。

更巧妙的数学观察：重复元素的两次出现距离不会超过 3（鸽笼原理），所以只需检查每个位置与前 1、2、3 位是否相等即可，空间降为 O(1)。

### 代码实现

```javascript
var repeatedNTimes = function(nums) {
  const seen = new Set();
  for (const x of nums) {
    if (seen.has(x)) return x;
    seen.add(x);
  }
  return -1;
};
```

### 复杂度分析

- 时间复杂度：O(n)，平均情况下很快命中。
- 空间复杂度：O(n)，Set 存储；间隔检查法可优化到 O(1)。
