# 买卖股票的最佳时机 II

> 难度：简单 | 标签：贪心、数组、动态规划 | [LeetCode 原题](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/description/)

## 题目描述

给你一个整数数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。在每一天你可以决定是否购买或出售股票，你在任何时候最多只能持有一股股票，也可以先购买然后在同一天出售。返回你能获得的最大利润。

**示例 1：**

```
输入：prices = [7,1,5,3,6,4]
输出：7
解释：第 2 天买入（价格 1）第 3 天卖出（价格 5）得 4；第 4 天买入（价格 3）第 5 天卖出（价格 6）得 3，总利润 4 + 3 = 7。
```

**示例 2：**

```
输入：prices = [1,2,3,4,5]
输出：4
解释：每天上涨，第 1 天买最后一天卖即可，利润 4。
```

**提示：**

- `1 <= prices.length <= 3 * 10^4`
- `0 <= prices[i] <= 10^4`

## 题解

::: details 点击查看题解

### 思路

与只能交易一次的版本不同，这里允许多次交易，可以用贪心：只要今天比昨天价格高，就把这段差价累加进利润。因为任何一段上涨区间都可以拆成相邻两天的小涨幅之和，收集所有「正差价」等价于在每个上升坡底买入、坡顶卖出。

### 代码实现

```javascript
var maxProfit = function(prices) {
  let profit = 0;
  for (let i = 1; i < prices.length; i++) {
    if (prices[i] > prices[i - 1]) {
      profit += prices[i] - prices[i - 1];
    }
  }
  return profit;
};
```

### 复杂度分析

- 时间复杂度：O(n)，单次遍历。
- 空间复杂度：O(1)。

:::
