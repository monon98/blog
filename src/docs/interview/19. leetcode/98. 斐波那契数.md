# 斐波那契数

> 难度：简单 | 标签：递归、记忆化搜索、数学、动态规划 | [LeetCode 原题](https://leetcode.cn/problems/fibonacci-number/description/)

## 题目描述

斐波那契数（通常用 `F(n)` 表示）形成的序列称为斐波那契数列。该数列由 0 和 1 开始，后面的每一项数字都是前面两项数字的和：`F(0) = 0, F(1) = 1; F(n) = F(n - 1) + F(n - 2)`（n > 1）。给定 `n`，请计算 `F(n)`。

**示例 1：**

```
输入：n = 2
输出：1
解释：F(2) = F(1) + F(0) = 1 + 0 = 1。
```

**示例 2：**

```
输入：n = 4
输出：3
解释：F(4) = F(3) + F(2) = 2 + 1 = 3。
```

**提示：**

- `0 <= n <= 30`

## 题解

::: details 点击查看题解

### 思路

迭代 + 滚动变量：从 F(0)、F(1) 出发逐项推进到第 n 项。相比朴素递归（指数级重复计算），线性递推是标准解法；矩阵快速幂可进一步优化到 O(log n)，属于进阶知识。

本题与「爬楼梯」互为同一模型的两种表述，是动态规划的起点。

### 代码实现

```javascript
var fib = function(n) {
  if (n < 2) return n;
  let a = 0;
  let b = 1;
  for (let i = 2; i <= n; i++) {
    const sum = a + b;
    a = b;
    b = sum;
  }
  return b;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。
