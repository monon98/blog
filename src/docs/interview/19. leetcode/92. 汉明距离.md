# 汉明距离

> 难度：简单 | 标签：位运算 | [LeetCode 原题](https://leetcode.cn/problems/hamming-distance/description/)

## 题目描述

两个整数之间的汉明距离指的是这两个数字对应二进制位不同的位置的数目。给你两个整数 `x` 和 `y`，计算并返回它们之间的汉明距离。

**示例 1：**

```
输入：x = 1, y = 4
输出：2
解释：1 (0 0 0 1)；4 (0 1 0 0)。箭头指出了对应二进制位不同的位置。
```

**示例 2：**

```
输入：x = 3, y = 1
输出：1
```

**提示：**

- `0 <= x, y <= 2^31 - 1`

## 题解

::: details 点击查看题解

### 思路

先异或：异或结果中为 1 的位恰好是两数不同的位。再统计异或值中 1 的个数，直接复用「位 1 的个数」的 Brian Kernighan 技巧（`z &= z - 1` 每次消掉最低位的 1）。

### 代码实现

```javascript
var hammingDistance = function(x, y) {
  let z = x ^ y;
  let count = 0;
  while (z !== 0) {
    z &= z - 1;
    count++;
  }
  return count;
};
```

### 复杂度分析

- 时间复杂度：O(k)，k 为不同位的个数。
- 空间复杂度：O(1)。

:::
