# 找出字符串中第一个匹配项的下标

> 难度：简单 | 标签：双指针、字符串、字符串匹配 | [LeetCode 原题](https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/description/)

## 题目描述

给你两个字符串 `haystack` 和 `needle`，请你在 `haystack` 字符串中找出 `needle` 字符串的第一个匹配项的下标（下标从 0 开始）。如果 `needle` 不是 `haystack` 的一部分，则返回 `-1`。

**示例 1：**

```
输入：haystack = "sadbutsad", needle = "sad"
输出：0
解释："sad" 在下标 0 处第一次出现。
```

**示例 2：**

```
输入：haystack = "leetcode", needle = "leeto"
输出：-1
解释："leeto" 没有在 "leetcode" 中出现过。
```

**提示：**

- `1 <= haystack.length, needle.length <= 10^4`
- `haystack` 和 `needle` 仅由小写英文字符组成

## 题解

::: details 点击查看题解

### 思路

朴素匹配即可通过本题数据规模：枚举每个可能的起点 i，截取长度为 `needle.length` 的子串与 `needle` 比较。也可以用内置的 `indexOf`（底层实现通常经过优化）。

面试加分项是 KMP 算法：先对 `needle` 构造前缀函数（next 数组），失配时利用已匹配前缀的信息跳过不必要的比较，将时间降到严格的 O(n + m)。

### 代码实现

```javascript
var strStr = function(haystack, needle) {
  for (let i = 0; i + needle.length <= haystack.length; i++) {
    if (haystack.slice(i, i + needle.length) === needle) return i;
  }
  return -1;
};
```

### 复杂度分析

- 时间复杂度：O((n - m) * m)，n 为 haystack 长度、m 为 needle 长度；KMP 可达 O(n + m)。
- 空间复杂度：O(1)；KMP 需要 O(m) 的 next 数组。

:::
