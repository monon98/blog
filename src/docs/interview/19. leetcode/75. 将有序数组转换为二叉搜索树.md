# 将有序数组转换为二叉搜索树

> 难度：简单 | 标签：树、二叉搜索树、数组、分治、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/description/)

## 题目描述

给你一个整数数组 `nums`，其中元素已经按升序排列，请你将其转换为一棵平衡的二叉搜索树。

**示例 1：**

```
输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
解释：另一个答案是 [0,-10,9,null,null,5,-3]，也被认为是正确答案。
```

**示例 2：**

```
输入：nums = [1,3]
输出：[3,1] 或 [1,3]
```

**提示：**

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 按严格递增顺序排列

## 题解

::: details 点击查看题解

### 思路

分治：有序数组的中位数天然适合做根——以中间元素建根，左半部分递归构建左子树，右半部分递归构建右子树。每次取中点分割保证左右子树规模均衡，因此结果自动是高度平衡的 BST。答案不唯一（偶数长度时取 `mid` 或 `mid + 1` 都合法），题目接受任意平衡解。

### 代码实现

```javascript
var sortedArrayToBST = function(nums) {
  const build = (l, r) => {
    if (l > r) return null;
    const mid = (l + r) >> 1;
    const node = new TreeNode(nums[mid]);
    node.left = build(l, mid - 1);
    node.right = build(mid + 1, r);
    return node;
  };
  return build(0, nums.length - 1);
};
```

### 复杂度分析

- 时间复杂度：O(n)，每个元素恰好创建一个节点。
- 空间复杂度：O(log n)，递归栈深度为平衡树高（不计返回的树）。
