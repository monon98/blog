# 存在重复元素

> 难度：简单 | 标签：数组、哈希表、排序 | [LeetCode 原题](https://leetcode.cn/problems/contains-duplicate/description/)

## 题目描述

给你一个整数数组 `nums`。如果任一数值在数组中至少出现两次，返回 `true`；如果数组中每个元素互不相同，返回 `false`。

**示例 1：**

```
输入：nums = [1,2,3,1]
输出：true
```

**示例 2：**

```
输入：nums = [1,2,3,4]
输出：false
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 题解

::: details 点击查看题解

### 思路

利用 `Set` 的去重特性：集合大小小于数组长度说明存在重复，一行解决。

也可以先排序后比较相邻元素（O(n log n) 时间、O(1) 空间），或边遍历边往 Set 里插入、发现已存在立即返回（平均 O(n)，最坏情况能提前结束）。

### 代码实现

```javascript
var containsDuplicate = function(nums) {
  return new Set(nums).size !== nums.length;
};
```

### 复杂度分析

- 时间复杂度：O(n)，构建哈希集合。
- 空间复杂度：O(n)。
