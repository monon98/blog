# 相交链表

> 难度：简单 | 标签：哈希表、链表、双指针 | [LeetCode 原题](https://leetcode.cn/problems/intersection-of-two-linked-lists/description/)

## 题目描述

给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。整个链式结构中不存在环，函数返回结果后，链表必须保持原有结构。

**示例 1：**

```
输入：intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
输出：Intersected at '8'
```

**示例 2：**

```
输入：intersectVal = 2, listA = [1,9,1,2,4], listB = [3,2,4], skipA = 3, skipB = 1
输出：Intersected at '2'
```

**提示：**

- `listA` 中节点数目为 `m`，`listB` 中节点数目为 `n`
- `1 <= m, n <= 3 * 10^4`
- 进阶：你能否设计一个时间复杂度 O(m + n)、仅用 O(1) 内存的解决方案？

## 题解

::: details 点击查看题解

### 思路

浪漫双指针法：指针 a 从 headA 出发，走完后转到 headB；指针 b 从 headB 出发，走完后转到 headA。两者走过的总步数都是 m + n，若相交必然在交点同时到达（消除长度差）；不相交则同时到达 null。

也可以先算出两链表长度差，让长链先走差值步再同步前进；哈希集合记录 A 的所有节点再扫 B 则是 O(m) 空间的朴素做法。

### 代码实现

```javascript
var getIntersectionNode = function(headA, headB) {
  let a = headA;
  let b = headB;
  while (a !== b) {
    a = a ? a.next : headB;
    b = b ? b.next : headA;
  }
  return a;
};
```

### 复杂度分析

- 时间复杂度：O(m + n)，两指针最多各走 m + n 步。
- 空间复杂度：O(1)。

:::
