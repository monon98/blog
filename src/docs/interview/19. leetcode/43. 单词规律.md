# 单词规律

> 难度：简单 | 标签：哈希表、字符串 | [LeetCode 原题](https://leetcode.cn/problems/word-pattern/description/)

## 题目描述

给定一种规律 `pattern` 和一个字符串 `s`，判断 `s` 是否遵循相同的规律。这里的「遵循」指完全匹配，例如 `pattern` 里的每个字母和字符串 `s` 中的每个非空单词之间存在双向连接的对应规律。

**示例 1：**

```
输入：pattern = "abba", s = "dog cat cat dog"
输出：true
```

**示例 2：**

```
输入：pattern = "abba", s = "dog cat cat fish"
输出：false
```

**示例 3：**

```
输入：pattern = "aaaa", s = "dog cat cat dog"
输出：false
```

**提示：**

- `1 <= pattern.length <= 300`
- `pattern` 只包含小写英文字母
- `1 <= s.length <= 3000`
- `s` 只包含小写英文和空格，且不含前导或尾随空格

## 题解

::: details 点击查看题解

### 思路

与「同构字符串」同源：把字符映射到单词，同时要求反向映射也唯一。先按空格切分 `s`，长度与 `pattern` 不等直接 false；再用两个哈希表逐位校验双向一致性。

### 代码实现

```javascript
var wordPattern = function(pattern, s) {
  const words = s.split(" ");
  if (pattern.length !== words.length) return false;
  const p2w = {};
  const w2p = {};
  for (let i = 0; i < pattern.length; i++) {
    const a = pattern[i];
    const b = words[i];
    if ((a in p2w && p2w[a] !== b) || (b in w2p && w2p[b] !== a)) {
      return false;
    }
    p2w[a] = b;
    w2p[b] = a;
  }
  return true;
};
```

### 复杂度分析

- 时间复杂度：O(n)，n 为 pattern（或单词数）。
- 空间复杂度：O(n)，切分数组与两个哈希表。
