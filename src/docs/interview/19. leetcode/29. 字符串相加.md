# 字符串相加

> 难度：简单 | 标签：数学、字符串、模拟 | [LeetCode 原题](https://leetcode.cn/problems/add-strings/description/)

## 题目描述

给定两个以字符串形式表示的非负整数 `num1` 和 `num2`，返回 `num1` 和 `num2` 的乘积和，它们的和同样以字符串形式返回。你不能使用任何內建的用于处理大整数的库（比如 `BigInt`），也不能直接将输入的字符串转换为整数形式。

**示例 1：**

```
输入：num1 = "456", num2 = "77"
输出："533"
```

**示例 2：**

```
输入：num1 = "0", num2 = "0"
输出："0"
```

**提示：**

- `1 <= num1.length, num2.length <= 10^4`
- `num1` 和 `num2` 都只包含数字 `0-9`
- 都不包含任何前导零

## 题解

::: details 点击查看题解

### 思路

模拟竖式加法：从两个串的末位开始逐位相加并维护进位。用 `charCodeAt(i) - 48` 把字符转成数字（不违反「不能整体转整数」的限制）。循环条件是任一串还有剩余位或有进位，结果逆序收集后翻转拼接。

这是大数运算类题目的通用模板，后续的「二进制求和」「字符串相乘」都基于同样的思路。

### 代码实现

```javascript
var addStrings = function(num1, num2) {
  let i = num1.length - 1;
  let j = num2.length - 1;
  let carry = 0;
  const res = [];
  while (i >= 0 || j >= 0 || carry > 0) {
    let sum = carry;
    if (i >= 0) sum += num1.charCodeAt(i--) - 48;
    if (j >= 0) sum += num2.charCodeAt(j--) - 48;
    carry = sum >= 10 ? 1 : 0;
    res.push(sum % 10);
  }
  return res.reverse().join("");
};
```

### 复杂度分析

- 时间复杂度：O(max(m, n))。
- 空间复杂度：O(1)（不计结果数组）。
