# 翻转二叉树

> 难度：简单 | 标签：树、深度优先搜索、广度优先搜索、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/invert-binary-tree/description/)

## 题目描述

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。（翻转即将每个节点的左右子树互换。）

**示例 1：**

```
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]
```

**示例 2：**

```
输入：root = []
输出：[]
```

**提示：**

- 树中节点数目范围在 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## 题解

::: details 点击查看题解

### 思路

递归交换每个节点的左右子树。先递归翻转得到新的左、右子树，再交换挂载到当前节点上，返回当前节点。空节点返回 null。

这道题因 Homebrew 作者「忘了在白板上写」的著名面试轶事而出名，本质是考察递归思维。

### 代码实现

```javascript
var invertTree = function(root) {
  if (!root) return null;
  const left = invertTree(root.left);
  const right = invertTree(root.right);
  root.left = right;
  root.right = left;
  return root;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(h)，递归栈深度为树高。
