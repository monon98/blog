# 合并两个有序链表

> 难度：简单 | 标签：递归、链表 | [LeetCode 原题](https://leetcode.cn/problems/merge-two-sorted-lists/description/)

## 题目描述

将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

**示例 1：**

```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

**示例 2：**

```
输入：l1 = [], l2 = [0]
输出：[0]
```

**提示：**

- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `l1` 和 `l2` 均按非递减顺序排列

## 题解

::: details 点击查看题解

### 思路

迭代 + 虚拟头节点（dummy node）：用一个哨兵节点统一处理「结果头」的边界问题，`cur` 指针在两链表中每次摘下较小值的节点接到结果尾部。任一链表耗尽后，把另一条剩余部分整体接上。

递归写法同样简洁：比较两表头，小者的 next 指向「其余部分的递归合并结果」。面试中两种都应掌握。

### 代码实现

```javascript
var mergeTwoLists = function(list1, list2) {
  const dummy = new ListNode(0);
  let cur = dummy;
  while (list1 && list2) {
    if (list1.val <= list2.val) {
      cur.next = list1;
      list1 = list1.next;
    } else {
      cur.next = list2;
      list2 = list2.next;
    }
    cur = cur.next;
  }
  cur.next = list1 ?? list2;
  return dummy.next;
};
```

### 复杂度分析

- 时间复杂度：O(m + n)，每个节点访问一次。
- 空间复杂度：O(1)（迭代）；递归版为 O(m + n) 栈空间。
