# 平方数之和

> 难度：简单 | 标签：数学、双指针、二分查找 | [LeetCode 原题](https://leetcode.cn/problems/sum-of-square-numbers/description/)

## 题目描述

给定一个非负整数 `c`，你要判断是否存在两个整数 `a` 和 `b`，使得 `a² + b² = c`，如果存在则返回 `true`，否则返回 `false`。

**示例 1：**

```
输入：c = 5
输出：true
解释：1 * 1 + 2 * 2 = 5。
```

**示例 2：**

```
输入：c = 3
输出：false
```

**提示：**

- `0 <= c <= 2^31 - 1`

## 题解

::: details 点击查看题解

### 思路

把问题看作在 `[0, √c]` 上找一对数：`a` 从 0 开始、`b` 从 ⌊√c⌋ 开始的双指针。和小于 c 时 a 增大，大于 c 时 b 减小，等于 c 即找到。双指针保证每步淘汰一行候选，线性时间完成。

也可以对每个 a 用二分查找 b²，复杂度 O(√c · log c)。

### 代码实现

```javascript
var judgeSquareSum = function(c) {
  let a = 0;
  let b = Math.floor(Math.sqrt(c));
  while (a <= b) {
    const sum = a * a + b * b;
    if (sum === c) return true;
    if (sum < c) {
      a++;
    } else {
      b--;
    }
  }
  return false;
};
```

### 复杂度分析

- 时间复杂度：O(√c)，双指针从两端向中间移动。
- 空间复杂度：O(1)。

:::
