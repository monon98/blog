# 二进制链表转整数

> 难度：简单 | 标签：链表、数学 | [LeetCode 原题](https://leetcode.cn/problems/convert-binary-number-in-a-linked-list-to-integer/description/)

## 题目描述

给你一个单链表的引用结点 `head`。链表中每个结点的值不是 0 就是 1。已知整条链表表示一个二进制数，最高位在链表头部。请你返回该数字所表示的十进制值。

**示例 1：**

```
输入：head = [1,0,1]
输出：5
解释：二进制数 (101) 转换为十进制数 5。
```

**示例 2：**

```
输入：head = [0]
输出：0
```

**提示：**

- 链表不为空
- 链表的结点总数范围为 `[1, 30]`
- `Node.val` 为 0 或 1

## 题解

::: details 点击查看题解

### 思路

从高位到低位扫描，每读一位就把已有结果左移一位（乘 2）再加上当前位：`res = res * 2 + head.val`。无需先反转链表或收集位数组，一次遍历完成。

### 代码实现

```javascript
var getDecimalValue = function(head) {
  let res = 0;
  while (head) {
    res = res * 2 + head.val;
    head = head.next;
  }
  return res;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。

:::
