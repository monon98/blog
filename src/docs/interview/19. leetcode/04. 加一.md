# 加一

> 难度：简单 | 标签：数组、数学 | [LeetCode 原题](https://leetcode.cn/problems/plus-one/description/)

## 题目描述

给定一个由整数组成的非空数组所表示的非负整数，在该数的基础上加一。最高位数字存放在数组的首位，数组中每个元素只存储单个数字。你可以假设除了整数 0 之外，这个整数不会以零开头。

**示例 1：**

```
输入：digits = [1,2,3]
输出：[1,2,4]
解释：输入数组表示数字 123，加一后为 124。
```

**示例 2：**

```
输入：digits = [9,9]
输出：[1,0,0]
```

**提示：**

- `1 <= digits.length <= 100`
- `0 <= digits[i] <= 9`

## 题解

::: details 点击查看题解

### 思路

从末位向前模拟进位：只要当前位小于 9，直接加一并返回；等于 9 则置 0 继续处理更高位。如果循环结束仍未返回，说明每一位都是 9（如 999 → 1000），需要在数组头部插入 1。

### 代码实现

```javascript
var plusOne = function(digits) {
  for (let i = digits.length - 1; i >= 0; i--) {
    if (digits[i] < 9) {
      digits[i]++;
      return digits;
    }
    digits[i] = 0;
  }
  digits.unshift(1);
  return digits;
};
```

### 复杂度分析

- 时间复杂度：O(n)，最坏情况所有位都是 9。
- 空间复杂度：O(1)，只在全 9 时扩展数组一次。

:::
