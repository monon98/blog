# 杨辉三角

> 难度：简单 | 标签：数组、动态规划 | [LeetCode 原题](https://leetcode.cn/problems/pascals-triangle/description/)

## 题目描述

给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。在「杨辉三角」中，每个数是它左上方和右上方的数的和。

**示例 1：**

```
输入：numRows = 5
输出：[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

**示例 2：**

```
输入：numRows = 1
输出：[[1]]
```

**提示：**

- `1 <= numRows <= 30`

## 题解

::: details 点击查看题解

### 思路

逐行构造。每一行的首尾都是 1，中间第 j 个元素等于上一行的 `res[i-1][j-1] + res[i-1][j]`。为第 i 行预分配长度 `i + 1` 且全部填 1 的数组，再只填中间部分，可以避免边界判断。

### 代码实现

```javascript
var generate = function(numRows) {
  const res = [];
  for (let i = 0; i < numRows; i++) {
    const row = new Array(i + 1).fill(1);
    for (let j = 1; j < i; j++) {
      row[j] = res[i - 1][j - 1] + res[i - 1][j];
    }
    res.push(row);
  }
  return res;
};
```

### 复杂度分析

- 时间复杂度：O(numRows²)，需要填满整个三角形。
- 空间复杂度：O(1)（不计返回值），只用了常数额外变量。
