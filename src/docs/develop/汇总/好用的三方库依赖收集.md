# 好用的三方库依赖收集

> 收集日常开发中好用、高质量的三方库，按用途分类，持续更新。

## Canvas / 图形渲染

1. [leaferjs](https://www.leaferjs.com/) — 国产 2D 图形引擎，Canvas / SVG / Web 统一渲染，适合画布编辑器、流程图等场景。

2. [pixi.js](https://www.pixijs.com/) — 高性能 2D WebGL 渲染引擎，适合游戏、可视化动效。

3. [fabric.js](http://fabricjs.com/) — Canvas 交互库，内置对象序列化、选中、拖拽，适合图片编辑器。

4. [konva](https://konvajs.org/) — 声明式 2D Canvas 库，支持 Vue / React，适合画布应用。

5. [paper.js](http://paperjs.org/) — 矢量图形脚本库，基于 Canvas，适合插画、图表动画。

## 3D / WebGL

1. [three.js](https://threejs.org/) — 最流行的 3D 库，生态完善，教程丰富。

2. [babylonjs](https://www.babylonjs.com/) — 微软开源的 3D 引擎，游戏向，功能开箱即用。

3. [ogl](https://github.com/oframe/ogl) — 极简 WebGL 库，体积小，适合轻量场景。

4. [three-nebula](https://github.com/creativelifeform/three-nebula) — three.js 粒子特效系统。

## 动画

1. [gsap](https://gsap.com/) — 业界标杆动画引擎，时间轴、滚动联动（ScrollTrigger）强大。

2. [motion](https://motion.dev/) — 前身 Framer Motion，弹簧动画与手势支持优秀。

3. [anime.js](https://animejs.com/) — 轻量 JS 动画库，API 简洁优雅。

4. [lottie-web](https://github.com/airbnb/lottie-web) — 渲染 AE 导出的 JSON 动画，设计师协作利器。

5. [velocity.js](http://velocityjs.org/) — jQuery animate 的替代品，支持 CSS 属性。

6. [auto-animate](https://formkit.com/auto-animate) — 零配置自动添加过渡动画，列表增删排序一行代码搞定。

7. [rive](https://rive.app/) — 交互动画运行时，适合复杂可交互动画。

## 可视化 / 图表

1. [echarts](https://echarts.apache.org/zh/index.html) — 百度开源，图表类型丰富，中文文档完善。

2. [antv](https://antv.antgroup.com/) — 蚂蚁可视化方案（G2 / G6 / S2 / X6），关系图、表格图强。

3. [d3](https://d3js.org/) — 数据驱动文档，可视化天花板，学习曲线陡。

4. [chart.js](https://www.chartjs.org/) — 轻量图表库，开箱即用，适合简单图表。

5. [victory](https://www.formidable.com/open-source/victory) — React 图表库，声明式组合。

6. [mermaid](https://mermaid.js.org/) — 用文本语法生成流程图、时序图、甘特图，文档必备。

7. [cytoscape.js](https://js.cytoscape.org/) — 图论可视化，适合网络拓扑、关系图。

## 地图

1. [leaflet](https://leafletjs.com/) — 轻量开源地图库，插件生态丰富。

2. [mapbox-gl-js](https://docs.mapbox.com/mapbox-gl-js/) — 3D 矢量地图，渲染效果出色。

3. [openlayers](https://openlayers.org/) — 功能全面的 GIS 地图库，适合专业场景。

4. [amap-js-api](https://lbs.amap.com/api/javascript-api-v2/documentation) — 高德地图 JS API，国内业务常用。

## 拖拽 / 排序

1. [sortablejs](https://sortablejs.github.io/Sortable/) — 经典列表拖拽排序，支持 Vue 封装（vue-draggable-plus）。

2. [vuedraggable](https://github.com/SortableJS/vue.draggable.next) — Sortable 的 Vue 3 封装。

3. [interact.js](https://interactjs.io/) — 拖拽、缩放、旋转手势库，支持约束与碰撞检测。

4. [gridstack.js](https://gridstackjs.com/) — 可拖拽缩放的网格布局，适合仪表盘 / 低代码。

5. [dragula](https://github.com/bevacqua/dragula) — 拖拽操作极简 API，上手快。

6. [pragmatic-drag-and-drop](https://github.com/atlassian/pragmatic-drag-and-drop) — Atlassian 出品，无障碍支持好的拖拽库。

## 表格 / 列表

1. [vxe-table](https://vxetable.cn/) — Vue 3 高性能表格，虚拟滚动、编辑、导出齐全，中文生态。

2. [ag-grid](https://www.ag-grid.com/) — 企业级表格，功能最全（部分功能收费）。

3. [tanstack-table](https://tanstack.com/table) — 无头表格逻辑，框架无关，可定制性强。

4. [tabulator](http://tabulator.info/) — 功能丰富的交互式表格，框架无关。

5. [vue-virtual-scroller](https://github.com/Akryum/vue-virtual-scroller) — Vue 虚拟滚动列表 / 网格。

6. [@tanstack/virtual](https://tanstack.com/virtual) — 无头虚拟滚动逻辑，框架无关。

## 表单 / 校验

1. [vee-validate](https://vee-validate.logaretm.com/) — Vue 表单校验，支持 schema 校验，API 友好。

2. [zod](https://zod.dev/) — TypeScript-first 校验库，schema 可复用。

3. [yup](https://github.com/jquense/yup) — 与 formik 搭配经典的 schema 校验库。

4. [formik](https://formik.org/) — React 表单状态管理。

5. [async-validator](https://github.com/yiminghe/async-validator) — Element / Ant Design 同款校验库，Vue 项目常用。

6. [ibiz-mify-formily](https://formilyjs.org/) — 阿里开源表单方案，中后台复杂表单利器。

## 编辑器

### 富文本

1. [wangEditor](https://www.wangeditor.net/) — 国产 Web 富文本编辑器，中文文档友好。

2. [tiptap](https://tiptap.dev/) — 基于 ProseMirror 的无头富文本框架，Vue / React 通用，可扩展性强。

3. [quill](https://quilljs.com/) — 经典富文本编辑器，生态成熟。

4. [editor.js](https://editorjs.io/) — 块状 JSON 结构编辑器，输出结构化数据。

5. [slate](https://www.slatejs.org/) — React 可定制富文本框架，完全可控。

### Markdown

1. [md-editor-rt](https://imzbf.github.io/md-editor-rt/) — Vue 3 的 Markdown 编辑器，功能全、中文文档。

2. [vditor](https://b3log.org/vditor/) — 稀土掘金同款编辑器，所见即所得。

3. [bytemd](https://bytemd.org/) — 字节开源的 Markdown 编辑器，插件化。

4. [marked](https://marked.js.org/) — 轻量 Markdown 转 HTML 解析器。

5. [markdown-it](https://markdown-it.github.io/) — 可扩展的 Markdown 解析器，插件丰富。

### 代码编辑

1. [monaco-editor](https://microsoft.github.io/monaco-editor/) — VS Code 同款编辑器，智能提示、多语言支持。

2. [codemirror](https://codemirror.net/) — 轻量可扩展代码编辑器，模块化按需加载。

3. [prismjs](https://prismjs.com/) — 代码语法高亮，轻量，主题多。

4. [highlight.js](https://highlightjs.org/) — 开箱即用的语法高亮，自动语言识别。

5. [shiki](https://shiki.style) — 基于 VS Code 语法，输出带主题的高亮 HTML，VitePress 同款。
