# 零钱兑换

> 难度：中等 | 标签：数组、动态规划、完全背包 | [LeetCode 原题](https://leetcode.cn/problems/coin-change/description/)

## 题目描述

给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount`，表示总金额。

计算并返回可以凑成总金额所需的 **最少**的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 -1 。

你可以认为每种硬币的数量是无限的。

**示例 1：**

```
输入：coins = [1, 2, 5], amount = 11
输出：3
解释：11 = 5 + 5 + 1
```

**示例 2：**

```
输入：coins = [2], amount = 3
输出：-1
```

**示例 3：**

```
输入：coins = [1], amount = 0
输出：0
```

**提示：**

- `1 <= coins.length <= 12`
- `1 <= coins[i] <= 2^31 - 1`
- `0 <= amount <= 10^4`

## 题解

:::: details 点击查看题解

### 思路

完全背包求最优，用「自底向上松弛」的一维 DP：`dp[a]` 表示凑成金额 `a` 所需的最少硬币数。初始化 `dp[0] = 0`、其余为一个不可能达到的大值（哨兵），然后对每个金额 `a` 从 1 到 `amount` 枚举最后一枚硬币 `c`（`c <= a`），若 `dp[a - c]` 可达则 `dp[a] = min(dp[a], dp[a - c] + 1)`。每个金额只松弛一次、内层枚举所有面额，天然把「每种硬币无限取」包含进来。

哨兵取 `amount + 1` 而不是 `INT_MAX`，因为任何可行解最多用 `amount` 枚硬币（最小面额至少为 1），所以 `> amount` 即不可达，返回 -1——这同时避免了 `dp[a-c] + 1` 溢出。

这题也可以按 BFS 理解（面值为边权的分层图，0-1 层即答案），或用记忆化搜索自顶向下；但松弛顺序要注意必须按金额从小到大，否则拿不到最优子结构。`amount <= 10^4`，O(amount × coins.length) 完全够用。

```javascript [JavaScript]
var coinChange = function(coins, amount) {
  const inf = amount + 1;
  const dp = new Array(amount + 1).fill(inf);
  dp[0] = 0;
  for (let a = 1; a <= amount; a++) {
    for (const c of coins) {
      if (c <= a && dp[a - c] + 1 < dp[a]) {
        dp[a] = dp[a - c] + 1;
      }
    }
  }
  return dp[amount] > amount ? -1 : dp[amount];
};
```

```python [Python]
class Solution:
    def coinChange(self, coins: list[int], amount: int) -> int:
        inf = amount + 1
        dp = [inf] * (amount + 1)
        dp[0] = 0
        for a in range(1, amount + 1):
            for c in coins:
                if c <= a and dp[a - c] + 1 < dp[a]:
                    dp[a] = dp[a - c] + 1
        return -1 if dp[amount] > amount else dp[amount]
```

```go [Go]
func coinChange(coins []int, amount int) int {
	inf := amount + 1

	for a := 1; a <= amount; a++ {
		dp[a] = inf
	}
	for a := 1; a <= amount; a++ {

				dp[a] = dp[a-c] + 1
			}
		}
	}
	if dp[amount] > amount {
		return -1
	}
	return dp[amount]
}
```
