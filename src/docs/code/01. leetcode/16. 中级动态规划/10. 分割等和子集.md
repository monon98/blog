# 分割等和子集

> 难度：中等 | 标签：数组、动态规划、0-1 背包 | [LeetCode 原题](https://leetcode.cn/problems/partition-equal-subset-sum/description/)

## 题目描述

给你一个 **只包含正整数**的 **非空**数组 `nums` 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**示例 1：**

```
输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1, 5, 5] 和 [11] 。
```

**示例 2：**

```
输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集。
```

**提示：**

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

## 题解

:::: details 点击查看题解

### 思路

先做剪枝：总和为奇数直接返回 false，否则问题转化为「能否从数组里选出若干个数，使其和恰好为 `target = sum / 2`」——这就是 0-1 背包的可行性问题。`dp[t]` 表示「能否凑出和 `t`」，初始化 `dp[0] = true`（一个数都不选），转移为对每个数 `x` 逆序更新 `dp[t] = dp[t] || dp[t - x]`。

逆序（从 `target` 到 `x`）是 0-1 背包的关键：每轮只用上一轮的 `dp` 状态，保证每个数最多用一次；若写成正序就变成完全背包，同一个数会被重复选取，`[1, 5, 11, 5]` 这类用例会误判。一维布尔数组即可，`target <= 10^4`（`200 × 100 / 2`），空间毫无压力。

等价理解：两个子集和相等意味着存在子集和为总和的一半，因此只需求一次背包，而不需要枚举划分方案。注意题目保证正整数，`x >= 1`，循环边界 `t >= x` 不会漏状态。

```javascript [JavaScript]
var canPartition = function(nums) {
  const total = nums.reduce((a, b) => a + b, 0);
  if (total % 2 !== 0) return false;
  const target = total / 2;
  const dp = new Array(target + 1).fill(false);
  dp[0] = true;
  for (const x of nums) {
    for (let t = target; t >= x; t--) {
      dp[t] = dp[t] || dp[t - x];
    }
  }
  return dp[target];
};
```

```python [Python]
class Solution:
    def canPartition(self, nums: list[int]) -> bool:
        total = sum(nums)
        if total % 2 != 0:
            return False
        target = total // 2
        dp = [False] * (target + 1)
        dp[0] = True
        for x in nums:
            for t in range(target, x - 1, -1):
                dp[t] = dp[t] or dp[t - x]
        return dp[target]
```

```rust [Rust]
impl Solution {
    pub fn can_partition(nums: Vec<i32>) -> bool {
        let total: i32 = nums.iter().sum();
        if total % 2 != 0 {
            return false;
        }
        let target = (total / 2) as usize;
        let mut dp = vec![false; target + 1];
        dp[0] = true;
        for &x in &nums {
            let x = x as usize;
            for t in (x..=target).rev() {
                dp[t] = dp[t] || dp[t - x];
            }
        }
        dp[target]
    }
}
```

### 复杂度分析

- 时间复杂度：O(n × target)，n 为数组长度、target 为总和的一半。
- 空间复杂度：O(target)，一维布尔数组。
