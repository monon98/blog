# 最小路径和

> 难度：中等 | 标签：数组、动态规划、矩阵 | [LeetCode 原题](https://leetcode.cn/problems/minimum-path-sum/description/)

## 题目描述

给定一个包含非负整数的 `m x n` 网格 `grid` ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明：**每次只能向下或者向右移动一步。

示例 1：

```
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：因为路径 1→3→1→1→1 的总和最小。
```

示例 2：

```
输入：grid = [[1,2,3],[4,5,6]]
输出：12
```

**提示：**

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`

## 题解

:::: details 点击查看题解

### 思路

`dp[i][j]` 表示从左上角走到 `(i, j)` 的最小路径和，转移为 `dp[i][j] = grid[i][j] + min(dp[i - 1][j], dp[i][j - 1])`，即只能从上方或左方走来；起点 `dp[0][0] = grid[0][0]`。

一维压缩时要注意两个方向的初值：首行先做前缀和（`dp[j] = dp[j - 1] + grid[0][j]`，到首行某格只能一路向右），首列则逐行累加 `dp[0] += grid[i][0]`（到首列某格只能一路向下）。之后内层从左到右更新 `dp[j] = grid[i][j] + min(dp[j], dp[j - 1])`：此时 `dp[j]` 还是上一行的值（上方），`dp[j - 1]` 已是本轮的值（左方），正好对应转移的两个来源。

网格最大 200×200、格值不超过 200，路径和不会超过 8×10^4，32 位整数绰绰有余；不要被「和」吓到而改用 `long`。

```javascript [JavaScript]
var minPathSum = function(grid) {
  const m = grid.length;
  const n = grid[0].length;
  const dp = new Array(n);
  dp[0] = grid[0][0];
  for (let j = 1; j < n; j++) {
    dp[j] = dp[j - 1] + grid[0][j];
  }
  for (let i = 1; i < m; i++) {
    dp[0] += grid[i][0];
    for (let j = 1; j < n; j++) {
      dp[j] = grid[i][j] + Math.min(dp[j], dp[j - 1]);
    }
  }
  return dp[n - 1];
};
```

class Solution:

        dp = [0] * n

```go [Go]
func minPathSum(grid [][]int) int {
	m, n := len(grid), len(grid[0])
	dp := make([]int, n)
	dp[0] = grid[0][0]
	for j := 1; j < n; j++ {
		dp[j] = dp[j-1] + grid[0][j]
	}
	for i := 1; i < m; i++ {
		dp[0] += grid[i][0]
		for j := 1; j < n; j++ {
			best := dp[j]
			if dp[j-1] < best {
				best = dp[j-1]
			}
			dp[j] = grid[i][j] + best
		}
	}
	return dp[n-1]
}
```

class Solution {
    public int minPathSum(int[][] grid) {

        int[] dp = new int[n];
        dp[0] = grid[0][0];
        for (int j = 1; j < n; j++) {

            dp[0] += grid[i][0];

            }
        }

    }
}
