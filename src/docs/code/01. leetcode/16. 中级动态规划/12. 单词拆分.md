# 单词拆分

> 难度：中等 | 标签：字符串、动态规划、哈希表 | [LeetCode 原题](https://leetcode.cn/problems/word-break/description/)

## 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s` 则返回 `true`。

**注意：**不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

**示例 1：**

```
输入：s = "leetcode", wordDict = ["leet", "code"]
输出：true
解释：返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。
```

**示例 2：**

```
输入：s = "applepenapple", wordDict = ["apple", "pen"]
输出：true
解释：返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
     注意，你可以重复使用字典中的单词。
```

**示例 3：**

```
输入：s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出：false
```

**提示：**

- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` 和 `wordDict[i]` 仅由小写英文字母组成
- `wordDict` 中的所有字符串 **互不相同**

## 题解

:::: details 点击查看题解

### 思路

`dp[i]` 表示 `s` 的前 `i` 个字符（`s[0..i)`）能否被字典中的单词拼接出来，`dp[0] = true`（空串恒成立）。对每个 `i` 枚举分割点 `j < i`：若 `dp[j]` 为真且尾段 `s[j..i)` 恰好是字典里的单词，则 `dp[i] = true`。答案即 `dp[n]`。

两个实用优化：把字典放进哈希集合做 O(1) 查词；记录字典中最长单词长度 `maxLen`，`j` 只需从 `i - maxLen` 起枚举，避免无意义的短尾段比较。`s.length <= 300`、单词长不超过 20，复杂度非常宽裕。

容易错的点：单词可以**重复使用**，所以不能用 0-1 背包的物品标记；另外示例 3 这种「贪心匹配最近的词」会失败的情况说明必须回溯/DP 枚举所有分割点，而非一次匹配到底。本题也可用记忆化 DFS 等价实现（自顶向下的同一个状态定义）。

```javascript [JavaScript]
var wordBreak = function(s, wordDict) {
  const n = s.length;
  const words = new Set(wordDict);
  let maxLen = 0;
  for (const w of wordDict) {
    if (w.length > maxLen) maxLen = w.length;
  }
  const dp = new Array(n + 1).fill(false);
  dp[0] = true;
  for (let i = 1; i <= n; i++) {
    const lo = Math.max(0, i - maxLen);
    for (let j = lo; j < i; j++) {
      if (dp[j] && words.has(s.slice(j, i))) {
        dp[i] = true;
        break;
      }
    }
  }
  return dp[n];
};
```

```python [Python]
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n = len(s)
        words = set(wordDict)
        max_len = max(len(w) for w in wordDict)
        dp = [False] * (n + 1)
        dp[0] = True
        for i in range(1, n + 1):
            for j in range(max(0, i - max_len), i):
                if dp[j] and s[j:i] in words:
                    dp[i] = True
                    break
        return dp[n]
```

```rust [Rust]
impl Solution {
    pub fn word_break(s: String, word_dict: Vec<String>) -> bool {
        let n = s.len();
        let mut words = std::collections::HashSet::new();
        let mut max_len = 0usize;
        for w in &word_dict {
            words.insert(w.as_str());
            max_len = max_len.max(w.len());
        }
        let mut dp = vec![false; n + 1];
        dp[0] = true;
        for i in 1..=n {
            let lo = i.saturating_sub(max_len);
            for j in lo..i {
                if dp[j] && words.contains(&s[j..i]) {
                    dp[i] = true;
                    break;
                }
            }
        }
        dp[n]
    }
}
```

```go [Go]
func wordBreak(s string, wordDict []string) bool {
	n := len(s)
	words := make(map[string]bool, len(wordDict))
	maxLen := 0
	for _, w := range wordDict {
		words[w] = true
		if len(w) > maxLen {
			maxLen = len(w)
		}
	}
	dp := make([]bool, n+1)
	dp[0] = true
	for i := 1; i <= n; i++ {
		lo := i - maxLen
		if lo < 0 {
			lo = 0
		}
		for j := lo; j < i; j++ {
			if dp[j] && words[s[j:i]] {
				dp[i] = true
				break
			}
		}
	}
	return dp[n]
}
```

```java [Java]
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        int n = s.length();
        Set<String> words = new HashSet<>(wordDict);
        int maxLen = 0;
        for (String w : wordDict) {
            maxLen = Math.max(maxLen, w.length());
        }
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        for (int i = 1; i <= n; i++) {
            int lo = Math.max(0, i - maxLen);
            for (int j = lo; j < i; j++) {
                if (dp[j] && words.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
}
```

### 复杂度分析

- 时间复杂度：O(n × maxLen × L)，n 为 s 长度、maxLen 为最长单词长、L 为单次切片比较的代价。
- 空间复杂度：O(n + D)，dp 数组与字典哈希集合（D 为字典总长度）。
