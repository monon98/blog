# 最长回文子串

> 难度：中等 | 标签：字符串、动态规划、双指针 | [LeetCode 原题](https://leetcode.cn/problems/longest-palindromic-substring/description/)

## 题目描述

给你一个字符串 `s`，找到 `s` 中最长的 回文 子串。

**示例 1：**

```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

**示例 2：**

```
输入：s = "cbbd"
输出："bb"
```

**提示：**

- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成

## 题解

:::: details 点击查看题解

### 思路

区间 DP。`dp[i][j]` 表示子串 `s[i..j]`（含两端）是否为回文。状态转移：`s[i] != s[j]` 时一定不是回文；相等时，若区间长度不超过 3（`j - i < 3`，即 `aa` 或 `aba`）则必为回文，否则取决于去掉两端后的 `dp[i + 1][j - 1]`。边界是所有 `dp[i][i] = true`（单字符是回文）。

填表必须**按区间长度从小到大**枚举（外层 `len`、内层起点 `i`），这样依赖的更短区间 `dp[i + 1][j - 1]` 已经算好。遍历过程中记录当前最优的起点与长度，最后截取即可；`s.length <= 1000`，O(n²) 时间、O(n²) 空间都在限额内。

这题还有更省空间的「中心扩展」（O(n²) 时间、O(1) 空间，奇偶中心各扩一次）与 O(n) 的 Manacher 算法；本页按动态规划组的主题给区间 DP 写法。注意「子串」要求连续，别和「最长回文子序列」混淆。

```javascript [JavaScript]
var longestPalindrome = function(s) {
  const n = s.length;
  const dp = Array.from({ length: n }, () => new Array(n).fill(false));
  let start = 0;
  let maxLen = 1;
  for (let i = 0; i < n; i++) {
    dp[i][i] = true;
  }
  for (let len = 2; len <= n; len++) {
    for (let i = 0; i + len - 1 < n; i++) {
      const j = i + len - 1;
      if (s[i] !== s[j]) continue;
      dp[i][j] = len <= 3 || dp[i + 1][j - 1];
      if (dp[i][j] && len > maxLen) {
        maxLen = len;
        start = i;
      }
    }
  }
  return s.substring(start, start + maxLen);
};
```

```python [Python]
class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        dp = [[False] * n for _ in range(n)]
        start, max_len = 0, 1
        for i in range(n):
            dp[i][i] = True
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] != s[j]:
                    continue
                dp[i][j] = length <= 3 or dp[i + 1][j - 1]
                if dp[i][j] and length > max_len:
                    max_len = length
                    start = i
        return s[start:start + max_len]
```

    pub fn longest_palindrome(s: String) -> String {
        let b = s.as_bytes();
        let n = b.len();
        let mut dp = vec![vec![false; n]; n];

class Solution {
    public String longestPalindrome(String s) {
        int n = s.length();
        boolean[][] dp = new boolean[n][n];
        int start = 0, maxLen = 1;
        for (int i = 0; i < n; i++) {
            dp[i][i] = true;

                dp[i][j] = len <= 3 || dp[i + 1][j - 1];
                if (dp[i][j] && len > maxLen) {
                    maxLen = len;
                    start = i;
                }
            }
        }
        return s.substring(start, start + maxLen);
    }
}
