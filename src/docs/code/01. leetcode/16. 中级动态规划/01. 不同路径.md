# 不同路径

> 难度：中等 | 标签：动态规划、数学、组合数学 | [LeetCode 原题](https://leetcode.cn/problems/unique-paths/description/)

## 题目描述

一个机器人位于一个 `m x n` 网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

**示例 1：**

```
输入：m = 3, n = 7
输出：28
```

**示例 2：**

```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

**示例 3：**

```
输入：m = 7, n = 3
输出：28
```

**示例 4：**

```
输入：m = 3, n = 3
输出：6
```

**提示：**

- `1 <= m, n <= 100`
- 题目数据保证答案小于等于 `2 * 10^9`

## 题解

:::: details 点击查看题解

### 思路

设 `dp[i][j]` 为从左上角走到 `(i, j)` 的路径数。因为只能向右或向下，到达 `(i, j)` 只可能从上方 `(i - 1, j)` 或左方 `(i, j - 1)` 走来，所以 `dp[i][j] = dp[i - 1][j] + dp[i][j - 1]`；第一行和第一列各自只有 1 条路径，全部初始化为 1。

转移只依赖上一行和当前行左边的值，因此把二维表压成一维数组，逐格执行 `dp[j] += dp[j - 1]` 即可，空间降到 O(n)。外层循环行、内层循环列从左到右，是这个压缩成立的关键：顺序反了会把本轮刚更新的值误当成本轮的来源。

`m`、`n` 最大为 100，答案不超过 `2 * 10^9`，32 位整数装得下，各语言直接用 `int` 即可。本题也可以用组合数 C(m + n - 2, m - 1) 直接计算，但乘法过程容易溢出，DP 写法更稳妥。

### 代码实现

::: code-group

```javascript [JavaScript]
var uniquePaths = function(m, n) {
  const dp = new Array(n).fill(1);
  for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
      dp[j] += dp[j - 1];
    }
  }
  return dp[n - 1];
};
```

```python [Python]
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [1] * n
        for _ in range(1, m):
            for j in range(1, n):
                dp[j] += dp[j - 1]
        return dp[n - 1]
```

```rust [Rust]
impl Solution {
    pub fn unique_paths(m: i32, n: i32) -> i32 {
        let mut dp = vec![1i32; n as usize];
```

```go [Go]
func uniquePaths(m int, n int) int {
	dp := make([]int, n)
	for j := range dp {
		dp[j] = 1
	}
	for i := 1; i < m; i++ {
		for j := 1; j < n; j++ {
			dp[j] += dp[j-1]
		}
	}
	return dp[n-1]
}
```

### 复杂度分析

- 时间复杂度：O(mn)，每个格子计算一次。
- 空间复杂度：O(n)，一维滚动数组。
