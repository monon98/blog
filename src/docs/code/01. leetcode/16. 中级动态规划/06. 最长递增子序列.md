# 最长递增子序列

> 难度：中等 | 标签：数组、动态规划、二分查找、最长上升子序列 | [LeetCode 原题](https://leetcode.cn/problems/longest-increasing-subsequence/description/)

## 题目描述

给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列**是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

**示例 1：**

```
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4 。
```

**示例 2：**

```
输入：nums = [0,1,0,3,2,3]
输出：4
```

**示例 3：**

```
输入：nums = [7,7,7,7,7,7,7]
输出：1
```

**提示：**

- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`

**进阶：**

- 你能将算法的时间复杂度降低到 `O(n log(n))` 吗?

## 题解

:::: details 点击查看题解

### 思路

贪心 + 二分的 `tails` 维护法：`tails[k]` 表示长度为 `k + 1` 的递增子序列结尾元素的**最小可能值**。遍历每个 `x`，在 `tails` 中二分找第一个 `>= x` 的位置：找到了就原地替换（结尾更小，后续更容易接上），没找到就追加（说明 `x` 比所有现有结尾都大，最长长度加一）。替换不会破坏正确性，因为被替换的结尾原本就 `>= x`，更小的结尾只会让可接续的范围变大。

因为 `tails` 始终有序，所以能二分，总时间 O(n log n)；`tails` 本身不是某个真实子序列，只是长度信息的载体，不要试图从中还原答案。注意找的是**第一个 `>= x`**（下界）而非上界，否则相等元素会被追加，破坏「严格递增」——示例 3 全是 7，用上界会错答 7。

朴素 DP `dp[i] = max(dp[j] + 1)`（`j < i` 且 `nums[j] < nums[i]`）是 O(n²)，`n = 2500` 时也能过，但进阶要求 O(n log n)，本页统一给二分写法。

```javascript [JavaScript]
var lengthOfLIS = function(nums) {
  const tails = [];
  for (const x of nums) {
    let l = 0;
    let r = tails.length;
    while (l < r) {
      const mid = (l + r) >> 1;
      if (tails[mid] < x) {
        l = mid + 1;
      } else {
        r = mid;
      }
    }
    tails[l] = x;
  }
  return tails.length;
};
```

```python [Python]
from bisect import bisect_left


class Solution:
    def lengthOfLIS(self, nums: list[int]) -> int:
        tails = []
        for x in nums:
            i = bisect_left(tails, x)
            if i == len(tails):
                tails.append(x)
            else:
                tails[i] = x
        return len(tails)
```

```rust [Rust]
impl Solution {
    pub fn length_of_lis(nums: Vec<i32>) -> i32 {
        let mut tails: Vec<i32> = Vec::new();
        for &x in &nums {
            let mut l = 0usize;
            let mut r = tails.len();
            while l < r {
                let mid = l + (r - l) / 2;
                if tails[mid] < x {
                    l = mid + 1;
                } else {
                    r = mid;
                }
            }
            if l == tails.len() {
                tails.push(x);
            } else {
                tails[l] = x;
            }
        }
        tails.len() as i32
    }
}
```

```go [Go]
import "sort"

func lengthOfLIS(nums []int) int {
	tails := []int{}
	for _, x := range nums {
		i := sort.Search(len(tails), func(i int) bool { return tails[i] >= x })
		if i == len(tails) {
			tails = append(tails, x)
		} else {
			tails[i] = x
		}
	}
	return len(tails)
}
```

```java [Java]
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;
        for (int x : nums) {
            int l = 0, r = size;
            while (l < r) {
                int mid = l + (r - l) / 2;
                if (tails[mid] < x) {
                    l = mid + 1;
                } else {
                    r = mid;
                }
            }
            tails[l] = x;
            if (l == size) {
                size++;
            }
        }
        return size;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n log n)，每个元素在有序 `tails` 上二分一次。
- 空间复杂度：O(n)，`tails` 数组最长为 n。
