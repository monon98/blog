# 左叶子之和

> 难度：简单 | 标签：树、深度优先搜索、广度优先搜索、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/sum-of-left-leaves/description/)

## 题目描述

给定二叉树的根节点 `root`，返回所有左叶子之和。注意：左叶子是指「既是父节点的左孩子、又是叶子节点（无左右子树）」的节点。

**示例 1：**

```
输入: root = [3,9,20,null,null,15,7]
输出: 24
解释：在这个二叉树中，有两个左叶子，分别是 9 和 15，所以返回 24。
```

**示例 2：**

```
输入: root = [1]
输出: 0
解释：根节点没有左叶子。
```

**提示：**

- 节点数在 `[1, 1000]` 范围内
- `-1000 <= Node.val <= 1000`

## 题解

::: details 点击查看题解

### 思路

递归遍历每个节点：判断它的左孩子是否为叶子（存在且无左右子树），是则累加其值；然后继续递归处理左右子树。关键在于「左叶子」必须同时满足位置与叶性两个条件——只看值无法判断方向信息，所以要站在父节点视角检查。

### 代码实现

```javascript
var sumOfLeftLeaves = function(root) {
  if (!root) return 0;
  let sum = 0;
  if (root.left && !root.left.left && !root.left.right) {
    sum += root.left.val;
  }
  return sum + sumOfLeftLeaves(root.left) + sumOfLeftLeaves(root.right);
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(h)，递归栈深度为树高。
