# 有效的字母异位词

> 难度：简单 | 标签：哈希表、字符串、排序 | [LeetCode 原题](https://leetcode.cn/problems/valid-anagram/description/)

## 题目描述

给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的字母异位词（即两个字符串包含的字母及各字母数量完全相同，只是排列不同）。

**示例 1：**

```
输入：s = "anagram", t = "nagaram"
输出：true
```

**示例 2：**

```
输入：s = "rat", t = "car"
输出：false
```

**提示：**

- `1 <= s.length, t.length <= 5 * 10^4`
- `s` 和 `t` 仅包含小写字母

**进阶：** 如果输入字符串包含 Unicode 字符怎么办？你能否调整你的解法来应对这种情况？

## 题解

::: details 点击查看题解

### 思路

长度不等直接返回 false。用长度 26 的计数数组，遍历 `s` 时对应位置加一、遍历 `t` 时减一，最后所有计数都为 0 则互为异位词。

进阶场景下把定长数组换成 `Map` 即可支持任意 Unicode 字符；也可以对两串分别排序后比较，复杂度 O(n log n)。

### 代码实现

```javascript
var isAnagram = function(s, t) {
  if (s.length !== t.length) return false;
  const cnt = new Array(26).fill(0);
  for (let i = 0; i < s.length; i++) {
    cnt[s.charCodeAt(i) - 97]++;
    cnt[t.charCodeAt(i) - 97]--;
  }
  return cnt.every((c) => c === 0);
};
```

### 复杂度分析

- 时间复杂度：O(n)，单层循环加一次数组检查。
- 空间复杂度：O(1)，固定 26 个计数器。
