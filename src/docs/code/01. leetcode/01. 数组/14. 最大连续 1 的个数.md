# 最大连续 1 的个数

> 难度：简单 | 标签：数组 | [LeetCode 原题](https://leetcode.cn/problems/max-consecutive-ones/description/)

## 题目描述

给定一个二进制数组 `nums`，计算其中最大连续 `1` 的个数。

**示例 1：**

```
输入：nums = [1,1,0,1,1,1]
输出：3
解释：开头两位和最后三位都连续是 1，最长连续 1 的个数是 3。
```

**示例 2：**

```
输入：nums = [1,0,1,1,0,1]
输出：2
```

**提示：**

- `1 <= nums.length <= 10^5`
- `nums[i]` 不是 `0` 就是 `1`

## 题解

:::: details 点击查看题解

### 思路

一次遍历维护当前连续计数 `cur` 和历史最大值 `max`。遇到 1 时 `cur` 加一，遇到 0 时把 `cur` 清零；每一步用 `cur` 刷新 `max`。

### 代码实现

::: code-group

```javascript [JavaScript]
var findMaxConsecutiveOnes = function(nums) {
  let max = 0;
  let cur = 0;
  for (const x of nums) {
    cur = x === 1 ? cur + 1 : 0;
    if (cur > max) max = cur;
  }
  return max;
};
```

```python [Python]
class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        mx = 0
        cur = 0
        for x in nums:
            cur = cur + 1 if x == 1 else 0
            if cur > mx:
                mx = cur
        return mx
```

```rust [Rust]
impl Solution {
    pub fn find_max_consecutive_ones(nums: Vec<i32>) -> i32 {
        let mut max = 0;
        let mut cur = 0;
        for x in nums {
            if x == 1 {
                cur += 1;
            } else {
                cur = 0;
            }
            if cur > max {
                max = cur;
            }
        }
        max
    }
}
```

```go [Go]
func findMaxConsecutiveOnes(nums []int) int {
	mx, cur := 0, 0
	for _, x := range nums {
		if x == 1 {
			cur++
		} else {
			cur = 0
		}
		if cur > mx {
			mx = cur
		}
	}
	return mx
}
```
