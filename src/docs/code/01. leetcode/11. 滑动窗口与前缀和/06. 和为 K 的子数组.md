# 和为 K 的子数组

> 难度：中等 | 标签：数组、哈希表、前缀和 | [LeetCode 原题](https://leetcode.cn/problems/subarray-sum-equals-k/description/)

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 *该数组中和为 `k` 的子数组的个数*。

子数组是数组中元素的连续非空序列。

**示例 1：**

```
输入：nums = [1,1,1], k = 2
输出：2
```

**示例 2：**

```
输入：nums = [1,2,3], k = 3
输出：2
```

**提示：**

- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`

## 题解

:::: details 点击查看题解

### 思路

用「前缀和 + 哈希表计数」把 O(n²) 暴力降到线性：记 `prefix[i]` 为前 `i` 个元素之和，子数组 `(j, i]` 的和就是 `prefix[i] - prefix[j]`，于是对每个右端点 `i`，只要查表「此前出现过多少次 `prefix[i] - k`」，累加即为答案。哈希表保存的是每个前缀和出现的次数，因为起止不同的子数组都算独立解。

关键是**先查询、再把当前前缀和入表**的顺序：入表必须发生在查询之后，否则 `prefix[i] - prefix[j]` 中 `j == i` 的空前缀会被提前计入，凭空多出错误答案（`k == 0` 时尤其明显）。初始化要放一条 `prefix = 0` 出现一次，代表「什么都不取」的空前缀，这样子数组从下标 0 开始的情况也能被统计到。

注意 `nums[i]` 和 `k` 都可为负，所以不能用「元素全为正」前提下的双指针/滑动窗口，只能靠哈希表回查。替代解法是预处理整个前缀和数组后排序二分，但要处理重复值，反而更繁琐。

### 代码实现

::: code-group

```javascript [JavaScript]
var subarraySum = function(nums, k) {
  const count = new Map();
  count.set(0, 1);
  let prefix = 0;
  let ans = 0;
  for (const num of nums) {
    prefix += num;
    ans += count.get(prefix - k) || 0;
    count.set(prefix, (count.get(prefix) || 0) + 1);
  }
  return ans;
};
```

```rust [Rust]
impl Solution {
    pub fn subarray_sum(nums: Vec<i32>, k: i32) -> i32 {
        use std::collections::HashMap;
        let mut count: HashMap<i32, i32> = HashMap::new();
        count.insert(0, 1);
        let mut prefix = 0i32;
        let mut ans = 0i32;
        for &num in &nums {
            prefix += num;
            ans += *count.get(&(prefix - k)).unwrap_or(&0);
            *count.entry(prefix).or_insert(0) += 1;
        }
        ans
    }
}
```

```go [Go]
func subarraySum(nums []int, k int) int {
```

```java [Java]
class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        count.put(0, 1);
        int prefix = 0;
        int ans = 0;
        for (int num : nums) {
            prefix += num;
            ans += count.getOrDefault(prefix - k, 0);
            count.put(prefix, count.getOrDefault(prefix, 0) + 1);
        }
        return ans;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个元素只做一次哈希表查询与一次更新。
- 空间复杂度：O(n)，哈希表最多保存 n + 1 个不同前缀和。
