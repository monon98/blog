# 乘积最大子数组

> 难度：中等 | 标签：数组、动态规划 | [LeetCode 原题](https://leetcode.cn/problems/maximum-product-subarray/description/)

## 题目描述

给你一个整数数组 `nums` ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32-位** 整数。

**请注意**，一个只包含一个元素的数组的乘积是这个元素的值。

示例 1:

```
输入：nums = [2,3,-2,4]
输出：6
解释：子数组 [2,3] 有最大乘积 6。
```

示例 2:

```
输入：nums = [-2,0,-1]
输出：0
解释：结果不能为 2, 因为 [-2,-1] 不是子数组。
```

**提示:**

- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- `nums` 的任何子数组的乘积都 **保证** 是一个 **32-位** 整数

## 题解

:::: details 点击查看题解

### 思路

在 Kadane 的基础上同时维护「以当前位置结尾的最大乘积 `maxCur`」与「最小乘积 `minCur`」：乘法会让符号翻转，当前的最大值可能由前一步的最小值（负负得正）乘上当前负数得来，所以两个状态必须成对滚动更新，更新时要用上一步的旧值，不能边改 `maxCur` 边用它算 `minCur`。

不变量是「`maxCur`/`minCur` 恰好是以 `i` 结尾的所有连续子数组乘积的最大/最小值」，转移为三者取最值：`nums[i]` 自成一段、`maxCur * nums[i]`、`minCur * nums[i]`。取 `nums[i]` 单独一项既覆盖了「子数组至少一个元素」，也让遇到 `0` 时状态自然清零重启——这正是示例 2 中答案为 `0` 而不是 `2` 的原因。

由于任何子数组乘积保证是 32 位整数，`int` 不会溢出，无需改用 `long`。替代解法是记录每个数之前最后一个 `0` 的位置把数组分段，段内负数个数决定取前缀还是后缀，复杂度相同但边界处理更琐碎。

### 代码实现

```javascript [JavaScript]
var maxProduct = function(nums) {
  let maxCur = nums[0];
  let minCur = nums[0];
  let ans = nums[0];
  for (let i = 1; i < nums.length; i++) {
    const x = nums[i];
    const candidates = [x, maxCur * x, minCur * x];
    maxCur = Math.max(...candidates);
    minCur = Math.min(...candidates);
    ans = Math.max(ans, maxCur);
  }
  return ans;
};
```

```rust [Rust]
impl Solution {
    pub fn max_product(nums: Vec<i32>) -> i32 {
        let mut max_cur = nums[0];
        let mut min_cur = nums[0];
        let mut ans = nums[0];
        for &num in &nums[1..] {
            let a = max_cur * num;
            let b = min_cur * num;
            max_cur = num.max(a.max(b));
            min_cur = num.min(a.min(b));
            ans = ans.max(max_cur);
        }
        ans
    }
}
```

```go [Go]
func maxProduct(nums []int) int {
	maxCur, minCur, ans := nums[0], nums[0], nums[0]
	for i := 1; i < len(nums); i++ {
		x := nums[i]
		a, b := maxCur*x, minCur*x
		maxCur, minCur = x, x
		if a > maxCur {
			maxCur = a
		}
		if b > maxCur {
			maxCur = b
		}
		if a < minCur {
			minCur = a
		}
		if b < minCur {
			minCur = b
		}
		if maxCur > ans {
			ans = maxCur
		}
	}
	return ans
}
```

```java [Java]
class Solution {
    public int maxProduct(int[] nums) {
        int maxCur = nums[0];
        int minCur = nums[0];
        int ans = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];
            int a = maxCur * x;
            int b = minCur * x;
            maxCur = Math.max(x, Math.max(a, b));
            minCur = Math.min(x, Math.min(a, b));
            ans = Math.max(ans, maxCur);
        }
        return ans;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，一次线性扫描，每步常数次乘法与比较。
- 空间复杂度：O(1)，只用到三个滚动变量。
