# 找到字符串中所有字母异位词

> 难度：中等 | 标签：哈希表、字符串、滑动窗口 | [LeetCode 原题](https://leetcode.cn/problems/find-all-anagrams-in-a-string/description/)

## 题目描述

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词**的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**示例 1：**

```
输入：s = "cbaebabacd", p = "abc"
输出：[0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
```

**示例 2：**

```
输入：s = "abab", p = "ab"
输出：[0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
```

**提示:**

- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 仅包含小写字母

## 题解

:::: details 点击查看题解

### 思路

本质是「定长滑动窗口 + 字符计数比较」：长度固定为 `|p|` 的窗口在 `s` 上滑动，用两张长度 26 的计数数组分别记录 `p` 的字符需求和窗口内的实际字符数，窗口每滑动一格就增一减二地维护计数，当两张表完全一致时窗口就是 `p` 的异位词，记录窗口左端点即可。

逐格比较两张表需要 O(26)，是常数，但更优雅的写法是维护一个 `matched` 计数：它等于「两张计数表相等的字母种数」，入窗前若该字母恰好相等先减一，更新计数后若重新相等再加一，出窗同理；当 `matched == 26` 时两张表完全相同。注意必须在更新计数**之前**判断相等性，顺序颠倒会让 `matched` 统计错位。

`p` 只含小写字母，所以 26 的定长数组即可，不必用哈希表；`s.length` 可达 `3 * 10^4` 而 `|p|` 可能比 `s` 还长，开头要先判断 `|p| > |s|` 直接返回空数组，避免负数下标。常见坑是把「窗口包含 `p` 的全部字母」当成异位词条件——包含不等于计数完全一致，必须逐字母计数相等。

```javascript [JavaScript]
var findAnagrams = function(s, p) {
  const n = s.length;
  const m = p.length;
  if (n < m) return [];
  const need = new Array(26).fill(0);
  const window = new Array(26).fill(0);
  for (let i = 0; i < m; i++) {
    need[p.charCodeAt(i) - 97]++;
  }
  let matched = 0;
  for (let i = 0; i < 26; i++) {
    if (window[i] === need[i]) matched++;
  }
  const res = [];
  for (let right = 0; right < n; right++) {
    const inIdx = s.charCodeAt(right) - 97;
    if (window[inIdx] === need[inIdx]) matched--;
    window[inIdx]++;
    if (window[inIdx] === need[inIdx]) matched++;
    if (right >= m) {
      const outIdx = s.charCodeAt(right - m) - 97;
      if (window[outIdx] === need[outIdx]) matched--;
      window[outIdx]--;
      if (window[outIdx] === need[outIdx]) matched++;
    }
    if (right >= m - 1 && matched === 26) {
      res.push(right - m + 1);
    }
  }
  return res;
};
```

```python [Python]
class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        n, m = len(s), len(p)
        if n < m:
            return []
        need = [0] * 26
        window = [0] * 26
        for ch in p:
            need[ord(ch) - 97] += 1
        matched = sum(1 for i in range(26) if window[i] == need[i])
        res = []
        for right in range(n):
            in_idx = ord(s[right]) - 97
            if window[in_idx] == need[in_idx]:
                matched -= 1
            window[in_idx] += 1
            if window[in_idx] == need[in_idx]:
                matched += 1
            if right >= m:
                out_idx = ord(s[right - m]) - 97
                if window[out_idx] == need[out_idx]:
                    matched -= 1
                window[out_idx] -= 1
                if window[out_idx] == need[out_idx]:
                    matched += 1
            if right >= m - 1 and matched == 26:
                res.append(right - m + 1)
        return res
```

```rust [Rust]
impl Solution {
    pub fn find_anagrams(s: String, p: String) -> Vec<i32> {
        let sb = s.as_bytes();
        let pb = p.as_bytes();
        let n = sb.len();
        let m = pb.len();
        if n < m {
            return vec![];
        }
        let mut need = [0i32; 26];
        let mut window = [0i32; 26];
        for &b in pb {
            need[(b - b'a') as usize] += 1;
        }
        let mut matched = 0i32;
        for i in 0..26 {
            if window[i] == need[i] {
                matched += 1;
            }
        }
        let mut res = Vec::new();
        for right in 0..n {
            let in_idx = (sb[right] - b'a') as usize;
            if window[in_idx] == need[in_idx] {
                matched -= 1;
            }
            window[in_idx] += 1;
            if window[in_idx] == need[in_idx] {
                matched += 1;
            }
            if right >= m {
                let out_idx = (sb[right - m] - b'a') as usize;
                if window[out_idx] == need[out_idx] {
                    matched -= 1;
                }
                window[out_idx] -= 1;
                if window[out_idx] == need[out_idx] {
                    matched += 1;
                }
            }
            if right + 1 >= m && matched == 26 {
                res.push((right + 1 - m) as i32);
            }
        }
        res
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，定长窗口滑过 `s` 每个位置一次，每次只做 O(1) 的计数增减（26 为常数）。
- 空间复杂度：O(1)，两张长度 26 的计数数组与常数个变量。
