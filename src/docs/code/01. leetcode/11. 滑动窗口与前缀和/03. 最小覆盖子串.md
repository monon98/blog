# 最小覆盖子串

> 难度：困难 | 标签：哈希表、字符串、滑动窗口 | [LeetCode 原题](https://leetcode.cn/problems/minimum-window-substring/description/)

## 题目描述

给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 s 中的 **最短窗口 子串**，使得该子串包含 `t` 中的每一个字符（**包括重复字符**）。如果没有这样的子串，返回空字符串 `""`。

测试用例保证答案唯一。

**示例 1：**

```
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。
```

**示例 2：**

```
输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。
```

**示例 3：**

```
输入：s = "a", t = "aa"
输出：""
解释：t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。
```

**提示：**

- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 10^5`
- `s` 和 `t` 由英文字母组成

**进阶：** 你能设计一个在 `O(m + n)` 时间内解决此问题的算法吗？

## 题解

:::: details 点击查看题解

### 思路

用「需求计数表 + 窗口计数表 + 已满足字符种数」的经典滑动窗口：先把 `t` 中每个字符需要的个数记入 `need`，右指针扩张时把字符计入 `window`，某字符个数恰好追平需求就让计数器 `matched` 加一；当 `matched` 达到 `need` 的键数量，说明窗口已覆盖 `t` 的全部字符，此时尝试收缩左指针——每移出一个字符，若其个数跌破需求就让 `matched` 减一——收缩过程中不断用更短的窗口更新答案。

循环不变量是「`matched` 等于 `window` 中个数已达到需求的字符种数」，只有在这个状态下窗口才合法，因此每次都在进入合法状态的那一刻先记录、再收缩，保证不漏解。`t` 中可能有重复字符，所以判定必须按「个数」而不是「出现过」来比较，示例 3 就是靠个数不足返回空串的。

注意更新答案要在收缩**之前**进行：若先移出字符再判断合法性，会错过以当前左端点为起点的最优窗口。`m`、`n` 最大 `10^5`，字符集只有 52 个字母，每次收缩只做 O(1) 的计数增减，整体达到进阶要求的 `O(m + n)`。

```javascript [JavaScript]
var minWindow = function(s, t) {
  const need = new Map();
  const window = new Map();
  for (const ch of t) {
    need.set(ch, (need.get(ch) || 0) + 1);
  }
  let matched = 0;
  let left = 0;
  let start = 0;
  let minLen = Infinity;
  for (let right = 0; right < s.length; right++) {
    const ch = s[right];
    window.set(ch, (window.get(ch) || 0) + 1);
    if (need.has(ch) && window.get(ch) === need.get(ch)) {
      matched++;
    }
    while (matched === need.size) {
      if (right - left + 1 < minLen) {
        minLen = right - left + 1;
        start = left;
      }
      const out = s[left];
      window.set(out, window.get(out) - 1);
      if (need.has(out) && window.get(out) < need.get(out)) {
        matched--;
      }
      left++;
    }
  }
  return minLen === Infinity ? "" : s.substring(start, start + minLen);
};
```

```python [Python]
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        need = {}
        window = {}
        for ch in t:
            need[ch] = need.get(ch, 0) + 1
        matched = 0
        left = 0
        start = 0
        min_len = float('inf')
        for right, ch in enumerate(s):
            window[ch] = window.get(ch, 0) + 1
            if ch in need and window[ch] == need[ch]:
                matched += 1
            while matched == len(need):
                if right - left + 1 < min_len:
                    min_len = right - left + 1
                    start = left
                out = s[left]
                window[out] -= 1
                if out in need and window[out] < need[out]:
                    matched -= 1
                left += 1
        return "" if min_len == float('inf') else s[start:start + min_len]
```

```rust [Rust]
impl Solution {
    pub fn min_window(s: String, t: String) -> String {
        use std::collections::HashMap;
        let chars: Vec<char> = s.chars().collect();
        let mut need: HashMap<char, i32> = HashMap::new();
        for ch in t.chars() {
            *need.entry(ch).or_insert(0) += 1;
        }
        let mut window: HashMap<char, i32> = HashMap::new();
        let mut matched = 0usize;
        let mut left = 0usize;
        let mut start = 0usize;
        let mut min_len = usize::MAX;
        for right in 0..chars.len() {
            let ch = chars[right];
            *window.entry(ch).or_insert(0) += 1;
            if let Some(&cnt) = need.get(&ch) {
                if window[&ch] == cnt {
                    matched += 1;
                }
            }
            while matched == need.len() {
                if right - left + 1 < min_len {
                    min_len = right - left + 1;
                    start = left;
                }
                let out = chars[left];
                *window.get_mut(&out).unwrap() -= 1;
                if let Some(&cnt) = need.get(&out) {
                    if window[&out] < cnt {
                        matched -= 1;
                    }
                }
                left += 1;
            }
        }
        if min_len == usize::MAX {
            String::new()
        } else {
            chars[start..start + min_len].iter().collect()
        }
    }
}
```

```go [Go]
func minWindow(s string, t string) string {
	need := make(map[byte]int)
	for i := 0; i < len(t); i++ {
		need[t[i]]++
	}
	window := make(map[byte]int)
	matched := 0
	left, start := 0, 0
	minLen := len(s) + 1
	for right := 0; right < len(s); right++ {
		ch := s[right]
		window[ch]++
		if cnt, ok := need[ch]; ok && window[ch] == cnt {
			matched++
		}
		for matched == len(need) {
			if right-left+1 < minLen {
				minLen = right - left + 1
				start = left
			}
			out := s[left]
			window[out]--
			if cnt, ok := need[out]; ok && window[out] < cnt {
				matched--
			}
			left++
		}
	}
	if minLen > len(s) {
		return ""
	}
	return s[start : start+minLen]
}
```

```java [Java]
class Solution {
    public String minWindow(String s, String t) {
        Map<Character, Integer> need = new HashMap<>();
        for (char ch : t.toCharArray()) {
            need.merge(ch, 1, Integer::sum);
        }
        Map<Character, Integer> window = new HashMap<>();
        int matched = 0;
        int left = 0, start = 0;
        int minLen = Integer.MAX_VALUE;
        for (int right = 0; right < s.length(); right++) {
            char ch = s.charAt(right);
            window.merge(ch, 1, Integer::sum);
            if (need.containsKey(ch) && window.get(ch).equals(need.get(ch))) {
                matched++;
            }
            while (matched == need.size()) {
                if (right - left + 1 < minLen) {
                    minLen = right - left + 1;
                    start = left;
                }
                char out = s.charAt(left);
                window.merge(out, -1, Integer::sum);
                if (need.containsKey(out) && window.get(out) < need.get(out)) {
                    matched--;
                }
                left++;
            }
        }
        return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
    }
}
```

### 复杂度分析

- 时间复杂度：O(m + n)，预处理 `t` 需 O(n)，双指针扫描 `s` 每个字符进出窗口各一次。
- 空间复杂度：O(k)，k 为 `t`（或窗口）中不同字符数，字符集为 52 个字母时为 O(1)。
