# 字符串的排列

> 难度：中等 | 标签：哈希表、双指针、字符串、滑动窗口 | [LeetCode 原题](https://leetcode.cn/problems/permutation-in-string/description/)

## 题目描述

给你两个字符串 `s1` 和 `s2` ，写一个函数来判断 `s2` 是否包含 `s1` 的 排列。如果是，返回 `true` ；否则，返回 `false` 。

换句话说，`s1` 的排列之一是 `s2` 的 **子串** 。

**示例 1：**

```
输入：s1 = "ab" s2 = "eidbaooo"
输出：true
解释：s2 包含 s1 的排列之一 ("ba").
```

**示例 2：**

```
输入：s1= "ab" s2 = "eidboaoo"
输出：false
```

**提示：**

- `1 <= s1.length, s2.length <= 10^4`
- `s1` 和 `s2` 仅包含小写字母

## 题解

### 思路

「`s1` 的排列是 `s2` 的子串」等价于「`s2` 中存在一个长度为 `|s1|` 的窗口，其字符计数与 `s1` 完全相同」，因此用定长滑动窗口求解：先把 `s1` 的字符计数记入 `need`，窗口以 `|s1|` 为固定宽度在 `s2` 上滑动，每移入一个字符就加一、移出一个字符就减一，两张计数表一致即返回 `true`。

和上一题一样，维护 `matched` 表示「两张计数表相等的字母种数」可以在 O(1) 内判断整表是否相等，避免每步 O(26) 的数组比较；判断相等的语句必须放在计数增减**之前**，否则统计的不是变更前的状态。窗口不足 `|s1|` 宽度时只扩张不判断，`right >= |s1| - 1` 之后才开始检查。

注意两个方向的顺序陷阱：先查再增、先查再减，任何一个写反都会让 `matched` 与真实状态脱节。若允许 `s1` 长于 `s2`，窗口永远凑不齐，直接返回 `false` 即可（提示中 `s1.length`、`s2.length` 虽都为正，但大小关系任意）。

```javascript [JavaScript]
var checkInclusion = function(s1, s2) {
  const n = s2.length;
  const m = s1.length;
  if (n < m) return false;
  const need = new Array(26).fill(0);
  const window = new Array(26).fill(0);
  for (let i = 0; i < m; i++) {
    need[s1.charCodeAt(i) - 97]++;
  }
  let matched = 0;
  for (let i = 0; i < 26; i++) {
    if (window[i] === need[i]) matched++;
  }
  for (let right = 0; right < n; right++) {
    const inIdx = s2.charCodeAt(right) - 97;
    if (window[inIdx] === need[inIdx]) matched--;
    window[inIdx]++;
    if (window[inIdx] === need[inIdx]) matched++;
    if (right >= m) {
      const outIdx = s2.charCodeAt(right - m) - 97;
      if (window[outIdx] === need[outIdx]) matched--;
      window[outIdx]--;
      if (window[outIdx] === need[outIdx]) matched++;
    }
    if (right >= m - 1 && matched === 26) return true;
  }
  return false;
};
```

```python [Python]
class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        n, m = len(s2), len(s1)
        if n < m:
            return False
        need = [0] * 26
        window = [0] * 26
        for ch in s1:
            need[ord(ch) - 97] += 1
        matched = sum(1 for i in range(26) if window[i] == need[i])
        for right in range(n):
            in_idx = ord(s2[right]) - 97
            if window[in_idx] == need[in_idx]:
                matched -= 1
            window[in_idx] += 1
            if window[in_idx] == need[in_idx]:
                matched += 1
            if right >= m:
                out_idx = ord(s2[right - m]) - 97
                if window[out_idx] == need[out_idx]:
                    matched -= 1
                window[out_idx] -= 1
                if window[out_idx] == need[out_idx]:
                    matched += 1
            if right >= m - 1 and matched == 26:
                return True
        return False
```

```rust [Rust]
impl Solution {
    pub fn check_inclusion(s1: String, s2: String) -> bool {
        let b1 = s1.as_bytes();
        let b2 = s2.as_bytes();
        let n = b2.len();
        let m = b1.len();
        if n < m {
            return false;
        }
        let mut need = [0i32; 26];
        let mut window = [0i32; 26];
        for &b in b1 {
            need[(b - b'a') as usize] += 1;
        }
        let mut matched = 0i32;
        for i in 0..26 {
            if window[i] == need[i] {
                matched += 1;
            }
        }
        for right in 0..n {
            let in_idx = (b2[right] - b'a') as usize;
            if window[in_idx] == need[in_idx] {
                matched -= 1;
            }
            window[in_idx] += 1;
            if window[in_idx] == need[in_idx] {
                matched += 1;
            }
            if right >= m {
                let out_idx = (b2[right - m] - b'a') as usize;
                if window[out_idx] == need[out_idx] {
                    matched -= 1;
                }
                window[out_idx] -= 1;
                if window[out_idx] == need[out_idx] {
                    matched += 1;
                }
            }
            if right + 1 >= m && matched == 26 {
                return true;
            }
        }
        false
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，定长窗口滑过 `s2` 每个位置一次，每次只做 O(1) 的计数增减。
- 空间复杂度：O(1)，两张长度 26 的计数数组与常数个变量。
