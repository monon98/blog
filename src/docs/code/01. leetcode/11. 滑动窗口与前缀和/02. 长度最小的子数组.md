# 长度最小的子数组

> 难度：中等 | 标签：数组、前缀和、滑动窗口 | [LeetCode 原题](https://leetcode.cn/problems/minimum-size-subarray-sum/description/)

## 题目描述

给定一个含有 `n` 个正整数的数组和一个正整数 `target`**。**

找出该数组中满足其总和大于等于 `target` 的长度最小的 **子数组** `[nums_l, nums_l+1, ..., nums_r-1, nums_r]` ，并返回其长度**。**如果不存在符合条件的子数组，返回 `0` 。

**示例 1：**

```
输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 是该条件下的长度最小的子数组。
```

**示例 2：**

```
输入：target = 4, nums = [1,4,4]
输出：1
```

**示例 3：**

```
输入：target = 11, nums = [1,1,1,1,1,1,1,1]
输出：0
```

**提示：**

- `1 <= target <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`

**进阶：**

- 如果你已经实现 `O(n)` 时间复杂度的解法, 请尝试设计一个 `O(n log(n))` 时间复杂度的解法。

### 思路

因为 `nums[i]` 全为正数，窗口和随右端点右移单调不减、随左端点右移严格减小，所以可以用滑动窗口线性求解：右指针不断纳入元素累加窗口和，一旦和达到 `target` 就尝试收缩左指针——每次收缩都用 `right - left + 1` 更新答案，直到和小于 `target` 再继续扩张。窗口和在过程中始终不小于 `target` 的收缩区间才会被记录，最终若答案仍是无穷大说明没有符合条件的子数组，返回 `0`。

循环不变量是「窗口 `[left, right]` 的元素和是扩张前缀上第一个（也是当前最靠左的）达到 `target` 的区间」。由于数组元素为正，收缩过程中一旦和跌破 `target` 必须停止，左指针不能继续右移，否则会漏掉以当前右端点结尾的更短合法区间。

这道题元素为正是关键前提；若允许负数，窗口和不再单调，滑动窗口失效，此时应改用前缀和加二分：对每个右端点在前缀和数组上二分找最小的 `left` 使 `prefix[right + 1] - prefix[left] >= target`，得到进阶要求的 `O(n log n)` 解法。

```javascript [JavaScript]
var minSubArrayLen = function(target, nums) {
  let left = 0;
  let sum = 0;
  let minLen = Infinity;
  for (let right = 0; right < nums.length; right++) {
    sum += nums[right];
    while (sum >= target) {
      minLen = Math.min(minLen, right - left + 1);
      sum -= nums[left];
      left++;
    }
  }
  return minLen === Infinity ? 0 : minLen;
};
```

```python [Python]
class Solution:
    def minSubArrayLen(self, target: int, nums: list[int]) -> int:
        left = 0
        window_sum = 0
        min_len = float('inf')
        for right, num in enumerate(nums):
            window_sum += num
            while window_sum >= target:
                min_len = min(min_len, right - left + 1)
                window_sum -= nums[left]
                left += 1
        return 0 if min_len == float('inf') else min_len
```

```rust [Rust]
        let mut window_sum = 0i64;
        let mut min_len = i32::MAX;

            }
        }
```

```go [Go]
func minSubArrayLen(target int, nums []int) int {
	left, windowSum := 0, 0
	minLen := len(nums) + 1
	for right := 0; right < len(nums); right++ {
		windowSum += nums[right]
		for windowSum >= target {
			if right-left+1 < minLen {
				minLen = right - left + 1
			}
			windowSum -= nums[left]
			left++
		}
	}
	if minLen > len(nums) {
		return 0
	}
	return minLen
}
```

### 复杂度分析

- 时间复杂度：O(n)，左右指针各至多移动 n 次，窗口和只做加减。
- 空间复杂度：O(1)，只用到常数个指针与累加变量。
