# 水果成篮

> 难度：中等 | 标签：数组、哈希表、滑动窗口 | [LeetCode 原题](https://leetcode.cn/problems/fruit-into-baskets/description/)

## 题目描述

你正在探访一家农场，农场从左到右种植了一排果树。这些树用一个整数数组 `fruits` 表示，其中 `fruits[i]` 是第 `i` 棵树上的水果 **种类** 。

你想要尽可能多地收集水果。然而，农场的主人设定了一些严格的规矩，你必须按照要求采摘水果：

- 你只有 **两个** 篮子，并且每个篮子只能装 **单一类型** 的水果。每个篮子能够装的水果总量没有限制。
- 你可以选择任意一棵树开始采摘，你必须从 **每棵** 树（包括开始采摘的树）上 **恰好摘一个水果** 。采摘的水果应当符合篮子中的水果类型。每采摘一次，你将会向右移动到下一棵树，并继续采摘。
- 一旦你走到某棵树前，但水果不符合篮子的水果类型，那么就必须停止采摘。

给你一个整数数组 `fruits` ，返回你可以收集的水果的 **最大** 数目。

**示例 1：**

```
输入：fruits = [1,2,1]
输出：3
解释：可以采摘全部 3 棵树。
```

**示例 2：**

```
输入：fruits = [0,1,2,2]
输出：3
解释：可以采摘 [1,2,2] 这三棵树。
如果从第一棵树开始采摘，则只能采摘 [0,1] 这两棵树。
```

**示例 3：**

```
输入：fruits = [1,2,3,2,2]
输出：4
解释：可以采摘 [2,3,2,2] 这四棵树。
如果从第一棵树开始采摘，则只能采摘 [1,2] 这两棵树。
```

**示例 4：**

```
输入：fruits = [3,3,3,1,2,1,1,2,3,3,4]
输出：5
解释：可以采摘 [1,2,1,1,2] 这五棵树。
```

**提示：**

- `1 <= fruits.length <= 10^5`
- `0 <= fruits[i] < fruits.length`

## 题解

:::: details 点击查看题解

### 思路

「两个篮子只能装两种水果」等价于「求最长的、至多包含两种不同取值的子数组」，于是套用滑动窗口模板：右指针逐棵树纳入，用哈希表统计窗口内每种水果的数量；一旦种类数超过 `2`，左指针不断右移并把移出水果的计数减一、减到 `0` 就删键，直到种类回到 `≤ 2`，窗口合法时更新答案。

循环不变量是「处理完收缩后，哈希表恰好统计着窗口 `[left, right]` 内的水果种类及数量，且种类数不超过 2」。必须**先纳入、再收缩、最后更新答案**，三步顺序不能换：若先更新再收缩，会把种类超限的非法窗口记入答案；计数减到 `0` 时不删除键会让 `size` 虚高，导致窗口被过度收缩。

常见坑是把问题理解成「必须从第一棵树开始」——题目明确可以任选起点，所以必须用双指针滑动而非固定起点；另一个变体是「至多 K 种」，把代码里的 `2` 换成 `K` 即可，本题 `K = 2` 时哈希表最多同时存在 3 个键（收缩前的瞬时状态），空间仍是常数级。

### 代码实现

```javascript [JavaScript]
var totalFruit = function(fruits) {
  const window = new Map();
  let left = 0;
  let ans = 0;
  for (let right = 0; right < fruits.length; right++) {
    const t = fruits[right];
    window.set(t, (window.get(t) || 0) + 1);
    while (window.size > 2) {
      const out = fruits[left];
      window.set(out, window.get(out) - 1);
      if (window.get(out) === 0) window.delete(out);
      left++;
    }
    ans = Math.max(ans, right - left + 1);
  }
  return ans;
};
```

```python [Python]
class Solution:
    def totalFruit(self, fruits: list[int]) -> int:
        window = {}
        left = 0
        ans = 0
        for right, t in enumerate(fruits):
            window[t] = window.get(t, 0) + 1
            while len(window) > 2:
                out = fruits[left]
                window[out] -= 1
                if window[out] == 0:
                    del window[out]
                left += 1
            ans = max(ans, right - left + 1)
        return ans
```

```rust [Rust]
impl Solution {
    pub fn total_fruit(fruits: Vec<i32>) -> i32 {
        use std::collections::HashMap;
        let mut window: HashMap<i32, i32> = HashMap::new();
        let mut left = 0usize;
        let mut ans = 0i32;
        for right in 0..fruits.len() {
            let t = fruits[right];
            *window.entry(t).or_insert(0) += 1;
            while window.len() > 2 {
                let out = fruits[left];
                *window.get_mut(&out).unwrap() -= 1;
                if window[&out] == 0 {
                    window.remove(&out);
                }
                left += 1;
            }
            ans = ans.max((right - left + 1) as i32);
        }
        ans
    }
}
```

```go [Go]
func totalFruit(fruits []int) int {
	window := make(map[int]int)
	left, ans := 0, 0
	for right := 0; right < len(fruits); right++ {
		t := fruits[right]
		window[t]++
		for len(window) > 2 {
			out := fruits[left]
			window[out]--
			if window[out] == 0 {
				delete(window, out)
			}
			left++
		}
		if right-left+1 > ans {
			ans = right - left + 1
		}
	}
	return ans
}
```

```java [Java]
class Solution {
    public int totalFruit(int[] fruits) {
        Map<Integer, Integer> window = new HashMap<>();
        int left = 0, ans = 0;
        for (int right = 0; right < fruits.length; right++) {
            int t = fruits[right];
            window.merge(t, 1, Integer::sum);
            while (window.size() > 2) {
                int out = fruits[left];
                window.merge(out, -1, Integer::sum);
                if (window.get(out) == 0) {
                    window.remove(out);
                }
                left++;
            }
            ans = Math.max(ans, right - left + 1);
        }
        return ans;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，左右指针各至多移动 n 次，每个元素进出哈希表各一次。
- 空间复杂度：O(1)，哈希表最多同时保存 3 个键（种类超过 2 即收缩）。
