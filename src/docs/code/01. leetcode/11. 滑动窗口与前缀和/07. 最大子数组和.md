# 最大子数组和

> 难度：中等 | 标签：数组、分治、动态规划 | [LeetCode 原题](https://leetcode.cn/problems/maximum-subarray/description/)

## 题目描述

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组 **是数组中的一个连续部分。

**示例 1：**

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
```

**示例 2：**

```
输入：nums = [1]
输出：1
```

**示例 3：**

```
输入：nums = [5,4,-1,7,8]
输出：23
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

**进阶：** 如果你已经实现复杂度为 `O(n)` 的解法，尝试使用更为精妙的 **分治法** 求解。

## 题解

:::: details 点击查看题解

### 思路

标准 Kadane 动态规划：状态 `cur` 表示「以当前位置结尾的最大子数组和」，转移方程是 `cur = max(nums[i], cur + nums[i])`——要么把当前元素接在上一个结尾子数组后面，要么另起炉灶从当前元素重新开始，答案在所有 `cur` 中取最大值。

「以 `i` 结尾」这一状态定义是不变量的关键：它保证了子数组的连续性，而 `max(nums[i], ...)` 中单独取 `nums[i]` 保证了子数组至少含一个元素，负数前缀会被果断丢弃。因为 `cur` 只依赖前一个状态，滚动一个变量即可，无需数组。

注意初始化：`cur` 和 `ans` 都必须从 `nums[0]` 开始，若初始化为 `0`，全负数组会错误地返回 `0`。题面数组长度下界是 `1`，不必处理空数组；进阶的分治解法把数组二分成左右两半，除递归答案外再统计「跨越中点的最大前缀和 + 最大后缀和」，复杂度同样是 O(n)，常数更大但思路与本解一致。

### 代码实现

::: code-group

```javascript [JavaScript]
var maxSubArray = function(nums) {
  let cur = nums[0];
  let ans = nums[0];
  for (let i = 1; i < nums.length; i++) {
    cur = Math.max(nums[i], cur + nums[i]);
    ans = Math.max(ans, cur);
  }
  return ans;
};
```

```python [Python]
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        cur = ans = nums[0]
        for num in nums[1:]:
            cur = max(num, cur + num)
            ans = max(ans, cur)
        return ans
```

```rust [Rust]
impl Solution {
    pub fn max_sub_array(nums: Vec<i32>) -> i32 {
        let mut cur = nums[0];
        let mut ans = nums[0];
        for &num in &nums[1..] {
            cur = num.max(cur + num);
            ans = ans.max(cur);
        }
        ans
    }
}
```

```go [Go]
func maxSubArray(nums []int) int {
	cur, ans := nums[0], nums[0]
	for i := 1; i < len(nums); i++ {
		if cur+nums[i] > nums[i] {
			cur = cur + nums[i]
		} else {
			cur = nums[i]
		}
		if cur > ans {
			ans = cur
		}
	}
	return ans
}
```

### 复杂度分析

- 时间复杂度：O(n)，只需一次线性扫描。
- 空间复杂度：O(1)，只用到两个滚动变量。
