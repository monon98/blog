# 平衡二叉树

> 难度：简单 | 标签：树、深度优先搜索、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/balanced-binary-tree/description/)

## 题目描述

给定一个二叉树，判断它是否是高度平衡的二叉树。本题中，一棵高度平衡二叉树定义为：二叉树每个节点的左右两个子树的高度差的绝对值不超过 1。

**示例 1：**

```
输入：root = [3,9,20,null,null,15,7]
输出：true
```

**示例 2：**

```
输入：root = [1,2,2,3,3,null,null,4,4]
输出：false
```

**提示：**

- 树中的节点数在范围 `[0, 5000]` 内
- `-10^4 <= Node.val <= 10^4`

## 题解

::: details 点击查看题解

### 思路

自底向上递归（后序遍历）：函数返回子树高度；一旦某棵子树不平衡就用 `-1` 作为标记快速上抛。当前节点检查左右高度——任一侧为 -1 或两侧高度差大于 1，就返回 -1；否则返回正常高度。根调用结果不等于 -1 即平衡。

对比「自顶向下」的写法（每个节点重复计算子树高度），自底向上只访问每个节点一次，是 O(n) 的最优实现。

### 代码实现

```javascript
var isBalanced = function(root) {
  const height = (node) => {
    if (!node) return 0;
    const lh = height(node.left);
    const rh = height(node.right);
    if (lh === -1 || rh === -1 || Math.abs(lh - rh) > 1) return -1;
    return 1 + Math.max(lh, rh);
  };
  return height(root) !== -1;
};
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点计算一次。
- 空间复杂度：O(h)，递归栈深度为树高。
