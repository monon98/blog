# 搜索插入位置

> 难度：简单 | 标签：数组、二分查找 | [LeetCode 原题](https://leetcode.cn/problems/search-insert-position/description/)

## 题目描述

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。请必须使用时间复杂度为 O(log n) 的算法。

**示例 1：**

```
输入：nums = [1,3,5,6], target = 5
输出：2
```

**示例 2：**

```
输入：nums = [1,3,5,6], target = 2
输出：1
```

**示例 3：**

```
输入：nums = [1,3,5,6], target = 7
输出：4
```

**提示：**

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- nums 为无重复元素的升序排列数组
- `-10^4 <= target <= 10^4`

## 题解

:::: details 点击查看题解

### 思路

标准二分查找的变体：找不到时不返回 -1，而是返回循环结束时 `l` 的位置——它恰好是「第一个大于等于 target 的下标」（即插入点）。

原因是不变量保证退出时 `l` 左边全部小于 target、右边（含 r+1 = l）全部大于 target，所以 l 就是应插入的位置。

### 代码实现

::: code-group

```javascript [JavaScript]
var searchInsert = function(nums, target) {
  let l = 0;
  let r = nums.length - 1;
  while (l <= r) {
    const mid = (l + r) >> 1;
    if (nums[mid] === target) return mid;
    if (nums[mid] < target) {
      l = mid + 1;
    } else {
      r = mid - 1;
    }
  }
  return l;
};
```

impl Solution {
    pub fn search_insert(nums: Vec<i32>, target: i32) -> i32 {
        let (mut l, mut r) = (0isize, nums.len() as isize - 1);
        while l <= r {
            let mid = l + (r - l) / 2;
            if nums[mid as usize] == target {
                return mid as i32;
            }
            if nums[mid as usize] < target {
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        l as i32
    }
}
