# 括号生成

> 难度：中等 | 标签：字符串、动态规划、回溯、括号序列 | [LeetCode 原题](https://leetcode.cn/problems/generate-parentheses/description/)

## 题目描述

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的**括号组合。

**示例 1：**

```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

**示例 2：**

```
输入：n = 1
输出：["()"]
```

**提示：**

- `1 <= n <= 8`

## 题解

:::: details 点击查看题解

### 思路

回溯构造字符串，状态是已放左括号数 `open` 与已放右括号数 `close`。每一步只有两个合法扩展：`open` 小于 n 时放 '('；`close` 小于 `open` 时放 ')'——右括号必须有左括号兜底。两个计数都达到 n 时得到一个长度 2n 的有效括号串，记录答案。

不变量「close 不超过 open」是有效性的核心：只要始终维持它且最终两者都等于 n，生成的每个串天然有效，无需事后用栈校验；反之若允许 close 超过 open，就会产出 ")(" 之类的非法串。n 最大为 8，搜索树是卡特兰数规模，直接枚举很快。

替代解法是动态规划：用 dp[len] 表示长度为 len 的有效括号串集合，按「( 内层 ) 外层」拼接递推（卡特兰递推），这正是题目带动态规划标签的由来，两种写法结果集合相同、顺序不同。常见坑是漏掉 close 与 open 的大小判断，生成非法串。

```javascript [JavaScript]
var generateParenthesis = function(n) {
  const res = [];
  const path = [];
  const dfs = (open, close) => {
    if (path.length === 2 * n) {
      res.push(path.join(''));
      return;
    }
    if (open < n) {
      path.push('(');
      dfs(open + 1, close);
      path.pop();
    }
    if (close < open) {
      path.push(')');
      dfs(open, close + 1);
      path.pop();
    }
  };
  dfs(0, 0);
  return res;
};
```

```rust [Rust]
impl Solution {
    pub fn generate_parenthesis(n: i32) -> Vec<String> {
        let n = n as usize;
        let mut res = Vec::new();
        let mut path = String::new();
        fn dfs(open: usize, close: usize, n: usize, path: &mut String, res: &mut Vec<String>) {
            if path.len() == 2 * n {
                res.push(path.clone());
                return;
            }
            if open < n {
                path.push('(');
                dfs(open + 1, close, n, path, res);
                path.pop();
            }
            if close < open {
                path.push(')');
                dfs(open, close + 1, n, path, res);
                path.pop();
            }
        }
        dfs(0, 0, n, &mut path, &mut res);
        res
    }
}
```

```java [Java]
class Solution {
    private List<String> res = new ArrayList<>();
    private StringBuilder path = new StringBuilder();
    private int n;

    public List<String> generateParenthesis(int n) {
        this.n = n;
        dfs(0, 0);
        return res;
    }

    private void dfs(int open, int close) {
        if (path.length() == 2 * n) {
            res.add(path.toString());
            return;
        }
        if (open < n) {
            path.append('(');
            dfs(open + 1, close);
            path.deleteCharAt(path.length() - 1);
        }
        if (close < open) {
            path.append(')');
            dfs(open, close + 1);
            path.deleteCharAt(path.length() - 1);
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(C_n × n)，C_n 为第 n 个卡特兰数（约 4^n / n^1.5），即结果个数，每个结果长 2n 需拷贝。
- 空间复杂度：O(n)，递归栈深度与当前构造串的长度（不计答案占用）。
