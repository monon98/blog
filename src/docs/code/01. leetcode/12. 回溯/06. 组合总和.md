# 组合总和

> 难度：中等 | 标签：数组、回溯 | [LeetCode 原题](https://leetcode.cn/problems/combination-sum/description/)

## 题目描述

给你一个 **无重复元素** 的整数数组 `candidates` 和一个目标整数 `target` ，找出 `candidates` 中可以使数字和为目标数 `target` 的 所有 **不同组合** ，并以列表形式返回。你可以按 **任意顺序** 返回这些组合。

`candidates` 中的 **同一个** 数字可以 **无限制重复被选取** 。如果至少一个数字的被选数量不同，则两种组合是不同的。

对于给定的输入，保证和为 `target` 的不同组合数少于 `150` 个。

**示例 1：**

```
输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：
2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。
7 也是一个候选， 7 = 7 。
仅有这两种组合。
```

**示例 2：**

```
输入：candidates = [2,3,5], target = 8
输出：[[2,2,2,2],[2,3,3],[3,5]]
```

**示例 3：**

```
输入：candidates = [2], target = 1
输出：[]
```

**提示：**

- `1 <= candidates.length <= 30`
- `2 <= candidates[i] <= 40`
- `candidates` 的所有元素 **互不相同**
- `1 <= target <= 40`

### 思路

先排序，再回溯：`dfs(start, remain)` 表示从下标 `start` 起把 `remain` 凑成 0。`remain` 为 0 时记录当前路径；否则 for `i` 从 `start` 到末尾，若 `candidates[i]` 大于 `remain` 直接 break（数组已排序，后面只会更大），否则加入路径、递归 `dfs(i, remain - candidates[i])`——注意下一轮起点仍是 `i` 而不是 `i + 1`，这正是「同一个数可重复使用」的体现。

循环不变量是路径内元素下标不降，因此 [2,2,3] 与 [2,3,2] 这类仅顺序不同的选择只生成 [2,2,3] 一条，天然去重。`target` 最大 40、`candidates[i]` 最大 40，题目又保证不同组合少于 150 个，指数级搜索配合剪枝完全可行。

最常见的坑是递归时传了 `i + 1`——那会退化成每个数最多用一次的组合问题，直接漏解；不排序则无法用 break 剪枝，只能用 continue，死分支明显变多。本实现是排序加 break 剪枝。

```javascript [JavaScript]
var combinationSum = function(candidates, target) {
  const n = candidates.length;
  const res = [];
  const path = [];
  candidates.sort((a, b) => a - b);
  const dfs = (start, remain) => {
    if (remain === 0) {
      res.push([...path]);
      return;
    }
    for (let i = start; i < n; i++) {
      if (candidates[i] > remain) break;
      path.push(candidates[i]);
      dfs(i, remain - candidates[i]);
      path.pop();
    }
  };
  dfs(0, target);
  return res;
};
```

```python [Python]
class Solution:
    def combinationSum(self, candidates: list[int], target: int) -> list[list[int]]:
        candidates.sort()
        res: list[list[int]] = []
        path: list[int] = []

        def dfs(start: int, remain: int) -> None:
            if remain == 0:
                res.append(path[:])
                return
            for i in range(start, len(candidates)):
                if candidates[i] > remain:
                    break
                path.append(candidates[i])
                dfs(i, remain - candidates[i])
                path.pop()

        dfs(0, target)
        return res
```

```rust [Rust]
impl Solution {
    pub fn combination_sum(mut candidates: Vec<i32>, target: i32) -> Vec<Vec<i32>> {
        candidates.sort();
        let mut res = Vec::new();
        let mut path = Vec::new();
        fn dfs(
            start: usize,
            remain: i32,
            candidates: &[i32],
            path: &mut Vec<i32>,
            res: &mut Vec<Vec<i32>>,
        ) {
            if remain == 0 {
                res.push(path.clone());
                return;
            }
            for i in start..candidates.len() {
                if candidates[i] > remain {
                    break;
                }
                path.push(candidates[i]);
                dfs(i, remain - candidates[i], candidates, path, res);
                path.pop();
            }
        }
        dfs(0, target, &candidates, &mut path, &mut res);
        res
    }
}
```

```go [Go]
import "sort"

func combinationSum(candidates []int, target int) [][]int {
	sort.Ints(candidates)
	res := [][]int{}
	path := []int{}
	var dfs func(start int, remain int)
	dfs = func(start int, remain int) {
		if remain == 0 {
			cur := make([]int, len(path))
			copy(cur, path)
			res = append(res, cur)
			return
		}
		for i := start; i < len(candidates); i++ {
			if candidates[i] > remain {
				break
			}
			path = append(path, candidates[i])
			dfs(i, remain-candidates[i])
			path = path[:len(path)-1]
		}
	}
	dfs(0, target)
	return res
}
```

```java [Java]
class Solution {
    private List<List<Integer>> res = new ArrayList<>();
    private List<Integer> path = new ArrayList<>();
    private int[] candidates;

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        Arrays.sort(candidates);
        this.candidates = candidates;
        dfs(0, target);
        return res;
    }

    private void dfs(int start, int remain) {
        if (remain == 0) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = start; i < candidates.length; i++) {
            if (candidates[i] > remain) break;
            path.add(candidates[i]);
            dfs(i, remain - candidates[i]);
            path.remove(path.size() - 1);
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(2^t)，t 为 target，排序 O(m log m)（m 为 candidates 长度），剪枝后实际远小于最坏情况，题目保证组合数少于 150。
- 空间复杂度：O(t)，递归栈深度与路径长度最坏为 target 除以最小候选数（不计排序与答案占用）。
