# 电话号码的字母组合

> 难度：中等 | 标签：哈希表、字符串、回溯 | [LeetCode 原题](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/description/)

## 题目描述

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

**示例 1：**

```
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

**示例 2：**

```
输入：digits = "2"
输出：["a","b","c"]
```

**提示：**

- `1 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字。

## 题解

### 思路

把数字到字母的映射存成数组（下标 = 数字字符减 '2'，依次为 "abc"、"def"、"ghi"、"jkl"、"mno"、"pqrs"、"tuv"、"wxyz"），回溯 `dfs(index, path)`：`index` 达到 `digits` 长度时记录当前路径构成的字符串；否则取出 `digits[index]` 对应的字母表，逐个字母加入路径、递归 `index + 1`、回溯弹出。

这是一棵每个节点最多 4 个分支、深度为 `digits.length` 的树，组合总数不超过 4^4 = 256，直接枚举即可，无需任何剪枝。映射数组本质上就是一张哈希表（题目哈希表标签的由来），用数组下标运算表达更省事。

常见坑是 `digits` 为空字符串：若不特判，首次调用就会把空串记进答案，返回 [""] 而不是 []，本实现开头直接判空返回。另一个小坑是数字转下标写错（'2' 对应下标 0 而不是 2）。

```javascript [JavaScript]
var letterCombinations = function(digits) {
  if (digits.length === 0) return [];
  const mapping = ['abc', 'def', 'ghi', 'jkl', 'mno', 'pqrs', 'tuv', 'wxyz'];
  const res = [];
  const path = [];
  const dfs = (index) => {
    if (index === digits.length) {
      res.push(path.join(''));
      return;
    }
    const letters = mapping[digits.charCodeAt(index) - 50];
    for (const ch of letters) {
      path.push(ch);
      dfs(index + 1);
      path.pop();
    }
  };
  dfs(0);
  return res;
};
```

```python [Python]
class Solution:
    def letterCombinations(self, digits: str) -> list[str]:
        if not digits:
            return []
        mapping = ["abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"]
        res: list[str] = []
        path: list[str] = []

        def dfs(index: int) -> None:
            if index == len(digits):
                res.append("".join(path))
                return
            for ch in mapping[ord(digits[index]) - ord("2")]:
                path.append(ch)
                dfs(index + 1)
                path.pop()

        dfs(0)
        return res
```

```rust [Rust]
impl Solution {
    pub fn letter_combinations(digits: String) -> Vec<String> {
        if digits.is_empty() {
            return Vec::new();
        }
        let mapping = ["abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"];
        let digits = digits.as_bytes();
        let mut res = Vec::new();
        let mut path = String::new();
        fn dfs(
            index: usize,
            digits: &[u8],
            mapping: &[&str; 8],
            path: &mut String,
            res: &mut Vec<String>,
        ) {
            if index == digits.len() {
                res.push(path.clone());
                return;
            }
            let letters = mapping[(digits[index] - b'2') as usize];
            for ch in letters.bytes() {
                path.push(ch as char);
                dfs(index + 1, digits, mapping, path, res);
                path.pop();
            }
        }
        dfs(0, digits, &mapping, &mut path, &mut res);
        res
    }
}
```

```go [Go]
func letterCombinations(digits string) []string {
	res := []string{}
	if len(digits) == 0 {
		return res
	}
	mapping := []string{"abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"}
	path := []byte{}
	var dfs func(index int)
	dfs = func(index int) {
		if index == len(digits) {
			res = append(res, string(path))
			return
		}
		letters := mapping[digits[index]-'2']
		for i := 0; i < len(letters); i++ {
			path = append(path, letters[i])
			dfs(index + 1)
			path = path[:len(path)-1]
		}
	}
	dfs(0)
	return res
}
```

```java [Java]
class Solution {
    private List<String> res = new ArrayList<>();
    private StringBuilder path = new StringBuilder();
    private String[] mapping = {"abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
    private String digits;

    public List<String> letterCombinations(String digits) {
        if (digits.isEmpty()) return res;
        this.digits = digits;
        dfs(0);
        return res;
    }

    private void dfs(int index) {
        if (index == digits.length()) {
            res.add(path.toString());
            return;
        }
        String letters = mapping[digits.charAt(index) - '2'];
        for (int i = 0; i < letters.length(); i++) {
            path.append(letters.charAt(i));
            dfs(index + 1);
            path.deleteCharAt(path.length() - 1);
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(4^n × n)，n 为 `digits` 的长度，组合数最多 4^n，每个组合构造需要 O(n)。
- 空间复杂度：O(n)，递归栈深度与路径长度（不计答案占用）。
