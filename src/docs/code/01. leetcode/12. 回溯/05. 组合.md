# 组合

> 难度：中等 | 标签：回溯 | [LeetCode 原题](https://leetcode.cn/problems/combinations/description/)

## 题目描述

给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。

你可以按 **任何顺序** 返回答案。

**示例 1：**

```
输入：n = 4, k = 2
输出：
[
  [2,4],
  [3,4],
  [2,3],
  [1,2],
  [1,3],
  [1,4],
]
```

**示例 2：**

```
输入：n = 1, k = 1
输出：[[1]]
```

**提示：**

- `1 <= n <= 20`
- `1 <= k <= n`

## 题解

:::: details 点击查看题解

### 思路

回溯枚举组合：`dfs(start)` 中路径长度达到 k 时记录答案，否则 for `i` 从 `start` 到 `n`，把 `i` 加入路径，递归 `dfs(i + 1)`（下一轮只能从 `i` 之后继续选），回溯弹出。`start` 递增保证路径内元素下标递增，[1,2] 与 [2,1] 这类顺序不同、集合相同的解只生成一次，天然去重。

再加一条剪枝：剩余可选元素不够填满路径时不必再往下走——枚举上界取 `n - (k - 当前长度) + 1`，即最后一个「还来得及」的位置。`n` 最大 20、`k` 不超过 `n`，不剪枝也能通过，但剪枝砍掉大量死分支，对 C(20,10) 这类最坏情况效果明显。

常见坑是上界差一写错导致漏解（比如写成 `n - (k - 当前长度)` 就会少枚举一个位置）。另一种等价写法是「选 / 不选」二叉树枚举，每个元素两个分支、共 2^n 个节点，正确但节点数翻倍。本实现用 start 枚举加上界剪枝。

```javascript [JavaScript]
var combine = function(n, k) {
  const res = [];
  const path = [];
  const dfs = (start) => {
    if (path.length === k) {
      res.push([...path]);
      return;
    }
    for (let i = start; i <= n - (k - path.length) + 1; i++) {
      path.push(i);
      dfs(i + 1);
      path.pop();
    }
  };
  dfs(1);
  return res;
};
```

```python [Python]
class Solution:
    def combine(self, n: int, k: int) -> list[list[int]]:
        res: list[list[int]] = []
        path: list[int] = []

        def dfs(start: int) -> None:
            if len(path) == k:
                res.append(path[:])
                return
            for i in range(start, n - (k - len(path)) + 2):
                path.append(i)
                dfs(i + 1)
                path.pop()

        dfs(1)
        return res
```

```rust [Rust]
impl Solution {
    pub fn combine(n: i32, k: i32) -> Vec<Vec<i32>> {
        let n = n as usize;
        let k = k as usize;
        let mut res = Vec::new();
        let mut path = Vec::new();
        fn dfs(start: usize, n: usize, k: usize, path: &mut Vec<i32>, res: &mut Vec<Vec<i32>>) {
            if path.len() == k {
                res.push(path.clone());
                return;
            }
            for i in start..=n - (k - path.len()) + 1 {
                path.push(i as i32);
                dfs(i + 1, n, k, path, res);
                path.pop();
            }
        }
        dfs(1, n, k, &mut path, &mut res);
        res
    }
}
```

```go [Go]
func combine(n int, k int) [][]int {
	res := [][]int{}
	path := []int{}
	var dfs func(start int)
	dfs = func(start int) {
		if len(path) == k {
			cur := make([]int, k)
			copy(cur, path)
			res = append(res, cur)
			return
		}
		for i := start; i <= n-(k-len(path))+1; i++ {
			path = append(path, i)
			dfs(i + 1)
			path = path[:len(path)-1]
		}
	}
	dfs(1)
	return res
}
```

```java [Java]
class Solution {
    private List<List<Integer>> res = new ArrayList<>();
    private List<Integer> path = new ArrayList<>();
    private int n, k;

    public List<List<Integer>> combine(int n, int k) {
        this.n = n;
        this.k = k;
        dfs(1);
        return res;
    }

    private void dfs(int start) {
        if (path.size() == k) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = start; i <= n - (k - path.size()) + 1; i++) {
            path.add(i);
            dfs(i + 1);
            path.remove(path.size() - 1);
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(C(n, k) × k)，共 C(n, k) 个组合，每个拷贝入答案需要 O(k)，剪枝后不枚举无效分支。
- 空间复杂度：O(k)，递归栈深度与 `path` 长度（不计答案占用）。
