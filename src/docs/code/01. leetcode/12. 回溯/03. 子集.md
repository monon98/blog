# 子集

> 难度：中等 | 标签：位运算、数组、回溯 | [LeetCode 原题](https://leetcode.cn/problems/subsets/description/)

## 题目描述

给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。

解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

**示例 1：**

```
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**示例 2：**

```
输入：nums = [0]
输出：[[],[0]]
```

**提示：**

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有元素 **互不相同**

## 题解

:::: details 点击查看题解

### 思路

回溯按「从 `start` 开始逐个决定选谁」的树形枚举：进入 `dfs(start)` 先把当前路径记录为一个子集，然后 for 循环 `i` 从 `start` 到末尾，把 `nums[i]` 加入路径、递归 `dfs(i + 1)`、回溯弹出。递归参数 `start` 保证每个子集只按「下标递增」的顺序生成一次，配合元素互不相同的约束，天然不重不漏。

注意答案要在「每次进入 dfs 时」记录，而不是只在递归边界记录——后者只能拿到长度为 n 的满子集，会漏掉绝大多数解。`nums.length` 最大为 10，子集总数为 2^10 = 1024，指数级枚举完全可行。

常见坑是漏掉回溯弹出，导致后续分支拿到被污染的路径。另一种等价写法是二进制枚举：枚举 0 到 2^n - 1，第 i 位为 1 表示选 `nums[i]`，与本实现一一对应（这也是题目带位运算标签的原因），`n` 较小时同样好写。

### 代码实现

::: code-group

```javascript [JavaScript]
var subsets = function(nums) {
  const res = [];
  const path = [];
  const dfs = (start) => {
    res.push([...path]);
    for (let i = start; i < nums.length; i++) {
      path.push(nums[i]);
      dfs(i + 1);
      path.pop();
    }
  };
  dfs(0);
  return res;
};
```

```python [Python]
class Solution:
    def subsets(self, nums: list[int]) -> list[list[int]]:
        res: list[list[int]] = []
        path: list[int] = []

        def dfs(start: int) -> None:
            res.append(path[:])
            for i in range(start, len(nums)):
                path.append(nums[i])
                dfs(i + 1)
                path.pop()

        dfs(0)
        return res
```

```rust [Rust]
impl Solution {
    pub fn subsets(nums: Vec<i32>) -> Vec<Vec<i32>> {
        let mut res = Vec::new();
        let mut path = Vec::new();
        fn dfs(start: usize, nums: &[i32], path: &mut Vec<i32>, res: &mut Vec<Vec<i32>>) {
            res.push(path.clone());
            for i in start..nums.len() {
                path.push(nums[i]);
                dfs(i + 1, nums, path, res);
                path.pop();
            }
        }
        dfs(0, &nums, &mut path, &mut res);
        res
    }
}
```

```go [Go]
func subsets(nums []int) [][]int {
	res := [][]int{}
	path := []int{}
	var dfs func(start int)
	dfs = func(start int) {
		cur := make([]int, len(path))
		copy(cur, path)
		res = append(res, cur)
		for i := start; i < len(nums); i++ {
			path = append(path, nums[i])
			dfs(i + 1)
			path = path[:len(path)-1]
		}
	}
	dfs(0)
	return res
}
```

```java [Java]
class Solution {
    private List<List<Integer>> res = new ArrayList<>();
    private List<Integer> path = new ArrayList<>();
    private int[] nums;

    public List<List<Integer>> subsets(int[] nums) {
        this.nums = nums;
        dfs(0);
        return res;
    }

    private void dfs(int start) {
        res.add(new ArrayList<>(path));
        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);
            dfs(i + 1);
            path.remove(path.size() - 1);
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(n × 2^n)，共 2^n 个子集，每个子集拷贝入答案需要 O(n)。
- 空间复杂度：O(n)，递归栈深度与 `path` 长度（不计答案占用）。
