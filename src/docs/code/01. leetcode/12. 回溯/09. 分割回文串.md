# 分割回文串

> 难度：中等 | 标签：字符串、动态规划、回溯 | [LeetCode 原题](https://leetcode.cn/problems/palindrome-partitioning/description/)

## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成一些 子串，使每个子串都是 **回文串** 。返回 `s` 所有可能的分割方案。

**示例 1：**

```
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
```

**示例 2：**

```
输入：s = "a"
输出：[["a"]]
```

**提示：**

- `1 <= s.length <= 16`
- `s` 仅由小写英文字母组成

## 题解

### 思路

回溯枚举分割点：`dfs(start)` 中，若 `start` 到达串尾，说明当前位置之前已经全部切成回文串，记录当前方案；否则枚举结束位置 `end`，若子串 `s[start..end]` 是回文就把它加入当前方案，递归 `dfs(end + 1)`，返回时弹出。每条从根到叶子的路径就是一种把 `s` 切成回文串的方案，`end` 从 `start` 试到末尾保证不漏。

回文判断用 O(n²) 的 DP 预处理：`isPal[i][j]` 表示 `s[i..j]` 是否回文，按 `i` 从后往前递推 `isPal[i][j] = (s[i] == s[j]) && isPal[i+1][j-1]`，`&&` 的短路保证下标不越界，这正是题目动态规划标签的由来；预处理后每次分割 O(1) 判断。递推必须从后往前，否则会读到尚未计算的位置。`s.length` 最大为 16，即使每次用双指针现判也够快，DP 写法更通用。

常见坑是只试单字符或只试最长回文，都会漏掉方案。另一种等价写法是不预处理、递归里直接双指针判断回文，代码更短但每次 O(n)。

```javascript [JavaScript]
var partition = function(s) {
  const n = s.length;
  const isPal = Array.from({ length: n }, () => new Array(n).fill(false));
  for (let i = n - 1; i >= 0; i--) {
    for (let j = i; j < n; j++) {
      isPal[i][j] = s[i] === s[j] && (j - i < 2 || isPal[i + 1][j - 1]);
    }
  }
  const res = [];
  const path = [];
  const dfs = (start) => {
    if (start === n) {
      res.push([...path]);
      return;
    }
    for (let end = start; end < n; end++) {
      if (!isPal[start][end]) continue;
      path.push(s.slice(start, end + 1));
      dfs(end + 1);
      path.pop();
    }
  };
  dfs(0);
  return res;
};
```

```python [Python]
class Solution:
    def partition(self, s: str) -> list[list[str]]:
        n = len(s)
        is_pal = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                is_pal[i][j] = s[i] == s[j] and (j - i < 2 or is_pal[i + 1][j - 1])
        res: list[list[str]] = []
        path: list[str] = []

        def dfs(start: int) -> None:
            if start == n:
                res.append(path[:])
                return
            for end in range(start, n):
                if not is_pal[start][end]:
                    continue
                path.append(s[start:end + 1])
                dfs(end + 1)
                path.pop()

        dfs(0)
        return res
```

```rust [Rust]
impl Solution {
    pub fn partition(s: String) -> Vec<Vec<String>> {
        let s = s.as_bytes();
        let n = s.len();
        let mut is_pal = vec![vec![false; n]; n];
        for i in (0..n).rev() {
            for j in i..n {
                is_pal[i][j] = s[i] == s[j] && (j - i < 2 || is_pal[i + 1][j - 1]);
            }
        }
        let mut res = Vec::new();
        let mut path: Vec<String> = Vec::new();
        fn dfs(
            start: usize,
            s: &[u8],
            is_pal: &[Vec<bool>],
            path: &mut Vec<String>,
            res: &mut Vec<Vec<String>>,
        ) {
            if start == s.len() {
                res.push(path.clone());
                return;
            }
            for end in start..s.len() {
                if !is_pal[start][end] {
                    continue;
                }
                path.push(String::from_utf8(s[start..=end].to_vec()).unwrap());
                dfs(end + 1, s, is_pal, path, res);
                path.pop();
            }
        }
        dfs(0, s, &is_pal, &mut path, &mut res);
        res
    }
}
```

```go [Go]
func partition(s string) [][]string {
	n := len(s)
	isPal := make([][]bool, n)
	for i := 0; i < n; i++ {
		isPal[i] = make([]bool, n)
	}
	for i := n - 1; i >= 0; i-- {
		for j := i; j < n; j++ {
			isPal[i][j] = s[i] == s[j] && (j-i < 2 || isPal[i+1][j-1])
		}
	}
	res := [][]string{}
	path := []string{}
	var dfs func(start int)
	dfs = func(start int) {
		if start == n {
			cur := make([]string, len(path))
			copy(cur, path)
			res = append(res, cur)
			return
		}
		for end := start; end < n; end++ {
			if !isPal[start][end] {
				continue
			}
			path = append(path, s[start:end+1])
			dfs(end + 1)
			path = path[:len(path)-1]
		}
	}
	dfs(0)
	return res
}
```

```java [Java]
class Solution {
    private List<List<String>> res = new ArrayList<>();
    private List<String> path = new ArrayList<>();
    private String s;
    private boolean[][] isPal;

    public List<List<String>> partition(String s) {
        int n = s.length();
        this.s = s;
        this.isPal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                isPal[i][j] = s.charAt(i) == s.charAt(j) && (j - i < 2 || isPal[i + 1][j - 1]);
            }
        }
        dfs(0);
        return res;
    }

    private void dfs(int start) {
        if (start == s.length()) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int end = start; end < s.length(); end++) {
            if (!isPal[start][end]) continue;
            path.add(s.substring(start, end + 1));
            dfs(end + 1);
            path.remove(path.size() - 1);
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(n² + S × n)，DP 预处理 O(n²)，S 为分割方案数，每个方案拷贝入答案 O(n)。
- 空间复杂度：O(n²)，`isPal` 表占用，另有 O(n) 的递归栈与路径（不计答案占用）。
