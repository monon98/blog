# N 皇后

> 难度：困难 | 标签：数组、回溯、X 算法 | [LeetCode 原题](https://leetcode.cn/problems/n-queens/description/)

## 题目描述

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回所有不同的 **n 皇后问题** 的解决方案。

每一种解法包含一个不同的 **n 皇后问题** 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

**示例 1：**

```
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
解释：如上图所示，4 皇后问题存在两个不同的解法。
```

**示例 2：**

```
输入：n = 1
输出：[["Q"]]
```

**提示：**

- `1 <= n <= 9`

### 思路

逐行放皇后的回溯：第 `row` 行枚举列 `j`，用三个布尔数组做占用标记——`cols[j]` 表示该列已有皇后，`diag1[row - j + n - 1]` 表示该主对角线（`row - j` 为常数）被占，`diag2[row + j]` 表示该副对角线（`row + j` 为常数）被占。三个标记都为空才放置，把该行棋盘字符串加入路径，递归下一行，返回时清除标记（撤销选择）。

不变量是：任意时刻前 `row` 行每行恰有一个皇后且两两不攻击——列与两条对角线的标记恰好刻画了皇后的全部攻击范围，因此到达 `row == n` 时的路径必然是合法解，无需再逐个检查。`n` 最大为 9，剪枝后搜索树很小（9 皇后仅 352 个解）。

坑点是对角线索引必须加偏移避免负下标（`row - j + n - 1`），标记数组长度取 2n 即可覆盖全部对角线。更省空间的写法是用三个位掩码做位运算剪枝（每行 O(1) 枚举合法列），或按题目标签用 X 算法（精确覆盖）建模求解；本实现用数组标记，直观且足够快。

```javascript [JavaScript]
var solveNQueens = function(n) {
  const res = [];
  const cols = new Array(n).fill(false);
  const diag1 = new Array(2 * n).fill(false);
  const diag2 = new Array(2 * n).fill(false);
  const path = [];
  const dfs = (row) => {
    if (row === n) {
      res.push([...path]);
      return;
    }
    for (let j = 0; j < n; j++) {
      if (cols[j] || diag1[row - j + n - 1] || diag2[row + j]) continue;
      cols[j] = true;
      diag1[row - j + n - 1] = true;
      diag2[row + j] = true;
      path.push('.'.repeat(j) + 'Q' + '.'.repeat(n - j - 1));
      dfs(row + 1);
      path.pop();
      cols[j] = false;
      diag1[row - j + n - 1] = false;
      diag2[row + j] = false;
    }
  };
  dfs(0);
  return res;
};
```

```python [Python]
class Solution:
    def solveNQueens(self, n: int) -> list[list[str]]:
        res: list[list[str]] = []
        cols = [False] * n
        diag1 = [False] * (2 * n)   # i - j + n - 1
        diag2 = [False] * (2 * n)   # i + j
        path: list[str] = []

        def dfs(row: int) -> None:
            if row == n:
                res.append(path[:])
                return
            for j in range(n):
                if cols[j] or diag1[row - j + n - 1] or diag2[row + j]:
                    continue
                cols[j] = True
                diag1[row - j + n - 1] = True
                diag2[row + j] = True
                path.append("." * j + "Q" + "." * (n - j - 1))
                dfs(row + 1)
                path.pop()
                cols[j] = False
                diag1[row - j + n - 1] = False
                diag2[row + j] = False

        return res
```

```rust [Rust]
impl Solution {
    pub fn solve_n_queens(n: i32) -> Vec<Vec<String>> {
        let n = n as usize;
        let mut res = Vec::new();
        let mut cols = vec![false; n];
        let mut diag1 = vec![false; 2 * n];
        let mut diag2 = vec![false; 2 * n];
        let mut path: Vec<String> = Vec::new();
        fn dfs(
            row: usize,
            n: usize,
            cols: &mut Vec<bool>,
            diag1: &mut Vec<bool>,
            diag2: &mut Vec<bool>,
            path: &mut Vec<String>,
            res: &mut Vec<Vec<String>>,
        ) {
            if row == n {
                res.push(path.clone());
                return;
            }
            for j in 0..n {
                if cols[j] || diag1[row + n - 1 - j] || diag2[row + j] {
                    continue;
                }
                cols[j] = true;
                diag1[row + n - 1 - j] = true;
                diag2[row + j] = true;
                path.push(format!("{}Q{}", ".".repeat(j), ".".repeat(n - j - 1)));
                dfs(row + 1, n, cols, diag1, diag2, path, res);
                path.pop();
                cols[j] = false;
                diag1[row + n - 1 - j] = false;
                diag2[row + j] = false;
            }
        }
        dfs(0, n, &mut cols, &mut diag1, &mut diag2, &mut path, &mut res);
        res
    }
}
```

```go [Go]
import "strings"

func solveNQueens(n int) [][]string {
	res := [][]string{}
	cols := make([]bool, n)
	diag1 := make([]bool, 2*n)
	diag2 := make([]bool, 2*n)
	path := []string{}
	var dfs func(row int)
	dfs = func(row int) {
		if row == n {
			cur := make([]string, n)
			copy(cur, path)
			res = append(res, cur)
			return
		}
		for j := 0; j < n; j++ {
			if cols[j] || diag1[row-j+n-1] || diag2[row+j] {
				continue
			}
			cols[j] = true
			diag1[row-j+n-1] = true
			diag2[row+j] = true
			path = append(path, strings.Repeat(".", j)+"Q"+strings.Repeat(".", n-j-1))
			dfs(row + 1)
			path = path[:len(path)-1]
			cols[j] = false
			diag1[row-j+n-1] = false
			diag2[row+j] = false
		}
	}
	dfs(0)
	return res
}
```

```java [Java]
class Solution {
    private List<List<String>> res = new ArrayList<>();
    private List<String> path = new ArrayList<>();
    private boolean[] cols, diag1, diag2;
    private int n;

    public List<List<String>> solveNQueens(int n) {
        this.n = n;
        this.cols = new boolean[n];
        this.diag1 = new boolean[2 * n];
        this.diag2 = new boolean[2 * n];
        dfs(0);
        return res;
    }

    private void dfs(int row) {
        if (row == n) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int j = 0; j < n; j++) {
            if (cols[j] || diag1[row - j + n - 1] || diag2[row + j]) continue;
            cols[j] = true;
            diag1[row - j + n - 1] = true;
            diag2[row + j] = true;
            path.add(".".repeat(j) + "Q" + ".".repeat(n - j - 1));
            dfs(row + 1);
            path.remove(path.size() - 1);
            cols[j] = false;
            diag1[row - j + n - 1] = false;
            diag2[row + j] = false;
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(n!)，逐行枚举候选列并被列与对角线标记大量剪枝，实际远小于此（n = 9 仅 352 个解）。
- 空间复杂度：O(n²)，递归栈 O(n)、当前路径的 n 行棋盘字符串（每行 n 字符）与 O(n) 的标记数组（不计答案占用）。
