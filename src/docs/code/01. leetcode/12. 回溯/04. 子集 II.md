# 子集 II

> 难度：中等 | 标签：位运算、数组、回溯 | [LeetCode 原题](https://leetcode.cn/problems/subsets-ii/description/)

## 题目描述

给你一个整数数组 `nums` ，其中可能包含重复元素，请你返回该数组所有可能的 子集（幂集）。

解集 **不能** 包含重复的子集。返回的解集中，子集可以按 **任意顺序** 排列。

**示例 1：**

```
输入：nums = [1,2,2]
输出：[[],[1],[1,2],[1,2,2],[2],[2,2]]
```

**示例 2：**

```
输入：nums = [0]
输出：[[],[0]]
```

**提示：**

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`

## 题解

:::: details 点击查看题解

### 思路

在子集的「start 枚举」框架上加排序去重：先排序使相同元素相邻，for 循环中若 `nums[i]` 与 `nums[i-1]` 相等且 `i > start` 就跳过——`i > start` 表示 `nums[i-1]` 是本层上一个已经展开过的起点，本层再从相同的数开始会生成一模一样的子集树。

关键就在 `i > start` 这个条件：`i == start` 是本层的第一个位置，必须允许。若写成 `i > 0`，第二层从第一个 2 继续扩展时会被误跳过，[1,2,2] 会漏掉 [1,2,2]。排序让同值元素相邻，同值的整棵子树在上一个同值起点处已经生成过全部结果，跳过即可去重。

常见坑是忘记排序，或直接照搬排列 II 的 `!used[i-1]` 写法（那里依赖 used 数组，本实现没有）。另一种做法是在答案层用集合去重，但要先生成含重复的全部子集，效率明显更差。

```javascript [JavaScript]
var subsetsWithDup = function(nums) {
  const n = nums.length;
  const res = [];
  const path = [];
  nums.sort((a, b) => a - b);
  const dfs = (start) => {
    res.push([...path]);
    for (let i = start; i < n; i++) {
      if (i > start && nums[i] === nums[i - 1]) continue;
      path.push(nums[i]);
      dfs(i + 1);
      path.pop();
    }
  };
  dfs(0);
  return res;
};
```

```python [Python]
class Solution:
    def subsetsWithDup(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        res: list[list[int]] = []
        path: list[int] = []

        def dfs(start: int) -> None:
            res.append(path[:])
            for i in range(start, len(nums)):
                if i > start and nums[i] == nums[i - 1]:
                    continue
                path.append(nums[i])
                dfs(i + 1)
                path.pop()

        dfs(0)
        return res
```

```rust [Rust]
impl Solution {
    pub fn subsets_with_dup(mut nums: Vec<i32>) -> Vec<Vec<i32>> {
        nums.sort();
        let mut res = Vec::new();
        let mut path = Vec::new();
        fn dfs(start: usize, nums: &[i32], path: &mut Vec<i32>, res: &mut Vec<Vec<i32>>) {
            res.push(path.clone());
            for i in start..nums.len() {
                if i > start && nums[i] == nums[i - 1] {
                    continue;
                }
                path.push(nums[i]);
                dfs(i + 1, nums, path, res);
                path.pop();
            }
        }
        dfs(0, &nums, &mut path, &mut res);
        res
    }
}
```

```go [Go]
import "sort"

func subsetsWithDup(nums []int) [][]int {
	sort.Ints(nums)
	res := [][]int{}
	path := []int{}
	var dfs func(start int)
	dfs = func(start int) {
		cur := make([]int, len(path))
		copy(cur, path)
		res = append(res, cur)
		for i := start; i < len(nums); i++ {
			if i > start && nums[i] == nums[i-1] {
				continue
			}
			path = append(path, nums[i])
			dfs(i + 1)
			path = path[:len(path)-1]
		}
	}
	dfs(0)
	return res
}
```

```java [Java]
class Solution {
    private List<List<Integer>> res = new ArrayList<>();
    private List<Integer> path = new ArrayList<>();
    private int[] nums;

    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums);
        this.nums = nums;
        dfs(0);
        return res;
    }

    private void dfs(int start) {
        res.add(new ArrayList<>(path));
        for (int i = start; i < nums.length; i++) {
            if (i > start && nums[i] == nums[i - 1]) continue;
            path.add(nums[i]);
            dfs(i + 1);
            path.remove(path.size() - 1);
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(n × 2^n)，排序 O(n log n)，主体为回溯枚举（去重后子集数不超过 2^n），每个子集拷贝 O(n)。
- 空间复杂度：O(n)，递归栈深度与 `path` 长度（不计排序与答案占用）。
