# 键盘行

> 难度：简单 | 标签：数组、哈希表、字符串 | [LeetCode 原题](https://leetcode.cn/problems/keyboard-row/description/)

## 题目描述

给你一个字符串数组 `words`，只返回可以使用在美式键盘同一行的字母打出来的单词。键盘布局如下所示：

- 第一行由字符 `"qwertyuiop"` 组成
- 第二行由字符 `"asdfghjkl"` 组成
- 第三行由字符 `"zxcvbnm"` 组成

**示例 1：**

```
输入：words = ["Hello","Alaska","Dad","Peace"]
输出：["Alaska","Dad"]
```

**示例 2：**

```
输入：words = ["omk"]
输出：[]
```

**提示：**

- `1 <= words.length <= 20`
- `1 <= words[i].length <= 100`
- `words[i]` 由英文字母（小写和大写）组成

## 题解

### 思路

预处理一张「字符 → 所在行号」的映射表。对每个单词转小写后，检查它的所有字符是否都属于第一个字符所在的行，全部满足才保留。

### 代码实现

```javascript [JavaScript]
var findWords = function(words) {
  const rows = ["qwertyuiop", "asdfghjkl", "zxcvbnm"];
  const charRow = {};
  rows.forEach((row, i) => {
    for (const ch of row) charRow[ch] = i;
  });
  return words.filter((word) => {
    const lower = word.toLowerCase();
    const target = charRow[lower[0]];
    return [...lower].every((ch) => charRow[ch] === target);
  });
};
```

```python [Python]
class Solution:
    def findWords(self, words: List[str]) -> List[str]:
        rows = ["qwertyuiop", "asdfghjkl", "zxcvbnm"]
        char_row = {}
        for i, row in enumerate(rows):
            for ch in row:
                char_row[ch] = i
        res = []
        for word in words:
            lower = word.lower()
            target = char_row[lower[0]]
            if all(char_row[ch] == target for ch in lower):
                res.append(word)
        return res
```

```rust [Rust]
impl Solution {
    pub fn find_words(words: Vec<String>) -> Vec<String> {
        let rows = ["qwertyuiop", "asdfghjkl", "zxcvbnm"];
        let mut char_row = std::collections::HashMap::new();
        for (i, row) in rows.iter().enumerate() {
            for c in row.chars() {
                char_row.insert(c, i);
            }
        }
        words
            .into_iter()
            .filter(|w| {
                let lower: Vec<char> = w.to_lowercase().chars().collect();
                let target = char_row[&lower[0]];
                lower.iter().all(|&c| char_row[&c] == target)
            })
            .collect()
    }
}
```

```go [Go]
func findWords(words []string) []string {
	rows := []string{"qwertyuiop", "asdfghjkl", "zxcvbnm"}
	charRow := map[byte]int{}
	for i, row := range rows {
		for j := 0; j < len(row); j++ {
			charRow[row[j]] = i
		}
	}
	res := []string{}
	for _, word := range words {
		lower := make([]byte, len(word))
		for i := 0; i < len(word); i++ {
			c := word[i]
			if c >= 'A' && c <= 'Z' {
				c += 'a' - 'A'
			}
			lower[i] = c
		}
		target := charRow[lower[0]]
		ok := true
		for i := 0; i < len(lower); i++ {
			if charRow[lower[i]] != target {
				ok = false
				break
			}
		}
		if ok {
			res = append(res, word)
		}
	}
	return res
}
```

```java [Java]
class Solution {
    public String[] findWords(String[] words) {
        String[] rows = {"qwertyuiop", "asdfghjkl", "zxcvbnm"};
        Map<Character, Integer> charRow = new HashMap<>();
        for (int i = 0; i < rows.length; i++) {
            for (char c : rows[i].toCharArray()) charRow.put(c, i);
        }
        List<String> res = new ArrayList<>();
        for (String word : words) {
            String lower = word.toLowerCase();
            int target = charRow.get(lower.charAt(0));
            boolean ok = true;
            for (int i = 0; i < lower.length(); i++) {
                if (charRow.get(lower.charAt(i)) != target) {
                    ok = false;
                    break;
                }
            }
            if (ok) res.add(word);
        }
        return res.toArray(new String[0]);
    }
}
```

### 复杂度分析

- 时间复杂度：O(S)，S 为所有单词的字符总数。
- 空间复杂度：O(1)，映射表大小固定为 26。
