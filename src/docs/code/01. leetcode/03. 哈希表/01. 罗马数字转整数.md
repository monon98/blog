# 罗马数字转整数

> 难度：简单 | 标签：哈希表、数学、字符串 | [LeetCode 原题](https://leetcode.cn/problems/roman-to-integer/description/)

## 题目描述

罗马数字包含以下七种字符：`I`（1）、`V`（5）、`X`（10）、`L`（50）、`C`（100）、`D`（500）和 `M`（1000）。通常写法是小的数字在大的数字右边，但也存在特例：`IV`（4）、`IX`（9）、`XL`（40）、`XC`（90）、`CD`（400）、`CM`（900）。给定一个罗马数字字符串，将其转换成整数。

**示例 1：**

```
输入：s = "III"
输出：3
```

**示例 2：**

```
输入：s = "MCMXCIV"
输出：1994
解释：M = 1000, CM = 900, XC = 90, IV = 4。
```

**提示：**

- `1 <= s.length <= 15`
- `s` 仅含字符 `('I', 'V', 'X', 'L', 'C', 'D', 'M')`
- 题目数据保证 `s` 是一个有效的罗马数字，取值范围 `[1, 3999]`

## 题解

### 思路

核心规律：小值在大值左边时做减法，否则做加法。建立字符到数值的映射后遍历字符串：当前值小于下一个值时减去当前值，否则加上。一次遍历即可。

另一种等价实现是把六种减法组合（IV、IX、XL、XC、CD、CM）预先放进映射表，遇到两字符组合优先匹配。

```javascript [JavaScript]
var romanToInt = function(s) {
  const map = { I: 1, V: 5, X: 10, L: 50, C: 100, D: 500, M: 1000 };
  let res = 0;
  for (let i = 0; i < s.length; i++) {
    const cur = map[s[i]];
    const next = map[s[i + 1]];
    if (next > cur) {
      res -= cur;
    } else {
      res += cur;
    }
  }
  return res;
};
```

```python [Python]
class Solution:
    def romanToInt(self, s: str) -> int:
        values = {'I': 1, 'V': 5, 'X': 10, 'L': 50, 'C': 100, 'D': 500, 'M': 1000}
        res = 0
        for i in range(len(s)):
            cur = values[s[i]]
            nxt = values[s[i + 1]] if i + 1 < len(s) else 0
            if nxt > cur:
                res -= cur
            else:
                res += cur
        return res
```

```rust [Rust]
impl Solution {
    pub fn roman_to_int(s: String) -> i32 {
        fn value(c: char) -> i32 {
            match c {
                'I' => 1,
                'V' => 5,
                'X' => 10,
                'L' => 50,
                'C' => 100,
                'D' => 500,
                _ => 1000,
            }
        }
        let chars: Vec<char> = s.chars().collect();
        let mut res = 0;
        for i in 0..chars.len() {
            let cur = value(chars[i]);
            let next = if i + 1 < chars.len() {
                value(chars[i + 1])
            } else {
                0
            };
            if next > cur {
                res -= cur;
            } else {
                res += cur;
            }
        }
        res
    }
}
```

```java [Java]
class Solution {
    private int value(char c) {
        switch (c) {
            case 'I':
                return 1;
            case 'V':
                return 5;
            case 'X':
                return 10;
            case 'L':
                return 50;
            case 'C':
                return 100;
            case 'D':
                return 500;
            default:
                return 1000;
        }
    }

    public int romanToInt(String s) {
        int res = 0;
        for (int i = 0; i < s.length(); i++) {
            int cur = value(s.charAt(i));
            int next = i + 1 < s.length() ? value(s.charAt(i + 1)) : 0;
            if (next > cur) {
                res -= cur;
            } else {
                res += cur;
            }
        }
        return res;
    }
}
```
