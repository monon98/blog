# 两个列表的最小索引总和

> 难度：简单 | 标签：数组、哈希表、字符串 | [LeetCode 原题](https://leetcode.cn/problems/minimum-index-sum-of-two-lists/description/)

## 题目描述

假设 Andy 和 Doris 想在晚餐时选择一家餐厅，并且他们都有一个表示最喜爱餐厅的列表，每个餐厅的名字用字符串表示。你需要帮他们用最少的索引和找出他们共同喜爱的餐厅。如果答案不止一个，则输出所有答案并且不考虑顺序。你可以假设答案总是存在。

**示例 1：**

```
输入：list1 = ["Shogun","Tapioca Express","Burger King","KFC"], list2 = ["KFC","Shogun","Burger King"]
输出：["Shogun"]
解释：他们共同喜爱且具有最小索引和的餐厅是 "Shogun"，它有最小的索引和 0 + 1 = 1。
```

**示例 2：**

```
输入：list1 = ["happy","sad","good"], list2 = ["sad","happy","good"]
输出：["sad","happy"]
解释："sad" 和 "happy" 的索引和都是 1。
```

**提示：**

- `1 <= list1.length, list2.length <= 1000`
- `1 <= list1[i].length, list2[i].length <= 30`

## 题解

:::: details 点击查看题解

### 思路

先把 `list1` 的「餐厅 → 下标」存入哈希表，再遍历 `list2` 找共同项。维护当前最小索引和 `minSum`：遇到更小的就重置结果列表；相等就追加。

```javascript [JavaScript]
var findRestaurant = function(list1, list2) {
  const idx = {};
  list1.forEach((r, i) => {
    idx[r] = i;
  });
  let minSum = Infinity;
  let res = [];
  list2.forEach((r, j) => {
    if (r in idx) {
      const sum = idx[r] + j;
      if (sum < minSum) {
        minSum = sum;
        res = [r];
      } else if (sum === minSum) {
        res.push(r);
      }
    }
  });
  return res;
};
```

```rust [Rust]
impl Solution {
    pub fn find_restaurant(list1: Vec<String>, list2: Vec<String>) -> Vec<String> {
        let idx: std::collections::HashMap<&str, usize> = list1
            .iter()
            .enumerate()
            .map(|(i, r)| (r.as_str(), i))
            .collect();
        let mut min_sum = usize::MAX;
        let mut res = Vec::new();
        for (j, r) in list2.iter().enumerate() {
            if let Some(&i) = idx.get(r.as_str()) {
                let sum = i + j;
                if sum < min_sum {
                    min_sum = sum;
                    res = vec![r.clone()];
                } else if sum == min_sum {
                    res.push(r.clone());
                }
            }
        }
        res
    }
}
```

```go [Go]
func findRestaurant(list1 []string, list2 []string) []string {
	idx := make(map[string]int, len(list1))
	for i, r := range list1 {
		idx[r] = i
	}
	minSum := 1 << 30
	res := []string{}
	for j, r := range list2 {
		if i, ok := idx[r]; ok {
			sum := i + j
			if sum < minSum {
				minSum = sum
				res = []string{r}
			} else if sum == minSum {
				res = append(res, r)
			}
		}
	}
	return res
}
```

```java [Java]
class Solution {
    public String[] findRestaurant(String[] list1, String[] list2) {
        Map<String, Integer> idx = new HashMap<>();
        for (int i = 0; i < list1.length; i++) idx.put(list1[i], i);
        int minSum = Integer.MAX_VALUE;
        List<String> res = new ArrayList<>();
        for (int j = 0; j < list2.length; j++) {
            Integer i = idx.get(list2[j]);
            if (i != null) {
                int sum = i + j;
                if (sum < minSum) {
                    minSum = sum;
                    res.clear();
                    res.add(list2[j]);
                } else if (sum == minSum) {
                    res.add(list2[j]);
                }
            }
        }
        return res.toArray(new String[0]);
    }
}
```
