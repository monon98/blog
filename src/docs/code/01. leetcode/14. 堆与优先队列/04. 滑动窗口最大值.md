# 滑动窗口最大值

> 难度：困难 | 标签：数组、滑动窗口、单调队列 | [LeetCode 原题](https://leetcode.cn/problems/sliding-window-maximum/description/)

## 题目描述

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回 *滑动窗口中的最大值*。

**示例 1：**

```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
```

**示例 2：**

```
输入：nums = [1], k = 1
输出：[1]
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

## 题解

### 思路

单调递减双端队列（存下标）：队列里下标对应的元素值从队首到队尾单调不增，队首就是当前窗口最大值的下标。处理到下标 `i` 时分三步——先把队首滑出窗口的下标弹掉（`deque[0] <= i - k`）；再把队尾所有值小于 `nums[i]` 的下标弹掉，因为它们在之后的窗口里永远轮不到当最大值；最后把 `i` 入队，当 `i >= k - 1` 时队首即窗口最大值，记录答案。

为什么每个下标只入队、出队各一次：入队时至多把一批更小的下标弹出，而这些下标一旦弹出就再也不回来，摊还下来每个元素操作常数次，总时间 O(n)。相比用堆做是 O(n log n)、ST 表预处理 O(n log n)，单调队列是本题正解。

常见坑是队列里必须存**下标**而不是值——存值就无法判断队首是否已经滑出窗口；另外别忘了先剔除越界下标再弹队尾，顺序反了会把还有效的下标误删。

```javascript [JavaScript]
var maxSlidingWindow = function(nums, k) {
  const n = nums.length;
  const deque = []; // 存下标，对应值单调递减
  let head = 0;
  const res = [];
  for (let i = 0; i < n; i++) {
    while (head < deque.length && deque[head] <= i - k) {
      head++;
    }
    while (deque.length > head && nums[deque[deque.length - 1]] < nums[i]) {
      deque.pop();
    }
    deque.push(i);
    if (i >= k - 1) {
      res.push(nums[deque[head]]);
    }
  }
  return res;
};
```

```python [Python]
from collections import deque


class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        dq = deque()  # 存下标，对应值单调递减
        res = []
        for i, num in enumerate(nums):
            while dq and dq[0] <= i - k:
                dq.popleft()
            while dq and nums[dq[-1]] < num:
                dq.pop()
            dq.append(i)
            if i >= k - 1:
                res.append(nums[dq[0]])
        return res
```

```rust [Rust]
use std::collections::VecDeque;

impl Solution {
    pub fn max_sliding_window(nums: Vec<i32>, k: i32) -> Vec<i32> {
        let k = k as usize;
        let mut dq: VecDeque<usize> = VecDeque::new();
        let mut res = Vec::new();
        for (i, &num) in nums.iter().enumerate() {
            while let Some(&front) = dq.front() {
                if front + k <= i {
                    dq.pop_front();
                } else {
                    break;
                }
            }
            while let Some(&back) = dq.back() {
                if nums[back] < num {
                    dq.pop_back();
                } else {
                    break;
                }
            }
            dq.push_back(i);
            if i + 1 >= k {
                res.push(nums[*dq.front().unwrap()]);
            }
        }
        res
    }
}
```

```go [Go]
func maxSlidingWindow(nums []int, k int) []int {
	n := len(nums)
	deque := make([]int, 0, n) // 存下标，对应值单调递减
	head := 0
	res := make([]int, 0, n-k+1)
	for i := 0; i < n; i++ {
		for head < len(deque) && deque[head] <= i-k {
			head++
		}
		for len(deque) > head && nums[deque[len(deque)-1]] < nums[i] {
			deque = deque[:len(deque)-1]
		}
		deque = append(deque, i)
		if i >= k-1 {
			res = append(res, nums[deque[head]])
		}
	}
	return res
}
```

```java [Java]
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        Deque<Integer> dq = new ArrayDeque<>(); // 存下标，对应值单调递减
        int[] res = new int[n - k + 1];
        int idx = 0;
        for (int i = 0; i < n; i++) {
            while (!dq.isEmpty() && dq.peekFirst() <= i - k) {
                dq.pollFirst();
            }
            while (!dq.isEmpty() && nums[dq.peekLast()] < nums[i]) {
                dq.pollLast();
            }
            dq.offerLast(i);
            if (i >= k - 1) {
                res[idx++] = nums[dq.peekFirst()];
            }
        }
        return res;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个下标至多入队、出队各一次，摊还常数时间。
- 空间复杂度：O(k)，双端队列中有效的下标不超过 k 个。
