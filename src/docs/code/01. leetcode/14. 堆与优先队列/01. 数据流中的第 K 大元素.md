# 数据流中的第 K 大元素

> 难度：简单 | 标签：设计、数据流、堆（优先队列） | [LeetCode 原题](https://leetcode.cn/problems/kth-largest-element-in-a-stream/description/)

## 题目描述

设计一个找到数据流中第 `k` 大元素的类（class）。注意是排序后的第 `k` 大元素，不是第 `k` 个不同的元素。

请实现 `KthLargest` 类：

- `KthLargest(int k, int[] nums)` 使用整数 `k` 和整数流 `nums` 初始化对象。
- `int add(int val)` 将 `val` 插入数据流 `nums` 后，返回当前数据流中第 `k` 大的元素。

示例 1：

**输入：**
["KthLargest", "add", "add", "add", "add", "add"]
[[3, [4, 5, 8, 2]], [3], [5], [10], [9], [4]]

**输出：**[null, 4, 5, 5, 8, 8]

**解释：**

KthLargest kthLargest = new KthLargest(3, [4, 5, 8, 2]);
kthLargest.add(3); // 返回 4
kthLargest.add(5); // 返回 5
kthLargest.add(10); // 返回 5
kthLargest.add(9); // 返回 8
kthLargest.add(4); // 返回 8

示例 2：

**输入：**
["KthLargest", "add", "add", "add", "add"]
[[4, [7, 7, 7, 7, 8, 3]], [2], [10], [9], [9]]

**输出：**[null, 7, 7, 7, 8]

**解释：**

KthLargest kthLargest = new KthLargest(4, [7, 7, 7, 7, 8, 3]);

kthLargest.add(2); // 返回 7

kthLargest.add(10); // 返回 7

kthLargest.add(9); // 返回 7

kthLargest.add(9); // 返回 8

**提示：**

- `0 <= nums.length <= 10^4`
- `1 <= k <= nums.length + 1`
- `-10^4 <= nums[i] <= 10^4`
- `-10^4 <= val <= 10^4`
- 最多调用 `add` 方法 `10^4` 次

## 题解

:::: details 点击查看题解

### 思路

核心是维护一个容量为 `k` 的最小堆，堆里始终保存数据流中最大的 `k` 个元素，那么堆顶就是第 `k` 大。每次 `add` 先把新值入堆，若堆大小超过 `k` 就弹出堆顶（当前堆里最小的那个），这样堆中留下的永远是最大的 `k` 个，堆顶即答案。构造函数先把初始 `nums` 逐个喂进同一套 `add` 逻辑即可。

注意本题允许重复值，第 `k` 大是排序后的第 `k` 个位置而非第 `k` 个不同元素，最小堆方案天然支持重复；另外 `k` 可以等于 `nums.length + 1`，此时堆可能暂时未满，但每次 `add` 之后堆内元素不少于 `k` 个，堆顶始终有定义。

每次 `add` 的入堆、弹堆均为 O(log k)，堆空间最多 `k` 个元素。常见坑是把堆的方向弄反（求第 `k` 大应该用最小堆，堆顶才是"守门员"），或用数组每次排序 O(n log n)，在 `10^4` 次调用下明显更慢。

```javascript [JavaScript]
class MinHeap {
  constructor() {
    this.data = [];
  }
  push(val) {
    const d = this.data;
    d.push(val);
    let i = d.length - 1;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (d[p] <= d[i]) break;
      [d[p], d[i]] = [d[i], d[p]];
      i = p;
    }
  }
  pop() {
    const d = this.data;
    const top = d[0];
    const last = d.pop();
    if (d.length) {
      d[0] = last;
      let i = 0;
      for (;;) {
        let s = i;
        const l = 2 * i + 1;
        const r = l + 1;
        if (l < d.length && d[l] < d[s]) s = l;
        if (r < d.length && d[r] < d[s]) s = r;
        if (s === i) break;
        [d[s], d[i]] = [d[i], d[s]];
        i = s;
      }
    }
    return top;
  }
  peek() {
    return this.data[0];
  }
  get size() {
    return this.data.length;
  }
}

class KthLargest {
  constructor(k, nums) {
    this.k = k;
    this.heap = new MinHeap();
    for (const num of nums) {
      this.add(num);
    }
  }

  add(val) {
    this.heap.push(val);
    if (this.heap.size > this.k) {
      this.heap.pop();
    }
    return this.heap.peek();
  }
}
```

```python [Python]
class KthLargest:

        self.k = k
        self.heap: list[int] = []

            self.add(num)

        if len(self.heap) > self.k:
            heapq.heappop(self.heap)
        return self.heap[0]
```

```rust [Rust]
use std::cell::RefCell;
use std::cmp::Reverse;
use std::collections::BinaryHeap;

struct KthLargest {
    k: i32,
    heap: RefCell<BinaryHeap<Reverse<i32>>>,
}

impl KthLargest {
    fn new(k: i32, nums: Vec<i32>) -> Self {
        let obj = KthLargest {
            k,
            heap: RefCell::new(BinaryHeap::new()),
        };
        for num in nums {
            obj.add(num);
        }
        obj
    }

    fn add(&self, val: i32) -> i32 {
        let mut heap = self.heap.borrow_mut();
        heap.push(Reverse(val));
        if heap.len() as i32 > self.k {
            heap.pop();
        }
        heap.peek().unwrap().0
    }
}
```

```go [Go]
type KthLargest struct {
	k    int
	heap []int
}

func Constructor(k int, nums []int) KthLargest {
	obj := KthLargest{k: k, heap: make([]int, 0, k)}
	for _, num := range nums {
		obj.Add(num)
	}
	return obj
}

func (this *KthLargest) Add(val int) int {
	this.push(val)
	if len(this.heap) > this.k {
		this.pop()
	}
	return this.heap[0]
}

func (this *KthLargest) push(val int) {
	this.heap = append(this.heap, val)
	i := len(this.heap) - 1
	for i > 0 {
		p := (i - 1) / 2
		if this.heap[p] <= this.heap[i] {
			break
		}
		this.heap[p], this.heap[i] = this.heap[i], this.heap[p]
		i = p
	}
}

func (this *KthLargest) pop() {
	n := len(this.heap) - 1
	this.heap[0] = this.heap[n]
	this.heap = this.heap[:n]
	i := 0
	for {
		s, l, r := i, 2*i+1, 2*i+2
		if l < len(this.heap) && this.heap[l] < this.heap[s] {
			s = l
		}
		if r < len(this.heap) && this.heap[r] < this.heap[s] {
			s = r
		}
		if s == i {
			break
		}
		this.heap[s], this.heap[i] = this.heap[i], this.heap[s]
		i = s
	}
}
```

```java [Java]
class KthLargest {

    private final int k;
    private final PriorityQueue<Integer> heap;

    public KthLargest(int k, int[] nums) {
        this.k = k;
        this.heap = new PriorityQueue<>();
        for (int num : nums) {
            add(num);
        }
    }

    public int add(int val) {
        heap.offer(val);
        if (heap.size() > k) {
            heap.poll();
        }
        return heap.peek();
    }
}
```

### 复杂度分析

- 时间复杂度：O(log k)，每次 add 入堆、弹堆均为 O(log k)，构造函数为 O(n log k)。
- 空间复杂度：O(k)，堆中最多保存 k 个元素。
