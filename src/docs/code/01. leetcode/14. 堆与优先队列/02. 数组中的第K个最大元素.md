# 数组中的第K个最大元素

> 难度：中等 | 标签：数组、分治、快速选择 | [LeetCode 原题](https://leetcode.cn/problems/kth-largest-element-in-an-array/description/)

## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1：**

```
输入：[3,2,1,5,6,4], k = 2
输出：5
```

**示例 2：**

```
输入：[3,2,3,1,2,4,5,5,6], k = 4
输出：4
```

**提示：**

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

### 思路

题目要求 O(n)，用快速选择（quickselect）：第 `k` 个最大元素就是升序排列后下标 `n - k` 处的元素，围绕这个目标下标不断划分数组，只递归（迭代）包含目标的一侧。每轮以中点元素为主元做三路划分，把数组分成「小于主元」「等于主元」「大于主元」三段：目标落在小于段就继续在左半边找，落在大于段就去右半边，落入等于段说明主元已经就位，直接返回。

三路划分是这道题的关键细节：`nums` 里有大量重复值（取值范围只有 2 万，数组长度可达 10^5），普通二路划分在全相等数组上会退化到 O(n²)，三路划分让所有等于主元的元素一次性归位，重复越多效率越高。主元取中点而非首元素，是为了规避有序输入的退化；也可以改用随机主元，期望复杂度同为 O(n)。

主元固定取首元素时，有序数组会一步步缩到只剩一个元素，退化为 O(n²) 而超时；另一常见解法是维护大小为 k 的最小堆 O(n log k)，但达不到题目要求的 O(n)，只作备选。

```javascript [JavaScript]
var findKthLargest = function(nums, k) {
  const target = nums.length - k;
  let lo = 0;
  let hi = nums.length - 1;
  while (lo <= hi) {
    const pivot = nums[lo + ((hi - lo) >> 1)];
    let lt = lo;
    let gt = hi;
    let i = lo;
    while (i <= gt) {
      if (nums[i] < pivot) {
        [nums[lt], nums[i]] = [nums[i], nums[lt]];
        lt++;
        i++;
      } else if (nums[i] > pivot) {
        [nums[gt], nums[i]] = [nums[i], nums[gt]];
        gt--;
      } else {
        i++;
      }
    }
    if (target < lt) {
      hi = lt - 1;
    } else if (target > gt) {
      lo = gt + 1;
    } else {
      return nums[target];
    }
  }
  return nums[target];
};
```

```rust [Rust]
impl Solution {
    pub fn find_kth_largest(mut nums: Vec<i32>, k: i32) -> i32 {
        let target = nums.len() - k as usize;
        let (mut lo, mut hi) = (0usize, nums.len() - 1);

    }
```

```java [Java]
class Solution {
    public int findKthLargest(int[] nums, int k) {
        int target = nums.length - k;
        int lo = 0, hi = nums.length - 1;
        while (lo <= hi) {
            int pivot = nums[lo + (hi - lo) / 2];
            int lt = lo, gt = hi, i = lo;
            while (i <= gt) {
                if (nums[i] < pivot) {
                    swap(nums, lt, i);
                    lt++;
                    i++;
                } else if (nums[i] > pivot) {
                    swap(nums, i, gt);
                    gt--;
                } else {
                    i++;
                }
            }
            if (target < lt) {
                hi = lt - 1;
            } else if (target > gt) {
                lo = gt + 1;
            } else {
                return nums[target];
            }
        }
        return nums[target];
    }

    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }
}
```

### 复杂度分析

- 时间复杂度：平均 O(n)，每轮三路划分后只处理包含目标的一侧，区间规模近似减半；取中点主元规避了有序、全同输入的最坏 O(n²)。
- 空间复杂度：O(1)，原地划分，无需递归栈。
