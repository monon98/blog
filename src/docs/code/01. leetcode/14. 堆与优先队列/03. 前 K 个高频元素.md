# 前 K 个高频元素

> 难度：中等 | 标签：数组、哈希表、桶排序、计数 | [LeetCode 原题](https://leetcode.cn/problems/top-k-frequent-elements/description/)

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k` ，请你返回其中出现频率前 `k` 高的元素。你可以按 **任意顺序** 返回答案。

示例 1：

**输入：**nums = [1,1,1,2,2,3], k = 2

**输出：**[1,2]

示例 2：

**输入：**nums = [1], k = 1

**输出：**[1]

示例 3：

**输入：**nums = [1,2,1,2,1,2,3,1,3,2], k = 2

**输出：**[1,2]

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `k` 的取值范围是 `[1, 数组中不相同的元素的个数]`
- 题目数据保证答案唯一，换句话说，数组中前 `k` 个高频元素的集合是唯一的

**进阶：** 你所设计算法的时间复杂度 **必须** 优于 `O(n log n)` ，其中 `n` 是数组大小。

## 题解

:::: details 点击查看题解

### 思路

计数 + 桶排序：先用哈希表统计每个数的出现频率，再按「频率」当下标建桶——桶数组长度 `n + 1`（某个数最多出现 `n` 次），把每个数放进 `buckets[freq]`。最后从高频率向低频率扫桶收集，凑满 `k` 个即返回。因为只需要前 k 个，扫到即停，不必真的把全部元素排序。

这样总时间是计数 O(n) + 填桶 O(n) + 收集 O(n) = O(n)，严格优于进阶要求的 O(n log n)。题目保证前 k 个高频元素的集合唯一，所以同一桶内顺序随意、频率并列时也不会产生歧义，按频率从大到小取满 k 个即可。

常见坑是桶数组长度开成 `n` 而非 `n + 1` 导致下标越界（频率最大可达 `n`）。备选解法是维护大小为 k 的最小堆，时间 O(n log k)，同样满足进阶但比 O(n) 略慢，且代码更长。

```javascript [JavaScript]
var topKFrequent = function(nums, k) {
  const n = nums.length;
  const count = new Map();
  for (const num of nums) {
    count.set(num, (count.get(num) ?? 0) + 1);
  }
  const buckets = Array.from({ length: n + 1 }, () => []);
  for (const [num, freq] of count) {
    buckets[freq].push(num);
  }
  const res = [];
  for (let freq = n; freq >= 1 && res.length < k; freq--) {
    for (const num of buckets[freq]) {
      res.push(num);
      if (res.length === k) break;
    }
  }
  return res;
};
```

```python [Python]
class Solution:
```

```rust [Rust]
use std::collections::HashMap;

impl Solution {
    pub fn top_k_frequent(nums: Vec<i32>, k: i32) -> Vec<i32> {
        let n = nums.len();
        let mut count: HashMap<i32, i32> = HashMap::new();
        for &num in &nums {
            *count.entry(num).or_insert(0) += 1;
        }
        let mut buckets = vec![Vec::new(); n + 1];
        for (num, freq) in count {
            buckets[freq as usize].push(num);
        }
        let mut res = Vec::new();
        for freq in (1..=n).rev() {
            for &num in &buckets[freq] {
                res.push(num);
                if res.len() as i32 == k {
                    return res;
                }
            }
        }
        res
    }
}
```

```go [Go]
func topKFrequent(nums []int, k int) []int {
	n := len(nums)
	count := make(map[int]int)
	for _, num := range nums {
		count[num]++
	}
	buckets := make([][]int, n+1)
	for num, freq := range count {
		buckets[freq] = append(buckets[freq], num)
	}
	res := make([]int, 0, k)
	for freq := n; freq >= 1; freq-- {
		for _, num := range buckets[freq] {
			res = append(res, num)
			if len(res) == k {
				return res
			}
		}
	}
	return res
}
```

```java [Java]
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        int n = nums.length;
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }
        List<Integer>[] buckets = new List[n + 1];
        for (int i = 0; i <= n; i++) {
            buckets[i] = new ArrayList<>();
        }
        for (Map.Entry<Integer, Integer> e : count.entrySet()) {
            buckets[e.getValue()].add(e.getKey());
        }
        int[] res = new int[k];
        int idx = 0;
        for (int freq = n; freq >= 1; freq--) {
            for (int num : buckets[freq]) {
                res[idx++] = num;
                if (idx == k) {
                    return res;
                }
            }
        }
        return res;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，计数、填桶、收集各扫一遍，均为线性。
- 空间复杂度：O(n)，哈希表与桶数组合计保存 O(n) 个元素。
