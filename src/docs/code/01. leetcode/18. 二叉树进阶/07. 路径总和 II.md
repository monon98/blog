# 路径总和 II

> 难度：中等 | 标签：树、深度优先搜索、回溯、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/path-sum-ii/description/)

## 题目描述

给你二叉树的根节点 `root` 和一个整数目标和 `targetSum` ，找出所有 **从根节点到叶子节点** 路径总和等于给定目标和的路径。

**叶子节点** 是指没有子节点的节点。

**示例 1：**

```
输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：[[5,4,11,2],[5,8,4,5]]
```

**示例 2：**

```
输入：root = [1,2,3], targetSum = 5
输出：[]
```

**示例 3：**

```
输入：root = [1,2], targetSum = 0
输出：[]
```

**提示：**

- 树中节点总数在范围 `[0, 5000]` 内
- `-1000

### 思路

DFS 回溯：维护一个全局路径数组 `path`，进入节点时把节点值压入，向左右子树递归时携带缩减后的目标和 `remain - node.val`；当节点是叶子且剩余值恰好等于叶子值时，把当前路径的拷贝加入结果。递归返回前必须弹栈（撤销选择），保证 `path` 在任何时刻都精确对应「根到当前节点」的路径。

两个常见坑：一是结果必须复制路径而不是存入引用，否则后续弹栈会把已经保存的答案改掉；二是结算必须同时满足「是叶子」和「剩余值相等」，内部节点即使 `remain` 恰好等于节点值也必须继续向下找叶子。判断叶子要检查左右孩子都为空，只检查其中一个在单支树上会误判。

另外题目允许负值（`-1000 <= Node.val <= 1000`），所以不能用「剩余值非正就剪枝」这类优化，负数相加仍可能在后面凑回目标和。

```javascript [JavaScript]
var pathSum = function(root, targetSum) {
  const res = [];
  const path = [];
  const dfs = (node, remain) => {
    if (!node) return;
    path.push(node.val);
    if (!node.left && !node.right && remain === node.val) {
      res.push([...path]);
    } else {
      dfs(node.left, remain - node.val);
      dfs(node.right, remain - node.val);
    }
    path.pop();
  };
  dfs(root, targetSum);
  return res;
};
```

```python [Python]
class Solution:
    def pathSum(self, root: TreeNode | None, targetSum: int) -> list[list[int]]:
        res, path = [], []

        def dfs(node: TreeNode | None, remain: int) -> None:
            if not node:
                return
            path.append(node.val)
            if not node.left and not node.right and remain == node.val:
                res.append(path[:])
            else:
                dfs(node.left, remain - node.val)
                dfs(node.right, remain - node.val)
            path.pop()

        dfs(root, targetSum)
        return res
```

```rust [Rust]
use std::rc::Rc;
use std::cell::RefCell;
impl Solution {
    pub fn path_sum(root: Option<Rc<RefCell<TreeNode>>>, target_sum: i32) -> Vec<Vec<i32>> {
        fn dfs(
            node: &Option<Rc<RefCell<TreeNode>>>,
            remain: i32,
            path: &mut Vec<i32>,
            res: &mut Vec<Vec<i32>>,
        ) {
            let n = match node {
                Some(n) => n,
                None => return,
            };
            let (val, left, right) = {
                let b = n.borrow();
                (b.val, b.left.clone(), b.right.clone())
            };
            path.push(val);
            if left.is_none() && right.is_none() && remain == val {
                res.push(path.clone());
            } else {
                dfs(&left, remain - val, path, res);
                dfs(&right, remain - val, path, res);
            }
            path.pop();
        }

        let mut res = Vec::new();
        let mut path = Vec::new();
        dfs(&root, target_sum, &mut path, &mut res);
        res
    }
}
```

```go [Go]
func pathSum(root *TreeNode, targetSum int) [][]int {
	var res [][]int
	var path []int
	var dfs func(*TreeNode, int)
	dfs = func(node *TreeNode, remain int) {
		if node == nil {
			return
		}
		path = append(path, node.Val)
		if node.Left == nil && node.Right == nil && remain == node.Val {
			tmp := make([]int, len(path))
			copy(tmp, path)
			res = append(res, tmp)
		} else {
			dfs(node.Left, remain-node.Val)
			dfs(node.Right, remain-node.Val)
		}
		path = path[:len(path)-1]
	}
	dfs(root, targetSum)
	return res
}
```

```java [Java]
class Solution {
    private List<List<Integer>> res = new ArrayList<>();
    private List<Integer> path = new ArrayList<>();

    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        dfs(root, targetSum);
        return res;
    }

    private void dfs(TreeNode node, int remain) {
        if (node == null) return;
        path.add(node.val);
        if (node.left == null && node.right == null && remain == node.val) {
            res.add(new ArrayList<>(path));
        } else {
            dfs(node.left, remain - node.val);
            dfs(node.right, remain - node.val);
        }
        path.remove(path.size() - 1);
    }
}
```

### 复杂度分析

- 时间复杂度：O(n²)，遍历所有节点为 O(n)，每条命中路径还需复制一次，链状或梳状树上复制总代价最坏 O(n²)。
- 空间复杂度：O(h)，递归栈与路径数组各 O(h)，h 为树高，最坏 O(n)；结果数组另计。
