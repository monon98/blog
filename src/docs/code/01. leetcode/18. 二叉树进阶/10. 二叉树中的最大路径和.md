# 二叉树中的最大路径和

> 难度：困难 | 标签：树、深度优先搜索、动态规划、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/binary-tree-maximum-path-sum/description/)

## 题目描述

二叉树中的**路径** 被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中 **至多出现一次** 。该路径**至少包含一个**节点，且不一定经过根节点。

**路径和** 是路径中各节点值的总和。

给你一个二叉树的根节点 `root` ，返回其 **最大路径和** 。

**示例 1：**

```
输入：root = [1,2,3]
输出：6
解释：最优路径是 2 -> 1 -> 3 ，路径和为 2 + 1 + 3 = 6
```

**示例 2：**

```
输入：root = [-10,9,20,null,null,15,7]
输出：42
解释：最优路径是 15 -> 20 -> 7 ，路径和为 15 + 20 + 7 = 42
```

**提示：**

- 树中节点数目范围是 `[1, 3 * 10^4]`
- `-1000 <= Node.val <= 1000`

### 思路

树形 DP。定义 `gain(node)` 为「从 node 出发向下延伸、且只向一侧走」的最大路径和：先递归求出左右孩子的收益，为负数就截断为 0（等价于不把那段子树接进来）。用它更新全局答案时可以在 node 处把左右两侧拼起来：候选值为 `left + node.val + right`；但向父节点返回时只能选一侧，返回 `node.val + max(left, right)`。

两个量的分工是本题的核心：拼接答案可以用左右两侧，向上汇报只能用一侧——路径要求相邻节点连成链、同一节点至多出现一次，若父节点再接上就会把 node 使用两次，形成非法路径。全局答案在每个节点处都会被一次候选值刷新，因此不需要额外考虑「路径不经过根」的情况。

负值孩子必须截断为 0，否则全为负的树会把「什么都不接」算成负收益拖低结果；节点至少有一个，单节点路径也由 `left = right = 0` 自然覆盖。答案初值取极小值即可（Java 用 `Integer.MIN_VALUE`，Rust 用 `i32::MIN`，JS 用 `-Infinity`）。

```javascript [JavaScript]
var maxPathSum = function(root) {
  let maxSum = -Infinity;
  const gain = (node) => {
    if (!node) return 0;
    const left = Math.max(gain(node.left), 0);
    const right = Math.max(gain(node.right), 0);
    maxSum = Math.max(maxSum, left + node.val + right);
    return node.val + Math.max(left, right);
  };
  gain(root);
  return maxSum;
};
```

```python [Python]
class Solution:
    def maxPathSum(self, root: TreeNode | None) -> int:
        self.max_sum = float('-inf')

        def gain(node: TreeNode | None) -> int:
            if not node:
                return 0
            left = max(gain(node.left), 0)
            right = max(gain(node.right), 0)
            self.max_sum = max(self.max_sum, left + node.val + right)
            return node.val + max(left, right)

        gain(root)
        return self.max_sum
```

```rust [Rust]
use std::rc::Rc;
use std::cell::RefCell;
impl Solution {
    pub fn max_path_sum(root: Option<Rc<RefCell<TreeNode>>>) -> i32 {
        fn gain(node: &Rc<RefCell<TreeNode>>, max_sum: &mut i32) -> i32 {
            let (val, left_node, right_node) = {
                let b = node.borrow();
                (b.val, b.left.clone(), b.right.clone())
            };
            let left = match &left_node {
                Some(n) => gain(n, max_sum).max(0),
                None => 0,
            };
            let right = match &right_node {
                Some(n) => gain(n, max_sum).max(0),
                None => 0,
            };
            *max_sum = (*max_sum).max(left + val + right);
            val + left.max(right)
        }

        let mut max_sum = i32::MIN;
        gain(root.as_ref().unwrap(), &mut max_sum);
        max_sum
    }
}
```

```go [Go]
import "math"

func maxPathSum(root *TreeNode) int {
	maxSum := math.MinInt32
	var gain func(*TreeNode) int
	gain = func(node *TreeNode) int {
		if node == nil {
			return 0
		}
		left := gain(node.Left)
		if left < 0 {
			left = 0
		}
		right := gain(node.Right)
		if right < 0 {
			right = 0
		}
		if s := left + node.Val + right; s > maxSum {
			maxSum = s
		}
		best := left
		if right > best {
			best = right
		}
		return node.Val + best
	}
	gain(root)
	return maxSum
}
```

```java [Java]
class Solution {
    private int maxSum = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        gain(root);
        return maxSum;
    }

    private int gain(TreeNode node) {
        if (node == null) return 0;
        int left = Math.max(gain(node.left), 0);
        int right = Math.max(gain(node.right), 0);
        maxSum = Math.max(maxSum, left + node.val + right);
        return node.val + Math.max(left, right);
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点的 gain 只计算一次。
- 空间复杂度：O(h)，递归栈深度为树高，树退化为链表时为 O(n)。
