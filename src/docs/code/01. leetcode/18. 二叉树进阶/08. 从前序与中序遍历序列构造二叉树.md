# 从前序与中序遍历序列构造二叉树

> 难度：中等 | 标签：树、数组、哈希表、分治 | [LeetCode 原题](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/)

## 题目描述

给定两个整数数组 `preorder` 和 `inorder` ，其中 `preorder` 是二叉树的**先序遍历**， `inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

**示例 1：**

```
输入：preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出：[3,9,20,null,null,15,7]
```

**示例 2：**

```
输入：preorder = [-1], inorder = [-1]
输出：[-1]
```

**提示:**

- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 均 **无重复** 元素
- `inorder` 均出现在 `preorder`
- `preorder` **保证** 为二叉树的前序遍历序列
- `inorder` **保证** 为二叉树的中序遍历序列

### 思路

前序序列的第一个元素一定是当前子树的根；在中序序列里定位这个根，它左侧的区间就是左子树、右侧就是右子树。先用哈希表把中序序列的「值 → 下标」记录下来，定位根即为 O(1)，之后对两段区间递归即可，无需在区间里线性扫描。

递归时维护中序的区间 `[lo, hi]`，并用一个全局指针在前序数组上依次取根：每取一次指针右移，因为左右子树递归取根的顺序与前序「根、左、右」完全一致，指针永远指向当前子树的根。判空条件是 `lo > hi`；当下标为 0 的根被取走后，左区间会变成 `[lo, -1]`，Rust 版需要用 `isize` 表示下标才能安全表达这种「空区间」，用 `usize` 会在 `mid - 1` 处下溢 panic。

题目保证两序列合法、元素互不相同且来自同一棵树，因此无需校验冲突；若序列可能非法，还需在递归中检查根在剩余区间内确实存在。

```javascript [JavaScript]
var buildTree = function(preorder, inorder) {
  const inIndex = new Map();
  inorder.forEach((v, i) => inIndex.set(v, i));
  let preIdx = 0;
  const build = (lo, hi) => {
    if (lo > hi) return null;
    const val = preorder[preIdx++];
    const node = new TreeNode(val);
    const mid = inIndex.get(val);
    node.left = build(lo, mid - 1);
    node.right = build(mid + 1, hi);
    return node;
  };
  return build(0, inorder.length - 1);
};
```

```python [Python]
class Solution:
    def buildTree(self, preorder: list[int], inorder: list[int]) -> TreeNode | None:
        in_index = {v: i for i, v in enumerate(inorder)}
        pre_idx = 0

        def build(lo: int, hi: int) -> TreeNode | None:
            nonlocal pre_idx
            if lo > hi:
                return None
            val = preorder[pre_idx]
            pre_idx += 1
            node = TreeNode(val)
            mid = in_index[val]
            node.left = build(lo, mid - 1)
            node.right = build(mid + 1, hi)
            return node

        return build(0, len(inorder) - 1)
```

```rust [Rust]
use std::rc::Rc;
use std::cell::RefCell;
use std::collections::HashMap;
impl Solution {
    pub fn build_tree(preorder: Vec<i32>, inorder: Vec<i32>) -> Option<Rc<RefCell<TreeNode>>> {
        let index: HashMap<i32, usize> = inorder
            .iter()
            .enumerate()
            .map(|(i, &v)| (v, i))
            .collect();
        let mut pre_idx = 0usize;
        fn build(
            preorder: &[i32],
            index: &HashMap<i32, usize>,
            pre_idx: &mut usize,
            lo: isize,
            hi: isize,
        ) -> Option<Rc<RefCell<TreeNode>>> {
            if lo > hi {
                return None;
            }
            let val = preorder[*pre_idx];
            *pre_idx += 1;
            let mid = index[&val] as isize;
            let mut node = TreeNode::new(val);
            node.left = build(preorder, index, pre_idx, lo, mid - 1);
            node.right = build(preorder, index, pre_idx, mid + 1, hi);
            Some(Rc::new(RefCell::new(node)))
        }
        build(&preorder, &index, &mut pre_idx, 0, inorder.len() as isize - 1)
    }
}
```

```go [Go]
func buildTree(preorder []int, inorder []int) *TreeNode {
	index := make(map[int]int, len(inorder))
	for i, v := range inorder {
		index[v] = i
	}
	preIdx := 0
	var build func(lo, hi int) *TreeNode
	build = func(lo, hi int) *TreeNode {
		if lo > hi {
			return nil
		}
		val := preorder[preIdx]
		preIdx++
		node := &TreeNode{Val: val}
		mid := index[val]
		node.Left = build(lo, mid-1)
		node.Right = build(mid+1, hi)
		return node
	}
	return build(0, len(inorder)-1)
}
```

```java [Java]
class Solution {
    private int[] preorder;
    private int preIdx;
    private Map<Integer, Integer> inIndex = new HashMap<>();

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        this.preorder = preorder;
        this.preIdx = 0;
        for (int i = 0; i < inorder.length; i++) {
            inIndex.put(inorder[i], i);
        }
        return build(0, inorder.length - 1);
    }

    private TreeNode build(int lo, int hi) {
        if (lo > hi) return null;
        int val = preorder[preIdx++];
        TreeNode node = new TreeNode(val);
        int mid = inIndex.get(val);
        node.left = build(lo, mid - 1);
        node.right = build(mid + 1, hi);
        return node;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点恰好取根一次，哈希表定位为 O(1)。
- 空间复杂度：O(n)，哈希表存储 n 个下标，递归栈最坏 O(h)。
