# 二叉树的最近公共祖先

> 难度：中等 | 标签：树、深度优先搜索、二叉树、最近公共祖先 | [LeetCode 原题](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/)

## 题目描述

给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

[百度百科](https://baike.baidu.com/item/%E6%9C%80%E8%BF%91%E5%85%AC%E5%85%B1%E7%A5%96%E5%85%88/8918834?fr=aladdin)中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。”

**示例 1：**

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3 。
```

**示例 2：**

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和节点 4 的最近公共祖先是节点 5 。因为根据定义最近公共祖先节点可以为节点本身。
```

**示例 3：**

```
输入：root = [1,2], p = 1, q = 2
输出：1
```

**提示：**

- 树中节点数目在范围 `[2, 10^5]` 内。
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` `互不相同` 。
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中。

## 题解

### 思路

后序递归搜索：分别在当前节点的左右子树中寻找 p 和 q。若当前节点本身就等于 p 或 q，立即返回它——题目保证 p、q 都在树中，一旦在某个子树里命中，答案必在该子树内，不需要再向下搜索。若左右递归的结果都非空，说明 p、q 分布在当前节点两侧，当前节点就是最近公共祖先；否则返回那个非空的结果（把命中继续向上抛）。

这种「命中即上抛」的写法不需要父指针、深度表或倍增预处理，一次遍历即可。两个判断顺序是关键：节点相等判断必须放在递归的第一行，否则会继续向空子树递归并丢失命中；而「祖先可以是节点本身」正是示例 2 要考察的情况。

注意各语言的比较方式不同：JavaScript、Go、Java 直接比较节点对象引用，Rust 版因 `Rc` 不便比较引用，利用题目「所有 `Node.val` 互不相同」的条件改用节点值比较，同样正确；p、q 保证存在，因此 Rust 里的 `unwrap` 不会失败。

### 代码实现

::: code-group

```javascript [JavaScript]
var lowestCommonAncestor = function(root, p, q) {
  if (!root || root === p || root === q) return root;
  const left = lowestCommonAncestor(root.left, p, q);
  const right = lowestCommonAncestor(root.right, p, q);
  if (left && right) return root;
  return left || right;
};
```

```python [Python]
class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if not root or root is p or root is q:
            return root
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left and right:
            return root
        return left or right
```

```rust [Rust]
use std::rc::Rc;
use std::cell::RefCell;
impl Solution {
    pub fn lowest_common_ancestor(
        root: Option<Rc<RefCell<TreeNode>>>,
        p: Option<Rc<RefCell<TreeNode>>>,
        q: Option<Rc<RefCell<TreeNode>>>,
    ) -> Option<Rc<RefCell<TreeNode>>> {
        let node = root?;
        let val = node.borrow().val;
        let p_val = p.as_ref().unwrap().borrow().val;
        let q_val = q.as_ref().unwrap().borrow().val;
        if val == p_val || val == q_val {
            return Some(node);
        }
        let left = Solution::lowest_common_ancestor(node.borrow().left.clone(), p.clone(), q.clone());
        let right = Solution::lowest_common_ancestor(node.borrow().right.clone(), p, q);
        match (left.is_some(), right.is_some()) {
            (true, true) => Some(node),
            (true, false) => left,
            (false, true) => right,
            (false, false) => None,
        }
    }
}
```

```go [Go]
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
	if root == nil || root == p || root == q {
		return root
	}
	left := lowestCommonAncestor(root.Left, p, q)
	right := lowestCommonAncestor(root.Right, p, q)
	if left != nil && right != nil {
		return root
	}
	if left != nil {
		return left
	}
	return right
}
```

```java [Java]
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) return root;
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);
        if (left != null && right != null) return root;
        return left != null ? left : right;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点至多被访问一次。
- 空间复杂度：O(h)，递归栈深度为树高，树退化为链表时为 O(n)。
