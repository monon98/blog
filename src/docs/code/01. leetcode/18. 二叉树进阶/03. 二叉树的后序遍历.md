# 二叉树的后序遍历

> 难度：简单 | 标签：栈、树、深度优先搜索、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/binary-tree-postorder-traversal/description/)

## 题目描述

给你一棵二叉树的根节点 `root` ，返回其节点值的 **后序遍历**。

示例 1：

**输入：**root = [1,null,2,3]

**输出：**[3,2,1]

**解释：**

示例 2：

**输入：**root = [1,2,3,4,5,null,8,null,null,6,7,9]

**输出：**[4,6,7,5,2,9,8,3,1]

**解释：**

示例 3：

**输入：**root = []

**输出：**[]

示例 4：

**输入：**root = [1]

**输出：**[1]

**提示：**

- 树中节点的数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

**进阶：** 递归算法很简单，你可以通过迭代算法完成吗？

### 思路

后序是「左、右、根」，可以复用前序的栈模板：压栈时先左后右，弹出顺序即「根、右、左」，边弹边记录，最后把结果数组整体反转，恰好得到「左、右、根」的后序序列。这样只需一个栈加一次反转，无需在结构上记录「上一个访问的节点」。

另一种经典写法是维护 `prev` 指针，判断当前节点的右子树是否已经访问过，从而决定能否输出该节点；它省掉反转，但要区分「从左孩子回上来」和「从右孩子回上来」两种状态，分支更多。节点值可以重复，用「值是否访问过」来代替 `prev` 判断并不可靠，反转法天然避开这个坑。

注意反转是就地完成的，代价 O(n)，与结果数组同阶，不影响整体渐进复杂度。

```javascript [JavaScript]
var postorderTraversal = function(root) {
  const res = [];
  if (!root) return res;
  const stack = [root];
  while (stack.length) {
    const node = stack.pop();
    res.push(node.val);
    if (node.left) stack.push(node.left);
    if (node.right) stack.push(node.right);
  }
  res.reverse();
  return res;
};
```

```rust [Rust]
use std::rc::Rc;
use std::cell::RefCell;
impl Solution {
    pub fn postorder_traversal(root: Option<Rc<RefCell<TreeNode>>>) -> Vec<i32> {
        let mut res = Vec::new();
        if root.is_none() {
            return res;
        }
        let mut stack = vec![root.unwrap()];
        while let Some(node) = stack.pop() {
            res.push(node.borrow().val);
            let (left, right) = {
                let b = node.borrow();
                (b.left.clone(), b.right.clone())
            };
            if let Some(l) = left {
                stack.push(l);
            }
            if let Some(r) = right {
                stack.push(r);
            }
        }
        res.reverse();
        res
    }
}
```

```go [Go]
func postorderTraversal(root *TreeNode) []int {
	if root == nil {
		return []int{}
	}
	res := []int{}
	stack := []*TreeNode{root}
	for len(stack) > 0 {
		node := stack[len(stack)-1]
		stack = stack[:len(stack)-1]
		res = append(res, node.Val)
		if node.Left != nil {
			stack = append(stack, node.Left)
		}
		if node.Right != nil {
			stack = append(stack, node.Right)
		}
	}
	for i, j := 0, len(res)-1; i < j; i, j = i+1, j-1 {
		res[i], res[j] = res[j], res[i]
	}
	return res
}
```

```java [Java]
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            res.add(node.val);
            if (node.left != null) stack.push(node.left);
            if (node.right != null) stack.push(node.right);
        }
        Collections.reverse(res);
        return res;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点入栈、出栈各一次，外加一次 O(n) 的反转。
- 空间复杂度：O(h)，h 为树高（不含存储结果的数组），最坏退化为链表时为 O(n)。
