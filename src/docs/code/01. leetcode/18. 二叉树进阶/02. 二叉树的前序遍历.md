**解释：**

## 题解

:::: details 点击查看题解

### 思路

用栈实现「根 → 左 → 右」的前序遍历：弹出栈顶节点就立即记录它的值，然后按与实际遍历相反的顺序压入孩子——先压右子树、再压左子树，这样左子树总是先被弹出，最终访问顺序仍是根、左、右。

与中序模板不同，前序不需要先沿左链下探：栈本身就是「待访问子树」的容器，压栈时跳过空孩子即可，栈中不会出现空节点，循环条件只看栈是否为空。顺序颠倒是本题最容易出的错：如果压栈时先右后左，得到的会是「根、右、左」的镜像前序。

另一种等价写法是先访问根，再一路压左链到底、靠回弹转向右子树；两种都能通过，本页采用「弹根 → 压右 → 压左」，它与后序、层序的栈式写法结构更统一，便于对照记忆。

```javascript [JavaScript]
var preorderTraversal = function(root) {
  const res = [];
  if (!root) return res;
  const stack = [root];
  while (stack.length) {
    const node = stack.pop();
    res.push(node.val);
    if (node.right) stack.push(node.right);
    if (node.left) stack.push(node.left);
  }
  return res;
};
```

```python [Python]
class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        res, stack = [], [root]
        while stack:
            node = stack.pop()
            res.append(node.val)
            if node.right:
                stack.append(node.right)
            if node.left:
                stack.append(node.left)
        return res
```

```rust [Rust]
use std::rc::Rc;
use std::cell::RefCell;
impl Solution {
    pub fn preorder_traversal(root: Option<Rc<RefCell<TreeNode>>>) -> Vec<i32> {
        let mut res = Vec::new();
        if root.is_none() {
            return res;
        }
        let mut stack = vec![root.unwrap()];
        while let Some(node) = stack.pop() {
            res.push(node.borrow().val);
            let (left, right) = {
                let b = node.borrow();
                (b.left.clone(), b.right.clone())
            };
            if let Some(r) = right {
                stack.push(r);
            }
            if let Some(l) = left {
                stack.push(l);
            }
        }
        res
    }
}
```

```go [Go]
func preorderTraversal(root *TreeNode) []int {
	if root == nil {
		return []int{}
	}
	res := []int{}
	stack := []*TreeNode{root}
	for len(stack) > 0 {
		node := stack[len(stack)-1]
		stack = stack[:len(stack)-1]
		res = append(res, node.Val)
		if node.Right != nil {
			stack = append(stack, node.Right)
		}
		if node.Left != nil {
			stack = append(stack, node.Left)
		}
	}
	return res
}
```

```java [Java]
class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            res.add(node.val);
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }
        return res;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点恰好入栈、出栈各一次。
- 空间复杂度：O(h)，h 为树高，最坏退化为链表时为 O(n)。
