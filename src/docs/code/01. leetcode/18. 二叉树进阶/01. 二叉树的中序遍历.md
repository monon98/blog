# 二叉树的中序遍历

> 难度：简单 | 标签：栈、树、深度优先搜索、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/binary-tree-inorder-traversal/description/)

## 题目描述

给定一个二叉树的根节点 `root` ，返回 *它的 **中序** 遍历* 。

**示例 1：**

```
输入：root = [1,null,2,3]
输出：[1,3,2]
```

**示例 2：**

```
输入：root = []
输出：[]
```

**示例 3：**

```
输入：root = [1]
输出：[1]
```

**提示：**

- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

**进阶:** 递归算法很简单，你可以通过迭代算法完成吗？

## 题解

:::: details 点击查看题解

### 思路

用显式栈模拟递归的中序遍历，循环不变量是：栈里保存「已遇到但尚未访问」的节点，且它们的左子树都已经走完，因此栈顶一定是下一个该访问的最小节点。指针 `cur` 先一路向左深入，把沿途节点全部压栈；弹出栈顶并记录值后转向它的右子树，重复同一过程。

循环条件写成 `while (cur || stack.length)` 把「继续下探」与「弹栈回溯」统一在一个循环里：右子树走完后 `cur` 为空，自然会回到弹栈父节点的分支，不会漏掉回溯这一步。空树时两条件同时不满足，直接返回空数组。

题目的进阶要求用迭代完成，本页给出的即迭代版。递归写法更简短，但树退化成链表时依赖系统递归栈，树深很大时有溢出风险；迭代版行为完全由显式栈控制，更可预期。

### 代码实现

::: code-group

```javascript [JavaScript]
var inorderTraversal = function(root) {
  const res = [];
  const stack = [];
  let cur = root;
  while (cur || stack.length) {
    while (cur) {
      stack.push(cur);
      cur = cur.left;
    }
    cur = stack.pop();
    res.push(cur.val);
    cur = cur.right;
  }
  return res;
};
```

```python [Python]
class Solution:
    def inorderTraversal(self, root: TreeNode | None) -> list[int]:
        res, stack, cur = [], [], root
        while cur or stack:
            while cur:
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()
            res.append(cur.val)
            cur = cur.right
        return res
```

```rust [Rust]
use std::rc::Rc;
use std::cell::RefCell;
impl Solution {
    pub fn inorder_traversal(root: Option<Rc<RefCell<TreeNode>>>) -> Vec<i32> {
        let mut res = Vec::new();
        let mut stack: Vec<Rc<RefCell<TreeNode>>> = Vec::new();
        let mut cur = root;
        while cur.is_some() || !stack.is_empty() {
            while let Some(node) = cur.take() {
                stack.push(node.clone());
                cur = node.borrow().left.clone();
            }
            let node = stack.pop().unwrap();
            res.push(node.borrow().val);
            cur = node.borrow().right.clone();
        }
        res
    }
}
```

```go [Go]
func inorderTraversal(root *TreeNode) []int {
	res := []int{}
	stack := []*TreeNode{}
	cur := root
	for cur != nil || len(stack) > 0 {
		for cur != nil {
			stack = append(stack, cur)
			cur = cur.Left
		}
		cur = stack[len(stack)-1]
		stack = stack[:len(stack)-1]
		res = append(res, cur.Val)
		cur = cur.Right
	}
	return res
}
```

```java [Java]
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {
                stack.push(cur);
                cur = cur.left;
            }
            cur = stack.pop();
            res.add(cur.val);
            cur = cur.right;
        }
        return res;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点恰好入栈、出栈各一次。
- 空间复杂度：O(h)，h 为树高，最坏退化为链表时为 O(n)。
