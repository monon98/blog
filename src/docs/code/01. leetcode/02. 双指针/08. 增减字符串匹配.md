# 增减字符串匹配

> 难度：简单 | 标签：贪心、数组、双指针、数学 | [LeetCode 原题](https://leetcode.cn/problems/di-string-match/description/)

## 题目描述

由范围 `[0,n]` 内所有整数组成的 `n + 1` 个整数的排列序列可以表示为长度为 `n` 的字符串 `s`，其中：如果 `perm[i] < perm[i + 1]`，那么 `s[i] == 'I'`（递增）；如果 `perm[i] > perm[i + 1]`，那么 `s[i] == 'D'`（递减）。给定一个字符串 `s`，重构出它的任意一个有效排列并返回。

**示例 1：**

```
输入：s = "IDID"
输出：[0,4,1,3,2]
```

**示例 2：**

```
输入：s = "III"
输出：[0,1,2,3]
```

**示例 3：**

```
输入：s = "DDI"
输出：[3,2,0,1]
```

**提示：**

- `1 <= s.length <= 10^5`
- `s` 只包含字符 `"I"` 或 `"D"`

## 题解

:::: details 点击查看题解

### 思路

贪心构造：维护可用数字区间的两端 `low = 0`、`high = n`。遇到 `'I'` 就放当前最小的数（保证下一个比它大），遇到 `'D'` 就放当前最大的数（保证下一个比它小）。每放一个数区间收缩一格，最后剩下的一个数直接放到末尾。

### 代码实现

::: code-group

```javascript [JavaScript]
var diStringMatch = function(s) {
  let low = 0;
  let high = s.length;
  const res = [];
  for (const ch of s) {
    if (ch === "I") {
      res.push(low++);
    } else {
      res.push(high--);
    }
  }
  res.push(low);
  return res;
};
```

```python [Python]
class Solution:
    def diStringMatch(self, s: str) -> List[int]:
        low, high = 0, len(s)
        res = []
        for ch in s:
            if ch == "I":
                res.append(low)
                low += 1
            else:
                res.append(high)
                high -= 1
        res.append(low)
        return res
```

```rust [Rust]
        let (mut low, mut high) = (0i32, s.len() as i32);

        }
        res.push(low);
        res
    }
}
```

```go [Go]
func diStringMatch(s string) []int {
	low, high := 0, len(s)
	res := make([]int, 0, len(s)+1)
	for i := 0; i < len(s); i++ {
		if s[i] == 'I' {
			res = append(res, low)
			low++
		} else {
			res = append(res, high)
			high--
		}
	}
	res = append(res, low)
	return res
}
```

```java [Java]
class Solution {
    public int[] diStringMatch(String s) {
        int low = 0, high = s.length();
        int[] res = new int[s.length() + 1];
        int idx = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == 'I') {
                res[idx++] = low++;
            } else {
                res[idx++] = high--;
            }
        }
        res[idx] = low;
        return res;
    }
}
```
