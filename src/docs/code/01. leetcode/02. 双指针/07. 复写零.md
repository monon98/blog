# 复写零

> 难度：简单 | 标签：数组、双指针 | [LeetCode 原题](https://leetcode.cn/problems/duplicate-zeros/description/)

## 题目描述

给你一个长度固定的整数数组 `arr`，请你将该数组中出现的每个零都复写一遍，并将其余的元素向右平移。注意：请不要在超过原数组长度的位置写入元素，请对输入的数组就地（原地）进行上述修改，不要从函数返回任何东西。

**示例 1：**

```
输入：arr = [1,0,2,3,0,4,5,0]
输出：null
解释：调用函数后，输入的数组将被修改为 [1,0,0,2,3,0,0,4]。
```

**示例 2：**

```
输入：arr = [1,2,3]
输出：null
解释：调用函数后，输入的数组将被修改为 [1,2,3]。
```

**提示：**

- `1 <= arr.length <= 10^4`
- `0 <= arr[i] <= 9`

## 题解

:::: details 点击查看题解

### 思路

借助辅助数组模拟复写过程最直观：按顺序把元素推入新数组，遇到 0 额外多推一个 0；一旦长度达到原数组长度立即停止（防止越界元素），最后拷回原数组。

双指针 O(1) 空间解法需要先找到最后一个会被保留的元素，再从右往左回填，实现更绕但空间最优。

```javascript [JavaScript]
var duplicateZeros = function(arr) {
  const n = arr.length;
  const res = [];
  for (let i = 0; i < n && res.length < n; i++) {
    res.push(arr[i]);
    if (res.length < n && arr[i] === 0) {
      res.push(0);
    }
  }
  for (let i = 0; i < n; i++) {
    arr[i] = res[i];
  }
};
```

```python [Python]
class Solution:

        n = len(arr)
        res = []
        i = 0
        while i < n and len(res) < n:
            res.append(arr[i])
            if len(res) < n and arr[i] == 0:
                res.append(0)
            i += 1
        for i in range(n):
            arr[i] = res[i]
```

```rust [Rust]
impl Solution {
    pub fn duplicate_zeros(arr: &mut Vec<i32>) {
        let n = arr.len();
        let mut res: Vec<i32> = Vec::with_capacity(n);
        let mut i = 0;
        while i < n && res.len() < n {
            res.push(arr[i]);
            if res.len() < n && arr[i] == 0 {
                res.push(0);
            }
            i += 1;
        }
        arr.copy_from_slice(&res);
    }
}
```

```java [Java]
class Solution {
    public void duplicateZeros(int[] arr) {
        int n = arr.length;
        int[] res = new int[n];
        int len = 0;
        int i = 0;
        while (i < n && len < n) {
            res[len++] = arr[i];
            if (len < n && arr[i] == 0) {
                res[len++] = 0;
            }
            i++;
        }
        for (i = 0; i < n; i++) {
            arr[i] = res[i];
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(n)；双指针法可优化到 O(1)。
