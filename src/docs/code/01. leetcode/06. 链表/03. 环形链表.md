# 环形链表

> 难度：简单 | 标签：哈希表、链表、双指针 | [LeetCode 原题](https://leetcode.cn/problems/linked-list-cycle/description/)

## 题目描述

给你一个链表的头节点 `head`，判断链表中是否有环。如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始），仅是为了标识链表的实际情况，不会作为参数传递。

**示例 1：**

```
输入：head = [3,2,0,-4], pos = 1
输出：true
解释：链表中有一个环，其尾部连接到第二个节点。
```

**示例 2：**

```
输入：head = [1,2], pos = 0
输出：true
```

**示例 3：**

```
输入：head = [1], pos = -1
输出：false
```

**提示：**

- 链表中节点的数目范围是 `[0, 10^4]`
- `-10^5 <= Node.val <= 10^5`
- `pos` 为 `-1` 或者链表中的一个有效索引

**进阶：** 你能用 O(1)（即常量）内存解决此问题吗？

### 思路

Floyd 快慢指针（龟兔赛跑）：慢指针每次走一步，快指针每次走两步。若无环，快指针先到 null；若有环，快指针会先进入环内「套圈」，最终与慢指针相遇。

哈希集合记录访问过的节点也能判断（遇到重复即有环），但需要 O(n) 空间；快慢指针满足 O(1) 空间的进阶要求，且该技巧还能延伸出「找环的入口」等进阶题。

```javascript [JavaScript]
var hasCycle = function(head) {
  let slow = head;
  let fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }
  return false;
};
```

```rust [Rust]
impl Solution {
    pub fn has_cycle(head: Option<Box<ListNode>>) -> bool {
        let mut slow = head.as_deref();
        let mut fast = head.as_deref();
        while let (Some(s), Some(f)) = (slow, fast) {
            let f_next = match f.next { Some(ref n) => n, None => return false };
            let f_next_next = match f_next.next { Some(ref n) => n, None => return false };
            slow = match s.next { Some(ref n) => Some(&**n), None => return false };
            fast = Some(&**f_next_next);
            if std::ptr::eq(slow.unwrap(), fast.unwrap()) {
                return true;
            }
        }
        false
    }
}
```

```go [Go]
func hasCycle(head *ListNode) bool {

		if slow == fast {

		}
	}
```

```java [Java]
class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) return true;
        }
        return false;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)，只用了两个指针。
