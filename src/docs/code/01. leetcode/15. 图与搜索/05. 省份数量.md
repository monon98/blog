# 省份数量

> 难度：中等 | 标签：深度优先搜索、广度优先搜索、并查集、图 | [LeetCode 原题](https://leetcode.cn/problems/number-of-provinces/description/)

## 题目描述

有 `n` 个城市，其中一些彼此相连，另一些没有相连。如果城市 `a` 与城市 `b` 直接相连，且城市 `b` 与城市 `c` 直接相连，那么城市 `a` 与城市 `c` 间接相连。

**省份** 是一组直接或间接相连的城市，组内不含其他没有相连的城市。

给你一个 `n x n` 的矩阵 `isConnected` ，其中 `isConnected[i][j] = 1` 表示第 `i` 个城市和第 `j` 个城市直接相连，而 `isConnected[i][j] = 0` 表示二者不直接相连。

返回矩阵中 **省份** 的数量。

**示例 1：**

```
输入：isConnected = [[1,1,0],[1,1,0],[0,0,1]]
输出：2
```

**示例 2：**

```
输入：isConnected = [[1,0,0],[0,1,0],[0,0,1]]
输出：3
```

**提示：**

- `1 <= n <= 200`
- `n == isConnected.length`
- `n == isConnected[i].length`
- `isConnected[i][j]` 为 `1` 或 `0`
- `isConnected[i][i] == 1`
- `isConnected[i][j] == isConnected[j][i]`

## 题解

:::: details 点击查看题解

### 思路

用并查集维护城市的连通关系：先把 n 个城市各自设为独立集合（`parent[i] = i`），省份初始计数就是 n。

只遍历矩阵上三角（`j > i`），遇到 `isConnected[i][j] == 1` 就把两个城市合并；只有当二者根不同（这次合并真正连通了两个原本分开的集合）时，计数才减 1。`find` 顺带做隔代路径压缩，均摊复杂度近似常数。坑：只扫上三角，避免对称位置与对角线的重复处理，对角线的 1 不代表任何合并；也可换成「对每个未访问城市做一次 DFS/BFS，统计连通块个数」，两者同阶。n ≤ 200，n² 的矩阵本身就是时间下限。

```javascript [JavaScript]
var findCircleNum = function(isConnected) {
  const n = isConnected.length;
  const parent = Array.from({ length: n }, (_, i) => i);

  const find = (x) => {
    while (parent[x] !== x) {
      parent[x] = parent[parent[x]];
      x = parent[x];
    }
    return x;
  };

  let provinces = n;
  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      if (isConnected[i][j] === 1) {
        const rootI = find(i);
        const rootJ = find(j);
        if (rootI !== rootJ) {
          parent[rootI] = rootJ;
          provinces--;
        }
      }
    }
  }
  return provinces;
};
```

        int n = isConnected.length;
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;

        int provinces = n;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (isConnected[i][j] == 1) {
                    int rootI = find(i);
                    int rootJ = find(j);
                    if (rootI != rootJ) {
                        parent[rootI] = rootJ;
                        provinces--;
                    }
                }
            }
        }
        return provinces;
    }

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
}

### 复杂度分析

- 时间复杂度：O(n²·α(n))，遍历 n² 个矩阵元素并执行并查集操作，α(n) 为反阿克曼函数、近似常数。
- 空间复杂度：O(n)，仅维护 parent 数组。
