# 岛屿的周长

> 难度：简单 | 标签：深度优先搜索、广度优先搜索、数组、矩阵 | [LeetCode 原题](https://leetcode.cn/problems/island-perimeter/description/)

## 题目描述

给定一个 `row x col` 的二维网格地图 `grid` ，其中：`grid[i][j] = 1` 表示陆地， `grid[i][j] = 0` 表示水域。

网格中的格子 **水平和垂直** 方向相连（对角线方向不相连）。整个网格被水完全包围，但其中恰好有一个岛屿（或者说，一个或多个表示陆地的格子相连组成的岛屿）。

岛屿中没有“湖”（“湖” 指水域在岛屿内部且不和岛屿周围的水相连）。格子是边长为 1 的正方形。网格为长方形，且宽度和高度均不超过 100 。计算这个岛屿的周长。

**示例 1：**

```
输入：grid = [[0,1,0,0],[1,1,1,0],[0,1,0,0],[1,1,0,0]]
输出：16
解释：它的周长是上面图片中的 16 个黄色的边
```

**示例 2：**

```
输入：grid = [[1]]
输出：4
```

**示例 3：**

```
输入：grid = [[1,0]]
输出：4
```

**提示：**

- `row == grid.length`
- `col == grid[i].length`
- `1 <= row, col <= 100`
- `grid[i][j]` 为 `0` 或 `1`

## 题解

:::: details 点击查看题解

### 思路

不靠搜索也能算周长：把每个陆地格子看成一个贡献 4 条边的方块，与它相邻的陆地会吃掉彼此共享的边。两重循环扫一遍网格，遇到 `grid[i][j] === 1` 就给周长加 4，然后只检查右、下两个邻居——若邻居也是陆地，说明这一对格子共享 2 条边，直接减 2。

只看右、下两个方向的好处是每对相邻格子恰好处理一次，天然不会重复扣减。坑：若四个方向都判，每条共享边会被相邻两格各算一次，必须额外约定去重方向，很容易写错。题目保证恰好一个岛屿且内部无湖，所以不必真的做 DFS/BFS；若要写可处理多岛与湖的通用版，从任意陆地出发、遇水边加 1、遇已访问陆地边减 1 也完全等价。

```javascript [JavaScript]
var islandPerimeter = function(grid) {
  const rows = grid.length;
  const cols = grid[0].length;
  let perimeter = 0;
  for (let i = 0; i < rows; i++) {
    for (let j = 0; j < cols; j++) {
      if (grid[i][j] === 1) {
        perimeter += 4;
        if (j + 1 < cols && grid[i][j + 1] === 1) perimeter -= 2;
        if (i + 1 < rows && grid[i + 1][j] === 1) perimeter -= 2;
      }
    }
  }
  return perimeter;
};
```

### 复杂度分析

- 时间复杂度：O(mn)，m、n 为网格的行、列数，每个格子只访问一次。
- 空间复杂度：O(1)，仅使用常数额外变量。
