# 二叉树的所有路径

> 难度：简单 | 标签：树、深度优先搜索、字符串、回溯、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/binary-tree-paths/description/)

## 题目描述

给你一个二叉树的根节点 `root`，按任意顺序返回所有从根节点到叶子节点的路径。叶子节点是指没有子节点的节点。

**示例 1：**

```
输入：root = [1,2,3,null,5]
输出：["1->2->5","1->3"]
```

**示例 2：**

```
输入：root = [1]
输出：["1"]
```

**提示：**

- 树中节点的数目在范围 `[1, 100]` 内
- `-100 <= Node.val <= 100`

## 题解

:::: details 点击查看题解

### 思路

DFS + 回溯：维护当前路径数组，进入节点时 push 值；到达叶子时把路径用 `->` 拼接存入结果；离开时 pop 回退（回溯），保证兄弟分支拿到的是干净路径。

也可以让递归函数直接携带拼接好的字符串（`path + "->" + val`），省去显式回溯，代价是产生更多临时字符串。

```javascript [JavaScript]
var binaryTreePaths = function(root) {
  const res = [];
  const dfs = (node, path) => {
    if (!node) return;
    path.push(node.val);
    if (!node.left && !node.right) {
      res.push(path.join("->"));
    } else {
      dfs(node.left, path);
      dfs(node.right, path);
    }
    path.pop();
  };
  dfs(root, []);
  return res;
};
```

```python [Python]
class Solution:
    def binaryTreePaths(self, root: TreeNode | None) -> list[str]:
        res = []

        def dfs(node, path):
            if not node:
                return
            path.append(str(node.val))
            if not node.left and not node.right:
                res.append("->".join(path))
            else:
                dfs(node.left, path)
                dfs(node.right, path)
            path.pop()

        dfs(root, [])
        return res
```

```rust [Rust]
use std::cell::RefCell;
use std::rc::Rc;

impl Solution {
    pub fn binary_tree_paths(root: Option<Rc<RefCell<TreeNode>>>) -> Vec<String> {
        fn dfs(
            node: &Option<Rc<RefCell<TreeNode>>>,
            path: &mut Vec<i32>,
            res: &mut Vec<String>,
        ) {
            let n = match node {
                None => return,
                Some(n) => n,
            };
            let n = n.borrow();
            path.push(n.val);
            if n.left.is_none() && n.right.is_none() {
                res.push(
                    path.iter()
                        .map(|v| v.to_string())
                        .collect::<Vec<_>>()
                        .join("->"),
                );
            } else {
                dfs(&n.left, path, res);
                dfs(&n.right, path, res);
            }
            path.pop();
        }

        let mut res = Vec::new();
        dfs(&root, &mut Vec::new(), &mut res);
        res
    }
}
```

```go [Go]
import (
	"strconv"
	"strings"
)

func binaryTreePaths(root *TreeNode) []string {
	var res []string
	var dfs func(node *TreeNode, path []string)
	dfs = func(node *TreeNode, path []string) {
		if node == nil {
			return
		}
		path = append(path, strconv.Itoa(node.Val))
		if node.Left == nil && node.Right == nil {
			res = append(res, strings.Join(path, "->"))
			return
		}
		dfs(node.Left, path)
		dfs(node.Right, path)
	}
	dfs(root, nil)
	return res
}
```

```java [Java]
class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> res = new ArrayList<>();
        dfs(root, new ArrayList<>(), res);
        return res;
    }

    private void dfs(TreeNode node, List<String> path, List<String> res) {
        if (node == null) return;
        path.add(String.valueOf(node.val));
        if (node.left == null && node.right == null) {
            res.add(String.join("->", path));
        } else {
            dfs(node.left, path, res);
            dfs(node.right, path, res);
        }
        path.remove(path.size() - 1);
    }
}
```

### 复杂度分析

- 时间复杂度：O(n · h)，n 为节点数、h 为树高（每条路径的拼接开销）。
- 空间复杂度：O(h) 递归与路径数组（不计结果）。
