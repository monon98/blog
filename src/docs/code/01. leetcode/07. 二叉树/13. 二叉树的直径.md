# 二叉树的直径

> 难度：简单 | 标签：树、深度优先搜索、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/diameter-of-binary-tree/description/)

## 题目描述

给你一棵二叉树的根节点，返回该树的直径。二叉树的直径是指树中任意两个节点之间最长路径的边数。这条路径可能穿过也可能不穿过根节点。

**示例 1：**

```
输入：root = [1,2,3,4,5]
输出：3
解释：最长路径 [4,2,1,3] 或 [5,2,1,3]，长度为 3。
```

**示例 2：**

```
输入：root = [1,2]
输出：1
```

**提示：**

- 树中节点数目在范围 `[1, 10^4]` 内
- `-100 <= Node.val <= 100`

## 题解

:::: details 点击查看题解

### 思路

「经过某节点的最长路径」= 左子树深度 + 右子树深度。在递归计算深度的过程中顺手维护全局最大值 `max`：每个节点作为「拐点」时用 `left + right` 尝试更新。注意返回值是深度（供父节点使用），而答案是边数（不 +1），两者含义不同。

这是「在遍历中维护全局变量」模式的经典示例，与最大路径和等题同构。

### 代码实现

::: code-group

```javascript [JavaScript]
var diameterOfBinaryTree = function(root) {
  let max = 0;
  const depth = (node) => {
    if (!node) return 0;
    const l = depth(node.left);
    const r = depth(node.right);
    if (l + r > max) max = l + r;
    return 1 + Math.max(l, r);
  };
  depth(root);
  return max;
};
```

```python [Python]
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        max_d = 0

        def depth(node):
            nonlocal max_d
            if not node:
                return 0
            l = depth(node.left)
            r = depth(node.right)
            max_d = max(max_d, l + r)
            return 1 + max(l, r)

        depth(root)
        return max_d
```

```rust [Rust]
use std::cell::RefCell;
use std::rc::Rc;

impl Solution {
    pub fn diameter_of_binary_tree(root: Option<Rc<RefCell<TreeNode>>>) -> i32 {
        fn depth(node: &Option<Rc<RefCell<TreeNode>>>, max: &mut i32) -> i32 {
            let n = match node {
                None => return 0,
                Some(n) => n,
            };
            let n = n.borrow();
            let l = depth(&n.left, max);
            let r = depth(&n.right, max);
            if l + r > *max {
                *max = l + r;
            }
            1 + l.max(r)
        }

        let mut max = 0;
        depth(&root, &mut max);
        max
    }
}
```

```go [Go]
func diameterOfBinaryTree(root *TreeNode) int {
	max := 0
	var depth func(node *TreeNode) int
	depth = func(node *TreeNode) int {
		if node == nil {
			return 0
		}
		l, r := depth(node.Left), depth(node.Right)
		if l+r > max {
			max = l + r
		}
		if l > r {
			return 1 + l
		}
		return 1 + r
	}
	depth(root)
	return max
}
```

```java [Java]
class Solution {
    private int max = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        depth(root);
        return max;
    }

    private int depth(TreeNode node) {
        if (node == null) return 0;
        int l = depth(node.left);
        int r = depth(node.right);
        if (l + r > max) max = l + r;
        return 1 + Math.max(l, r);
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归栈深度为树高。
