# 二叉树的最小深度

> 难度：简单 | 标签：树、深度优先搜索、广度优先搜索、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/minimum-depth-of-binary-tree/description/)

## 题目描述

给定一个二叉树，找出其最小深度。最小深度是从根节点到最近叶子节点的最短路径上的节点数量。注意：叶子节点是指没有子节点的节点。

**示例 1：**

```
输入：root = [3,9,20,null,null,15,7]
输出：2
```

**示例 2：**

```
输入：root = [2,null,3,null,4,null,5,null,6]
输出：5
```

**提示：**

- 树中节点数的范围在 `[0, 10^5]` 内
- `-1000 <= Node.val <= 1000`

## 题解

:::: details 点击查看题解

### 思路

与最大深度不同，本题有陷阱：如果某棵子树为空，不能直接取 min（空子树深度 0 会误导结果），必须沿另一侧继续走到叶子。规则是：

- 空树返回 0；
- 只有左孩子或只有右孩子时，返回 `1 + 单侧递归结果`；
- 两侧都存在时才取 `1 + min(左, 右)`。

BFS 层序遍历找到的第一个叶子层就是答案，也可以避免遍历整棵树。

### 代码实现

::: code-group

```javascript [JavaScript]
var minDepth = function(root) {
  if (!root) return 0;
  if (!root.left) return 1 + minDepth(root.right);
  if (!root.right) return 1 + minDepth(root.left);
  return 1 + Math.min(minDepth(root.left), minDepth(root.right));
};
```

```python [Python]
class Solution:
    def minDepth(self, root: TreeNode | None) -> int:
        if not root:
            return 0
        if not root.left:
            return 1 + self.minDepth(root.right)
        if not root.right:
            return 1 + self.minDepth(root.left)
        return 1 + min(self.minDepth(root.left), self.minDepth(root.right))
```

```rust [Rust]
use std::cell::RefCell;
use std::rc::Rc;

impl Solution {
    pub fn min_depth(root: Option<Rc<RefCell<TreeNode>>>) -> i32 {
        let node = match root {
            None => return 0,
            Some(n) => n,
        };
        let node = node.borrow();
        match (&node.left, &node.right) {
            (None, right) => 1 + Self::min_depth(right.clone()),
            (left, None) => 1 + Self::min_depth(left.clone()),
            (left, right) => {
                1 + Self::min_depth(left.clone()).min(Self::min_depth(right.clone()))
            }
        }
    }
}
```

```go [Go]
func minDepth(root *TreeNode) int {
	if root == nil {
		return 0
	}
	if root.Left == nil {
		return 1 + minDepth(root.Right)
	}
	if root.Right == nil {
		return 1 + minDepth(root.Left)
	}
	l, r := minDepth(root.Left), minDepth(root.Right)
	if l < r {
		return 1 + l
	}
	return 1 + r
}
```

```java [Java]
class Solution {
    public int minDepth(TreeNode root) {
        if (root == null) return 0;
        if (root.left == null) return 1 + minDepth(root.right);
        if (root.right == null) return 1 + minDepth(root.left);
        return 1 + Math.min(minDepth(root.left), minDepth(root.right));
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，最坏访问全部节点。
- 空间复杂度：O(h)，最坏 O(n)。
