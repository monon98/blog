# 合并二叉树

> 难度：简单 | 标签：树、深度优先搜索、广度优先搜索、二叉树 | [LeetCode 原题](https://leetcode.cn/problems/merge-two-binary-trees/description/)

## 题目描述

给你两棵二叉树：`root1` 和 `root2`。想象一下，当你将其中一棵覆盖到另一棵之上时，两棵树上的一些节点将会重叠（而另一些不会）。你需要将这两棵树合并成一棵新二叉树。合并的规则是：如果两个节点重叠，那么将这两个节点的值相加作为合并后节点的新值；否则，不为 null 的节点将直接作为新二叉树的节点。返回合并后的二叉树。注意：合并过程必须从两个树的根节点开始。

**示例 1：**

```
输入：root1 = [1,3,2,5], root2 = [2,1,3,null,4,null,7]
输出：[3,4,5,5,4,null,7]
```

**示例 2：**

```
输入：root1 = [1], root2 = [1,2]
输出：[2,2]
```

**提示：**

- 两棵树中的节点数目在范围 `[0, 2000]` 内
- `-10^4 <= Node.val <= 10^4`

## 题解

### 思路

递归同步遍历两棵树：一侧为空时直接返回另一侧子树（整棵复用）；都非空时值相加，再递归合并左右孩子。为节省空间通常在 `root1` 上原地合并。

### 代码实现

::: code-group

```javascript [JavaScript]
var mergeTrees = function(root1, root2) {
  if (!root1) return root2;
  if (!root2) return root1;
  root1.val += root2.val;
  root1.left = mergeTrees(root1.left, root2.left);
  root1.right = mergeTrees(root1.right, root2.right);
  return root1;
};
```

class Solution:
    def mergeTrees(
        self, root1: TreeNode | None, root2: TreeNode | None

        if not root1:
            return root2
        if not root2:
            return root1
        root1.val += root2.val
        root1.left = self.mergeTrees(root1.left, root2.left)
        root1.right = self.mergeTrees(root1.right, root2.right)
        return root1

```rust [Rust]
use std::cell::RefCell;
use std::rc::Rc;

impl Solution {
    pub fn merge_trees(
        root1: Option<Rc<RefCell<TreeNode>>>,
        root2: Option<Rc<RefCell<TreeNode>>>,
    ) -> Option<Rc<RefCell<TreeNode>>> {
        match (root1, root2) {
            (None, None) => None,
            (Some(a), None) => Some(a),
            (None, Some(b)) => Some(b),
            (Some(a), Some(b)) => {
                let (a_left, a_right) = {
                    let a_ref = a.borrow();
                    (a_ref.left.clone(), a_ref.right.clone())
                };
                let (b_val, b_left, b_right) = {
                    let b_ref = b.borrow();
                    (b_ref.val, b_ref.left.clone(), b_ref.right.clone())
                };
                let left = Self::merge_trees(a_left, b_left);
                let right = Self::merge_trees(a_right, b_right);
                let mut a_mut = a.borrow_mut();
                a_mut.val += b_val;
                a_mut.left = left;
                a_mut.right = right;
                drop(a_mut);
                Some(a)
            }
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(min(m, n))，重叠部分才需要处理。
- 空间复杂度：O(min(m, n))，递归栈深度取决于较小的树。
