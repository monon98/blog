# 移动零

> 难度：简单 | 标签：数组、双指针 | [LeetCode 原题](https://leetcode.cn/problems/move-zeroes/description/)

## 题目描述

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。请注意必须在不复制数组的情况下原地对数组进行操作。

**示例 1：**

```
输入：nums = [0,1,0,3,12]
输出：[1,3,12,0,0]
```

**示例 2：**

```
输入：nums = [0]
输出：[0]
```

**提示：**

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

**进阶：** 你能尽量减少完成的操作次数吗？

## 题解

::: details 点击查看题解

### 思路

快慢双指针「覆盖 + 补零」：`slow` 指向下一个非零元素应写入的位置，快指针 `i` 扫描数组，遇到非零元素就覆盖到 `nums[slow++]`。扫描结束后，把 `slow` 到末尾的位置全部补 0。

不变量：`[0, slow)` 始终是按原顺序排列的非零元素。每个非零元素只写一次、每个 0 也只写一次，总写操作恰好 n 次——正好满足「尽量减少操作次数」的进阶要求。

交换版（每次非零都与 `nums[slow]` 交换）同样正确，但当数组中没有 0 时会产生大量自交换，写次数最多接近 2n，不是操作次数最优解，仅作为对照写法。

### 代码实现

```javascript
var moveZeroes = function(nums) {
  let slow = 0;
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] !== 0) {
      nums[slow++] = nums[i];
    }
  }
  while (slow < nums.length) {
    nums[slow++] = 0;
  }
};
```

对照：交换版写法

```javascript
var moveZeroes = function(nums) {
  let slow = 0;
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] !== 0) {
      [nums[slow], nums[i]] = [nums[i], nums[slow]];
      slow++;
    }
  }
};
```

### 复杂度分析

- 时间复杂度：O(n)，快指针遍历一次，补零循环累计也不超过 n 次。
- 空间复杂度：O(1)，原地修改。
