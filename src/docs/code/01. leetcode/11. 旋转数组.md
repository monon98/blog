# 旋转数组

> 难度：简单 | 标签：数组、双指针、数学 | [LeetCode 原题](https://leetcode.cn/problems/rotate-array/description/)

## 题目描述

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。要求使用 O(1) 原地算法完成（空间复杂度为 O(1)）。

**示例 1：**

```
输入：nums = [1,2,3,4,5,6,7], k = 3
输出：[5,6,7,1,2,3,4]
解释：向右轮转 1 步: [7,1,2,3,4,5,6]；2 步: [6,7,1,2,3,4,5]；3 步: [5,6,7,1,2,3,4]。
```

**示例 2：**

```
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

## 题解

::: details 点击查看题解

### 思路

三次翻转法：先把整个数组翻转，再翻转前 k 个元素，最后翻转剩余的 n - k 个元素。例如 `[1,2,3,4,5,6,7]` → 全翻 `[7,6,5,4,3,2,1]` → 翻前 3 位 `[5,6,7,4,3,2,1]` → 翻后面 `[5,6,7,1,2,3,4]`。

注意先做 `k %= n`，因为当 k 大于数组长度时结果会循环。相比每次右移一步共 k 次的写法（O(n·k) 会超时），三次翻转只需 O(n) 时间且完全原地。

### 代码实现

```javascript
var rotate = function(nums, k) {
  const n = nums.length;
  k %= n;

  const reverse = (l, r) => {
    while (l < r) {
      const t = nums[l];
      nums[l] = nums[r];
      nums[r] = t;
      l++;
      r--;
    }
  };

  reverse(0, n - 1);
  reverse(0, k - 1);
  reverse(k, n - 1);
};
```

### 复杂度分析

- 时间复杂度：O(n)，每个元素被翻转两次以内。
- 空间复杂度：O(1)，原地翻转。
