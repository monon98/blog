# 合并两个有序数组

> 难度：简单 | 标签：数组、双指针、排序 | [LeetCode 原题](https://leetcode.cn/problems/merge-sorted-array/description/)

## 题目描述

以非递减顺序排列的两个整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示它们的元素数目。请你合并 `nums2` 到 `nums1` 中，使合并后的数组同样按非递减顺序排列。

注意：最终合并后数组不应由函数返回，而是存储在数组 `nums1` 中。为应对这种情况，`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示应合并的元素，后 `n` 个元素为 0 应被忽略。

**示例 1：**

```
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
```

**示例 2：**

```
输入：nums1 = [1], m = 1, nums2 = [], n = 0
输出：[1]
```

**提示：**

- `nums1.length == m + n`
- `nums2.length == n`
- `-10^9 <= nums1[i], nums2[j] <= 10^9`

## 题解

::: details 点击查看题解

### 思路

从后往前三指针合并，避免覆盖 `nums1` 中尚未处理的元素：`i` 指向 `nums1` 有效部分末尾，`j` 指向 `nums2` 末尾，`k` 指向 `nums1` 物理末尾。每次取两者中较大的放到 `k` 处。由于 `nums1` 后半部分是空的，向前填充永远不会覆盖有效数据。当 `j < 0` 时 `nums2` 已全部就位，剩余 `nums1` 元素本来就在正确位置。

### 代码实现

```javascript
var merge = function(nums1, m, nums2, n) {
  let i = m - 1;
  let j = n - 1;
  let k = m + n - 1;
  while (j >= 0) {
    if (i >= 0 && nums1[i] > nums2[j]) {
      nums1[k] = nums1[i];
      i--;
    } else {
      nums1[k] = nums2[j];
      j--;
    }
    k--;
  }
};
```

### 复杂度分析

- 时间复杂度：O(m + n)，每个元素最多处理一次。
- 空间复杂度：O(1)，原地合并。
