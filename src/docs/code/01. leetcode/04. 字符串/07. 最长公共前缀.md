# 最长公共前缀

> 难度：简单 | 标签：字符串、字典树 | [LeetCode 原题](https://leetcode.cn/problems/longest-common-prefix/description/)

## 题目描述

编写一个函数来查找字符串数组中的最长公共前缀。如果不存在公共前缀，返回空字符串 `""`。

**示例 1：**

```
输入：strs = ["flower","flow","flight"]
输出："fl"
```

**示例 2：**

```
输入：strs = ["dog","racecar","car"]
输出：""
解释：输入不存在公共前缀。
```

**提示：**

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 仅由小写英文字母组成

## 题解

:::: details 点击查看题解

### 思路

以第一个字符串为初始前缀，逐个与后续字符串比较：只要当前字符串不是以该前缀开头，就不断把前缀缩短一位，直到匹配或前缀为空。所有字符串处理完后剩下的就是最长公共前缀。

也可以纵向扫描：按列逐字符比较所有字符串同一位置的字符，遇到不同立即返回。

### 代码实现

::: code-group

```javascript [JavaScript]
var longestCommonPrefix = function(strs) {
  let prefix = strs[0];
  for (let i = 1; i < strs.length; i++) {
    while (!strs[i].startsWith(prefix)) {
      prefix = prefix.slice(0, -1);
      if (!prefix) return "";
    }
  }
  return prefix;
};
```

```python [Python]
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        prefix = strs[0]
        for s in strs[1:]:
            while not s.startswith(prefix):
                prefix = prefix[:-1]
                if not prefix:
                    return ""
        return prefix
```

```rust [Rust]
impl Solution {
    pub fn longest_common_prefix(strs: Vec<String>) -> String {
        let mut prefix = strs[0].clone();
        for s in &strs[1..] {
            while !s.starts_with(&prefix) {
                prefix.pop();
                if prefix.is_empty() {
                    return String::new();
                }
            }
        }
        prefix
    }
}
```

```go [Go]
import "strings"

func longestCommonPrefix(strs []string) string {
	prefix := strs[0]
	for _, s := range strs[1:] {
		for !strings.HasPrefix(s, prefix) {
			prefix = prefix[:len(prefix)-1]
			if prefix == "" {
				return ""
			}
		}
	}
	return prefix
}
```

```java [Java]
class Solution {
    public String longestCommonPrefix(String[] strs) {
        String prefix = strs[0];
        for (int i = 1; i < strs.length; i++) {
            while (!strs[i].startsWith(prefix)) {
                prefix = prefix.substring(0, prefix.length() - 1);
                if (prefix.isEmpty()) return "";
            }
        }
        return prefix;
    }
}
```

### 复杂度分析

- 时间复杂度：O(S)，S 为所有字符总数（最坏情况）。
- 空间复杂度：O(1)，只维护一个前缀引用。
