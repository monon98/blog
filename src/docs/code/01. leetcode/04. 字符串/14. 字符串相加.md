# 字符串相加

> 难度：简单 | 标签：数学、字符串、模拟 | [LeetCode 原题](https://leetcode.cn/problems/add-strings/description/)

## 题目描述

给定两个以字符串形式表示的非负整数 `num1` 和 `num2`，返回 `num1` 和 `num2` 的乘积和，它们的和同样以字符串形式返回。你不能使用任何內建的用于处理大整数的库（比如 `BigInt`），也不能直接将输入的字符串转换为整数形式。

**示例 1：**

```
输入：num1 = "456", num2 = "77"
输出："533"
```

**示例 2：**

```
输入：num1 = "0", num2 = "0"
输出："0"
```

**提示：**

- `1 <= num1.length, num2.length <= 10^4`
- `num1` 和 `num2` 都只包含数字 `0-9`
- 都不包含任何前导零

## 题解

:::: details 点击查看题解

### 思路

模拟竖式加法：从两个串的末位开始逐位相加并维护进位。用 `charCodeAt(i) - 48` 把字符转成数字（不违反「不能整体转整数」的限制）。循环条件是任一串还有剩余位或有进位，结果逆序收集后翻转拼接。

这是大数运算类题目的通用模板，后续的「二进制求和」「字符串相乘」都基于同样的思路。

```javascript [JavaScript]
var addStrings = function(num1, num2) {
  let i = num1.length - 1;
  let j = num2.length - 1;
  let carry = 0;
  const res = [];
  while (i >= 0 || j >= 0 || carry > 0) {
    let sum = carry;
    if (i >= 0) sum += num1.charCodeAt(i--) - 48;
    if (j >= 0) sum += num2.charCodeAt(j--) - 48;
    carry = sum >= 10 ? 1 : 0;
    res.push(sum % 10);
  }
  return res.reverse().join("");
};
```

```python [Python]
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        i, j = len(num1) - 1, len(num2) - 1
        carry = 0
        res = []
        while i >= 0 or j >= 0 or carry > 0:
            total = carry
            if i >= 0:
                total += ord(num1[i]) - 48
                i -= 1
            if j >= 0:
                total += ord(num2[j]) - 48
                j -= 1
            carry = 1 if total >= 10 else 0
            res.append(str(total % 10))
        return "".join(reversed(res))
```

```rust [Rust]
impl Solution {
    pub fn add_strings(num1: String, num2: String) -> String {
        let (a, b) = (num1.as_bytes(), num2.as_bytes());
        let (mut i, mut j) = (a.len() as i64 - 1, b.len() as i64 - 1);
        let mut carry = 0u8;
        let mut res = Vec::new();
        while i >= 0 || j >= 0 || carry > 0 {
            let mut sum = carry;
            if i >= 0 {
                sum += a[i as usize] - b'0';
                i -= 1;
            }
            if j >= 0 {
                sum += b[j as usize] - b'0';
                j -= 1;
            }
            carry = sum / 10;
            res.push(b'0' + sum % 10);
        }
        res.reverse();
        String::from_utf8(res).unwrap()
    }
}
```

```go [Go]
func addStrings(num1 string, num2 string) string {
	i, j := len(num1)-1, len(num2)-1
	carry := 0
	var res []byte
	for i >= 0 || j >= 0 || carry > 0 {
		sum := carry
		if i >= 0 {
			sum += int(num1[i]) - 48
			i--
		}
		if j >= 0 {
			sum += int(num2[j]) - 48
			j--
		}
		carry = sum / 10
		res = append(res, byte(sum%10+'0'))
	}
	for l, r := 0, len(res)-1; l < r; l, r = l+1, r-1 {
		res[l], res[r] = res[r], res[l]
	}
	return string(res)
}
```

```java [Java]
class Solution {
    public String addStrings(String num1, String num2) {
        int i = num1.length() - 1, j = num2.length() - 1;
        int carry = 0;
        StringBuilder res = new StringBuilder();
        while (i >= 0 || j >= 0 || carry > 0) {
            int sum = carry;
            if (i >= 0) sum += num1.charAt(i--) - '0';
            if (j >= 0) sum += num2.charAt(j--) - '0';
            carry = sum / 10;
            res.append(sum % 10);
        }
        return res.reverse().toString();
    }
}
```
