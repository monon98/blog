# 反转字符串 II

> 难度：简单 | 标签：双指针、字符串 | [LeetCode 原题](https://leetcode.cn/problems/reverse-string-ii/description/)

## 题目描述

给定一个字符串 `s` 和一个整数 `k`，从字符串开头开始计数，每计数至 `2k` 个字符，就反转这 `2k` 字符中的前 `k` 个字符。如果剩余字符少于 `k` 个，则将剩余字符全部反转；如果剩余字符小于 `2k` 但大于或等于 `k` 个，则反转前 `k` 个字符，其余字符保持原样。

**示例 1：**

```
输入：s = "abcdefg", k = 2
输出："bacdfeg"
```

**示例 2：**

```
输入：s = "abcd", k = 2
输出："dcba"
```

**提示：**

- `1 <= s.length <= 10^4`
- `s` 仅由小写英文字母组成
- `1 <= k <= 10^4`

## 题解

:::: details 点击查看题解

### 思路

把字符串转成数组方便原地交换。每 `2k` 个字符为一组处理：对每组的前 k 个字符（注意右边界不能越界）做区间翻转，其余字符不动。最后拼回字符串。

### 代码实现

::: code-group

```javascript [JavaScript]
var reverseStr = function(s, k) {
  const arr = s.split("");
  for (let start = 0; start < arr.length; start += 2 * k) {
    let l = start;
    let r = Math.min(start + k - 1, arr.length - 1);
    while (l < r) {
      const t = arr[l];
      arr[l] = arr[r];
      arr[r] = t;
      l++;
      r--;
    }
  }
  return arr.join("");
};
```

```python [Python]
class Solution:
    def reverseStr(self, s: str, k: int) -> str:
        arr = list(s)
        for start in range(0, len(arr), 2 * k):
            l, r = start, min(start + k - 1, len(arr) - 1)
            while l < r:
                arr[l], arr[r] = arr[r], arr[l]
                l += 1
                r -= 1
        return "".join(arr)
```

```rust [Rust]
impl Solution {
    pub fn reverse_str(s: String, k: i32) -> String {
        let k = k as usize;
        let mut chars: Vec<char> = s.chars().collect();
        let mut start = 0;
        while start < chars.len() {
            let mut l = start;
            let mut r = std::cmp::min(start + k - 1, chars.len() - 1);
            while l < r {
                chars.swap(l, r);
                l += 1;
                r -= 1;
            }
            start += 2 * k;
        }
        chars.into_iter().collect()
    }
}
```

```go [Go]
func reverseStr(s string, k int) string {
	arr := []byte(s)
	for start := 0; start < len(arr); start += 2 * k {
		l := start
		r := start + k - 1
		if r > len(arr)-1 {
			r = len(arr) - 1
		}
		for l < r {
			arr[l], arr[r] = arr[r], arr[l]
			l++
			r--
		}
	}
	return string(arr)
}
```

```java [Java]
class Solution {
    public String reverseStr(String s, int k) {
        char[] arr = s.toCharArray();
        for (int start = 0; start < arr.length; start += 2 * k) {
            int l = start;
            int r = Math.min(start + k - 1, arr.length - 1);
            while (l < r) {
                char t = arr[l];
                arr[l] = arr[r];
                arr[r] = t;
                l++;
                r--;
            }
        }
        return new String(arr);
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个字符最多被交换一次。
- 空间复杂度：O(n)，字符数组（JavaScript 中字符串不可变）。
