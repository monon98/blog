# 反转字符串

> 难度：简单 | 标签：双指针、字符串 | [LeetCode 原题](https://leetcode.cn/problems/reverse-string/description/)

## 题目描述

编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 `s` 的形式给出，不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

**示例 1：**

```
输入：s = ["h","e","l","l","o"]
输出：["o","l","l","e","h"]
```

**示例 2：**

```
输入：s = ["H","a","n","n","a","h"]
输出：["h","a","n","n","a","H"]
```

**提示：**

- `1 <= s.length <= 10^5`

## 题解

:::: details 点击查看题解

### 思路

经典首尾双指针：左指针指向开头，右指针指向末尾，交换两个字符后同时向中间靠拢，相遇即结束。

### 代码实现

::: code-group

```javascript [JavaScript]
var reverseString = function(s) {
  let l = 0;
  let r = s.length - 1;
  while (l < r) {
    const t = s[l];
    s[l] = s[r];
    s[r] = t;
    l++;
    r--;
  }
};
```

```python [Python]
class Solution:
    def reverseString(self, s: List[str]) -> None:
        l, r = 0, len(s) - 1
        while l < r:
            s[l], s[r] = s[r], s[l]
            l += 1
            r -= 1
```

```rust [Rust]
impl Solution {
    pub fn reverse_string(s: &mut Vec<char>) {
        let mut l = 0;
        let mut r = s.len() - 1;
        while l < r {
            s.swap(l, r);
            l += 1;
            r -= 1;
        }
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，执行 n / 2 次交换。
- 空间复杂度：O(1)，原地修改。
