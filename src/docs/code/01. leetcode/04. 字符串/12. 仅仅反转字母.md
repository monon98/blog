# 仅仅反转字母

> 难度：简单 | 标签：双指针、字符串 | [LeetCode 原题](https://leetcode.cn/problems/reverse-only-letters/description/)

## 题目描述

给你一个字符串 `s`，根据下述规则反转它：所有英文字母反转位置，非英文字母的位置保持不变。返回反转后的结果。

**示例 1：**

```
输入：s = "ab-cd"
输出："dc-ba"
```

**示例 2：**

```
输入：s = "a-bC-dEf-ghIj"
输出："j-Ih-gfE-dCba"
```

**示例 3：**

```
输入：s = "Test1ng-Leet=code-Q!"
输出："Qedo1ct-eeLg=ntse-T!"
```

**提示：**

- `0 <= s.length <= 100`
- `s` 包含 ASCII 字符，其中字母为英文字母（大小写）

## 题解

:::: details 点击查看题解

### 思路

首尾双指针 + 字母判断。左右指针分别跳过非字母字符，遇到两个字母就交换并继续向中间推进。非字母字符始终留在原位。

### 代码实现

::: code-group

```javascript [JavaScript]
var reverseOnlyLetters = function(s) {
  const isLetter = (c) => (c >= "a" && c <= "z") || (c >= "A" && c <= "Z");
  const arr = s.split("");
  let l = 0;
  let r = arr.length - 1;
  while (l < r) {
    if (!isLetter(arr[l])) {
      l++;
    } else if (!isLetter(arr[r])) {
      r--;
    } else {
      const t = arr[l];
      arr[l] = arr[r];
      arr[r] = t;
      l++;
      r--;
    }
  }
  return arr.join("");
};
```

```python [Python]
class Solution:
    def reverseOnlyLetters(self, s: str) -> str:
        arr = list(s)
        l, r = 0, len(arr) - 1
        while l < r:
            if not arr[l].isalpha():
                l += 1
            elif not arr[r].isalpha():
                r -= 1
            else:
                arr[l], arr[r] = arr[r], arr[l]
                l += 1
                r -= 1
        return "".join(arr)
```

```rust [Rust]
impl Solution {
    pub fn reverse_only_letters(s: String) -> String {
        let mut chars: Vec<char> = s.chars().collect();
        let (mut l, mut r) = (0, chars.len().saturating_sub(1));
        while l < r {
            if !chars[l].is_ascii_alphabetic() {
                l += 1;
            } else if !chars[r].is_ascii_alphabetic() {
                r -= 1;
            } else {
                chars.swap(l, r);
                l += 1;
                r -= 1;
            }
        }
        chars.into_iter().collect()
    }
}
```
