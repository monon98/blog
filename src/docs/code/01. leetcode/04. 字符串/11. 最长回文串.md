# 最长回文串

> 难度：简单 | 标签：贪心、哈希表、字符串 | [LeetCode 原题](https://leetcode.cn/problems/longest-palindrome/description/)

## 题目描述

给定一个包含大写字母和小写字母的字符串 `s`，返回通过这些字母能构造出的最长的回文串的长度。在构造过程中请注意区分大小写，比如 `"Aa"` 不能当做一个回文字符串。

**示例 1：**

```
输入：s = "abccccdd"
输出：7
解释：可以构造的最长回文串是 "dccaccd"，其长度为 7。
```

**示例 2：**

```
输入：s = "a"
输出：1
```

**提示：**

- `1 <= s.length <= 2000`
- `s` 只由小写或大写英文字母组成

## 题解

:::: details 点击查看题解

### 思路

回文串中字符成对出现（最多一个字符落单放中间）。统计每个字符出现次数：每种字符能贡献 `⌊count / 2⌋ * 2` 个长度；只要存在奇数计数的字符，最终长度还能再加 1（放在正中间）。

### 代码实现

::: code-group

```javascript [JavaScript]
var longestPalindrome = function(s) {
  const cnt = {};
  for (const ch of s) {
    cnt[ch] = (cnt[ch] || 0) + 1;
  }
  let len = 0;
  let hasOdd = false;
  for (const c of Object.values(cnt)) {
    len += Math.floor(c / 2) * 2;
    if (c % 2 === 1) hasOdd = true;
  }
  return hasOdd ? len + 1 : len;
};
```

```python [Python]
class Solution:
    def longestPalindrome(self, s: str) -> int:
        cnt = {}
        for ch in s:
            cnt[ch] = cnt.get(ch, 0) + 1
        length = 0
        has_odd = False
        for c in cnt.values():
            length += c // 2 * 2
            if c % 2 == 1:
                has_odd = True
        return length + 1 if has_odd else length
```

```rust [Rust]
impl Solution {
    pub fn longest_palindrome(s: String) -> i32 {
        let mut cnt = [0; 52];
        for b in s.bytes() {
            let idx = if b >= b'a' {
                (b - b'a') as usize
            } else {
                26 + (b - b'A') as usize
            };
            cnt[idx] += 1;
        }
        let mut length = 0;
        let mut has_odd = false;
        for &c in &cnt {
            length += c / 2 * 2;
            if c % 2 == 1 {
                has_odd = true;
            }
        }
        if has_odd {
            length + 1
        } else {
            length
        }
    }
}
```

```go [Go]
func longestPalindrome(s string) int {
	var cnt [52]int
	for i := 0; i < len(s); i++ {
		b := s[i]
		if b >= 'a' {
			cnt[b-'a']++
		} else {
			cnt[26+b-'A']++
		}
	}
	length := 0
	hasOdd := false
	for _, c := range cnt {
		length += c / 2 * 2
		if c%2 == 1 {
			hasOdd = true
		}
	}
	if hasOdd {
		return length + 1
	}
	return length
}
```

```java [Java]
class Solution {
    public int longestPalindrome(String s) {
        int[] cnt = new int[128];
        for (char ch : s.toCharArray()) {
            cnt[ch]++;
        }
        int len = 0;
        boolean hasOdd = false;
        for (int c : cnt) {
            len += c / 2 * 2;
            if (c % 2 == 1) hasOdd = true;
        }
        return hasOdd ? len + 1 : len;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，n 为字符串长度。
- 空间复杂度：O(1)，最多 52 种大小写字母。
