# 整数反转

> 难度：简单 | 标签：数学 | [LeetCode 原题](https://leetcode.cn/problems/reverse-integer/description/)

## 题目描述

给你一个 32 位的有符号整数 `x`，返回将 `x` 中的数字部分反转后的结果。如果反转后整数超过 32 位的有符号整数的范围 `[−2^31, 2^31 − 1]`，就返回 0。假设环境不允许存储 64 位整数（有符号或无符号）。

**示例 1：**

```
输入：x = 123
输出：321
```

**示例 2：**

```
输入：x = -123
输出：-321
```

**示例 3：**

```
输入：x = 120
输出：21
```

**提示：**

- `-2^31 <= x <= 2^31 - 1`

## 题解

:::: details 点击查看题解

### 思路

逐位弹出并推入：每次取 `x % 10` 拼到结果末尾（`res = res * 10 + x % 10`），再对 `x` 做除 10。负数在 JavaScript 中 `%` 会保留符号，所以对负数用 `Math.ceil(x / 10)` 向零取整，保证循环正确终止。

最后检查结果是否超出 32 位范围，溢出则返回 0。（若环境严格限制 64 位整数，需要在乘法前判断 `res > Math.floor((2 ** 31 - 1) / 10)` 提前拦截，JavaScript 中数字为 double 可直接算完再判。）

### 代码实现

::: code-group

```javascript [JavaScript]
var reverse = function(x) {
  let res = 0;
  while (x !== 0) {
    res = res * 10 + (x % 10);
    x = x > 0 ? Math.floor(x / 10) : Math.ceil(x / 10);
  }
  return res >= -(2 ** 31) && res <= 2 ** 31 - 1 ? res : 0;
};
```

```python [Python]
class Solution:
    def reverse(self, x: int) -> int:
        sign = -1 if x < 0 else 1
        x = abs(x)
        res = 0
        while x:
            res = res * 10 + x % 10
            x //= 10
        res *= sign
        return res if -(2 ** 31) <= res <= 2 ** 31 - 1 else 0
```

```rust [Rust]
impl Solution {
    pub fn reverse(x: i32) -> i32 {
        let sign = if x < 0 { -1i64 } else { 1 };
        let mut x = (x as i64).abs();
        let mut res: i64 = 0;
        while x != 0 {
            res = res * 10 + x % 10;
            x /= 10;
        }
        res *= sign;
        if res < i32::MIN as i64 || res > i32::MAX as i64 {
            0
        } else {
            res as i32
        }
    }
}
```

```go [Go]
func reverse(x int) int {
	sign := 1
	if x < 0 {
		sign = -1
		x = -x
	}
	var res int64
	for x != 0 {
		res = res*10 + int64(x%10)
		x /= 10
	}
	res *= int64(sign)
	if res < -2147483648 || res > 2147483647 {
		return 0
	}
	return int(res)
}
```

```java [Java]
class Solution {
    public int reverse(int x) {
        long res = 0;
        while (x != 0) {
            res = res * 10 + x % 10;
            x /= 10;
        }
        if (res < Integer.MIN_VALUE || res > Integer.MAX_VALUE) return 0;
        return (int) res;
    }
}
```
