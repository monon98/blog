# Dota2 参议院

> 难度：中等 | 标签：贪心、队列、字符串 | [LeetCode 原题](https://leetcode.cn/problems/dota2-senate/description/)

## 题目描述

Dota2 的世界里有两个阵营：`Radiant`（天辉）和 `Dire`（夜魇）

Dota2 参议院由来自两派的参议员组成。现在参议院希望对一个 Dota2 游戏里的改变作出决定。他们以一个基于轮为过程的投票进行。在每一轮中，每一位参议员都可以行使两项权利中的 **一**项：

- **剥夺一名参议员的权利**：一名参议员可以使另一名参议员在本轮及所有后续轮次中失去所有权利。
- **宣布胜利**：如果参议员发现有权利投票的参议员都是 **同一个阵营的** ，他可以宣布胜利并决定在游戏中的有关变化。

给你一个字符串 `senate` 代表每个参议员的阵营。字母 `'R'` 和 `'D'`分别代表了 `Radiant`（天辉）和 `Dire`（夜魇）。然后，如果有 `n` 个参议员，给定字符串的大小将是 `n`。

以轮为基础的过程从给定顺序的第一个参议员开始到最后一个参议员结束。这一过程将持续到投票结束。所有失去权利的参议员将在过程中被跳过。

假设每一位参议员都足够聪明，会为自己的政党做出最好的策略，你需要预测哪一方最终会宣布胜利并在 Dota2 游戏中决定改变。输出应该是 `"Radiant"` 或 `"Dire"` 。

示例 1：

```
输入：senate = "RD"
输出："Radiant"
解释：
第 1 轮时，第一个参议员来自 Radiant 阵营，他可以使用第一项权利让第二个参议员失去所有权利。
这一轮中，第二个参议员将会被跳过，因为他的权利被禁止了。
第 2 轮时，第一个参议员可以宣布胜利，因为他是唯一一个有投票权的人。
```

示例 2：

```
输入：senate = "RDD"
输出："Dire"
解释：
第 1 轮时，第一个来自 Radiant 阵营的参议员可以使用第一项权利禁止第二个参议员的权利。
这一轮中，第二个来自 Dire 阵营的参议员会将被跳过，因为他的权利被禁止了。
这一轮中，第三个来自 Dire 阵营的参议员可以使用他的第一项权利禁止第一个参议员的权利。
因此在第二轮只剩下第三个参议员拥有投票的权利,于是他可以宣布胜利
```

**提示：**

- `n == senate.length`
- `1 <= n <= 10^4`
- `senate[i]` 为 `'R'` 或 `'D'`

## 题解

:::: details 点击查看题解

### 思路

用两个队列分别记录 `R`、`D` 参议员的原始下标，模拟轮转过程：每一步从两个队列各弹出队首，比较两者的下标——下标更小者在本轮先行动，他最优的策略是剥夺「下一个能轮到的对手」的权力，因此胜者把 `自己的下标 + n` 重新入队（`+n` 表示要等到下一轮才再次轮到），下标更大的败者直接出局。重复直到某一队列为空，此时剩下的阵营宣布胜利。

正确性在于：每个参议员面对的下一个对手就是当前队列里最靠前的对方参议员，而下标小者一定先获得行动权，所以「先到先剥夺」就是双方的最优策略，模拟即贪心。常见坑是用字符串反复删除被禁者（最坏 O(n²)，`n` 可达 `10^4`），用队列记录回合数即可线性完成；也要注意败者出局后胜者的下标要 `+n` 而不是保持原值，否则会在同一轮内重复行动。

```javascript [JavaScript]
var predictPartyVictory = function(senate) {
  const n = senate.length;
  const radiant = [];
  const dire = [];
  for (let i = 0; i < n; i++) {
    if (senate[i] === 'R') {
      radiant.push(i);
    } else {
      dire.push(i);
    }
  }
  let ri = 0;
  let di = 0;
  while (ri < radiant.length && di < dire.length) {
    if (radiant[ri] < dire[di]) {
      radiant.push(radiant[ri] + n);
    } else {
      dire.push(dire[di] + n);
    }
    ri++;
    di++;
  }
  return ri < radiant.length ? 'Radiant' : 'Dire';
};
```

```python [Python]
            else:
                dire.append(i)
        while radiant and dire:
            r, d = radiant.popleft(), dire.popleft()
            if r < d:
                radiant.append(r + n)
            else:
                dire.append(d + n)
        return 'Radiant' if radiant else 'Dire'
```

```rust [Rust]
use std::collections::VecDeque;

impl Solution {
    pub fn predict_party_victory(senate: String) -> String {
        let n = senate.len();
        let mut radiant = VecDeque::new();
        let mut dire = VecDeque::new();
        for (i, c) in senate.chars().enumerate() {
            if c == 'R' {
                radiant.push_back(i);
            } else {
                dire.push_back(i);
            }
        }
        while !radiant.is_empty() && !dire.is_empty() {
            let r = radiant.pop_front().unwrap();
            let d = dire.pop_front().unwrap();
            if r < d {
                radiant.push_back(r + n);
            } else {
                dire.push_back(d + n);
            }
        }
        if !radiant.is_empty() {
            "Radiant".to_string()
        } else {
            "Dire".to_string()
        }
    }
}
```

```go [Go]
func predictPartyVictory(senate string) string {
	n := len(senate)
	radiant := make([]int, 0, n)
	dire := make([]int, 0, n)
	for i := 0; i < n; i++ {
		if senate[i] == 'R' {
			radiant = append(radiant, i)
		} else {
			dire = append(dire, i)
		}
	}
	ri, di := 0, 0
	for ri < len(radiant) && di < len(dire) {
		if radiant[ri] < dire[di] {
			radiant = append(radiant, radiant[ri]+n)
		} else {
			dire = append(dire, dire[di]+n)
		}
		ri++
		di++
	}
	if ri < len(radiant) {
		return "Radiant"
	}
	return "Dire"
}
```

```java [Java]
class Solution {
    public String predictPartyVictory(String senate) {
        int n = senate.length();
        Queue<Integer> radiant = new LinkedList<>();
        Queue<Integer> dire = new LinkedList<>();
        for (int i = 0; i < n; i++) {
            if (senate.charAt(i) == 'R') {
                radiant.offer(i);
            } else {
                dire.offer(i);
            }
        }
        while (!radiant.isEmpty() && !dire.isEmpty()) {
            int r = radiant.poll();
            int d = dire.poll();
            if (r < d) {
                radiant.offer(r + n);
            } else {
                dire.offer(d + n);
            }
        }
        return radiant.isEmpty() ? "Dire" : "Radiant";
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每位参议员至多入队两次（每轮一次），总操作次数与 n 同阶。
- 空间复杂度：O(n)，两个队列存储参议员下标。
