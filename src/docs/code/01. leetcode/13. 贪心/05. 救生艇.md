# 救生艇

> 难度：中等 | 标签：贪心、数组、双指针、排序 | [LeetCode 原题](https://leetcode.cn/problems/boats-to-save-people/description/)

## 题目描述

给定数组 `people` 。`people[i]`表示第 `i`个人的体重 ，**船的数量不限**，每艘船可以承载的最大重量为 `limit`。

每艘船最多可同时载两人，但条件是这些人的重量之和最多为 `limit`。

返回 *承载所有人所需的最小船数* 。

**示例 1：**

```
输入：people = [1,2], limit = 3
输出：1
解释：1 艘船载 (1, 2)
```

**示例 2：**

```
输入：people = [3,2,2,1], limit = 3
输出：3
解释：3 艘船分别载 (1, 2), (2) 和 (3)
```

**示例 3：**

```
输入：people = [3,5,3,4], limit = 5
输出：4
解释：4 艘船分别载 (3), (3), (4), (5)
```

**提示：**

- `1 <= people.length <= 5 * 10^4`
- `1 <= people[i] <= limit <= 3 * 10^4`

## 题解

:::: details 点击查看题解

### 思路

排序后双指针：`light` 指向最轻的人（左端），`heavy` 指向最重的人（右端），船数从 0 计。每艘船先尝试让最重的人上船，再看最轻的人能否与他同乘：若 `people[light] + people[heavy] <= limit`，两人同船，`light++`；否则最重的人只能单独一船。无论哪种情况 `heavy--`、船数都 +1，直到两指针相遇。

贪心不变量是：最重的人必须在某条船上，而给他配同伴时，配最轻的人是唯一「可能塞得下」的选择——若最轻的人都配不上，其他人更配不上，最重者必然单独成行；若配得上，则这一组合同时消掉了当前最大和最小两个元素，不会让任何后续选择变差。常见坑是只从一端贪心（每次都装满两人）而忽略超重必须单人的情况；本题每船最多两人，所以双指针一次遍历即可，`people.length` 达 `5 * 10^4`，排序 O(n log n) 足够。

### 代码实现

::: code-group

```javascript [JavaScript]
var numRescueBoats = function(people, limit) {
  people.sort((a, b) => a - b);
  let light = 0;
  let heavy = people.length - 1;
  let boats = 0;
  while (light <= heavy) {
    if (people[light] + people[heavy] <= limit) {
      light++;
    }
    heavy--;
    boats++;
  }
  return boats;
};
```

### 复杂度分析

- 时间复杂度：O(n log n)，排序主导；双指针扫描为 O(n)。
- 空间复杂度：O(log n)，排序栈空间（Go 原地排序为 O(1)）。
