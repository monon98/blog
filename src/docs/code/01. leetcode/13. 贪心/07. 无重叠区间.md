# 无重叠区间

> 难度：中等 | 标签：贪心、数组、动态规划、排序 | [LeetCode 原题](https://leetcode.cn/problems/non-overlapping-intervals/description/)

## 题目描述

给定一个区间的集合 `intervals` ，其中 `intervals[i] = [start_i, end_i]` 。返回 *需要移除区间的最小数量，使剩余区间互不重叠*。

**注意** 只在一点上接触的区间是 **不重叠的**。例如 `[1, 2]` 和 `[2, 3]` 是不重叠的。

**示例 1：**

```
输入：intervals = [[1,2],[2,3],[3,4],[1,3]]
输出：1
解释：移除 [1,3] 后，剩下的区间没有重叠。
```

**示例 2：**

```
输入：intervals = [ [1,2], [1,2], [1,2] ]
输出：2
解释：你需要移除两个 [1,2] 来使剩下的区间没有重叠。
```

**示例 3：**

```
输入：intervals = [ [1,2], [2,3] ]
输出：0
解释：你不需要移除任何区间，因为它们已经是无重叠的了。
```

**提示:**

- `1 <= intervals.length <= 10^5`
- `intervals[i].length == 2`
- `-5 * 10^4 <= start_i < end_i <= 5 * 10^4`

## 题解

:::: details 点击查看题解

### 思路

问题等价于「求最多能保留多少个互不重叠的区间」，最少移除数 = 总数 − 最多保留数。贪心策略是经典的「按右端点排序，尽早结束」：把所有区间按 `end` 升序排序，用 `lastEnd` 记录已保留区间的结束位置，从左到右扫描，若当前区间的 `start >= lastEnd`（端点相接不算重叠，与题面一致），说明它可以接在后面，保留它并更新 `lastEnd = end`；否则它必然与已保留的某个区间重叠，只能移除。

关键在于必须按**右端点**排序而不是左端点：结束最早的区间给后面留下的空间最大，这是「活动选择问题」的标准证明思路；反例是 `[[1,100],[2,3],[4,5]]`，按左端点贪心会先选 `[1,100]` 而只剩一个区间，按右端点则保留 `[2,3]`、`[4,5]` 两个。常见坑还有把 `start == lastEnd` 误判为重叠。约束 `intervals.length` 达 `10^5`，排序 O(n log n) 后一遍扫描即可。

### 代码实现

::: code-group

```javascript [JavaScript]
var eraseOverlapIntervals = function(intervals) {
  intervals.sort((a, b) => a[1] - b[1]);
  let count = 1;
  let lastEnd = intervals[0][1];
  for (let i = 1; i < intervals.length; i++) {
    if (intervals[i][0] >= lastEnd) {
      count++;
      lastEnd = intervals[i][1];
    }
  }
  return intervals.length - count;
};
```

```python [Python]
class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        intervals.sort(key=lambda iv: iv[1])
        count, last_end = 1, intervals[0][1]
        for i in range(1, len(intervals)):
            if intervals[i][0] >= last_end:
                count += 1
                last_end = intervals[i][1]
        return len(intervals) - count
```

```rust [Rust]
impl Solution {
    pub fn erase_overlap_intervals(mut intervals: Vec<Vec<i32>>) -> i32 {
        intervals.sort_by_key(|iv| iv[1]);
        let mut count = 1;
        let mut last_end = intervals[0][1];
        for iv in intervals.iter().skip(1) {
            if iv[0] >= last_end {
                count += 1;
                last_end = iv[1];
            }
        }
        intervals.len() as i32 - count
    }
}
```

```go [Go]
func eraseOverlapIntervals(intervals [][]int) int {
	sort.Slice(intervals, func(i, j int) bool {
		return intervals[i][1] < intervals[j][1]
	})
	count := 1
	lastEnd := intervals[0][1]
	for _, iv := range intervals[1:] {
		if iv[0] >= lastEnd {
			count++
			lastEnd = iv[1]
		}
	}
	return len(intervals) - count
}
```

### 复杂度分析

- 时间复杂度：O(n log n)，按右端点排序主导；随后一遍扫描为 O(n)。
- 空间复杂度：O(log n)，排序栈空间（Go 原地排序为 O(1)）。
