# 分发糖果

> 难度：困难 | 标签：贪心、数组 | [LeetCode 原题](https://leetcode.cn/problems/candy/description/)

## 题目描述

`n` 个孩子站成一排。

给你一个整数数组 `ratings` 表示每个孩子的评分。

你需要按照以下要求，给这些孩子分发糖果：

- 每个孩子 **至少** 分配到 `1` 个糖果。
- 相邻两个孩子中，评分 **更高** 的那个会获得更多的糖果。

请你给每个孩子分发糖果，计算并返回需要准备的 **最少**糖果数目。

**示例 1：**

```
输入：ratings = [1,0,2]
输出：5
解释：你可以分别给第一个、第二个、第三个孩子分发 2、1、2 颗糖果。
```

**示例 2：**

```
输入：ratings = [1,2,2]
输出：4
解释：你可以分别给第一个、第二个、第三个孩子分发 1、2、1 颗糖果。
     第三个孩子只得到 1 颗糖果，这满足题面中的两个条件。
```

**提示：**

- `1 <= n == ratings.length <= 5 * 10^4`
- `0 <= ratings[i] <= 5 * 10^4`

## 题解

:::: details 点击查看题解

### 思路

贪心 + 两遍扫描：先从左到右扫一遍，只处理「左边比右边低」的上升约束——若 `ratings[i] > ratings[i - 1]`，则 `candies[i] = candies[i - 1] + 1`，否则先给 1；再从右到左对称地处理下降约束，若 `ratings[i] > ratings[i + 1]`，取 `max(candies[i], candies[i + 1] + 1)`。最后求和。

关键是 `max` 这一步：一个孩子可能同时处在上升沿和下降沿（比如山峰），第一遍只保证了左侧约束，第二遍必须在满足右侧约束的同时**不破坏**已经给过的左侧约束，所以要取较大值而不是直接覆盖。单遍按排名分配会漏掉这类冲突——例如 `[1,2,3,1]` 中下标 2 的峰顶在两遍法下得到 3（左侧要求 3、右侧要求 2，取 3），只按一遍算会偏小。两遍都是 O(n)，`n` 达 `5 * 10^4`，总和用 32 位整数即可装下（最坏 `5 * 10^4 * 5 * 10^4 = 2.5 * 10^9` 略超 `int` 上限……实际最坏总和为等差数列约 `n²/2 ≈ 1.25 * 10^9`，仍在 `int` 范围内）。

```javascript [JavaScript]
var candy = function(ratings) {
  const n = ratings.length;
  const candies = new Array(n).fill(1);
  for (let i = 1; i < n; i++) {
    if (ratings[i] > ratings[i - 1]) {
      candies[i] = candies[i - 1] + 1;
    }
  }
  for (let i = n - 2; i >= 0; i--) {
    if (ratings[i] > ratings[i + 1]) {
      candies[i] = Math.max(candies[i], candies[i + 1] + 1);
    }
  }
  let total = 0;
  for (const c of candies) total += c;
  return total;
};
```

```python [Python]
class Solution:
    def candy(self, ratings: List[int]) -> int:
        n = len(ratings)
        candies = [1] * n
        for i in range(1, n):
            if ratings[i] > ratings[i - 1]:
                candies[i] = candies[i - 1] + 1
        for i in range(n - 2, -1, -1):
            if ratings[i] > ratings[i + 1]:
                candies[i] = max(candies[i], candies[i + 1] + 1)
        return sum(candies)
```

```rust [Rust]
impl Solution {
    pub fn candy(ratings: Vec<i32>) -> i32 {
        let n = ratings.len();
        let mut candies = vec![1i32; n];
        for i in 1..n {
            if ratings[i] > ratings[i - 1] {
                candies[i] = candies[i - 1] + 1;
            }
        }
        for i in (0..n - 1).rev() {
            if ratings[i] > ratings[i + 1] {
                candies[i] = candies[i].max(candies[i + 1] + 1);
            }
        }
        candies.iter().sum()
    }
}
```

```go [Go]
func candy(ratings []int) int {
	n := len(ratings)
	candies := make([]int, n)
	for i := range candies {
		candies[i] = 1
	}
	for i := 1; i < n; i++ {
		if ratings[i] > ratings[i-1] {
			candies[i] = candies[i-1] + 1
		}
	}
	for i := n - 2; i >= 0; i-- {
		if ratings[i] > ratings[i+1] && candies[i] < candies[i+1]+1 {
			candies[i] = candies[i+1] + 1
		}
	}
	total := 0
	for _, c := range candies {
		total += c
	}
	return total
}
```

### 复杂度分析

- 时间复杂度：O(n)，正反两遍各扫描一次。
- 空间复杂度：O(n)，存储每个孩子的糖果数。
