# K 次取反后最大化的数组和

> 难度：简单 | 标签：贪心、数组、排序 | [LeetCode 原题](https://leetcode.cn/problems/maximize-sum-of-array-after-k-negations/description/)

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k` ，按以下方法修改该数组：

- 选择某个下标 `i` 并将 `nums[i]` 替换为 `-nums[i]` 。

重复这个过程恰好 `k` 次。可以多次选择同一个下标 `i` 。

以这种方式修改数组后，返回数组 **可能的最大和** 。

**示例 1：**

```
输入：nums = [4,2,3], k = 1
输出：5
解释：选择下标 1 ，nums 变为 [4,-2,3] 。
```

**示例 2：**

```
输入：nums = [3,-1,0,2], k = 3
输出：6
解释：选择下标 (1, 2, 2) ，nums 变为 [3,1,0,2] 。
```

**示例 3：**

```
输入：nums = [2,-3,-1,5,-4], k = 2
输出：13
解释：选择下标 (1, 4) ，nums 变为 [2,3,-1,5,4] 。
```

**提示：**

- `1 <= nums.length <= 10^4`
- `-100 <= nums[i] <= 100`
- `1 <= k <= 10^4`

## 题解

:::: details 点击查看题解

### 思路

先升序排序，然后贪心地「先处理负数」：从最小的元素开始，只要 `k > 0` 且当前元素为负，就取反它（每一步都让和增加最多，是显然的局部最优）。如果负数全部取反完 `k` 还没用完，剩下的取反次数必须成对落在同一个元素上——偶数次相互抵消，只有奇数次会真正改变结果，此时取反「绝对值最小的元素」代价最小。

一个细节：当 `k` 还有剩余时，说明所有负数都已变成非负，整个数组 `>= 0`，此时绝对值最小的元素就是排序后的最小值（可能是 0，取反它不损失任何和），用 `sum - 2 * min` 即可，无需再扫一遍找绝对值。常见坑是只顾取反负数、忘了处理剩余的奇数次，或误以为还要按绝对值重新排序——只要 `k` 还有剩余，就说明负数已全部取反、数组全部非负，此时「绝对值最小」就是「数值最小」，直接取最小值即可。

### 代码实现

```javascript [JavaScript]
var largestSumAfterKNegations = function(nums, k) {
  nums.sort((a, b) => a - b);
  for (let i = 0; i < nums.length && k > 0; i++) {
    if (nums[i] < 0) {
      nums[i] = -nums[i];
      k--;
    }
  }
  let sum = nums.reduce((a, b) => a + b, 0);
  if (k % 2 === 1) {
    sum -= 2 * Math.min(...nums);
  }
  return sum;
};
```

```python [Python]
class Solution:

        for i in range(len(nums)):
            if k == 0:
                break
            if nums[i] < 0:
                nums[i] = -nums[i]
                k -= 1
        total = sum(nums)
        if k % 2 == 1:
            total -= 2 * min(nums)
        return total
```

```rust [Rust]
impl Solution {
    pub fn largest_sum_after_k_negations(mut nums: Vec<i32>, mut k: i32) -> i32 {
        nums.sort();
        for x in nums.iter_mut() {
            if k == 0 {
                break;
            }
            if *x < 0 {
                *x = -*x;
                k -= 1;
            }
        }
        let total: i32 = nums.iter().sum();
        if k % 2 == 1 {
            total - 2 * nums.iter().min().unwrap()
        } else {
            total
        }
    }
}
```

```go [Go]
func largestSumAfterKNegations(nums []int, k int) int {
	sort.Ints(nums)
	for i := 0; i < len(nums) && k > 0; i++ {
		if nums[i] < 0 {
			nums[i] = -nums[i]
			k--
		}
	}
	sum := 0
	min := nums[0]
	for _, v := range nums {
		sum += v
		if v < min {
			min = v
		}
	}
	if k%2 == 1 {
		sum -= 2 * min
	}
	return sum
}
```

```java [Java]
class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {
        Arrays.sort(nums);
        for (int i = 0; i < nums.length && k > 0; i++) {
            if (nums[i] < 0) {
                nums[i] = -nums[i];
                k--;
            }
        }
        int sum = 0;
        for (int v : nums) sum += v;
        if (k % 2 == 1) {
            int min = Integer.MAX_VALUE;
            for (int v : nums) min = Math.min(min, v);
            sum -= 2 * min;
        }
        return sum;
    }
}
```

### 复杂度分析

- 时间复杂度：O(n log n)，排序主导；随后的取反与求和均为 O(n)。
- 空间复杂度：O(log n)，排序所需的栈空间（Go 原地排序为 O(1)）。
