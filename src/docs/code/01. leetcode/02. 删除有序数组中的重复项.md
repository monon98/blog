# 删除有序数组中的重复项

> 难度：简单 | 标签：数组、双指针 | [LeetCode 原题](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/description/)

## 题目描述

给一个非严格递增排列的数组 `nums`，请原地删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。元素的相对顺序应保持一致，必须在不使用额外空间的情况下原地修改输入数组（使用 O(1) 额外空间）。

**示例 1：**

```
输入：nums = [1,1,2]
输出：2, nums = [1,2,_]
解释：函数应返回新长度 2，前两个元素为 1、2。
```

**示例 2：**

```
输入：nums = [0,0,1,1,1,2,2,3,3,4]
输出：5, nums = [0,1,2,3,4,...]
```

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-100 <= nums[i] <= 100`
- `nums` 已按非严格递增排序

## 题解

::: details 点击查看题解

### 思路

快慢双指针。数组已排序，所以重复元素一定相邻：`slow` 指向已去重部分的末尾，`fast` 向右扫描，遇到与 `nums[slow]` 不同的值就把 `slow` 前移一位并写入该值。扫描结束后 `[0, slow]` 即去重后的结果，长度为 `slow + 1`。

### 代码实现

```javascript
var removeDuplicates = function(nums) {
  if (nums.length === 0) return 0;
  let slow = 0;
  for (let fast = 1; fast < nums.length; fast++) {
    if (nums[fast] !== nums[slow]) {
      slow++;
      nums[slow] = nums[fast];
    }
  }
  return slow + 1;
};
```

### 复杂度分析

- 时间复杂度：O(n)，快指针遍历一次数组。
- 空间复杂度：O(1)，原地修改。
