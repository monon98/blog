# 力扣算法题库

本组对应力扣算法分组 · [力扣算法题库](https://leetcode.cn/problemset/algorithms/)，从中精选 172 道高频题（原 100 道初级简单题 + 72 道中进阶题），覆盖数组、双指针、哈希表、栈/队列、链表、二叉树、二分查找、位运算与数学、动态规划入门，以及滑动窗口与前缀和、回溯、贪心、堆与优先队列、图与搜索、中级动态规划、链表进阶、二叉树进阶等进阶考点。

每道题包含题目描述、示例、思路讲解、多语言代码实现（JavaScript / Python / Rust / Go / Java 标签页切换）与复杂度分析。题解默认折叠，建议先自己动手实现再对照参考。
