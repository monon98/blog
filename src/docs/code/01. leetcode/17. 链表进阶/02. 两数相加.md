# 两数相加

> 难度：中等 | 标签：递归、链表、数学 | [LeetCode 原题](https://leetcode.cn/problems/add-two-numbers/description/)

## 题目描述

给你两个 **非空** 的链表，表示两个非负的整数。它们每位数字都是按照 **逆序** 的方式存储的，并且每个节点只能存储 **一位** 数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

示例 1：

```
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807.
```

示例 2：

```
输入：l1 = [0], l2 = [0]
输出：[0]
```

示例 3：

```
输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出：[8,9,9,9,0,0,0,1]
```

**提示：**

- 每个链表中的节点数在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`
- 题目数据保证列表表示的数字不含前导零

## 题解

:::: details 点击查看题解

### 思路

同步双指针逐位相加：因为数字是逆序存储的，个位在链表头部，所以直接从头到尾遍历即可，无需先反转。用 `carry` 记录进位，每一轮取出两个链表当前节点的值（已走完的链表按 0 处理）相加，节点值写 `sum % 10`，下一轮进位写 `sum / 10`。

循环条件必须是「`l1`、`l2` 至少一个未走完 **或** `carry` 非 0」，否则会漏掉最高位进位——示例 3 中 `9999999 + 9999 = 10009998`，最后一步正是靠 `carry` 多补出一个节点。常见替代解法是递归：每层处理一对节点并把 `carry` 传给下一层，与迭代完全等价，只是多了 O(max(m, n)) 的调用栈空间。

```javascript [JavaScript]
var addTwoNumbers = function(l1, l2) {
  const dummy = new ListNode(0);
  let cur = dummy;
  let carry = 0;
  while (l1 || l2 || carry) {
    const x = l1 ? l1.val : 0;
    const y = l2 ? l2.val : 0;
    const sum = x + y + carry;
    carry = Math.floor(sum / 10);
    cur.next = new ListNode(sum % 10);
    cur = cur.next;
    if (l1) l1 = l1.next;
    if (l2) l2 = l2.next;
  }
  return dummy.next;
};
```

```python [Python]
class Solution:
    def addTwoNumbers(self, l1: ListNode | None, l2: ListNode | None) -> ListNode | None:
        dummy = ListNode(0)
        cur = dummy
        carry = 0
        while l1 or l2 or carry:
            x = l1.val if l1 else 0
            y = l2.val if l2 else 0
            carry, val = divmod(x + y + carry, 10)
            cur.next = ListNode(val)
            cur = cur.next
            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next
        return dummy.next
```

```rust [Rust]
impl Solution {
    pub fn add_two_numbers(l1: Option<Box<ListNode>>, l2: Option<Box<ListNode>>) -> Option<Box<ListNode>> {
        let mut dummy = Box::new(ListNode::new(0));
        let mut cur = &mut dummy;
        let (mut a, mut b) = (l1, l2);
        let mut carry = 0;
        while a.is_some() || b.is_some() || carry > 0 {
            let mut sum = carry;
            if let Some(mut node) = a.take() {
                sum += node.val;
                a = node.next.take();
            }
            if let Some(mut node) = b.take() {
                sum += node.val;
                b = node.next.take();
            }
            carry = sum / 10;
            cur.next = Some(Box::new(ListNode::new(sum % 10)));
            cur = cur.next.as_mut().unwrap();
        }
        dummy.next
    }
}
```

```go [Go]
func addTwoNumbers(l1 *ListNode, l2 *ListNode) *ListNode {

		cur = cur.Next
```

### 复杂度分析

- 时间复杂度：O(max(m, n))，两个链表各遍历一次，m、n 分别为两链表长度。
- 空间复杂度：O(1)，除结果链表外只使用了常数个变量（结果链表最多比长者多一个节点）。
