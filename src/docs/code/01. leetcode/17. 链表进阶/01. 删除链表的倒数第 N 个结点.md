# 删除链表的倒数第 N 个结点

> 难度：中等 | 标签：链表、双指针 | [LeetCode 原题](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/description/)

## 题目描述

给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

**示例 1：**

```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

**示例 2：**

```
输入：head = [1], n = 1
输出：[]
```

**示例 3：**

```
输入：head = [1,2], n = 1
输出：[1]
```

**提示：**

- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

**进阶：** 你能尝试使用一趟扫描实现吗？

## 题解

:::: details 点击查看题解

### 思路

一趟扫描的快慢指针：引入哑节点 `dummy` 指向 `head`，让 `fast` 先从 `dummy` 走 `n` 步，之后快慢指针同速前进；当 `fast` 走到链表末尾节点时，`slow` 恰好停在待删节点的前驱上，执行 `slow.next = slow.next.next` 即完成删除。用 `dummy` 统一处理「删除的是头结点」（`n == sz`）的边界，避免对 `head` 特判。

该算法正好满足题目进阶要求的一趟扫描。常见替代做法是先遍历求长度 `sz`，再走 `sz - n` 步定位前驱，本质相同但要扫两趟。另一个易错点是快指针先行的步数与循环条件写错：`fast` 从 `dummy` 出发走 `n` 步，循环条件必须是 `fast.next`，否则会删错节点或在 `slow.next` 为 null 时越界。因 Rust 的 `Box` 是独占所有权，无法让快慢指针同时持有链表引用再原地修改，所以 Rust 版先用只读借用扫描算出慢指针应走的步数，再释放借用完成删除，指针移动语义与其他语言一致。

### 代码实现

::: code-group

```javascript [JavaScript]
var removeNthFromEnd = function(head, n) {
  const dummy = new ListNode(0, head);
  let fast = dummy;
  let slow = dummy;
  for (let i = 0; i < n; i++) {
    fast = fast.next;
  }
  while (fast.next) {
    fast = fast.next;
    slow = slow.next;
  }
  slow.next = slow.next.next;
  return dummy.next;
};
```

```rust [Rust]
impl Solution {
    pub fn remove_nth_from_end(head: Option<Box<ListNode>>, n: i32) -> Option<Box<ListNode>> {
        let mut dummy = Box::new(ListNode { val: 0, next: head });
        let mut steps = 0;
        {
            let mut fast: Option<&ListNode> = Some(&*dummy);
            for _ in 0..n {
                fast = fast.and_then(|f| f.next.as_deref());
            }
            while fast.and_then(|f| f.next.as_deref()).is_some() {
                fast = fast.and_then(|f| f.next.as_deref());
                steps += 1;
            }
        }
        let mut slow = &mut dummy;
        for _ in 0..steps {
            slow = slow.next.as_mut().unwrap();
        }
        slow.next = slow.next.as_mut().unwrap().next.take();
        dummy.next
    }
}
```

```go [Go]
func removeNthFromEnd(head *ListNode, n int) *ListNode {
	dummy := &ListNode{Next: head}
	fast, slow := dummy, dummy
	for i := 0; i < n; i++ {
		fast = fast.Next
	}
	for fast.Next != nil {
		fast = fast.Next
		slow = slow.Next
	}
	slow.Next = slow.Next.Next
	return dummy.Next
}
```

### 复杂度分析

- 时间复杂度：O(n)，快慢指针各最多遍历一次链表。
- 空间复杂度：O(1)，只使用了若干指针。
