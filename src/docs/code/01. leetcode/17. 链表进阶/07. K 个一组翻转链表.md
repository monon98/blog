# K 个一组翻转链表

> 难度：困难 | 标签：递归、链表 | [LeetCode 原题](https://leetcode.cn/problems/reverse-nodes-in-k-group/description/)

## 题目描述

给你链表的头节点 `head` ，每 `k` 个节点一组进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

**示例 1：**

```
输入：head = [1,2,3,4,5], k = 2
输出：[2,1,4,3,5]
```

**示例 2：**

```
输入：head = [1,2,3,4,5], k = 3
输出：[3,2,1,4,5]
```

**提示：**

- 链表中的节点数目为 `n`
- `1 <= k <= n <= 5000`
- `0 <= Node.val <= 1000`

**进阶：** 你可以设计一个只用 `O(1)` 额外内存空间的算法解决此问题吗？

### 思路

迭代 + 哨兵节点逐组处理，每轮固定三步：**检查、反转、接线**。引入 `dummy` 哨兵并用 `groupPrev` 指向已处理部分的尾节点，`groupPrev.next` 恒指向当前待处理组的组首。第一步从 `groupPrev` 向后走 k 步，若中途遇到 `null` 说明剩余不足 k 个，直接返回 `dummy.next` 保持尾部原序；第二步就地反转这 k 个节点——保存后继指针后把节点逐个前移，反转完成时原组首变成组尾、`cur` 停在新头；第三步接线：`groupPrev.next` 指向新头 `cur`，原组尾 `groupTail.next` 指向剩余部分，再把 `groupPrev` 推进到 `groupTail`，开始下一组。

易错点集中在两处：一是「不足 k 个」的检查必须在反转**之前**完成，若先反转再判断，尾部不足一组的节点会被错误倒序，违反题面「最后剩余的节点保持原有顺序」；二是反转循环里必须先用临时变量保存 `next` 再改 `cur.next` 的指向，否则后继链直接丢失。Rust 版因为 `Box` 独占所有权无法像其他语言那样同时持有相邻指针，先把整组节点从链上取下、用头插法重建后再接回，步骤与其余语言一一对应。

满足进阶要求的 O(1) 额外空间：迭代版只用常数个指针。常见替代解法是递归——先递归翻转 `head` 之后的部分拿到新头，再把前 k 个节点翻转后接到最前面——代码更短，但递归栈是 O(n/k)（k=1 时退化为 O(n)），不满足严格的常数空间；按值重排或借助数组都不是「实际进行节点交换」。

```javascript [JavaScript]
var reverseKGroup = function(head, k) {
  const dummy = new ListNode(0, head);
  let groupPrev = dummy;
  while (true) {
    let end = groupPrev;
    for (let i = 0; i < k; i++) {
      end = end.next;
      if (!end) return dummy.next;
    }
    let cur = groupPrev.next;
    const groupTail = cur;
    let next = cur.next;
    for (let i = 0; i < k - 1; i++) {
      const tmp = next.next;
      next.next = cur;
      cur = next;
      next = tmp;
    }
    groupPrev.next = cur;
    groupTail.next = next;
    groupPrev = groupTail;
  }
};
```

class Solution:
    def reverseKGroup(self, head: ListNode | None, k: int) -> ListNode | None:
        dummy = ListNode(0, head)
        group_prev = dummy
        while True:
            end = group_prev

                end = end.next

```rust [Rust]
impl Solution {
    pub fn reverse_k_group(head: Option<Box<ListNode>>, k: i32) -> Option<Box<ListNode>> {
        let mut dummy = Box::new(ListNode::new(0));
        dummy.next = head;
        let mut group_prev: &mut Option<Box<ListNode>> = &mut dummy.next;
        loop {
            // 检查剩余是否够 k 个，不够则保持原序
            let mut count = 1;
            let mut probe: Option<&ListNode> = group_prev.as_deref();
            while count < k {
                probe = match probe.and_then(|p| p.next.as_deref()) {
                    Some(node) => node,
                    None => break,
                };
                count += 1;
            }
            if count < k {
                break;
            }
            // 整组取下，头插法反转，remain 是后面的剩余链
            let mut remain = group_prev.as_mut().unwrap().next.take();
            let mut rev: Option<Box<ListNode>> = None;
            for _ in 0..k {
                let mut node = remain.take().unwrap();
                remain = node.next.take();
                node.next = rev;
                rev = Some(node);
            }
            // 组尾（原组首）接上剩余链
            let mut tail_slot: &mut Option<Box<ListNode>> = &mut rev;
            for _ in 1..k {
                tail_slot = &mut tail_slot.as_mut().unwrap().next;
            }
            tail_slot.as_mut().unwrap().next = remain;
            // 上一组尾接上反转后的新头
            group_prev.as_mut().unwrap().next = rev;
            // 游标前移到本组尾的 next 槽，作为下一组组首
            let mut p = group_prev;
            for _ in 1..k {
                p = &mut p.as_mut().unwrap().next;
            }
            group_prev = &mut p.as_mut().unwrap().next;
        }
        dummy.next
    }
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点恰好被访问、反转和接线各常数次。
- 空间复杂度：O(1)，迭代只使用常数个指针；递归写法为 O(n/k) 调用栈。
