# 两两交换链表中的节点

> 难度：中等 | 标签：递归、链表 | [LeetCode 原题](https://leetcode.cn/problems/swap-nodes-in-pairs/description/)

## 题目描述

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

**示例 1：**

```
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```

**示例 2：**

```
输入：head = []
输出：[]
```

**示例 3：**

```
输入：head = [1]
输出：[1]
```

**提示：**

- 链表中节点的数目在范围 `[0, 100]` 内
- `0 <= Node.val <= 100`

## 题解

:::: details 点击查看题解

### 思路

虚拟头节点 + 前驱指针的迭代交换：`prev` 始终指向「已处理部分的尾节点」，每轮先确认存在完整一对（`prev.next` 与 `prev.next.next` 都非空），再取出 `first = prev.next`、`second = first.next`，四步完成接线——`first.next = second.next`、`second.next = first`、`prev.next = second`，最后 `prev = first` 为下一对做好准备。交换两节点时务必先保存 `second.next`（下一对的起点）再改指向，否则会丢链。

不足一对的尾部（节点数为奇数或空链表）由循环条件天然处理，直接保留原序。递归解法更简洁：先递归交换 `head.next` 之后的子链表拿到新头 `newHead`，再让 `head` 与 `head.next` 互换、把 `newHead` 接到 `head.next`，但递归栈是 O(n) 空间；迭代版只用常数个指针，满足 O(1) 额外空间。

```javascript [JavaScript]
var swapPairs = function(head) {
  const dummy = new ListNode(0, head);
  let prev = dummy;
  while (prev.next && prev.next.next) {
    const first = prev.next;
    const second = first.next;
    first.next = second.next;
    second.next = first;
    prev.next = second;
    prev = first;
  }
  return dummy.next;
};
```

```rust [Rust]
impl Solution {
    pub fn swap_pairs(head: Option<Box<ListNode>>) -> Option<Box<ListNode>> {
        let mut dummy = Box::new(ListNode::new(0));
        dummy.next = head;
        let mut prev = &mut dummy;
        while prev.next.is_some() && prev.next.as_ref().unwrap().next.is_some() {
            let mut first = prev.next.take().unwrap();
            let mut second = first.next.take().unwrap();
            first.next = second.next.take();
            second.next = Some(first);
            prev.next = Some(second);
            prev = prev.next.as_mut().unwrap().next.as_mut().unwrap();
        }
        dummy.next
    }
}
```

```go [Go]
func swapPairs(head *ListNode) *ListNode {

	prev := dummy
	for prev.Next != nil && prev.Next.Next != nil {

		second := first.Next
		first.Next = second.Next
		second.Next = first
		prev.Next = second
		prev = first
	}
	return dummy.Next
}
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点恰好被访问和接线一次。
- 空间复杂度：O(1)，迭代只用常数个指针；递归解法为 O(n) 调用栈。
