# 奇偶链表

> 难度：中等 | 标签：链表 | [LeetCode 原题](https://leetcode.cn/problems/odd-even-linked-list/description/)

## 题目描述

给定单链表的头节点 `head` ，将所有索引为奇数的节点和索引为偶数的节点分别分组，保持它们原有的相对顺序，然后把偶数索引节点分组连接到奇数索引节点分组之后，返回重新排序的链表。

**第一个**节点的索引被认为是 **奇数** ， **第二个**节点的索引为 **偶数** ，以此类推。

请注意，偶数组和奇数组内部的相对顺序应该与输入时保持一致。

你必须在 `O(1)` 的额外空间复杂度和 `O(n)` 的时间复杂度下解决这个问题。

**示例 1：**

```
输入：head = [1,2,3,4,5]
输出：[1,3,5,2,4]
```

**示例 2：**

```
输入：head = [2,1,3,5,6,4,7]
输出：[2,3,6,7,1,5,4]
```

**提示:**

- `n == ` 链表中的节点数
- `0 <= n <= 10^4`
- `-10^6 <= Node.val <= 10^6`

### 思路

奇偶双指针原地分组：用 `odd` 指向奇数段的尾节点、`even` 指向偶数段的尾节点，并先用 `evenHead` 记住偶数段的起点。每一轮执行两次「跳一格」——`odd.next = odd.next.next` 跳过紧随的偶数节点、`even.next = even.next.next` 跳过紧随的奇数节点——然后两个指针同速前进。循环不变量是：`odd` 走过的部分全部是奇数索引节点、`even` 走过的部分全部是偶数索引节点，且两段内部相对顺序与输入一致。遍历结束后把奇数段尾的 `odd.next` 接回 `evenHead`，即完成拼接。

关键细节有三处：一是必须在改指针前保存 `evenHead`，否则第一次跳转后偶数段就失联了；二是循环条件必须是 `even && even.next` 而不是 `odd && odd.next`——偶数段永远比奇数段少一个或与之等长，奇数指针总是落后一格且至少有头节点兜底，用偶数指针判空才能保证跳转时 `odd.next.next` 一定存在；三是收尾时 `odd` 一定非空，直接接线即可。该做法满足题面要求的 O(n) 时间与 O(1) 额外空间。替代做法是把节点值取进数组重排再写回，或按索引奇偶分桶，都需要 O(n) 额外空间，不满足约束。

```javascript [JavaScript]
var oddEvenList = function(head) {
  if (!head || !head.next) return head;
  let odd = head;
  let even = head.next;
  const evenHead = even;
  while (even && even.next) {
    odd.next = odd.next.next;
    even.next = even.next.next;
    odd = odd.next;
    even = even.next;
  }
  odd.next = evenHead;
  return head;
};
```

```rust [Rust]
impl Solution {
    pub fn odd_even_list(head: Option<Box<ListNode>>) -> Option<Box<ListNode>> {
        let mut head = head;
        if head.as_ref().map_or(true, |n| n.next.is_none()) {
            return head;
        }
        // 先拆出偶数段起点，奇偶两条链各自重接
        let mut even_head = head.as_mut().unwrap().next.take();
        let mut odd_slot: &mut Option<Box<ListNode>> = &mut head;
        let mut even_slot: &mut Option<Box<ListNode>> = &mut even_head;
        loop {
            // 偶数节点后面挂着下一个奇数节点
            let mut next_odd = match even_slot.as_mut().and_then(|e| e.next.take()) {
                Some(node) => node,
                None => break,
            };
            // 奇数节点后面挂着下一个偶数节点
            let next_even = next_odd.next.take();
            odd_slot.as_mut().unwrap().next = Some(next_odd);
            odd_slot = &mut odd_slot.as_mut().unwrap().next;
            match next_even {
                Some(node) => {
                    even_slot.as_mut().unwrap().next = Some(node);
                    even_slot = &mut even_slot.as_mut().unwrap().next;
                }
                None => break,
            }
        }
        // 奇数段尾接回偶数段
        odd_slot.as_mut().unwrap().next = even_head;
        head
    }
}
```

func oddEvenList(head *ListNode) *ListNode {

	odd, even := head, head.Next

		odd.Next = odd.Next.Next
		even.Next = even.Next.Next
		odd = odd.Next
		even = even.Next
	}
	odd.Next = evenHead
	return head
}

### 复杂度分析

- 时间复杂度：O(n)，每个节点恰好被访问并重接一次。
- 空间复杂度：O(1)，只使用了若干指针和偶数段头的引用。
