# 对象路径取值 deepGet 与 deepSet

> 难度：简单 | 标签：对象、路径解析、lodash

## 题目描述

实现两个安全读写嵌套属性的工具函数（lodash 的 get/set 核心逻辑）：

- `deepGet(obj, path)`：按路径取值，任意一层不存在返回 undefined 而不报错；路径支持 `"a.b.c"`、`"list[0].name"` 两种写法，也支持数组形式 `["a", 0, "name"]`
- `deepSet(obj, path, value)`：按路径写入，中间层不存在时自动创建对象

**示例：**

```javascript
const state = { user: { tags: ["vue"] } };

deepGet(state, "user.tags[0]"); // "vue"
deepGet(state, "user.address.city"); // undefined
deepSet(state, "user.address.city", "杭州");
state.user.address.city; // "杭州"
```

## 题解

::: details 点击查看题解

### 思路

1. **路径归一化**：把方括号写法转成点分——`path.replace(/\[(\w+)\]/g, ".$1")` 再 split(".")，统一成键名数组。注意数字索引会以字符串形式出现，JS 对象访问自动兼容
2. **deepGet 用 reduce 短路**：`reduce((o, k) => o?.[k], obj)` 一行完成，可选链保证中途为 null/undefined 不抛错
3. **deepSet 逐层补建**：遍历到倒数第二个键，当前层缺键就创建空对象，最后赋值

### 代码实现

```javascript
function toPathKeys(path) {
  if (Array.isArray(path)) return path;
  return path.replace(/\[(\w+)\]/g, ".$1").split(".").filter(Boolean);
}

function deepGet(obj, path) {
  return toPathKeys(path).reduce((o, key) => (o == null ? undefined : o[key]), obj);
}

function deepSet(obj, path, value) {
  const keys = toPathKeys(path);
  let current = obj;
  for (let i = 0; i < keys.length - 1; i++) {
    const key = keys[i];
    if (typeof current[key] !== "object" || current[key] === null) {
      current[key] = {};
    }
    current = current[key];
  }
  current[keys[keys.length - 1]] = value;
  return obj;
}
```

### 考察点

- 正则归一化两种路径语法是第一步也是易错点（含点号的 key、负数索引属于进阶边界）
- 可选链 + reduce 组合让「安全读」极其简洁
- 中间层被非对象值占据时的覆盖策略
- 应用：表单状态管理、i18n 字典查找、接口响应字段容错读取
