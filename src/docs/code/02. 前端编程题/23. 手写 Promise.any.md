# 手写 Promise.any

> 难度：简单 | 标签：Promise、异步

## 题目描述

实现 `myAny(promises)`：

- 任一任务成功即整体 resolve 该值（与 race 不同，忽略先到达的失败）
- 全部失败时 reject 一个 `AggregateError`，其 `errors` 属性按原始顺序包含所有失败原因
- 空数组直接 reject AggregateError

**示例：**

```javascript
myAny([fail("a"), ok("fast"), slow()]).then(console.log); // "fast"
myAny([fail("a"), fail("b")]).catch((e) => e.errors.map(String));
// ["Error: a", "Error: b"]
```

## 题解

::: details 点击查看题解

### 思路

all 的镜像题：成功计数器换成失败计数器。每个元素挂两个回调——成功直接 resolve；失败计数加一，达到总数时用 `new AggregateError(errors, "All promises were rejected")` 拒绝。

注意 `AggregateError` 是 ES2021 标准类，Node 15+ / 现代浏览器可用，旧环境可退化为普通 Error 并手动挂 errors 数组。

### 代码实现

```javascript
MyPromise.any = function (promises) {
  return new MyPromise((resolve, reject) => {
    const errors = [];
    let rejectedCount = 0;
    const list = Array.from(promises);
    const total = list.length;

    if (total === 0) {
      return reject(new AggregateError([], "All promises were rejected"));
    }

    list.forEach((item, index) => {
      MyPromise.resolve(item).then(resolve, (reason) => {
        errors[index] = reason;
        if (++rejectedCount === total) {
          reject(new AggregateError(errors, "All promises were rejected"));
        }
      });
    });
  });
};
```

### 考察点

- any / race / all / allSettled 四兄弟的行为矩阵：谁短路、谁等待、谁透传错误
- errors 必须按下标写入以维持顺序语义
- 典型场景：多镜像源竞速取首个可用响应
- 追问：any 成功后其余任务是否继续执行——继续，只是结果被丢弃
