# 解析 URL 参数

> 难度：入门 | 标签：URL、正则、字符串处理

## 题目描述

实现 `parseQueryString(url)`，从 URL 中提取查询参数并返回对象：

- 支持 `?a=1&b=2` 形式；同名参数转为数组：`?tag=a&tag=b → { tag: ["a", "b"] }`
- 对值做 `decodeURIComponent` 解码
- 无值的键解析为空字符串或 true
- 兼容 hash 路由中的 query（`#/list?id=5`）
- 给出 URLSearchParams 的现代写法对照

**示例：**

```javascript
parseQuery("https://a.com/list?page=2&keyword=%E5%89%8D%E7%AB%AF&tag=vue&tag=react");
// { page: "2", keyword: "前端", tag: ["vue", "react"] }
```

## 题解

::: details 点击查看题解

### 思路

1. 先定位 query 段：优先取 `?` 之后、`#` 之前的部分（注意顺序——hash 里也可能带 ？，需取最后一个 ？ 或按业务约定）
2. 按 `&` 分割、每个键值对按第一个 `=` 切开（value 里可能含 =，如 base64）
3. 同名键已存在则合并为数组；最后统一 decodeURIComponent

现代方案直接 `new URL(url).searchParams` 或 `URLSearchParams(searchString)`，自动完成解码与 get/getAll/getAll 语义。

### 代码实现

```javascript
function parseQuery(url) {
  const queryStart = url.indexOf("?");
  if (queryStart === -1) return {};

  let search = url.slice(queryStart + 1);
  const hashIndex = search.indexOf("#");
  if (hashIndex !== -1) search = search.slice(0, hashIndex);

  const result = {};
  if (!search) return result;

  for (const pair of search.split("&")) {
    if (!pair) continue;
    const eqIndex = pair.indexOf("=");
    const rawKey = eqIndex === -1 ? pair : pair.slice(0, eqIndex);
    const rawValue = eqIndex === -1 ? "" : pair.slice(eqIndex + 1);

    const key = decodeURIComponent(rawKey);
    const value = decodeURIComponent(rawValue);

    if (key in result) {
      result[key] = [].concat(result[key], value);
    } else {
      result[key] = value;
    }
  }
  return result;
}

const parseQueryModern = (url) =>
  Object.fromEntries(
    [...new URL(url).searchParams].map(([k, v]) => {
      return [k, v];
    })
  );
```

### 考察点

- 「第一个 = 分割」保护 base64 等含等号值
- 同名参数合并数组的写法 `[].concat(existing, value)` 兼容单值与多值两种现状
- URLSearchParams 与手写的差异：它把 `+` 当空格解码，且不区分数组语义
- 追问：如何生成 query 字符串（反向序列化）、history 路由与 hash 路由下获取方式的区别
