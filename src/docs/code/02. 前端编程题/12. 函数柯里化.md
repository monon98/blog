# 函数柯里化 curry

> 难度：简单 | 标签：闭包、高阶函数、函数式

## 题目描述

实现 `curry(fn)`，把多参数函数转换为可分步传参的柯里化函数：

- 收集的参数达到原函数形参个数时立即执行并返回结果
- 参数不足时返回一个新函数继续收集（支持一次传多个）
- 需要兼容 `this` 传递

**示例：**

```javascript
function add(a, b, c) {
  return a + b + c;
}

const curried = curry(add);
curried(1)(2)(3); // 6
curried(1, 2)(3); // 6
curried(1, 2, 3); // 6
```

## 题解

::: details 点击查看题解

### 思路

利用函数的 `length` 属性获取「第一个默认参数之前的形参个数」作为目标。内部递归：每次收集一批参数，够数就执行，不够就再返回一层闭包继续收——闭包天然负责跨调用保存已收集参数。

注意 `fn.length` 不含剩余参数和带默认值的参数之后的形参，这是与 lodash/ramma 等库实现的细微差异点。

### 代码实现

```javascript
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn.apply(this, args);
    }
    return function (...rest) {
      return curried.apply(this, args.concat(rest));
    };
  };
}
```

### 考察点

- 闭包在「分次调用间共享状态」中的作用
- 函数式编程中柯里化的价值：参数复用、延迟执行、配合 compose 组合
- 变体追问：占位符版本（lodash 的 `_`）、无限收集直到显式调用的「不定参柯里化」
- 与偏函数（partial application）的区别：固定部分参数 vs 完全逐参求值
