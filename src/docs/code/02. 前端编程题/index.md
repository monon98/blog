# 前端编程题

这里是 30 道前端高频编程题（手写题）的题解汇总，覆盖 JavaScript 语言核心、异步编程、经典场景、数据转换、框架原理（Vue / React）与工具函数六大类。

与 [LeetCode 初级算法](../01.%20leetcode/) 侧重的数据结构算法不同，本目录聚焦前端工程中的手写实现能力；与 `01. javascript/99. 面试场景题` 的提纲式条目互补，这里每道题都提供完整可运行的参考实现。

::: tip 与力扣 JS 专项的关系
原收录的 21 道手写题（call/apply/bind、instanceof、扁平化、map/filter/reduce、柯里化、compose、记忆化、JSON.stringify、深比较、防抖、节流、sleep、promisify、EventEmitter、并发控制 ×2、chunk、groupBy、once）与 [力扣 JS 专项](../04.%20力扣%20JS%20专项/) 高度重复，其独有讲解已并入对应力扣题页，本目录不再保留；本目录剩余 30 题均为**非力扣来源的面试手写题**（各题页头部行已标注「来源：面试手写题（非力扣）」）。
:::

每道题包含题目描述、示例、思路讲解与代码实现。题解默认折叠，建议先自己动手实现再对照参考。
