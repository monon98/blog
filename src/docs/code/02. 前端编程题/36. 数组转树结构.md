# 数组转树结构

> 难度：中等 | 标签：递归、Map、数据转换

## 题目描述

实现 `listToTree(items)`，把扁平的节点数组转换为树形结构：

- 每个节点形如 `{ id, parentId, ... }`，`parentId` 指向父节点的 id，根节点 parentId 为 null
- 子节点放入 `children` 数组
- 要求 O(n) 时间复杂度（不允许对每个节点全表查找父级）
- 支持乱序输入、孤儿节点容错

**示例：**

```javascript
listToTree([
  { id: 1, parentId: null },
  { id: 2, parentId: 1 },
  { id: 3, parentId: 1 },
  { id: 4, parentId: 2 }
]);
// [{ id: 1, children: [
//   { id: 2, children: [{ id: 4, children: [] }] },
//   { id: 3, children: [] }
// ]}]
```

## 题解

::: details 点击查看题解

### 思路

两遍扫描 + 哈希索引：

1. 第一遍把每个节点包装成带空 children 的对象，以 id 为键存入 Map——O(1) 定位任意节点
2. 第二遍按 parentId 找父节点挂载：是根就进结果数组，否则 push 进父的 children

因为引用共享，第二遍的 push 会自动反映在第一遍构建的结构里，无需递归。相比「每次 filter 找孩子」的 O(n²) 写法，这是标准优化答案。

### 代码实现

```javascript
function listToTree(items, rootParentId = null) {
  const nodeMap = new Map();

  for (const item of items) {
    nodeMap.set(item.id, { ...item, children: [] });
  }

  const tree = [];
  for (const item of items) {
    const node = nodeMap.get(item.id);
    if (item.parentId === rootParentId) {
      tree.push(node);
    } else {
      const parent = nodeMap.get(item.parentId);
      if (parent) {
        parent.children.push(node);
      } else {
        tree.push(node);
      }
    }
  }
  return tree;
}
```

### 考察点

- 空间换时间：id → 节点 的 Map 索引把找父级降到 O(1)
- 「先建索引再连线」避免了两层嵌套 filter
- 孤儿节点（parentId 不存在）按业务决定丢弃或提升为根
- 追问：树转回数组（见下一篇）、多根节点、排序稳定性（children 内保持原顺序）
