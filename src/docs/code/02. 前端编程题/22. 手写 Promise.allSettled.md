# 手写 Promise.allSettled

> 难度：简单 | 标签：Promise、异步

## 题目描述

实现 `myAllSettled(promises)`：

- 等待全部任务结束（无论成败），返回统一格式的状态数组
- 成功项：`{ status: "fulfilled", value }`
- 失败项：`{ status: "rejected", reason }`
- 结果顺序与输入顺序一致；整体永不 reject

**示例：**

```javascript
myAllSettled([ok(), fail("boom")]).then(console.log);
// [
//   { status: "fulfilled", value: "ok" },
//   { status: "rejected", reason: Error("boom") }
// ]
```

## 题解

::: details 点击查看题解

### 思路

在 Promise.all 的骨架上做两处改造：失败分支不再 reject 整体，而是包装成 `{ status: "rejected", reason }` 计入结果；成功分支同样包一层 `{ status: "fulfilled", value }`。计数逻辑完全一致。

适用场景：批量请求容错展示、并行初始化多个互不依赖的模块。

### 代码实现

```javascript
MyPromise.allSettled = function (promises) {
  return new MyPromise((resolve) => {
    const results = [];
    let settledCount = 0;
    const list = Array.from(promises);
    const total = list.length;

    if (total === 0) return resolve(results);

    list.forEach((item, index) => {
      MyPromise.resolve(item).then(
        (value) => {
          results[index] = { status: "fulfilled", value };
          if (++settledCount === total) resolve(results);
        },
        (reason) => {
          results[index] = { status: "rejected", reason };
          if (++settledCount === total) resolve(results);
        }
      );
    });
  });
};
```

### 考察点

- 与 all 的唯一结构差异：把「错误也当作一种正常结果」收集
- 返回对象的字段名是规范强约束（status/value/reason），写错会被测试抓住
- 追问：如何统计失败数量、如何在全部结束后做统一 UI 提示
