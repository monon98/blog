# 手写 apply

> 难度：入门 | 标签：this、原型、Function

## 题目描述

实现 `Function.prototype.myApply`，模拟原生 `apply` 方法：

- 第二个参数为数组或类数组，作为函数的实参列表展开传入
- 其余行为与 `call` 一致（绑定 `this`、处理空值、返回执行结果）
- 不传第二个参数时函数应正常以无参方式执行

**示例：**

```javascript
function sum(a, b) {
  return a + b + this.base;
}

sum.myApply({ base: 100 }, [1, 2]);
// 输出: 103
```

## 题解

::: details 点击查看题解

### 思路

与手写 `call` 完全同构，仅参数处理不同：直接把第二个参数透传给调用即可，无需展开。需要兼容 `arguments` 这种类数组对象吗？现代 JavaScript 中 `context[key](argsArray)` 本身支持数组；若要严格兼容类数组，可用 `Array.from(argsList)` 转换。

### 代码实现

```javascript
Function.prototype.myApply = function (context, argsList) {
  if (typeof this !== "function") {
    throw new TypeError("myApply must be called on a function");
  }
  context = context ?? globalThis;
  const key = Symbol();
  context[key] = this;
  const result =
    Array.isArray(argsList) || typeof argsList === "object"
      ? context[key](...argsList)
      : context[key]();
  delete context[key];
  return result;
};
```

### 考察点

- `call` 与 `apply` 只差在参数形态：`call(ctx, a, b)` vs `apply(ctx, [a, b])`
- 类数组转数组：`Array.from` / 展开运算符
- 参数为 `null` / `undefined` 时按无参调用处理

:::
