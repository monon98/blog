# 图片懒加载

> 难度：中等 | 标签：DOM、IntersectionObserver、性能优化

## 题目描述

实现图片懒加载 `lazyLoadImages(selector)`：

- 页面初始只加载视口内的图片，滚动到附近时再按需加载
- 图片真实地址存放在 `data-src` 属性上，进入可视区时赋值给 `src` 并停止监听
- 提供两种方案：IntersectionObserver（现代首选）与 scroll + getBoundingClientRect（兼容降级）
- 降级方案需节流，且已加载的图片要移出处理队列

**示例：**

```html
<img data-src="https://cdn.example.com/a.jpg" alt="" />
```

## 题解

::: details 点击查看题解

### 思路

方案一 IntersectionObserver：浏览器在合成线程异步计算交叉状态，不阻塞主线程。`isIntersecting` 为真时换 src 并 `unobserve`。

方案二 scroll 监听：每次滚动遍历未加载图片，用 `getBoundingClientRect().top < viewportHeight + threshold` 判断是否进入预加载区；必须配合节流，加载完成后从数组移除避免重复判断。

### 代码实现

```javascript
function lazyLoadWithObserver(selector = "img[data-src]", rootMargin = "200px") {
  const observer = new IntersectionObserver(
    (entries, self) => {
      for (const entry of entries) {
        if (entry.isIntersecting) {
          const img = entry.target;
          img.src = img.dataset.src;
          img.removeAttribute("data-src");
          self.unobserve(img);
        }
      }
    },
    { rootMargin, threshold: 0.01 }
  );
  document.querySelectorAll(selector).forEach((img) => observer.observe(img));
  return () => observer.disconnect();
}

function lazyLoadWithScroll(selector = "img[data-src]") {
  let images = Array.from(document.querySelectorAll(selector));

  const loadIfNeeded = () => {
    const viewportBottom =
      window.innerHeight || document.documentElement.clientHeight;
    images = images.filter((img) => {
      const rect = img.getBoundingClientRect();
      if (rect.top <= viewportBottom + 100) {
        img.src = img.dataset.src;
        return false;
      }
      return true;
    });
    if (!images.length) {
      window.removeEventListener("scroll", throttledCheck);
      window.removeEventListener("resize", throttledCheck);
    }
  };

  const throttledCheck = throttle(loadIfNeeded, 200);
  window.addEventListener("scroll", throttledCheck);
  window.addEventListener("resize", throttledCheck);
  loadIfNeeded();
}
```

### 考察点

- IntersectionObserver 为什么优于 scroll 监听：主线程无关、无布局抖动
- rootMargin 实现「提前一段距离预加载」，改善体验
- data-src 占位与宽高预留防止 CLS 布局偏移
- 追问：首屏大图如何进一步优化——preload、priority hints、响应式 srcset 配合
