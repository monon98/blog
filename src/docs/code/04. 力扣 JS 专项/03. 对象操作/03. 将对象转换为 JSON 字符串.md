# 将对象转换为 JSON 字符串

> 难度：中等 | 标签：递归、序列化、类型判断 | LeetCode 2633（VIP 专属题） · [原题链接](https://leetcode.cn/problems/convert-object-to-json-string/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

请实现函数 `jsonStringify(object)`：给定一个值，返回该值的有效 JSON 字符串。你可以假设这个值只包括字符串、整数、数组、对象、布尔值和 null。返回的字符串不能包含额外的空格，键的返回顺序应该与 `Object.keys()` 的顺序相同。

请你在不使用内置方法 `JSON.stringify` 的前提下解决这个问题。

**示例 1：**

```
输入：object = {"y":1,"x":2}
输出：{"y":1,"x":2}
解释：
返回该对象的 JSON 表示形式。
注意，键的返回顺序应该与 Object.keys() 的顺序相同。
```

**示例 2：**

```
输入：object = {"a":"str","b":-12,"c":true,"d":null}
输出：{"a":"str","b":-12,"c":true,"d":null}
解释：
JSON 的基本类型是字符串、数字型、布尔值和 null。
```

**示例 3：**

```
输入：object = {"key":{"a":1,"b":[{},null,"Hello"]}}
输出：{"key":{"a":1,"b":[{},null,"Hello"]}}
解释：
对象和数组可以包括其他对象和数组。
```

**示例 4：**

```
输入：object = true
输出：true
解释：
基本类型是有效的输入
```

**提示：**

- `value` 是一个有效的 JSON 值
- `1 <= JSON.stringify(object).length <= 10^5`
- `maxNestingLevel <= 1000`
- 所有字符串只包含字母数字字符

## 题解

::: details 点击查看题解

### 思路

整体策略是按类型分支递归：每种 JSON 值对应一段固定文本，对象与数组互相嵌套，必须递归展开后拼接，输入是合法 JSON 所以不存在环。

`null` 必须最先判断——它的 `typeof` 是 `object`，混进对象分支会走错逻辑；随后字符串包双引号、数字与布尔用字符串化输出、数组套中括号、对象套花括号。

数组用 `map(jsonStringify).join(",")` 一行拼接；对象按 `Object.keys()` 的顺序遍历，拼成 `"key":value` 的形式，题目要求的键序由此天然满足。

本题字符串只包含字母数字，省掉了转义步骤；通用版 `JSON.stringify` 还要把 `"` 和 `\` 加上反斜杠、处理 `\n` 等控制字符，**键名也要走同一套转义**，否则含引号的键会破坏结构。

输入不含 `undefined`、函数、`Symbol`、`NaN` 与循环引用，所以简版实现里那些「跳过」语义用不上：对象属性中的 `undefined`/函数被丢弃、数组元素变 `null`、顶层变 `undefined`，`NaN`/`Infinity` 输出 `null`，循环引用抛 `TypeError`（用 `WeakSet` 记录路径上的对象，进入子级前添加、回溯时删除，只增不减会把兄弟节点的共享引用误判成环）。

追问方向：`toJSON` 方法、`replacer`/`space` 参数、`BigInt` 抛 `TypeError` 等原生扩展行为。

### 代码实现

```javascript
var jsonStringify = function (object) {
  // null 的 typeof 是 object，必须先单独处理
  if (object === null) return "null";

  const type = typeof object;
  if (type === "string") return `"${object}"`; // 题目保证只含字母数字，无需转义
  if (type === "number" || type === "boolean") return String(object);

  if (Array.isArray(object)) {
    return `[${object.map(jsonStringify).join(",")}]`;
  }

  // 普通对象：键序与 Object.keys() 一致，键同样包双引号
  const pairs = Object.keys(object).map(
    (key) => `"${key}":${jsonStringify(object[key])}`
  );
  return `{${pairs.join(",")}}`;
};
```

### 复杂度分析

- 时间复杂度：O(n)，n 为输出字符串长度，每个值只序列化一次。
- 空间复杂度：O(d + n)，d 为嵌套深度（递归栈），另有拼接产生的字符串开销。
