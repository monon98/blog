# 两个对象之间的差异

> 难度：中等 | 标签：递归、深度比较、对象 | LeetCode 2700（VIP 专属题） · [原题链接](https://leetcode.cn/problems/differences-between-two-objects/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

请你编写一个函数，它接收两个深度嵌套的对象或数组 `obj1` 和 `obj2`，并返回一个新对象表示它们之间的差异。

该函数应该比较这两个对象的属性，并识别任何变化。返回的对象应仅包含从 `obj1` 到 `obj2` 的值不同的键。

对于每个变化的键，值应表示为一个数组 `[obj1 value, obj2 value]`。不存在于一个对象中但存在于另一个对象中的键不应包含在返回的对象中。在比较两个数组时，数组的索引被视为它们的键。最终结果应是一个深度嵌套的对象，其中每个叶子的值都是一个差异数组。

你可以假设这两个对象都是 `JSON.parse` 的输出结果。

**示例 1：**

```
输入：
obj1 = {}
obj2 = {
  "a": 1,
  "b": 2
}
输出：{}
解释：obj1 没有进行任何修改。obj2 中出现了新的键 "a" 和 "b"，但添加或删除的键应该被忽略。
```

**示例 2：**

```
输入：
obj1 = {
  "a": 1,
  "v": 3,
  "x": [],
  "z": {
    "a": null
  }
}
obj2 = {
  "a": 2,
  "v": 4,
  "x": [],
  "z": {
    "a": 2
  }
}
输出：
{
  "a": [1, 2],
  "v": [3, 4],
  "z": {
    "a": [null, 2]
  }
}
解释：键 "a"、"v" 和 "z" 都有变化。"a" 从 1 变为 2，"v" 从 3 变为 4，"z" 的子对象 "a" 从 null 变为 2。
```

**示例 3：**

```
输入：
obj1 = {
  "a": 5,
  "v": 6,
  "z": [1, 2, 4, [2, 5, 7]]
}
obj2 = {
  "a": 5,
  "v": 7,
  "z": [1, 2, 3, [1]]
}
输出：
{
  "v": [6, 7],
  "z": {
    "2": [4, 3],
    "3": {
      "0": [2, 1]
    }
  }
}
解释：在 obj1 和 obj2 中，键 "v" 和 "z" 的值不同。"a" 被忽略，因为值没有变化。在键 "z" 中，有一个嵌套的数组，数组被视为对象，其中索引被视为键。数组发生了两处变化：z[2] 和 z[3][0]。z[0] 和 z[1] 没有变化，因此没有包含在结果中。z[3][1] 和 z[3][2] 被删除，因此也没有包含在结果中。
```

**示例 4：**

```
输入：
obj1 = {
  "a": {"b": 1}
}
obj2 = {
  "a": [5]
}
输出：
{
  "a": [{"b": 1}, [5]]
}
解释：键 "a" 在两个对象中都存在。但由于两个相关值具有不同的类型，所以它们被放置在差异数组中。
```

**示例 5：**

```
输入：
obj1 = {
  "a": [1, 2, {}],
  "b": false
}
obj2 = {
  "b": false,
  "a": [1, 2, {}]
}
输出：{}
解释：除了键的顺序不同之外，两个对象是相同的，因此返回一个空对象。
```

**提示：**

- `obj1` 和 `obj2` 都是有效的 JSON 对象或数组
- `2 <= JSON.stringify(obj1).length <= 10^4`
- `2 <= JSON.stringify(obj2).length <= 10^4`

## 题解

::: details 点击查看题解

### 思路

整体策略是递归下钻、只保留变化：双方同一位置都是容器且类型一致时，逐个共有的键比较；只要有一方是标量或类型不匹配，就把 `[obj1, obj2]` 作为叶子差异整体返回，不再往下拆。

只出现在一侧的键必须丢弃（示例 1、示例 3 中被删除的 `z[3][1]` 都不进结果），所以遍历 `obj1` 的键并用 `hasOwnProperty` 确认 `obj2` 也有，交集之外一律跳过。

「类型不一致就是叶子」这一步要放在最前面，而且必须区分数组与普通对象——示例 4 里 `{"b": 1}` 与 `[5]` 一个对象一个数组，若继续按键下钻会得出错误的嵌套差异，应整体输出 `[{"b": 1}, [5]]`。

递归得到的子差异若为空对象，说明这一层没有变化，父层不能收录该键；`[v1, v2]` 形式的叶子差异永远非空，两者用 `Object.keys` 的长度即可区分。

比较相等用严格相等即可：入参都是合法 JSON，不存在 `NaN`（`NaN !== NaN` 会让相等值被误判为差异）。

最终结构里容器层是普通对象（哪怕这一层原来是数组），索引键以字符串形式出现，正如示例 3 输出的 `"2"`、`"3"`。

### 代码实现

```javascript
var objDiff = function (obj1, obj2) {
  const isObj = (v) => v !== null && typeof v === "object";

  // 类型不同（数组 / 普通对象 / 标量混用）→ 整段作为叶子差异
  if (Array.isArray(obj1) !== Array.isArray(obj2)) return [obj1, obj2];
  if (!isObj(obj1) || !isObj(obj2)) {
    return obj1 === obj2 ? {} : [obj1, obj2];
  }

  const diff = {};
  for (const key of Object.keys(obj1)) {
    // 只比较双方共有的键：单侧新增/删除的键按题意忽略
    if (!Object.prototype.hasOwnProperty.call(obj2, key)) continue;
    const sub = objDiff(obj1[key], obj2[key]);
    if (Object.keys(sub).length > 0) diff[key] = sub;
  }
  return diff;
};
```

### 复杂度分析

- 时间复杂度：O(n)，n 为两棵结构中被共同访问的节点数，每个节点只比较一次。
- 空间复杂度：O(n)，递归栈与结果差异对象。
