# 将 JSON 字符串转换为对象

> 难度：困难 | 标签：递归下降、解析、JSON | LeetCode 2759（VIP 专属题） · [原题链接](https://leetcode.cn/problems/convert-json-string-to-object/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

给定一个字符串 `str`，返回 JSON 解析后的 `parsedStr`。你可以假设 `str` 是一个有效的 JSON 字符串，因此它只包含字符串、数字、数组、对象、布尔值和 null，`str` 不会包含不可见字符和转义字符。

请在不使用内置的 `JSON.parse` 方法的情况下解决此问题。

**示例 1：**

```
输入：str = '{"a":2,"b":[1,2,3]}'
输出：{"a":2,"b":[1,2,3]}
解释：返回由 JSON 字符串表示的对象。
```

**示例 2：**

```
输入：str = 'true'
输出：true
解释：原始类型是有效的 JSON。
```

**示例 3：**

```
输入：str = '[1,5,"false",{"a":2}]'
输出：[1,5,"false",{"a":2}]
解释：返回由 JSON 字符串表示的数组。
```

**提示：**

- `str` 是一个有效的 JSON 字符串
- `1 <= str.length <= 10^5`

## 题解

::: details 点击查看题解

### 思路

整体策略是手写递归下降解析器：维护一个下标指针 `i`，入口 `parseValue` 看当前字符分派到对象、数组、字符串、数字或字面量的解析函数，从头调用一次即可。

正则切分或按逗号 `split` 都不可靠——嵌套括号、字符串里出现的逗号与引号都会让简单的切分错位，只有顺着结构递归才稳。

对象解析：跳过 `{`，循环读「键 → 跳过冒号 → 解析值 → 遇到逗号再进下一轮、遇到右花括号结束」，最后把 `}` 也消耗掉。数组同理，把分隔符换成 `,` 与 `]`，空数组在进入循环时就被 `]` 挡住。

字符串解析从左引号开始逐字符搬运，直到遇到右引号；题目保证没有转义字符，所以不必处理 `\"`，通用版本要在这里识别反斜杠并把后一个字符原样吞掉。

数字解析读到 `,`、`}``、`]` 任一分隔符即停（不消耗分隔符，交还给上层），再用 `Number` 转换，正负号、小数、指数形式都能覆盖。

`true`、`false`、`null` 三个字面量直接按长度跳步返回——它们出现在值的位置且输入合法，无需逐字校验。

解析出的键用普通赋值即可，但若要兼容含 `__proto__` 的键，应改用 `Object.defineProperty`，否则会触发原型 setter 而丢键。

### 代码实现

```javascript
var jsonParse = function (str) {
  let i = 0;

  const parseValue = () => {
    const c = str[i];
    if (c === "{") return parseObject();
    if (c === "[") return parseArray();
    if (c === '"') return parseString();
    if (c === "t") { i += 4; return true; }
    if (c === "f") { i += 5; return false; }
    if (c === "n") { i += 4; return null; }
    return parseNumber();
  };

  const parseObject = () => {
    const obj = {};
    i++; // 跳过 {
    while (str[i] !== "}") {
      const key = parseString(); // 结束后 i 停在 :
      i++; // 跳过 :
      obj[key] = parseValue(); // 结束后 i 停在 , 或 }
      if (str[i] === ",") i++;
    }
    i++; // 跳过 }
    return obj;
  };

  const parseArray = () => {
    const arr = [];
    i++; // 跳过 [
    while (str[i] !== "]") {
      arr.push(parseValue());
      if (str[i] === ",") i++;
    }
    i++; // 跳过 ]
    return arr;
  };

  const parseString = () => {
    let s = "";
    i++; // 跳过开始引号
    while (str[i] !== '"') {
      s += str[i];
      i++;
    }
    i++; // 跳过结束引号
    return s;
  };

  const parseNumber = () => {
    let s = "";
    while (i < str.length && !",}]".includes(str[i])) {
      s += str[i];
      i++;
    }
    return Number(s);
  };

  return parseValue();
};
```

### 复杂度分析

- 时间复杂度：O(n)，每个字符只被读取一次。
- 空间复杂度：O(n)，解析出的对象/数组结构与递归调用栈。
