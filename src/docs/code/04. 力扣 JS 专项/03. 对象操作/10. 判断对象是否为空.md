# 判断对象是否为空

> 难度：简单 | 标签：对象、数组、长度判断 | LeetCode 2727 · [原题链接](https://leetcode.cn/problems/is-object-empty/)

## 题目描述

给定一个对象或数组，判断它是否为空。

- 一个空对象不包含任何键值对。
- 一个空数组不包含任何元素。

你可以假设对象或数组是通过 `JSON.parse` 解析得到的。

**示例 1：**

```
输入：obj = {"x": 5, "y": 42}
输出：false
解释：这个对象有两个键值对，所以它不为空。
```

**示例 2：**

```
输入：obj = {}
输出：true
解释：这个对象没有任何键值对，所以它为空。
```

**示例 3：**

```
输入：obj = [null, false, 0]
输出：false
解释：这个数组有 3 个元素，所以它不为空。
```

**提示：**

- `obj` 是一个有效的 JSON 对象或数组
- `2 <= JSON.stringify(obj).length <= 10^5`

**你可以在 O(1) 时间复杂度内解决这个问题吗？**

## 题解

::: details 点击查看题解

### 思路

整体策略是按形态分流：数组看 `length`，对象看有没有可枚举键，两者都为空才返回 `true`。

数组必须用 `length` 判断，不能用 `Object.keys`——`[null, false, 0]` 的每个元素都是合法值，键肯定存在，但更关键的是 `length` 直接反映元素个数且是最直观的 O(1) 读取。

对象的常规写法是 `Object.keys(obj).length === 0`，它会把全部键收集一遍，时间与键数成正比。

进阶要求的 O(1) 写法是 `for...in` 提前返回：对象非空时，第一个键就足以判定 `false`；对象为空时循环体一次都不会执行，直接落到 `return true`。两种情况都只做常数次工作。

`for...in` 会遍历原型链上的可枚举属性，但入参是 `JSON.parse` 的产物，普通对象的原型上没有可枚举键，结果不受影响。

注意 `obj` 一定是对象或数组（序列化长度至少为 2，`{}` 或 `[]`），不存在还要额外处理原始值的分支；也不要写成 `!obj`，那会把空对象误判为真值之外的情况。

### 代码实现

```javascript
var isEmpty = function (obj) {
  if (Array.isArray(obj)) return obj.length === 0;
  // 非空对象遇到第一个键就能返回；空对象循环体一次都不进 → 期望 O(1)
  for (const key in obj) {
    return false;
  }
  return true;
};
```

### 复杂度分析

- 时间复杂度：O(1)，数组读 `length`；对象要么第一个键就返回、要么没有键可遍历。
- 空间复杂度：O(1)，不产生额外结构。

:::
