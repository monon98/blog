# 从两个数组中创建对象

> 难度：简单 | 标签：对象、键值对、去重 | LeetCode 2794（VIP 专属题） · [原题链接](https://leetcode.cn/problems/create-object-from-two-arrays/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

给定两个数组 `keysArr` 和 `valuesArr`，返回一个新的对象 `obj`。`obj` 中的每个键值对都来自 `keysArr[i]` 和 `valuesArr[i]`。

如果前面的索引中存在重复的键，则应该跳过该键值对。换句话说，只有第一次出现的键会被添加到对象中。

如果键不是字符串，则应通过调用 `String()` 方法将其转换为字符串。

**示例 1：**

```
输入：keysArr = ["a", "b", "c"], valuesArr = [1, 2, 3]
输出：{"a": 1, "b": 2, "c": 3}
解释：键 "a"、"b" 和 "c" 分别与值 1、2 和 3 配对。
```

**示例 2：**

```
输入：keysArr = ["1", 1, false], valuesArr = [4, 5, 6]
输出：{"1": 4, "false": 6}
解释：首先，将 arr1 中的所有元素转换为字符串。我们可以看到有两个 "1" 的出现。使用第一次出现 "1" 的关联值：4。
```

**示例 3：**

```
输入：keysArr = [], valuesArr = []
输出：{}
解释：没有键，因此返回一个空对象。
```

**提示：**

- `keysArr` 和 `valuesArr` 都是有效的 JSON 数组
- `2 <= JSON.stringify(keysArr).length, JSON.stringify(valuesArr).length <= 5 * 10^5`
- `keysArr.length === valuesArr.length`

## 题解

::: details 点击查看题解

### 思路

整体策略是按下标配对遍历：同一个 `i` 上的键与值组成一对，键先字符串化再写入结果，两个数组等长所以循环到 `keysArr.length` 即可。

重复键只保留第一次：写入前用 `hasOwnProperty` 查一下，已有就 `continue` 跳过。示例 2 的 `"1"` 与 `1` 字符串化后撞成同一个键，于是 5 被丢掉、保留首次的 4。

判「键是否已存在」必须用 `hasOwnProperty` 而不是 `in`/直接读取：若键是 `constructor`、`toString` 这类原型链上的名字，读取会拿到函数而误判为已存在。

不能用 `Object.fromEntries(keysArr.map((k, i) => [k, valuesArr[i]]))`——后者是后者覆盖前者，与「保留首次」正好相反。

键写入建议用 `Object.defineProperty`：当键是 `__proto__` 时，普通赋值会触发原型 setter 而不是创建同名属性，键就丢了；`defineProperty` 会强制创建自有属性。

三个边界都过一遍：空数组返回 `{}`；键为布尔 `false` 转成 `"false"`；键为数字转成十进制字符串，`String(1)` 与 `1 + ""` 等价，但前者更直白。

### 代码实现

```javascript
var createObject = function (keysArr, valuesArr) {
  const obj = {};
  for (let i = 0; i < keysArr.length; i++) {
    const key = String(keysArr[i]); // 非字符串键统一转成字符串
    if (Object.prototype.hasOwnProperty.call(obj, key)) continue; // 重复键只保留首次
    // 用 defineProperty 强制建自有属性，避免 __proto__ 触发原型 setter
    Object.defineProperty(obj, key, {
      value: valuesArr[i],
      writable: true,
      enumerable: true,
      configurable: true,
    });
  }
  return obj;
};
```

### 复杂度分析

- 时间复杂度：O(n)，n 为 `keysArr.length`，每对键值只处理一次。
- 空间复杂度：O(k)，k 为去重后的键数量。
