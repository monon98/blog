# 精简对象

> 难度：中等 | 标签：递归、对象、真值判断 | LeetCode 2705 · [原题链接](https://leetcode.cn/problems/compact-object/)

## 题目描述

现给定一个对象或数组 `obj`，返回一个 **精简对象** 。

**精简对象** 与原始对象相同，只是将包含 **假** 值的键移除。该操作适用于对象及其嵌套对象。数组被视为索引作为键的对象。当 `Boolean(value)` 返回 `false` 时，值被视为 **假** 值。

你可以假设 `obj` 是 `JSON.parse` 的输出结果。换句话说，它是有效的 JSON。

**示例 1：**

```
输入：obj = [null, 0, false, 1]
输出：[1]
解释：数组中的所有假值已被移除。
```

**示例 2：**

```
输入：obj = {"a": null, "b": [false, 1]}
输出：{"b": [1]}
解释：obj["a"] 和 obj["b"][0] 包含假值，因此被移除。
```

**示例 3：**

```
输入：obj = [null, 0, 5, [0], [false, 16]]
输出：[5, [], [16]]
解释：obj[0], obj[1], obj[3][0], 和 obj[4][0] 包含假值，因此被移除。
```

**提示：**

- `obj` 是一个有效的 JSON 对象
- `2 <= JSON.stringify(obj).length <= 10^6`

## 题解

::: details 点击查看题解

### 思路

整体策略是递归三路分流：数组走数组的处理，普通对象走对象的处理，原始值原样返回、由上一层决定去留。

原始值不要在本层就过滤成 `undefined`——`undefined` 与「被移除」语义不同，交给上一层用 `Boolean(value)` 判真伪更统一。

对象分支逐键递归，递归结果为假值的键直接不写入新对象；数组分支先 `map` 递归精简、再 `filter(Boolean)` 丢掉假值元素，顺序保持不变。

关键在「先递归、后判真伪」的顺序：示例 3 的 `[0]` 递归后变成空数组 `[]`，`[]` 是真值所以整项保留（输出里的 `[5, [], [16]]` 正是如此）；若先判 `[0]` 为真再递归，或者把空数组也当假值丢掉，都会得到错误结果。

嵌套容器被精简成空之后仍是真值，父层会保留这个空容器（如对象 `a` 的值是 `b` 键为 `null` 的对象，精简后 `a` 仍保留为空对象）——题目只说移除「含假值的键」，空对象/空数组本身不是假值。

边界检查：根节点必然是对象或数组（序列化长度至少 2），不会出现整根被判假的情况；`null`、`0`、`""`、`false`、`NaN` 是要被移除的全部假值，其中 JSON 里只有前四者。

### 代码实现

```javascript
var compactObject = function (obj) {
  const dfs = (node) => {
    if (Array.isArray(node)) {
      // 数组：先递归精简，再丢掉假值元素（保持相对顺序）
      return node.map(dfs).filter(Boolean);
    }
    if (node !== null && typeof node === "object") {
      const res = {};
      for (const [key, value] of Object.entries(node)) {
        const compacted = dfs(value);
        if (compacted) res[key] = compacted; // 只保留真值键
      }
      return res;
    }
    return node; // 原始值交给上一层判断
  };

  return dfs(obj);
};
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(n)，递归栈加精简后的新结构（不会超过原结构大小）。
