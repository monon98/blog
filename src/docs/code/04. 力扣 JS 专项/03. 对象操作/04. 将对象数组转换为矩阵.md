# 将对象数组转换为矩阵

> 难度：困难 | 标签：递归、深度优先搜索、对象 | LeetCode 2675（VIP 专属题） · [原题链接](https://leetcode.cn/problems/array-of-objects-to-matrix/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

编写一个函数，将对象数组 `arr` 转换为矩阵 `m`。

`arr` 是一个由对象组成的数组或一个数组。数组中的每个项都可以包含深层嵌套的子数组和子对象，还可以包含数字、字符串、布尔值和空值。

矩阵 `m` 的第一行应该是列名。如果没有嵌套，列名是对象中的唯一键；如果存在嵌套，列名是对象中相应路径，以点号 `.` 分隔。

剩余的每一行对应 `arr` 中的一个对象。矩阵中的每个值对应对象中的一个值。如果给定对象在给定列中没有值，则应该包含空字符串 `""`。

矩阵中的列应按 **字典序升序** 排列。

**示例 1：**

```
输入：
arr = [
  {"b": 1, "a": 2},
  {"b": 3, "a": 4}
]
输出：
[
  ["a", "b"],
  [2, 1],
  [4, 3]
]
解释：
两个对象中有两个唯一的列名："a"和"b"。
"a"对应 [2, 4]。
"b"对应 [1, 3]。
```

**示例 2：**

```
输入：
arr = [
  {"a": 1, "b": 2},
  {"c": 3, "d": 4},
  {}
]
输出：
[
  ["a", "b", "c", "d"],
  [1, 2, "", ""],
  ["", "", 3, 4],
  ["", "", "", ""]
]
解释：
有四个唯一的列名："a"、"b"、"c"、"d"。
第一个对象具有与 "a" 和 "b" 关联的值。
第二个对象具有与 "c" 和 "d" 关联的值。
第三个对象没有键，因此只是一行空字符串。
```

**示例 3：**

```
输入：
arr = [
  {"a": {"b": 1, "c": 2}},
  {"a": {"b": 3, "d": 4}}
]
输出：
[
  ["a.b", "a.c", "a.d"],
  [1, 2, ""],
  [3, "", 4]
]
解释：
在这个例子中，对象是嵌套的。键表示每个值的完整路径，路径之间用句点分隔。
有三个路径："a.b"、"a.c"、"a.d"。
```

**示例 4：**

```
输入：
arr = [
  [{"a": null}],
  [{"b": true}],
  [{"c": "x"}]
]
输出：
[
  ["0.a", "0.b", "0.c"],
  [null, "", ""],
  ["", true, ""],
  ["", "", "x"]
]
解释：
数组也被视为具有索引为键的对象。
每个数组只有一个元素，所以键是 "0.a"、"0.b" 和 "0.c"。
```

**示例 5：**

```
输入：
arr = [
  {},
  {},
  {}
]
输出：
[
  [],
  [],
  [],
  []
]
解释：
没有键，所以每一行都是一个空数组。
```

**提示：**

- `arr` 是一个有效的 JSON 数组
- `1 <= arr.length <= 1000`
- `unique keys <= 1000`

## 题解

::: details 点击查看题解

### 思路

整体策略是先把每个对象摊平成「点分路径 -> 叶子值」的键值对，再对全部路径去重排序当表头，最后按表头逐行取值，缺失的补空字符串。

摊平用深度优先递归：下钻时把父路径与当前键用 `.` 拼起来，遇到原始值（数字、字符串、布尔、null）就产出一条记录；数组同样按下标当键处理，所以示例 4 会出现 `0.a` 这样的列名。

手工分层拼路径容易漏掉「对象里套数组再套对象」的组合，DFS 只关心「到叶子为止的完整路径」，天然覆盖任意嵌套。

列名收集后用 `Set` 去重、`sort()` 排序——默认字典序正是题目要求的升序（按 UTF-16 码元逐字符比较）。

取值时每行先建一张路径到值的映射，再按表头顺序查表，查不到写 `""`。判断「有没有值」要用 `hasOwnProperty` 而不是 `in`，否则路径撞上原型链上的名字会误判；也不能直接判 `undefined`，因为合法 JSON 叶子只会是 null 等具体值，判空串即可区分缺失。

注意空对象、空数组不会产生任何叶子，所以列名里不会有它们的位置；示例 5 四行全空正是由此而来。

### 代码实现

```javascript
var jsonToMatrix = function (arr) {
  // 深度优先把每个叶子展开成「点分路径 -> 值」的记录
  const dfs = (prefix, node) => {
    const type = typeof node;
    if (
      node === null ||
      type === "number" ||
      type === "string" ||
      type === "boolean"
    ) {
      return [{ path: prefix, value: node }];
    }
    const res = [];
    // 数组按下标当键，对象按自身键遍历
    const keys = Array.isArray(node)
      ? node.map((_, i) => i)
      : Object.keys(node);
    for (const key of keys) {
      const path = prefix ? `${prefix}.${key}` : `${key}`;
      res.push(...dfs(path, node[key]));
    }
    return res;
  };

  const rows = arr.map((obj) => dfs("", obj));

  // 全部路径去重后按字典序升序作为表头
  const keySet = new Set();
  for (const row of rows) {
    for (const { path } of row) keySet.add(path);
  }
  const columns = [...keySet].sort();

  const matrix = [columns];
  for (const row of rows) {
    const map = Object.fromEntries(row.map(({ path, value }) => [path, value]));
    matrix.push(
      columns.map((path) =>
        Object.prototype.hasOwnProperty.call(map, path) ? map[path] : ""
      )
    );
  }
  return matrix;
};
```

### 复杂度分析

- 时间复杂度：O(L + C log C + R × C)，L 为叶子总数、C 为唯一列数、R 为行数（摊平 O(L)、排序 O(C log C)、填表 O(R × C)）。
- 空间复杂度：O(L + R × C)，保存中间映射与结果矩阵。
