# 将 undefined 转为 null

> 难度：中等 | 标签：递归、对象、undefined | LeetCode 2775（VIP 专属题） · [原题链接](https://leetcode.cn/problems/undefined-to-null/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

给定一个深层嵌套的对象或数组 `obj`，创建该对象 `obj` 的副本，将其中的任何 `undefined` 值替换为 `null`。

当使用 `JSON.stringify()` 将对象转换为 JSON 字符串时，`undefined` 值与 `null` 值的处理方式不同：前者会被直接丢弃（对象键消失、数组元素变 `null`），后者会原样保留。该函数有助于确保序列化数据不会出现意外错误。

**示例 1：**

```
输入：obj = {"a": undefined, "b": 3}
输出：{"a": null, "b": 3}
解释：obj.a 的值已从 undefined 更改为 null。
```

**示例 2：**

```
输入：obj = {"a": undefined, "b": ["a", undefined]}
输出：{"a": null, "b": ["a", null]}
解释：obj.a 和 obj.b[1] 的值已从 undefined 更改为 null。
```

**提示：**

- `obj` 是一个有效的 JSON 对象或数组
- `2 <= JSON.stringify(obj).length <= 10^5`

## 题解

::: details 点击查看题解

### 思路

整体策略是递归重建：遍历每个键，值是容器就先递归拿到处理好的副本，否则按「undefined 换 null、其余原样」写入，最后返回新容器。

题目要求「创建副本」，所以不要在原对象上原地改——用 `{}`/`[]` 逐键写入新结构，入参保持不变。

判定顺序有讲究：先看是不是容器再看是不是 `undefined`。因为 `typeof undefined === "undefined"` 而 `typeof null === "object"`，容器判断必须显式排除 `null`，否则会把 `null` 递归进去遍历出错。

`undefined` 只可能出现在叶子槽位（对象的属性值、数组的元素），容器本身不可能是 `undefined`，所以「递归结果」与「undefined 替换」两个分支天然互斥，用 `if / else if` 串联即可。

数组用 `for...in` 同样能覆盖下标——它遍历的是自有可枚举键，数组的每个元素下标正是这样的键，稀疏槽位（本题不会出现）才会被跳过。

不要图省事走 `JSON.parse(JSON.stringify(obj))`：那会把对象属性里的 `undefined` 直接丢键，而本题恰恰要求它变成 `null` 后保留，方向正好相反。

### 代码实现

```javascript
var undefinedToNull = function (obj) {
  const res = Array.isArray(obj) ? [] : {};
  for (const key in obj) {
    const value = obj[key];
    if (value !== null && typeof value === "object") {
      res[key] = undefinedToNull(value); // 容器递归复制
    } else if (value === undefined) {
      res[key] = null; // 叶子槽位：undefined 统一换成 null
    } else {
      res[key] = value;
    }
  }
  return res;
};
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点只被访问一次。
- 空间复杂度：O(n)，递归栈与新副本的结构开销。
