# 深度合并两个对象

> 难度：中等 | 标签：递归、对象、合并 | LeetCode 2755（VIP 专属题） · [原题链接](https://leetcode.cn/problems/deep-merge-of-two-objects/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

给定两个值 `obj1` 和 `obj2`，返回一个 **深度合并** 的值。

你应该遵循以下规则进行值的 **深度合并**：

- 如果两个值都是对象，则结果对象应包含两个对象上存在的所有键。
- 如果一个键同时存在于两个对象中，则 **深度合并** 两个关联的值。否则，将键值对添加到结果对象中。
- 如果两个值都是数组，则结果数组的长度应与较长的数组相同。对于对象的合并逻辑，将索引视为键。
- 否则，结果值为 `obj2`。

你可以假设 `obj1` 和 `obj2` 是 `JSON.parse()` 的输出结果。

**示例 1：**

```
输入：obj1 = {"a": 1, "c": 3}, obj2 = {"a": 2, "b": 2}
输出：{"a": 2, "c": 3, "b": 2}
解释：obj1["a"] 的值变为 2，因为如果两个对象具有相同的键且它们的值不是数组或对象，则将 obj1 的值更改为 obj2 的值。键 "b" 和其值被添加到结果中，因为它在 obj1 中不存在。
```

**示例 2：**

```
输入：obj1 = [{}, 2, 3], obj2 = [[], 5]
输出：[[], 5, 3]
解释：result[0] = obj2[0]，因为 obj1[0] 和 obj2[0] 类型不同。result[2] = obj1[2]，因为 obj2[2] 不存在。
```

**示例 3：**

```
输入：
obj1 = {"a": 1, "b": {"c": [1, [2, 7], 5], "d": 2}},
obj2 = {"a": 1, "b": {"c": [6, [6], [9]], "e": 3}}
输出：{"a": 1, "b": {"c": [6, [6, 7], [9]], "d": 2, "e": 3}}
解释：数组 obj1["b"]["c"] 和 obj2["b"]["c"] 已合并，如果 obj2 的值不是数组或对象，则深度覆盖 obj1 的值。obj2["b"]["c"] 有键 "e"，而 obj1 中没有，所以将其添加到结果中。
```

**示例 4：**

```
输入：obj1 = true, obj2 = null
输出：null
```

**提示：**

- `obj1` 和 `obj2` 都是有效的 JSON 值
- `1 <= JSON.stringify(obj1).length <= 5 * 10^5`
- `1 <= JSON.stringify(obj2).length <= 5 * 10^5`

## 题解

::: details 点击查看题解

### 思路

整体策略是递归合并：两个值都是容器且类型一致时逐键深合并，其余情况一律以 `obj2` 为准——这正对应题目的第四条规则「否则，结果值为 `obj2`」。

先做两道类型闸门：任一方不是对象（标量、null）直接返回 `obj2`（示例 4 的 `true` 与 `null` 得到 `null`）；一方是数组另一方是对象也直接返回 `obj2`（示例 2 的 `{}` 与 `[]`，`result[0]` 取了 `[]`）。

键的三种归属各有去处：只在 `obj1` 里的键靠「先拷贝 `obj1`」自动保留（示例 1 的 `"c"`、示例 2 的下标 2）；只在 `obj2` 里的键由循环补进来（入口 `deepMerge(undefined, v)` 不满足容器条件，直接返回 `v`，示例 1 的 `"b"`）；双方都有的键才真正递归合并。

数组合并按「较长者长度为准」：以 `obj1` 的副本为底，遍历 `obj2` 的下标逐个覆盖，`obj2` 更长则多出的下标被补进来，`obj1` 更长则尾部保留，天然得到较长数组的长度。

对象合并先拷贝 `obj1` 再写入 `obj2` 的键：`obj2` 独有的键直接新增（示例 1 的 `"b"`），双方都有的键递归合并，嵌套层（示例 3 的 `"b"`、`"c"`、内层 `[2, 7]` 与 `[6]`）逐层套用同一套规则。

用副本而不是原地改 `obj1`，可以避免污染入参；标量与 `null` 的判定必须先于 `Array.isArray` 之外的所有逻辑，`typeof null === "object"` 是这里最常见的坑。

### 代码实现

```javascript
var deepMerge = function (obj1, obj2) {
  const isObj = (v) => v !== null && typeof v === "object";

  // 规则四：任一方不是对象、或一方数组一方对象 → 结果直接取 obj2
  if (!isObj(obj1) || !isObj(obj2)) return obj2;
  if (Array.isArray(obj1) !== Array.isArray(obj2)) return obj2;

  // 以 obj1 的副本为底，逐键覆盖 / 递归合并 obj2
  const result = Array.isArray(obj1) ? [...obj1] : { ...obj1 };
  for (const key of Object.keys(obj2)) {
    result[key] = deepMerge(result[key], obj2[key]);
  }
  return result;
};
```

### 复杂度分析

- 时间复杂度：O(n)，n 为合并后结构的节点数，每个节点只被访问一次。
- 空间复杂度：O(n)，结果是一份新结构（仅复制被触及的容器层，子结构按需共享）。
