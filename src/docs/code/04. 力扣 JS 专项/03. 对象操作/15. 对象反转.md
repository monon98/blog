# 对象反转

> 难度：简单 | 标签：对象、键值对、数组 | LeetCode 2822（VIP 专属题） · [原题链接](https://leetcode.cn/problems/inversion-of-object/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

给定一个对象 `obj`，返回一个反转的对象 `invertedObj`。

`invertedObj` 应该以 `obj` 的键作为值，以 `obj` 的值作为键。题目保证 `obj` 中的值仅为字符串。该函数应该处理重复值，也就是说，如果在 `obj` 中有多个具有相同值的键，那么 `invertedObj` 应该将该值映射到一个包含所有相应键的数组中。

**示例 1：**

```
输入：obj = {"a": "1", "b": "2", "c": "3", "d": "4"}
输出：invertedObj = {"1": "a", "2": "b", "3": "c", "4": "d"}
解释：obj 中的键变成 invertedObj 中的值，而 obj 中的值变成 invertedObj 中的键。
```

**示例 2：**

```
输入：obj = {"a": "1", "b": "2", "c": "2", "d": "4"}
输出：invertedObj = {"1": "a", "2": ["b", "c"], "4": "d"}
解释：在 obj 中有两个具有相同值的键，invertedObj 将该值映射到一个包含所有对应键的数组中。
```

**示例 3：**

```
输入：obj = ["1", "2", "3", "4"]
输出：invertedObj = {"1": "0", "2": "1", "3": "2", "4": "3"}
解释：数组也是对象，因此数组已经转换为一个对象，obj 中的键（索引）变成了 invertedObj 中的值，而 obj 中的值变成了 invertedObj 中的键。
```

**提示：**

- `obj` 是一个有效的 JSON 对象
- `typeof obj[key] === "string"`
- `2 <= JSON.stringify(obj).length <= 10^5`

## 题解

::: details 点击查看题解

### 思路

整体策略是单遍扫描：遍历 `obj` 的每个键，把「原值」当新键、「原键」当新值写进结果，重复值就地升级成数组。

同一个值出现三次以上时要有三态：首次写标量、第二次改成 `[旧键, 新键]`、之后往数组 `push`。用 `Array.isArray` 判断当前存的是标量还是数组即可覆盖全部情况。

判「这个值出现过没有」要用 `hasOwnProperty`：结果对象的值是任意字符串，可能撞上 `constructor`、`toString` 这类原型链上的名字，用 `in` 或直接读取会拿到原型成员而误判。

数组天然满足题意——`Object.keys(["1", "2"])` 得到下标 `"0"`、`"1"`，按同样逻辑反转后正是示例 3 的 `{"1": "0", "2": "1", ...}`，不需要为数组单开分支。

第一次写入用 `Object.defineProperty` 更稳：当反转后的键是 `__proto__` 时普通赋值会触发原型 setter，键会凭空消失。

时间上每个键只处理一次；空间上结果规模与原对象相同（键值对数量守恒，重复值会让部分条目从标量变数组，但总元素数不变）。

### 代码实现

```javascript
var invertObject = function (obj) {
  const inverted = {};
  for (const key of Object.keys(obj)) {
    const value = obj[key]; // 题目保证值是字符串，天然适合作键
    if (!Object.prototype.hasOwnProperty.call(inverted, value)) {
      // 首次出现：值 -> 键
      Object.defineProperty(inverted, value, {
        value: key,
        writable: true,
        enumerable: true,
        configurable: true,
      });
    } else if (Array.isArray(inverted[value])) {
      inverted[value].push(key); // 第三次及以后：追加
    } else {
      inverted[value] = [inverted[value], key]; // 第二次：升级为数组
    }
  }
  return inverted;
};
```

### 复杂度分析

- 时间复杂度：O(n)，n 为 `obj` 的键数量，每键只遍历一次。
- 空间复杂度：O(n)，保存全部键值对（顺序与原对象一致）。
