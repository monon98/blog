# 深度对象筛选

> 难度：中等 | 标签：递归、对象、筛选 | LeetCode 2823（VIP 专属题） · [原题链接](https://leetcode.cn/problems/deep-object-filter/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

给定一个对象 `obj` 和一个函数 `fn`，返回一个经过筛选的对象 `filteredObject`。

函数 `deepFilter` 应该在对象 `obj` 上执行深度筛选操作。深度筛选操作应该移除筛选函数 `fn` 输出为 `false` 的属性，以及在键被移除后仍然存在的任何空对象或数组。

如果深度筛选操作导致对象或数组为空，没有剩余属性，`deepFilter` 应该返回 `undefined`，表示在 `filteredObject` 中没有有效数据。

**示例 1：**

```
输入：
obj = [-5, -4, -3, -2, -1, 0, 1],
fn = (x) => x > 0
输出：[1]
解释：所有不大于 0 的值都被移除。
```

**示例 2：**

```
输入：
obj = {"a": 1, "b": "2", "c": 3, "d": "4", "e": 5, "f": 6, "g": {"a": 1}},
fn = (x) => typeof x === "string"
输出：{"b":"2","d":"4"}
解释：所有值不是字符串的键都被移除。在筛选过程中移除键后，任何导致为空的对象也被移除。
```

**示例 3：**

```
输入：
obj = [-1, [-1, -1, 5, -1, 10], -1, [-1], [-5]],
fn = (x) => x > 0
输出：[[5,10]]
解释：所有不大于 0 的值都被移除。在筛选过程中移除值后，任何导致为空的数组也被移除。
```

**示例 4：**

```
输入：
obj = [[[[5]]]],
fn = (x) => Array.isArray(x)
输出：undefined
```

**提示：**

- `fn` 是一个返回布尔值的函数
- `obj` 是一个有效的 JSON 对象
- `2 <= JSON.stringify(obj).length <= 10^5`

## 题解

::: details 点击查看题解

### 思路

整体策略是后序递归：先让子节点各自筛选，再用 `undefined` 表示「这一支被清空了」，父层据此决定丢弃；只有原始值才真正交给 `fn` 判定。

数组分支对每个元素递归、过滤掉返回 `undefined` 的项，剩下的长度为 0 就整体返回 `undefined`（示例 3 的 `[-1]`、`[-5]` 连同根层的散装 `-1` 一起消失，只剩 `[[5, 10]]`）。

对象分支逐键递归，值为 `undefined` 的键不写入新对象，收尾时对象没有任何键就返回 `undefined`（示例 2 的 `"g"` 因内层被清空而整个消失）。

`undefined` 是唯一的「删除」信号，所以容器判空必须放在递归之后：容器本身不会是 `undefined`，两者不会混淆，而叶子被 `fn` 拒绝时正好复用同一个信号。

`null` 要走叶子分支而不是容器分支——`typeof null === "object"`，容器判断必须显式排除它，否则会对 `null` 展开遍历；排除后 `null` 与数字、字符串一样交给 `fn` 决定去留。

示例 4 是这条规则的极端情形：`Array.isArray` 只对叶子 `5` 返回 `false`，于是逐层清空，最终根节点返回 `undefined`。

`fn` 只在叶子上调用一次，容器永远不参与判定，这也保证了「移除后再判空」的语义顺序。

### 代码实现

```javascript
var deepFilter = function (obj, fn) {
  const dfs = (node) => {
    if (Array.isArray(node)) {
      const res = node.map(dfs).filter((v) => v !== undefined);
      return res.length > 0 ? res : undefined; // 被清空的数组整体丢弃
    }
    if (node !== null && typeof node === "object") {
      const res = {};
      for (const key of Object.keys(node)) {
        const value = dfs(node[key]);
        if (value !== undefined) res[key] = value;
      }
      return Object.keys(res).length > 0 ? res : undefined;
    }
    return fn(node) ? node : undefined; // 叶子交给筛选函数
  };

  return dfs(obj);
};
```

### 复杂度分析

- 时间复杂度：O(n)，每个节点递归一次，`fn` 只对叶子调用一次。
- 空间复杂度：O(n)，递归栈与筛选后的新结构（不会超过原结构大小）。
