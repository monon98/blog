# 完全相等的 JSON 对象

> 难度：中等 | 标签：递归、深比较、JSON | LeetCode 2628（VIP 专属题） · [原题链接](https://leetcode.cn/problems/json-deep-equal/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

请实现函数 `areDeeplyEqual(o1, o2)`，给定两个值 `o1` 和 `o2`，返回一个布尔值，表示两个值是否 **完全相等**。

对于两个 **完全相等** 的值，必须满足以下条件：

- 如果两个值都是原始类型，它们通过了 `===` 等式检查，则认为这两个值是 **完全相等** 的。
- 如果两个值都是数组，当它们具有相同元素且顺序相同，并且每个元素在这些条件下也 **完全相等** 时，认为这两个值是 **完全相等** 的。
- 如果两个值都是对象，当它们具有相同键，并且每个键关联的值在这些条件下也 **完全相等** 时，认为这两个值是 **完全相等** 的。

你可以假设这两个值都是 `JSON.parse` 的输出。换句话说，它们是有效的 `JSON`。

请你在不使用 lodash 的 `_.isEqual()` 函数的前提下解决这个问题。

**示例 1：**

```
输入：o1 = {"x":1,"y":2}, o2 = {"x":1,"y":2}
输出：true
解释：键和值完全匹配。
```

**示例 2：**

```
输入：o1 = {"y":2,"x":1}, o2 = {"x":1,"y":2}
输出：true
解释：尽管键的顺序不同，但它们仍然完全匹配。
```

**示例 3：**

```
输入：o1 = {"x":null,"L":[1,2,3]}, o2 = {"x":null,"L":["1","2","3"]}
输出：false
解释：数字数组不同于字符串数组。
```

**示例 4：**

```
输入：o1 = true, o2 = false
输出：false
解释：true !== false
```

**提示：**

- `1 <= JSON.stringify(o1).length <= 10^5`
- `1 <= JSON.stringify(o2).length <= 10^5`
- `maxNestingDepth <= 1000`

## 题解

::: details 点击查看题解

### 思路

整体策略是递归三段式：原始值直接严格相等收尾；类型不同立即判 false；类型一致时再按下标（数组）或按键（对象）递归比较。

入参保证是 `JSON.parse` 的输出，所以不存在 `Date`、`RegExp`、`NaN`、循环引用和 `undefined` 键，不必像通用深比较那样用 `Object.is` 特判 `NaN !== NaN` 的陷阱。

类型剪枝要分两层：先用 `typeof` 排掉「原始值 vs 对象」的混搭，再用 `Array.isArray` 区分数组与普通对象——只靠 `typeof` 分不出这两者，数组和对象都返回 `object`。

数组按下标对齐递归，长度不同直接返回 false；对象先比 `Object.keys` 的键数，再逐个键递归。键顺序不影响结果：键数相同且每个键的值都相等，两组键集合必然一致。

「先比长度/键数、再逐项递归」是双重剪枝：大多数不相等的输入在浅层就被挡下，不会白白递归到叶子，代价只有一次线性扫描。

扩展到通用深比较时还有几个边角：`NaN` 要用 `Object.is` 才能判相等；`Date` 比时间戳、`RegExp` 比源串；类型判定用 `Object.prototype.toString.call` 比 `instanceof` 可靠（跨 iframe 时 `instanceof` 会失效）；循环引用要用记录路径的 `WeakSet` 挡住，进入子级前添加、离开后删除。本题都用不上，但面试常被追问。

这类函数的应用场景：React `memo`/`useMemo` 的自定义比较（浅比较不够时）、测试断言库的深相等断言。

### 代码实现

```javascript
var areDeeplyEqual = function (o1, o2) {
  // 原始值与 null：直接严格相等（null 也会落到这里）
  if (o1 === null || typeof o1 !== "object") return o1 === o2;
  // o1 是对象而 o2 不是，直接判不等
  if (typeof o2 !== "object") return false;
  // 数组与普通对象不能互等
  if (Array.isArray(o1) !== Array.isArray(o2)) return false;

  if (Array.isArray(o1)) {
    if (o1.length !== o2.length) return false;
    for (let i = 0; i < o1.length; i++) {
      if (!areDeeplyEqual(o1[i], o2[i])) return false;
    }
    return true;
  }

  const keys1 = Object.keys(o1);
  const keys2 = Object.keys(o2);
  if (keys1.length !== keys2.length) return false;
  for (const key of keys1) {
    if (!areDeeplyEqual(o1[key], o2[key])) return false;
  }
  return true;
};
```

### 复杂度分析

- 时间复杂度：O(n)，n 为序列化后的总长度，每个节点只被访问一次。
- 空间复杂度：O(d)，d 为最大嵌套深度（递归调用栈），提示给出上限 1000。
