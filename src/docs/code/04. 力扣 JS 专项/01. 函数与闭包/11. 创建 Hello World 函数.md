# 创建 Hello World 函数

> 难度：简单 | 标签：闭包、高阶函数 | LeetCode 2667 · [原题链接](https://leetcode.cn/problems/create-hello-world-function/)

## 题目描述

请你编写一个名为 `createHelloWorld` 的函数。它应该返回一个新的函数，该函数总是返回 `"Hello World"`。

**示例 1：**

```
输入：args = []
输出："Hello World"
解释：
const f = createHelloWorld();
f(); // "Hello World"

createHelloWorld 返回的函数应始终返回 "Hello World"。
```

**示例 2：**

```
输入：args = [{},null,42]
输出："Hello World"
解释：
const f = createHelloWorld();
f({}, null, 42); // "Hello World"

可以传递任何参数给函数，但它应始终返回 "Hello World"。
```

**提示：**

- `0 <= args.length <= 10`

## 题解

::: details 点击查看题解

### 思路

考察的是高阶函数的最基本形态：函数作为返回值。外层 `createHelloWorld` 不做事，只负责产出内层函数。

内层必须能接收任意参数且全部忽略，所以用剩余参数 `...args` 收集——测试可能传 0 个到任意多个参数，不声明形参也能直接忽略，写上 `...args` 更直观地表达「接受任意参数」。

返回值是带空格的字符串字面量 `"Hello World"`，注意别写成没有空格或写成模板串拼错。

`createHelloWorld` 每次调用都返回一个功能相同的新函数，彼此独立，这是无状态函数的典型特征。

### 代码实现

```javascript
/**
 * @return {Function}
 */
var createHelloWorld = function() {
  // 返回的函数接收任意参数，但一律忽略
  return function(...args) {
    return "Hello World";
  };
};
```

### 复杂度分析

- 时间复杂度：O(1)，每次调用只返回常量字符串。
- 空间复杂度：O(1)。

:::
