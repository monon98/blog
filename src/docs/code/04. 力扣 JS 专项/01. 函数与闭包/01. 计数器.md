# 计数器

> 难度：简单 | 标签：闭包、高阶函数 | LeetCode 2620 · [原题链接](https://leetcode.cn/problems/counter/)

## 题目描述

给定一个整型参数 `n`，请你编写并返回一个 `counter` 函数。这个 `counter` 函数最初返回 `n`，每次调用它时会返回前一个值加 1 的值 ( `n` ,  `n + 1` ,  `n + 2`，等等)。

**示例 1：**

```
输入：
n = 10 
["call","call","call"]
输出：[10,11,12]
解释：
counter() = 10 // 第一次调用 counter()，返回 n。
counter() = 11 // 返回上次调用的值加 1。
counter() = 12 // 返回上次调用的值加 1。
```

**示例 2：**

```
输入：
n = -2
["call","call","call","call","call"]
输出：[-2,-1,0,1,2]
解释：counter() 最初返回 -2。然后在每个后续调用后增加 1。
```

**提示：**

- `-1000 <= n <= 1000`
- `0 <= calls.length <= 1000`
- `calls[i] === "call"`

## 题解

::: details 点击查看题解

### 思路

最基础的闭包题：外层 `createCounter` 只执行一次，返回的内部函数通过闭包共享同一个计数变量，跨调用保留状态。

关键是用后置自增 `current++`——它先返回当前值再加 1，第一次调用正好返回 `n`；如果写成 `++current`，首次会返回 `n + 1`。

初始值不能直接写进返回函数里（每次调用都会重置），必须声明在外层作用域。

闭包在这里充当了「对象的私有字段」，外部拿不到也改不了 `current`，只能通过 `counter()` 间接推进。

### 代码实现

```javascript
/**
 * @param {number} n
 * @return {Function} counter
 */
var createCounter = function(n) {
  // 闭包保存当前计数值，外部无法直接访问
  let current = n;

  return function() {
    // 后置自增：先返回旧值，再加 1
    return current++;
  };
};
```

### 复杂度分析

- 时间复杂度：O(1)，每次调用只做一次读取与自增。
- 空间复杂度：O(1)，只额外保存一个计数变量（不计入调用栈）。
