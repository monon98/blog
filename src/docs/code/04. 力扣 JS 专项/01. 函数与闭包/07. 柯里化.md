# 柯里化

> 难度：中等 | 标签：闭包、高阶函数、函数式 | LeetCode 2632（VIP 专属题） · [原题链接](https://leetcode.cn/problems/curry/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

请你编写一个函数，它接收一个其他的函数，并返回该函数的 **柯里化** 后的形式。

**柯里化** 函数的定义是接受与原函数相同数量或更少数量的参数，并返回另一个 **柯里化** 后的函数或与原函数相同的值。

实际上，当你调用原函数，如 `sum(1,2,3)` 时，它将调用 **柯里化** 函数的某个形式，如 `csum(1)(2)(3)`、`csum(1,2)(3)`、`csum(1)(2,3)` 或 `csum(1,2,3)`。所有调用 **柯里化** 函数的方法都应该返回与原始函数相同的值。

**示例 1：**

```
输入：
fn = function sum(a, b, c) { return a + b + c; }
inputs = [[1],[2],[3]]
输出：6
解释：
执行的代码是：
const curriedSum = curry(fn);
curriedSum(1)(2)(3) === 6;
curriedSum(1)(2)(3) 应该返回像原函数 sum(1, 2, 3) 一样的值。
```

**示例 2：**

```
输入：
fn = function sum(a, b, c) { return a + b + c; }
inputs = [[1,2],[3]]
输出：6
解释：
curriedSum(1, 2)(3) 应该返回像原函数 sum(1, 2, 3) 一样的值。
```

**示例 3：**

```
输入：
fn = function sum(a, b, c) { return a + b + c; }
inputs = [[],[],[1,2,3]]
输出：6
解释：
你应该能够以任何方式传递参数，包括一次性传递所有参数或完全不传递参数。
curriedSum()()(1, 2, 3) 应该返回像原函数 sum(1, 2, 3) 一样的值。
```

**示例 4：**

```
输入：
fn = function life() { return 42; }
inputs = [[]]
输出：42
解释：
柯里化一个没有接收参数、没做有效操作的函数。
curriedLife() === 42
```

**提示：**

- `1 <= inputs.length <= 1000`
- `0 <= inputs[i][j] <= 10^5`
- `0 <= fn.length <= 1000`
- `inputs.flat().length == fn.length`
- 函数参数需要被显式定义
- 如果 `fn.length > 0` 则最后一个数组 `inputs` 不为空
- 如果 `fn.length === 0` 则 `inputs.length === 1`

## 题解

::: details 点击查看题解

### 思路

整体策略：内部定义具名函数 `curried` 递归收集参数，每收到一批先与目标个数比较——够了就 `fn.apply(ctx, args)` 一次执行，不够就再返回一层新函数继续收。

目标个数取 `fn.length`，即「第一个默认参数之前的形参个数」；`fn.length` 不统计剩余参数 `...rest` 和带默认值的参数之后的形参，这是与 lodash / ramda 实现的细微差异点（本题保证参数显式定义，正好规避）。

闭包在这里负责跨调用保存已收集的参数：`curried(1)(2)` 中第一层的 `args = [1]` 必须活到第二次调用。

一次传多个、一次传空、零参函数都统一由「`args.length >= fn.length` 才执行」这条规则覆盖：`csum(1,2)(3)` 攒够 3 个直接执行；`csum()()(1,2,3)` 每层空数组只做续接；`fn.length === 0` 时首次调用即达条件、直接执行原函数。

`this` 要跟着参数一起往后传：把调用时的上下文存下来，在后续续接调用中 `apply`，保证 `curried.call(obj, ...)` 这类用法不丢上下文。

柯里化的价值在于参数复用与延迟执行——先固化一部分输入，再配合 compose / pipe 组装管道；它与偏函数（partial application）的区别是：柯里化逐参求值直至收满，偏函数固定部分参数后一次性调用（本目录的「带有占位符的部分函数」就是带 `_` 占位的偏函数变体）。

### 代码实现

```javascript
/**
 * @param {Function} fn
 * @return {Function}
 */
var curry = function(fn) {
  return function curried(...args) {
    // 记住本次调用的上下文，透传给续接调用
    const ctx = this;
    // 攒够原函数形参个数就执行，否则返回新函数继续收集
    if (args.length >= fn.length) {
      return fn.apply(ctx, args);
    }
    return (...nextArgs) => curried.apply(ctx, args.concat(nextArgs));
  };
};
```

### 复杂度分析

- 时间复杂度：每次续接为 O(k)，k 为已收集参数个数（拼接数组）；总调用次数等于传参批次数。
- 空间复杂度：O(m)，m 为原函数形参个数（闭包累积保存的参数）。
