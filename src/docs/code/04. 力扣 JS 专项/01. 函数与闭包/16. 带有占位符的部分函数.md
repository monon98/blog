# 带有占位符的部分函数

> 难度：简单 | 标签：偏函数、高阶函数、柯里化 | LeetCode 2797（VIP 专属题） · [原题链接](https://leetcode.cn/problems/partial-function-with-placeholders/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

给定函数 `fn` 和数组 `args`，返回一个函数 `partialFn`。`args` 中的占位符 `"_"` 需要用 `restArgs` 中索引从 0 开始的值替换。`restArgs` 中剩余的值则添加到 `args` 的末尾。`partialFn` 应该返回 `fn` 的结果。`fn` 应该使用修改后的 `args` 的元素作为单独的参数调用。

**示例 1：**

```
输入：fn = (...args) => args, args = [2,4,6], restArgs = [8,10]
输出：[2,4,6,8,10]
解释：
const partialFn = partial(fn, args)
const result = partialFn(...restArgs) 
console.log(result) // [2,4,6,8,10]

args 中没有占位符 "_"，因此 restArgs 只是添加到 args 的末尾。然后将 args 的元素作为单独的参数传递给 fn，fn 返回传递的参数作为数组。
```

**示例 2：**

```
输入：fn = (...args) => args, args = [1,2,"_",4,"_",6], restArgs = [3,5]
输出：[1,2,3,4,5,6]
解释：
const partialFn = partial(fn, args) 
const result = partialFn(...restArgs) 
console.log(result) // [1,2,3,4,5,6] 

占位符 "_" 被 restArgs 中的值替换。然后将 args 的元素作为单独的参数传递给 fn，fn 返回传递的参数作为数组。
```

**示例 3：**

```
输入：fn = (a, b, c) => b + a - c, args = ["_", 5], restArgs = [5, 20]
输出：-10
解释：
const partialFn = partial(fn, args)
const result = partialFn(...restArgs)
console.log(result) // -10

占位符 "_" 被替换为 5，并将 20 添加到 args 的末尾。然后将 args 的元素作为单独的参数传递给 fn，fn 返回 -10（5 + 5 - 20）。
```

**提示：**

- `fn` 是一个函数
- `args` 和 `restArgs` 都是有效的 JSON 数组
- `1 <= args.length <= 5 * 10^4`
- `1 <= restArgs.length <= 5 * 10^4`
- `0 <= 占位符个数 <= restArgs.length`

## 题解

::: details 点击查看题解

### 思路

这是带占位符的部分应用（partial application）：`partial` 返回一个新函数，把「模板参数 `args`」与「调用时参数 `restArgs`」合并成最终实参列表。

合并分两步：先从左到右扫描 `args`，遇到 `"_"` 就按顺序从 `restArgs` 里取一个值补上（示例 2 的两个占位符分别吃掉 3 和 5，游标 `i` 一路前进）；扫描结束后 `restArgs` 还没用完的值整体追加到末尾（示例 1 没有占位符，`i` 从 0 开始，全部追加）。

占位符个数可能少于 `restArgs` 长度，也可能为 0，两种游标逻辑统一由同一个 `i` 串起来，不需要分支特判。

一个容易被忽略的坑：不要直接修改传入的 `args` 数组（参考实现里 `args.push(...)` 就是就地改）——`partial` 返回的函数可能被调用多次，或同一 `args` 被复用，污染原数组会串数据；先 `[...args]` 复制一份再动手。

最终用 `fn.apply(this, params)` 把元素「作为单独的参数」传给 `fn`，`this` 一并透传（箭头函数写的 `fn` 不受影响）。

它与柯里化的分工：柯里化逐批收参直到收满（见本目录的「柯里化」），部分函数一次性固定一批模板参数；占位符 `_` 正是 lodash `_.partial` 的能力，普通 `bind` 无法表达。

### 代码实现

```javascript
/**
 * @param {Function} fn
 * @param {Array} args
 * @return {Function}
 */
var partial = function(fn, args) {
  return function(...restArgs) {
    // 复制模板数组，避免污染调用方传入的 args
    const params = [...args];
    let i = 0; // restArgs 的消费游标

    // 第一步：按顺序用 restArgs 替换占位符 "_"
    for (let j = 0; j < params.length; j++) {
      if (params[j] === "_") {
        params[j] = restArgs[i++];
      }
    }

    // 第二步：restArgs 剩余的值追加到末尾
    while (i < restArgs.length) {
      params.push(restArgs[i++]);
    }

    // 元素作为单独的参数传给原函数
    return fn.apply(this, params);
  };
};
```

### 复杂度分析

- 时间复杂度：O(m + n)，m 为 `args` 长度、n 为 `restArgs` 长度（一次扫描 + 一次追加）。
- 空间复杂度：O(m + n)，复制出的合并后实参列表。
