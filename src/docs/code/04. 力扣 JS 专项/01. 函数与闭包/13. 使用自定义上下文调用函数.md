# 使用自定义上下文调用函数

> 难度：中等 | 标签：this、Function、原型 | LeetCode 2693 · [原题链接](https://leetcode.cn/problems/call-function-with-custom-context/)

## 题目描述

增强所有函数，使其具有 `callPolyfill` 方法。该方法接受一个对象 `obj` 作为第一个参数，以及任意数量的附加参数。`obj` 成为函数的 `this` 上下文。附加参数将传递给该函数（即 `callPolyfill` 方法所属的函数）。

例如，如果有以下函数：

```
function tax(price, taxRate) {
  const totalCost = price * (1 + taxRate);
  console.log(`The cost of ${this.item} is ${totalCost}`);
}
```

调用 `tax(10, 0.1)` 将输出 `"The cost of undefined is 11"`。这是因为 `this` 上下文未定义。

然而，调用 `tax.callPolyfill({item: "salad"}, 10, 0.1)` 将输出 `"The cost of salad is 11"`。`this` 上下文被正确设置，函数输出了适当的结果。

请在不使用内置的 `Function.call` 方法的情况下解决这个问题。

**示例 1：**

```
输入：
fn = function add(b) {
  return this.a + b;
}
args = [{"a": 5}, 7]
输出：12
解释：
fn.callPolyfill({"a": 5}, 7); // 12
callPolyfill 将 "this" 上下文设置为 {"a": 5} ，并将 7 作为参数传递。
```

**示例 2：**

```
输入：
fn = function tax(price, taxRate) { 
 return `The cost of the ${this.item} is ${price * taxRate}`; 
}
args = [{"item": "burger"}, 10, 1.1]
输出："The cost of the burger is 11"
解释：callPolyfill 将 "this" 上下文设置为 {"item": "burger"} ，并将 10 和 1.1 作为附加参数传递。
```

**提示：**

- `typeof args[0] == 'object' and args[0] != null`
- `1 <= args.length <= 100`
- `2 <= JSON.stringify(args[0]).length <= 10^5`

## 题解

::: details 点击查看题解

### 思路

核心技巧是「属性挂载」：把函数临时挂到目标对象的一个属性上再以 `obj[key](...args)` 的方式调用——方法调用的隐式绑定规则会让 `this` 自然指向宿主对象，等于手工复刻了 `call`。

签名上 `callPolyfill` 是挂在 `Function.prototype` 上的方法，所以它内部的 `this` 就是被调用的原函数，第一个形参才是要绑定的 `obj`，其余 `...args` 是原函数的实参。

属性名必须用 `Symbol`：独一无二，绝不会撞上对象已有属性，也天然不可枚举，遍历对象时看不见它。

调用完立刻 `delete context[key]`，保证不留任何痕迹——这是「不产生副作用」的考点，也是与 ES3 时代 `context.fn = this` + `eval` 老写法的主要差距。

`context` 理论上可能为空（原生 `call` 会兜底到全局对象），本题提示保证第一个参数是非空对象，但留一句 `?? globalThis` 的防御也没坏处。

同一套技巧换个参数形态就是 `apply`：`call(ctx, a, b)` 逐个传，`apply(ctx, [a, b])` 传数组再展开；本题用 rest 收集，等价于 `call` 语义。现代 JS 还有更短的 `Reflect.apply(fn, obj, args)` 可以直接做到，面试时讲清楚两种方案的取舍即可。

### 代码实现

```javascript
/**
 * @param {Object} context
 * @param {Array} args
 * @return {null|boolean|number|string|Array|Object}
 */
Function.prototype.callPolyfill = function(context, ...args) {
  // this 即被调用的原函数；context 是要绑定的 this
  const key = Symbol(); // 独一无二的临时属性名
  context[key] = this;  // 挂载，制造方法调用的隐式绑定
  const result = context[key](...args);
  delete context[key];  // 用完即删，不污染原对象
  return result;
};
```

### 复杂度分析

- 时间复杂度：O(k)，k 为附加参数个数（展开 + 删除各一次），相对原函数执行是常数级附加开销。
- 空间复杂度：O(1)，在 `context` 上临时新增并移除一个属性。
