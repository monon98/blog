# 复合函数

> 难度：简单 | 标签：函数式、高阶函数、reduce | LeetCode 2629 · [原题链接](https://leetcode.cn/problems/function-composition/)

## 题目描述

请你编写一个函数，它接收一个函数数组 `[f_1, f_2, f_3，…， f_n]`，并返回一个新的函数 `fn`，它是函数数组的 **复合函数**。

`[f(x)， g(x)， h(x)]` 的 **复合函数** 为 `fn(x) = f(g(h(x)))`。

一个空函数列表的 **复合函数** 是 **恒等函数** `f(x) = x`。

你可以假设数组中的每个函数接受一个整型参数作为输入，并返回一个整型作为输出。

**示例 1：**

```
输入：functions = [x => x + 1, x => x * x, x => 2 * x], x = 4
输出：65
解释：
从右向左计算......
Starting with x = 4.
2 * (4) = 8
(8) * (8) = 64
(64) + 1 = 65
```

**示例 2：**

```
输入：functions = [x => 10 * x, x => 10 * x, x => 10 * x], x = 1
输出：1000
解释：
从右向左计算......
10 * (1) = 10
10 * (10) = 100
10 * (100) = 1000
```

**示例 3：**

```
输入：functions = [], x = 42
输出：42
解释：空函数列表的复合函数就是恒等函数
```

**提示：**

- `-1000 <= x <= 1000`
- `0 <= functions.length <= 1000`
- 所有函数都接受并返回一个整型

## 题解

::: details 点击查看题解

### 思路

用 `reduceRight` 把函数数组折叠成一个新函数：以初始值 `x` 出发，从数组末尾开始，让「当前函数」吃掉上一轮的结果，天然对应 `f(g(h(x)))` 的执行顺序。

`reduceRight` 不带初始值时空数组会抛错，所以空列表要单独处理，返回恒等函数 `(v) => v`——本题里 `reduceRight` 携带初始值 `x` 时已天然满足，`functions` 为空直接原样返回 `x`。

执行方向是最容易搞混的点：本题 compose 是 **从右向左**；它的逆运算是 pipe（从左向右），`pipe(f, g)(x) === g(f(x))`、`compose(f, g)(x) === f(g(x))`，两者只差一个折叠方向——pipe 可以直接用 `reduce` 写成。

每层只传递一个值（单入单出），这是函数式管道能自由组合的前提；本题也保证每个函数单参单出。

Redux / Express 的中间件洋葱模型，思想源头就是这一组合子。

### 代码实现

```javascript
/**
 * @param {Function[]} functions
 * @return {Function}
 */
var compose = function(functions) {
  return function(x) {
    // 空数组时 reduceRight 直接返回初始值 x，即恒等函数
    // 从右往左折叠：后一个函数先执行
    return functions.reduceRight((acc, fn) => fn(acc), x);
  };
};
```

### 复杂度分析

- 时间复杂度：O(n)，n 为函数个数，每个函数恰好调用一次。
- 空间复杂度：O(1)，只保留一个中间结果（不计函数调用栈）。
