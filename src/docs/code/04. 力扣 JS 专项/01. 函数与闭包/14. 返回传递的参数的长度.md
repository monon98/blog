# 返回传递的参数的长度

> 难度：简单 | 标签：rest 参数、arguments | LeetCode 2703 · [原题链接](https://leetcode.cn/problems/return-length-of-arguments-passed/)

## 题目描述

请你编写一个函数 `argumentsLength`，返回传递给该函数的参数数量。

**示例 1：**

```
输入：args = [5]
输出：1
解释：
argumentsLength(5); // 1

只传递了一个值给函数，因此它应返回 1。
```

**示例 2：**

```
输入：args = [{}, null, "3"]
输出：3
解释：
argumentsLength({}, null, "3"); // 3

传递了三个值给函数，因此它应返回 3。
```

**提示：**

- `args` 是一个有效的 JSON 数组
- `0 <= args.length <= 100`

## 题解

::: details 点击查看题解

### 思路

最直接的考点是「不定参数怎么收」：用剩余参数 `...args` 把所有实参收进一个真正的数组，返回 `args.length` 即可。

`args` 这个入参名只影响测试的描述方式（测试方把实参展开来调用），函数本身拿到的是调用时的全部实参。

另一种等价写法是返回 `arguments.length`——`arguments` 是函数自带的类数组对象，但要注意它在箭头函数里不存在，也不含剩余参数的语义，日常更推荐 `...args`。

参数里可以是 `null`、对象、字符串等任意类型，长度统计与类型无关；0 个参数时返回 0，天然成立。

### 代码实现

```javascript
/**
 * @param {...(null|boolean|number|string|Array|Object)} args
 * @return {number}
 */
var argumentsLength = function(...args) {
  // 剩余参数收集成数组，直接取长度
  return args.length;
};
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(n)，n 为参数个数（收集实参的开销）。
