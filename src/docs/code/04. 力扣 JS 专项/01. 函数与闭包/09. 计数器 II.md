# 计数器 II

> 难度：简单 | 标签：闭包、对象 | LeetCode 2665 · [原题链接](https://leetcode.cn/problems/counter-ii/)

## 题目描述

请你写一个函数 `createCounter`。这个函数接收一个初始的整数值 `init`。并返回一个包含三个函数的对象。

这三个函数是：

- `increment()` 将当前值加 1 并返回。

- `decrement()` 将当前值减 1 并返回。

- `reset()` 将当前值设置为 `init` 并返回。

**示例 1：**

```
输入：init = 5, calls = ["increment","reset","decrement"]
输出：[6,5,4]
解释：
const counter = createCounter(5);
counter.increment(); // 6
counter.reset(); // 5
counter.decrement(); // 4
```

**示例 2：**

```
输入：init = 0, calls = ["increment","increment","decrement","reset","reset"]
输出：[1,2,1,0,0]
解释：
const counter = createCounter(0);
counter.increment(); // 1
counter.increment(); // 2
counter.decrement(); // 1
counter.reset(); // 0
counter.reset(); // 0
```

**提示：**

- `-1000 <= init <= 1000`
- `0 <= calls.length <= 1000`
- `calls[i]` 是 “increment”、“decrement” 和 “reset” 中的一个

## 题解

::: details 点击查看题解

### 思路

与「计数器」同一套路，只是状态多了一个「出厂值」：闭包里同时保存当前值 `current` 和创建时的 `init` 快照。

返回的对象字面量里放三个函数，每个都是直接修改闭包变量的箭头函数——它们不依赖 `this`，谁来调用都不会丢上下文，把对象解构出来调用也依然有效。

`increment` / `decrement` 用前置自增自减 `++current` / `--current`，先改再返回，正好符合「加 1 并返回」的语义。

`reset` 要回到 `init` 并返回它：赋值表达式本身有值，直接 `current = init` 再返回即可；注意 `init` 是数值，闭包里存的就是创建时的快照，不会被后续调用改坏。

三个方法共享同一个闭包，所以互相可见：先 `increment` 再 `reset` 必须回到 `init` 而不是回到递增后的值。

### 代码实现

```javascript
/**
 * @param {integer} init
 * @return { increment: Function, decrement: Function, reset: Function }
 */
var createCounter = function(init) {
  // 闭包保存当前值与出厂值快照
  let current = init;

  return {
    increment: () => ++current,   // 加 1 并返回新值
    decrement: () => --current,   // 减 1 并返回新值
    reset: () => (current = init) // 恢复到 init 并返回
  };
};
```

### 复杂度分析

- 时间复杂度：O(1)，三个方法均为常数次读写。
- 空间复杂度：O(1)，闭包保存两个整数。
