# 检查是否是类的对象实例

> 难度：中等 | 标签：原型链、instanceof | LeetCode 2618 · [原题链接](https://leetcode.cn/problems/check-if-object-instance-of-class/)

## 题目描述

请你编写一个函数，检查给定的值是否是给定类或超类的实例。

可以传递给函数的数据类型没有限制。例如，值或类可能是 `undefined` 。

**示例 1：**

```
输入：func = () => checkIfInstance(new Date(), Date)
输出：true
解释：根据定义，Date 构造函数返回的对象是 Date 的一个实例。
```

**示例 2：**

```
输入：func = () => { class Animal {}; class Dog extends Animal {}; return checkIfInstance(new Dog(), Animal); }
输出：true
解释：
class Animal {};
class Dog extends Animal {};
checkIfInstanceOf(new Dog(), Animal); // true

Dog 是 Animal 的子类。因此，Dog 对象同时是 Dog 和 Animal 的实例。
```

**示例 3：**

```
输入：func = () => checkIfInstance(Date, Date)
输出：false
解释：日期的构造函数在逻辑上不能是其自身的实例。
```

**示例 4：**

```
输入：func = () => checkIfInstance(5, Number)
输出：true
解释：5 是一个 Number。注意，"instanceof" 关键字将返回 false。
```

## 题解

::: details 点击查看题解

### 思路

`instanceof` 的本质就是**沿对象的原型链逐级向上查找，看某一级原型是否全等于构造函数的 `prototype`**——本题要复现的正是这个判定。沿链上溯也顺带解释了为什么 `[] instanceof Object` 为 `true`：`Array.prototype` 的原型是 `Object.prototype`，原型链具有传递性。

不能直接写 `obj instanceof cls`：示例 4 里基本类型 `5` 没有原型链，`5 instanceof Number` 是 `false`，而题目期望 `true`（原始值同样能访问到 Number 的方法，例如 `toFixed()`）。

所以先做边界拒绝：类为 `null` / `undefined`（以及箭头函数这类没有 `prototype` 的目标）直接返回 `false`；`obj` 为 `null` / `undefined` 时循环条件不成立，同样返回 `false`——题面明确说数据类型没有限制，这些都可能作为输入出现。

主循环用 `Object.getPrototypeOf` 逐级上溯（标准 API，比读 `__proto__` 更可靠）：某级原型等于 `cls.prototype` 即返回 `true`；一路走到原型链尽头（`Object.prototype` 的原型是 `null`）仍未命中则返回 `false`。

示例 3 中 `checkIfInstance(Date, Date)` 为 `false`：`Date` 是函数，其原型链是 `Function.prototype → Object.prototype → null`，途中不会出现 `Date.prototype`，循环自然走空；示例 2 的子类对象同理，`Dog` 实例的链上既有 `Dog.prototype` 也有 `Animal.prototype`，因此对两者都成立。

也可以一行判断：`Object(obj) instanceof cls`——`Object(5)` 会把原始值装箱成 `new Number(5)`，装箱对象确实 `instanceof Number`。两种写法等价，原型链上溯的版本更能看清 `instanceof` 的原理，也是手写 `instanceof` 的通用骨架。

边角补充：`Symbol.hasInstance` 允许任意对象自定义 `instanceof` 的行为；`Object.create(null)` 创建的对象没有原型链，对任何类的判定都是 `false`。

### 代码实现

```javascript
var checkIfInstanceOf = function (obj, classFunction) {
  if (classFunction === null || classFunction === undefined) return false;
  while (obj !== null && obj !== undefined) {
    const proto = Object.getPrototypeOf(obj); // 沿原型链上溯，等价于 instanceof 的查找
    if (proto === classFunction.prototype) return true;
    obj = proto;
  }
  return false;
};

// 题面示例中函数名有 checkIfInstance / checkIfInstanceOf 两种写法，补一个别名以兼容
var checkIfInstance = checkIfInstanceOf;
```

### 复杂度分析

- 时间复杂度：O(d)，d 为原型链长度，通常是个位数。
- 空间复杂度：O(1)，只保存当前原型引用。
