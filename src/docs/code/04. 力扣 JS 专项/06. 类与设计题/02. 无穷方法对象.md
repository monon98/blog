# 无穷方法对象

> 难度：简单 | 标签：Proxy、元编程 | LeetCode 2690（VIP 专属题） · [原题链接](https://leetcode.cn/problems/infinite-method-object/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

请你编写一个函数 `createInfiniteObject()`，返回一个 **无穷方法对象** 。

**无穷方法对象** 被定义为一个对象，它允许你调用任何方法，并始终返回方法的名称。

例如，如果执行 `obj.abc123()` ，它将返回 `"abc123"` 。

**示例 1：**

```
输入：method = "abc123"
输出："abc123"
解释：
const obj = createInfiniteObject();
obj['abc123'](); // "abc123"
返回的字符串应始终与方法名称匹配。
```

**示例 2：**

```
输入：method = ".-qw73n|^2It"
输出：".-qw73n|^2It"
解释：返回的字符串应始终与方法名称匹配。
```

**提示：**

- `0 <= method.length <= 1000`

## 题解

::: details 点击查看题解

### 思路

方法名有无穷多种，不可能预先枚举成对象属性——问题的本质是"**任意属性访问都要返回一个函数**"，这正好是 `Proxy` 的用武之地。

`Proxy` 的 `get` 陷阱会拦截所有属性读取：无论是 `obj.abc123` 还是 `obj['.-qw73n|^2It']`（示例 2 的名字含特殊字符，只能用括号访问），都会进入 `get` 并拿到属性名 `prop`。

`get` 里返回的是一个**闭包**：读取属性时只是"造出函数"，真正调用时才把捕获到的 `prop` 转成字符串返回——两步分离，`obj['abc123']()` 才能得到 `"abc123"`。

不要在 `get` 里直接返回 `prop`：那样读到的是字符串而不是函数，`obj.abc123()` 会直接报"不是函数"；同理也不要试图用普通对象 + `defineProperty` 硬凑，属性是列不完的。

`prop` 可能是字符串或 Symbol，统一用 `prop.toString()` 转换即可，两种类型都能得到对应的名字。

约束 `method.length <= 1000` 只是说明名字可能很长，与实现无关；闭包按需创建，开销恒定。

### 代码实现

```javascript
var createInfiniteObject = function () {
  return new Proxy({}, {
    // 任意属性读取都返回一个"返回该属性名"的函数
    get: (_, prop) => () => prop.toString(),
  });
};
```

### 复杂度分析

- 时间复杂度：O(1)，每次属性读取与函数调用都只做常数工作。
- 空间复杂度：O(1)，代理本身不保存任何状态。

:::
