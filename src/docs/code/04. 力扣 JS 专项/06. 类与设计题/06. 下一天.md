# 下一天

> 难度：简单 | 标签：原型扩展、日期 | LeetCode 2758（VIP 专属题） · [原题链接](https://leetcode.cn/problems/next-day/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

请你编写一个有关日期对象的方法，使得任何日期对象都可以调用 `date.nextDay()` 方法，然后返回调用日期对象的下一天，格式为 `YYYY-MM-DD` 。

**示例 1：**

```
输入：date = "2014-06-20"
输出："2014-06-21"
解释：
const date = new Date("2014-06-20");
date.nextDay(); // "2014-06-21"
```

**示例 2：**

```
输入：date = "2017-10-31"
输出："2017-11-01"
解释：日期 2017-10-31 的下一天是 2017-11-01.
```

**提示：**

- `new Date(date)` 是一个有效的日期对象

## 题解

::: details 点击查看题解

### 思路

题目要求**所有日期对象**都能调用 `nextDay()`，所以挂载点是 `Date.prototype.nextDay`——定义一次，每个 `Date` 实例都会继承这个方法。

千万不要手写"每月天数表 + 闰年判断"：跨月、跨年、2 月 29 日这些边界极易出错，而 `Date` 自带的进位逻辑是现成且经过验证的。

实现时先复制一份时间戳（`new Date(this.valueOf())`）再推进一天：如果直接在 `this` 上改，调用一次 `nextDay()` 会把原日期对象也改掉，产生副作用；复制后原对象保持不变。

推进用 `getUTCDate` / `setUTCDate`、取值用 `toISOString().slice(0, 10)`：形如 `"2014-06-20"` 的日期字符串按规范解析为 UTC 零点，这套 UTC 组合拳截出的 `YYYY-MM-DD` 在任何时区都一致，本地 `getDate` / `setDate` 在非 UTC 时区则可能差一天。

边界全部交给 `Date` 自动处理：`2017-10-31` 的下一天是 `2017-11-01`（跨月，示例 2），`2023-12-31` 是 `2024-01-01`（跨年），闰年 `2024-02-28` 是 `2024-02-29`。

### 代码实现

```javascript
Date.prototype.nextDay = function () {
  const date = new Date(this.valueOf()); // 复制时间戳，避免修改原对象
  date.setUTCDate(date.getUTCDate() + 1); // 按天推进，自动跨月/跨年/闰年
  return date.toISOString().slice(0, 10); // 截取 YYYY-MM-DD
};
```

### 复杂度分析

- 时间复杂度：O(1)，构造、推进、截取都是常数操作。
- 空间复杂度：O(1)，只额外创建一个 `Date` 对象。
