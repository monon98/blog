# 重复字符串

> 难度：简单 | 标签：原型扩展、字符串 | LeetCode 2796（VIP 专属题） · [原题链接](https://leetcode.cn/problems/repeat-string/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

编写代码实现字符串方法 `string.replicate(x)` ，它将返回重复的字符串 `x` 次。

请尝试在不使用内置方法 `string.repeat` 的情况下实现它。

**示例 1：**

```
输入：str = "hello", times = 2
输出："hellohello"
解释："hello" 被重复了 2 次
```

**示例 2：**

```
输入：str = "code", times = 3
输出："codecodecode"
解释："code" 被重复了 3 次
```

**示例 3：**

```
输入：str = "js", times = 1
输出："js"
解释："js" 被重复了 1 次
```

**提示：**

- `1 <= times <= 10^5`
- `1 <= str.length <= 1000`

**进阶**：为了简化分析，让我们假设连接字符串是一个常数时间操作 `O(1)`。考虑到这个假设，您能编写时间复杂度为 `O(log n)` 的算法吗？

## 题解

::: details 点击查看题解

### 思路

题目要求扩展**所有字符串**：方法挂在 `String.prototype.replicate` 上，调用 `s.replicate(n)` 时 `this` 就是该字符串，返回重复后的结果。

最直观的实现是"先备好 times 份副本、再一次拼接"：`Array(times).fill(this).join("")` —— 数组承接副本、`join` 单次分配完成，比在循环里反复 `+=` 少掉大量中间字符串。

题目明令禁止的是内置方法 `string.repeat`，而 `Array.prototype.fill` 与 `join` 都不在其列；`join` 会把每个元素按字符串拼接，正好得到重复结果。

边界：`times = 1` 时原样返回（示例 3）；`this` 在普通函数里是装箱的 `String` 对象，`join` 会自动取回它的字符串值，返回值仍是原始字符串类型。结果长度可达 `times × str.length`，一次性 `join` 正好避免中间产物的反复分配。

进阶问法（假设单次拼接为 O(1)）：可用**倍增（二分）** 把拼接次数降到 O(log n) —— `replicate(k)` 先递归得到 `replicate(⌊k/2⌋)`，复制两份拼起来，k 为奇数时再补一份，拼接次数与 k 的二进制位数同阶，这与快速幂的思路一致。

### 代码实现

```javascript
String.prototype.replicate = function (times) {
  // 数组承接 times 份副本，join 一次性拼接（禁止使用 String.prototype.repeat）
  return Array(times).fill(this).join("");
};
```

### 复杂度分析

- 时间复杂度：O(times × n)，n 为原串长度，结果本身就有这么长。
- 空间复杂度：O(times × n)，用于存放结果字符串。

:::
