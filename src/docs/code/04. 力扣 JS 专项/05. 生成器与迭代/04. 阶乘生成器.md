# 阶乘生成器

> 难度：简单 | 标签：生成器、循环 | LeetCode 2803（VIP 专属题） · [原题链接](https://leetcode.cn/problems/factorial-generator/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

编写生成器函数 `factorial(n)`，该函数以一个整数 `n` 作为参数，并返回一个生成器对象，该生成器对象可以生成 **阶乘序列** 。

**阶乘序列** 的定义如下：`n! = n * (n-1) * (n-2) * ... * 2 * 1` 。

0 的阶乘被定义为 1。

**示例 1：**

```
输入：n = 5
输出：[1,2,6,24,120]
解释：
const gen = factorial(5)
gen.next().value // 1
gen.next().value // 2
gen.next().value // 6
gen.next().value // 24
gen.next().value // 120
```

**示例 2：**

```
输入：n = 2
输出：[1,2]
解释：
const gen = factorial(2)
gen.next().value // 1
gen.next().value // 2
```

**示例 3：**

```
输入：n = 0
输出：[1]
解释：
const gen = factorial(0)
gen.next().value // 1
```

**提示：**

- `0 <= n <= 18`

## 题解

::: details 点击查看题解

### 思路

阶乘序列是典型的累积乘积：1! = 1，之后每一项都等于前一项乘以当前因子，所以只要维护一个滚动变量 `ans`，边乘边产出即可。

先产出一次 `1`——它既是 0! 也是 1!，`n = 0` 时循环体一次都不执行，天然只产出一个 1（示例 3）；`n = 2` 时再乘一次 2 产出 2（示例 2）。

随后让因子从 2 走到 `n`，每乘一次 `ans` 就 `yield` 一次，产出顺序即 1, 2, 6, 24, 120（示例 1），与题目要求的序列一一对应。

不需要预先算完整个阶乘数组：生成器按需推进，算到哪存到哪，这也正是题目用生成器而非返回数组的原因。

提示里 `n <= 18`：18! = 6402373705728000，仍在 `Number.MAX_SAFE_INTEGER`（约 9 × 10^15）之内，普通浮点乘法不会丢精度，无需 BigInt。

### 代码实现

```javascript
var factorial = function* (n) {
  let ans = 1;
  yield ans; // 0! 与 1! 都是 1
  for (let i = 2; i <= n; i++) {
    ans *= i; // 累积乘积
    yield ans;
  }
};
```

### 复杂度分析

- 时间复杂度：O(n)，共 n 次产出，每次 `next()` 只做一次乘法。
- 空间复杂度：O(1)，只保存一个累积变量。
