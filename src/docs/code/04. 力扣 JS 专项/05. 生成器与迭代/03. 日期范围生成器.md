# 日期范围生成器

> 难度：中等 | 标签：生成器、日期 | LeetCode 2777（VIP 专属题） · [原题链接](https://leetcode.cn/problems/date-range-generator/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

实现生成器函数 `dateRangeGenerator(start, end, step)`：现给定起始日期 `start` 、结束日期 `end` 和正整数 `step` ，返回一个生成器对象，该生成器对象按照从 `start` 到 `end` （包括 `start` 和 `end` ）的范围生成日期。

`step` 的值表示连续生成的日期之间的天数间隔。

所有日期都以字符串格式 `YYYY-MM-DD` 表示。

**示例 1：**

```
输入：start = "2023-04-01", end = "2023-04-04", step = 1
输出：["2023-04-01","2023-04-02","2023-04-03","2023-04-04"]
解释：
const g = dateRangeGenerator(start, end, step);
g.next().value // '2023-04-01'
g.next().value // '2023-04-02'
g.next().value // '2023-04-03'
g.next().value // '2023-04-04'
```

**示例 2：**

```
输入：start = "2023-04-10", end = "2023-04-20", step = 3
输出：["2023-04-10","2023-04-13","2023-04-16","2023-04-19"]
解释：
const g = dateRangeGenerator(start, end, step);
g.next().value // '2023-04-10'
g.next().value // '2023-04-13'
g.next().value // '2023-04-16'
g.next().value // '2023-04-19'
```

**示例 3：**

```
输入：start = "2023-04-10", end = "2023-04-10", step = 1
输出：["2023-04-10"]
解释：
const g = dateRangeGenerator(start, end, step);
g.next().value // '2023-04-10'
```

**提示：**

- `new Date(start) <= new Date(end)`
- `start` 和 `end` 的日期格式是 `YYYY-MM-DD`
- `0 <= 结束日期与开始日期之间的天数差 <= 1500`
- `1 <= step <= 1000`

## 题解

::: details 点击查看题解

### 思路

闭区间、固定步长：从起始日开始，只要当前日期不超过 `end` 就 `yield` 它，然后把日期推进 `step` 天，循环直到越界为止。

日期推进交给 `Date` 的 `setUTCDate`：跨月、跨年、闰年、大小月都由标准库自动进位，手写"每月天数表 + 闰年判断"反而容易在月末、2 月底这类边界出错。

`start` / `end` 是 `YYYY-MM-DD` 形式的日期字符串，按规范会被解析为 UTC 零点，因此统一用 `getUTCDate` / `setUTCDate` 推进、`toISOString().slice(0, 10)` 截取日期部分，结果与时区无关；若改用本地 `getDate` / `setDate`，在非 UTC 时区可能差一天。

生成器天然是惰性的：区间最长 1500 天，但调用方不取就不算，内存里只维护当前这一个 `Date` 对象。

边界：`start == end` 时只产出一天（示例 3）；`step` 大于剩余跨度时，下一轮比较即结束，绝不会产出超过 `end` 的日期。

### 代码实现

```javascript
var dateRangeGenerator = function* (start, end, step) {
  const endDate = new Date(end);
  let cur = new Date(start); // 起始日（YYYY-MM-DD 按 UTC 解析）
  while (cur <= endDate) {
    yield cur.toISOString().slice(0, 10); // 产出 YYYY-MM-DD
    cur.setUTCDate(cur.getUTCDate() + step); // 按步长推进，自动跨月/跨年
  }
};
```

### 复杂度分析

- 时间复杂度：O(k)，k 为区间内产出的日期数，每次 `next()` 只做常数工作。
- 空间复杂度：O(1)，只持有当前日期与结束日期两个对象。
