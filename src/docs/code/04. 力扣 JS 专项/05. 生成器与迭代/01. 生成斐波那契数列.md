# 生成斐波那契数列

> 难度：简单 | 标签：生成器、迭代器 | LeetCode 2648 · [原题链接](https://leetcode.cn/problems/generate-fibonacci-sequence/)

## 题目描述

请你编写一个生成器函数，并返回一个可以生成 **斐波那契数列** 的生成器对象。

**斐波那契数列** 的递推公式为 `Xn = Xn-1 + Xn-2` 。

这个数列的前几个数字是 `0, 1, 1, 2, 3, 5, 8, 13` 。

**示例 1：**

```
输入：callCount = 5
输出：[0,1,1,2,3]
解释：
const gen = fibGenerator();
gen.next().value; // 0
gen.next().value; // 1
gen.next().value; // 1
gen.next().value; // 2
gen.next().value; // 3
```

**示例 2：**

```
输入：callCount = 0
输出：[]
解释：gen.next() 永远不会被调用，所以什么也不会输出
```

**提示：**

- `0 <= callCount <= 50`

## 题解

::: details 点击查看题解

### 思路

用 `function*` 定义生成器函数：调用 `fibGenerator()` 返回迭代器，每调用一次 `next()` 产出一个数，调用多少次由调用方决定，因此完全不需要预先生成整个数列。

用两个变量 `a`、`b` 滚动保存前两项：先 `yield a`，再同时更新为 `b` 与 `a + b`（即 `[a, b] = [b, a + b]`），两步就完成一次推进。

初始值 `a = 0`、`b = 1`，第一次产出 0、第二次产出 1、第三次产出 1、第四次产出 2……与示例 1 的 `0, 1, 1, 2, 3` 完全吻合。

数列是无穷的，循环写成 `while (true)` 即可；示例 2 中 `callCount = 0` 时调用方一次 `next()` 都不执行，自然什么也不会输出。

不要用数组缓存已生成的项——生成器的价值就在于按需计算、常数空间，`callCount` 上限只有 50 也说明没必要物化。

### 代码实现

```javascript
var fibGenerator = function* () {
  let a = 0, b = 1; // 数列前两项
  while (true) {
    yield a; // 产出当前项
    [a, b] = [b, a + b]; // 滚动到下一项
  }
};
```

### 复杂度分析

- 时间复杂度：O(1)，每次 `next()` 只做一次加法。
- 空间复杂度：O(1)，始终只保存两个滚动变量。
