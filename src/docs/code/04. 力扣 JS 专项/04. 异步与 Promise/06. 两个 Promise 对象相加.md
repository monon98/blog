# 两个 Promise 对象相加

> 难度：简单 | 标签：Promise、async/await | LeetCode 2723 · [原题链接](https://leetcode.cn/problems/add-two-promises/)

## 题目描述

给定两个 promise 对象 `promise1` 和 `promise2`，返回一个新的 promise。`promise1` 和 `promise2` 都会被解析为一个数字。返回的 Promise 应该解析为这两个数字的和。

**示例 1：**

```
输入：
promise1 = new Promise(resolve => setTimeout(() => resolve(2), 20)),
promise2 = new Promise(resolve => setTimeout(() => resolve(5), 60))
输出：7
解释：两个输入的 Promise 分别解析为值 2 和 5。返回的 Promise 应该解析为 2 + 5 = 7。返回的 Promise 解析的时间不作为判断条件。
```

**示例 2：**

```
输入：
promise1 = new Promise(resolve => setTimeout(() => resolve(10), 50)),
promise2 = new Promise(resolve => setTimeout(() => resolve(-12), 30))
输出：-2
解释：两个输入的 Promise 分别解析为值 10 和 -12。返回的 Promise 应该解析为 10 + -12 = -2。
```

**提示：**

- `promise1 和 promise2` 都是被解析为一个数字的 promise 对象

## 题解

::: details 点击查看题解

### 思路

两个 promise 传进来时 **已经在运行中**（它们各自内部的定时器早就排上了），所以直接顺序 `await` 即可：`await promise1` 期间 `promise2` 并没有停下等它，总耗时仍等于较慢的那个，不是两者之和。

`async` 函数的返回值会自动包装成 promise，`await` 到的两个数字相加后 `return`，语义上就是「返回一个新的 promise，解析为两数之和」；如果任一输入 promise 被拒绝，`await` 会把错误抛出，返回的 promise 也随之拒绝（本题保证都解析为数字）。

也可以写成 `const [a, b] = await Promise.all([promise1, promise2])`，效果完全相同——本题没有禁止使用内置方法，而最朴素的两次 `await` 已经足够。

容易混淆的对照：若两个 promise 是在函数内部 **串行创建** 的（前一个结束后才创建下一个），耗时才会相加；本题的输入是现成的并行任务，`await` 的先后只影响取值顺序，不影响起跑时刻。

### 代码实现

```javascript
/**
 * @param {Promise<number>} promise1
 * @param {Promise<number>} promise2
 * @return {Promise<number>}
 */
var addTwoPromises = async function(promise1, promise2) {
  // 两个 promise 已在运行中，顺序 await 的总耗时仍等于较慢的那个
  const a = await promise1;
  const b = await promise2;
  return a + b;
};
```

### 复杂度分析

- 时间复杂度：O(1)，只做两次等待与一次加法，等待时长取决于传入的 promise。
- 空间复杂度：O(1)，只保存两个中间值。
