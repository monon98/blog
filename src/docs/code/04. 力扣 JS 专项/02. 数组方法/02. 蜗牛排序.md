# 蜗牛排序

> 难度：中等 | 标签：数组、矩阵、模拟 | LeetCode 2624 · [原题链接](https://leetcode.cn/problems/snail-traversal/)

## 题目描述

请你编写一段代码为所有数组实现 `snail(rowsCount, colsCount)` 方法，该方法将 1D 数组转换为以蜗牛排序的模式的 2D 数组。无效的输入值应该输出一个空数组，当 `rowsCount * colsCount !== nums.length` 时，该输入被认为是无效的。

蜗牛排序从左上角的单元格开始，从当前数组的第一个值开始。然后，它从上到下遍历第一列，接着移动到右边的下一列，并从下到上遍历它。将这种模式持续下去，每列交替变换遍历方向，直到覆盖整个数组。例如，当给定输入数组 `[19, 10, 3, 7, 9, 8, 5, 2, 1, 17, 16, 14, 12, 18, 6, 13, 11, 20, 4, 15]`，当 `rowsCount = 5` 且 `colsCount = 4` 时，需要输出的矩阵见示例 1。注意，矩阵沿箭头方向对应于原数组中数字的顺序。

**示例 1：**

```
输入：
nums = [19, 10, 3, 7, 9, 8, 5, 2, 1, 17, 16, 14, 12, 18, 6, 13, 11, 20, 4, 15]
rowsCount = 5
colsCount = 4
输出：
[
  [19,17,16,15],
  [10,1,14,4],
  [3,2,12,20],
  [7,5,18,11],
  [9,8,6,13]
]
```

**示例 2：**

```
输入：
nums = [1,2,3,4]
rowsCount = 1
colsCount = 4
输出：[[1, 2, 3, 4]]
```

**示例 3：**

```
输入：
nums = [1,3]
rowsCount = 2
colsCount = 2
输出：[]
解释：2 * 2 = 4，而原数组 [1,3] 的长度为 2，所以输入是无效的。
```

**提示：**

- 0 <= nums.length <= 250
- 1 <= nums[i] <= 1000
- 1 <= rowsCount <= 250
- 1 <= colsCount <= 250

## 题解

::: details 点击查看题解

### 思路

先校验 `rowsCount * colsCount !== this.length`，不合法直接返回空数组，避免矩阵被填出半截或留下空洞（示例 3 就是行数乘积对不上）。

接着创建 `rowsCount` 行、`colsCount` 列的空矩阵作为骨架，用一个指针 `k` 从 0 开始顺序消费原数组。

按列填充：偶数列（第 0、2、4… 列）自上而下写入，奇数列自下而上写入，方向只由列号奇偶决定 —— 这正是蜗牛轨迹「一列向下、一列向上」的折线，填满 `colsCount` 列后 `k` 恰好走完整个数组。

另一种等价写法是维护上下左右四个边界（top、bottom、left、right），沿外圈顺时针收缩，每走完一边收一个边界；列奇偶法状态变量更少、不易写错，优先推荐。

边界情况：行列乘积对不上一律返回 `[]`；空数组同样满足不了乘积等式（行列至少为 1），自然返回空数组。

注意要先建好二维骨架再按下标写入，不能按行 push 后跨列错位填充，那样行列方向极易颠倒。

### 代码实现

```javascript
Array.prototype.snail = function (rowsCount, colsCount) {
  if (rowsCount * colsCount !== this.length) return [];
  // 先建好 rowsCount × colsCount 的空矩阵
  const matrix = Array.from({ length: rowsCount }, () => new Array(colsCount));
  let k = 0;
  for (let c = 0; c < colsCount; c++) {
    if (c % 2 === 0) {
      // 偶数列：自上而下
      for (let r = 0; r < rowsCount; r++) matrix[r][c] = this[k++];
    } else {
      // 奇数列：自下而上
      for (let r = rowsCount - 1; r >= 0; r--) matrix[r][c] = this[k++];
    }
  }
  return matrix;
};
```

### 复杂度分析

- 时间复杂度：O(rowsCount × colsCount)，即 O(n)。
- 空间复杂度：O(rowsCount × colsCount)，即结果矩阵本身。
