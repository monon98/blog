# 数组原型的 forEach 方法

> 难度：简单 | 标签：数组、原型方法、高阶函数 | LeetCode 2804（VIP 专属题） · [原题链接](https://leetcode.cn/problems/array-prototype-foreach/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

编写你自己版本的 `forEach` 方法，增强所有数组，使你可以在任意数组上调用 `array.forEach(callback, context)` 方法，对数组的每个元素执行 `callback`。`forEach` 方法不应返回任何值。

`callback` 接受以下参数：

- `currentValue` —— 正在处理的当前元素，即当前迭代中该元素的值。
- `index` —— 正在处理的当前元素的索引。
- `array` —— 数组本身，允许在回调函数中访问整个数组。

`context` 是作为函数上下文参数传给 `callback` 的对象，确保回调函数中的 `this` 关键字指向该 `context` 对象。尝试在不使用内置数组方法的情况下实现它。

**示例 1：**

```
输入：
arr = [1,2,3],
callback = (val, i, arr) => arr[i] = val * 2,
context = {"context":true}
输出：[2,4,6]
解释：
arr.forEach(callback, context)
console.log(arr) // [2,4,6]
callback 对数组的每个元素执行了一次。
```

**示例 2：**

```
输入：
arr = [true, true, false, false],
callback = (val, i, arr) => arr[i] = this,
context = {"context": false}
输出：[{"context":false},{"context":false},{"context":false},{"context":false}]
解释：
arr.forEach(callback, context)
console.log(arr) // [{"context":false},{"context":false},{"context":false},{"context":false}]
callback 在正确的 context 下对数组的每个元素执行了一次。
```

**示例 3：**

```
输入：
arr = [true, true, false, false],
callback = (val, i, arr) => arr[i] = !val,
context = {"context": 5}
输出：[false,false,true,true]
```

**提示：**

- arr 是一个有效的 JSON 数组
- context 是一个有效的 JSON 对象
- callback 是一个函数
- 0 <= arr.length <= 10^5

## 题解

::: details 点击查看题解

### 思路

整体策略：用普通 for 循环按下标遍历，回调写成 `callback.call(context, this[i], i, this)` —— `call` 一次完成两件事：把回调的 `this` 绑到 `context`，并按 `(currentValue, index, array)` 三个参数传值，正好对齐题面的参数约定。

方法不返回任何值：函数体不写 `return`，隐式返回 `undefined`，对应「forEach 不应返回任何返回值」的要求，也不要写 `return callback(...)`。

三个示例各自检验一件事：示例 2 检验 `this` 绑定（回调里的 `this` 取到 `context`，每个元素被替换成该对象）；示例 1、3 说明回调可以原地写回数组，`forEach` 本身不产出新数组、只是执行副作用。

题面要求不使用内置数组方法，for 循环即可；`apply`、`bind` 也能绑定 context，但 `call` 最直白。

与原生的差异面试可提：原生 `forEach` 会跳过稀疏数组的空洞（本题输入是 JSON 稠密数组，无需 `i in this` 判断）、回调里的 `return` 只能跳过本次迭代、不能中断整个循环、`context` 传 `undefined` 时非严格模式会挂到全局对象。

工程提醒：直接给 `Array.prototype.forEach` 赋值会覆写原生方法、污染全局数组原型，这类写法只在力扣与面试场景使用。

### 代码实现

```javascript
Array.prototype.forEach = function (callback, context) {
  for (let i = 0; i < this.length; i++) {
    // 绑定 context，并按 (currentValue, index, array) 传参
    callback.call(context, this[i], i, this);
  }
  // 不写 return：隐式返回 undefined
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。
