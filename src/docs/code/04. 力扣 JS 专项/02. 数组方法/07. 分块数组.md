# 分块数组

> 难度：简单 | 标签：数组、模拟 | LeetCode 2677 · [原题链接](https://leetcode.cn/problems/chunk-array/)

## 题目描述

给定一个数组 `arr` 和一个块大小 `size`，返回一个分块的数组。

分块的数组包含了 `arr` 中的原始元素，但是每个子数组的长度都是 `size`。如果 `arr.length` 不能被 `size` 整除，那么最后一个子数组的长度可能小于 `size`。

你可以假设该数组是 `JSON.parse` 的输出结果。换句话说，它是有效的 JSON。

请你在不使用 lodash 的函数 `_.chunk` 的情况下解决这个问题。

**示例 1：**

```
输入：arr = [1,2,3,4,5], size = 1
输出：[[1],[2],[3],[4],[5]]
解释：数组 arr 被分割成了每个只有一个元素的子数组。
```

**示例 2：**

```
输入：arr = [1,9,6,3,2], size = 3
输出：[[1,9,6],[3,2]]
解释：数组 arr 被分割成了每个有三个元素的子数组。然而，第二个子数组只有两个元素。
```

**示例 3：**

```
输入：arr = [8,5,3,2,6], size = 6
输出：[[8,5,3,2,6]]
解释：size 大于 arr.length，因此所有元素都在第一个子数组中。
```

**示例 4：**

```
输入：arr = [], size = 1
输出：[]
解释：没有元素需要分块，因此返回一个空数组。
```

**提示：**

- arr 是一个合法 JSON 数组。
- 2 <= JSON.stringify(arr).length <= 10^5
- 1 <= size <= arr.length + 1

## 题解

::: details 点击查看题解

### 思路

整体策略是步长循环：`i` 以 `size` 为步长前进，每次取 `[i, i + size)` 的切片。`slice` 越界自动截断的特性天然处理了「最后一组不满」的情况 —— 示例 2 的 `[3,2]`、示例 3 的整段单组都靠它兜住，不需要单独算余数。

边界逐个过：空数组时循环不执行直接返回 `[]`（示例 4）；`size >= arr.length` 时只产生一组（题目允许 `size` 取到 `arr.length + 1`）；本题保证 `1 <= size`，所以不用做非法 size 校验，但面试常被追问 `size <= 0` 该怎么办 —— 抛 `RangeError` 或返回 `[]` 都是常见答案。

每个分块都由 `slice` 产生，是互不重叠的新数组，元素沿用原引用，入参不被修改。

延伸对比：`slice` 与 `splice` 的区别（前者纯读取返回新数组，后者原地修改）；步长循环是分页、批量上传分片的基础模式；变体追问包括异步场景按批处理（配合 await）、lodash.chunk 对 size 缺省值的处理。

本题明令禁止使用 lodash 的 `_.chunk`，手写步长循环即可。

### 代码实现

```javascript
var chunk = function (arr, size) {
  const res = [];
  for (let i = 0; i < arr.length; i += size) {
    res.push(arr.slice(i, i + size)); // 越界自动截断，末组可短
  }
  return res;
};
```

### 复杂度分析

- 时间复杂度：O(n)，每个元素被 `slice` 拷贝恰好一次。
- 空间复杂度：O(n)，结果二维数组。

:::
