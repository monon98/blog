# 生成循环数组的值

> 难度：中等 | 标签：生成器、数组、数学 | LeetCode 2757（VIP 专属题） · [原题链接](https://leetcode.cn/problems/generate-circular-array-values/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

给定一个循环数组 `arr` 和一个整数 `startIndex`，返回一个生成器对象 `gen`，用于依次产出 `arr` 中的值。

第一次调用 `gen.next()` 时，应该产出 `arr[startIndex]`。此后每次调用 `gen.next()` 时，都会向生成器传入一个整数 `jump`（例如 `gen.next(-3)`）。

- 如果 `jump` 为正，索引应该增加该值；但如果当前已经是最后一个索引，则应该跳到第一个索引。
- 如果 `jump` 为负，索引应该减少该值的绝对值；但如果当前已经是第一个索引，则应该跳到最后一个索引。

**示例 1：**

```
输入：arr = [1,2,3,4,5], steps = [1,2,6], startIndex = 0
输出：[1,2,4,5]
解释：
const gen = cycleGenerator(arr, startIndex);
gen.next().value;  // 1, index = startIndex = 0
gen.next(1).value; // 2, index = 1, 0 -> 1
gen.next(2).value; // 4, index = 3, 1 -> 2 -> 3
gen.next(6).value; // 5, index = 4, 3 -> 4 -> 0 -> 1 -> 2 -> 3 -> 4
```

**示例 2：**

```
输入：arr = [10,11,12,13,14,15], steps = [1,4,0,-1,-3], startIndex = 1
输出：[11,12,10,10,15,12]
解释：
const gen = cycleGenerator(arr, startIndex);
gen.next().value;   // 11, index = 1
gen.next(1).value;  // 12, index = 2
gen.next(4).value;  // 10, index = 0
gen.next(0).value;  // 10, index = 0
gen.next(-1).value; // 15, index = 5
gen.next(-3).value; // 12, index = 2
```

**示例 3：**

```
输入：arr = [2,4,6,7,8,10], steps = [-4,5,-3,10], startIndex = 3
输出：[7,10,8,4,10]
解释：
const gen = cycleGenerator(arr, startIndex);
gen.next().value;   // 7,  index = 3
gen.next(-4).value; // 10, index = 5
gen.next(5).value;  // 8,  index = 4
gen.next(-3).value; // 4,  index = 1
gen.next(10).value; // 10, index = 5
```

**提示：**

- 1 <= arr.length <= 10^4
- 1 <= steps.length <= 100
- -10^4 <= steps[i], arr[i] <= 10^4
- 0 <= startIndex < arr.length

## 题解

::: details 点击查看题解

### 思路

整体策略：生成器把「当前索引」当作自己的状态，在 `while (true)` 里先 `yield arr[index]`，被恢复时拿到本次的 `jump`，用取模把索引归一化回 `[0, n)`，再进入下一轮产出。

归一化公式 `((index + jump) % n + n) % n`：先 `% n` 压掉正跳的越界，`+ n` 再 `% n` 把负数抬回正区间 —— 一步等价于题目描述里「一格一格循环走 jump 次」。示例 1 中从索引 3 一次跳 6：`(3 + 6) % 5 = 4`，与逐格走 `3 → 4 → 0 → 1 → 2 → 3 → 4` 的结果一致。

生成器语义要点：第一次 `gen.next()` 的入参会被规范忽略，恰好对上「首拍只产出 `arr[startIndex]`、不接受 jump」；此后每次 `gen.next(jump)` 传入的参数正是 `yield` 表达式的值，也就是从产出点恢复后 `jump` 拿到的值。

边界：`jump = 0` 原地不动（示例 2 第四拍）；数组只有一个元素时取模恒为 0；题目保证此后每次都会传入整数，防御性地写 `jump ?? 0` 可以避免误用不带参数的 `gen.next()` 时索引变 NaN。

写法对比：按 `±1` 步进的循环也能做，但单次是 O(|jump|)；取模写法每次 O(1)。也不要试图把数组拼成双倍再线性偏移 —— `jump` 绝对值可达 10^4，拼接长度不够，取模才是正解。

### 代码实现

```javascript
function* cycleGenerator(arr, startIndex) {
  const n = arr.length;
  let index = startIndex;
  while (true) {
    // 恢复时拿到本次 jump；题目保证除第一拍外都会传入整数
    const jump = yield arr[index];
    index = (((index + (jump ?? 0)) % n) + n) % n;
  }
}
```

### 复杂度分析

- 时间复杂度：每次 `gen.next()` 调用 O(1)。
- 空间复杂度：O(1)，生成器仅保存索引与数组引用。
