# 过滤数组中的元素

> 难度：简单 | 标签：数组、高阶函数 | LeetCode 2634 · [原题链接](https://leetcode.cn/problems/filter-elements-from-array/)

## 题目描述

给定一个整数数组 `arr` 和一个过滤函数 `fn`，并返回一个过滤后的数组 `filteredArr`。

`fn` 函数接受一个或两个参数：

- `arr[i]` —— arr 中的数字
- `i` —— `arr[i]` 的索引

`filteredArr` 应该只包含使表达式 `fn(arr[i], i)` 的值为真值的 `arr` 中的元素。真值是指 `Boolean(value)` 返回参数为 `true` 的值。

请在不使用内置的 `Array.filter` 方法的情况下解决该问题。

**示例 1：**

```
输入：arr = [0,10,20,30], fn = function greaterThan10(n) { return n > 10; }
输出：[20,30]
解释：const newArray = filter(arr, fn); // [20, 30]，过滤函数过滤掉不大于 10 的值。
```

**示例 2：**

```
输入：arr = [1,2,3], fn = function firstIndex(n, i) { return i === 0; }
输出：[1]
解释：过滤函数也可以接受每个元素的索引，在这种情况下，过滤函数删除索引不为 0 的元素。
```

**示例 3：**

```
输入：arr = [-2,-1,0,1,2], fn = function plusOne(n) { return n + 1 }
输出：[-2,0,1,2]
解释：像 0 这样的假值应被过滤掉。
```

**提示：**

- 0 <= arr.length <= 1000
- -10^9 <= arr[i] <= 10^9

## 题解

::: details 点击查看题解

### 思路

整体策略：顺序遍历 `arr`，把 `(arr[i], i)` 传给 `fn`，返回值为真值时才把 `arr[i]` 收入新数组，最后返回新数组，不修改原数组、保持原相对顺序。

最容易写错的是判断对象：题面判的是 **`fn` 返回值** 的真值，而不是元素本身。示例 3 中 `n + 1` 对 `n = -1` 返回 0，`Boolean(0)` 为 false 所以 -1 被过滤，而元素 0 自己反而留下了 —— 凭直觉写成「过滤掉假值元素」就会错。

`fn` 的第二个参数是索引（示例 2 用到），本题签名只暴露前两个参数，传两参即可；面试手写原生 filter 的完整回调是 `(element, index, array)` 三元组，并支持 `thisArg` 绑定，可作为扩展点讲一句。

与原生对齐的另一个细节是稀疏数组：原生 `filter` 会用 `i in this` 跳过空洞、只收集真实存在的元素。本题输入是 JSON 稠密数组，无需判断，但面试值得主动提（完整手写见下方扩展代码）。

边界：`arr` 为空时循环不执行，返回空数组；本题明令禁止使用内置 `Array.filter`。

### 代码实现

```javascript
var filter = function (arr, fn) {
  const filteredArr = [];
  for (let i = 0; i < arr.length; i++) {
    if (fn(arr[i], i)) filteredArr.push(arr[i]); // 只收 fn 返回真值的元素
  }
  return filteredArr;
};
```

扩展：面试手写「原生 `Array.filter` 完整版」，含 thisArg 与稀疏空洞处理：

```javascript
Array.prototype.myFilter = function (fn, thisArg) {
  const result = [];
  for (let i = 0; i < this.length; i++) {
    if (i in this && fn.call(thisArg, this[i], i, this)) {
      result.push(this[i]); // i in this 跳过稀疏数组的空洞
    }
  }
  return result;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(n)，结果数组。
