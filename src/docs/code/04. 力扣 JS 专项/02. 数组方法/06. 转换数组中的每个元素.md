# 转换数组中的每个元素

> 难度：简单 | 标签：数组、高阶函数 | LeetCode 2635 · [原题链接](https://leetcode.cn/problems/apply-transform-over-each-element-in-array/)

## 题目描述

编写一个函数，这个函数接收一个整数数组 `arr` 和一个映射函数 `fn`，通过该映射函数返回一个新的数组。

返回数组的创建语句应为 `returnedArray[i] = fn(arr[i], i)`。

请你在不使用内置方法 `Array.map` 的前提下解决这个问题。

**示例 1：**

```
输入：arr = [1,2,3], fn = function plusone(n) { return n + 1; }
输出：[2,3,4]
解释：const newArray = map(arr, plusone); // [2,3,4]，此映射函数返回值是将数组中每个元素的值加 1。
```

**示例 2：**

```
输入：arr = [1,2,3], fn = function plusI(n, i) { return n + i; }
输出：[1,3,5]
解释：此映射函数返回值根据输入数组索引增加每个值。
```

**示例 3：**

```
输入：arr = [10,20,30], fn = function constant() { return 42; }
输出：[42,42,42]
解释：此映射函数返回值恒为 42。
```

**提示：**

- 0 <= arr.length <= 1000
- -10^9 <= arr[i] <= 10^9
- fn 返回一个整数。

## 题解

::: details 点击查看题解

### 思路

整体策略：按 `arr.length` 预分配一个等长数组，再按下标写入 `returnedArray[i] = fn(arr[i], i)` —— 题面直接给出了这行赋值语句，预分配 + 下标写入比 push 更贴合语义，结果长度恒等于入参长度。

`fn` 的第二个参数是索引（示例 2 用到），本题只需传前两参；面试手写原生 map 的完整回调是 `(element, index, array)` 三元组并支持 `thisArg`，可作为扩展补充。

手写 map 与 filter、reduce 最容易混淆的差异是对稀疏数组的态度：原生 map 会**保持空洞**（返回数组长度不变、未访问位置仍是 empty），filter 会压缩收集，reduce 则跳过空洞。本题输入是 JSON 稠密数组无需处理，但面试时把这一组对比讲清楚很加分（完整手写见下方扩展代码）。

边界：`arr` 为空时预分配长度为 0、循环不执行，返回空数组；本题明令禁止使用内置 `Array.map`，也不要改用 `forEach` 取巧。

### 代码实现

```javascript
var map = function (arr, fn) {
  const returnedArray = new Array(arr.length);
  for (let i = 0; i < arr.length; i++) {
    returnedArray[i] = fn(arr[i], i); // 题面指定的赋值语句
  }
  return returnedArray;
};
```

扩展：面试手写「原生 `Array.map` 完整版」，含 thisArg 与稀疏空洞保持：

```javascript
Array.prototype.myMap = function (fn, thisArg) {
  const result = [];
  for (let i = 0; i < this.length; i++) {
    if (i in this) result[i] = fn.call(thisArg, this[i], i, this); // 保持空洞、长度不变
  }
  return result;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(n)，结果数组。
