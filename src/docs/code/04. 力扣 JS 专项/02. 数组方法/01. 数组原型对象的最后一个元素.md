# 数组原型对象的最后一个元素

> 难度：简单 | 标签：数组、原型方法 | LeetCode 2619 · [原题链接](https://leetcode.cn/problems/array-prototype-last/)

## 题目描述

请你编写一段代码实现一个数组方法，使任何数组都可以调用 `array.last()` 方法，该方法将返回数组最后一个元素。如果数组中没有元素，则返回 -1。

你可以假设数组是 `JSON.parse` 的输出结果。

**示例 1：**

```
输入：nums = [null, {}, 3]
输出：3
解释：调用 nums.last() 后返回最后一个元素：3。
```

**示例 2：**

```
输入：nums = []
输出：-1
解释：因为此数组没有元素，所以应该返回 -1。
```

**提示：**

- arr 是一个有效的 JSON 数组
- 0 <= arr.length <= 1000

## 题解

::: details 点击查看题解

### 思路

整体策略是直接读 `this[this.length - 1]`：原型方法里的 `this` 就是调用它的那个数组，读末位是 O(1) 操作，也不修改原数组。

判空必须以 `length` 为准：最后一个元素可能是 `null`、`0` 或 `false`，用 `||` 兜底会把这些合法值错误地换成 -1，所以只能写成「空则 -1，否则取末位」的三元判断。示例 1 的首个元素就是 `null`，正说明 JSON 数组里假值很常见。

也可以用 `this.at(-1)`，但空数组上 `at(-1)` 返回的是 `undefined` 而不是 -1，仍要补一次空数组判断，没有更简洁。

### 代码实现

```javascript
Array.prototype.last = function () {
  return this.length === 0 ? -1 : this[this.length - 1];
};
```

### 复杂度分析

- 时间复杂度：O(1)。
- 空间复杂度：O(1)。
