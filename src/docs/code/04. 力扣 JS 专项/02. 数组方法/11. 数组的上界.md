# 数组的上界

> 难度：简单 | 标签：数组、二分查找 | LeetCode 2774（VIP 专属题） · [原题链接](https://leetcode.cn/problems/array-upper-bound/)

## 题目描述

> 本题为 LeetCode VIP 专属题，官方题面需登录后查看，以下为按原题题意整理的版本。

编写代码增强所有数组，使你可以在任意数组上调用 `upperBound()` 方法，返回给定目标数字 `target` 的最后一个索引。`nums` 是一个升序排列的数字数组，可能包含重复项。如果数组中没有找到目标数字，返回 -1。

**示例 1：**

```
输入：nums = [3,4,5], target = 5
输出：2
解释：目标值的最后一个索引是 2。
```

**示例 2：**

```
输入：nums = [1,4,5], target = 2
输出：-1
解释：因为数组中没有数字 2，所以返回 -1。
```

**示例 3：**

```
输入：nums = [3,4,6,6,6,6,7], target = 6
输出：5
解释：目标值的最后一个索引是 5。
```

**提示：**

- 1 <= nums.length <= 10^4
- -10^4 <= nums[i], target <= 10^4
- nums 按升序排序。

**进阶：** 你能将算法的时间复杂度优化到 O(log n) 吗？

## 题解

::: details 点击查看题解

### 思路

整体策略是二分：找到「第一个大于 `target` 的位置」`left`（即 C++ `upper_bound` 的语义），如果 `nums[left - 1] === target`，它就是最后一个出现位置；否则数组里没有 `target`，返回 -1。

循环不变量要讲清楚：结束时 `[0, left)` 内全部 `<= target`，`[left, n)` 内全部 `> target`。`mid` 处的值比 `target` 大时收缩右边界 `right = mid`（mid 可能就是分界线，必须保留），否则 `left = mid + 1`，这样 `left` 会停在分界线上。

边界逐个过：`target` 小于所有元素时 `left = 0`，取不到 `left - 1`，直接返回 -1；`target` 大于等于末尾元素时 `left = n`，检查 `nums[n - 1]` 即可；重复项全部被二分压到分界线左侧，取前一位正好是最后一次出现（示例 3）。

一行写法是 `this.lastIndexOf(target)`，代码最短但最坏 O(n)，不满足进阶要求 —— 面试时先给 O(log n) 的二分，再补这一行做对比更稳妥。

原型方法里的 `this` 即调用它的数组；题面没有禁用内置方法，但按进阶要求应实现手写二分，读取操作不修改原数组。

### 代码实现

```javascript
Array.prototype.upperBound = function (target) {
  let left = 0;
  let right = this.length;
  while (left < right) {
    const mid = (left + right) >> 1;
    if (this[mid] > target) {
      right = mid; // mid 可能是分界线，保留
    } else {
      left = mid + 1;
    }
  }
  // left 是第一个大于 target 的位置，看它前一位是否命中
  return left > 0 && this[left - 1] === target ? left - 1 : -1;
};
```

### 复杂度分析

- 时间复杂度：O(log n)。
- 空间复杂度：O(1)。
