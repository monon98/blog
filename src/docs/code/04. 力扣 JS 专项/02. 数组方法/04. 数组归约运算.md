# 数组归约运算

> 难度：简单 | 标签：数组、高阶函数 | LeetCode 2626 · [原题链接](https://leetcode.cn/problems/array-reduce-transformation/)

## 题目描述

给定一个整数数组 `nums`、一个 reducer 函数 `fn` 和一个初始值 `init`，返回通过依次对数组的每个元素执行 `fn` 函数得到的最终结果。

通过以下操作实现这个结果：`val = fn(init, nums[0])`，`val = fn(val, nums[1])`，`val = fn(val, nums[2])`，…… 直到处理数组中的每个元素。然后返回 `val` 的最终值。

如果数组的长度为 0，则函数应返回 `init`。

请你在不使用内置的 `Array.reduce` 方法的前提下解决这个问题。

**示例 1：**

```
输入：
nums = [1,2,3,4]
fn = function sum(accum, curr) { return accum + curr; }
init = 0
输出：10
解释：
初始值为 init = 0。
(0) + nums[0] = 1
(1) + nums[1] = 3
(3) + nums[2] = 6
(6) + nums[3] = 10
val 最终值为 10。
```

**示例 2：**

```
输入：
nums = [1,2,3,4]
fn = function sum(accum, curr) { return accum + curr * curr; }
init = 100
输出：130
解释：
初始值为 init = 100。
(100) + nums[0]^2 = 101
(101) + nums[1]^2 = 105
(105) + nums[2]^2 = 114
(114) + nums[3]^2 = 130
val 最终值为 130。
```

**示例 3：**

```
输入：
nums = []
fn = function sum(accum, curr) { return 0; }
init = 25
输出：25
解释：这是一个空数组，所以返回 init。
```

**提示：**

- 0 <= nums.length <= 1000
- 0 <= nums[i] <= 1000
- 0 <= init <= 1000

## 题解

::: details 点击查看题解

### 思路

整体策略是把 `init` 作为累加器起点存进 `val`，循环里顺序执行 `val = fn(val, num)`，结束返回 `val`；空数组时循环一次都不走，自然返回 `init`，不需要特判（示例 3）。

本题 `fn` 只用到 `(accum, curr)` 两个参数；原生 `reduce` 的回调其实还接收 `(acc, curr, index, array)`，并且支持第二个参数 `thisArg`，只是这道题的签名没有暴露它们，实现时按需传两参即可。

面试手写原生 `reduce` 时有三个最常写错的分支：① 未提供初始值时要跳过空洞、找第一个元素作为起步累加器；② 空数组且无初始值时抛 `TypeError`；③ 稀疏数组要用 `i in this` 判断槽位存在、跳过空洞。本题 `init` 恒有、输入是 JSON 稠密数组，这三个分支都不会触发，实现退化为最简循环 —— 但答完本题后主动把它们讲出来是加分项（完整手写见下方扩展代码）。

本题明令禁止使用内置 `Array.reduce`，普通 for 循环或 for...of 最稳；注意不要顺手用 `forEach` 去改外层变量绕过限制，那样显得没有理解归约语义。

### 代码实现

```javascript
var reduce = function (nums, fn, init) {
  let val = init;
  for (const num of nums) {
    val = fn(val, num); // 累加器逐个元素推进
  }
  return val;
};
```

扩展：面试手写「原生 `Array.reduce` 完整版」，覆盖上面提到的三个边界分支：

```javascript
Array.prototype.myReduce = function (fn, initialValue) {
  let acc = initialValue;
  let start = 0;
  if (arguments.length < 2) {
    // 未提供初始值：跳过空洞，找第一个存在的元素起步
    while (start < this.length && !(start in this)) start++;
    if (start === this.length) {
      throw new TypeError("Reduce of empty array with no initial value");
    }
    acc = this[start++];
  }
  for (let i = start; i < this.length; i++) {
    if (i in this) acc = fn(acc, this[i], i, this); // 稀疏数组跳过空洞
  }
  return acc;
};
```

### 复杂度分析

- 时间复杂度：O(n)。
- 空间复杂度：O(1)（扩展版同样 O(1)）。
