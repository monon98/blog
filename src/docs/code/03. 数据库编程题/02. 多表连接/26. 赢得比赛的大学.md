# 赢得比赛的大学

> 难度：简单 | 标签：分组聚合、子查询 | [LeetCode 原题](https://leetcode.cn/problems/the-winner-university/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `NewYork`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| student_id  | int  |
| score       | int  |
+-------------+------+
在 SQL 中，student_id 是该表的主键。
每一行包含纽约大学（New York University）一名学生的考试成绩。
```

表 `California`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| student_id  | int  |
| score       | int  |
+-------------+------+
在 SQL 中，student_id 是该表的主键。
每一行包含加利福尼亚大学（California University）一名学生的考试成绩。
```

纽约大学与加利福尼亚大学之间有一场比赛，两校派出**人数相同**的学生参赛。**优秀学生**（excellent student）指考试成绩 **≥ 90** 的学生。拥有更多优秀学生的一方获胜；若两校优秀学生数量相同，则比赛以平局收场。

返回一个字符串 `winner`：

- 纽约大学获胜时返回 `"New York University"`；
- 加利福尼亚大学获胜时返回 `"California University"`；
- 平局时返回 `"No Winner"`。

**示例 1：**

```
输入：
NewYork 表：
+------------+-------+
| student_id | score |
+------------+-------+
| 1          | 90    |
| 2          | 87    |
+------------+-------+
California 表：
+------------+-------+
| student_id | score |
+------------+-------+
| 2          | 89    |
| 3          | 88    |
+------------+-------+
输出：
+---------------------+
| winner              |
+---------------------+
| New York University |
+---------------------+
解释：
纽约大学有 1 名优秀学生（90 分），加利福尼亚大学有 0 名，纽约大学获胜。
```

## 题解

::: details 点击查看题解

### 思路

两表结构完全对称，且**不需要按学生关联**（题目只比较人数），所以只要各自统计"分数 ≥ 90 的学生数"，再做一次三路比较即可。用两个标量子查询（或 `FROM` 里两个派生表做笛卡尔积）各拿一个计数，外层 `CASE WHEN` 决定输出哪个字符串。

三个易错点：其一，优秀线是 **`>= 90`**（90 分及以上），写成 `> 90` 会让示例 1 的 90 分学生落空，结果从 `New York University` 变成 `No Winner`；其二，三个返回值字符串必须**一字不差**——`New York University`、`California University`、`No Winner`（注意大小写和空格，平局不是 `Tie`）；其三，两表行数可能不同、学生也可能重号，绝不能 `JOIN student_id` 比较，那是另一道题。

`score` 直接 `COUNT(*)` 配 `WHERE score >= 90` 即可，不需要 `DISTINCT`——`student_id` 是主键，每行就是一个学生。替代写法：把两个聚合成一行 `SELECT (SELECT COUNT(*) ...) AS ny, (SELECT COUNT(*) ...) AS ca`，再套一层 `CASE`，行数更少，执行计划也一致。

### SQL 实现

```sql
SELECT CASE
        WHEN n.cnt > c.cnt THEN 'New York University'
        WHEN n.cnt < c.cnt THEN 'California University'
        ELSE 'No Winner'
    END AS winner
FROM (SELECT COUNT(*) AS cnt FROM NewYork WHERE score >= 90) AS n
CROSS JOIN (SELECT COUNT(*) AS cnt FROM California WHERE score >= 90) AS c;
```

### 复杂度分析

- 时间复杂度：O(m + n)，m、n 分别为两表学生数，各扫描一次计数。
- 空间复杂度：O(1)，两个标量结果与固定长度的输出。

:::
