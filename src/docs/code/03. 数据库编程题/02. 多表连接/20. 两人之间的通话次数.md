# 两人之间的通话次数

> 难度：中等 | 标签：分组聚合、多表连接 | [LeetCode 原题](https://leetcode.cn/problems/number-of-calls-between-two-persons/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Calls`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| from_id     | int     |
| to_id       | int     |
| duration    | int     |
+-------------+---------+
该表没有主键，可能包含重复行。
此表的每一行都包含 from_id 和 to_id 之间的一次通话及时长（单位：秒）。
from_id != to_id。
```

编写解决方案，统计每一对不同的用户 `(person1, person2)`（其中 `person1 < person2`）之间的**通话次数**与**总通话时长**。

`A 打给 B` 和 `B 打给 A` 属于同一对用户，需要合并统计；返回 `person1`、`person2`、`call_count`、`total_duration` 四列，以任意顺序返回。

**示例 1：**

```
输入：
Calls 表：
+---------+-------+----------+
| from_id | to_id | duration |
+---------+-------+----------+
| 1       | 2     | 59       |
| 2       | 1     | 11       |
| 1       | 3     | 20       |
| 3       | 4     | 100      |
| 3       | 4     | 200      |
| 3       | 4     | 200      |
| 4       | 3     | 499      |
+---------+-------+----------+
输出：
+---------+---------+------------+----------------+
| person1 | person2 | call_count | total_duration |
+---------+---------+------------+----------------+
| 1       | 2       | 2          | 70             |
| 1       | 3       | 1          | 20             |
| 3       | 4       | 4          | 999            |
+---------+---------+------------+----------------+
解释：
用户 1 和 2 共通话 2 次，总时长 70（59 + 11）。
用户 1 和 3 共通话 1 次，总时长 20。
用户 3 和 4 共通话 4 次，总时长 999（100 + 200 + 200 + 499）。
```

## 题解

::: details 点击查看题解

### 思路

通话是**无向**的：`(1,2)` 和 `(2,1)` 是同一对人，而表里两个方向各存一行。所以第一步是把每行**规范化**成「小 ID 在前」的一对，`LEAST(from_id, to_id)` 取较小者作为 `person1`，`GREATEST(from_id, to_id)` 取较大者作为 `person2`。规范化之后再按这两列分组，方向不同的行自然落进同一组。

分组后就是纯聚合：`COUNT(*)` 统计通话次数，`SUM(duration)` 累加总时长。注意表**没有主键、允许重复行**，示例里 `(3,4,200)` 出现了两次，必须按普通行计数，任何 `DISTINCT` 都会把真实通话抹掉。

易错点：一是忘了方向归一化，结果里同时出现 `(1,2)` 和 `(2,1)` 两组；二是用 `COUNT(DISTINCT ...)` 去"去重"，把重复但真实的通话删掉；三是分组时直接 `GROUP BY from_id, to_id`，同样会拆成两组。另外 `LEAST`/`GREATEST` 写在 `GROUP BY` 里、或先在子查询里算好 `person1`/`person2` 再外层分组，两种写法都行；MySQL 8 也允许 `GROUP BY 1, 2`（按 select 列序号），但显式重复表达式可读性更好。

### SQL 实现

```sql
SELECT
    LEAST(from_id, to_id) AS person1,
    GREATEST(from_id, to_id) AS person2,
    COUNT(*) AS call_count,
    SUM(duration) AS total_duration
FROM Calls
GROUP BY LEAST(from_id, to_id), GREATEST(from_id, to_id);
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为通话记录数，聚合本身 O(n)，排序去重的代价在分组阶段。
- 空间复杂度：O(p)，p 为不同用户对的数量。
