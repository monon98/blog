# 三人国家代表队

> 难度：简单 | 标签：多表连接 | [LeetCode 原题](https://leetcode.cn/problems/all-valid-triplets-that-can-represent-a-country/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `SchoolA`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| student_id    | int     |
| student_name  | varchar |
+---------------+---------+
student_id 是该表中具有唯一值的列。
该表的每一行表示 A 校的一名学生及其 id 和姓名。
所有 student_name 互不相同。
```

表 `SchoolB`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| student_id    | int     |
| student_name  | varchar |
+---------------+---------+
student_id 是该表中具有唯一值的列。
该表的每一行表示 B 校的一名学生及其 id 和姓名。
所有 student_name 互不相同。
```

表 `SchoolC`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| student_id    | int     |
| student_name  | varchar |
+---------------+---------+
student_id 是该表中具有唯一值的列。
该表的每一行表示 C 校的一名学生及其 id 和姓名。
所有 student_name 互不相同。
```

某个国家有三所学校，每名学生 **恰好只在一所学校** 注册。该国要派 **每校各一人** 组队参加比赛，要求：

- `member_A` 从 `SchoolA` 中选出；

- `member_B` 从 `SchoolB` 中选出；

- `member_C` 从 `SchoolC` 中选出；

- 三名学生的 **姓名和 ID 两两互不相同**（任意两人不能同名，也不能同 ID）。

编写解决方案，找出所有能代表该国家的合法三人组。

返回结果表 **无顺序要求**。

结果格式如下所示。

**示例 1：**

```
输入：
SchoolA 表：
+------------+--------------+
| student_id | student_name |
+------------+--------------+
| 1          | Alice        |
| 2          | Bob          |
+------------+--------------+
SchoolB 表：
+------------+--------------+
| student_id | student_name |
+------------+--------------+
| 3          | Tom          |
+------------+--------------+
SchoolC 表：
+------------+--------------+
| student_id | student_name |
+------------+--------------+
| 3          | Tom          |
| 2          | Jerry        |
| 10         | Alice        |
+------------+--------------+
输出：
+----------+----------+----------+
| member_A | member_B | member_C |
+----------+----------+----------+
| Alice    | Tom      | Jerry    |
| Bob      | Tom      | Alice    |
+----------+----------+----------+
解释：
列举所有可能的三人组：
- (Alice, Tom, Tom)：member_B 与 member_C 姓名、ID 都相同，不合法。
- (Alice, Tom, Jerry)：合法。
- (Alice, Tom, Alice)：member_A 与 member_C 姓名相同，不合法。
- (Bob, Tom, Tom)：member_B 与 member_C 姓名、ID 都相同，不合法。
- (Bob, Tom, Jerry)：member_A 与 member_C 的 ID 都是 2，不合法。
- (Bob, Tom, Alice)：合法。
```

## 题解

::: details 点击查看题解

### 思路

三张小表、无连接键、要枚举所有组合——这就是 **三表笛卡尔积** 的应用场景：`FROM SchoolA a, SchoolB b, SchoolC c` 会生成 `|A| × |B| × |C|` 个候选三人组，再用 `WHERE` 逐条筛掉不合法的。

筛选条件是六个不等式：姓名两两不等（`a.name <> b.name`、`a.name <> c.name`、`b.name <> c.name`）**且** ID 两两不等（`a.id <> b.id`、`a.id <> c.id`、`b.id <> c.id`）。容易漏掉的是 **ID 维度**：示例里 `(Bob, Tom, Jerry)` 姓名全不同，但 Bob 和 Jerry 的 `student_id` 都是 2，官方把它判为不合法——如果只写三个姓名比较，就会多输出这一行。反过来只写 ID 比较也不行，`(Alice, Tom, Alice)` 的 ID 是 1、3、10 全不同，却因重名要被剔除。两个维度必须同时约束。

写法上，MySQL 支持 `JOIN ... JOIN ...` 不带 `ON`（等价于逗号连接），但逗号形式 `FROM A, B, C WHERE ...` 是最不易歧义的经典写法，连接条件统一放 `WHERE`。输出列名是 `member_A、member_B、member_C`，别直接输出 `student_name`。注意 SQL 中 `<>` 与 `!=` 等价；也不要用 `NOT (a.name = b.name AND ...)` 这种容易写错德摩根律的形式。替代思路：若某校人数很大，可先两两连接并过滤再与第三张表连接，把笛卡尔积拆小，但本题数据量下没有收益。

### SQL 实现

```sql
SELECT
    a.student_name AS member_A,
    b.student_name AS member_B,
    c.student_name AS member_C
FROM SchoolA a, SchoolB b, SchoolC c
WHERE a.student_name <> b.student_name
  AND a.student_name <> c.student_name
  AND b.student_name <> c.student_name
  AND a.student_id <> b.student_id
  AND a.student_id <> c.student_id
  AND b.student_id <> c.student_id;
```

### 复杂度分析

- 时间复杂度：O(|A| × |B| × |C|)，枚举全部组合并逐条判定。
- 空间复杂度：O(1)，除结果集外无需额外空间。

:::
