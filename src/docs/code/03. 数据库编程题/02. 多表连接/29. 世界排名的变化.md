# 世界排名的变化

> 难度：中等 | 标签：窗口函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/the-change-in-global-rankings/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `TeamPoints`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| team_id     | int     |
| name        | varchar |
| points      | int     |
+-------------+---------+
team_id 是该表的主键，具有唯一值。
每一行包含一支国家队的 ID、它所代表国家的名称，以及它在全球排名中的积分。
不会有两支队伍代表同一个国家。
```

表 `PointsChange`：

```
+---------------+------+
| Column Name   | Type |
+---------------+------+
| team_id       | int  |
| points_change | int  |
+---------------+------+
team_id 是该表的主键，具有唯一值。
每一行包含一支国家队的 ID 及其全球排名积分的变化值。
points_change 的含义：
- 0：积分不变；
- 正数：积分增加；
- 负数：积分减少。
TeamPoints 中出现的每个 team_id 也会出现在本表中。
```

一支国家队的**全球排名**是把所有队伍按积分**降序**排序后的名次；**若两队积分相同，则按队名字典序（lexicographical order）升序**打破平局。

每支队伍的积分要按 `points_change` 更新（新积分 = 原积分 + 变化值）。编写解决方案，计算积分更新后**排名的变化**。

`rank_diff = 更新前的名次 - 更新后的名次`：名次上升（数字变小）结果为正，下降为负，不变为 0。返回 `team_id`、`name`、`rank_diff`，以任意顺序返回。

**示例 1：**

```
输入：
TeamPoints 表：
+---------+-------------+--------+
| team_id | name        | points |
+---------+-------------+--------+
| 3       | Algeria     | 1431   |
| 1       | Senegal     | 2132   |
| 2       | New Zealand | 1402   |
| 4       | Croatia     | 1817   |
+---------+-------------+--------+
PointsChange 表：
+---------+---------------+
| team_id | points_change |
+---------+---------------+
| 3       | 399           |
| 2       | 0             |
| 4       | 13            |
| 1       | -22           |
+---------+---------------+
输出：
+---------+-------------+-----------+
| team_id | name        | rank_diff |
+---------+-------------+-----------+
| 1       | Senegal     | 0         |
| 4       | Croatia     | -1        |
| 3       | Algeria     | 1         |
| 2       | New Zealand | 0         |
+---------+-------------+-----------+
解释：
更新前的排名：
| team_id | name        | points | rank |
| 1       | Senegal     | 2132   | 1    |
| 4       | Croatia     | 1817   | 2    |
| 3       | Algeria     | 1431   | 3    |
| 2       | New Zealand | 1402   | 4    |
更新后的排名（Algeria 与 Croatia 同为 1830 分，按字典序 Algeria 在前）：
| team_id | name        | points | rank |
| 1       | Senegal     | 2110   | 1    |
| 3       | Algeria     | 1830   | 2    |
| 4       | Croatia     | 1830   | 3    |
| 2       | New Zealand | 1402   | 4    |
Senegal 少了 22 分，名次没变；Croatia 多 13 分，名次下降一位；
Algeria 多 399 分，名次上升一位；New Zealand 积分不变，名次也不变。
```

## 题解

::: details 点击查看题解

### 思路

要算的是**两次排名的差**：一次按原积分排，一次按新积分排，同一支队两次名次相减。所以整条 SQL 只做两件事——先把 `PointsChange` 按队聚合出积分变化量（`SUM(points_change)`，防止同队多行），再在 `TeamPoints` 上用两个 `RANK()` 窗口分别算"旧名次"和"新名次"。

排序规则是本题的**最大坑**：`ORDER BY points DESC` 之后**必须再 `ORDER BY name`**。示例里 Algeria 和 Croatia 更新后同为 1830 分，不加队名就由数据库实现决定顺序，可能算出 `rank_diff` 为 0/0 或 ±1 的随机结果；题目明确要求按字典序破平局，加了 `name` 才稳定得到 Algeria 第 2、Croatia 第 3。

平局的处理也值得注意：因为有队名兜底，排序键必然唯一，`RANK()`、`DENSE_RANK()`、`ROW_NUMBER()` 三者结果相同，用哪个都对；若没有队名兜底，就必须用 `RANK()`/`DENSE_RANK()` 并想清楚并列语义。另外 `rank_diff` 的符号方向别搞反——**旧名次 - 新名次**，名次从 2 变 1 是上升，应为正数。

还有一个只在 MySQL 里才会踩的坑：窗口函数 `RANK()` 返回的是**无符号** BIGINT，直接相减在"名次下降"（结果为负）时会抛 `BIGINT UNSIGNED value is out of range`。所以两次 `RANK()` 都要先 `CAST(... AS SIGNED)` 转成有符号数再相减，这一步在示例数据上就会触发（Croatia 的 `rank_diff` 是 -1），不是可有可无的写法。

替代写法：把"新积分"算出来后先物化成一个 CTE，再在两次 `RANK()` 的 `OVER` 里分别引用原列和新列，可读性更好；也可以分两次子查询各排一次名再 `JOIN` 相减，但多一次连接，窗口函数一次扫表就能完成。

### SQL 实现

```sql
WITH delta AS (
    SELECT team_id, SUM(points_change) AS points_change
    FROM PointsChange
    GROUP BY team_id
)
SELECT
    t.team_id,
    t.name,
    CAST(RANK() OVER (ORDER BY t.points DESC, t.name) AS SIGNED)
        - CAST(RANK() OVER (ORDER BY t.points + d.points_change DESC, t.name) AS SIGNED) AS rank_diff
FROM TeamPoints AS t
JOIN delta AS d
  ON t.team_id = d.team_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为队伍数，两次窗口排序各 O(n log n)，聚合 O(m)（m 为 `PointsChange` 行数）。
- 空间复杂度：O(n)，保存聚合结果与两个排名窗口。

:::

## 建表与测试数据

```sql
Create table If Not Exists TeamPoints (team_id int, name varchar(100), points int);
Create table If Not Exists PointsChange (team_id int, points_change int);
Truncate table TeamPoints;
insert into TeamPoints (team_id, name, points) values ('3', 'Algeria', '1431');
insert into TeamPoints (team_id, name, points) values ('1', 'Senegal', '2132');
insert into TeamPoints (team_id, name, points) values ('2', 'New Zealand', '1402');
insert into TeamPoints (team_id, name, points) values ('4', 'Croatia', '1817');
Truncate table PointsChange;
insert into PointsChange (team_id, points_change) values ('3', '399');
insert into PointsChange (team_id, points_change) values ('2', '0');
insert into PointsChange (team_id, points_change) values ('4', '13');
insert into PointsChange (team_id, points_change) values ('1', '-22');
```
