# 矩形面积

> 难度：中等 | 标签：多表连接、排序 | [LeetCode 原题](https://leetcode.cn/problems/rectangles-area/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Points`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| id            | int     |
| x_value       | int     |
| y_value       | int     |
+---------------+---------+
id 是该表中具有唯一值的列。
每个点都用二维坐标 (x_value, y_value) 表示。
```

编写解决方案，报告由表中 **任意两点** 可以形成的所有 **边与坐标轴平行且面积不为零** 的矩形。

结果表中的每一行包含三列 `(p1, p2, area)`，其中：

- `p1` 和 `p2` 是确定矩形一对对角线的两个点的 `id`；

- `area` 是该矩形的面积，必须 **不为零**。

返回结果表请按面积 `area` **降序** 排列；面积相同时按 `p1` **升序**；仍相同时按 `p2` **升序**。

结果格式如下例所示。

**示例 1：**

```
输入：
Points 表:
+----------+-------------+-------------+
| id       | x_value     | y_value     |
+----------+-------------+-------------+
| 1        | 2           | 7           |
| 2        | 4           | 8           |
| 3        | 2           | 10          |
+----------+-------------+-------------+
输出：
+------+------+------+
| p1   | p2   | area |
+------+------+------+
| 2    | 3    | 4    |
| 1    | 2    | 2    |
+------+------+------+
解释：
p1 = 2、p2 = 3 时，面积等于 |4-2| * |8-10| = 4。
p1 = 1、p2 = 2 时，面积等于 |2-4| * |7-8| = 2。
点 1 和点 3 的 x 坐标相同，形成的矩形面积为 0，不合法。
```

## 题解

::: details 点击查看题解

### 思路

平面内任取两点，若它们 **x、y 坐标都不同**，就能唯一确定一个边与坐标轴平行的矩形，面积为 `|x1 - x2| × |y1 - y2|`；只要有一个坐标相同，两点就落在同一条水平线或垂直线上，构成的「矩形」面积为 0，必须剔除（示例里的点 1 与点 3 正是 x 相同的反例）。

做法是把 `Points` **自连接**，用 `p1.id < p2.id` 限定每对点只出现一次——这点很关键：不加限定的话 (1,2) 和 (2,1) 会各出一行，等于把所有组合算两遍，还可能让 `p1 > p2` 的行混进结果。面积直接 `ABS(...)` 相乘，`WHERE` 里排除坐标相同的点对。

排序是题面硬要求：`ORDER BY area DESC, p1 ASC, p2 ASC`，三档排序缺一不可（只有面积降序时，并列行的顺序未定义，判题会挂）。别名 `p1、p2、area` 在 `ORDER BY` 中可以直接使用。一个常见的思路弯路是想「先算面积再过滤 `area > 0`」——结果等价，但把「坐标不同」这个几何条件显式写进 `WHERE` 语义更清楚。此题本质是笛卡尔积的带条件版本，数据量小时自连接完全够用；点集很大时才需要考虑按 x、y 排序做扫描优化，SQL 题里不必展开。

### SQL 实现

```sql
SELECT
    p1.id AS p1,
    p2.id AS p2,
    ABS(p1.x_value - p2.x_value) * ABS(p1.y_value - p2.y_value) AS area
FROM Points p1
JOIN Points p2 ON p1.id < p2.id
WHERE p1.x_value <> p2.x_value
  AND p1.y_value <> p2.y_value
ORDER BY area DESC, p1 ASC, p2 ASC;
```

### 复杂度分析

- 时间复杂度：O(n² + n² log n²)，n 为点数，自连接产生 O(n²) 对后排序。
- 空间复杂度：O(n²)，连接结果集的开销。

:::

```sql
Create table If Not Exists Points (id int, x_value int, y_value int);
Truncate table Points;

```
