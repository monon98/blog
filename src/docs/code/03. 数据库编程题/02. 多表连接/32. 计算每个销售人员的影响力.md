# 计算每个销售人员的影响力

> 难度：中等 | 标签：多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/calculate-the-influence-of-each-salesperson/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Salesperson`：

```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| salesperson_id | int     |
| name           | varchar |
+----------------+---------+
salesperson_id 具有唯一值。
每一行表示一名销售人员的 ID 与姓名。
```

表 `Customer`：

```
+----------------+------+
| Column Name    | Type |
+----------------+------+
| customer_id    | int  |
| salesperson_id | int  |
+----------------+------+
customer_id 具有唯一值。
salesperson_id 是引用 Salesperson 表的外键。
每一行表示一名客户及其对应的销售人员。
```

表 `Sales`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| sale_id     | int  |
| customer_id | int  |
| price       | int  |
+-------------+------+
sale_id 具有唯一值。
customer_id 是引用 Customer 表的外键。
每一行表示 ID 为 sale_id 的这笔销售的成交金额 price。
```

编写解决方案，统计**每位销售人员名下客户消费金额的总和**。若某销售人员没有任何客户，总额记为 0。

返回 `salesperson_id`、`name`、`total` 三列，以任意顺序返回。

**示例 1：**

```
输入：
Salesperson 表：
+----------------+-------+
| salesperson_id | name  |
+----------------+-------+
| 1              | Alice |
| 2              | Bob   |
| 3              | Jerry |
+----------------+-------+
Customer 表：
+-------------+----------------+
| customer_id | salesperson_id |
+-------------+----------------+
| 1           | 1              |
| 2           | 1              |
| 3           | 2              |
+-------------+----------------+
Sales 表：
+---------+-------------+-------+
| sale_id | customer_id | price |
+---------+-------------+-------+
| 1       | 2           | 892   |
| 2       | 1           | 354   |
| 3       | 3           | 988   |
| 4       | 3           | 856   |
+---------+-------------+-------+
输出：
+----------------+-------+-------+
| salesperson_id | name  | total |
+----------------+-------+-------+
| 1              | Alice | 1246  |
| 2              | Bob   | 1844  |
| 3              | Jerry | 0     |
+----------------+-------+-------+
解释：
Alice 是客户 1 和 2 的销售：客户 1 消费 354，客户 2 消费 892，合计 1246。
Bob 是客户 3 的销售：客户 3 消费 988 + 856 = 1844。
Jerry 没有任何客户，总额为 0。
```

## 题解

::: details 点击查看题解

### 思路

从 `Salesperson` 出发，依次左连 `Customer`（销售 → 客户）、再左连 `Sales`（客户 → 消费记录），形成一条"人 → 客户 → 订单"的链路，按 `salesperson_id` 分组求 `SUM(price)` 就是影响力总额。

用 **`LEFT JOIN` 而不是 `INNER JOIN`** 是本题的胜负手：`INNER JOIN` 会把没有任何客户的 Jerry（3 号）直接过滤掉，而题目要求他出现在结果里且 `total = 0`。链条上任何一环断了（没客户、或客户没订单）都必须保留左表行。

配套地，`SUM(price)` 在全为 `NULL` 的组里返回 `NULL`，要用 `IFNULL(SUM(price), 0)`（`COALESCE` 同效）转成 0，否则输出 `NULL` 与期望的 `0` 不一致——两个细节缺一不可。

分组建议写 `GROUP BY sp.salesperson_id, sp.name`（或等价的 `GROUP BY sp.salesperson_id` + 函数依赖），保证在 `ONLY_FULL_GROUP_BY` 模式下也能跑；`salesperson_id` 是主键，`name` 函数依赖于它。易错点还有：`SUM` 之前不要 `DISTINCT`，同一客户的多笔订单（示例中客户 3 有两笔）都要累加。替代写法：先在子查询里按 `customer_id` 聚合出每个客户的消费，再连回 `Salesperson`，行数更小，结果相同。

### SQL 实现

```sql
SELECT
    sp.salesperson_id,
    sp.name,
    IFNULL(SUM(s.price), 0) AS total
FROM Salesperson AS sp
LEFT JOIN Customer AS c
  ON sp.salesperson_id = c.salesperson_id
LEFT JOIN Sales AS s
  ON s.customer_id = c.customer_id
GROUP BY sp.salesperson_id, sp.name;
```

### 复杂度分析

- 时间复杂度：O(c + s)，c 为客户数、s 为订单数，两次连接后一次分组聚合。
- 空间复杂度：O(p)，p 为销售人数，用于存放分组结果。

:::

```sql
Create table If Not Exists Salesperson (salesperson_id int, name varchar(30));
Create table If Not Exists Customer (customer_id int, salesperson_id int);
Create table If Not Exists Sales (sale_id int, customer_id int, price int);
Truncate table Salesperson;
insert into Salesperson (salesperson_id, name) values ('1', 'Alice');
insert into Salesperson (salesperson_id, name) values ('2', 'Bob');
insert into Salesperson (salesperson_id, name) values ('3', 'Jerry');
Truncate table Customer;
insert into Customer (customer_id, salesperson_id) values ('1', '1');
insert into Customer (customer_id, salesperson_id) values ('2', '1');
insert into Customer (customer_id, salesperson_id) values ('3', '2');
Truncate table Sales;
insert into Sales (sale_id, customer_id, price) values ('1', '2', '892');
insert into Sales (sale_id, customer_id, price) values ('2', '1', '354');
insert into Sales (sale_id, customer_id, price) values ('3', '3', '988');
insert into Sales (sale_id, customer_id, price) values ('4', '3', '856');
```
