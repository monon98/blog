# 形成化学键

> 难度：简单 | 标签：多表连接 | [LeetCode 原题](https://leetcode.cn/problems/form-a-chemical-bond/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Elements`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| symbol      | varchar |
| type        | enum    |
| electrons   | int     |
+-------------+---------+
symbol 是该表的主键（具有唯一值的列）。
每一行包含一种元素的信息。
type 是枚举类型，取值为 ('Metal', 'Nonmetal', 'Noble')：
 - 若 type 为 Noble（惰性气体），electrons 为 0；
 - 若 type 为 Metal（金属），electrons 表示一个该原子可以**给出**的电子数；
 - 若 type 为 Nonmetal（非金属），electrons 表示一个该原子**需要**的电子数。
```

当两个元素中一个是 `'Metal'`、另一个是 `'Nonmetal'` 时，它们可以形成化学键。

编写解决方案，找出**所有能形成化学键的元素对**，返回 `metal`（金属元素）与 `nonmetal`（非金属元素）两列，以任意顺序返回。

**示例 1：**

```
输入：
Elements 表：
+--------+----------+-----------+
| symbol | type     | electrons |
+--------+----------+-----------+
| He     | Noble    | 0         |
| Na     | Metal    | 1         |
| Ca     | Metal    | 2         |
| La     | Metal    | 3         |
| Cl     | Nonmetal | 1         |
| O      | Nonmetal | 2         |
| N      | Nonmetal | 3         |
+--------+----------+-----------+
输出：
+-------+----------+
| metal | nonmetal |
+-------+----------+
| Na    | Cl       |
| Na    | O        |
| Na    | N        |
| Ca    | Cl       |
| Ca    | O        |
| Ca    | N        |
| La    | Cl       |
| La    | O        |
| La    | N        |
+-------+----------+
解释：
金属元素有 La、Ca、Na；非金属元素有 Cl、O、N。
每种金属与每种非金属各组成一对，共 3 × 3 = 9 对。
He 是惰性气体，不参与成键。
```

## 题解

::: details 点击查看题解

### 思路

题目本质是**两张筛选后的名单做笛卡尔积**：把 `Elements` 自连接，左表限定 `type = 'Metal'`、右表限定 `type = 'Nonmetal'`，得到所有"金属 × 非金属"的组合，再把两列分别命名为 `metal`、`nonmetal`。

写法上 `CROSS JOIN` 与旧式逗号连接（`FROM Elements a, Elements b WHERE ...`）等价；关键是两个过滤条件的位置——写在 `ON` 里对 `CROSS JOIN` 不起作用（没有匹配条件），必须放在 `WHERE` 或直接写成带 `ON` 的 `INNER JOIN`。示例里 3 金属 × 3 非金属 = 9 行，`Noble` 的 `He` 被条件自然排除。

几个容易想多的地方：**不需要**按 `electrons` 匹配（比如金属给出数 ≥ 非金属需求数），题目只要求类型一金一非金，所有组合都算；也不需要 `WHERE a.symbol <> b.symbol`——类型条件已保证两边不可能是同一元素。易错点是漏掉 `Noble` 要排除、或把两列顺序写反（输出列必须叫 `metal` 和 `nonmetal`，且分别放金属、非金属符号）。结果顺序任意，示例展示的只是其中一种排列。

### SQL 实现

```sql
SELECT a.symbol AS metal, b.symbol AS nonmetal
FROM Elements AS a
CROSS JOIN Elements AS b
WHERE a.type = 'Metal'
  AND b.type = 'Nonmetal';
```

### 复杂度分析

- 时间复杂度：O(n²)，n 为元素行数，最坏做一次全配对（实际由类型条件裁剪为 m × k，m 为金属数、k 为非金属数）。
- 空间复杂度：O(m × k)，输出本身即 m × k 行。

```sql

Truncate table Elements;

insert into Elements (symbol, type, electrons) values ('Na', 'Metal', '1');
insert into Elements (symbol, type, electrons) values ('Ca', 'Metal', '2');
insert into Elements (symbol, type, electrons) values ('La', 'Metal', '3');
insert into Elements (symbol, type, electrons) values ('Cl', 'Nonmetal', '1');
insert into Elements (symbol, type, electrons) values ('O', 'Nonmetal', '2');

```
