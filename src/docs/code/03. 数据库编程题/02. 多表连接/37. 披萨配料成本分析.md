# 披萨配料成本分析

> 难度：中等 | 标签：多表连接、自连接 | [LeetCode 原题](https://leetcode.cn/problems/pizza-toppings-cost-analysis/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Toppings` 表：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| topping_name | varchar |
| cost         | decimal |
+--------------+---------+
topping_name 是这张表的主键。
每一行包含一种配料的名称和单价。
```

连锁披萨店要做一次「三配料披萨」促销，需要评估成本。编写解决方案，计算从给定配料列表中任选 **3 种不同配料** 的所有组合的总成本，总成本保留两位小数。

注意：

- 不允许同一种配料重复出现，例如 `Pepperoni,Pepperoni,Onion` 不合法。
- 每个组合内的配料名必须按字母序排列，例如 `Chicken,Onions,Sausage` 合法，`Onion,Sausage,Chicken` 不合法。

返回结果按 `total_cost` 降序排序，成本相同时按组合名称升序排序。

**示例 1：**

```
输入：
Toppings 表：
+--------------+------+
| topping_name | cost |
+--------------+------+
| Pepperoni    | 0.50 |
| Sausage      | 0.70 |
| Chicken      | 0.55 |
| Extra Cheese | 0.40 |
+--------------+------+

输出：
+--------------------------------+------------+
| pizza                          | total_cost |
+--------------------------------+------------+
| Chicken,Pepperoni,Sausage      | 1.75       |
| Chicken,Extra Cheese,Sausage   | 1.65       |
| Extra Cheese,Pepperoni,Sausage | 1.60       |
| Chicken,Extra Cheese,Pepperoni | 1.45       |
+--------------------------------+------------+

解释：
4 种配料里选 3 种一共有 C(4,3) = 4 种组合：
- Chicken,Pepperoni,Sausage：0.55 + 0.50 + 0.70 = 1.75
- Chicken,Extra Cheese,Sausage：0.55 + 0.40 + 0.70 = 1.65
- Extra Cheese,Pepperoni,Sausage：0.40 + 0.50 + 0.70 = 1.60
- Chicken,Extra Cheese,Pepperoni：0.55 + 0.40 + 0.50 = 1.45
按总成本降序、组合名升序返回。
```

## 题解

::: details 点击查看题解

### 思路

这是经典的「三表自连接求组合」：把 `Toppings` 自连三次当作 t1、t2、t3，用严格不等式 `t1.rk < t2.rk < t3.rk` 约束三者互不相同且顺序唯一，正好生成 C(n,3) 个组合——不等式既排除了重复配料，也天然保证每个组合只出现一次、且三个名字按字母序排列（配合 `CONCAT` 直接得到题目要求的 `pizza` 字符串）。

如果直接用 `topping_name` 的字符串比较写 `t1.topping_name < t2.topping_name < t3.topping_name` 也能得到同样效果；先用 `RANK() OVER (ORDER BY topping_name)` 编号再比较，语义更直观，也避免长字符串反复比较。

易错点：一是漏掉去重约束，三重 `FROM Toppings` 不加条件会产生 n³ 行并包含重复配料；二是排序方向，题目要求 `total_cost DESC, pizza ASC`，与「成本从高到低」的业务直觉一致但别写反；三是 `decimal` 相加的结果直接展示即可，但要留意题目要求保留两位小数，必要时用 `ROUND(..., 2)`。

### SQL 实现

```sql
WITH T AS (
    SELECT *, RANK() OVER (ORDER BY topping_name) AS rk
    FROM Toppings
)
SELECT
    CONCAT(t1.topping_name, ',', t2.topping_name, ',', t3.topping_name) AS pizza,
    ROUND(t1.cost + t2.cost + t3.cost, 2) AS total_cost
FROM T AS t1
JOIN T AS t2 ON t1.rk < t2.rk
JOIN T AS t3 ON t2.rk < t3.rk
ORDER BY total_cost DESC, pizza ASC;
```

### 复杂度分析

- 时间复杂度：O(n³)，三重组合枚举，n 为配料数（组合数为 n(n-1)(n-2)/6）。
- 空间复杂度：O(n)，窗口函数生成的排名。

:::
