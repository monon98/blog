# 计算产品最终价格

> 难度：中等 | 标签：多表连接、外连接 | [LeetCode 原题](https://leetcode.cn/problems/calculate-product-final-price/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Products` 表：

```
+------------+---------+
| Column Name| Type    |
+------------+---------+
| product_id | int     |
| category   | varchar |
| price      | int     |
+------------+---------+
product_id 是这张表的主键。
每一行包含产品的 ID、类别和价格。
```

`Discounts` 表：

```
+------------+----------+
| Column Name| Type     |
+------------+----------+
| category   | varchar  |
| discount   | int      |
+------------+----------+
category 是这张表的主键。
每一行表示某个类别的折扣百分比（取值范围 0 ~ 100）。
```

编写解决方案，计算每个产品应用 **类别折扣** 后的最终价格：`最终价格 = 原价 × (100 - 折扣) / 100`。如果产品所属类别没有对应的折扣记录，则价格保持不变。返回 `product_id`、`final_price`、`category`，按 `product_id` 升序排序。

**示例 1：**

```
输入：
Products 表：
+------------+-------------+-------+
| product_id | category    | price |
+------------+-------------+-------+
| 1          | Electronics | 1000  |
| 2          | Clothing    | 50    |
| 3          | Electronics | 1200  |
| 4          | Home        | 500   |
+------------+-------------+-------+

Discounts 表：
+-------------+----------+
| category    | discount |
+-------------+----------+
| Electronics | 10       |
| Clothing    | 20       |
+-------------+----------+

输出：
+------------+-------------+-------------+
| product_id | final_price | category    |
+------------+-------------+-------------+
| 1          | 900         | Electronics |
| 2          | 40          | Clothing    |
| 3          | 1080        | Electronics |
| 4          | 500         | Home        |
+------------+-------------+-------------+

解释：
- 产品 1 属于 Electronics，折扣 10%，最终价格 1000 - 100 = 900。
- 产品 2 属于 Clothing，折扣 20%，最终价格 50 - 10 = 40。
- 产品 3 属于 Electronics，折扣 10%，最终价格 1200 - 120 = 1080。
- 产品 4 属于 Home，没有折扣记录，价格保持 500。
结果按 product_id 升序排序。
```

## 题解

::: details 点击查看题解

### 思路

这是「维表左连接」的入门题：`Products` 是事实表，每一条产品都必须出现在结果里；`Discounts` 是维度表，某些类别可能没有折扣。因此必须用 `LEFT JOIN`（以 `Products` 为左表），而不是 `INNER JOIN`——后者会把没有折扣的 Home 类产品直接丢掉，这正是本题最大的坑。

连接后没有折扣的行其 `discount` 为 `NULL`，计算时要用 `IFNULL(discount, 0)`（或 `COALESCE`）把 NULL 当 0 处理，价格自然保持原价。写法上 `price * (100 - IFNULL(discount, 0)) / 100` 与 `price - price * IFNULL(discount, 0) / 100` 等价；注意 `discount` 是整数百分比，除法要确保不被整数截断——MySQL 中 `price` 为整数时 `(100 - discount) / 100` 的除数带小数点会触发浮点除法，结果正确，但若写成 `price * (100 - discount) DIV 100` 就会丢精度，应避免。

`Discounts.category` 是主键，左连接不会放大行数，所以不需要去重。替代写法：相关子查询 `COALESCE((SELECT discount FROM Discounts d WHERE d.category = p.category), 0)`，语义相同但可读性稍差。

### SQL 实现

```sql
SELECT
    p.product_id,
    p.price * (100 - IFNULL(d.discount, 0)) / 100 AS final_price,
    p.category
FROM Products AS p
LEFT JOIN Discounts AS d ON p.category = d.category
ORDER BY p.product_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，连接与排序主导，n 为产品数。
- 空间复杂度：O(k)，k 为折扣类别数。

:::

## 建表与测试数据

```sql
Create table if not exists Products (product_id int, category varchar(50), price int);
Create table if not exists Discounts(category varchar(50), discount int);
Truncate table Products;
insert into Products (product_id, category, price) values ('1', 'Electronics', '1000');
insert into Products (product_id, category, price) values ('2', 'Clothing', '50');
insert into Products (product_id, category, price) values ('3', 'Electronics', '1200');
insert into Products (product_id, category, price) values ('4', 'Home', '500');
Truncate table Discounts;
insert into Discounts (category, discount) values ('Electronics', '10');
insert into Discounts (category, discount) values ('Clothing', '20');
```
