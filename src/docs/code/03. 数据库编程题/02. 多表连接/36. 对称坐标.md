# 对称坐标

> 难度：中等 | 标签：多表连接、自连接 | [LeetCode 原题](https://leetcode.cn/problems/symmetric-coordinates/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Coordinates` 表：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| X           | int  |
| Y           | int  |
+-------------+------+
每一行包含整数 X 和 Y。表中可能包含重复值。
```

两个坐标 `(X1, Y1)` 与 `(X2, Y2)` 称为 **对称坐标** ，当且仅当 `X1 = Y2` 且 `X2 = Y1`（即把两行的横纵坐标互换后完全重合）。

编写解决方案，在所有对称坐标中，只输出满足 `X1 <= Y1` 的 **去重后** 的坐标。返回结果按 `X`、`Y` 分别升序排序。

**示例 1：**

```
输入：
Coordinates 表：
+----+----+
| X  | Y  |
+----+----+
| 20 | 20 |
| 20 | 20 |
| 20 | 21 |
| 23 | 22 |
| 22 | 23 |
| 21 | 20 |
+----+----+

输出：
+----+----+
| x  | y  |
+----+----+
| 20 | 20 |
| 20 | 21 |
| 22 | 23 |
+----+----+

解释：
- (20, 20) 与另一行的 (20, 20) 构成对称坐标，去重后输出一次 (20, 20)。
- (20, 21) 与 (21, 20) 互为对称坐标，但只输出满足 X1 <= Y1 的 (20, 21)。
- (23, 22) 与 (22, 23) 互为对称坐标，但只输出满足 X1 <= Y1 的 (22, 23)。
结果按 X、Y 升序排序。
```

## 题解

::: details 点击查看题解

### 思路

对称坐标的本质是「表里同时存在 (x, y) 和 (y, x) 两行」，最直接的表达就是把表和自己连接：`p1.x = p2.y AND p1.y = p2.x`。但有三个坑必须处理。

第一，表 **没有主键**，还有重复行（示例里 (20, 20) 出现两次），如果不给每行编号，自连接时 (20, 20) 会和自己这一行「配对成功」，导致本不该出现的点混进结果。用 `ROW_NUMBER() OVER ()` 给每一行生成唯一 id，再要求 `p1.id <> p2.id` 即可。

第二，加上 `p1.x <= p1.y` 过滤：一对互为对称的坐标只会留下「横坐标不大于纵坐标」的那一半，避免同一对输出两次；对 (20, 20) 这种 `x = y` 的点，该条件天然成立，配合「存在另一行相同的点」的判断仍能正确输出。

第三，即便有 id 区分行，同一坐标仍可能被多行匹配出多次，最后要 `DISTINCT` 去重。替代写法：先 `GROUP BY x, y` 得到去重坐标再自连接，或用 `UNION` 处理 `x = y` 的特例。

### SQL 实现

```sql
WITH P AS (
    SELECT ROW_NUMBER() OVER () AS id, x, y
    FROM Coordinates
)
SELECT DISTINCT p1.x, p1.y
FROM P AS p1
JOIN P AS p2
    ON p1.x = p2.y
    AND p1.y = p2.x
    AND p1.x <= p1.y
    AND p1.id <> p2.id
ORDER BY p1.x, p1.y;
```

### 复杂度分析

- 时间复杂度：O(n²)，自连接最坏两两配对，n 为坐标行数。
- 空间复杂度：O(n)，窗口函数生成的行号与去重结果。

:::
