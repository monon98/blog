# 富有客户的数量

> 难度：简单 | 标签：分组聚合、条件过滤 | [LeetCode 原题](https://leetcode.cn/problems/the-number-of-rich-customers/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Store`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| bill_id     | int     |
| customer_id | int     |
| amount      | int     |
+-------------+---------+
bill_id 是该表中具有唯一值的列。
每一行包含一张账单的金额以及该账单对应的客户。
```

编写解决方案，统计**至少有一张账单金额严格大于 500** 的客户数量。

同一客户有多张达标账单时只计一次；返回一列 `rich_count`。

**示例 1：**

```
输入：
Store 表：
+---------+-------------+--------+
| bill_id | customer_id | amount |
+---------+-------------+--------+
| 6       | 1           | 549    |
| 8       | 1           | 834    |
| 4       | 2           | 394    |
| 11      | 3           | 657    |
| 13      | 3           | 257    |
+---------+-------------+--------+
输出：
+------------+
| rich_count |
+------------+
| 2          |
+------------+
解释：
客户 1 有两张账单金额严格大于 500。
客户 2 没有任何账单金额严格大于 500。
客户 3 有一张账单金额严格大于 500。
因此富有的客户数为 2。
```

## 题解

::: details 点击查看题解

### 思路

先把"富有"定义翻译成行级过滤：`WHERE amount > 500`，剩下的账单都属于富有客户的达标账单。然后统计的是**客户数**而不是账单数，必须 `COUNT(DISTINCT customer_id)`——示例里客户 1 有 549、834 两张达标账单，写成 `COUNT(*)` 会得到 3 而不是 2。

三个易错点：其一，边界是**严格大于** 500，`>= 500` 在本组测试数据里碰巧结果相同（没有正好 500 的账单），换组数据就会错，别因为"样例过了"就放松；其二，先 `GROUP BY customer_id` 再 `HAVING MAX(amount) > 500` 然后 `COUNT(*)` 也能做，但多一次分组，且列别忘了 `COUNT(DISTINCT ...)`；其三，输出列名必须是 `rich_count`，且只有一行一列，多带出 `customer_id` 会导致判题不通过。

### SQL 实现

```sql
SELECT COUNT(DISTINCT customer_id) AS rich_count
FROM Store
WHERE amount > 500;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为账单行数，单次扫描过滤并维护去重集合。
- 空间复杂度：O(c)，c 为达标的不同客户数，用于去重。

:::
