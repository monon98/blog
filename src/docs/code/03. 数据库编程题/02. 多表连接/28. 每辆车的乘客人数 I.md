# 每辆车的乘客人数 I

> 难度：中等 | 标签：多表连接、窗口函数 | [LeetCode 原题](https://leetcode.cn/problems/the-number-of-passengers-in-each-bus-i/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Buses`：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| bus_id       | int  |
| arrival_time | int  |
+--------------+------+
bus_id 是该表中具有唯一值的列。
每一行包含一班车到达 LeetCode 车站的时刻。
不会有两班车在同一时刻到达。
```

表 `Passengers`：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| passenger_id | int  |
| arrival_time | int  |
+--------------+------+
passenger_id 是该表中具有唯一值的列。
每一行包含一名乘客到达 LeetCode 车站的时刻。
```

乘客与班车先后到达车站。若某班车在 `t_bus` 时刻到达，而乘客在 `t_passenger` 时刻到达且满足 `t_passenger <= t_bus`，并且该乘客**尚未上过任何一班车**，那么这名乘客就会乘坐这班车上车（即每人乘坐的是"不早于自己到达时刻"的第一班车）。

编写解决方案，统计**每辆车实际乘坐的乘客数**，按 `bus_id` 升序返回，列名为 `bus_id`、`passengers_cnt`。

**示例 1：**

```
输入：
Buses 表：
+--------+--------------+
| bus_id | arrival_time |
+--------+--------------+
| 1      | 2            |
| 2      | 4            |
| 3      | 7            |
+--------+--------------+
Passengers 表：
+--------------+--------------+
| passenger_id | arrival_time |
+--------------+--------------+
| 11           | 1            |
| 12           | 5            |
| 13           | 6            |
| 14           | 7            |
+--------------+--------------+
输出：
+--------+----------------+
| bus_id | passengers_cnt |
+--------+----------------+
| 1      | 1              |
| 2      | 0              |
| 3      | 3              |
+--------+----------------+
解释：
乘客 11 在时刻 1 到达，班车 1 在时刻 2 到达并接上他。
班车 2 在时刻 4 到达，没有接到任何乘客。
乘客 12、13、14 分别在时刻 5、6、7 到达。
班车 3 在时刻 7 到达，接上乘客 12、13、14（时刻 7 到达的乘客 14 恰好赶上）。
```

## 题解

::: details 点击查看题解

### 思路

关键洞察：**每班车接到的人数 = 截至该班车时刻"已到站的累计人数" - 上一班车接走后的累计人数**。因为先到站的乘客永远上前面的车，晚到的乘客绝不会"插队"坐早发的车，所以按到达时刻排序后，累计人数曲线在每个 `bus_id` 处的**跳变**正好就是该车的载客量。

据此，先把 `Buses` 与 `Passengers` 做一个宽松连接（`p.arrival_time <= b.arrival_time`，即"截至每班车时刻到站的所有乘客"），按车分组 `COUNT` 得到累计人数，再用窗口函数 `LAG(COUNT(...), 1, 0) OVER (ORDER BY arrival_time)` 取上一班车的累计值，两者相减即为本车载客数。注意窗口要按 **`arrival_time`** 排序而不是 `bus_id`——题目只保证输出按 `bus_id` 升序，若数据里 `bus_id` 顺序与到站顺序不一致，按 `bus_id` 取 `LAG` 就会减错。

`LAG` 的第三个参数 `0` 是帧内无值时的默认值（第一辆车没有"上一班车"，直接减 0）。`COUNT(p.passenger_id)` 用列名而非 `COUNT(*)`，配合 `LEFT JOIN` 才能让"没有乘客的车"得到 0（如示例的班车 2），写成 `COUNT(*)` 会把 `NULL` 也算成 1。

替代思路：先给每名乘客分配"他要坐的那班车的到站时刻"`(SELECT MIN(arrival_time) FROM Buses WHERE arrival_time >= p.arrival_time)`，再按车 `LEFT JOIN` 计数，结果一致，直观但多一层相关子查询。

### SQL 实现

```sql
SELECT
    b.bus_id,
    COUNT(p.passenger_id)
        - LAG(COUNT(p.passenger_id), 1, 0) OVER (ORDER BY b.arrival_time) AS passengers_cnt
FROM Buses AS b
LEFT JOIN Passengers AS p
  ON p.arrival_time <= b.arrival_time
GROUP BY b.bus_id, b.arrival_time
ORDER BY b.bus_id;
```

### 复杂度分析

- 时间复杂度：O(B × P)，B 为班次数、P 为乘客数，连接产生累计人数，窗口计算 O(B log B)。
- 空间复杂度：O(B × P)，连接中间结果的规模。

:::
