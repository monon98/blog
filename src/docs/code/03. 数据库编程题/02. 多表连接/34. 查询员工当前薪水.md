# 查询员工当前薪水

> 难度：简单 | 标签：窗口函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/find-latest-salaries/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Salary`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| emp_id        | int     |
| firstname     | varchar |
| lastname      | varchar |
| salary        | int     |
| department_id | varchar |
+---------------+---------+
(emp_id, salary) 是该表的主键。
每一行包含员工的详细信息与他的年薪，但其中部分记录是过时的旧薪水。
```

假设**员工的薪水逐年递增**，编写解决方案，求出每位员工**当前的薪水记录**（即该员工所有记录里金额最高的那条），输出 `emp_id`、`firstname`、`lastname`、`salary`、`department_id` 五列，按 `emp_id` 升序返回。

**示例 1：**

```
输入：
Salary 表：
+--------+-----------+----------+--------+---------------+
| emp_id | firstname | lastname | salary | department_id |
+--------+-----------+----------+--------+---------------+
| 1      | Todd      | Wilson   | 110000 | D1006         |
| 1      | Todd      | Wilson   | 106119 | D1006         |
| 2      | Justin    | Simon    | 128922 | D1005         |
| 2      | Justin    | Simon    | 130000 | D1005         |
| 3      | Kelly     | Rosario  | 42689  | D1002         |
| 4      | Patricia  | Powell   | 162825 | D1004         |
| 4      | Patricia  | Powell   | 170000 | D1004         |
| 5      | Sherry    | Golden   | 44101  | D1002         |
| 6      | Natasha   | Swanson  | 79632  | D1005         |
| 6      | Natasha   | Swanson  | 90000  | D1005         |
+--------+-----------+----------+--------+---------------+
输出：
+--------+-----------+----------+--------+---------------+
| emp_id | firstname | lastname | salary | department_id |
+--------+-----------+----------+--------+---------------+
| 1      | Todd      | Wilson   | 110000 | D1006         |
| 2      | Justin    | Simon    | 130000 | D1005         |
| 3      | Kelly     | Rosario  | 42689  | D1002         |
| 4      | Patricia  | Powell   | 170000 | D1004         |
| 5      | Sherry    | Golden   | 44101  | D1002         |
| 6      | Natasha   | Swanson  | 90000  | D1005         |
+--------+-----------+----------+--------+---------------+
解释：
1 号员工有 110000、106119 两条记录，薪水逐年递增，110000 是最新的。
2 号员工取 130000，4 号取 170000，6 号取 90000。
3 号和 5 号各只有一条记录，本身就是最新薪水。
```

## 题解

::: details 点击查看题解

### 思路

表里没有时间戳列，"最新"只能靠题目的假设——**薪水逐年递增**——来判定：每个员工金额最大的那条记录就是当前薪水。于是问题变成"**每组取金额最大的一行**"，这是 `ROW_NUMBER()` 窗口函数的标准场景。

`PARTITION BY emp_id` 按员工分组，`ORDER BY salary DESC` 让组内金额大的排最前，外层 `WHERE rn = 1` 每人只留一行，最后 `ORDER BY emp_id` 满足升序要求。`(emp_id, salary)` 是主键，同一员工不可能有两条金额相同的记录，所以 `ROW_NUMBER()` 不存在并列歧义，用 `DENSE_RANK()`、`MAX(salary)` 也都等价。

一个更短的写法是 `GROUP BY emp_id` 配 `MAX(salary)`，但要小心：`firstname`、`lastname`、`department_id` 既不在分组里也没聚合，在开启 `ONLY_FULL_GROUP_BY`（MySQL 8 默认 sql_mode 之一）的实例上会直接报 1055 错——本题的建表语句没有声明 `emp_id` 单列唯一，优化器无法推断函数依赖。窗口函数版本没有这个隐患，因此作为主解。

易错点：一是忘了最后 `ORDER BY emp_id`（题目明确要求升序）；二是按 `salary ASC` 取 `rn = 1`，会拿到最旧的那条；三是只 `SELECT` 出 `MAX(salary)` 而丢掉姓名、部门列——本题要求输出整行。

### SQL 实现

```sql
WITH ranked AS (
    SELECT
        emp_id,
        firstname,
        lastname,
        salary,
        department_id,
        ROW_NUMBER() OVER (PARTITION BY emp_id ORDER BY salary DESC) AS rn
    FROM Salary
)
SELECT emp_id, firstname, lastname, salary, department_id
FROM ranked
WHERE rn = 1
ORDER BY emp_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为 `Salary` 行数，窗口排序主导。
- 空间复杂度：O(n)，保存带行号的中间结果。
