# 即时食物配送 III

> 难度：中等 | 标签：分组聚合、日期函数 | [LeetCode 原题](https://leetcode.cn/problems/immediate-food-delivery-iii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Delivery` 表：

```
+-----------------------------+---------+
| Column Name                 | Type    |
+-----------------------------+---------+
| delivery_id                 | int     |
| customer_id                 | int     |
| order_date                  | date    |
| customer_pref_delivery_date | date    |
+-----------------------------+---------+
delivery_id 是该表的具有唯一值的列。
每一行包含有关向顾客交付食物的信息，顾客在某个日期下订单，并指定了一个首选交付日期（在订单日期当天或之后）。
```

如果顾客的首选交付日期与订单日期相同，则该订单称为 **立即交付** ，否则称为 **计划交付** 。

编写解决方案，找出每个唯一的 `order_date` 中立即交付订单的百分比，结果保留两位小数。返回查询结果并按 `order_date` 升序排序。

**示例 1：**

```
输入：
Delivery 表：
+-------------+-------------+------------+-----------------------------+
| delivery_id | customer_id | order_date | customer_pref_delivery_date |
+-------------+-------------+------------+-----------------------------+
| 1           | 1           | 2019-08-01 | 2019-08-02                  |
| 2           | 2           | 2019-08-01 | 2019-08-01                  |
| 3           | 1           | 2019-08-01 | 2019-08-01                  |
| 4           | 3           | 2019-08-02 | 2019-08-13                  |
| 5           | 3           | 2019-08-02 | 2019-08-02                  |
| 6           | 2           | 2019-08-02 | 2019-08-02                  |
| 7           | 4           | 2019-08-03 | 2019-08-03                  |
| 8           | 1           | 2019-08-03 | 2019-08-03                  |
| 9           | 5           | 2019-08-04 | 2019-08-18                  |
| 10          | 2           | 2019-08-04 | 2019-08-18                  |
+-------------+-------------+------------+-----------------------------+

输出：
+------------+----------------------+
| order_date | immediate_percentage |
+------------+----------------------+
| 2019-08-01 | 66.67                |
| 2019-08-02 | 66.67                |
| 2019-08-03 | 100.00               |
| 2019-08-04 | 0.00                 |
+------------+----------------------+

解释：
- 2019-08-01 共有 3 个订单，其中 2 个是即时订单，1 个是计划订单，所以该日期的即时订单百分比为 66.67。
- 2019-08-02 共有 3 个订单，其中 2 个是即时订单，1 个是计划订单，所以该日期的即时订单百分比为 66.67。
- 2019-08-03 共有 2 个订单，均为即时订单，所以该日期的即时订单百分比为 100.00。
- 2019-08-04 共有 2 个订单，均为计划订单，所以该日期的即时订单百分比为 0.00。
order_date 按升序排序。
```

## 题解

::: details 点击查看题解

### 思路

这题的统计口径是「按下单日期分组」而不是「按客户分组」，所以第一步就是 `GROUP BY order_date`。组内的分子是满足 `order_date = customer_pref_delivery_date` 的订单数，分母是该组的总订单数，两者相乘 100 再除即得百分比。

MySQL 里布尔表达式可以直接当 0/1 参与聚合，`SUM(order_date = customer_pref_delivery_date)` 就等价于 `SUM(CASE WHEN ... THEN 1 ELSE 0 END)`，这是最简洁的写法；`AVG(order_date = customer_pref_delivery_date) * 100` 也是等价写法。注意一定要先乘 100 再 `ROUND(..., 2)`，否则整数除法会把结果截断成 0。

易错点有两个：一是忘记 `ROUND` 导致 66.666… 与 66.67 不匹配；二是排序遗漏，题目要求按 `order_date` 升序返回。本题没有跨表连接，放在「多表连接」分类里是因为它是 Delivery 系列（I / II / III）的延续，常与需要自连接的题目一起练习。

### SQL 实现

```sql
SELECT
    order_date,
    ROUND(
        100 * SUM(order_date = customer_pref_delivery_date) / COUNT(*),
        2
    ) AS immediate_percentage
FROM Delivery
GROUP BY order_date
ORDER BY order_date;
```

### 复杂度分析

- 时间复杂度：O(n log n)，分组与排序主导，n 为订单数。
- 空间复杂度：O(d)，d 为不同下单日期的数量。

:::
