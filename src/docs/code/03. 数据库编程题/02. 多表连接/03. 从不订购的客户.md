# 从不订购的客户

> 难度：简单 | 标签：多表连接、子查询 | [LeetCode 原题](https://leetcode.cn/problems/customers-who-never-order/)

## 题目描述

`Customers` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| name        | varchar |
+-------------+---------+
在 SQL 中，id 是该表的主键。
该表的每一行都表示客户的 ID 和名称。
```

`Orders` 表：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| customerId  | int  |
+-------------+------+
在 SQL 中，id 是该表的主键。
customerId 是 Customers 表中 ID 的外键( Pandas 中的连接键)。
该表的每一行都表示订单的 ID 和订购该订单的客户的 ID。
```

找出所有从不点任何东西的顾客。

以 **任意顺序** 返回结果表。

结果格式如下所示。

**示例 1：**

```
输入：
Customers table:
+----+-------+
| id | name  |
+----+-------+
| 1  | Joe   |
| 2  | Henry |
| 3  | Sam   |
| 4  | Max   |
+----+-------+
Orders table:
+----+------------+
| id | customerId |
+----+------------+
| 1  | 3          |
| 2  | 1          |
+----+------------+
输出：
+-----------+
| Customers |
+-----------+
| Henry     |
| Max       |
+-----------+
```

## 题解

::: details 点击查看题解

### 思路

求「从未出现过」的成员，最经典的套路就是 **左连接 + 判空**：以 `Customers` 为左表去 `LEFT JOIN Orders`，能连上的行说明该客户下过单，连不上的行右表各列全是 `NULL`，`WHERE o.id IS NULL` 筛出来的正是从不订购的客户。注意判空必须写 `IS NULL`，写成 `= NULL` 比较结果仍是 `NULL`，一行都过滤不出来。

另一个易错点是输出列名：题目要求的列名是 `Customers`（不是 `name`），所以要 `SELECT c.name AS Customers`，否则列名不匹配判定失败。

替代写法是子查询：`WHERE c.id NOT IN (SELECT customerId FROM Orders)`，语义同样直观；但若子查询结果里出现 `NULL`，`NOT IN` 会整体失效（任何值与 `NULL` 比较都是未知），本题 `customerId` 非空所以安全，换成 `NOT EXISTS` 则完全不用担心这个问题。三种写法里左连接是面试中最常被要求的手写版本。

### SQL 实现

```sql
SELECT c.name AS Customers
FROM Customers c
LEFT JOIN Orders o ON c.id = o.customerId
WHERE o.id IS NULL;
```

### 复杂度分析

- 时间复杂度：O(m + n)，m、n 分别为两张表的行数，连接与过滤各扫描一遍。
- 空间复杂度：O(m)，连接哈希表的开销。

:::
