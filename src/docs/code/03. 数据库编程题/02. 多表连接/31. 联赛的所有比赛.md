# 联赛的所有比赛

> 难度：简单 | 标签：多表连接 | [LeetCode 原题](https://leetcode.cn/problems/all-the-matches-of-the-league/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Teams`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| team_name   | varchar |
+-------------+---------+
team_name 是该表中具有唯一值的列。
每一行表示一支球队。
```

编写解决方案，列出联赛中**所有可能的比赛**。注意每两支球队之间要踢**两场**比赛：一场由其中一队主场（`home_team`），另一场由另一队主场。

返回 `home_team`、`away_team` 两列，以任意顺序返回。

**示例 1：**

```
输入：
Teams 表：
+-------------+
| team_name   |
+-------------+
| Leetcode FC |
| Ahly SC     |
| Real Madrid |
+-------------+
输出：
+-------------+-------------+
| home_team   | away_team   |
+-------------+-------------+
| Leetcode FC | Ahly SC     |
| Leetcode FC | Real Madrid |
| Ahly SC     | Leetcode FC |
| Ahly SC     | Real Madrid |
| Real Madrid | Leetcode FC |
| Real Madrid | Ahly SC     |
+-------------+-------------+
解释：
3 支球队两两主客各踢一场，共 3 × 2 = 6 场比赛。
```

## 题解

::: details 点击查看题解

### 思路

只有一张表、没有关联字段，要生成"每两支球队的两种主客组合"，本质是**表与自身的笛卡尔积**：把 `Teams` 当成 `t1`（主队）和 `t2`（客队）各取一份，相乘得到 3 × 3 = 9 行，再用 `WHERE t1.team_name <> t2.team_name` 砍掉"自己踢自己"，正好剩下 6 场。

关键在于**保留有序对**：`(Leetcode FC, Ahly SC)` 和 `(Ahly SC, Leetcode FC)` 是两场不同的比赛，所以既不能 `DISTINCT`、也不能加 `t1.team_name < t2.team_name` 这类对称条件——那样只会得到 3 场，正好少一半。

写法上 MySQL 8 支持显式 `CROSS JOIN`，也允许 `FROM Teams t1, Teams t2` 的旧式逗号连接，等价；把两份 `Teams` 起不同别名是必须的，否则无法表达 `t1`/`t2` 的区别。注意不要漏掉 `<>` 条件，否则会输出"自己对自己"的 3 场垃圾数据；也不需要 `ORDER BY`，题目允许任意顺序。

### SQL 实现

```sql
SELECT t1.team_name AS home_team, t2.team_name AS away_team
FROM Teams AS t1
CROSS JOIN Teams AS t2
WHERE t1.team_name <> t2.team_name;
```

### 复杂度分析

- 时间复杂度：O(n²)，n 为球队数，笛卡尔积产生 n² 行再过滤。
- 空间复杂度：O(n²)，输出本身即 n(n - 1) 行。

:::
