# 司机成为乘客的次数

> 难度：中等 | 标签：多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/number-of-times-a-driver-was-a-passenger/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Rides`：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| ride_id      | int  |
| driver_id    | int  |
| passenger_id | int  |
+--------------+------+
ride_id 是该表中具有唯一值的列。
每一行都包含一次行程的司机 ID 和乘客 ID。
注意 driver_id != passenger_id。
```

编写解决方案，统计**每一位司机作为乘客乘坐的次数**（即他的 `driver_id` 在别的行程里作为 `passenger_id` 出现了多少次；从未当过乘客则记 0）。

返回 `driver_id` 与对应次数 `cnt`，以任意顺序返回。

**示例 1：**

```
输入：
Rides 表：
+---------+-----------+--------------+
| ride_id | driver_id | passenger_id |
+---------+-----------+--------------+
| 1       | 7         | 1            |
| 2       | 7         | 2            |
| 3       | 11        | 1            |
| 4       | 11        | 7            |
| 5       | 11        | 7            |
| 6       | 11        | 3            |
+---------+-----------+--------------+
输出：
+-----------+-----+
| driver_id | cnt |
+-----------+-----+
| 7         | 2   |
| 11        | 0   |
+-----------+-----+
解释：
所有行程中一共有两位司机：7 和 11。
ID 为 7 的司机当过 2 次乘客（第 4、5 次行程）。
ID 为 11 的司机从未当过乘客。
```

## 题解

::: details 点击查看题解

### 思路

题目要的是**以司机为主体**的统计：先枚举所有出现过的 `driver_id`，再问每个人在 `passenger_id` 列里出现过几次。这个"左表有、右表可能没有"的形状决定了必须用 **`LEFT JOIN`**——直接 `GROUP BY passenger_id` 或 `INNER JOIN` 会把"从没当过乘客"的司机（示例中的 11 号）整行丢掉，而题目明确要求输出 0。

具体做法：用一个 `WITH` 把 `DISTINCT driver_id` 取出来当驱动表，`LEFT JOIN Rides ON driver_id = passenger_id`，然后 `COUNT(passenger_id)` 聚合。这里**必须数 `passenger_id` 这一列而不能 `COUNT(*)`**：没匹配上的行里 `passenger_id` 是 `NULL`，`COUNT(列)` 自动忽略 `NULL` 得到 0，`COUNT(*)` 却会把这行算成 1，是本题最经典的翻车点。

易错点还有：其一，司机和乘客身份用**同一列语义**比较（`t.driver_id = r.passenger_id`），别写成 `= r.driver_id`，那等于统计"当过几次司机"；其二，`driver_id != passenger_id` 保证自己不会算自己一次；其三，统计对象只取 `Rides` 里出现过的司机，不需要凭空补全所有用户。替代写法：分别按 `driver_id`、`passenger_id` 聚合后 `FULL OUTER JOIN`，但 MySQL 不支持全外连接，用 `LEFT JOIN` + 聚合更省事。

### SQL 实现

```sql
WITH drivers AS (
    SELECT DISTINCT driver_id
    FROM Rides
)
SELECT d.driver_id, COUNT(r.passenger_id) AS cnt
FROM drivers AS d
LEFT JOIN Rides AS r
  ON d.driver_id = r.passenger_id
GROUP BY d.driver_id;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为行程行数，去重与聚合各扫一遍（连接键可走哈希索引）。
- 空间复杂度：O(d)，d 为不同司机数。
