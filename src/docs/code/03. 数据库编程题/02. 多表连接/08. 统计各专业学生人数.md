# 统计各专业学生人数

> 难度：中等 | 标签：多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/count-student-number-in-departments/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Student`：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| student_id   | int     |
| student_name | varchar |
| gender       | varchar |
| dept_id      | int     |
+--------------+---------+
student_id 是该表的主键（具有唯一值的列）。
dept_id 是 Department 表中 dept_id 的外键（reference 列）。
该表的每一行表示一名学生的姓名、性别及其所在院系的 id。
```

表 `Department`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| dept_id     | int     |
| dept_name   | varchar |
+-------------+---------+
dept_id 是该表的主键（具有唯一值的列）。
该表的每一行表示一个院系的 id 及其名称。
```

编写解决方案，报告 `Department` 表中 **所有院系** 的名称及其学生人数（**没有学生的院系也要报告，人数记为 0**）。

返回结果表按 `student_number` **降序** 排列；如果人数相同，则按 `dept_name` **字母顺序升序** 排列。

结果格式如下所示。

**示例 1：**

```
输入：
Student 表：
+------------+--------------+--------+---------+
| student_id | student_name | gender | dept_id |
+------------+--------------+--------+---------+
| 1          | Jack         | M      | 1       |
| 2          | Jane         | F      | 1       |
| 3          | Mark         | M      | 2       |
+------------+--------------+--------+---------+
Department 表：
+---------+-------------+
| dept_id | dept_name   |
+---------+-------------+
| 1       | Engineering |
| 2       | Science     |
| 3       | Law         |
+---------+-------------+
输出：
+-------------+----------------+
| dept_name   | student_number |
+-------------+----------------+
| Engineering | 2              |
| Science     | 1              |
| Law         | 0              |
+-------------+----------------+
```

## 题解

::: details 点击查看题解

### 思路

题目的核心约束是「**所有院系**都要出现，包括一个学生都没有的 Law」。如果图省事写成 `Student JOIN Department ... GROUP BY`，内连接会先把没有学生的院系行丢掉，Law 直接消失——这是本题最常见的错误。必须以 `Department` 为左表 `LEFT JOIN Student`，让「连不上学生的院系」保留下来，其 `student_id` 为 `NULL`。

计数要写 `COUNT(s.student_id)` 而不是 `COUNT(*)`：左连接没匹配上的行里 `student_id` 是 `NULL`，`COUNT(列)` 会忽略 `NULL` 得到 0，正好是题目要的「0 人」；而 `COUNT(*)` 数的是行数，对这种行会算成 1。这是本题第二个坑。

排序是题面明说的：`ORDER BY student_number DESC, dept_name ASC`，人数并列时按院系名字母序。用 `LEFT JOIN ... USING (dept_id)` 可以让 `dept_id` 只保留一份，分组直接写 `GROUP BY dept_id` 即可（MySQL 8 知道它函数依赖于主键，满足 `ONLY_FULL_GROUP_BY`）。替代写法：子查询先 `SELECT dept_id, COUNT(*) FROM Student GROUP BY dept_id` 算出各院系人数，再与 `Department` 左连接并用 `IFNULL(cnt, 0)` 补零，逻辑等价但更啰嗦。

### SQL 实现

```sql
SELECT d.dept_name, COUNT(s.student_id) AS student_number
FROM Department d
LEFT JOIN Student s ON d.dept_id = s.dept_id
GROUP BY d.dept_id, d.dept_name
ORDER BY student_number DESC, d.dept_name;
```

### 复杂度分析

- 时间复杂度：O(n + m log m)，n 为学生数、m 为院系数，分组计数后排序。
- 空间复杂度：O(m)，分组计数的哈希表开销。

:::
