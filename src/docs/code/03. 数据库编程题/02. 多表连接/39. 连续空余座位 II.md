# 连续空余座位 II

> 难度：中等 | 标签：窗口函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/consecutive-available-seats-ii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Cinema` 表：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| seat_id     | int  |
| free        | bool |
+-------------+------+
seat_id 是这张表的自增主键。
每一行表示第 i 个座位是否空闲，1 表示空闲，0 表示已占用。
```

编写解决方案，找出影院中 **最长的连续空闲座位段** 的长度。注意：

- 最长段总是唯一存在的；如果存在多个长度相同的最长段，则全部输出。
- 每个输出段给出其首个座位号、末尾座位号和段长度。

返回结果按 `first_seat_id` 升序排序。

**示例 1：**

```
输入：
Cinema 表：
+---------+------+
| seat_id | free |
+---------+------+
| 1       | 1    |
| 2       | 0    |
| 3       | 1    |
| 4       | 1    |
| 5       | 1    |
+---------+------+

输出：
+--------------+--------------+-----------------------+
| first_seat_id| last_seat_id | consecutive_seats_len  |
+--------------+--------------+-----------------------+
| 3            | 5            | 3                     |
+--------------+--------------+-----------------------+

解释：
最长的连续空闲座位段从 3 号座位开始、到 5 号座位结束，长度为 3。
1 号座位虽然空闲，但 2 号座位被占用，它所在的段长度只有 1，不是最长段。
结果按 first_seat_id 升序排序。
```

## 题解

::: details 点击查看题解

### 思路

这是标准的「连续段分组（gaps and islands）」问题：座位号是天然连续的整数，只要先把空闲座位挑出来按 `seat_id` 编号，再用「座位号 − 行号」作差，同一连续段内的差值恒定，不同段之间差值必然跳变——差值就成了段的分组键。

具体地，对 `WHERE free = 1` 的行计算 `seat_id - ROW_NUMBER() OVER (ORDER BY seat_id)` 得到 `gid`：示例中座位 1 得 1-1=0，座位 3、4、5 分别得 3-1=2、4-2=2、5-3=2，显然 3~5 被分到同一组。随后按 `gid` 聚合，`MIN(seat_id)`、`MAX(seat_id)`、`COUNT(*)` 就是每段的首座、尾座和长度。

最后一步取最长段：用窗口 `MAX(len) OVER ()` 或标量子查询筛出最大长度即可。易错点：一是别忘了先过滤 `free = 1`，否则占用座位会把连续段切断甚至污染分组键；二是 `ROW_NUMBER()` 必须按 `seat_id` 排序，与差值保持同一顺序；三是注意「多个最长段都要输出」，不能只 `LIMIT 1`。替代写法：`LAG(seat_id)` 找断点分段，或用 `SUM(free)` 前缀和技巧。

### SQL 实现

```sql
WITH T AS (
    SELECT
        seat_id,
        seat_id - ROW_NUMBER() OVER (ORDER BY seat_id) AS gid
    FROM Cinema
    WHERE free = 1
),
P AS (
    SELECT
        MIN(seat_id) AS first_seat_id,
        MAX(seat_id) AS last_seat_id,
        COUNT(*) AS consecutive_seats_len
    FROM T
    GROUP BY gid
)
SELECT first_seat_id, last_seat_id, consecutive_seats_len
FROM P
WHERE consecutive_seats_len = (SELECT MAX(consecutive_seats_len) FROM P)
ORDER BY first_seat_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，窗口排序主导，n 为座位数。
- 空间复杂度：O(n)，中间分组结果。

:::
