# 上月播放的儿童适宜电影

> 难度：简单 | 标签：多表连接、日期函数 | [LeetCode 原题](https://leetcode.cn/problems/friendly-movies-streamed-last-month/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`TVProgram`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| program_date | date    |
| content_id   | int     |
| channel      | varchar |
+--------------+---------+
```

（`program_date`, `content_id`）是该表的主键，每行表示某频道在某天播出的节目。

表：`Content`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| content_id   | varchar |
| title        | varchar |
| Kids_content | enum    |
| content_type | varchar |
+--------------+---------+
```

`content_id` 是该表主键；`Kids_content` 取值为 `('Y', 'N')`，`'Y'` 表示儿童适宜内容；`content_type` 是内容类型，例如 `Movies`（电影）、`Series`（电视剧）。

请写一个解决方案，报告在 **2020 年 6 月**播放过的、**儿童适宜的电影**的去重电影名。返回列 `title`，顺序任意。

**示例 1：**

```
输入：
TVProgram 表：
+-------------------+------------+------------+
| program_date      | content_id | channel    |
+-------------------+------------+------------+
| 2020-06-10 08:00  | 1          | LC-Channel |
| 2020-05-11 12:00  | 2          | LC-Channel |
| 2020-05-12 12:00  | 3          | LC-Channel |
| 2020-05-13 14:00  | 4          | Disney Ch  |
| 2020-06-18 14:00  | 4          | Disney Ch  |
| 2020-07-15 16:00  | 5          | Disney Ch  |
+-------------------+------------+------------+
Content 表：
+------------+----------------+--------------+--------------+
| content_id | title          | Kids_content | content_type |
+------------+----------------+--------------+--------------+
| 1          | Leetcode Movie | N            | Movies       |
| 2          | Alg. for Kids  | Y            | Series       |
| 3          | Database Sols  | N            | Series       |
| 4          | Aladdin        | Y            | Movies       |
| 5          | Cinderella     | Y            | Movies       |
+------------+----------------+--------------+--------------+
输出：
+---------+
| title   |
+---------+
| Aladdin |
+---------+
```

解释：`Leetcode Movie` 不是儿童适宜的；`Alg. for Kids` 是儿童适宜但不是电影；`Database Sols` 既不是电影也不适宜儿童；`Aladdin` 是儿童适宜电影且 6 月播出过；`Cinderella` 只在 7 月播出。

## 题解

::: details 点击查看题解

### 思路

两张表靠 `content_id` 等值连接，然后在 `WHERE` 里同时卡三个条件：儿童适宜、类型是电影、播出时间落在 2020 年 6 月。缺任何一个条件都会混入错误结果——只写 `Kids_content = 'Y'` 会把 `Alg. for Kids` 这种电视剧也算进来，只写 `content_type = 'Movies'` 又会把 `Leetcode Movie` 算进来。

时间条件建议写成半开区间 `>= '2020-06-01' AND < '2020-07-01'`，而不是 `DATE_FORMAT(program_date, '%Y%m') = '202006'`：前者是范围比较，能利用索引，也避免了在过滤列上套函数。注意 `TVProgram.program_date` 声明为 `date`，插入的 `'2020-06-10 08:00'` 会被截断成日期，比较时不必关心时分秒。

同一部电影当月可能播出多次，所以要 `DISTINCT` 去重；另外两张表的 `content_id` 一个是 `int` 一个是 `varchar`，MySQL 会做隐式转换完成连接，无需手动 `CAST`。

### SQL 实现

```sql
SELECT DISTINCT c.title
FROM Content AS c
JOIN TVProgram AS t ON t.content_id = c.content_id
WHERE c.Kids_content = 'Y'
  AND c.content_type = 'Movies'
  AND t.program_date >= '2020-06-01'
  AND t.program_date < '2020-07-01';
```

### 复杂度分析

- 时间复杂度：O(n + m)，两表各扫一遍做连接；`content_id` 有索引时接近 O(n + m)，否则哈希连接仍需线性扫描。
- 空间复杂度：O(1)，不计结果集；`DISTINCT` 若走排序则需 O(k) 去重空间。
