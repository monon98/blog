# 计算布尔表达式的值

> 难度：中等 | 标签：多表连接、CASE 表达式 | [LeetCode 原题](https://leetcode.cn/problems/evaluate-boolean-expression/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Variables` 表：

```
+-------+---------+
| name  | varchar |
| value | int     |
+-------+---------+
name 是该表的主键。
每一行表示一个变量名（如 'x'、'y'）及其对应的整数值。
```

`Expressions` 表：

```
+----------------+---------+
| left_operand   | varchar |
| operator       | enum    |
| right_operand  | varchar |
+----------------+---------+
(left_operand, operator, right_operand) 是该表的主键。
operator 取值为 ('>', '<', '=')；左右操作数都是 Variables 表中的变量名。
```

编写一个 SQL 查询，计算 `Expressions` 中每个布尔表达式的结果。

- 结果列名为 `value`，取值为字符串 `'true'` 或 `'false'`；
- 返回列：`left_operand`、`operator`、`right_operand`、`value`，顺序不限。

**示例 1：**

```
输入：
Variables 表：
+------+-------+
| name | value |
+------+-------+
| x    | 66    |
| y    | 77    |
+------+-------+
Expressions 表：
+--------------+----------+---------------+
| left_operand | operator | right_operand |
+--------------+----------+---------------+
| x            | >        | y             |
| x            | <        | y             |
| x            | =        | y             |
| y            | >        | x             |
| y            | <        | x             |
| x            | =        | x             |
+--------------+----------+---------------+
输出：
+--------------+----------+---------------+-------+
| left_operand | operator | right_operand | value |
+--------------+----------+---------------+-------+
| x            | >        | y             | false |
| x            | <        | y             | true  |
| x            | =        | y             | false |
| y            | >        | x             | true  |
| y            | <        | x             | false |
| x            | =        | x             | true  |
+--------------+----------+---------------+-------+
解释：
x = 66、y = 77，逐条比较即可：66 > 77 为 false，66 < 77 为 true，66 = 77 为 false；
77 > 66 为 true，77 < 66 为 false，66 = 66 为 true。
```

## 题解

::: details 点击查看题解

### 思路

`Expressions` 里存的是变量**名字**而不是数值，所以第一步是把左右操作数各自翻译成数值——这需要把 `Variables` 表连接两次，一次取左操作数、一次取右操作数，用两个不同的别名（`lv` 与 `rv`）区分。

数值拿到后，用 `CASE operator` 分三种情况比较并输出字符串 `'true'` / `'false'`。MySQL 里布尔表达式本身返回 1/0，可以直接用于 `IF`/`CASE WHEN`，但最终输出要求是字符串，所以要显式转换成 `'true'` / `'false'`，不能直接返回 1/0。

易错点：一是必须连接 `Variables` 两次，且两个别名的连接条件分别绑定 `left_operand` 和 `right_operand`，只连接一次会拿错值；二是 `CASE` 的 `WHEN` 顺序无所谓，但要保证三个运算符都被覆盖，建议把 `=` 放在 `ELSE` 里兜底；三是不要用字符串比较代替数值比较，`'66' > '77'` 按字典序虽然本例结果相同，但 `'9' > '10'` 就会出错。

替代写法：用 `IF(e.operator = '>', lv.value > rv.value, IF(e.operator = '<', lv.value < rv.value, lv.value = rv.value))` 嵌套，再套一层 `IF(..., 'true', 'false')`，逻辑一样但可读性略差。

### SQL 实现

```sql
SELECT e.left_operand,
       e.operator,
       e.right_operand,
       CASE e.operator
           WHEN '>' THEN IF(lv.value > rv.value, 'true', 'false')
           WHEN '<' THEN IF(lv.value < rv.value, 'true', 'false')
           ELSE IF(lv.value = rv.value, 'true', 'false')
       END AS value
FROM Expressions e
JOIN Variables lv
    ON lv.name = e.left_operand
JOIN Variables rv
    ON rv.name = e.right_operand;
```

### 复杂度分析

- 时间复杂度：O(e × log v) 左右，e 为表达式数、v 为变量数；变量名有主键索引时可视为 O(e)。
- 空间复杂度：O(1)，除结果集外只用到常量级临时空间。
