# 指定日期的产品价格

> 难度：中等 | 标签：窗口函数、子查询、LEFT JOIN | [LeetCode 原题](https://leetcode.cn/problems/product-price-at-a-given-date/)

## 题目描述

产品数据表: `Products`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| product_id    | int     |
| new_price     | int     |
| change_date   | date    |
+---------------+---------+
(product_id, change_date) 是此表的主键（具有唯一值的列组合）。
这张表的每一行分别记录了 某产品 在某个日期 更改后 的新价格。
```

一开始，所有产品价格都为 10。

编写一个解决方案，找出在 `2019-08-16`** **所有产品的价格。

以 **任意顺序 **返回结果表。

结果格式如下例所示。

**示例 1:**

```
输入：
Products 表:
+------------+-----------+-------------+
| product_id | new_price | change_date |
+------------+-----------+-------------+
| 1          | 20        | 2019-08-14  |
| 2          | 50        | 2019-08-14  |
| 1          | 30        | 2019-08-15  |
| 1          | 35        | 2019-08-16  |
| 2          | 65        | 2019-08-17  |
| 3          | 20        | 2019-08-18  |
+------------+-----------+-------------+
输出：
+------------+-------+
| product_id | price |
+------------+-------+
| 2          | 50    |
| 1          | 35    |
| 3          | 10    |
+------------+-------+
```

## 题解

::: details 点击查看题解

### 思路

对每个产品，要取的是「变更日期不晚于 2019-08-16 的最后一次改价」；如果该产品在这个日期之前从未改过价，则价格是初始值 10。这可以拆成两个子问题：先求符合条件的最近一次改价，再与产品全集左连接补默认值。

第一步在主键 `(product_id, change_date)` 上做 `ROW_NUMBER() OVER (PARTITION BY product_id ORDER BY change_date DESC)`，并且必须在窗口之前用 `WHERE change_date <= '2019-08-16'` 过滤掉未来改价——否则 8 月 17 日、18 日的改价会被误当成目标日的价格。第二步用 `LEFT JOIN` 连接「产品全集」，保证像产品 3 这种 8 月 16 日之后才改价的产品也能出现，并用 `COALESCE(new_price, 10)` 给出默认价。

产品全集从 `Products` 里 `SELECT DISTINCT product_id` 取即可（题目保证所有产品都至少出现在表中一次），也可以从单独的 Product 表取，但本题没有该表。

易错点有三：一是过滤未来日期的位置，必须写在窗口计算之前；二是必须用 `LEFT JOIN` 而不是 `INNER JOIN`，否则没有早期改价记录的产品会凭空消失；三是不要用 `MAX(change_date)` 直接连回去时忘记同时比较日期，那样同一产品可能匹配到多条记录。

替代写法：用相关子查询 `WHERE change_date = (SELECT MAX(change_date) FROM Products p2 WHERE p2.product_id = p.product_id AND p2.change_date <= '2019-08-16')`，再对没匹配上的产品单独 `UNION` 一份默认价，可读性略差，但不需要窗口函数。

### SQL 实现

```sql
SELECT p.product_id,
       COALESCE(t.new_price, 10) AS price
FROM (
    SELECT DISTINCT product_id
    FROM Products
) p
LEFT JOIN (
    SELECT product_id, new_price
    FROM (
        SELECT product_id,
               new_price,
               ROW_NUMBER() OVER (
                   PARTITION BY product_id
                   ORDER BY change_date DESC
               ) AS rn
        FROM Products
        WHERE change_date <= '2019-08-16'
    ) x
    WHERE x.rn = 1
) t
    ON t.product_id = p.product_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为改价记录数，窗口排序主导。
- 空间复杂度：O(p)，p 为产品数，用于保存每个产品的最新改价与产品全集。
