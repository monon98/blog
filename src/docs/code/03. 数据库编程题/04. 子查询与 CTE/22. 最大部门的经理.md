# 最大部门的经理

> 难度：中等 | 标签：分组聚合、窗口函数 | [LeetCode 原题](https://leetcode.cn/problems/manager-of-the-largest-department/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Employees`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| emp_id      | int     |
| emp_name    | varchar |
| dep_id      | int     |
| position    | varchar |
+-------------+---------+
```

`emp_id` 是该表唯一列，每行是一位员工的编号、姓名、所属部门编号和职位；`position = 'Manager'` 的行是该部门的经理。

请找出**员工人数最多的部门**的经理姓名。员工人数相同的最大部门可能有多个，此时要把这些部门的经理都返回。

返回列 `manager_name`、`dep_id`，按 `dep_id` 升序排列。

**示例 1：**

```
输入：
Employees 表：
+--------+----------+--------+---------------+
| emp_id | emp_name | dep_id | position      |
+--------+----------+--------+---------------+
| 156    | Michael  | 107    | Manager       |
| 112    | Lucas    | 107    | Consultant    |
| 8      | Isabella | 101    | Manager       |
| 160    | Joseph   | 100    | Manager       |
| 80     | Aiden    | 100    | Engineer      |
| 190    | Skylar   | 100    | Freelancer    |
| 196    | Stella   | 101    | Coordinator   |
| 167    | Audrey   | 100    | Consultant    |
| 97     | Nathan   | 101    | Supervisor    |
| 128    | Ian      | 101    | Administrator |
| 81     | Ethan    | 107    | Administrator |
+--------+----------+--------+---------------+
输出：
+--------------+--------+
| manager_name | dep_id |
+--------------+--------+
| Joseph       | 100    |
| Isabella     | 101    |
+--------------+--------+
```

解释：部门 100 和 101 各有 4 名员工，部门 107 有 3 名员工。100 和 101 并列人数最多，所以两位经理 Joseph 和 Isabella 都要输出，结果按 `dep_id` 升序。

## 题解

::: details 点击查看题解

### 思路

先在 `Employees` 上按 `dep_id` 分组数人数，得到「部门 → 人数」；再在这个结果上对人数字段做 `DENSE_RANK() ... ORDER BY cnt DESC`，排名为 1 的部门就是人数最多的部门（并列的都会拿到 rank 1）。最后把部门表和 `Employees` 连接，并限定 `position = 'Manager'` 取出经理姓名。

不能写成 `ORDER BY cnt DESC LIMIT 1`：题目明确说了最大部门可能并列，`LIMIT 1` 会漏掉并列的另一位经理；用 `DENSE_RANK` 或者 `WHERE cnt = (SELECT MAX(cnt) FROM ...)` 才能把并列部门全部保留。

统计人数时要数部门的**所有**员工行，包括经理本人，不能加 `position` 过滤条件，否则部门人数会被少算 1。

### SQL 实现

```sql
WITH dep_size AS (
    SELECT dep_id, COUNT(*) AS cnt
    FROM Employees
    GROUP BY dep_id
),
ranked AS (
    SELECT dep_id, DENSE_RANK() OVER (ORDER BY cnt DESC) AS rnk
    FROM dep_size
)
SELECT
    e.emp_name AS manager_name,
    r.dep_id
FROM ranked AS r
JOIN Employees AS e
  ON e.dep_id = r.dep_id
 AND e.position = 'Manager'
WHERE r.rnk = 1
ORDER BY r.dep_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，分组聚合后再对部门数量排序计算排名。
- 空间复杂度：O(d)，d 为部门数量，用于存放分组与排名结果。

:::
