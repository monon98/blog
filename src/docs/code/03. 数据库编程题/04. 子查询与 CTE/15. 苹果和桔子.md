# 苹果和桔子

> 难度：中等 | 标签：分组聚合、条件表达式 | [LeetCode 原题](https://leetcode.cn/problems/apples-oranges/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Sales`

```
+------------+---------------------------+
| Column Name| Type                      |
+------------+---------------------------+
| sale_date  | date                      |
| fruit      | enum('apples', 'oranges') |
| sold_num   | int                       |
+------------+---------------------------+
```

（`sale_date`, `fruit`）是该表的主键，同一天里「苹果」和「桔子」各占一行，`sold_num` 是当天该种水果的销量。

请写一个解决方案，报告每一天**苹果**与**桔子**销量的差值（苹果销量 − 桔子销量），差值列命名为 `diff`，结果按 `sale_date` 升序排列。

**示例 1：**

```
输入：
Sales 表：
+------------+---------+----------+
| sale_date  | fruit   | sold_num |
+------------+---------+----------+
| 2020-05-01 | apples  | 10       |
| 2020-05-01 | oranges | 8        |
| 2020-05-02 | apples  | 15       |
| 2020-05-02 | oranges | 15       |
| 2020-05-03 | apples  | 20       |
| 2020-05-03 | oranges | 0        |
| 2020-05-04 | apples  | 15       |
| 2020-05-04 | oranges | 16       |
+------------+---------+----------+
输出：
+------------+------+
| sale_date  | diff |
+------------+------+
| 2020-05-01 | 2    |
| 2020-05-02 | 0    |
| 2020-05-03 | 20   |
| 2020-05-04 | -1   |
+------------+------+
```

解释：05-01 卖了 10 个苹果、8 个桔子，差值 2；05-04 卖了 15 个苹果、16 个桔子，差值 -1（差值可以是负数）。

## 题解

::: details 点击查看题解

### 思路

每天固定两行（苹果、桔子），所以「按天分组 + 把桔子取负」就能把两行合成一个差值，不需要做自连接。`SUM(CASE WHEN fruit = 'apples' THEN sold_num ELSE -sold_num END)` 里苹果记正、桔子记负，累加即得当天差值。

易错点：一是别写成 `SUM(sold_num)`，那是当天总销量而不是差值；二是别用 `apples JOIN oranges` 的自连接写法，一旦某天只卖了一种水果，内连接就会把这一整天丢掉，而条件聚合对缺行天然兼容（缺的那侧贡献 0）。

### SQL 实现

```sql
SELECT
    sale_date,
    SUM(CASE WHEN fruit = 'apples' THEN sold_num ELSE -sold_num END) AS diff
FROM Sales
GROUP BY sale_date
ORDER BY sale_date;
```

### 复杂度分析

- 时间复杂度：O(n)，扫一遍表并按日期聚合；分组用哈希时为 O(n)，走排序实现时最坏 O(n log n)。
- 空间复杂度：O(1)，不计返回的分组结果集。

:::
