# 每位学生的最高成绩

> 难度：中等 | 标签：窗口函数、分组聚合、排序取优 | [LeetCode 原题](https://leetcode.cn/problems/highest-grade-for-each-student/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Enrollments` 表：

```
+------------+---------+
| Column Name| Type    |
+------------+---------+
| student_id | int     |
| course_id  | int     |
| grade      | int     |
+------------+---------+
(student_id, course_id) 是该表的主键。
每一行表示某个学生在某门课程中取得的成绩。
```

编写一个 SQL 查询，报告 **每个学生的最高成绩** 以及取得该成绩的课程 id。

- 对每个 `student_id`，取 `grade` 最大的那条记录；
- 如果同一个学生在多门课程中取得了相同的最高成绩，返回 `course_id` 最小的那条记录；
- 返回列：`student_id`、`course_id`、`grade`，按 `student_id` 升序排列。

**示例 1：**

```
输入：
Enrollments 表：
+------------+-----------+-------+
| student_id | course_id | grade |
+------------+-----------+-------+
| 2          | 2         | 95    |
| 2          | 3         | 95    |
| 1          | 1         | 90    |
| 1          | 2         | 99    |
| 3          | 1         | 80    |
| 3          | 2         | 75    |
| 3          | 3         | 82    |
+------------+-----------+-------+
输出：
+------------+-----------+-------+
| student_id | course_id | grade |
+------------+-----------+-------+
| 1          | 2         | 99    |
| 2          | 2         | 95    |
| 3          | 3         | 82    |
+------------+-----------+-------+
解释：
学生 1 的最高分是课程 2 的 99。
学生 2 在课程 2 和课程 3 都拿到 95，按规则取较小的 course_id，即课程 2。
学生 3 的最高分是课程 3 的 82。
```

## 题解

::: details 点击查看题解

### 思路

这是典型的「分组取第一名」问题。由于要同时输出 `course_id` 和 `grade`，不能只写 `GROUP BY student_id` 配 `MAX(grade)`——那样拿不到最高分对应的课程；用窗口函数 `ROW_NUMBER()` 在每组内部按 `grade DESC, course_id ASC` 排序后取 `rn = 1`，可以一次性把整行带出来。

排序键的顺序很关键：先按成绩降序，成绩相同时按 `course_id` 升序。这样并列最高分时，`course_id` 最小的那条会排在最前面，正好满足题目要求。如果漏写第二排序键，MySQL 返回哪一条取决于执行计划，结果不可靠。

为什么用 `ROW_NUMBER` 而不是 `RANK`？`RANK` 会给并列的行相同的名次（都是 1），`WHERE rnk = 1` 会把两条都留下，与「只返回一条」的要求冲突；`ROW_NUMBER` 保证每组恰好一行。

易错点：窗口函数不能直接出现在 `WHERE` 中（`WHERE` 先于窗口计算执行），必须套一层子查询或 CTE；另外成绩可能有 `NULL` 时，MySQL 默认 `NULLS LAST` 的降序行为与多数数据库一致，但本题成绩非空，不必处理。

替代写法：子查询 `(student_id, grade)` 与 `(SELECT student_id, MAX(grade) ... GROUP BY student_id)` 连接后再取 `MIN(course_id)`，逻辑绕一些，可读性不如窗口函数。

### SQL 实现

```sql
SELECT student_id, course_id, grade
FROM (
    SELECT student_id,
           course_id,
           grade,
           ROW_NUMBER() OVER (
               PARTITION BY student_id
               ORDER BY grade DESC, course_id ASC
           ) AS rn
    FROM Enrollments
) t
WHERE rn = 1
ORDER BY student_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为选课记录数，窗口排序主导。
- 空间复杂度：O(n)，窗口计算需要保存排序后的中间结果。
