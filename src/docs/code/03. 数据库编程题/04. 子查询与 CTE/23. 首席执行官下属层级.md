# 首席执行官下属层级

> 难度：困难 | 标签：递归 CTE、多表连接 | [LeetCode 原题](https://leetcode.cn/problems/ceo-subordinate-hierarchy/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Employees`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| employee_id   | int     |
| employee_name | varchar |
| manager_id    | int     |
| salary        | int     |
+---------------+---------+
```

`employee_id` 是该表唯一标识；`manager_id` 是该员工上级的 `employee_id`，CEO 的 `manager_id` 为 `NULL`。

请找出 CEO 的所有下属（**直接和间接**都算），并给出他们在层级中的位置以及与自己上面的 CEO 的工资差。返回列：

- `subordinate_id`：下属的 `employee_id`
- `subordinate_name`：下属姓名
- `hierarchy_level`：下属在层级中的深度，直接向 CEO 汇报为 `1`，其直接下属为 `2`，以此类推
- `salary_difference`：该下属工资与 CEO 工资之差（下属工资 − CEO 工资）

结果按 `hierarchy_level` 升序、`subordinate_id` 升序排列。

**示例 1：**

```
输入：
Employees 表：
+-------------+----------------+------------+---------+
| employee_id | employee_name  | manager_id | salary  |
+-------------+----------------+------------+---------+
| 1           | Alice          | NULL       | 150000  |
| 2           | Bob            | 1          | 120000  |
| 3           | Charlie        | 1          | 110000  |
| 4           | David          | 2          | 105000  |
| 5           | Eve            | 2          | 100000  |
| 6           | Frank          | 3          | 95000   |
| 7           | Grace          | 3          | 98000   |
| 8           | Helen          | 5          | 90000   |
+-------------+----------------+------------+---------+
输出：
+----------------+------------------+-----------------+-------------------+
| subordinate_id | subordinate_name | hierarchy_level | salary_difference |
+----------------+------------------+-----------------+-------------------+
| 2              | Bob              | 1               | -30000            |
| 3              | Charlie          | 1               | -40000            |
| 4              | David            | 2               | -45000            |
| 5              | Eve              | 2               | -50000            |
| 6              | Frank            | 2               | -55000            |
| 7              | Grace            | 2               | -52000            |
| 8              | Helen            | 3               | -60000            |
+----------------+------------------+-----------------+-------------------+
```

解释：Bob 和 Charlie 直接向 CEO Alice 汇报，层级为 1；David、Eve 向 Bob 汇报，Frank、Grace 向 Charlie 汇报，层级为 2；Helen 向 Eve 汇报，层级为 3。工资差都相对 CEO 的 150000 计算。

## 题解

::: details 点击查看题解

### 思路

组织架构是一棵树，深度事先未知，用固定次数的自连接写不出来，所以要用递归 CTE。起点（锚点）取 `manager_id IS NULL` 的行，也就是 CEO，层级记 0；递归部分沿着 `e.manager_id = 上一层的 employee_id` 往下走，每走一层层级加 1。

查出来的结果里 CEO 自己也在（层级 0），但题目只要「下属」，所以外层过滤 `hierarchy_level > 0`。工资差要以 CEO 的工资为基准，可以再取一份「只含 CEO 工资」的派生表做 `CROSS JOIN`，也可以用标量子查询；用 `CROSS JOIN` 的好处是基准只算一次、写法更清楚。

注意 `UNION ALL` 两边列的类型和个数必须一致，层级用一个整型列一路累加即可；如果数据里存在环（某人间接管理自己），递归会无限展开，实际业务表需要额外加深度上限保护。

### SQL 实现

```sql
WITH RECURSIVE hierarchy AS (
    SELECT
        employee_id,
        employee_name,
        salary,
        0 AS hierarchy_level
    FROM Employees
    WHERE manager_id IS NULL
    UNION ALL
    SELECT
        e.employee_id,
        e.employee_name,
        e.salary,
        h.hierarchy_level + 1
    FROM hierarchy AS h
    JOIN Employees AS e ON e.manager_id = h.employee_id
)
SELECT
    h.employee_id AS subordinate_id,
    h.employee_name AS subordinate_name,
    h.hierarchy_level,
    h.salary - ceo.salary AS salary_difference
FROM hierarchy AS h
CROSS JOIN (SELECT salary FROM Employees WHERE manager_id IS NULL) AS ceo
WHERE h.hierarchy_level > 0
ORDER BY h.hierarchy_level, h.employee_id;
```

### 复杂度分析

- 时间复杂度：O(n)，每个员工只会被展开一次（树结构下递归行数等于员工数），排序 O(n log n)。
- 空间复杂度：O(n)，递归 CTE 需要保存每一层的结果。
