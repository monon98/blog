# 每件商品的最新订单

> 难度：中等 | 标签：窗口函数、多表连接 | [LeetCode 原题](https://leetcode.cn/problems/the-most-recent-orders-for-each-product/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Customers`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| customer_id | int     |
| name        | varchar |
+-------------+---------+
```

`customer_id` 是该表主键，表中存顾客信息。

表：`Orders`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| order_id    | int     |
| order_date  | date    |
| customer_id | int     |
| product_id  | int     |
+-------------+---------+
```

`order_id` 是该表主键，每行是某顾客下的一个订单；同一个顾客不会在同一天对同一件商品下多单。

表：`Products`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| product_id   | int     |
| product_name | varchar |
| price        | int     |
+--------------+---------+
```

`product_id` 是该表主键，表中存所有商品信息。

请写一个解决方案，找出每件商品的**最新**订单（可能有多个）。返回 `product_name`、`product_id`、`order_id`、`order_date`，按 `product_name` 升序、`product_id` 升序、`order_id` 升序排列。

**示例 1：**

```
输入：
Customers 表：
+-------------+-----------+
| customer_id | name      |
+-------------+-----------+
| 1           | Winston   |
| 2           | Jonathan  |
| 3           | Annabelle |
| 4           | Marwan    |
| 5           | Khaled    |
+-------------+-----------+
Orders 表：
+----------+------------+-------------+------------+
| order_id | order_date | customer_id | product_id |
+----------+------------+-------------+------------+
| 1        | 2020-07-31 | 1           | 1          |
| 2        | 2020-07-30 | 2           | 2          |
| 3        | 2020-08-29 | 3           | 3          |
| 4        | 2020-07-29 | 4           | 1          |
| 5        | 2020-06-10 | 1           | 2          |
| 6        | 2020-08-01 | 2           | 1          |
| 7        | 2020-08-01 | 3           | 1          |
| 8        | 2020-08-03 | 1           | 2          |
| 9        | 2020-08-07 | 2           | 3          |
| 10       | 2020-07-15 | 1           | 2          |
+----------+------------+-------------+------------+
Products 表：
+------------+--------------+-------+
| product_id | product_name | price |
+------------+--------------+-------+
| 1          | keyboard     | 120   |
| 2          | mouse        | 80    |
| 3          | screen       | 600   |
| 4          | hard disk    | 450   |
+------------+--------------+-------+
输出：
+--------------+------------+----------+------------+
| product_name | product_id | order_id | order_date |
+--------------+------------+----------+------------+
| keyboard     | 1          | 6        | 2020-08-01 |
| keyboard     | 1          | 7        | 2020-08-01 |
| mouse        | 2          | 8        | 2020-08-03 |
| screen       | 3          | 3        | 2020-08-29 |
+--------------+------------+----------+------------+
```

解释：keyboard 的最新订单日期是 2020-08-01，这天有两笔订单；mouse 的最新订单在 2020-08-03；screen 的最新订单在 2020-08-29；hard disk 从未被下单，不出现在结果中。

## 题解

::: details 点击查看题解

### 思路

「每件商品的最新订单」本质是分组取 Top-1，但**并列第一要全部保留**：keyboard 在 2020-08-01 有两个订单（订单 6、7），两行都要输出。所以窗口函数必须用 `RANK()`，不能用 `ROW_NUMBER()`——后者在同一天多单时会随机砍掉一行。

把 `Orders` 与 `Products` 内连接后，按 `product_id` 分区、`order_date` 降序排名，取 `rk = 1` 即可；内连接还顺带解决了「没有订单的商品不输出」（hard disk 根本不会出现在连接结果里）。

替代写法是不用窗口函数，直接过滤 `WHERE (product_id, order_date) IN (SELECT product_id, MAX(order_date) FROM Orders GROUP BY product_id)`，MySQL 8 支持行构造器 `IN`，效果相同；数据量大时窗口函数只扫一次表，通常更快。

### SQL 实现

```sql
WITH ranked AS (
    SELECT
        p.product_name,
        o.product_id,
        o.order_id,
        o.order_date,
        RANK() OVER (PARTITION BY o.product_id ORDER BY o.order_date DESC) AS rk
    FROM Orders AS o
    JOIN Products AS p ON p.product_id = o.product_id
)
SELECT product_name, product_id, order_id, order_date
FROM ranked
WHERE rk = 1
ORDER BY product_name, product_id, order_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，连接后按商品分区排序计算排名，排序是主要开销。
- 空间复杂度：O(n)，窗口函数需要缓存分区数据，CTE 结果也要物化。

:::
