# 买下所有产品的客户

> 难度：中等 | 标签：分组聚合、HAVING、子查询 | [LeetCode 原题](https://leetcode.cn/problems/customers-who-bought-all-products/)

## 题目描述

`Customer` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| customer_id | int     |
| product_key | int     |
+-------------+---------+
该表可能包含重复的行。
customer_id 不为 NULL。
product_key 是 Product 表的外键(reference 列)。
```

`Product` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_key | int     |
+-------------+---------+
product_key 是这张表的主键（具有唯一值的列）。
```

编写解决方案，报告 `Customer` 表中购买了 `Product` 表中所有产品的客户的 id。

返回结果表 **无顺序要求** 。

返回结果格式如下所示。

**示例 1：**

```
输入：
Customer 表：
+-------------+-------------+
| customer_id | product_key |
+-------------+-------------+
| 1           | 5           |
| 2           | 6           |
| 3           | 5           |
| 3           | 6           |
| 1           | 6           |
+-------------+-------------+
Product 表：
+-------------+
| product_key |
+-------------+
| 5           |
| 6           |
+-------------+
输出：
+-------------+
| customer_id |
+-------------+
| 1           |
| 3           |
+-------------+
解释：
购买了所有产品（5 和 6）的客户的 id 是 1 和 3 。
```

## 题解

::: details 点击查看题解

### 思路

「买了所有产品」可以等价转换为「该客户买过的**不同**产品数量 = 产品表中的产品总数」。因此按 `customer_id` 分组，`COUNT(DISTINCT product_key)` 与 `SELECT COUNT(*) FROM Product` 比较即可，`HAVING` 天然适合这种「先聚合再比较聚合值」的筛选。

两个易错点：第一，`COUNT` 必须带 `DISTINCT`，因为 `Customer` 表可能包含重复行，同一客户同一产品可能出现多次，不去重会把数量算大，导致只买了两种产品的人误判为买全了；第二，分母用 `Product` 表的总行数，而 `product_key` 是主键所以不会重复，直接 `COUNT(*)` 即可，不需要再去重。

需要留意「外键约束」的语义：`Customer.product_key` 一定能在 `Product` 中找到，所以不会出现「客户买了产品表里没有的产品」把分子抬高的情况。如果业务上允许这种脏数据，则分子应改为只统计存在于 `Product` 中的产品（加一层 `JOIN`）。

替代写法：用 `NOT EXISTS` 表达「不存在某个产品是该客户没买过的」，语义更贴近题意，但相关子查询在客户多、产品多时开销更大；也可以先 `JOIN Product` 再按客户分组计数，效果与上面等价。

### SQL 实现

```sql
SELECT customer_id
FROM Customer
GROUP BY customer_id
HAVING COUNT(DISTINCT product_key) = (SELECT COUNT(*) FROM Product);
```

### 复杂度分析

- 时间复杂度：O(n + m)，n 为 `Customer` 行数、m 为 `Product` 行数，一次分组去重加一次全表计数。
- 空间复杂度：O(c)，c 为客户数，用于保存每个客户的产品去重集合。

:::

## 建表与测试数据

```sql
Create table If Not Exists Customer (customer_id int, product_key int);
Create table Product (product_key int);
Truncate table Customer;
insert into Customer (customer_id, product_key) values ('1', '5');
insert into Customer (customer_id, product_key) values ('2', '6');
insert into Customer (customer_id, product_key) values ('3', '5');
insert into Customer (customer_id, product_key) values ('3', '6');
insert into Customer (customer_id, product_key) values ('1', '6');
Truncate table Product;
insert into Product (product_key) values ('5');
insert into Product (product_key) values ('6');
```
