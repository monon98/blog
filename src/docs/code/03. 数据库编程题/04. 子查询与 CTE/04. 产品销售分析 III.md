# 产品销售分析 III

> 难度：中等 | 标签：子查询、多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/product-sales-analysis-iii/)

## 题目描述

销售表 `Sales`：

```
+-------------+-------+
| Column Name | Type  |
+-------------+-------+
| sale_id     | int   |
| product_id  | int   |
| year        | int   |
| quantity    | int   |
| price       | int   |
+-------------+-------+
(sale_id, year) 是这张表的主键（具有唯一值的列的组合）。
这张表的每一行都表示：编号 product_id 的产品在某一年的销售额。
一个产品可能在同一年内有多个销售条目。
请注意，价格是按每单位计的。
```

编写解决方案，选出每个售出过的产品 **第一年** 销售的 **产品 id**、**年份**、**数量 **和 **价格**。

	- 对每个 product_id，找到其在Sales表中首次出现的最早年份。

	- 返回该产品在该年度的 所有 销售条目。

返回一张有这些列的表：**product_id**，**first_year**，**quantity **和** price**。

结果表中的条目可以按 **任意顺序** 排列。

**示例 1：**

```
输入：
Sales 表：
+---------+------------+------+----------+-------+
| sale_id | product_id | year | quantity | price |
+---------+------------+------+----------+-------+
| 1       | 100        | 2008 | 10       | 5000  |
| 2       | 100        | 2009 | 12       | 5000  |
| 7       | 200        | 2011 | 15       | 9000  |
+---------+------------+------+----------+-------+
输出：
+------------+------------+----------+-------+
| product_id | first_year | quantity | price |
+------------+------------+----------+-------+
| 100        | 2008       | 10       | 5000  |
| 200        | 2011       | 15       | 9000  |
+------------+------------+----------+-------+
```

## 题解

::: details 点击查看题解

### 思路

题目要的不是「每个产品最早那一年的某一条记录」，而是「该产品最早年份里的**全部**销售条目」。这一点决定了不能简单用 `GROUP BY product_id` 配 `MIN(year)` 后随意取行——同一年内可能有多条销售记录（题目明确提示），必须把它们全部保留。

稳妥的做法是两步走：子查询按 `product_id` 求出 `MIN(year)` 作为该产品的首年，然后原表与这个子查询连接，连接条件同时包含 `product_id` 与 `year = first_year`。这样同一年内的多条记录都会命中，输出时把 `year` 重命名为 `first_year` 即可。

易错点：一是别用 `GROUP BY` 后的裸列（例如 `SELECT product_id, year, quantity ... GROUP BY product_id`），在 `ONLY_FULL_GROUP_BY` 下会报错，即便关掉该模式，取到的 `quantity` 也不保证来自最早年份；二是不要按 `sale_id` 最小来近似「最早」，`sale_id` 的顺序与年份没有必然关系；三是同一年有多条记录时不能去重，去重会漏掉条目。

替代写法：用窗口函数 `RANK() OVER (PARTITION BY product_id ORDER BY year)` 取 `rnk = 1`，一条语句完成，且天然保留同年所有记录，可读性好，适合更复杂的「每组前 N 名」场景。

### SQL 实现

```sql
SELECT s.product_id,
       s.year AS first_year,
       s.quantity,
       s.price
FROM Sales s
JOIN (
    SELECT product_id, MIN(year) AS first_year
    FROM Sales
    GROUP BY product_id
) f
    ON f.product_id = s.product_id
   AND f.first_year = s.year;
```

窗口函数写法（等价，可二选一）：

```sql
SELECT product_id, year AS first_year, quantity, price
FROM (
    SELECT product_id, year, quantity, price,
           RANK() OVER (PARTITION BY product_id ORDER BY year) AS rnk
    FROM Sales
) t
WHERE rnk = 1;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为销售记录数，分组求最小年份与连接匹配主导。
- 空间复杂度：O(p)，p 为产品数，用于保存每个产品的首年。
