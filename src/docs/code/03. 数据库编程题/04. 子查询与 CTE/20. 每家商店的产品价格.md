# 每家商店的产品价格

> 难度：简单 | 标签：行转列、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/products-price-for-each-store/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Products`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| store       | enum    |
| price       | int     |
+-------------+---------+
```

（`product_id`, `store`）是该表主键，`store` 是枚举类型，取值只有 `('store1', 'store2', 'store3')` 三种；`price` 是该商品在该商店的价格。

请找出每种商品在各个商店中的价格，把行结构转成「一行一个商品」的宽表：返回列 `product_id`、`store1`、`store2`、`store3`，某个商店没有销售该商品时对应列为 `null`。结果顺序任意。

**示例 1：**

```
输入：
Products 表：
+------------+--------+-------+
| product_id | store  | price |
+------------+--------+-------+
| 0          | store1 | 95    |
| 0          | store3 | 105   |
| 0          | store2 | 100   |
| 1          | store1 | 70   |
| 1          | store3 | 80    |
+------------+--------+-------+
输出：
+------------+--------+--------+--------+
| product_id | store1 | store2 | store3 |
+------------+--------+--------+--------+
| 0          | 95     | 100    | 105    |
| 1          | 70     | null   | 80     |
+------------+--------+--------+--------+
```

解释：产品 0 在三个商店的价格分别是 95、100、105；产品 1 只在 store1 和 store3 有售，store2 为 `null`。

## 题解

::: details 点击查看题解

### 思路

这是典型的行转列（pivot）：数据是「商品 + 商店 + 价格」的长表，输出要「一个商品一行、一个商店一列」。做法是按 `product_id` 分组，对每一列写条件聚合——只有 `store` 命中该店时才取 `price`，否则给 `NULL`，聚合函数把每组的多行压成一行。

关键是把 `ELSE` 留空（即 `NULL`）。如果顺手写成 `ELSE 0`，缺货的店铺会被填成 0，与题面要求的 `null` 不符，这是本题最常见的错误。因为每种商品在每家店最多只有一行记录，(product_id, store) 是主键，所以 `MAX`、`MIN`、`SUM` 在这里结果都一样，用 `MAX(CASE ...)` 语义最直观。

### SQL 实现

```sql
SELECT
    product_id,
    MAX(CASE WHEN store = 'store1' THEN price END) AS store1,
    MAX(CASE WHEN store = 'store2' THEN price END) AS store2,
    MAX(CASE WHEN store = 'store3' THEN price END) AS store3
FROM Products
GROUP BY product_id
ORDER BY product_id;
```

### 复杂度分析

- 时间复杂度：O(n)，扫一遍表按 `product_id` 分组聚合。
- 空间复杂度：O(1)，不计分组结果集。

:::

```sql

Truncate table Products;

insert into Products (product_id, store, price) values ('0', 'store3', '105');
insert into Products (product_id, store, price) values ('0', 'store2', '100');
insert into Products (product_id, store, price) values ('1', 'store1', '70');
insert into Products (product_id, store, price) values ('1', 'store3', '80');
```
