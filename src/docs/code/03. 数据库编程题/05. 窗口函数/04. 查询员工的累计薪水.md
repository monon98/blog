# 查询员工的累计薪水

> 难度：困难 | 标签：窗口函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/find-cumulative-salary-of-an-employee/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Employee`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| month       | int  |
| salary      | int  |
+-------------+------+
```

（`id`, `month`）是该表主键，每行表示某员工在 2020 年某个月的工资。

请计算每位员工的**累计工资汇总**：

- 对员工工作的每个月，把**该月**和**前两个月**的工资相加，得到当月的「3 个月工资总和」；如果员工前几个月没有在职记录，那几个月的工资按 `0` 计。
- 汇总中**不包含**每位员工**最近一个月**的 3 个月工资总和。
- 员工**没有工作**的月份不输出。

返回 `id`、`month`、`Salary`，按 `id` 升序排列；`id` 相同时按 `month` 降序排列。

**示例 1：**

```
输入：
Employee 表：
+----+-------+--------+
| id | month | salary |
+----+-------+--------+
| 1  | 1     | 20     |
| 2  | 1     | 20     |
| 1  | 2     | 30     |
| 2  | 2     | 30     |
| 3  | 2     | 40     |
| 1  | 3     | 40     |
| 3  | 3     | 60     |
| 1  | 4     | 60     |
| 3  | 4     | 70     |
| 1  | 7     | 90     |
| 1  | 8     | 90     |
+----+-------+--------+
输出：
+----+-------+--------+
| id | month | Salary |
+----+-------+--------+
| 1  | 7     | 90     |
| 1  | 4     | 130    |
| 1  | 3     | 90     |
| 1  | 2     | 50     |
| 1  | 1     | 20     |
| 2  | 1     | 20     |
| 3  | 3     | 100    |
| 3  | 2     | 40     |
+----+-------+--------+
```

解释：1 号员工有 6 条记录，最近的 8 月不输出。7 月因为 5、6 月没在职，累计只有 90；4 月是 60 + 40 + 30 = 130；3 月是 40 + 30 + 20 = 90；2 月是 30 + 20 + 0 = 50；1 月是 20。2 号员工只输出 1 月的 20（2 月是最近一个月）。3 号员工输出 3 月 100（60 + 40 + 0）和 2 月 40。

## 题解

::: details 点击查看题解

### 思路

思路分两步：先按员工排除「最近一个月」，再对剩下的月份算「当月 + 前两个月」的工资和。最近一个月就是每个 `id` 的 `MAX(month)`，用窗口 `MAX(month) OVER (PARTITION BY id)` 拿到手后过滤 `month < last_month` 最直观（等价写法是 `(id, month) NOT IN (SELECT id, MAX(month) ... GROUP BY id)`）。

关键在于窗口框架必须按**月份值**取范围，而不是按行数。1 号员工从 4 月直接跳到 7 月，如果写成 `ROWS BETWEEN 2 PRECEDING AND CURRENT ROW`，7 月会把前面的 3 月、4 月一起加进来得到 190；而 `RANGE BETWEEN 2 PRECEDING AND CURRENT ROW` 取的是 `month` 落在 `[month-2, month]` 的行，5、6 月没有记录就按 0 计，结果正好是题目要求的 90。

另外输出列名是 `Salary`（首字母大写），排序是 `id` 升序 + `month` 降序，别写成默认升序。

### SQL 实现

```sql
WITH t AS (
    SELECT
        id,
        month,
        SUM(salary) OVER (
            PARTITION BY id
            ORDER BY month
            RANGE BETWEEN 2 PRECEDING AND CURRENT ROW
        ) AS cum,
        MAX(month) OVER (PARTITION BY id) AS last_month
    FROM Employee
)
SELECT
    id,
    month,
    cum AS Salary
FROM t
WHERE month < last_month
ORDER BY id, month DESC;
```

### 复杂度分析

- 时间复杂度：O(n log n)，按 `id`、`month` 排序后做窗口聚合。
- 空间复杂度：O(n)，窗口函数需要缓存分区内的行。

:::
