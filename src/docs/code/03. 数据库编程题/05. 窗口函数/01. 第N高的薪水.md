# 第N高的薪水

> 难度：中等 | 标签：窗口函数、去重 | [LeetCode 原题](https://leetcode.cn/problems/nth-highest-salary/)

## 题目描述

表: `Employee`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| salary      | int  |
+-------------+------+
id 是该表的主键（列中的值互不相同）。
该表的每一行都包含有关员工工资的信息。
```

编写一个解决方案查询 `Employee` 表中第 `n` 高的 **不同** 工资。如果少于 `n` 个不同工资，查询结果应该为 `null` 。

查询结果格式如下所示。

**示例 1:**

```
输入:
Employee table:
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
| 2  | 200    |
| 3  | 300    |
+----+--------+
n = 2
输出:
+------------------------+
| getNthHighestSalary(2) |
+------------------------+
| 200                    |
+------------------------+
```

**示例 2:**

```
输入:
Employee 表:
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
+----+--------+
n = 2
输出:
+------------------------+
| getNthHighestSalary(2) |
+------------------------+
| null                   |
+------------------------+
```

## 题解

::: details 点击查看题解

### 思路

「第 N 高」有两个隐含要求：一是按**不同工资**排序（重复工资只算一个名次），二是名次之间不能跳号。`DENSE_RANK() OVER (ORDER BY salary DESC)` 正好满足：相同工资同名次，下一个名次紧接着 `+1`。取 `rnk = N` 的那行就是答案；用 `RANK()` 会因并列而跳号（例如 300、300、200 中 200 是第 3 名而非第 2 名），用 `ROW_NUMBER()` 则会把重复工资拆成不同名次。

另一个容易忽略的点是「不足 N 个不同工资时返回 `null`」：直接 `SELECT salary ... WHERE rnk = N` 在没有匹配行时返回的是**空结果集**（0 行），而不是一行 NULL。外面套一个 `MIN(salary)` 之类的聚合就能把空集变成 `NULL`，恰好对上题目要求。

N 的传法有两种：本地验证时用 `SET @N := 2`；LeetCode 原题给的是函数模板 `getNthHighestSalary(N INT)`，把 N 当入参即可。等价的经典写法是 `SELECT DISTINCT salary FROM Employee ORDER BY salary DESC LIMIT 1 OFFSET N - 1`，但 `LIMIT/OFFSET` 后面不接受表达式，得先把 `N - 1` 算好存进变量。

### SQL 实现

```sql
SET @N := 2;

WITH ranked AS (
    SELECT
        salary,
        DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
    FROM Employee
)
SELECT MIN(salary) AS `getNthHighestSalary(2)`
FROM ranked
WHERE rnk = @N;
```

### 复杂度分析

- 时间复杂度：O(n log n)，按工资降序排序后计算排名。
- 空间复杂度：O(n)，窗口函数需要物化排序后的中间结果。
