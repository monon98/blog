# 每辆车的乘客人数 II

> 难度：困难 | 标签：窗口函数、前缀和 | [LeetCode 原题](https://leetcode.cn/problems/the-number-of-passengers-in-each-bus-ii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Buses`：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| bus_id       | int  |
| arrival_time | int  |
| capacity     | int  |
+--------------+------+
bus_id 是该表的主键。每行表示一辆公交车到站的时间（整数时刻）与空座位数 capacity。
保证没有两辆车同时到站，且 capacity 为正整数。
```

表 `Passengers`：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| passenger_id | int  |
| arrival_time | int  |
+--------------+------+
passenger_id 是该表的主键。每行表示一位乘客到达车站的时刻。
```

规则：公交车到站时，所有到达时间不晚于该车到站时间、且还没有上过车的乘客都来排队；如果排队人数超过 `capacity`，只有前 `capacity` 位能上车，其余的人继续等下一班。

要求：统计每辆车的实际载客人数，返回 `bus_id`、`passengers_cnt` 两列，按 `bus_id` 升序排列。没有拉到乘客的车也要输出，人数为 0。

**示例 1：**

```
输入：
Buses 表：
+--------+--------------+----------+
| bus_id | arrival_time | capacity |
+--------+--------------+----------+
| 1      | 2            | 1        |
| 2      | 4            | 10       |
| 3      | 7            | 2        |
+--------+--------------+----------+

Passengers 表：
+--------------+--------------+
| passenger_id | arrival_time |
+--------------+--------------+
| 11           | 1            |
| 12           | 1            |
| 13           | 5            |
| 14           | 6            |
| 15           | 7            |
+--------------+--------------+
输出：
+--------+----------------+
| bus_id | passengers_cnt |
+--------+----------------+
| 1      | 1              |
| 2      | 1              |
| 3      | 2              |
+--------+----------------+
解释：
2 时刻：乘客 11、12 在等车，1 号车只有 1 个座位，载走 11，12 继续等；
4 时刻：12 还在等，2 号车座位充足，载走 12；
7 时刻：13、14、15 三人已在等，3 号车 2 个座位，载走其中 2 人。
```

## 题解

::: details 点击查看题解

### 思路

每辆车能载的人 = `MIN(本车容量, 本车到站时已到达的乘客数 - 之前各车已载走的乘客数)`。难点是"之前各车已载走多少人"依赖上一辆车的结果，是个逐车递推，不能简单对容量求前缀和。

设 `cum_arrived[i]` 为到第 i 辆车到站时累计到达的乘客数，`cum_capacity[i]` 为前 i 辆车的容量前缀和，`taken[i]` 为前 i 辆车累计载客数，则递推是 `taken[i] = MIN(taken[i-1] + capacity[i], cum_arrived[i])`。这个递推有闭式解：`taken[i] = cum_capacity[i] + MIN(0, MIN over j<=i (cum_arrived[j] - cum_capacity[j]))`，也就是"容量前缀和 + 到当前为止 `(累计到达 - 累计容量)` 的滑动最小值（并和 0 取小）"。于是两个窗口函数就能自底向上一次算完：`SUM` 求前缀和、`MIN` 求滑动最小值，最后相邻两行 `taken` 相减就是本车载客数（`LAG` 的默认值取 0）。

坑点：不能直接把 `cum_arrived` 和 `capacity` 取 `MIN`，那会把前面车已经载走的人重复算进来；必须按 `arrival_time` 排序，`bus_id` 与到站顺序无必然关系；`MIN(0, ...)` 里的 0 是递推初始项 `taken[0] = 0` 的锚点，漏掉它会让第一辆车永远满载。

替代写法：用用户变量（`@t`、`@cur`）逐行模拟，或递归 CTE 逐车递推；思路更直白，但用户变量在 MySQL 8 中已被标记为不推荐，且顺序在优化器下不保证，能用窗口函数就用窗口函数。

### SQL 实现

```sql
WITH arrived AS (
    SELECT b.bus_id, b.arrival_time, b.capacity,
           (SELECT COUNT(*) FROM Passengers p WHERE p.arrival_time <= b.arrival_time) AS cum_arrived
    FROM Buses b
),
prefixed AS (
    SELECT bus_id, arrival_time, capacity, cum_arrived,
           SUM(capacity) OVER (ORDER BY arrival_time) AS cum_capacity
    FROM arrived
),
boarded AS (
    SELECT bus_id, arrival_time, capacity, cum_arrived, cum_capacity,
           cum_capacity + LEAST(0, MIN(cum_arrived - cum_capacity) OVER (ORDER BY arrival_time)) AS total_boarded
    FROM prefixed
)
SELECT bus_id,
       total_boarded - LAG(total_boarded, 1, 0) OVER (ORDER BY arrival_time) AS passengers_cnt
FROM boarded
ORDER BY bus_id;
```

### 复杂度分析

- 时间复杂度：O(b log b + b * p)，b 为公交车数，p 为乘客数（累计到达用相关子查询统计）；窗口排序为 O(b log b)。
- 空间复杂度：O(b)，保存每辆车的累计量。
