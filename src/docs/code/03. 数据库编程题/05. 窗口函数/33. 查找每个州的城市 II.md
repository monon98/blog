# 查找每个州的城市 II

> 难度：中等 | 标签：分组聚合、字符串函数 | [LeetCode 原题](https://leetcode.cn/problems/find-cities-in-each-state-ii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`cities` 表：

```
+-------------+--------------+
| Column Name | Type         |
+-------------+--------------+
| state       | varchar(100) |
| city        | varchar(100) |
+-------------+--------------+
(state, city) 组合唯一，每一行表示州名以及该州内的一个城市名。
```

编写一个解决方案，找出 **每个州** 的全部城市并按下列要求分析：

- 把该州所有城市用「逗号 + 空格」拼成一个字符串，城市名按字母序排列；
- 只保留城市数量 **至少为 3** 的州；
- 只保留 **至少有一个城市** 与州名 **首字母相同** 的州；
- 输出还要给出匹配首字母的城市数量 `matching_letter_count`；
- 结果按 `matching_letter_count` 降序、州名升序排序。

**示例 1：**

```
输入：
cities 表：
+--------------+---------------+
| state        | city          |
+--------------+---------------+
| New York     | New York City |
| New York     | Newark        |
| New York     | Buffalo       |
| New York     | Rochester     |
| California   | San Francisco |
| California   | Sacramento    |
| California   | San Diego     |
| California   | Los Angeles   |
| Texas        | Tyler         |
| Texas        | Temple        |
| Texas        | Taylor        |
| Texas        | Dallas        |
| Pennsylvania | Philadelphia  |
| Pennsylvania | Pittsburgh    |
| Pennsylvania | Pottstown     |
+--------------+---------------+

输出：
+--------------+-------------------------------------------+-----------------------+
| state        | cities                                    | matching_letter_count |
+--------------+-------------------------------------------+-----------------------+
| Pennsylvania | Philadelphia, Pittsburgh, Pottstown       | 3                     |
| Texas        | Dallas, Taylor, Temple, Tyler             | 3                     |
| New York     | Buffalo, New York City, Newark, Rochester | 2                     |
+--------------+-------------------------------------------+-----------------------+

解释：
Pennsylvania 有 3 个城市且全部以 P 开头，匹配数为 3；
Texas 有 4 个城市，其中 Taylor、Temple、Tyler 以 T 开头，匹配数为 3；
New York 有 4 个城市，其中 New York City、Newark 以 N 开头，匹配数为 2；
California 虽然有 4 个城市，但没有城市以 C 开头，被过滤掉。
（Newark 与 New York City 的先后取决于字符串排序规则中空格的处理方式。）
```

## 题解

::: details 点击查看题解

### 思路

按州分组后用 `GROUP_CONCAT(city ORDER BY city SEPARATOR ', ')` 把城市拼成一个字符串；匹配数量用 `SUM(LEFT(city, 1) = LEFT(state, 1))` 求和 —— 布尔表达式在 MySQL 里就是 1/0，直接加总即可。

过滤条件放在 `HAVING`：`COUNT(*) >= 3` 保证至少 3 个城市，`matching_letter_count > 0` 保证至少一个城市首字母与州名相同。MySQL 允许在 `HAVING` 中引用 `SELECT` 里的别名。

易错点：

- 首字母用 `LEFT(x, 1)` 取，`SUBSTRING(x, 1, 1)` 等价；若数据里大小写混用，需要先 `LOWER()` 再比较。
- `GROUP_CONCAT` 内部的排序依赖字段的 collation。像 `Newark` 与 `New York City` 这种「空格与字母」的比较，不同排序规则下顺序会不同，本题输出以 MySQL 8 默认的 `utf8mb4_0900_ai_ci` 为准。
- `GROUP_CONCAT` 默认长度上限是 1024 字节，城市极多时会被截断，可用 `SET SESSION group_concat_max_len = 100000` 放宽。
- 最终排序是匹配数量降序、州名升序；注意 Pennsylvania 与 Texas 的匹配数都是 3，按字母序 Pennsylvania 在前。

### SQL 实现

```sql
SELECT state,
       GROUP_CONCAT(city ORDER BY city SEPARATOR ', ') AS cities,
       SUM(LEFT(city, 1) = LEFT(state, 1)) AS matching_letter_count
FROM cities
GROUP BY state
HAVING COUNT(*) >= 3 AND matching_letter_count > 0
ORDER BY matching_letter_count DESC, state;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为城市数，分组内的字符串排序主导。
- 空间复杂度：O(n)，每个州要保存拼接后的字符串。
