# 英超积分榜排名

> 难度：简单 | 标签：窗口函数、RANK | [LeetCode 原题](https://leetcode.cn/problems/premier-league-table-ranking/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`TeamStats` 表：

```
+----------------+--------------+
| Column Name    | Type         |
+----------------+--------------+
| team_id        | int          |
| team_name      | varchar(100) |
| matches_played | int          |
| wins           | int          |
| draws          | int          |
| losses         | int          |
+----------------+--------------+
team_id 是该表的主键，每一行包含球队 id、队名、场次、胜、平、负。
```

编写一个解决方案，计算每支球队的 **积分** 与 **排名**：

- 胜一场 3 分，平一场 1 分，负一场 0 分，即 `points = wins * 3 + draws`；
- 按积分降序排名，**积分相同的球队名次相同**，且后续名次跳过（例如 1、1、3）；
- 返回 `team_id`、`team_name`、`points`、`position`，按 `points` 降序、`team_name` 升序排序。

**示例 1：**

```
输入：
TeamStats 表：
+---------+-----------------+----------------+------+-------+--------+
| team_id | team_name       | matches_played | wins | draws | losses |
+---------+-----------------+----------------+------+-------+--------+
| 1       | Manchester City | 10             | 6    | 2     | 2      |
| 2       | Liverpool       | 10             | 6    | 2     | 2      |
| 3       | Chelsea         | 10             | 5    | 3     | 2      |
| 4       | Arsenal         | 10             | 4    | 4     | 2      |
| 5       | Tottenham       | 10             | 3    | 5     | 2      |
+---------+-----------------+----------------+------+-------+--------+

输出：
+---------+-----------------+--------+----------+
| team_id | team_name       | points | position |
+---------+-----------------+--------+----------+
| 2       | Liverpool       | 20     | 1        |
| 1       | Manchester City | 20     | 1        |
| 3       | Chelsea         | 18     | 3        |
| 4       | Arsenal         | 16     | 4        |
| 5       | Tottenham       | 14     | 5        |
+---------+-----------------+--------+----------+

解释：
曼城与利物浦都是 6 * 3 + 2 = 20 分，并列第 1，下一名直接是第 3；
切尔西 18 分第 3，阿森纳 16 分第 4，热刺 14 分第 5。
```

## 题解

::: details 点击查看题解

### 思路

积分直接算 `wins * 3 + draws`，名次用 `RANK()` 窗口函数：`RANK` 会给排序键相同的行相同的名次，并跳过后续名次（1,1,3,4,5），正好对应积分榜「同分并列、下一名跳号」的规则。

易错点：

- 窗口函数的 `ORDER BY` 里不能引用同一层 `SELECT` 的别名 `points`，必须重复完整表达式 `wins * 3 + draws`。
- 输出要求按 `points` 降序、`team_name` 升序，而不是按 `position` 排序；并列第一时 Liverpool 要排在 Manchester City 之前。
- 用 `ROW_NUMBER()` 会把两个 20 分拆成第 1、2 名，与「同分同名次」冲突。

### SQL 实现

```sql
SELECT team_id,
       team_name,
       wins * 3 + draws AS points,
       RANK() OVER (ORDER BY wins * 3 + draws DESC) AS position
FROM TeamStats
ORDER BY points DESC, team_name;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为球队数，一次排序主导。
- 空间复杂度：O(n)，窗口排序需要额外空间。

:::
