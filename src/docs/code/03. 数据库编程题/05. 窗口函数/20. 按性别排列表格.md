# 按性别排列表格

> 难度：中等 | 标签：窗口函数、排序 | [LeetCode 原题](https://leetcode.cn/problems/arrange-table-by-gender/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Genders`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| gender      | varchar |
+-------------+---------+
user_id 是该表的主键。
gender 是 ENUM 类型，取值只可能是 'female'、'other'、'male'。
表中三种性别的人数相等。
```

要求：重排表格，使结果行按 `female`、`other`、`male` 的顺序**循环交替**出现（第一行 female，第二行 other，第三行 male，第四行又是 female……），并且同性别内部按 `user_id` 升序排列。返回 `user_id`、`gender` 两列，顺序即上述排列。

**示例 1：**

```
输入：
Genders 表：
+---------+--------+
| user_id | gender |
+---------+--------+
| 4       | male   |
| 7       | female |
| 2       | other  |
| 5       | male   |
| 3       | female |
| 8       | male   |
| 6       | other  |
| 1       | other  |
| 9       | female |
+---------+--------+
输出：
+---------+--------+
| user_id | gender |
+---------+--------+
| 3       | female |
| 1       | other  |
| 4       | male   |
| 7       | female |
| 2       | other  |
| 5       | male   |
| 9       | female |
| 6       | other  |
| 8       | male   |
+---------+--------+
解释：
female 的 user_id 升序为 3、7、9，other 为 1、2、6，male 为 4、5、8；按位次依次取三个性别的一组，形成交替序列。
```

## 题解

::: details 点击查看题解

### 思路

题目要的是"交替"而不是"分块"：如果只写 `ORDER BY gender`，结果是三大段（全部 female、全部 other、全部 male），与要求不符。

正确的排序键是**两个键的组合**：第一个键是"同性别内部的位次"——对每个性别用 `ROW_NUMBER()` 按 `user_id` 升序编号，得到 1、2、3……；第二个键是性别本身的顺序（female 最小、other 次之、male 最大）。这样第 1 名里三个性别依次出现，第 2 名里又依次出现，自然形成 female、other、male 的循环；由于每个性别内部是按 `user_id` 升序编号的，交替序列里的同性别行也天然满足升序。

坑点：性别顺序不能依赖 `ENUM` 的定义顺序或字母序（`female` < `male` < `other` 是字母序，和要求的 female、other、male 不同），要用 `FIELD(gender, 'female', 'other', 'male')` 或 `CASE WHEN` 显式映射。另外要用 `RANK`/`ROW_NUMBER` 而不是直接对性别排序；题目保证三种性别行数相等，若不等，多出的行会落在各自位次上，交替序列尾部会缺项，但本解法依旧给出确定顺序。

### SQL 实现

```sql
WITH t AS (
    SELECT user_id,
           gender,
           RANK() OVER (PARTITION BY gender ORDER BY user_id) AS rn,
           FIELD(gender, 'female', 'other', 'male') AS g
    FROM Genders
)
SELECT user_id, gender
FROM t
ORDER BY rn, g;
```

### 复杂度分析

- 时间复杂度：O(n log n)，分区排序与最终排序主导。
- 空间复杂度：O(n)，保存每位用户的位次。
