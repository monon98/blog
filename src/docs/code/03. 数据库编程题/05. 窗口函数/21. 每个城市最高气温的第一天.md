# 每个城市最高气温的第一天

> 难度：中等 | 标签：窗口函数、排名 | [LeetCode 原题](https://leetcode.cn/problems/the-first-day-of-the-maximum-recorded-degree-in-each-city/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Weather`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| city_id     | int  |
| day         | date |
| degree      | int  |
+-------------+------+
(city_id, day) 是该表的主键，degree 是当天记录到的气温（可能为负数）。
```

要求：找出每个城市记录到**最高气温的那一天中最早的一天**，返回 `city_id`、`day`、`degree` 三列，按 `city_id` 升序排列。

**示例 1：**

```
输入：
Weather 表：
+---------+------------+--------+
| city_id | day        | degree |
+---------+------------+--------+
| 1       | 2022-01-07 | -12    |
| 1       | 2022-03-07 | 5      |
| 1       | 2022-07-07 | 24     |
| 2       | 2022-08-07 | 37     |
| 2       | 2022-08-17 | 37     |
| 3       | 2022-02-07 | -7     |
| 3       | 2022-12-07 | -6     |
+---------+------------+--------+
输出：
+---------+------------+--------+
| city_id | day        | degree |
+---------+------------+--------+
| 1       | 2022-07-07 | 24     |
| 2       | 2022-08-07 | 37     |
| 3       | 2022-12-07 | -6     |
+---------+------------+--------+
解释：
城市 1 最高气温是 24，只出现过一次；
城市 2 的 37 在 08-07 和 08-17 都出现过，取更早的 08-07；
城市 3 最高气温是 -6（负数的比较不要弄反）。
```

## 题解

::: details 点击查看题解

### 思路

"最高温，且取最早的一天"可以一次排序搞定：在城市内按 `degree DESC, day ASC` 排序，排在第一位的行正好同时满足两个条件——温度最高，温度相同时日期最早。

取第一行要用 `ROW_NUMBER()` 而不是 `RANK()`：`RANK` 会把并列最高温的所有日期都保留（城市 2 会返回两行），而题目只要最早那一天。这也是本题最容易踩的坑。

另一个坑是负数的排序方向：`degree DESC` 对 `-7` 和 `-6` 会正确地把 `-6` 排在前面，但如果误写成按绝对值或字符串排序就会出错。`degree` 是 `int`，直接倒序即可。替代写法：先 `GROUP BY city_id` 求 `MAX(degree)`，再 `JOIN` 回原表并取 `MIN(day)`，需要两三次扫描，窗口函数更简洁。

### SQL 实现

```sql
WITH ranked AS (
    SELECT city_id, day, degree,
           ROW_NUMBER() OVER (PARTITION BY city_id ORDER BY degree DESC, day ASC) AS rn
    FROM Weather
)
SELECT city_id, day, degree
FROM ranked
WHERE rn = 1
ORDER BY city_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，分区排序主导。
- 空间复杂度：O(n)，保存带名次的气温记录。
