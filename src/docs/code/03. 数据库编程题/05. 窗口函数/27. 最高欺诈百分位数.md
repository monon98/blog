# 最高欺诈百分位数

> 难度：中等 | 标签：窗口函数、百分位排名 | [LeetCode 原题](https://leetcode.cn/problems/top-percentile-fraud/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Fraud` 表：

```
+-------------+--------------+
| Column Name | Type         |
+-------------+--------------+
| policy_id   | int          |
| state       | varchar(50)  |
| fraud_score | decimal(5,2) |
+-------------+--------------+
policy_id 具有唯一值，每一行表示保单 id、所属州以及欺诈分数。
```

保险公司会安排经验最丰富的理赔员处理每个州中排名前 **5%** 的保单。编写一个解决方案，找出 **每个州中处于前 5 百分位** 的保单（即欺诈分数高于本州 95% 的保单）。

返回 `policy_id`、`state`、`fraud_score`，按 `state` 升序、`fraud_score` 降序、`policy_id` 升序排序。

**示例 1：**

```
输入：
Fraud 表：
+-----------+------------+-------------+
| policy_id | state      | fraud_score |
+-----------+------------+-------------+
| 1         | California | 0.92        |
| 2         | California | 0.68        |
| 3         | California | 0.17        |
| 4         | New York   | 0.94        |
| 5         | New York   | 0.81        |
| 6         | New York   | 0.77        |
| 7         | Texas      | 0.98        |
| 8         | Texas      | 0.97        |
| 9         | Texas      | 0.96        |
| 10        | Florida    | 0.97        |
| 11        | Florida    | 0.98        |
| 12        | Florida    | 0.78        |
| 13        | Florida    | 0.88        |
| 14        | Florida    | 0.66        |
+-----------+------------+-------------+

输出：
+-----------+------------+-------------+
| policy_id | state      | fraud_score |
+-----------+------------+-------------+
| 1         | California | 0.92        |
| 11        | Florida    | 0.98        |
| 4         | New York   | 0.94        |
| 7         | Texas      | 0.98        |
+-----------+------------+-------------+

解释：
California 的 0.92、Florida 的 0.98、New York 的 0.94、Texas 的 0.98 分别是各自州内
分数最高的一笔，只有它们落在该州前 5 百分位内。
```

## 题解

::: details 点击查看题解

### 思路

「前 5 百分位」用 `PERCENT_RANK()`：它在每个分区内按指定顺序算出相对名次 `(rank - 1) / (rows - 1)`，结果落在 0~1。按 `fraud_score` 降序计算时，每个州的最高分得到 0，分数越低越接近 1，所以筛 `pr <= 0.05` 就是「比本州 95% 的保单分数都高」。

易错点：

- 必须 `PARTITION BY state`，题目是按州各自取前 5%，不是全表取一次。
- 不要用绝对阈值（比如 `fraud_score > 0.95`）替代百分位，两者含义不同：某州可能整体分数偏低，最高分也进不了 0.95。
- 本题每个州只有 3~5 行，`PERCENT_RANK` 只有最高分那一行 ≤ 0.05，结果看起来和 `RANK() = 1` 一样；但一行数超过 21 行时二者就不同了，`RANK() = 1` 只是这道题数据规模下「碰巧对」的简化写法。
- 排序要求是 `state` 升序、`fraud_score` 降序、`policy_id` 升序，三层都要写，否则同一分数（如 Florida 与 Texas 的 0.98）的先后不确定。

### SQL 实现

```sql
WITH t AS (
    SELECT policy_id, state, fraud_score,
           PERCENT_RANK() OVER (PARTITION BY state ORDER BY fraud_score DESC) AS pr
    FROM Fraud
)
SELECT policy_id, state, fraud_score
FROM t
WHERE pr <= 0.05
ORDER BY state, fraud_score DESC, policy_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为保单数，分区内按分数排序主导。
- 空间复杂度：O(n)，需要保存每行的百分位计算结果。
