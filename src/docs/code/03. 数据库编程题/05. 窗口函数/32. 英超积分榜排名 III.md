# 英超积分榜排名 III

> 难度：中等 | 标签：窗口函数、多条件排序 | [LeetCode 原题](https://leetcode.cn/problems/premier-league-table-ranking-iii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`SeasonStats` 表：

```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| season_id      | int     |
| team_id        | int     |
| team_name      | varchar |
| matches_played | int     |
| wins           | int     |
| draws          | int     |
| losses         | int     |
| goals_for      | int     |
| goals_against  | int     |
+----------------+---------+
(season_id, team_id) 是该表的主键，每一行包含某个赛季中某支球队的
场次、胜、平、负、进球数 (goals_for) 和失球数 (goals_against)。
```

编写一个解决方案，计算 **每个赛季每支球队** 的积分、净胜球和排名：

- 积分：胜 3 分、平 1 分、负 0 分，即 `points = wins * 3 + draws`；
- 净胜球：`goal_difference = goals_for - goals_against`；
- 排名规则：先按积分降序；积分相同按净胜球降序；净胜球也相同按队名字母升序；
- 排名在每个赛季内独立计算（`PARTITION BY season_id`）；
- 返回 `season_id`、`team_id`、`team_name`、`points`、`goal_difference`、`position`，
  按 `season_id` 升序、`position` 升序、`team_name` 升序排序。

**示例 1：**


## 题解

::: details 点击查看题解

### 思路

净胜球 `goals_for - goals_against` 可以直接算，排名规则按优先级写成三段排序键：积分降序 → 净胜球降序 → 队名升序，交给 `RANK()` 一次性得到名次。`PARTITION BY season_id` 保证每个赛季独立排名。

易错点：

- `RANK` 内部的 `ORDER BY` 同样不能引用 `SELECT` 别名（`points`、`goal_difference`），要把完整表达式重复一遍；外层输出再用别名。
- 队名参与排序时是升序（默认方向），不要顺手写成 `DESC`。
- 输出顺序是 `season_id` 升序、`position` 升序、`team_name` 升序，其中 `position` 是别名，`ORDER BY` 可以引用它。
- 用 `RANK()` 而不是 `ROW_NUMBER()`：如果两支球队积分与净胜球完全相同，它们应当并列同名次；本题数据没有完全并列，两者结果相同。

### SQL 实现

```sql
SELECT season_id,
       team_id,
       team_name,
       wins * 3 + draws AS points,
       goals_for - goals_against AS goal_difference,
       RANK() OVER (PARTITION BY season_id
                    ORDER BY wins * 3 + draws DESC,
                             goals_for - goals_against DESC,
                             team_name ASC) AS position
FROM SeasonStats
ORDER BY season_id, position, team_name;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为赛季-球队记录数，按赛季分区排序主导。
- 空间复杂度：O(n)，窗口计算需要保存中间结果。

:::
