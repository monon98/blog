# 将表中的空值更改为前一个值

> 难度：中等 | 标签：窗口函数、NULL 处理 | [LeetCode 原题](https://leetcode.cn/problems/change-null-values-in-a-table-to-the-previous-value/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`CoffeeShop` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| drink       | varchar |
+-------------+---------+
id 是该表的主键，每一行表示订单 id 和所点饮料的名称，部分饮料为 NULL。
```

编写一个解决方案，把 `drink` 的 `NULL` 值替换为「按 `id` 升序排列时，它前面最近一行不为 `NULL` 的 `drink`」。题目保证 `id` 最小的那一行 `drink` 不为 `NULL`。

返回包含 `id` 与 `drink` 的结果表（这里按 `id` 升序展示，便于核对填充结果）。

**示例 1：**

```
输入：
CoffeeShop 表：
+----+-------------------+
| id | drink             |
+----+-------------------+
| 9  | Rum and Coke      |
| 6  | NULL              |
| 7  | NULL              |
| 3  | St Germain Spritz |
| 1  | Orange Margarita  |
| 2  | NULL              |
+----+-------------------+

输出：
+----+-------------------+
| id | drink             |
+----+-------------------+
| 1  | Orange Margarita  |
| 2  | Orange Margarita  |
| 3  | St Germain Spritz |
| 6  | St Germain Spritz |
| 7  | St Germain Spritz |
| 9  | Rum and Coke      |
+----+-------------------+

解释：
按 id 排序后依次是 1、2、3、6、7、9。
id = 2 的前一个非空值是 id = 1 的 "Orange Margarita"；
id = 6、7 的前一个非空值是 id = 3 的 "St Germain Spritz"；
id = 9 本身不为空，保持 "Rum and Coke"。
```

## 题解

::: details 点击查看题解

### 思路

「把空值改成前一个值」本质是按 `id` 排序后做向前填充（forward fill）。SQL 没有 fill-down 函数，标准解法是「分组 + 组内取唯一非空值」：

1. 先用 `ROW_NUMBER() OVER (ORDER BY id)` 把行固定成唯一序号 `rn`，后面所有窗口都按它排序，避免并列导致的顺序不确定；
2. 用 `SUM(drink IS NOT NULL) OVER (ORDER BY rn)` 做前缀和得到组号 `gid`：每遇到一个非空值组号加 1，紧跟其后的连续 `NULL` 与它同组；
3. 每个 `gid` 组里恰好只有一个非空值，因此 `MAX(drink) OVER (PARTITION BY gid)` 就是该组要填充的值。

易错点：

- 前缀和的 `ORDER BY` 必须是唯一且稳定的键。如果直接 `OVER (ORDER BY drink)` 或 `OVER ()`，默认的 `RANGE` 帧会把排序键相同的行算进同一组，结果不可控。
- 只有「开头连续 NULL」所在的 `gid = 0` 组没有非空值，`MAX` 会返回 `NULL`；本题保证第一行（最小 id）不为空，所以不用额外处理。
- `SUM(条件)` 中布尔值被当作 1/0，是 MySQL 的常用写法，等价于 `SUM(CASE WHEN ... THEN 1 ELSE 0 END)`。
- 题目要求的是「返回结果表」，所以用 `SELECT` 即可；如果要求原地修改表，可以把这个查询包成派生表再 `UPDATE ... JOIN`，用会话变量 `@cur` 逐行赋值也能实现，但可移植性差。

输出按 `id` 升序展示，便于核对「前一个值」的传递关系。

### SQL 实现

```sql
WITH seq AS (
    SELECT id, drink,
           ROW_NUMBER() OVER (ORDER BY id) AS rn
    FROM CoffeeShop
), grouped AS (
    SELECT id, drink, rn,
           SUM(drink IS NOT NULL) OVER (ORDER BY rn) AS gid
    FROM seq
)
SELECT id,
       MAX(drink) OVER (PARTITION BY gid) AS drink
FROM grouped
ORDER BY id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为订单行数，两次窗口排序主导。
- 空间复杂度：O(n)，中间 CTE 保存了带序号的完整行。

```sql
Create table If Not Exists CoffeeShop (id int, drink varchar(20));
Truncate table CoffeeShop;
insert into CoffeeShop (id, drink) values ('9', 'Rum and Coke');
insert into CoffeeShop (id, drink) values ('6', NULL);
insert into CoffeeShop (id, drink) values ('7', NULL);
insert into CoffeeShop (id, drink) values ('3', 'St Germain Spritz');
insert into CoffeeShop (id, drink) values ('1', 'Orange Margarita');

```
