# 以百分比计算排名

> 难度：中等 | 标签：窗口函数、排名函数 | [LeetCode 原题](https://leetcode.cn/problems/compute-the-rank-as-a-percentage/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Students` 表：

```
+---------------+------+
| Column Name   | Type |
+---------------+------+
| student_id    | int  |
| department_id | int  |
| mark          | int  |
+---------------+------+
student_id 包含唯一值，每一行表示学生 ID、所在院系 ID 以及考试分数。
```

编写一个解决方案，以百分比的形式报告每个学生在其院系内的排名：

- 百分比按公式 `(院系内该学生的名次 - 1) * 100 / (院系学生数 - 1)` 计算；
- 名次由 `mark` 降序决定，`mark` 最高者名次为 1，分数相同则名次相同；
- `percentage` 四舍五入到小数点后两位；院系只有一名学生时分母为 0，此时百分比记为 0；
- 以任意顺序返回包含 `student_id`、`department_id`、`percentage` 的结果表。

**示例 1：**

```
输入：
Students 表：
+------------+---------------+------+
| student_id | department_id | mark |
+------------+---------------+------+
| 2          | 2             | 650  |
| 8          | 2             | 650  |
| 7          | 1             | 920  |
| 1          | 1             | 610  |
| 3          | 1             | 530  |
+------------+---------------+------+

输出：
+------------+---------------+------------+
| student_id | department_id | percentage |
+------------+---------------+------------+
| 7          | 1             | 0.0        |
| 1          | 1             | 50.0       |
| 3          | 1             | 100.0      |
| 2          | 2             | 0.0        |
| 8          | 2             | 0.0        |
+------------+---------------+------------+

解释：
院系 1 共 3 人，学生 7 名次第 1：(1 - 1) * 100 / (3 - 1) = 0.0；
学生 1 名次第 2：(2 - 1) * 100 / (3 - 1) = 50.0；
学生 3 名次第 3：(3 - 1) * 100 / (3 - 1) = 100.0。
院系 2 的两人同为 650 分，名次都是第 1：(1 - 1) * 100 / (2 - 1) = 0.0。
```

## 题解

::: details 点击查看题解

### 思路

先在院系内按分数降序排名（`RANK`），再用窗口版 `COUNT` 拿到院系人数，最后套公式算百分比。两处细节最容易出错：

- 分数相同时名次必须相同，所以要用 `RANK()` 而不是 `ROW_NUMBER()`。示例里院系 2 的两人都是 650 分，都应是第 1 名，百分比都是 0；如果换成 `ROW_NUMBER()`，其中一人会被算成第 2 名、百分比 100。
- 院系只有 1 人时分母为 0。MySQL 中整数除零返回 `NULL` 而不是报错，但题目要求这种情形的百分比记为 0，所以外面套一层 `IFNULL(..., 0)`（也可以写 `CASE WHEN COUNT(*) OVER (...) = 1 THEN 0`）。

窗口函数不能写在同层 `WHERE` 里，本题不需要过滤，直接投影即可；`ORDER BY` 可以引用 `SELECT` 的别名 `percentage`，题目允许任意顺序，这里按院系、百分比升序输出，与示例一致。

替代写法：自连接统计「分数比自己高的人数 + 1」得到名次，再除以院系人数减一，逻辑直白但是 O(n²)，数据量大时不如窗口函数。

### SQL 实现

```sql
SELECT student_id,
       department_id,
       IFNULL(
           ROUND((RANK() OVER (PARTITION BY department_id ORDER BY mark DESC) - 1) * 100.0
                 / (COUNT(*) OVER (PARTITION BY department_id) - 1), 2),
           0
       ) AS percentage
FROM Students
ORDER BY department_id, percentage;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为学生数，窗口内的分区排序主导。
- 空间复杂度：O(n)，窗口计算需要保存分区后的中间结果。

:::
