# 访问日期之间最大的空档期

> 难度：中等 | 标签：窗口函数、日期函数 | [LeetCode 原题](https://leetcode.cn/problems/biggest-window-between-visits/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `UserVisits`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| user_id     | int  |
| visit_date  | date |
+-------------+------+
该表记录用户的访问日期，同一个用户同一天可能有多条记录（重复行）。
```

要求：计算每个用户**任意两次相邻访问之间**相隔的最多天数，返回 `user_id`、`biggest_window` 两列，按 `user_id` 升序排列。如果某个用户只访问过一次（没有"相邻的两次"），空档期记为 `0`。

**示例 1：**

```
输入：
UserVisits 表：
+---------+------------+
| user_id | visit_date |
+---------+------------+
| 1       | 2020-11-28 |
| 1       | 2020-10-20 |
| 1       | 2020-12-03 |
| 2       | 2020-10-05 |
| 2       | 2020-12-09 |
| 3       | 2020-11-11 |
+---------+------------+
输出：
+---------+----------------+
| user_id | biggest_window |
+---------+----------------+
| 1       | 39             |
| 2       | 65             |
| 3       | 0              |
+---------+----------------+
解释：
用户 1 的访问日期排序后为 10-20、11-28、12-03，相邻间隔分别是 39 天和 5 天，最大空档期是 39；
用户 2 只有两次访问，间隔 65 天；用户 3 只访问过一次，空档期为 0。
```

## 题解

::: details 点击查看题解

### 思路

"相邻两次的差值"用 `LAG` 一句话就能拿到：在每个用户内按 `visit_date` 升序取上一行日期，再用 `DATEDIFF(当前日期, 上一次日期)` 得到间隔天数；最后按用户 `MAX` 就是这个用户的最大空档期。

细节有三个。第一，表里允许同一用户同一天有重复记录，必须先 `DISTINCT`，否则同一天两条记录会算出 0 天间隔（虽然不影响最大值，但语义上"访问"应算一天，去重也更稳）。第二，`MAX` 遇到只有一次访问的用户时所有 `LAG` 都是 `NULL`，聚合结果为 `NULL`，必须用 `COALESCE(..., 0)` 转成题目要求的 0。第三，`DATEDIFF(a, b)` 是"a 减 b 的天数"，参数顺序写反会得到负数，`MAX` 就会退化成接近 0 的值。

替代写法：按用户自连接，条件是 `v2.visit_date < v1.visit_date` 再取相邻（可以用 `NOT EXISTS` 约束中间没有别的访问），逻辑正确但连接代价高，`LAG` 是更现代也更高效的写法。

### SQL 实现

```sql
WITH visits AS (
    SELECT DISTINCT user_id, visit_date
    FROM UserVisits
),
gaps AS (
    SELECT user_id,
           visit_date,
           LAG(visit_date) OVER (PARTITION BY user_id ORDER BY visit_date) AS prev_date
    FROM visits
)
SELECT user_id,
       COALESCE(MAX(DATEDIFF(visit_date, prev_date)), 0) AS biggest_window
FROM gaps
GROUP BY user_id
ORDER BY user_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，去重与窗口排序占主导。
- 空间复杂度：O(n)，保存去重后的访问记录。
