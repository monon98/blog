# 每位顾客最经常订购的商品

> 难度：中等 | 标签：分组聚合、窗口函数 | [LeetCode 原题](https://leetcode.cn/problems/the-most-frequently-ordered-products-for-each-customer/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Customers`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| customer_id | int     |
| name        | varchar |
+-------------+---------+
customer_id 是该表的主键，name 是顾客姓名。
```

表 `Orders`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| order_id    | int     |
| order_date  | date    |
| customer_id | int     |
| product_id  | int     |
+-------------+---------+
order_id 是该表的主键，每行表示某位顾客在某天订购了一件商品。
```

表 `Products`：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| product_id   | int     |
| product_name | varchar |
| price        | int     |
+--------------+---------+
product_id 是该表的主键。
```

要求：找出每位顾客**订购次数最多**的商品，返回 `customer_id`、`product_id`、`product_name` 三列。题目保证每位顾客最常订购的商品唯一；只考虑至少下过一次订单的顾客。

**示例 1：**

```

+-------------+-------+

| 3        | 2020-08-29 | 3           | 3          |
| 4        | 2020-07-29 | 4           | 1          |
| 5        | 2020-06-10 | 1           | 2          |
| 6        | 2020-08-01 | 2           | 1          |
| 7        | 2020-08-01 | 3           | 3          |
| 8        | 2020-08-03 | 1           | 2          |
| 9        | 2020-08-07 | 2           | 3          |
| 10       | 2020-07-15 | 1           | 2          |
+----------+------------+-------------+------------+

Products 表：
+------------+--------------+-------+
| product_id | product_name | price |
+------------+--------------+-------+
| 1          | keyboard     | 120   |
| 2          | mouse        | 80    |
| 3          | screen       | 600   |
| 4          | hard disk    | 450   |
+------------+--------------+-------+
输出：
+-------------+------------+--------------+

示例数据中顾客 2 的三种商品各只买过 1 次（并列），这里按 product_id 较小的 keyboard 返回。
```

## 题解

::: details 点击查看题解

### 思路

"最经常订购"是按订单条数统计，不是按 `quantity`（本表也没有数量列）。所以第一层先按 `(customer_id, product_id)` 分组 `COUNT(*)`，得到每位顾客每个商品的订购次数；第二层再在每位顾客内部按次数倒序排名，取第一名。

坑点在于不能一步到位：`MAX(COUNT(*))` 这种嵌套聚合在 MySQL 里是非法的。常见错误写法是 `GROUP BY customer_id` 后直接 `MAX(COUNT(*))`，或者试图在 `ORDER BY` 里做二次聚合。先聚合、再开窗，是这类"组内取最大值对应行"问题的固定两层结构。

并列的处理要看题目约定。本题保证唯一，所以理论上 `RANK`/`ROW_NUMBER` 都行；但示例数据里顾客 2 三个商品各一次，属于并列，若用 `RANK` 会返回三行。为了与预期输出一致，这里用 `ROW_NUMBER` 并补一个 `product_id ASC` 作为并列时的兜底排序，让结果稳定可复现。最后与 `Products` 连接取出商品名，顾客 5 没有订单自然被排除。

### SQL 实现

```sql
WITH counts AS (
    SELECT customer_id, product_id, COUNT(*) AS cnt
    FROM Orders
    GROUP BY customer_id, product_id
),
ranked AS (
    SELECT customer_id, product_id,
           ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY cnt DESC, product_id ASC) AS rn
    FROM counts
)
SELECT r.customer_id, r.product_id, p.product_name
FROM ranked r
JOIN Products p ON p.product_id = r.product_id
WHERE r.rn = 1
ORDER BY r.customer_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，分组聚合加上窗口排序。
- 空间复杂度：O(m)，m 为顾客与商品组合的数量。

:::
