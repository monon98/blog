# 分别排序两列

> 难度：中等 | 标签：窗口函数、排序 | [LeetCode 原题](https://leetcode.cn/problems/order-two-columns-independently/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Data`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| first_col   | int  |
| second_col  | int  |
+-------------+------+
该表没有主键，每一行是一对整数。
```

要求：把 `first_col` 按升序独立排序、`second_col` 按降序独立排序，然后把两列按行"对齐"组成新的结果表，返回 `first_col`、`second_col` 两列。

**示例 1：**

```
输入：
Data 表：
+-----------+------------+
| first_col | second_col |
+-----------+------------+
| 4         | 2          |
| 2         | 3          |
| 3         | 1          |
| 1         | 4          |
+-----------+------------+
输出：
+-----------+------------+
| first_col | second_col |
+-----------+------------+
| 1         | 4          |
| 2         | 3          |
| 3         | 2          |
| 4         | 1          |
+-----------+------------+
解释：
first_col 升序得到 1、2、3、4；second_col 降序得到 4、3、2、1；两列按行拼接即上述结果。
```

## 题解

::: details 点击查看题解

### 思路

一条 `SELECT` 里的 `ORDER BY` 作用于**整行**，所以不可能让同一行的两列朝相反方向排序。正确做法是把两列当成两份独立的列表：各自排序并打上序号，再按序号对齐拼回去。

窗口函数正好用来造这个序号：`ROW_NUMBER() OVER (ORDER BY first_col)` 得到升序名次，`ROW_NUMBER() OVER (ORDER BY second_col DESC)` 得到降序名次，两个派生表按序号做等值连接即可。因为两列来自同一张表、行数相同，内连接不会丢行也不会放大行数。

坑点：不要用 `SELECT ... ORDER BY first_col, second_col DESC` 试图"分别排序"，那只是整体按 `first_col` 主序、`second_col` 次序排；也不要忘记连接条件，笛卡尔积会得到 n² 行。若某列存在重复值，`ROW_NUMBER` 的编号仍然是 1..n 一一对应，配对结果依旧合法。

### SQL 实现

```sql
WITH first_sorted AS (
    SELECT first_col, ROW_NUMBER() OVER (ORDER BY first_col) AS rn
    FROM Data
),
second_sorted AS (
    SELECT second_col, ROW_NUMBER() OVER (ORDER BY second_col DESC) AS rn
    FROM Data
)
SELECT f.first_col, s.second_col
FROM first_sorted f
JOIN second_sorted s ON s.rn = f.rn
ORDER BY f.rn;
```

### 复杂度分析

- 时间复杂度：O(n log n)，两次窗口排序主导。
- 空间复杂度：O(n)，保存两份带序号的列。

:::
