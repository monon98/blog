# 每天的最大交易

> 难度：中等 | 标签：窗口函数、排名 | [LeetCode 原题](https://leetcode.cn/problems/maximum-transaction-each-day/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Transactions`：

```
+----------------+-------+
| Column Name    | Type  |
+----------------+-------+
| transaction_id | int   |
| day            | date  |
| amount         | int   |
+----------------+-------+
transaction_id 是该表的主键，day 是交易发生的日期，amount 是交易金额。
```

要求：找出**每天金额最大**的那笔交易，如果同一天有多笔交易金额并列最大，全部返回。返回 `transaction_id`、`day`、`amount` 三列，按 `day` 升序排列。

**示例 1：**

```
输入：
Transactions 表：
+----------------+---------------------+--------+
| transaction_id | day                 | amount |
+----------------+---------------------+--------+
| 8              | 2021-04-03 15:57:28 | 57     |
| 9              | 2021-04-28 08:47:25 | 21     |
| 1              | 2021-04-29 13:28:30 | 58     |
| 5              | 2021-04-28 16:39:59 | 40     |
| 6              | 2021-04-29 23:39:28 | 58     |
+----------------+---------------------+--------+
输出：
+----------------+------------+--------+
| transaction_id | day        | amount |
+----------------+------------+--------+
| 8              | 2021-04-03 | 57     |
| 5              | 2021-04-28 | 40     |
| 1              | 2021-04-29 | 58     |
| 6              | 2021-04-29 | 58     |
+----------------+------------+--------+
解释：
04-03 只有一笔交易；04-28 有两笔，取金额 40 的那笔；
04-29 的两笔金额都是 58，并列最大，两笔都要返回。
```

## 题解

::: details 点击查看题解

### 思路

按天分组取最大值对应的行，最直接的是"组内排名"：`PARTITION BY day ORDER BY amount DESC` 之后筛第一名。这里必须用 `RANK`（或 `DENSE_RANK`），不能用 `ROW_NUMBER`：示例中 04-29 的 58 有两笔，`ROW_NUMBER` 只会留一笔，属于典型踩坑点。

还有一个容易忽视的地方是 `day` 的类型。`day` 是 `DATE`，虽然插入语句里写的是 `2021-04-03 15:57:28` 这样的完整时间，MySQL 会把它截断成 `2021-04-03`，因此同一天的交易天然落在同一个 `day` 值上，按 `day` 分区就等价于按天分组。如果 `day` 是 `DATETIME`，就必须先 `DATE(day)` 归一化，否则同一天不同时刻会被当成不同分组，输出也会带上时分秒。

替代写法：先 `GROUP BY day` 求 `MAX(amount)`，再 `JOIN` 回原表匹配金额，也能保留并列（用 `IN`/`EXISTS`），但需要扫两遍表；窗口函数一次排序就够。

### SQL 实现

```sql
WITH ranked AS (
    SELECT transaction_id, day, amount,
           RANK() OVER (PARTITION BY day ORDER BY amount DESC) AS rk
    FROM Transactions
)
SELECT transaction_id, day, amount
FROM ranked
WHERE rk = 1
ORDER BY day, transaction_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，窗口排序主导。
- 空间复杂度：O(n)，保存带名次的交易行。

:::
