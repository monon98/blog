# 第二高的薪水 II

> 难度：中等 | 标签：窗口函数、DENSE_RANK | [LeetCode 原题](https://leetcode.cn/problems/second-highest-salary-ii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Employees` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| emp_id      | int     |
| salary      | int     |
| dept        | varchar |
+-------------+---------+
emp_id 是该表的主键，每一行包含员工 ID、薪水与所属部门。
```

编写一个解决方案，找出 **每个部门中薪水第二高** 的员工：

- 按部门分别看薪水排名，取排名第 2 的薪水；
- 如果同一部门有多人的薪水都等于第二高，**把这些员工全部返回**；
- 部门中不足两个不同薪水时不返回该部门的任何人；
- 返回 `emp_id`、`dept`，按 `emp_id` 升序排序。

**示例 1：**

```
输入：
Employees 表：
+--------+--------+-----------+
| emp_id | salary | dept      |
+--------+--------+-----------+
| 1      | 70000  | Sales     |
| 2      | 80000  | Sales     |
| 3      | 80000  | Sales     |
| 4      | 90000  | Sales     |
| 5      | 55000  | IT        |
| 6      | 65000  | IT        |
| 7      | 65000  | IT        |
| 8      | 50000  | Marketing |
| 9      | 55000  | Marketing |
| 10     | 55000  | HR        |
+--------+--------+-----------+

输出：
+--------+-----------+
| emp_id | dept      |
+--------+-----------+
| 2      | Sales     |
| 3      | Sales     |
| 5      | IT        |
| 8      | Marketing |
+--------+-----------+

解释：
Sales 的最高薪水是 90000，第二高是 80000，员工 2 与 3 并列，都返回；
IT 的最高薪水是 65000（员工 6、7），第二高是 55000，只有员工 5；
Marketing 的最高薪水是 55000，第二高是 50000，返回员工 8；
HR 只有一名员工，不足两个不同薪水，不返回任何行。
```

## 题解

::: details 点击查看题解

### 思路

「每个部门第二高的薪水」加上「并列全部保留」，这两个要求共同指向 `DENSE_RANK()`：按部门分区、薪水降序做密集排名，相同薪水拿到相同名次且不跳号，筛 `rk = 2` 就能把并列第二的人全部取到。

易错点：

- 用 `ROW_NUMBER()` 会让同为 80000 的两个人变成第 2、3 名，只会输出一个，错。
- 用 `RANK()` 在本题数据（90000, 80000, 80000, 70000）上恰好也是 1,2,2,4，筛 2 没问题；但若出现「90000, 90000, 80000」，`RANK` 给出 1,1,3，`rk = 2` 就一个都取不到，而 `DENSE_RANK` 给出 1,1,2，正确。
- 部门只有一个员工时只有第 1 名，天然被 `rk = 2` 过滤，不需要额外判断。

### SQL 实现

```sql
WITH t AS (
    SELECT emp_id, dept,
           DENSE_RANK() OVER (PARTITION BY dept ORDER BY salary DESC) AS rk
    FROM Employees
)
SELECT emp_id, dept
FROM t
WHERE rk = 2
ORDER BY emp_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为员工数，按部门分区排序主导。
- 空间复杂度：O(n)，需要保存每行的密集排名。

:::
