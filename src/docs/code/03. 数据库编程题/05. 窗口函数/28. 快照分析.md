# 快照分析

> 难度：中等 | 标签：分组聚合、条件聚合、多表连接 | [LeetCode 原题](https://leetcode.cn/problems/snaps-analysis/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Activities` 表：

```
+---------------+--------------+
| Column Name   | Type         |
+---------------+--------------+
| activity_id   | int          |
| user_id       | int          |
| activity_type | enum         |
| time_spent    | decimal(5,2) |
+---------------+--------------+
activity_id 具有唯一值；activity_type 是 ('send', 'open') 中的一个，
表示发送还是打开快照；time_spent 为该次活动花费的时间。
```

`Age` 表：

```
+------------+------+
| Column Name| Type |
+------------+------+
| user_id    | int  |
| age_bucket | enum |
+------------+------+
user_id 具有唯一值，age_bucket 是 ('21-25', '26-30', '31-35') 中的一个。
```

编写一个解决方案，计算 **每个年龄段** 花费在发送快照（`send`）和打开快照（`open`）上的 **时间百分比**，百分比四舍五入到小数点后两位。只统计在 `Age` 表中有年龄分组的用户。以任意顺序返回 `age_bucket`、`send_perc`、`open_perc`。

**示例 1：**

```
输入：
Activities 表：
+-------------+---------+---------------+------------+
| activity_id | user_id | activity_type | time_spent |
+-------------+---------+---------------+------------+
| 7274        | 123     | open          | 4.50       |
| 2425        | 123     | send          | 3.50       |
| 1413        | 456     | send          | 5.67       |
| 2536        | 456     | open          | 3.00       |
| 8564        | 456     | send          | 8.24       |
| 5235        | 789     | send          | 6.24       |
| 4251        | 123     | open          | 1.25       |
| 1435        | 789     | open          | 5.25       |
+-------------+---------+---------------+------------+

Age 表：
+---------+------------+
| user_id | age_bucket |
+---------+------------+
| 123     | 31-35      |
| 789     | 21-25      |
| 456     | 26-30      |
+---------+------------+

输出：
+------------+-----------+-----------+
| age_bucket | send_perc | open_perc |
+------------+-----------+-----------+
| 21-25      | 54.31     | 45.69     |
| 26-30      | 82.26     | 17.74     |
| 31-35      | 37.84     | 62.16     |
+------------+-----------+-----------+

解释：
31-35 组只有用户 123：发送 3.50，打开 4.50 + 1.25 = 5.75，总计 9.25，
发送占比 3.50 / 9.25 * 100 = 37.84，打开占比 62.16；
26-30 组只有用户 456：发送 5.67 + 8.24 = 13.91，打开 3.00，总计 16.91；
21-25 组只有用户 789：发送 6.24，打开 5.25，总计 11.49。
```

## 题解

::: details 点击查看题解

### 思路

先把活动表和年龄表按 `user_id` 内连接（题目只统计能确定年龄分组的用户），再用条件聚合一次性算出每个年龄组的两个占比：`SUM(IF(activity_type = 'send', time_spent, 0))` 是发送总时长，`SUM(IF(activity_type = 'open', time_spent, 0))` 是打开总时长，分母统一用 `SUM(time_spent)`。

易错点：

- 分母是「该年龄组所有 send + open 的时长之和」，不是人均时长，也不是全表总时长；正常情况下 `send_perc + open_perc` 应等于 100。
- 不要拆成两次按 `activity_type` 分组的查询再拼接，条件聚合扫一遍表就够了。
- 顺序上要先乘 100 再 `ROUND`，反过来会丢精度；四舍五入保留 2 位。
- `activity_type` 是 `ENUM`，与字符串比较没有问题，但注意拼写是 `'send'` 和 `'open'`。

替代写法：先 `GROUP BY age_bucket, activity_type` 求和，再用 `SUM(CASE WHEN ...)` 或自连接把两行透视成两列，结果一样，代码更长。

### SQL 实现

```sql
SELECT a.age_bucket,
       ROUND(100 * SUM(IF(ac.activity_type = 'send', ac.time_spent, 0)) / SUM(ac.time_spent), 2) AS send_perc,
       ROUND(100 * SUM(IF(ac.activity_type = 'open', ac.time_spent, 0)) / SUM(ac.time_spent), 2) AS open_perc
FROM Activities ac
JOIN Age a ON a.user_id = ac.user_id
GROUP BY a.age_bucket
ORDER BY a.age_bucket;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为活动记录数，一次连接 + 一次分组聚合。
- 空间复杂度：O(1)，只按年龄段保存聚合值。
