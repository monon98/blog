# 连续空余座位

> 难度：简单 | 标签：自连接、相邻判断 | [LeetCode 原题](https://leetcode.cn/problems/consecutive-available-seats/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Cinema`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| seat_id     | int  |
| free        | bool |
+-------------+------+
```

`seat_id` 是自增主键，每行表示该座位是否空闲：`1` 表示空闲，`0` 表示已占用。

请找出所有**连续空闲**的座位——即该座位本身空闲，并且它左边或右边相邻的座位也空闲。返回列 `seat_id`，按 `seat_id` 升序排列。

**示例 1：**

```
输入：
Cinema 表：
+---------+------+
| seat_id | free |
+---------+------+
| 1       | 1    |
| 2       | 0    |
| 3       | 1    |
| 4       | 1    |
| 5       | 1    |
+---------+------+
输出：
+---------+
| seat_id |
+---------+
| 3       |
| 4       |
| 5       |
+---------+
```

解释：3、4、5 号座位连续空闲；1 号座位虽然空闲，但 2 号被占用，所以不满足「相邻座位也空闲」。

## 题解

::: details 点击查看题解

### 思路

把 `Cinema` 和它自己做连接，连接条件写成「座位号相差 1」，再要求两侧 `free` 都为真，就得到了所有「至少有一个空邻居」的空座位。中间座位（示例中的 4 号）会分别与左邻、右邻各匹配一次，所以要 `DISTINCT` 去重，最后按 `seat_id` 排序。

连接条件用 `ABS(a.seat_id - b.seat_id) = 1` 最省事，等价于 `a.seat_id = b.seat_id + 1 OR a.seat_id = b.seat_id - 1`。如果只写 `a.seat_id + 1 = b.seat_id`，那就只能看到右邻居，5 号这种「左边空、右边没座位」的情况会被漏掉。

替代写法是窗口函数：用 `LAG(free)` 和 `LEAD(free)` 把前后座位的状态取到当前行，`free + 相邻状态 = 2` 即说明邻座也空闲；或者用 `SUM(free) OVER (ORDER BY seat_id ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING) > 1` 一次看三连。题目只要求「两侧任一为空」，不需要整段都空。

### SQL 实现

```sql
SELECT DISTINCT c1.seat_id
FROM Cinema AS c1
JOIN Cinema AS c2
  ON ABS(c1.seat_id - c2.seat_id) = 1
 AND c2.free = 1
WHERE c1.free = 1
ORDER BY c1.seat_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，自连接后需要去重排序；若座位号有索引，连接本身接近 O(n)。
- 空间复杂度：O(n)，`DISTINCT` 需要临时空间保存去重结果。

:::
