# 找到连续区间的开始和结束数字

> 难度：中等 | 标签：窗口函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/find-the-start-and-end-number-of-continuous-ranges/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Logs`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| log_id      | int     |
+-------------+---------+
log_id 是该表中具有唯一值的列。
该表的每一行表示一个日志编号，编号可以按数值大小分成若干段连续（步长为 1）的区间。
```

要求：找出 `Logs` 表中所有连续区间的起始编号和结束编号，返回两列 `start_id`、`end_id`，结果按 `start_id` 升序排列。

**示例 1：**

```
输入：
Logs 表：
+--------+
| log_id |
+--------+
| 1      |
| 2      |
| 3      |
| 7      |
| 8      |
| 10     |
+--------+
输出：
+----------+--------+
| start_id | end_id |
+----------+--------+
| 1        | 3      |
| 7        | 8      |
| 10       | 10     |
+----------+--------+
解释：
1、2、3 连续，组成区间 [1, 3]；7、8 连续，组成区间 [7, 8]；10 单独成段，组成区间 [10, 10]。
```

## 题解

::: details 点击查看题解

### 思路

判断"连续"最省事的办法是做差：把编号按升序编号（`ROW_NUMBER()`），如果一段编号的步长恒为 1，那么 `log_id - 行号` 在这个区间里是一个常数；一旦中间断了，差值就会跳到新的值。于是这个差值天然就是"区间分组键"，同一组内取 `MIN`/`MAX` 就得到区间两端。

坑点有两个。一是同一区间的分组键必须稳定，所以要先 `DISTINCT`（官方数据里 `log_id` 唯一，但重复值会让行号错位、把一段切碎）；二是结果要按 `start_id` 排序，而分组键本身没有这个语义，`ORDER BY start_id` 不能省。

替代写法：用 `NOT EXISTS` 找出"没有前驱编号"的行当起点，再用 `LEAD` 往后续到断点；逻辑更直白，但要扫两遍表，MySQL 8 下窗口函数写法更短也更快。

### SQL 实现

```sql
SELECT MIN(log_id) AS start_id,
       MAX(log_id) AS end_id
FROM (
    SELECT log_id,
           log_id - ROW_NUMBER() OVER (ORDER BY log_id) AS grp
    FROM (SELECT DISTINCT log_id FROM Logs) d
) t
GROUP BY grp
ORDER BY start_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，去重与窗口函数的排序占主导。
- 空间复杂度：O(n)，需要保存去重后的行和行号。

:::
