# 数据库编程题（LeetCode SQL）

这里是 LeetCode 数据库（SQL）题目的全量题解，共 323 道：简单 113 / 中等 144 / 困难 66，其中 VIP 专属题 218 道（VIP 题题面根据表结构与测试数据整理，页面有标注）。

与 [力扣算法题库](../01.%20leetcode/) 侧重算法实现不同，本目录聚焦 SQL 查询能力：多表连接、聚合分组、子查询与 CTE、窗口函数、字符串与日期处理、增删改语句等高频考点。每道题包含题目描述、SQL 题解（思路 + MySQL 8 可执行实现）与建表测试数据，题解默认折叠，建议先自己动手实现再对照参考。
