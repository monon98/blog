# 2020年最后一次登录

> 难度：简单 | 标签：日期过滤、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/the-latest-login-in-2020/)

## 题目描述

表: `Logins`

```
+----------------+----------+
| 列名           | 类型      |
+----------------+----------+
| user_id        | int      |
| time_stamp     | datetime |
+----------------+----------+
(user_id, time_stamp) 是这个表的主键(具有唯一值的列的组合)。
每一行包含的信息是user_id 这个用户的登录时间。
```

编写解决方案以获取在 `2020` 年登录过的所有用户的本年度 **最后一次 **登录时间。结果集 **不** 包含 `2020` 年没有登录过的用户。

返回的结果集可以按 **任意顺序 **排列。

返回结果格式如下例。

**示例 1:**

```
输入：
Logins 表:
+---------+---------------------+
| user_id | time_stamp          |
+---------+---------------------+
| 6       | 2020-06-30 15:06:07 |
| 6       | 2021-04-21 14:06:06 |
| 6       | 2019-03-07 00:18:15 |
| 8       | 2020-02-01 05:10:53 |
| 8       | 2020-12-30 00:46:50 |
| 2       | 2020-01-16 02:49:50 |
| 2       | 2019-08-25 07:59:08 |
| 14      | 2019-07-14 09:00:00 |
| 14      | 2021-01-06 11:59:59 |
+---------+---------------------+
输出：
+---------+---------------------+
| user_id | last_stamp          |
+---------+---------------------+
| 6       | 2020-06-30 15:06:07 |
| 8       | 2020-12-30 00:46:50 |
| 2       | 2020-01-16 02:49:50 |
+---------+---------------------+
解释：
6号用户登录了3次，但是在2020年仅有一次，所以结果集应包含此次登录。
8号用户在2020年登录了2次，一次在2月，一次在12月，所以，结果集应该包含12月的这次登录。
2号用户登录了2次，但是在2020年仅有一次，所以结果集应包含此次登录。
14号用户在2020年没有登录，所以结果集不应包含。
```

## 题解

::: details 点击查看题解

### 思路

题意是「2020 年内所有用户各自最后一次登录时间」，所以聚合前必须先过滤年份。直接用 `MAX(time_stamp)` 分组后再筛年份是错的：用户 6 的全局最后登录是 2021-04-21，会被误判为合格，而正确答案应该是 2020-06-30。

年份过滤用左闭右开区间（大于等于 2020-01-01 且小于 2021-01-01）比 `YEAR(time_stamp) = 2020` 更好：前者能利用索引、且不受列上函数影响；后者对列做函数运算，索引失效。

过滤之后按 `user_id` 分组取 `MAX(time_stamp)` 就得到每人最后一次登录。2020 年没有登录的用户（示例里的 14）在 `WHERE` 阶段就被排除，不需要额外处理。

还要注意 `time_stamp` 是 `datetime` 而不是 `date`，别用 `DATE(time_stamp)` 去比较日期字符串，那样会把当天时刻信息抹掉，`MAX` 出来就不再是「最后一次」的精确时间了。

### SQL 实现

```sql
SELECT user_id, MAX(time_stamp) AS last_stamp
FROM Logins
WHERE time_stamp >= '2020-01-01' AND time_stamp < '2021-01-01'
GROUP BY user_id
ORDER BY user_id;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为登录记录数（有索引时可用索引扫描 + 分组）。
- 空间复杂度：O(m)，m 为 2020 年登录过的用户数。
