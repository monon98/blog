# 每个帖子的评论数

> 难度：简单 | 标签：自连接、去重计数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/number-of-comments-per-post/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Submissions` 表：

```
+------------+---------+
| Column Name | Type   |
+------------+---------+
| sub_id     | int    |
| parent_id  | int    |
+------------+---------+
该表没有主键，可能包含重复行。
每一行表示一条提交（帖子或评论）：
- 当 parent_id 为 NULL 时，sub_id 是一个帖子的编号；
- 当 parent_id 不为 NULL 时，这一行是一条评论，parent_id 是它所属帖子的编号。
注意 sub_id 自身不唯一，同一个编号可能出现多次（重复提交），评论也可能重复出现。
```

编写一个 SQL 查询，统计 **每个帖子** 的评论数，返回列 `post_id` 与 `number_of_comments`，结果按 `post_id` 升序排列。

- 必须列出所有（去重后的）帖子，即使它一条评论都没有，评论数记 0。
- 评论按 `sub_id` 去重计数：同一条评论重复出现多次只算一条。
- 若某条评论的 `parent_id` 指向的不是一个帖子（例如样本中 `parent_id = 7` 但没有 7 号帖子），忽略它。

**示例 1：**

```
输入：
Submissions table:
+---------+-----------+
| sub_id  | parent_id |
+---------+-----------+
| 1       | NULL      |
| 2       | NULL      |
| 1       | NULL      |
| 12      | NULL      |
| 3       | 1         |
| 5       | 2         |
| 3       | 1         |
| 4       | 1         |
| 9       | 1         |
| 10      | 2         |
| 6       | 7         |
+---------+-----------+
输出：
+---------+--------------------+
| post_id | number_of_comments |
+---------+--------------------+
| 1       | 3                  |
| 2       | 2                  |
| 12      | 0                  |
+---------+--------------------+
解释：
帖子有 1、2、12 三个（1 号重复出现两次，去重后只算一个）。
1 号帖子的评论是 3、4、9（3 号评论重复两次，只算一条），共 3 条。
2 号帖子的评论是 5、10，共 2 条。
12 号帖子没有评论，记 0。
6 号评论的 parent_id 为 7，但 7 不是帖子，忽略。
```

## 题解

::: details 点击查看题解

### 思路

第一步先把帖子集合从明细里「提炼」出来：`SELECT DISTINCT sub_id FROM Submissions WHERE parent_id IS NULL`，去重是因为同一条帖子可能被插入多次。第二步用这个帖子集合去 `LEFT JOIN` 原表，连接条件是 `c.parent_id = p.sub_id`，这样没有评论的帖子也能保留下来。

计数要用 `COUNT(DISTINCT c.sub_id)`。样本里 `(3, 1)` 出现两次，若用 `COUNT(*)` 会把重复评论算成两条；用 `COUNT(c.sub_id)` 也只是跳过 NULL，去不了重，所以必须加 `DISTINCT`。`LEFT JOIN` 之后没有评论的帖子对应一行 `c.*` 全 NULL，`COUNT` 恰好返回 0，符合「无评论记 0」。

`parent_id = 7` 那条评论在做连接时因为不存在 7 号帖子而自然被排除，不需要额外过滤——这体现的是「以帖子为主表」而非「以评论为主表」的方向选择。若反过来从评论出发再分组，就会漏掉 0 评论的帖子。

### SQL 实现

```sql
SELECT p.sub_id AS post_id,
       COUNT(DISTINCT c.sub_id) AS number_of_comments
FROM (
    SELECT DISTINCT sub_id
    FROM Submissions
    WHERE parent_id IS NULL
) p
LEFT JOIN Submissions c ON c.parent_id = p.sub_id
GROUP BY p.sub_id
ORDER BY post_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为 `Submissions` 行数，去重与连接可借助排序/哈希。
- 空间复杂度：O(p + c)，p 为帖子数、c 为评论数，用于保存帖子集合与连接中间结果。

:::
