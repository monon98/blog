# 各赛事的用户注册率

> 难度：简单 | 标签：分组聚合、子查询、ROUND | [LeetCode 原题](https://leetcode.cn/problems/percentage-of-users-attended-a-contest/)

## 题目描述

用户表： `Users`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| user_name   | varchar |
+-------------+---------+
user_id 是该表的主键(具有唯一值的列)。
该表中的每行包括用户 ID 和用户名。
```

注册表： `Register`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| contest_id  | int     |
| user_id     | int     |
+-------------+---------+
(contest_id, user_id) 是该表的主键(具有唯一值的列的组合)。
该表中的每行包含用户的 ID 和他们注册的赛事。
```

编写解决方案统计出各赛事的用户注册百分率，保留两位小数。

返回的结果表按 `percentage` 的 **降序 **排序，若相同则按 `contest_id` 的 **升序 **排序。

返回结果如下示例所示。

**示例 1：**

```
输入：
Users 表：
+---------+-----------+
| user_id | user_name |
+---------+-----------+
| 6       | Alice     |
| 2       | Bob       |
| 7       | Alex      |
+---------+-----------+

Register 表：
+------------+---------+
| contest_id | user_id |
+------------+---------+
| 215        | 6       |
| 209        | 2       |
| 208        | 2       |
| 210        | 6       |
| 208        | 6       |
| 209        | 7       |
| 209        | 6       |
| 215        | 7       |
| 208        | 7       |
| 210        | 2       |
| 207        | 2       |
| 210        | 7       |
+------------+---------+
输出：
+------------+------------+
| contest_id | percentage |
+------------+------------+
| 208        | 100.0      |
| 209        | 100.0      |
| 210        | 100.0      |
| 215        | 66.67      |
| 207        | 33.33      |
+------------+------------+
解释：
所有用户都注册了 208、209 和 210 赛事，因此这些赛事的注册率为 100% ，我们按 contest_id 的升序排序加入结果表中。
Alice 和 Alex 注册了 215 赛事，注册率为 ((2/3) * 100) = 66.67%
Bob 注册了 207 赛事，注册率为 ((1/3) * 100) = 33.33%
```

## 题解

::: details 点击查看题解

### 思路

注册率 = 该赛事的注册人数 / 全站用户总数 × 100。分母是「所有用户」，与赛事无关，所以用一个标量子查询 `(SELECT COUNT(*) FROM Users)` 取一次即可，不要把它写进 `GROUP BY`，否则分母会跟着分组一起被切碎。

`Register` 的主键是 `(contest_id, user_id)`，因此每个用户在同一个赛事里最多出现一次，`COUNT(*)` 与 `COUNT(DISTINCT user_id)` 等价；如果表结构没有这个约束，就该写成 `COUNT(DISTINCT user_id)` 更保险。

保留两位小数用 `ROUND(..., 2)`。注意乘法顺序：先 `COUNT(*) * 100` 再除以总人数，避免先做除法时因精度截断影响四舍五入。MySQL 的 `/` 返回小数，不会像某些数据库那样做整数除法，但仍建议显式乘 100 让语义更清楚。

排序用了两个键：`percentage DESC`、`contest_id ASC`。示例里 208、209、210 三个赛事都是 100%，正是靠第二个排序键才排出升序；别名可以直接出现在 `ORDER BY` 中（MySQL 支持），但同样不能出现在 `WHERE` 里。

### SQL 实现

```sql
SELECT contest_id,
       ROUND(COUNT(*) * 100 / (SELECT COUNT(*) FROM Users), 2) AS percentage
FROM Register
GROUP BY contest_id
ORDER BY percentage DESC, contest_id ASC;
```

### 复杂度分析

- 时间复杂度：O(n + m)，n 为注册记录数、m 为用户数。
- 空间复杂度：O(k)，k 为赛事数。

:::
