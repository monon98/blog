# 电影评分

> 难度：中等 | 标签：分组聚合、排序取优、子查询 | [LeetCode 原题](https://leetcode.cn/problems/movie-rating/)

## 题目描述

表：`Movies`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| movie_id      | int     |
| title         | varchar |
+---------------+---------+
movie_id 是这个表的主键(具有唯一值的列)。
title 是电影的名字。
每部电影都有一个唯一的 title。
```

表：`Users`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| user_id       | int     |
| name          | varchar |
+---------------+---------+
user_id 是表的主键(具有唯一值的列)。
'name' 列具有唯一值。
```

表：`MovieRating`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| movie_id      | int     |
| user_id       | int     |
| rating        | int     |
| created_at    | date    |
+---------------+---------+
(movie_id, user_id) 是这个表的主键(具有唯一值的列的组合)。
这个表包含用户在其评论中对电影的评分 rating 。
created_at 是用户的点评日期。
```

请你编写一个解决方案：

	- 查找评论电影数量最多的用户名。如果出现平局，返回字典序较小的用户名。

	- 查找在 February 2020 平均评分最高 的电影名称。如果出现平局，返回字典序较小的电影名称。

**字典序** ，即按字母在字典中出现顺序对字符串排序，字典序较小则意味着排序靠前。

返回结果格式如下例所示。

**示例 1：**

## 题解

::: details 点击查看题解

### 思路

题目要求两次独立的「取第一名」，最直观的做法是写两段查询再纵向拼起来，输出统一使用列名 `results`。

第一段按用户分组统计评论条数：`GROUP BY u.user_id, u.name` 后 `COUNT(*)` 即该用户点评过的电影数。由于 `(movie_id, user_id)` 是主键，一个用户对同一部电影只会有一条评分，所以直接 `COUNT(*)` 就是电影部数。排序规则是「数量降序、名字升序」，取 `LIMIT 1` 就同时解决了并列时取字典序较小者的问题。

第二段先过滤出 `2020-02` 的评分，用 `created_at >= '2020-02-01' AND created_at < '2020-03-01'` 而不是 `LIKE '2020-02%'` 或 `DATE_FORMAT`，这样能走索引。然后按电影分组求 `AVG(rating)`，同样按「平均分降序、片名升序」排序取第一条。注意 3 月 1 日的评分不能算进 2 月，这是样本里特意埋的边界。

两段各自放在带 `ORDER BY ... LIMIT 1` 的派生表里，再用 `UNION ALL` 拼接。不要用 `UNION`（去重没有必要），也不要把两段的 `ORDER BY` 提到最外层——那样只会对合并后的两行排序，取不到各自的第一名。

### SQL 实现

```sql
SELECT results
FROM (
    SELECT u.name AS results
    FROM MovieRating mr
    JOIN Users u ON u.user_id = mr.user_id
    GROUP BY u.user_id, u.name
    ORDER BY COUNT(*) DESC, u.name ASC
    LIMIT 1
) top_user

UNION ALL

SELECT results
FROM (
    SELECT m.title AS results
    FROM MovieRating mr
    JOIN Movies m ON m.movie_id = mr.movie_id
    WHERE mr.created_at >= '2020-02-01'
      AND mr.created_at < '2020-03-01'
    GROUP BY m.movie_id, m.title
    ORDER BY AVG(mr.rating) DESC, m.title ASC
    LIMIT 1
) top_movie;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为评分记录数，两段查询各需一次分组与排序。
- 空间复杂度：O(u + m)，u 为用户数、m 为电影数，用于保存分组结果。
