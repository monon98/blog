# 只出现一次的最大数字

> 难度：简单 | 标签：分组聚合、子查询 | [LeetCode 原题](https://leetcode.cn/problems/biggest-single-number/)

## 题目描述

`MyNumbers` 表：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| num         | int  |
+-------------+------+
该表可能包含重复项（换句话说，在SQL中，该表没有主键）。
这张表的每一行都含有一个整数。
```

**单一数字** 是在 `MyNumbers` 表中只出现一次的数字。

找出最大的 **单一数字** 。如果不存在 **单一数字** ，则返回 `null` 。

查询结果如下例所示。

**示例 1：**

```
输入：
MyNumbers 表：
+-----+
| num |
+-----+
| 8   |
| 8   |
| 3   |
| 3   |
| 1   |
| 4   |
| 5   |
| 6   |
+-----+
输出：
+-----+
| num |
+-----+
| 6   |
+-----+
解释：单一数字有 1、4、5 和 6 。
6 是最大的单一数字，返回 6 。
```

**示例 2：**

```
输入：
MyNumbers table:
+-----+
| num |
+-----+
| 8   |
| 8   |
| 7   |
| 7   |
| 3   |
| 3   |
| 3   |
+-----+
输出：
+------+
| num  |
+------+
| null |
+------+
解释：输入的表中不存在单一数字，所以返回 null 。
```

## 题解

::: details 点击查看题解

### 思路

两步走：先按 `num` 分组、用 `HAVING COUNT(*) = 1` 筛出「只出现一次」的数字，再在这批数字里取最大值。第二步有两种常见写法——直接 `SELECT MAX(num) FROM (子查询)`，或在外层加 `ORDER BY num DESC LIMIT 1`。这里推荐前者，因为 `MAX` 对空集返回 `NULL`，天然满足「不存在单一数字时返回 null」的要求。

易错点有两个。其一，如果把 `MAX` 写在内层 `SELECT MAX(num) ... GROUP BY num HAVING ...`，得到的是每个单次数字各自的最大值（即它们本身），外层不套聚合就无法在无结果时输出一行 `null`，示例 2 会返回空结果集。其二，`HAVING` 里写 `COUNT(num) = 1` 或 `COUNT(*) = 1` 都可以（`num` 不会为 NULL），但不能漏掉去重语义之外的条件——本题统计的是出现次数，不需要 `DISTINCT`。

替代写法：用窗口函数 `DENSE_RANK() OVER (ORDER BY num DESC)` 配合 `COUNT(*) OVER (PARTITION BY num)` 一次筛出，或先 `GROUP BY num` 再 `ORDER BY COUNT(*) , num DESC LIMIT 1`（后者逻辑不对，需注意先过滤再排序）。

### SQL 实现

```sql
SELECT MAX(num) AS num
FROM (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(*) = 1
) t;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为表行数，分组计数接近线性，外层 MAX 为线性扫描。
- 空间复杂度：O(k)，k 为不同数字的个数，分组哈希表开销。
