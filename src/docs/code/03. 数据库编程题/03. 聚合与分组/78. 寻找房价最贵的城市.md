# 寻找房价最贵的城市

> 难度：简单 | 标签：分组聚合、子查询 | [LeetCode 原题](https://leetcode.cn/problems/find-expensive-cities/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Listings`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| listing_id  | int     |
| city        | varchar |
| price       | int     |
+-------------+---------+
listing_id 是这张表具有唯一值的列。
这张表包括 listing_id、city 和 price。
```

编写一个解决方案，查找 **房价平均值** 超过 **全国** 平均房价的城市。返回按 `city` 升序排序的结果表。结果格式如下例所示。

**示例 1：**

输入：

```
Listings table:
+------------+--------------+---------+
| listing_id | city         | price   |
+------------+--------------+---------+
| 113        | LosAngeles   | 7560386 |
| 136        | SanFrancisco | 2380268 |
| 92         | Chicago      | 9833209 |
| 60         | Chicago      | 5147582 |
| 8          | Chicago      | 5274441 |
| 79         | SanFrancisco | 8372065 |
| 37         | Chicago      | 7939595 |
| 53         | LosAngeles   | 4965123 |
| 178        | SanFrancisco | 999207  |
| 51         | NewYork      | 5951718 |
| 121        | NewYork      | 2893760 |
+------------+--------------+---------+
```

输出：

```
+------------+
| city       |
+------------+
| Chicago    |
| LosAngeles |
+------------+
```

解释：

- 全国平均房价为 $6,122,059.45。在列出的城市中：
  - Chicago 的平均价格为 $7,048,706.75
  - Los Angeles 的平均价格为 $6,277,754.5
  - San Francisco 的平均价格为 $3,900,513.33
  - New York 的平均价格为 $4,422,739
- 只有 Chicago 和 Los Angeles 的平均房价超过了全国平均水平。因此，这两个城市包含在输出表中。输出表按城市名称升序排序。

## 题解

::: details 点击查看题解

### 思路

比较的对象是「城市均价」和「全国均价」，两者都来自同一张表，但计算粒度不同：前者按 `city` 分组，后者是全表一条。SQL 里 `HAVING` 子句可以引用聚合结果，而全国均价用标量子查询 `(SELECT AVG(price) FROM Listings)` 即可——它对全表只算一次，与外层的分组互不干扰。

两个易错点：一是**全国均价不能按城市算**，若把子查询也写成按 city 分组，就变成城市自己和自己比，永远筛不出任何行；二是比较必须放在 `HAVING` 而不是 `WHERE`，`WHERE` 里不能出现 `AVG(...)` 这类聚合函数，会直接报错。

注意全国均价是把所有挂牌求平均（不是先求各城均价再平均），示例中的 6,122,059.45 正是 11 条记录的总和除以 11。最后按 `city` 升序输出即可。

### SQL 实现

```sql
SELECT city
FROM Listings
GROUP BY city
HAVING AVG(price) > (SELECT AVG(price) FROM Listings)
ORDER BY 1;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为 Listings 行数，主查询与标量子查询各扫一遍表。
- 空间复杂度：O(c)，c 为城市数量，分组结果每城一行。
