# 大满贯数量

> 难度：中等 | 标签：UNION ALL、多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/grand-slam-titles/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Players`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| player_id   | int     |
| player_name | varchar |
+-------------+---------+
player_id 是此表中具有唯一值的列。
每一行包含一名网球选手的 id 和姓名。
```

表：`Championships`

```
+-----------+------+
| Column Name| Type |
+-----------+------+
| year       | int  |
| Wimbledon  | int  |
| Fr_open    | int  |
| US_open    | int  |
| Au_open    | int  |
+-----------+------+
year 是此表中具有唯一值的列。
每一行表示一届四大满贯赛事，四列分别记录温网、法网、美网、澳网的**冠军选手 id**。
四列都是 `Players` 表中的 `player_id`。
```

编写一个解决方案，统计每位选手获得的大满贯冠军总数。

返回结果表包含 `player_id`、`player_name` 和 `grand_slams_count`；从未夺冠的选手也要列出，数量为 0。

返回结果表**无顺序要求**。

**示例 1：**

输入：

```
Players table:
+-----------+-------------+
| player_id | player_name |
+-----------+-------------+
| 1         | Nadal       |
| 2         | Federer     |
| 3         | Novak       |
+-----------+-------------+

Championships table:
+------+-----------+---------+---------+---------+
| year | Wimbledon | Fr_open | US_open | Au_open |
+------+-----------+---------+---------+---------+
| 2018 | 1         | 1       | 1       | 1       |
| 2019 | 1         | 1       | 2       | 2       |
| 2020 | 2         | 1       | 2       | 2       |
+------+-----------+---------+---------+---------+
```

输出：

```
+-----------+-------------+-------------------+
| player_id | player_name | grand_slams_count |
+-----------+-------------+-------------------+
| 1         | Nadal       | 7                 |
| 2         | Federer     | 5                 |
| 3         | Novak       | 0                 |
+-----------+-------------+-------------------+
```

解释：

- Nadal（1）在 2018 年包揽四项，2019 年拿下温网和法网，2020 年拿下法网，共 7 冠。
- Federer（2）在 2019 年拿到美网和澳网，2020 年拿到温网、美网和澳网，共 5 冠。
- Novak（3）没有出现在任何冠军列中，冠军数为 0。

## 题解

::: details 点击查看题解

### 思路

难点是「横向」的四列冠军需要变成「纵向」的明细：每位冠军是长表里的一行。用四个 `SELECT` 各取一列再 `UNION ALL`（每个冠军单元格就是一条记录），就能得到 `(player_id)` 的长表，然后按选手计数。这里不需要 `contest_id` 之类的额外字段，只要计数。

必须以 `Players` 为左表做 `LEFT JOIN`，否则 0 冠选手（Novak）会被内连接直接筛掉——题目明确要求列出所有选手。

最经典的坑是计数方式：`COUNT(*)` 在左连接未匹配时也会数 1（因为右表补出来的一行也算一行），结果把 0 冠选手算成 1 冠；必须写成 `COUNT(w.player_id)`，`COUNT(列)` 不统计 NULL，才能得到 0。

另一种思路是先把长表按 `player_id` 分组计数，再 `RIGHT JOIN` / 反向 `LEFT JOIN` 回 `Players`；思路一致，但要注意补 NULL 后同样得用 `IFNULL(计数, 0)`。`UNION ALL` 与 `UNION` 在这题结果相同（同一人同一列不会重复），但 `UNION ALL` 少一次去重，更快。

### SQL 实现

```sql
SELECT p.player_id,
       p.player_name,
       COUNT(w.player_id) AS grand_slams_count
FROM Players p
LEFT JOIN (
    SELECT Wimbledon AS player_id FROM Championships
    UNION ALL SELECT Fr_open  FROM Championships
    UNION ALL SELECT US_open  FROM Championships
    UNION ALL SELECT Au_open  FROM Championships
) w ON w.player_id = p.player_id
GROUP BY p.player_id, p.player_name
ORDER BY p.player_id;
```

### 复杂度分析

- 时间复杂度：O(n + m)，n 为 `Championships` 行数（展开成 4n 条记录）、m 为选手数。
- 空间复杂度：O(m)，结果每个选手一行。
