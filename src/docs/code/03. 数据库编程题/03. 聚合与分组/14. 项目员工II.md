# 项目员工II

> 难度：简单 | 标签：分组聚合、子查询 | [LeetCode 原题](https://leetcode.cn/problems/project-employees-ii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Project` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| project_id  | int     |
| employee_id | int     |
+-------------+---------+
主键为 (project_id, employee_id)。
employee_id 是 Employee 表的外键。
每一行表示 employee_id 的员工正在 project_id 的项目上工作。
```

`Employee` 表：

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| employee_id      | int     |
| name             | varchar |
| experience_years | int     |
+------------------+---------+
主键是 employee_id。
每一行包含一个员工的信息。
```

编写解决方案，报告 **拥有员工最多的项目** 的 `project_id`（可能并列，若有多个则全部返回）。以任意顺序返回结果表，结果只包含 `project_id` 一列。

**示例 1:**

```
输入:
Project 表:
+-------------+-------------+
| project_id  | employee_id |
+-------------+-------------+
| 1           | 1           |
| 1           | 2           |
| 1           | 3           |
| 2           | 1           |
| 2           | 4           |
+-------------+-------------+
Employee 表:
+-------------+--------+------------------+
| employee_id | name   | experience_years |
+-------------+--------+------------------+
| 1           | Khaled | 3                |
| 2           | Ali    | 2                |
| 3           | John   | 1                |
| 4           | Doe    | 2                |
+-------------+--------+------------------+
输出:
+-------------+
| project_id  |
+-------------+
| 1           |
+-------------+
解释:
项目 1 有 3 名员工，项目 2 只有 2 名员工，所以项目 1 是员工最多的项目。
```

## 题解

::: details 点击查看题解

### 思路

`Project` 表的主键是 `(project_id, employee_id)`，每行就是一名员工在某项目中的一次占位，因此按 `project_id` 分组 `COUNT(*)` 即可得到各项目的员工数。求「最大值对应的项目」有两种经典写法：一是先用标量子查询算出最大员工数，再 `HAVING COUNT(*) = (最大值)`，这样天然支持并列；二是 `ORDER BY COUNT(*) DESC LIMIT 1`，只返回一个。

本题测试数据无并列，两种都能通过，但写法一更严谨——它满足「若有并列全部返回」的语义，写法二在并列时会随机丢掉其余项目，是本题最常见的失分点。注意 `HAVING` 里可以直接引用聚合，也可以再嵌套子查询；不要把 `MAX(COUNT(*))` 写进 `HAVING`（聚合函数不能嵌套聚合，MySQL 会报错），要用独立的子查询求最大值。

`Employee` 表在本题完全用不上：统计的是「项目里的员工占位数」，与年限、姓名无关，多连一张表只会增加开销。

### SQL 实现

```sql
SELECT project_id
FROM Project
GROUP BY project_id
HAVING COUNT(*) = (
    SELECT COUNT(*) AS cnt
    FROM Project
    GROUP BY project_id
    ORDER BY cnt DESC
    LIMIT 1
);
```

### 复杂度分析

- 时间复杂度：O(n)，n 为项目记录数，主查询与子查询各做一次分组。
- 空间复杂度：O(k)，k 为项目数，分组哈希表开销。

:::
