# 将工资相同的雇员分组

> 难度：中等 | 标签：窗口函数、分组聚合、子查询 | [LeetCode 原题](https://leetcode.cn/problems/group-employees-of-the-same-salary/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Employees`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| employee_id | int     |
| name        | varchar |
| salary      | int     |
+-------------+---------+
employee_id 是此表中具有唯一值的列。
每一行包含员工的 id、姓名和工资。
```

编写一个解决方案，把工资相同的员工分到同一组：

- 只有**至少有两名员工**的工资才需要成组，独一无二的工资不输出；
- 组号 `team_id` 从 1 开始，按工资**升序**依次编号；
- 输出 `employee_id`、`name`、`salary`、`team_id`，按 `team_id` 升序、`employee_id` 升序排列。

**示例 1：**

输入：

```
Employees table:
+-------------+---------+--------+
| employee_id | name    | salary |
+-------------+---------+--------+
| 2           | Meir    | 3000   |
| 3           | Michael | 3000   |
| 7           | Addilyn | 7400   |
| 8           | Juan    | 6100   |
| 9           | Kannon  | 7400   |
+-------------+---------+--------+
```

输出：

```
+-------------+---------+--------+---------+
| employee_id | name    | salary | team_id |
+-------------+---------+--------+---------+
| 2           | Meir    | 3000   | 1       |
| 3           | Michael | 3000   | 1       |
| 7           | Addilyn | 7400   | 2       |
| 9           | Kannon  | 7400   | 2       |
+-------------+---------+--------+---------+
```

解释：

- 工资 3000 有两人，成组并编号 1。
- 工资 7400 有两人，成组并编号 2。
- 工资 6100 只有 Juan 一人，不输出。

## 题解

::: details 点击查看题解

### 思路

先用子查询筛出「够格成组」的工资：`GROUP BY salary HAVING COUNT(*) >= 2`，把只有一个人的 6100 排除掉，否则 Juan 会单独占一个组号。

编号用窗口函数 `DENSE_RANK() OVER (ORDER BY salary)`。注意必须是 `DENSE_RANK`：`ROW_NUMBER` 会把同工资的两个人编成不同组号；`RANK` 在同工资并列后会让下一个组号跳号（7400 会变成 3 而不是 2）。这题的组号本质是「不同工资值的序号」，只有 `DENSE_RANK` 符合。

因为有窗口函数，`WHERE` 不能直接写在同一个 `SELECT` 里参与筛选（窗口函数在 `WHERE` 之后才计算），所以把「工资至少出现两次」的判断放在 `IN` 子查询里；这样窗口函数的输入已经过滤干净，编号天然连续。

排序按 `team_id` 再按 `employee_id`，同组内员工按 id 升序；两个都是 `SELECT` 别名，MySQL 允许在 `ORDER BY` 中引用别名。如果想完全避开窗口函数，也可用 `COUNT(DISTINCT salary) WHERE salary <= 当前工资` 的相关子查询算组号，但性能与可读性都更差。

### SQL 实现

```sql
SELECT employee_id,
       name,
       salary,
       DENSE_RANK() OVER (ORDER BY salary) AS team_id
FROM Employees
WHERE salary IN (
    SELECT salary FROM Employees GROUP BY salary HAVING COUNT(*) >= 2
)
ORDER BY team_id, employee_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为员工数，主要开销是窗口函数排序。
- 空间复杂度：O(n)，结果最多 n 行。
