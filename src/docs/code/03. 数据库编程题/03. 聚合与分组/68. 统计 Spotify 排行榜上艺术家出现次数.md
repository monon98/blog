# 统计 Spotify 排行榜上艺术家出现次数

> 难度：简单 | 标签：分组聚合、排序 | [LeetCode 原题](https://leetcode.cn/problems/count-artist-occurrences-on-spotify-ranking-list/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

榜单表 `Spotify`：

```
+------------+---------+
| 列名       | 类型    |
+------------+---------+
| id         | int     |
| track_name | varchar |
| artist     | varchar |
+------------+---------+
id 是该表的主键。
每一行包含歌曲编号、歌曲名和艺术家名称。
```

请编写一个解决方案，查找每个艺术家在榜单上出现的次数。结果表包含艺术家名称与相应出现次数，按出现次数**降序**排列；次数相同时按艺术家名称**升序**排列。

**示例 1：**

```
输入：
Spotify 表：
+---------+--------------------+------------+
| id      | track_name         | artist     |
+---------+--------------------+------------+
| 303651  | Heart Won't Forget | Ed Sheeran |
| 1046089 | Shape of you       | Sia        |
| 33445   | I'm the one        | DJ Khalid  |
| 811266  | Young Dumb & Broke | DJ Khalid  |
| 505727  | Happier            | Ed Sheeran |
+---------+--------------------+------------+

输出：
+------------+-------------+
| artist     | occurrences |
+------------+-------------+
| DJ Khalid  | 2           |
| Ed Sheeran | 2           |
| Sia        | 1           |
+------------+-------------+

解释：DJ Khalid 与 Ed Sheeran 都出现 2 次，按名称升序 DJ Khalid 在前；Sia 出现 1 次排在最后。
```

## 题解

::: details 点击查看题解

### 思路

最基础的按艺术家分组计数：GROUP BY artist 配 COUNT(*) 就得到每位艺术家在榜单上出现的次数。

排序有两个键：出现次数降序；次数相同时艺术家名称升序。ORDER BY occurrences DESC, artist 即可，MySQL 允许直接引用 SELECT 别名。

注意 artist 是 varchar，相等判断与排序都按字符集比较，写别名排序时不要再套一次 COUNT(*)，否则可读性差且容易写错方向。

### SQL 实现

```sql
SELECT artist,
       COUNT(*) AS occurrences
FROM Spotify
GROUP BY artist
ORDER BY occurrences DESC, artist;
```

### 复杂度分析

- 时间复杂度：O(n log n)，分组后排序，n 为榜单记录数
- 空间复杂度：O(k)，k 为不同艺术家数量

:::
