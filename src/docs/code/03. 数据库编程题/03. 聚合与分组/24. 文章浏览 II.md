# 文章浏览 II

> 难度：中等 | 标签：分组聚合、去重计数、HAVING | [LeetCode 原题](https://leetcode.cn/problems/article-views-ii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Views` 表：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| article_id    | int     |
| author_id     | int     |
| viewer_id    | int     |
| view_date     | date    |
+---------------+---------+
该表没有主键，可能存在重复行。
每一行表示某个读者（viewer_id）在某一天（view_date）浏览了某篇文章（article_id）。
同一篇文章也可能被同一个读者在同一天浏览多次（产生重复行）。
```

编写一个 SQL 查询，找出 **同一天浏览了不止一篇文章** 的所有读者，结果列名为 `id`，可以按任意顺序返回。

- 只统计不同文章的篇数，同一篇文章当天浏览多次只算一篇。
- 结果需要去重：一个读者若有多天满足条件，也只输出一次。

**示例 1：**

```
输入：
Views table:
+------------+-----------+-----------+------------+
| article_id | author_id | viewer_id | view_date  |
+------------+-----------+-----------+------------+
| 1          | 3         | 5         | 2019-08-01 |
| 3          | 4         | 5         | 2019-08-01 |
| 1          | 3         | 6         | 2019-08-02 |
| 2          | 7         | 7         | 2019-08-01 |
| 2          | 7         | 6         | 2019-08-02 |
| 4          | 7         | 1         | 2019-07-22 |
| 3          | 4         | 4         | 2019-07-21 |
| 3          | 4         | 4         | 2019-07-21 |
+------------+-----------+-----------+------------+
输出：
+------+
| id   |
+------+
| 5    |
| 6    |
+------+
解释：
读者 5 在 2019-08-01 浏览了文章 1 和 3，两篇不同文章，满足条件。
读者 6 在 2019-08-02 浏览了文章 1 和 2，满足条件。
读者 7 在 2019-08-01 只浏览了文章 2，不满足。
读者 4 在 2019-07-21 两次浏览的都是文章 3，只算一篇，不满足。
```

## 题解

::: details 点击查看题解

### 思路

判定条件是「同一个读者 + 同一天」，所以分组键必须是 `(viewer_id, view_date)`，两个维度缺一不可：只按 `viewer_id` 分组会把不同日期的浏览量累加，得出「这个读者总共看过几篇文章」；只按 `view_date` 分组则把所有人的浏览混在一起。

组内统计文章种数要用 `COUNT(DISTINCT article_id)`。样本中读者 4 在 `2019-07-21` 有两行记录，但都是文章 3，如果写成 `COUNT(*) > 1` 就会把它误判成合格读者。这正是本题唯一的坑。

外层再套一个 `DISTINCT viewer_id`（或 `SELECT DISTINCT viewer_id ... GROUP BY viewer_id, view_date`）保证一个读者只出现一次。结果列名按题目要求起别名为 `id`，若需要稳定输出可加 `ORDER BY id`。

### SQL 实现

```sql
SELECT DISTINCT viewer_id AS id
FROM Views
GROUP BY viewer_id, view_date
HAVING COUNT(DISTINCT article_id) > 1
ORDER BY id;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为 `Views` 行数，按「读者 + 日期」哈希分组。
- 空间复杂度：O(g)，g 为「读者 × 日期」组合数。

:::
