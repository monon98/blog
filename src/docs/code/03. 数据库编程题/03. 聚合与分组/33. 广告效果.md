# 广告效果

> 难度：简单 | 标签：条件聚合、数值计算 | [LeetCode 原题](https://leetcode.cn/problems/ads-performance/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Ads` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| ad_id       | int     |
| user_id     | int     |
| action      | enum    |
+-------------+---------+
(ad_id, user_id) 是该表的主键，action 取值为 ('Clicked', 'Viewed', 'Ignored')。
每一行记录某个用户对某条广告的行为。
```

编写一个 SQL 查询，计算每条广告的 **点击率（CTR）**，定义为：

`CTR = 点击数 / (点击数 + 浏览次数) * 100`

返回列 `ad_id` 与 `ctr`，`ctr` 四舍五入保留两位小数。按 `ctr` **降序** 排列，`ctr` 相同时按 `ad_id` **升序** 排列。若某条广告既没有点击也没有浏览（只有 `Ignored`），其 `ctr` 记为 0。

**示例 1：**

```
输入：
Ads table:
+-------+---------+---------+
| ad_id | user_id | action  |
+-------+---------+---------+
| 1     | 1       | Clicked |
| 2     | 2       | Clicked |
| 3     | 3       | Viewed  |
| 5     | 5       | Ignored |
| 1     | 7       | Ignored |
| 2     | 7       | Viewed  |
| 3     | 5       | Clicked |
| 1     | 4       | Viewed  |
| 2     | 11      | Viewed  |
| 1     | 2       | Clicked |
+-------+---------+---------+
输出：
+-------+-------+
| ad_id | ctr   |
+-------+-------+
| 1     | 66.67 |
| 3     | 50.00 |
| 2     | 33.33 |
| 5     | 0.00  |
+-------+-------+
解释：
1 号广告：点击 2 次（用户 1、2），浏览 1 次（用户 4），CTR = 2 / 3 * 100 = 66.67。
3 号广告：点击 1 次，浏览 1 次，CTR = 1 / 2 * 100 = 50.00。
2 号广告：点击 1 次，浏览 2 次，CTR = 1 / 3 * 100 = 33.33。
5 号广告：只有 Ignored，分母为 0，CTR 记为 0。
```

## 题解

::: details 点击查看题解

### 思路

按 `ad_id` 分组，分子是 `Clicked` 的条数，分母是 `Clicked + Viewed` 的条数——`Ignored` 必须排除在分母之外，否则把「被忽略」当成「看过没点」，点击率会被系统性压低。

分子分母都用条件求和表达：`SUM(action = 'Clicked')` 与 `SUM(action IN ('Clicked', 'Viewed'))`。MySQL 中布尔比较返回 0/1，写成 `SUM(CASE WHEN ... THEN 1 ELSE 0 END)` 也完全等价，后者跨方言更通用。

关键坑在分母为 0：只有 `Ignored` 记录的广告（样本中的 5 号）相除会得到 NULL。MySQL 里除零不报错而是返回 NULL，所以要用 `NULLIF(分母, 0)` 把 0 变成 NULL，再在外层用 `IFNULL(..., 0)` 兜底成 0，顺序不能反——先 `IFNULL` 再除零仍然会得到 NULL。最后 `ROUND(..., 2)` 保留两位小数，排序按 `ctr DESC, ad_id ASC`。

### SQL 实现

```sql
SELECT ad_id,
       IFNULL(
           ROUND(
               SUM(action = 'Clicked')
               / NULLIF(SUM(action IN ('Clicked', 'Viewed')), 0) * 100,
               2
           ),
           0
       ) AS ctr
FROM Ads
GROUP BY ad_id
ORDER BY ctr DESC, ad_id ASC;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为 `Ads` 行数，一次分组聚合。
- 空间复杂度：O(a)，a 为不同广告数。

:::
