# 制作会话柱状图

> 难度：简单 | 标签：条件分支、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/create-a-session-bar-chart/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Sessions` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| session_id  | int     |
| duration    | int     |
+-------------+---------+
session_id 是该表的主键。
duration 是某次会话的时长，单位为分钟。
```

编写一个 SQL 查询，把会话按时长分桶，统计每个桶内的会话数量，用来画柱状图。分桶规则：

```
[0-5>     duration >= 0 且 < 5
[5-10>    duration >= 5 且 < 10
[10-15>   duration >= 10 且 < 15
[15-30>   duration >= 15 且 < 30
[30-60>   duration >= 30 且 < 60
60+       duration >= 60
```

返回列 `bin`、`total`，**六个桶都要出现**（即使某个桶的会话数为 0，也要显示 0），按上面的桶顺序排列。

**示例 1：**

```
输入：
Sessions table:
+------------+----------+
| session_id | duration |
+------------+----------+
| 1          | 30       |
| 2          | 199      |
| 3          | 299      |
| 4          | 580      |
| 5          | 1000     |
+------------+----------+
输出：
+-----------+-------+
| bin       | total |
+-----------+-------+
| [0-5>     | 0     |
| [5-10>    | 0     |
| [10-15>   | 0     |
| [15-30>   | 0     |
| [30-60>   | 1     |
| 60+       | 4     |
+-----------+-------+
解释：
30 分钟落在 [30-60> 桶；199、299、580、1000 分钟都 ≥ 60，落在 60+ 桶。
其余四个桶没有任何会话，计数为 0，但仍需输出。
```

## 题解

::: details 点击查看题解

### 思路

本质是「先分桶再计数」，分桶用 `CASE WHEN` 链实现。注意每个桶都是左闭右开区间，`CASE` 的判定顺序必须从最小区间开始，命中即返回：`duration < 5`、`duration < 10`……如果先判 `duration < 60` 再判 `duration < 30`，30 分钟的会话就会被错误地归到小桶里。这类「按区间分类」的写法比 `FLOOR(duration / 5)` 更直观，也能处理最后一个开口桶 `60+`。

题目要求零计数的桶也出现，这是最容易漏的一点：直接 `GROUP BY bin` 只会产生实际存在的桶。做法是先用 `UNION ALL` 造一张固定的六行桶清单，再 `LEFT JOIN Sessions`，连接条件就是「该行 duration 计算出的桶名等于清单里的桶名」，最后 `COUNT(s.session_id)` 统计——左连接产生的空行计数为 0，正好补全空缺。

排序不能依赖字符串顺序：按字典序 `[10-15>` 会排在 `[5-10>` 前面，与要求的桶顺序不一致。用 `ORDER BY FIELD(bin, ...)` 显式指定顺序，或者给桶加一个序号列再按序号排序。

### SQL 实现

```sql
SELECT b.bin,
       COUNT(s.session_id) AS total
FROM (
    SELECT '[0-5>'   AS bin UNION ALL
    SELECT '[5-10>'  UNION ALL
    SELECT '[10-15>' UNION ALL
    SELECT '[15-30>' UNION ALL
    SELECT '[30-60>' UNION ALL
    SELECT '60+'
) b
LEFT JOIN Sessions s
       ON b.bin = CASE
                      WHEN s.duration < 5  THEN '[0-5>'
                      WHEN s.duration < 10 THEN '[5-10>'
                      WHEN s.duration < 15 THEN '[10-15>'
                      WHEN s.duration < 30 THEN '[15-30>'
                      WHEN s.duration < 60 THEN '[30-60>'
                      ELSE '60+'
                  END
GROUP BY b.bin
ORDER BY FIELD(b.bin, '[0-5>', '[5-10>', '[10-15>', '[15-30>', '[30-60>', '60+');
```

### 复杂度分析

- 时间复杂度：O(n)，n 为 `Sessions` 行数，一次连接 + 六个桶的聚合。
- 空间复杂度：O(1)，桶清单固定六行，额外空间为常量级。

:::
