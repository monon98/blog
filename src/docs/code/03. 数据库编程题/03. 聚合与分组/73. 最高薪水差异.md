# 最高薪水差异

> 难度：简单 | 标签：分组聚合、子查询 | [LeetCode 原题](https://leetcode.cn/problems/highest-salaries-difference/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Salaries`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| emp_name    | varchar |
| department  | varchar |
| salary      | int     |
+-------------+---------+
该表的主键（具有唯一值的列的组合）是 (emp_name, department)。
该表的每一行包含 emp_name、department 和 salary。
工程部门和市场部门至少会有一条记录。
```

编写一个解决方案，计算 **市场部门** 和 **工程部门** 中 **最高** 工资之间的差异。输出工资的绝对差异 `salary_difference`。返回结果表。

**示例 1：**

输入：

```
Salaries table:
+----------+-------------+--------+
| emp_name | department  | salary |
+----------+-------------+--------+
| Kathy    | Engineering | 50000  |
| Roy      | Marketing   | 30000  |
| Charles  | Engineering | 45000  |
| Jack     | Engineering | 85000  |
| Benjamin | Marketing   | 34000  |
| Anthony  | Marketing   | 42000  |
| Edward   | Engineering | 102000 |
| Terry    | Engineering | 44000  |
| Evelyn   | Marketing   | 53000  |
| Arthur   | Engineering | 32000  |
+----------+-------------+--------+
```

输出：

```
+-------------------+
| salary_difference |
+-------------------+
| 49000             |
+-------------------+
```

解释：

- 工程部门和市场部门的最高工资分别为 102,000 和 53,000，因此绝对差异为 49,000。

## 题解

::: details 点击查看题解

### 思路

先按 `department` 分组取 `MAX(salary)`，得到每个部门的最高薪，再在这份「部门最高薪」的小结果集上求最大值与最小值之差。用 `MAX(s) - MIN(s)` 而不是硬编码两个部门相减有两个好处：一是不依赖部门名的字面顺序，天然得到绝对差；二是即便将来多出一个部门也仍然有意义。

之所以要在**外层**做差而不是在一条 SQL 里直接写两个 `MAX` 条件求值，是因为同一层里既 `GROUP BY` 又拿 `MAX` 参与比较容易踩 `ONLY_FULL_GROUP_BY` 的坑；拆成派生表后语义最清晰。题目保证两个部门都至少有一行，所以不必处理空组。

替代写法：用两个标量子查询分别 `SELECT MAX(salary) ... WHERE department = 'Engineering'` 和 `'Marketing'` 再相减，也完全正确，写法更直白，但扩展性不如「先分组再求极差」。

### SQL 实现

```sql
SELECT MAX(s) - MIN(s) AS salary_difference
FROM (
    SELECT MAX(salary) AS s
    FROM Salaries
    GROUP BY department
) AS t;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为 Salaries 行数，一次分组扫描 + 派生表上两次聚合。
- 空间复杂度：O(d)，d 为部门数量，分组结果只保留每部门一行。

:::
