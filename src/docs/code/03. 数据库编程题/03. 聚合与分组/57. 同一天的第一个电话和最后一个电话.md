# 同一天的第一个电话和最后一个电话

> 难度：困难 | 标签：窗口函数、日期函数、UNION ALL | [LeetCode 原题](https://leetcode.cn/problems/first-and-last-call-on-the-same-day/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

通话表 `Calls`：

```
+--------------+----------+
| Column Name  | Type     |
+--------------+----------+
| caller_id    | int      |
| recipient_id | int      |
| call_time    | datetime |
+--------------+----------+
(caller_id, recipient_id, call_time) 是该表的主键。
每一行表示 caller_id 在 call_time 给 recipient_id 打了一通电话。通话是双向的，双方都算参与了这通电话。
```

请编写一个 SQL 查询，找出在**任意一天**里，当天第一通电话和最后一通电话都是和**同一个人**通话的用户 ID。通话不论拨打方还是接听方都会被记录。

结果表只有 `user_id` 一列，顺序不限。

**示例 1：**

```
输入：
Calls 表：
+-----------+--------------+---------------------+
| caller_id | recipient_id | call_time           |
+-----------+--------------+---------------------+
| 8         | 4            | 2021-08-24 17:46:07 |
| 4         | 8            | 2021-08-24 19:57:13 |
| 5         | 1            | 2021-08-11 05:28:44 |
| 8         | 3            | 2021-08-17 04:04:15 |
| 11        | 3            | 2021-08-17 13:07:00 |
| 8         | 11           | 2021-08-17 22:22:22 |
+-----------+--------------+---------------------+

输出：
+---------+
| user_id |
+---------+
| 1       |
| 4       |
| 5       |
| 8       |
+---------+

解释：
2021-08-24 这天 8 和 4 之间有两通电话，分别是当天的第一通和最后一通，所以 4 和 8 都入选；
2021-08-11 只有 5 与 1 的一通电话，它既是当天第一通也是最后一通，两人都入选；
2021-08-17 这天 8 的第一通是打给 3，最后一通是打给 11，对象不同，因此 8、3、11 都不入选。
```

## 题解

::: details 点击查看题解

### 思路

Calls 一行只记录 caller → recipient 一个方向，但通话是双向的：只关心拨打方会漏掉只在当天接过电话的人（示例中的 4 和 1）。所以先把每行拆成两个方向 UNION ALL 成一张「用户 ← 对方 + 时间」的长表。

「每天的第一通和最后一通」是典型的分区内首尾取值：按 (user_id, 日期) 分区，一个窗口按 call_time 升序取 FIRST_VALUE(recipient_id)，另一个按降序取，两者相等说明当天首尾都是同一个人。日期用 DATE(call_time) 截断即可。

同一用户同一天可能有多通电话，每条记录都会算出一个 first/last 值，所以最后要 DISTINCT 去重。替代写法是先 ROW_NUMBER() 升序、降序各编一次号，再按用户和日期分组取 rn = 1 的那两行比较。

### SQL 实现

```sql
WITH BothWays AS (
    SELECT caller_id AS user_id, recipient_id, call_time FROM Calls
    UNION ALL
    SELECT recipient_id, caller_id, call_time FROM Calls
),
Ranked AS (
    SELECT user_id,
           DATE(call_time) AS call_date,
           FIRST_VALUE(recipient_id) OVER (
               PARTITION BY user_id, DATE(call_time)
               ORDER BY call_time
           ) AS first_recipient,
           FIRST_VALUE(recipient_id) OVER (
               PARTITION BY user_id, DATE(call_time)
               ORDER BY call_time DESC
           ) AS last_recipient
    FROM BothWays
)
SELECT DISTINCT user_id
FROM Ranked
WHERE first_recipient = last_recipient
ORDER BY user_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，双向展开后按分区排序，n 为通话数
- 空间复杂度：O(n)，需要物化双向展开的中间结果

:::
