# 每个产品在不同商店的价格

> 难度：简单 | 标签：UNION ALL、列转行 | [LeetCode 原题](https://leetcode.cn/problems/rearrange-products-table/)

## 题目描述

表：`Products`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| store1      | int     |
| store2      | int     |
| store3      | int     |
+-------------+---------+
在 SQL 中，这张表的主键是 product_id（产品Id）。
每行存储了这一产品在不同商店 store1, store2, store3 的价格。
如果这一产品在商店里没有出售，则值将为 null。
```

请你重构 `Products` 表，查询每个产品在不同商店的价格，使得输出的格式变为`(product_id, store, price)` 。如果这一产品在商店里没有出售，则不输出这一行。

输出结果表中的 **顺序不作要求** 。

查询输出格式请参考下面示例。

**示例 1：**

```
输入：
Products table:
+------------+--------+--------+--------+
| product_id | store1 | store2 | store3 |
+------------+--------+--------+--------+
| 0          | 95     | 100    | 105    |
| 1          | 70     | null   | 80     |
+------------+--------+--------+--------+
输出：
+------------+--------+-------+
| product_id | store  | price |
+------------+--------+-------+
| 0          | store1 | 95    |
| 0          | store2 | 100   |
| 0          | store3 | 105   |
| 1          | store1 | 70    |
| 1          | store3 | 80    |
+------------+--------+-------+
解释：
产品 0 在 store1、store2、store3 的价格分别为 95、100、105。
产品 1 在 store1、store3 的价格分别为 70、80。在 store2 无法买到。
```

## 题解

::: details 点击查看题解

### 思路

这是一道宽表转长表的题：输入是 `(product_id, store1, store2, store3)`，输出是 `(product_id, store, price)` 三列。最直接的解法是写三段 `SELECT`，每段负责一家商店，把列名作为常量 `store` 值，再用 `UNION ALL` 纵向拼起来。

两家店同价的情况很常见（示例里产品 0 三家店都不同，但别的数据完全可能相同），所以必须用 `UNION ALL`。用 `UNION` 会按三列整体去重，一旦 `(product_id, store, price)` 有重复就少行——而 `store` 列其实保证了不会重复，仍然推荐 `UNION ALL`，语义更明确也更快。

`WHERE storeN IS NOT NULL` 用来实现「某店不卖就不输出这一行」。注意 `NULL` 只能用 `IS NOT NULL` 判断，`storeN <> NULL` 恒为 NULL；这一步如果不写，产品 1 的 `store2` 会输出一行 price 为 NULL 的记录。

另一种写法是 `CROSS JOIN` 一张三行的商店字典，再用 `CASE` 取对应列，好处是商店数量变化时只改字典；不过在列数固定的场景下，三段 `UNION ALL` 更易读，MySQL 8 也支持 `LATERAL` 派生表，但属于杀鸡用牛刀。

### SQL 实现

```sql
SELECT product_id, 'store1' AS store, store1 AS price FROM Products WHERE store1 IS NOT NULL
UNION ALL
SELECT product_id, 'store2', store2 FROM Products WHERE store2 IS NOT NULL
UNION ALL
SELECT product_id, 'store3', store3 FROM Products WHERE store3 IS NOT NULL;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为产品数，需要扫三遍表。
- 空间复杂度：O(3n)，最多输出每个产品三行。

:::

## 建表与测试数据

```sql
Create table If Not Exists Products (product_id int, store1 int, store2 int, store3 int);
Truncate table Products;
insert into Products (product_id, store1, store2, store3) values ('0', '95', '100', '105');
insert into Products (product_id, store1, store2, store3) values ('1', '70', NULL, '80');
```
