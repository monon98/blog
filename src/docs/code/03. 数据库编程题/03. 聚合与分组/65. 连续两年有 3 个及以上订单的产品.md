# 连续两年有 3 个及以上订单的产品

> 难度：中等 | 标签：分组聚合、自连接 | [LeetCode 原题](https://leetcode.cn/problems/products-with-three-or-more-orders-in-two-consecutive-years/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

订单表 `Orders`：

```
+---------------+------+
| Column Name   | Type |
+---------------+------+
| order_id      | int  |
| product_id    | int  |
| quantity      | int  |
| purchase_date | date |
+---------------+------+
order_id 唯一。
每一行表示订单编号、购买的产品 ID、数量以及购买日期。
```

请编写一个解决方案，找出**连续两年**都订购了**三次或三次以上**的所有产品 ID。返回顺序不限。

**示例 1：**

```
输入：
Orders 表：
+----------+------------+----------+---------------+
| order_id | product_id | quantity | purchase_date |
+----------+------------+----------+---------------+
| 1        | 1          | 7        | 2020-03-16    |
| 2        | 1          | 4        | 2020-12-02    |
| 3        | 1          | 7        | 2020-05-10    |
| 4        | 1          | 6        | 2021-12-23    |
| 5        | 1          | 5        | 2021-05-21    |
| 6        | 1          | 6        | 2021-10-11    |
| 7        | 2          | 6        | 2022-10-11    |
+----------+------------+----------+---------------+

输出：
+------------+
| product_id |
+------------+
| 1          |
+------------+

解释：产品 1 在 2020 年和 2021 年都各有 3 笔订单，连续两年达标；产品 2 在 2022 年只有 1 笔订单，不符合条件。
```

## 题解

::: details 点击查看题解

### 思路

先压缩数据：按 (product_id, 年份) 分组统计订单数，HAVING COUNT(*) >= 3 后只留下「某产品在某年至少 3 单」的年份，其余年份不必再参与比较。

接着自连接找出相邻年份：同一产品、年份相差 1 的任意两条压缩记录都构成一对连续两年达标。这种「任意相邻两年」的连接方式不会漏掉连续三年都达标的产品。

自连接会为链式年份（2020 达标、2021 达标、2022 达标）产生多行，最后用 DISTINCT 去重。替代写法是用 LAG/LEAD 比较相邻年份。

### SQL 实现

```sql
WITH YearlyOrders AS (
    SELECT product_id, YEAR(purchase_date) AS order_year
    FROM Orders
    GROUP BY product_id, YEAR(purchase_date)
    HAVING COUNT(*) >= 3
)
SELECT DISTINCT a.product_id
FROM YearlyOrders AS a
JOIN YearlyOrders AS b
  ON b.product_id = a.product_id
 AND b.order_year = a.order_year + 1
ORDER BY a.product_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，分组聚合加自连接排序，n 为订单数
- 空间复杂度：O(k)，k 为达标的产品-年份对数

:::
