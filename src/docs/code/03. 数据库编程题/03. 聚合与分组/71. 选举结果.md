# 选举结果

> 难度：中等 | 标签：窗口函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/election-results/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Votes`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| voter       | varchar |
| candidate   | varchar |
+-------------+---------+
(voter, candidate) 是该表的主键（具有唯一值的列）。
该表的每一行都包含选民及其候选人的姓名。
```

选举在一个城市进行，每个人都可以投票给 **一个或多个** 候选人，也可以选择 **不** 投票。每个人都有 1 票，所以如果他们投票给多个候选人，他们的选票会被平均分配。例如，如果一个人投票给 2 个候选人，这些候选人每人获得 0.5 张选票。

编写一个解决方案来查找获得最多选票并赢得选举的候选人 `candidate`。输出候选人的姓名，或者如果多个候选人的票数相等，则输出所有候选人的姓名。返回按 `candidate` 升序排序的结果表。

**示例 1：**

输入：

```
Votes table:
+----------+-----------+
| voter    | candidate |
+----------+-----------+
| Kathy    | null      |
| Charles  | Ryan      |
| Charles  | Christine |
| Charles  | Kathy     |
| Benjamin | Christine |
| Anthony  | Ryan      |
| Edward   | Ryan      |
| Terry    | null      |
| Evelyn   | Kathy     |
| Arthur   | Christine |
+----------+-----------+
```

输出：

```
+-----------+
| candidate |
+-----------+
| Christine |
| Ryan      |
+-----------+
```

解释：

- Kathy 和 Terry 选择不投票，导致他们的投票被记录为 0。
- Charles 将他的选票分配给了三位候选人，相当于每位候选人得到 0.33 票。另一方面，Benjamin、Arthur、Anthony、Edward 和 Evelyn 各自把票投给了一位候选人。
- Ryan 和 Christine 总共获得了 2.33 票，而 Kathy 总共获得了 1.33 票。
- 由于 Ryan 和 Christine 获得的票数相等，我们将按升序显示他们的名字。

## 题解

::: details 点击查看题解

### 思路

本题的关键在于「一票拆多份」：某个选民投给了 k 个候选人，每个候选人只能得到 `1 / k` 票，因此绝不能直接 `COUNT(*)` 统计行数——那样 Charles 的三票会各记 1 票，把结果算错。先过滤掉 `candidate IS NULL` 的弃票行（弃票者不应进入任何候选人的计票），再用窗口函数 `COUNT(*) OVER (PARTITION BY voter)` 求出每位选民的有效投票人数，即可给每行赋予 `1 / k` 的权重。

拿到权重后按 `candidate` 分组 `SUM` 出总得票，最后用 `RANK() OVER (ORDER BY tot DESC)` 取最高分。注意必须用 `RANK` 而不是 `ROW_NUMBER`：题目要求并列第一的候选人**全部**返回，`ROW_NUMBER` 会把并列者强行排出先后、只留一个。`RANK` 会给并列者相同的名次 1，外层 `WHERE rk = 1` 即可全部保留，再按姓名升序输出。

替代写法：先 `GROUP BY voter` 算出每个选民的投票数，再与明细表连接除权，也能得到同样结果，但窗口函数一步到位、无需自连接。

### SQL 实现

```sql
WITH
    T AS (
        SELECT candidate, SUM(vote) AS tot
        FROM (
            SELECT
                candidate,
                1 / (COUNT(candidate) OVER (PARTITION BY voter)) AS vote
            FROM Votes
            WHERE candidate IS NOT NULL
        ) AS t
        GROUP BY 1
    ),
    P AS (
        SELECT
            candidate,
            RANK() OVER (ORDER BY tot DESC) AS rk
        FROM T
    )
SELECT candidate
FROM P
WHERE rk = 1
ORDER BY 1;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为有效投票行数，两次窗口排序 + 一次分组聚合。
- 空间复杂度：O(n)，窗口函数与聚合均需哈希/排序中间结构。
