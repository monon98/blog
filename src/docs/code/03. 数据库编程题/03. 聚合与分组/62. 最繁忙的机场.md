# 最繁忙的机场

> 难度：中等 | 标签：UNION ALL、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/the-airport-with-the-most-traffic/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

航班表 `Flights`：

```
+-------------------+------+
| Column Name       | Type |
+-------------------+------+
| departure_airport | int  |
| arrival_airport   | int  |
| flights_count     | int  |
+-------------------+------+
(departure_airport, arrival_airport) 是该表的主键。
每一行表示有 flights_count 架次航班从 departure_airport 起飞、抵达 arrival_airport。
```

请编写一个 SQL 查询，找出**流量最大**的机场 ID。机场流量指从该机场起飞或抵达该机场的航班总数。若多个机场并列最大，请全部返回。返回顺序不限。

**示例 1：**

```
输入：
Flights 表：
+-------------------+-----------------+---------------+
| departure_airport | arrival_airport | flights_count |
+-------------------+-----------------+---------------+
| 1                 | 2               | 4             |
| 2                 | 1               | 5             |
| 2                 | 4               | 5             |
+-------------------+-----------------+---------------+

输出：
+------------+
| airport_id |
+------------+
| 2          |
+------------+

解释：
机场 1 有 9 架次（4 架次起飞 + 5 架次到达）；
机场 2 有 14 架次（10 架次起飞 + 4 架次到达）；
机场 4 有 5 架次（5 架次到达）。
流量最大的是机场 2。
```

## 题解

::: details 点击查看题解

### 思路

机场流量 = 起飞航班数 + 到达航班数，而 Flights 一行只记录一个方向。只按 departure_airport 聚合会漏掉作为目的地的流量，示例里机场 2 有 10 个起飞（5 + 5）和 4 个到达，必须两方向相加才是 14。

做法是把航班表拼成「每个机场一行」的长表：原样取出发机场，再把起降对调取一次到达机场，UNION ALL 之后按机场 SUM(flights_count)。UNION ALL 不要写成 UNION，重复航班不能被去重。

取最大值用子查询过滤而不是 ORDER BY ... LIMIT 1，因为可能有多个机场并列最大，题目要求全部返回。

### SQL 实现

```sql
WITH Traffic AS (
    SELECT departure_airport AS airport_id, flights_count FROM Flights
    UNION ALL
    SELECT arrival_airport, flights_count FROM Flights
),
Total AS (
    SELECT airport_id, SUM(flights_count) AS flights_count
    FROM Traffic
    GROUP BY airport_id
)
SELECT airport_id
FROM Total
WHERE flights_count = (SELECT MAX(flights_count) FROM Total)
ORDER BY airport_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，2n 行展开后分组排序，n 为航班记录数
- 空间复杂度：O(m)，m 为机场数量

:::
