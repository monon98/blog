# 寻找数据科学家职位的候选人

> 难度：简单 | 标签：分组聚合、HAVING 筛选 | [LeetCode 原题](https://leetcode.cn/problems/find-candidates-for-data-scientist-position/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Candidates` 表：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| candidate_id | int     |
| skill        | varchar |
+--------------+---------+
(candidate_id, skill) 是该表的主键。
每一行表示某位候选人掌握的一项技能。
```

数据科学家职位要求候选人同时精通 **Python**、**Tableau** 和 **PostgreSQL** 三项技能。编写一个解决方案，找出满足该要求的全部候选人。

返回结果表，以 `candidate_id` 升序排序。

**示例 1：**

输入：

```
Candidates 表：
+--------------+--------------+
| candidate_id | skill        |
+--------------+--------------+
| 123          | Python       |
| 234          | R            |
| 123          | Tableau      |
| 123          | PostgreSQL   |
| 234          | PowerBI      |
| 234          | SQL Server   |
| 147          | Python       |
| 147          | Tableau      |
| 147          | Java         |
| 147          | PostgreSQL   |
| 256          | Tableau      |
| 102          | DataAnalysis |
+--------------+--------------+
```

输出：

```
+--------------+
| candidate_id |
+--------------+
| 123          |
| 147          |
+--------------+
```

解释：

- 候选人 123 与 147 同时具备 Python、Tableau、PostgreSQL 三项技能。
- 候选人 256 只会 Tableau，234 与 102 一项都不具备，因此都被排除。

## 题解

::: details 点击查看题解

### 思路

技能是按「一个候选人一行一项技能」的方式竖着存的，所以这里最典型的坑是写成 `WHERE skill = 'Python' AND skill = 'Tableau'`：同一行里 `skill` 只可能等于一个值，条件永远为假，结果必然为空。多值匹配必须落到「分组计数」上。

正确做法是先把行过滤成只保留三个目标技能，再按 `candidate_id` 分组，最后用 `HAVING` 断言组内技能数为 3。没被 `WHERE` 选中的技能不会进入计数，所以「会 4 项技能」的候选人不会被误判 —— 只要能凑齐这三项就算命中。

计数建议写 `COUNT(DISTINCT skill)`：虽然主键已保证不会重复，但用 `DISTINCT` 表达的是「三种不同技能」的语义，数据里真出现重复行时不至于把同一技能数两遍。替代写法是用三次 `EXISTS` 或三个子查询取交集，可读性更好但扫描次数更多。

### SQL 实现

```sql
SELECT candidate_id
FROM Candidates
WHERE skill IN ('Python', 'Tableau', 'PostgreSQL')
GROUP BY candidate_id
HAVING COUNT(DISTINCT skill) = 3
ORDER BY candidate_id;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为 Candidates 行数，一次扫描加一次分组。
- 空间复杂度：O(k)，k 为候选人数量，用于存放分组状态。

:::
