# 平均工资：部门与公司比较

> 难度：困难 | 标签：窗口函数、多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/average-salary-departments-vs-company/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Salary` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| employee_id | int     |
| amount      | int     |
| pay_date    | date    |
+-------------+---------+
id 是主键。
每一行表示 employee_id 的员工在 pay_date 收到了 amount 的工资。
```

`Employee` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| employee_id | int     |
| department_id | int   |
+-------------+---------+
employee_id 是主键。
每一行表示 employee_id 的员工属于 department_id 部门。
```

编写解决方案，对 **每个发薪月**，比较各部门平均工资与全公司平均工资的高低，输出：

- `pay_month`：格式为 `YYYY-MM` 的发薪月份；
- `department_id`：部门 id；
- `comparison`：部门平均工资相对公司平均工资的结果，取值 `higher`（高）、`lower`（低）、`same`（相同）。

以任意顺序返回结果表。

**示例 1:**

```
输入:
Salary 表:
+----+-------------+--------+------------+
| id | employee_id | amount | pay_date   |
+----+-------------+--------+------------+
| 1  | 1           | 9000   | 2017/03/31 |
| 2  | 2           | 6000   | 2017/03/31 |
| 3  | 3           | 10000  | 2017/03/31 |
| 4  | 1           | 7000   | 2017/02/28 |
| 5  | 2           | 6000   | 2017/02/28 |
| 6  | 3           | 8000   | 2017/02/28 |
+----+-------------+--------+------------+
Employee 表:
+-------------+---------------+
| employee_id | department_id |
+-------------+---------------+
| 1           | 1             |
| 2           | 2             |
| 3           | 2             |
+-------------+---------------+
输出:
+-----------+-------------+------------+
| pay_month | department_id | comparison |
+-----------+-------------+------------+
| 2017-03   | 1            | higher     |
| 2017-03   | 2            | lower      |
| 2017-02   | 1            | same       |
| 2017-02   | 2            | same       |
+-----------+-------------+------------+
解释:
2017-03 公司平均工资为 (9000 + 6000 + 10000) / 3 = 8333.33，
部门 1 平均工资 9000 更高（higher），部门 2 平均工资 8000 更低（lower）。
2017-02 公司平均工资为 (7000 + 6000 + 8000) / 3 = 7000，
两个部门平均工资均为 7000，结果都是 same。
```

## 题解

::: details 点击查看题解

### 思路

要比较「部门 vs 公司」，关键是两次聚合都必须 **按发薪月分组**：公司平均工资是该月所有员工的平均值，部门平均工资是该月该部门员工的平均值，两者口径必须一致，否则跨月混算会得到错误结论。做法是先把 `Salary` 与 `Employee` 按 `employee_id` 连接拿到部门信息，然后用窗口函数一次性算出两个平均值：`AVG(amount) OVER (PARTITION BY pay_date, department_id)` 得到部门月均，`AVG(amount) OVER (PARTITION BY pay_date)` 得到公司月均，最后逐行比较输出。

用窗口函数的好处是每行自带两个平均值，比较逻辑只写一次；替代写法是两个 CTE 分别 `GROUP BY` 出部门月均和公司月均再 `JOIN`，逻辑等价但代码更长。比较结果要用 `CASE WHEN ... THEN ... END` 三路分支，注意 `same` 必须用 `=` 精确判断——虽然浮点数比较理论上要小心，但同一份数据算出的平均值在 MySQL 中结果一致，用 `>`、`<`、`ELSE 'same'` 的顺序也能覆盖。

另一个易错点是月份格式：`pay_date` 是日期，直接按天分组会把同月不同发薪日拆开，必须先用 `DATE_FORMAT(pay_date, '%Y-%m')` 归一成 `YYYY-MM` 字符串再分组、输出。

### SQL 实现

```sql
SELECT DISTINCT
    DATE_FORMAT(s.pay_date, '%Y-%m') AS pay_month,
    e.department_id,
    CASE
        WHEN dept.dept_avg > comp.comp_avg THEN 'higher'
        WHEN dept.dept_avg < comp.comp_avg THEN 'lower'
        ELSE 'same'
    END AS comparison
FROM Salary s
JOIN Employee e
    ON s.employee_id = e.employee_id
JOIN (
    SELECT DATE_FORMAT(pay_date, '%Y-%m') AS pay_month,
           AVG(amount) AS comp_avg
    FROM Salary
    GROUP BY DATE_FORMAT(pay_date, '%Y-%m')
) comp
    ON comp.pay_month = DATE_FORMAT(s.pay_date, '%Y-%m')
JOIN (
    SELECT DATE_FORMAT(s2.pay_date, '%Y-%m') AS pay_month,
           e2.department_id,
           AVG(s2.amount) AS dept_avg
    FROM Salary s2
    JOIN Employee e2
        ON s2.employee_id = e2.employee_id
    GROUP BY DATE_FORMAT(s2.pay_date, '%Y-%m'), e2.department_id
) dept
    ON dept.pay_month = DATE_FORMAT(s.pay_date, '%Y-%m')
   AND dept.department_id = e.department_id;
```

等价的窗口函数写法：

```sql
SELECT DISTINCT
    pay_month,
    department_id,
    CASE
        WHEN dept_avg > comp_avg THEN 'higher'
        WHEN dept_avg < comp_avg THEN 'lower'
        ELSE 'same'
    END AS comparison
FROM (
    SELECT DATE_FORMAT(pay_date, '%Y-%m') AS pay_month,
           e.department_id,
           AVG(amount) OVER (PARTITION BY DATE_FORMAT(pay_date, '%Y-%m'), e.department_id) AS dept_avg,
           AVG(amount) OVER (PARTITION BY DATE_FORMAT(pay_date, '%Y-%m')) AS comp_avg
    FROM Salary s
    JOIN Employee e
        ON s.employee_id = e.employee_id
) t;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为工资记录数，连接与分组接近线性，排序/去重主导。
- 空间复杂度：O(m)，m 为「月份 × 部门」组合数与去重开销。
