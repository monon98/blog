# 联赛信息统计

> 难度：中等 | 标签：条件聚合、CASE 表达式、多表连接 | [LeetCode 原题](https://leetcode.cn/problems/league-statistics/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Teams`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| team_id     | int     |
| team_name   | varchar |
+-------------+---------+
team_id 是此表中具有唯一值的列。
每一行包含一支球队的 id 和队名。
```

表：`Matches`

```
+-----------------+------+
| Column Name     | Type |
+-----------------+------+
| home_team_id    | int  |
| away_team_id    | int  |
| home_team_goals | int  |
| away_team_goals | int  |
+-----------------+------+
此表没有主键。
每一行表示一场比赛：主队、客队及双方进球数。
`home_team_id`、`away_team_id` 都是 `Teams` 表中的 `team_id`。
```

编写一个解决方案，统计每支球队的联赛数据：

- `matches_played`：参加的比赛场数；
- `points`：积分，胜一场 3 分、平一场 1 分、负一场 0 分；
- `goal_for`：总进球数；
- `goal_against`：总失球数；
- `goal_difference`：净胜球，等于 `goal_for - goal_against`。

返回结果表需包含 `team_name`，并按 `points` 降序、`goal_difference` 降序、`team_name` 升序排列。

**示例 1：**

输入：

```
Teams table:
+---------+-----------+
| team_id | team_name |
+---------+-----------+
| 1       | Ajax      |
| 4       | Dortmund  |
| 6       | Arsenal   |
+---------+-----------+

Matches table:
+--------------+--------------+-----------------+-----------------+
| home_team_id | away_team_id | home_team_goals | away_team_goals |
+--------------+--------------+-----------------+-----------------+
| 1            | 4            | 0               | 1               |
| 1            | 6            | 3               | 3               |
| 4            | 1            | 5               | 2               |
| 6            | 1            | 0               | 0               |
+--------------+--------------+-----------------+-----------------+
```

输出：

```
+-----------+----------------+--------+----------+--------------+-----------------+
| team_name | matches_played | points | goal_for | goal_against | goal_difference |
+-----------+----------------+--------+----------+--------------+-----------------+
| Dortmund  | 2              | 6      | 6        | 2            | 4               |
| Arsenal   | 2              | 2      | 3        | 3            | 0               |
| Ajax      | 4              | 2      | 5        | 9            | -4              |
+-----------+----------------+--------+----------+--------------+-----------------+
```

解释：

- Dortmund 主场 1:0 胜 Ajax、客场 5:2 胜 Ajax，两战全胜 6 分，进 6 失 2。
- Arsenal 客场 3:3 平 Ajax、主场 0:0 平 Ajax，两战两平 2 分，进 3 失 3。
- Ajax 四战两平两负，积 2 分，进 5 失 9，净胜球 -4。
- 积分相同（2 分）时比净胜球，Arsenal 的 0 大于 Ajax 的 -4。

## 题解

::: details 点击查看题解

### 思路

一场比赛要同时算进两支球队的战绩，所以要让 `Teams` 与 `Matches` 按「主队或客队」连接：`ON t.team_id IN (m.home_team_id, m.away_team_id)`。这样每场比赛被展开两次，各队各拿到一行，随后所有指标都能按球队 `GROUP BY` 聚合。

所有指标都是「按球队视角取值」的条件聚合：进球数在主队视角取 `home_team_goals`、客队视角取 `away_team_goals`，失球数反过来，用 `CASE WHEN t.team_id = m.home_team_id THEN ... ELSE ... END` 一行搞定。

积分要按三种结果分别给分，`CASE` 的分支顺序很关键：先判平局（双方进球相等）给 1 分，再判该队是否赢球给 3 分，剩下给 0 分。如果先写「主队进球 > 客队进球 → 3 分」而不区分该队是主是客，客队赢球会被算成 0 分——这是本题最典型的错误。

净胜球可以直接用两个 `SUM(CASE ...)` 相减，不必引用别名；`ORDER BY` 里则可以放心使用 `points`、`goal_difference` 这些别名（MySQL 允许 `ORDER BY` 引用列别名），但 `GROUP BY` 不允许，得写完整表达式或原始列。

### SQL 实现

```sql
SELECT t.team_name,
       COUNT(*) AS matches_played,
       SUM(CASE
             WHEN m.home_team_goals = m.away_team_goals THEN 1
             WHEN t.team_id = m.home_team_id AND m.home_team_goals > m.away_team_goals THEN 3
             WHEN t.team_id = m.away_team_id AND m.away_team_goals > m.home_team_goals THEN 3
             ELSE 0
           END) AS points,
       SUM(CASE WHEN t.team_id = m.home_team_id THEN m.home_team_goals ELSE m.away_team_goals END) AS goal_for,
       SUM(CASE WHEN t.team_id = m.home_team_id THEN m.away_team_goals ELSE m.home_team_goals END) AS goal_against,
       SUM(CASE WHEN t.team_id = m.home_team_id THEN m.home_team_goals ELSE m.away_team_goals END)
         - SUM(CASE WHEN t.team_id = m.home_team_id THEN m.away_team_goals ELSE m.home_team_goals END) AS goal_difference
FROM Teams t
JOIN Matches m ON t.team_id IN (m.home_team_id, m.away_team_id)
GROUP BY t.team_id, t.team_name
ORDER BY points DESC, goal_difference DESC, t.team_name;
```

### 复杂度分析

- 时间复杂度：O(n + m)，n 为球队数、m 为比赛数，一次展开连接加分组聚合。
- 空间复杂度：O(n)，每支球队一行结果。

:::

```sql
Create table If Not Exists Teams (team_id int, team_name varchar(20));
Create table If Not Exists Matches (home_team_id int, away_team_id int, home_team_goals int, away_team_goals int);
Truncate table Teams;
insert into Teams (team_id, team_name) values ('1', 'Ajax');

```
