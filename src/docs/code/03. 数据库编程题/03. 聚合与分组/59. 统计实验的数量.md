# 统计实验的数量

> 难度：中等 | 标签：交叉连接、分组聚合、补零 | [LeetCode 原题](https://leetcode.cn/problems/count-the-number-of-experiments/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

实验表 `Experiments`：

```
+-----------------+------+
| Column Name     | Type |
+-----------------+------+
| experiment_id   | int  |
| platform        | enum |
| experiment_name | enum |
+-----------------+------+
experiment_id 是该表的主键。
platform 是枚举类型，取值只能是 ('Android', 'IOS', 'Web') 之一。
experiment_name 是枚举类型，取值只能是 ('Reading', 'Sports', 'Programming') 之一。
每一行记录一次实验的编号、所在平台和实验名称。
```

请编写一个 SQL 查询，统计三个平台上每种实验完成的次数。注意**每一对（平台、实验名称）都必须出现在结果中**，包括次数为 0 的组合。返回顺序不限。

**示例 1：**

```
输入：
Experiments 表：
+---------------+----------+-----------------+
| experiment_id | platform | experiment_name |
+---------------+----------+-----------------+
| 4             | IOS      | Programming     |
| 13            | IOS      | Sports          |
| 14            | Android  | Reading         |
| 8             | Web      | Reading         |
| 12            | Web      | Reading         |
| 18            | Web      | Programming     |
+---------------+----------+-----------------+

输出：
+----------+-----------------+-----------------+
| platform | experiment_name | num_experiments |
+----------+-----------------+-----------------+
| Android  | Reading         | 1               |
| Android  | Sports          | 0               |
| Android  | Programming     | 0               |
| IOS      | Reading         | 0               |
| IOS      | Sports          | 1               |
| IOS      | Programming     | 1               |
| Web      | Reading         | 2               |
| Web      | Sports          | 0               |
| Web      | Programming     | 1               |
+----------+-----------------+-----------------+

解释：安卓平台只做了 1 次 Reading；IOS 平台做了 1 次 Sports 和 1 次 Programming；Web 平台做了 2 次 Reading 和 1 次 Programming，其余组合为 0。
```

## 题解

::: details 点击查看题解

### 思路

输出要求 3 个平台 × 3 种实验的 9 种组合一个都不能少，包括计数为 0 的组合。直接 GROUP BY platform, experiment_name 只能得到出现过的组合，缺的组合会整行消失。

做法是先造模板：两个常量集合（平台、实验名）交叉连接出 9 行，再 LEFT JOIN 原表补上真实数据。COUNT(x.experiment_id) 只统计匹配上的行，没匹配到自然是 0。

这里不能用 COUNT(*)：模板行本身也会被算进去，0 会变成 1。顺序无关紧要，如果想让结果和示例一致，可以用 FIELD() 指定枚举顺序。

### SQL 实现

```sql
WITH P AS (
    SELECT 'Android' AS platform
    UNION ALL SELECT 'IOS'
    UNION ALL SELECT 'Web'
),
E AS (
    SELECT 'Reading' AS experiment_name
    UNION ALL SELECT 'Sports'
    UNION ALL SELECT 'Programming'
)
SELECT p.platform,
       e.experiment_name,
       COUNT(x.experiment_id) AS num_experiments
FROM P AS p
CROSS JOIN E AS e
LEFT JOIN Experiments AS x
       ON x.platform = p.platform
      AND x.experiment_name = e.experiment_name
GROUP BY p.platform, e.experiment_name
ORDER BY FIELD(p.platform, 'Android', 'IOS', 'Web'),
         FIELD(e.experiment_name, 'Reading', 'Sports', 'Programming');
```

### 复杂度分析

- 时间复杂度：O(n)，一次左连接加 9 行常量模板，n 为实验记录数
- 空间复杂度：O(1)，模板固定 9 行

:::
