# 查找无可用副本的书籍

> 难度：简单 | 标签：多表连接、分组聚合、HAVING | [LeetCode 原题](https://leetcode.cn/problems/find-books-with-no-available-copies/)

## 题目描述

表：`library_books`

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| book_id          | int     |
| title            | varchar |
| author           | varchar |
| genre            | varchar |
| publication_year | int     |
| total_copies     | int     |
+------------------+---------+
book_id 是这张表的唯一主键。
每一行包含图书馆中一本书的信息，包括图书馆拥有的副本总数。
```

表：`borrowing_records`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| record_id     | int     |
| book_id       | int     |
| borrower_name | varchar |
| borrow_date   | date    |
| return_date   | date    |
+---------------+---------+
record_id 是这张表的唯一主键。
每一行代表一笔借阅交易并且如果这本书目前被借出并且还没有被归还，return_date 为 NULL。
```

编写一个解决方案以找到 **所有** **当前被借出（未归还） **且图书馆中 **无可用副本** 的书籍。

	- 如果存在一条借阅记录，其 return_date 为 NULL，那么这本书被认为 当前是借出的。

返回结果表按当前借阅者数量 **降序** 排列，然后按书名 **升序** 排列。

结果格式如下所示。

示例：

**输入：**

library_books 表：

+---------+------------------------+------------------+----------+------------------+--------------+
| book_id | title                  | author           | genre    | publication_year | total_copies |
+---------+------------------------+------------------+----------+------------------+--------------+

| 6       | Brave New World        | Aldous Huxley    | Dystopian| 1932             | 4            |
+---------+------------------------+------------------+----------+------------------+--------------+

borrowing_records 表：

+-----------+---------+---------------+-------------+-------------+
| record_id | book_id | borrower_name | borrow_date | return_date |
+-----------+---------+---------------+-------------+-------------+
| 1         | 1       | Alice Smith   | 2024-01-15  | NULL        |
| 2         | 1       | Bob Johnson   | 2024-01-20  | NULL        |

**输出：**

+---------+------------------+---------------+-----------+------------------+-------------------+
| book_id | title            | author        | genre     | publication_year | current_borrowers |
+---------+------------------+---------------+-----------+------------------+-------------------+
| 1       | The Great Gatsby | F. Scott      | Fiction   | 1925             | 3                 |
| 3       | 1984             | George Orwell | Dystopian | 1949             | 1                 |
+---------+------------------+---------------+-----------+------------------+-------------------+

**解释：**

	- The Great Gatsby (book_id = 1)：

		总副本数：3

		- 当前被 Alice Smith，Bob Johnson 和 Grace Miller 借阅（3 名借阅者）

		- 可用副本数：3 - 3 = 0

		- 因为 available_copies = 0，所以被包含

	- 1984 (book_id = 3):

		总副本数：1

		- 当前被 David Brown 借阅（1 名借阅者）

		- 可用副本数：1 - 1 = 0

		- 因为 available_copies = 0，所以被包含

	- 未被包含的书：

		To Kill a Mockingbird (book_id = 2)：总副本数 = 3，当前借阅者 = 2，可用副本 = 1

		- Pride and Prejudice (book_id = 4)：总副本数 = 2，当前借阅者 = 1，可用副本 = 1

		- The Catcher in the Rye (book_id = 5)：总副本数 = 1，当前借阅者 = 0，可用副本 = 1

		- Brave New World (book_id = 6)：总副本数 = 4，当前借阅者 = 1，可用副本 = 3

	- 结果顺序：

		The Great Gatsby 有 3 名当前借阅者，排序第一

		- 1984 有 1 名当前借阅者，排序第二

输出表以 current_borrowers 降序排序，然后以 book_title 升序排序。

## 题解

::: details 点击查看题解

### 思路

「无可用副本」等价于「当前未归还的借阅人数 ≥ 总副本数」，所以需要两件事：把每本书未归还的借阅记录数出来，再和 `total_copies` 比较。

数「当前借出」时，`return_date IS NULL` 这个条件必须放在连接条件上，而不是 `WHERE` 里。如果先在 `WHERE` 过滤再连接，那么「所有副本都已归还」的书会整行消失 —— 本题确实要排除它们，所以结果看起来没错；但一旦想同时保留「有书但无人借」的信息，写法就不可复用了。用 `JOIN ... ON r.book_id = b.book_id AND r.return_date IS NULL` 更准确，含义是「只连接未归还的记录」。

比较放在 `HAVING` 里，因为 `COUNT(*)` 是聚合值，`WHERE` 阶段还拿不到。注意 `ONLY_FULL_GROUP_BY`（MySQL 8 默认开启）要求 `HAVING` 中引用的 `b.total_copies` 出现在 `GROUP BY` 中，否则会直接报错；把 `total_copies` 一起分组即可，它由 `book_id` 唯一决定，不会改变分组粒度。

另外「无可用副本」是 `>=` 而不是 `=`：借阅记录数理论上不会超过副本数，但数据里若出现脏数据（同一副本被重复外借），用 `=` 会漏掉这些书。

替代写法：用 `NOT EXISTS` 子查询统计或 `LEFT JOIN` 后 `IS NULL` 判断，但计数 + `HAVING` 一条语句最直观。

### SQL 实现

```sql
SELECT
    b.book_id,
    b.title,
    b.author,
    b.genre,
    b.publication_year,
    COUNT(*) AS current_borrowers
FROM library_books b
JOIN borrowing_records r
    ON r.book_id = b.book_id
   AND r.return_date IS NULL
GROUP BY
    b.book_id,
    b.title,
    b.author,
    b.genre,
    b.publication_year,
    b.total_copies
HAVING COUNT(*) >= b.total_copies
ORDER BY current_borrowers DESC, b.title ASC;
```

### 复杂度分析

- 时间复杂度：O(n + m)，n、m 分别为书籍数与借阅记录数，一次连接加分组。
- 空间复杂度：O(b)，b 为结果中的书籍数量，用于分组与排序。
