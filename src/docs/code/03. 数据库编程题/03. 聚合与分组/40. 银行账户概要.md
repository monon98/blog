# 银行账户概要

> 难度：中等 | 标签：分组聚合、子查询、CASE 表达式 | [LeetCode 原题](https://leetcode.cn/problems/bank-account-summary/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Users`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| user_name   | varchar |
| credit      | int     |
+-------------+---------+
user_id 是此表中具有唯一值的列。
每一行包含用户的 id、姓名和开户时的初始信用额度。
```

表：`Transactions`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| trans_id      | int     |
| paid_by       | int     |
| paid_to       | int     |
| amount        | int     |
| transacted_on | date    |
+---------------+---------+
trans_id 是此表中具有唯一值的列。
每一行表示一笔转账：`paid_by` 付给 `paid_to`，金额为 `amount`。
`paid_by` 和 `paid_to` 都是 `Users` 表中的 `user_id`。
`amount` 始终为正数。
```

编写一个解决方案，报告每个用户的 `user_id`、`user_name`、当前余额 `credit`，以及余额是否为负（`credit_limit_breached`，负数填 `'Yes'`，否则填 `'No'`）。

当前余额的计算方式：初始额度 **加上** 收到的所有转账金额，**减去** 付出的所有转账金额。

返回结果表按 `user_id` **升序**排列。

**示例 1：**

输入：

```
Users table:
+---------+-----------+--------+
| user_id | user_name | credit |
+---------+-----------+--------+
| 1       | Moustafa  | 100    |
| 2       | Jonathan  | 200    |
| 3       | Winston   | 10000  |
| 4       | Luis      | 800    |
+---------+-----------+--------+

Transactions table:
+----------+---------+---------+--------+---------------+
| trans_id | paid_by | paid_to | amount | transacted_on |
+----------+---------+---------+--------+---------------+
| 1        | 1       | 3       | 400    | 2020-08-01    |
| 2        | 3       | 2       | 500    | 2020-08-02    |
| 3        | 2       | 1       | 200    | 2020-08-03    |
+----------+---------+---------+--------+---------------+
```

输出：

```
+---------+-----------+--------+-----------------------+
| user_id | user_name | credit | credit_limit_breached |
+---------+-----------+--------+-----------------------+
| 1       | Moustafa  | -100   | Yes                   |
| 2       | Jonathan  | 500    | No                    |
| 3       | Winston   | 9900   | No                    |
| 4       | Luis      | 800    | No                    |
+---------+-----------+--------+-----------------------+
```

解释：

- 用户 1：100 - 400 + 200 = -100，余额为负。
- 用户 2：200 + 500 - 200 = 500。
- 用户 3：10000 - 400 - 500 = 9900。
- 用户 4：没有任何交易，余额维持 800。

## 题解

::: details 点击查看题解

### 思路

每笔转账对两个用户分别产生一次「支出」和一次「收入」，所以既不能只按 `paid_by` 聚合，也不能只按 `paid_to` 聚合——一次 join 只能算到一侧。既然收入、支出是两种口径，最直接的写法是用两个标量子查询分别求 `SUM(amount) WHERE paid_to = user_id` 和 `SUM(amount) WHERE paid_by = user_id`，再用初始额度相加相减。

另一种同样常见、且只扫一次交易表的写法是把流水「竖起来」：`SELECT paid_by, -amount FROM Transactions UNION ALL SELECT paid_to, amount FROM Transactions`，然后按用户 `SUM`，最后与 `Users` 连接。数据量大时这种写法只需一次聚合，比两个相关子查询更高效，可以当作进阶替代方案。

这里有个语法坑：`credit_limit_breached` 需要判断余额是否小于 0，而余额是同一层 `SELECT` 里刚算出来的别名，MySQL 不允许在 `SELECT` 的 `CASE` 中引用同级别名，所以要把计算塞进派生表（或 CTE），外层再套 `CASE WHEN credit < 0 THEN 字符串 Yes ELSE 字符串 No END`。

还有两点别忘：用户可能一笔交易都没有（如 Luis），`SUM` 会返回 NULL，要用 `IFNULL(..., 0)` 兜底，否则整行余额会变成 NULL；返回的 Yes / No 大小写要和题面完全一致。

### SQL 实现

```sql
SELECT user_id,
       user_name,
       credit,
       CASE WHEN credit < 0 THEN 'Yes' ELSE 'No' END AS credit_limit_breached
FROM (
    SELECT u.user_id,
           u.user_name,
           u.credit
             + IFNULL((SELECT SUM(t.amount) FROM Transactions t WHERE t.paid_to = u.user_id), 0)
             - IFNULL((SELECT SUM(t.amount) FROM Transactions t WHERE t.paid_by = u.user_id), 0) AS credit
    FROM Users u
) AS balance
ORDER BY user_id;
```

### 复杂度分析

- 时间复杂度：O(n * m) 的最坏情况（相关子查询按用户扫描交易表），n 为交易数、m 为用户数；若改用 UNION ALL 竖表写法则是 O(n + m)。
- 空间复杂度：O(m)，结果集每个用户一行。

```sql
Create table If Not Exists Users (user_id int, user_name varchar(20), credit int)
;
Create table If Not Exists Transactions (trans_id int, paid_by int, paid_to int, amount int, transacted_on date);
Truncate table Users;
insert into Users (user_id, user_name, credit) values ('1', 'Moustafa', '100');
insert into Users (user_id, user_name, credit) values ('2', 'Jonathan', '200');

insert into Users (user_id, user_name, credit) values ('4', 'Luis', '800');

```
