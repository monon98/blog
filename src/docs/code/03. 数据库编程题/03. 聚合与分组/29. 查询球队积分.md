# 查询球队积分

> 难度：中等 | 标签：多表连接、条件聚合 | [LeetCode 原题](https://leetcode.cn/problems/team-scores-in-football-tournament/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Teams` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| team_id     | int     |
| team_name   | varchar |
+-------------+---------+
team_id 是该表的主键，每一行是一支参赛球队。
```

`Matches` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| match_id    | int     |
| host_team   | int     |
| guest_team  | int     |
| host_goals  | int     |
| guest_goals | int     |
+-------------+---------+
match_id 是该表的主键。
host_team 与 guest_team 分别是主队和客队的 team_id，host_goals 与 guest_goals 是对应进球数。
```

积分规则：胜一场得 3 分，平一场得 1 分，负一场得 0 分。

编写一个 SQL 查询，统计每支球队的总积分，返回列 `team_id`、`team_name`、`num_points`，按 `num_points` **降序** 排列，积分相同时按 `team_id` **升序** 排列。**没有参加任何比赛的球队也要出现在结果中，积分为 0。**

**示例 1：**

```
输入：
Teams table:
+---------+-------------+
| team_id | team_name   |
+---------+-------------+
| 10      | Leetcode FC |
| 20      | NewYork FC  |
| 30      | Atlanta FC  |
| 40      | Chicago FC  |
| 50      | Toronto FC  |
+---------+-------------+
Matches table:
+----------+-----------+------------+------------+-------------+
| match_id | host_team | guest_team | host_goals | guest_goals |
+----------+-----------+------------+------------+-------------+
| 1        | 10        | 20         | 3          | 0           |
| 2        | 30        | 10         | 2          | 2           |
| 3        | 10        | 50         | 5          | 1           |
| 4        | 20        | 30         | 1          | 0           |
| 5        | 50        | 30         | 1          | 0           |
+----------+-----------+------------+------------+-------------+
输出：
+---------+-------------+------------+
| team_id | team_name   | num_points |
+---------+-------------+------------+
| 10      | Leetcode FC | 7          |
| 20      | NewYork FC  | 3          |
| 50      | Toronto FC  | 3          |
| 30      | Atlanta FC  | 1          |
| 40      | Chicago FC  | 0          |
+---------+-------------+------------+
解释：
10 号队：胜 20 号、胜 50 号、平 30 号，3 + 3 + 1 = 7 分。
20 号队：负 10 号、胜 30 号，3 分。
50 号队：负 10 号、胜 30 号，3 分。
30 号队：平 10 号、负 20 号、负 50 号，1 分。
40 号队没有比赛，0 分。
```

## 题解

::: details 点击查看题解

### 思路

一支球队的积分散落在 `Matches` 的两列里：它可能作为 `host_team` 出现，也可能作为 `guest_team` 出现，所以必须从 `Teams` 出发做 `LEFT JOIN`，连接条件写成 `t.team_id IN (m.host_team, m.guest_team)`，这样每场比赛会为该场的两支球队各产生一行「参赛记录」，一支球队每场比赛只会匹配到一次。

得分判定用 `CASE` 分三种情况：作为主队且主队进球多、作为客队且客队进球多都是 3 分；双方进球相同是 1 分；其余 0 分。注意平局要在前两个「获胜」分支之后判断，否则平局会被误判成主队获胜或客队获胜。由于用 `LEFT JOIN` 保留了没有比赛的球队，其连接行所有 `m.*` 为 NULL，`CASE` 落到 `ELSE 0`，`SUM` 得到 0，不必额外 `IFNULL`（用 `SUM` 时 NULL 行会被算作 0；若用 `COUNT` 则需注意）。

也可以用 `UNION ALL` 把比赛拆成「主队视角」和「客队视角」两张事实表，各自算分后再合并汇总，思路更直白但要多写一段。排序时按别名 `num_points DESC, team_id ASC` 即可，题目要求积分相同按 team_id 升序。

### SQL 实现

```sql
SELECT t.team_id,
       t.team_name,
       SUM(CASE
               WHEN m.host_team = t.team_id AND m.host_goals > m.guest_goals THEN 3
               WHEN m.guest_team = t.team_id AND m.guest_goals > m.host_goals THEN 3
               WHEN m.host_goals = m.guest_goals THEN 1
               ELSE 0
           END) AS num_points
FROM Teams t
LEFT JOIN Matches m
       ON t.team_id IN (m.host_team, m.guest_team)
GROUP BY t.team_id, t.team_name
ORDER BY num_points DESC, t.team_id ASC;
```

### 复杂度分析

- 时间复杂度：O(n + m)，n 为球队数、m 为比赛数，连接后行数为 2m，聚合接近线性。
- 空间复杂度：O(n)，用于保存每支球队的积分累加值。
