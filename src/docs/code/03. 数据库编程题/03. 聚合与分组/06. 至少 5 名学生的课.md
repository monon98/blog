# 至少 5 名学生的课

> 难度：简单 | 标签：分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/classes-with-at-least-5-students/)

## 题目描述

表: `Courses`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| student     | varchar |
| class       | varchar |
+-------------+---------+
(student, class)是该表的主键（不同值的列的组合）。
该表的每一行表示学生的名字和他们注册的课程。
```

查询 **至少有 5 个学生** 的所有课程。

以 **任意顺序 **返回结果表。

结果格式如下所示。

示例 1:

```
输入:
Courses 表:
+---------+----------+
| student | class    |
+---------+----------+
| A       | Math     |
| B       | English  |
| C       | Math     |
| D       | Biology  |
| E       | Math     |
| F       | Computer |
| G       | Math     |
| H       | Math     |
| I       | Math     |
+---------+----------+
输出:
+---------+
| class   |
+---------+
| Math    |
+---------+
解释:
-数学课有 6 个学生，所以我们包括它。
-英语课有 1 名学生，所以我们不包括它。
-生物课有 1 名学生，所以我们不包括它。
-计算机课有 1 个学生，所以我们不包括它。
```

## 题解

::: details 点击查看题解

### 思路

这是一道最典型的「分组 + 过滤」题：先按 `class` 把行聚合成每门课的学生数，再用 `HAVING` 筛出人数不少于 5 的课程。关键在于区分 `WHERE` 和 `HAVING`——`WHERE` 在分组前过滤行，无法使用聚合结果；`HAVING` 才能对 `COUNT(...)` 这类聚合值做条件判断。若误写成 `WHERE COUNT(student) >= 5`，MySQL 会直接报错。

由于 `(student, class)` 是主键，同一门课里不会出现重复学生，所以 `COUNT(student)` 与 `COUNT(DISTINCT student)` 等价，直接计数即可。输出只需要 `class` 一列，注意不要把 `COUNT` 也查出来（题目要求的列名只有 `class`）。

替代写法：因为本题不需要先过滤行，用窗口函数 `COUNT(*) OVER (PARTITION BY class)` 再在外层筛 `>= 5` 也能通过，但对这种纯聚合场景，`GROUP BY + HAVING` 是最直观高效的写法。

### SQL 实现

```sql
SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(student) >= 5;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为表行数，一次哈希分组即可完成。
- 空间复杂度：O(k)，k 为课程种类数，分组哈希表的开销。
