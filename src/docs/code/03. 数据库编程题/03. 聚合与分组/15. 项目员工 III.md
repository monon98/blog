# 项目员工 III

> 难度：中等 | 标签：窗口函数、多表连接 | [LeetCode 原题](https://leetcode.cn/problems/project-employees-iii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Project` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| project_id  | int     |
| employee_id | int     |
+-------------+---------+
主键为 (project_id, employee_id)。
employee_id 是 Employee 表的外键。
每一行表示 employee_id 的员工正在 project_id 的项目上工作。
```

`Employee` 表：

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| employee_id      | int     |
| name             | varchar |
| experience_years | int     |
+------------------+---------+
主键是 employee_id。
每一行包含一个员工的信息。
```

编写解决方案，报告每个项目中 **经验最丰富** 的员工（`experience_years` 最大者）。如果某个项目里经验最多的员工有多人（并列），**全部返回**。结果包含 `project_id` 和 `employee_id` 两列，以任意顺序返回。

**示例 1:**

```
输入:
Project 表:
+-------------+-------------+
| project_id  | employee_id |
+-------------+-------------+
| 1           | 1           |
| 1           | 2           |
| 1           | 3           |
| 2           | 1           |
| 2           | 4           |
+-------------+-------------+
Employee 表:
+-------------+--------+------------------+
| employee_id | name   | experience_years |
+-------------+--------+------------------+
| 1           | Khaled | 3                |
| 2           | Ali    | 2                |
| 3           | John   | 3                |
| 4           | Doe    | 2                |
+-------------+--------+------------------+
输出:
+-------------+---------------+
| project_id  | employee_id   |
+-------------+---------------+
| 1           | 1             |
| 1           | 3             |
| 2           | 1             |
+-------------+---------------+
解释:
项目 1 中员工 1 和 3 的经验年限并列最多（都是 3 年）。
项目 2 中员工 1 的经验年限最多（3 年）。
```

## 题解

::: details 点击查看题解

### 思路

先把 `Project` 与 `Employee` 按 `employee_id` 连接，拿到每个「项目 × 员工」的经验年限，然后在每个项目内部按年限降序排名。排名必须用 `RANK()` 而不是 `ROW_NUMBER()` 或 `DENSE_RANK()` 的变通：`RANK()` 对并列值给出相同名次（1, 1, 3），筛 `rk = 1` 时能保留所有并列者；`ROW_NUMBER()` 会强行把并列者排成 1、2，导致只返回一个人，正是本题的头号易错点。

窗口按 `PARTITION BY project_id` 分区、`ORDER BY experience_years DESC` 排序，分区保证排名只在项目内部进行。外层查询从子结果里筛出名次为 1 的行即可。注意别在 `ORDER BY` 里加 `employee_id` 做次级排序——那不会影响 `RANK` 的并列语义，但若误用 `ROW_NUMBER` 就会破坏并列。

替代写法：不使用窗口函数时，可用相关子查询 `experience_years = (SELECT MAX(...) FROM Project p2 JOIN Employee e2 ... WHERE p2.project_id = p.project_id)`，或先分组求 `MAX` 再连接回来，两种写法都能正确保留并列，代价是多一次扫描。

### SQL 实现

```sql
SELECT project_id, employee_id
FROM (
    SELECT p.project_id,
           p.employee_id,
           RANK() OVER (
               PARTITION BY p.project_id
               ORDER BY e.experience_years DESC
           ) AS rk
    FROM Project p
    JOIN Employee e
        ON p.employee_id = e.employee_id
) t
WHERE rk = 1;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为项目记录数，连接接近线性，窗口排序主导。
- 空间复杂度：O(n)，窗口分区与排序的额外开销。
