# 查找重复的电子邮箱

> 难度：简单 | 标签：分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/duplicate-emails/)

## 题目描述

表: `Person`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| email       | varchar |
+-------------+---------+
id 是该表的主键（具有唯一值的列）。
此表的每一行都包含一封电子邮件。电子邮件不包含大写字母。
```

编写解决方案来报告所有重复的电子邮件。 请注意，可以保证电子邮件字段不为 NULL。

以 **任意顺序 **返回结果表。

结果格式如下例。

**示例 1:**

```
输入:
Person 表:
+----+---------+
| id | email   |
+----+---------+
| 1  | a@b.com |
| 2  | c@d.com |
| 3  | a@b.com |
+----+---------+
输出:
+---------+
| Email   |
+---------+
| a@b.com |
+---------+
解释: a@b.com 出现了两次。
```

## 题解

::: details 点击查看题解

### 思路

重复的定义是「同一个 `email` 出现了不止一次」，所以最直接的思路就是按 `email` 分组数个数，再把个数大于 1 的组挑出来。`GROUP BY email HAVING COUNT(*) > 1` 正好表达了这个语义——`HAVING` 是分组后过滤的唯一正确位置，写成 `WHERE COUNT(*) > 1` 会直接语法报错。

两个细节：一是题目只要 `Email` 一列（列名大小写按示例写成 `Email` 即可），不需要 `id`；二是字段保证非 NULL，所以 `COUNT(*)` 与 `COUNT(email)` 等价，不用操心 NULL 被计数规则忽略。替代写法：自连接 `Person a JOIN Person b ON a.email = b.email AND a.id < b.id` 再 `DISTINCT`，或窗口函数 `COUNT(*) OVER (PARTITION BY email)` 筛 `> 1`——都能通过，但分组 + `HAVING` 是最短也最易读的。

### SQL 实现

```sql
SELECT email AS Email
FROM Person
GROUP BY email
HAVING COUNT(*) > 1;
```

### 复杂度分析

- 时间复杂度：O(n log n)，分组哈希/排序主导，n 为记录数。
- 空间复杂度：O(k)，k 为不同邮箱数。

:::

```sql
Create table If Not Exists Person (id int, email varchar(255));
Truncate table Person;
insert into Person (id, email) values ('1', 'a@b.com');
insert into Person (id, email) values ('2', 'c@d.com');
insert into Person (id, email) values ('3', 'a@b.com');
```
