# 产品销售分析 II

> 难度：简单 | 标签：分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/product-sales-analysis-ii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Sales` 表：

```
+-------------+-------+
| Column Name | Type  |
+-------------+-------+
| sale_id     | int   |
| product_id  | int   |
| year        | int   |
| quantity    | int   |
| price       | int   |
+-------------+-------+
sale_id 是该表的主键。
product_id 是 Product 表的外键。
注意：price 是单价。
```

`Product` 表：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| product_id   | int     |
| product_name | varchar |
+--------------+---------+
product_id 是该表的主键。
```

编写解决方案，报告每个产品 id 的 **总销售数量**，结果包含 `product_id` 和 `total_quantity` 两列。只统计有销售记录的产品，以任意顺序返回结果表。

**示例 1:**

```
输入:
Sales 表:
+---------+------------+------+----------+-------+
| sale_id | product_id | year | quantity | price |
+---------+------------+------+----------+-------+
| 1       | 100        | 2008 | 10       | 5000  |
| 2       | 100        | 2009 | 12       | 5000  |
| 7       | 200        | 2011 | 15       | 9000  |
+---------+------------+------+----------+-------+
Product 表:
+------------+--------------+
| product_id | product_name |
+------------+--------------+
| 100        | Nokia        |
| 200        | Apple        |
| 300        | Samsung      |
+------------+--------------+
输出:
+--------------+----------------+
| product_id   | total_quantity |
+--------------+----------------+
| 100          | 22             |
| 200          | 15             |
+--------------+----------------+
解释:
产品 100 卖出 10 + 12 = 22 件，产品 200 卖出 15 件。
产品 300 没有任何销售记录，不出现在结果中。
```

## 题解

::: details 点击查看题解

### 思路

按 `product_id` 分组求和即可：`SUM(quantity)` 得到每个产品的总销量。题目只要求「有销售记录的产品」，所以直接 `GROUP BY Sales.product_id`，不需要连接 `Product` 表，也没必要用 `LEFT JOIN` 补出零销量的产品（那样反而要额外处理 `NULL`）。

易错点一是把 `SUM(quantity)` 和 `SUM(price)` 搞混：`price` 是单价，销量统计要用 `quantity`。易错点二是误以为需要去重——`sale_id` 是主键，每行就是一次销售，直接累加即可，加 `DISTINCT` 反而会把同数量的多笔订单错误合并。

虽然 `Product` 表在本查询里用不上，但如果题目改成「输出产品名」或要求列出零销量产品，就需要 `LEFT JOIN Product`：`SELECT p.product_id, IFNULL(SUM(s.quantity), 0) ... FROM Product p LEFT JOIN Sales s ON ... GROUP BY p.product_id`。

### SQL 实现

```sql
SELECT product_id, SUM(quantity) AS total_quantity
FROM Sales
GROUP BY product_id;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为销售记录数，一次分组累加。
- 空间复杂度：O(k)，k 为有销售的产品数。

:::
