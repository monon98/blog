# 面试中被录取的候选人

> 难度：中等 | 标签：多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/accepted-candidates-from-the-interviews/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

候选人表 `Candidates`：

```
+--------------+----------+
| Column Name  | Type     |
+--------------+----------+
| candidate_id | int      |
| name         | varchar  |
| years_of_exp | int      |
| interview_id | int      |
+--------------+----------+
candidate_id 是该表的主键。
每一行表示候选人的姓名、工作年限以及对应的面试编号。
```

面试轮次表 `Rounds`：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| interview_id | int  |
| round_id     | int  |
| score        | int  |
+--------------+------+
(interview_id, round_id) 是该表的主键。
每一行表示某场面试中某一轮的得分。
```

请编写一个解决方案，找出**至少有两年工作经验**、且**面试分数之和严格大于 15** 的候选人 ID。返回顺序不限。

**示例 1：**

```
输入：
Candidates 表：
+--------------+---------+--------------+--------------+
| candidate_id | name    | years_of_exp | interview_id |
+--------------+---------+--------------+--------------+
| 11           | Atticus | 1            | 101          |
| 9            | Ruben   | 6            | 104          |
| 6            | Aliza   | 10           | 109          |
| 8            | Alfredo | 0            | 107          |
+--------------+---------+--------------+--------------+

Rounds 表：
+--------------+----------+-------+
| interview_id | round_id | score |
+--------------+----------+-------+
| 109          | 3        | 4     |
| 101          | 2        | 8     |
| 109          | 4        | 1     |
| 107          | 1        | 3     |
| 104          | 3        | 6     |
| 109          | 1        | 4     |
| 104          | 4        | 7     |
| 104          | 1        | 2     |
| 109          | 2        | 1     |
| 104          | 2        | 7     |
| 107          | 2        | 3     |
| 101          | 1        | 8     |
+--------------+----------+-------+

输出：
+--------------+
| candidate_id |
+--------------+
| 9            |
+--------------+

解释：候选人 11 总分 16 但只有 1 年经验；候选人 9 总分 22、6 年经验，入选；候选人 6 总分 10，分数不足；候选人 8 总分 6、0 年经验。
```

## 题解

::: details 点击查看题解

### 思路

录取条件分别作用在不同层级：工作年限 years_of_exp >= 2 是候选人级别的行过滤，放在 WHERE；总分 > 15 是分组后的聚合过滤，必须放在 HAVING。

先按 interview_id 把 Candidates 和 Rounds 连起来，再按 candidate_id 分组，SUM(score) 才是这名候选人所有轮次的总分。

常见错误是把 SUM(score) > 15 也塞进 WHERE（聚合函数不能出现在 WHERE 里），或者在 SELECT 里带上 name 却没加进 GROUP BY（ONLY_FULL_GROUP_BY 会直接报错）。

### SQL 实现

```sql
SELECT c.candidate_id
FROM Candidates AS c
JOIN Rounds AS r ON r.interview_id = c.interview_id
WHERE c.years_of_exp >= 2
GROUP BY c.candidate_id
HAVING SUM(r.score) > 15
ORDER BY c.candidate_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，连接后分组排序，n 为轮次记录数
- 空间复杂度：O(k)，k 为候选人数量

:::
