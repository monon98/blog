# 自行车的最后使用时间

> 难度：简单 | 标签：分组聚合、排序 | [LeetCode 原题](https://leetcode.cn/problems/bikes-last-time-used/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

骑行表 `Bikes`：

```
+-------------+----------+
| 列名        | 类型     |
+-------------+----------+
| ride_id     | int      |
| bike_number | int      |
| start_time  | datetime |
| end_time    | datetime |
+-------------+----------+
ride_id 是该表的主键。
每一行表示一次骑行记录，包含骑行编号、自行车编号、起始时间与结束时间。
```

请编写一个解决方案，找出每辆自行车**最近一次被使用**的时间。结果表按最近被使用的时间从晚到早排序。

**示例 1：**

```
输入：
Bikes 表：
+---------+-------------+---------------------+---------------------+
| ride_id | bike_number | start_time          | end_time            |
+---------+-------------+---------------------+---------------------+
| 1       | W00576      | 2012-03-25 11:30:00 | 2012-03-25 12:40:00 |
| 2       | W00300      | 2012-03-25 10:30:00 | 2012-03-25 10:50:00 |
| 3       | W00455      | 2012-03-26 14:30:00 | 2012-03-26 17:40:00 |
| 4       | W00455      | 2012-03-25 12:30:00 | 2012-03-25 13:40:00 |
| 5       | W00576      | 2012-03-25 08:10:00 | 2012-03-25 09:10:00 |
| 6       | W00576      | 2012-03-28 02:30:00 | 2012-03-28 02:50:00 |
+---------+-------------+---------------------+---------------------+

输出：
+-------------+---------------------+
| bike_number | end_time            |
+-------------+---------------------+
| W00576      | 2012-03-28 02:50:00 |
| W00455      | 2012-03-26 17:40:00 |
| W00300      | 2012-03-25 10:50:00 |
+-------------+---------------------+

解释：W00576 有三次骑行，最近一次是 ride_id 6，结束于 2012-03-28 02:50:00；
W00455 最近一次是 ride_id 3，结束于 2012-03-26 17:40:00；
W00300 只有一次骑行，结束于 2012-03-25 10:50:00。
```

## 题解

::: details 点击查看题解

### 思路

每辆车可能有多条骑行记录，题目只关心「最后一次被使用」的时刻，也就是该车所有记录里最大的 end_time。

分组键是 bike_number，GROUP BY 后直接 MAX(end_time) 即可，不需要回表取 ride_id 或 start_time。

最后按最近使用时间降序输出。注意别用 ride_id 或 start_time 的最大值代替 end_time——ride_id 自增通常与时间同序，但题目并不保证这一点。

### SQL 实现

```sql
SELECT bike_number,
       MAX(end_time) AS end_time
FROM Bikes
GROUP BY bike_number
ORDER BY end_time DESC;
```

### 复杂度分析

- 时间复杂度：O(n log n)，分组取最大值后排序，n 为骑行记录数
- 空间复杂度：O(k)，k 为自行车数量

:::
