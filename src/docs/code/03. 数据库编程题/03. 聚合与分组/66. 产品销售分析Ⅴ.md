# 产品销售分析Ⅴ

> 难度：简单 | 标签：多表连接、分组聚合、排序 | [LeetCode 原题](https://leetcode.cn/problems/product-sales-analysis-v/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

销售表 `Sales`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| sale_id     | int  |
| product_id  | int  |
| user_id     | int  |
| quantity    | int  |
+-------------+------+
sale_id 唯一。
product_id 是指向 Product 表的外键。
每一行表示某用户购买某个产品的数量。
```

产品表 `Product`：

```
+------------+------+
| Column Name| Type |
+------------+------+
| product_id | int  |
| price      | int  |
+------------+------+
product_id 唯一。
每一行表示某个产品的单价。
```

请编写一个解决方案，获取每个用户的消费额。结果按消费额 `spending` **递减** 排序；消费额相同时按 `user_id` **递增** 排序。

**示例 1：**

```
输入：
Sales 表：
+---------+------------+---------+----------+
| sale_id | product_id | user_id | quantity |
+---------+------------+---------+----------+
| 1       | 1          | 101     | 10       |
| 2       | 2          | 101     | 1        |
| 3       | 3          | 102     | 3        |
| 4       | 3          | 102     | 2        |
| 5       | 2          | 103     | 3        |
+---------+------------+---------+----------+

Product 表：
+------------+-------+
| product_id | price |
+------------+-------+
| 1          | 10    |
| 2          | 25    |
| 3          | 15    |
+------------+-------+

输出：
+---------+----------+
| user_id | spending |
+---------+----------+
| 101     | 125      |
| 102     | 75       |
| 103     | 75       |
+---------+----------+

解释：用户 101 消费 10 * 10 + 1 * 25 = 125；用户 102 消费 3 * 15 + 2 * 15 = 75；用户 103 消费 3 * 25 = 75。102 与 103 金额相同，按 user_id 升序排列。
```

## 题解

::: details 点击查看题解

### 思路

Sales 只有购买数量，单价存在 Product 表，必须按 product_id 关联后才能算出这笔订单的金额 quantity * price。

聚合粒度是用户：GROUP BY user_id 之后 SUM(quantity * price) 就是该用户的总消费额。

排序有两个键，先按消费额降序，再按 user_id 升序打破平局；MySQL 允许在 ORDER BY 里直接引用 SELECT 中的别名 spending。

### SQL 实现

```sql
SELECT s.user_id,
       SUM(s.quantity * p.price) AS spending
FROM Sales AS s
JOIN Product AS p ON p.product_id = s.product_id
GROUP BY s.user_id
ORDER BY spending DESC, s.user_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，连接后分组排序，n 为销售记录数
- 空间复杂度：O(k)，k 为用户数

:::
