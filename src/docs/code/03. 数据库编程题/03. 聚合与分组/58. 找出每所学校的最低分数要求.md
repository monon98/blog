# 找出每所学校的最低分数要求

> 难度：中等 | 标签：左连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/find-cutoff-score-for-each-school/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

学校表 `Schools`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| school_id   | int  |
| capacity    | int  |
+-------------+------+
school_id 唯一，表示学校编号。
capacity 表示学校能够接纳的最大学生数量。
```

成绩表 `Exam`：

```
+---------------+------+
| Column Name   | Type |
+---------------+------+
| score         | int  |
| student_count | int  |
+---------------+------+
score 唯一。
每一行表示有 student_count 名学生的成绩至少达到了 score 分。
```

每年学校都会公布申请所需的最低分数要求，并遵守三条规则：

1. 学校希望确保即使**每一个**满足分数要求的学生都申请该学校，学校也有足够的容量接纳；
2. 学校也希望**尽可能多**的学生能申请该学校；
3. 学校**必须**使用 `Exam` 表中出现过的 score 作为分数要求。

请报告每所学校的**最低分数要求**。如果有多个 score 都满足条件，选择其中**最小**的一个；如果数据不足以确定分数线，输出 `-1`。返回顺序不限。

**示例 1：**

```
输入：
Schools 表：
+-----------+----------+
| school_id | capacity |
+-----------+----------+
| 11        | 151      |
| 5         | 48       |
| 9         | 9        |
| 10        | 99       |
+-----------+----------+

Exam 表：
+-------+---------------+
| score | student_count |
+-------+---------------+
| 975   | 10            |
| 966   | 60            |
| 844   | 76            |
| 749   | 76            |
| 744   | 100           |
+-------+---------------+

输出：
+-----------+-------+
| school_id | score |
+-----------+-------+
| 5         | 975   |
| 9         | -1    |
| 10        | 749   |
| 11        | 744   |
+-----------+-------+

解释：
学校 5（容量 48）：只有 975 分档的 10 人不超过容量，输出 975；
学校 10（容量 99）：844 与 749 都只对应 76 人，取更小的 749；
学校 11（容量 151）：所有分档人数都不超过容量，取最小的 744；
学校 9（容量 9）：没有任何分档人数不超过 9，数据不足，输出 -1。
```

## 题解

::: details 点击查看题解

### 思路

关键在读懂 Exam.student_count：它表示「至少拿到该分数」的学生人数（各分数档之间已经包含关系，不是增量）。所以学校把分数线定在某个 score 时，最多会收到 student_count 份申请。

因此可行的分数线满足 student_count <= capacity；在可行分数里要选最低的那个——分数越低申请人数越多，既保证不超出容量，又能招到尽可能多的学生。

写法上用 Schools 左连 Exam（容量够得上的那些分数档），再按学校分组取 MIN(score)；整组都是 NULL 说明数据不足以确定分数线，用 COALESCE 补 -1。注意别把 student_count 当成累加人数再用窗口 SUM，那样会算错。

### SQL 实现

```sql
SELECT s.school_id,
       COALESCE(MIN(e.score), -1) AS score
FROM Schools AS s
LEFT JOIN Exam AS e ON e.student_count <= s.capacity
GROUP BY s.school_id
ORDER BY s.school_id;
```

### 复杂度分析

- 时间复杂度：O(n·m)，左连接最多产生 学校数 × 分数档数 行
- 空间复杂度：O(k)，k 为学校数

:::
