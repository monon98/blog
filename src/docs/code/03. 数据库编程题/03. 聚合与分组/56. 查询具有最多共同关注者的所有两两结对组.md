# 查询具有最多共同关注者的所有两两结对组

> 难度：中等 | 标签：自连接、分组聚合、窗口函数 | [LeetCode 原题](https://leetcode.cn/problems/all-the-pairs-with-the-maximum-number-of-common-followers/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

关系表 `Relations`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| user_id     | int  |
| follower_id | int  |
+-------------+------+
(user_id, follower_id) 是该表的主键。
每一行表示 follower_id 这个用户关注了 user_id 这个用户，即 user_id 是博主、follower_id 是他的关注者。
```

请编写一个查询，找出**共同关注者数量最多**的所有两两结对组。换句话说，如果若干对用户的共同关注者数量并列最大，就把这些结对组全部返回。

结果表每行包含 `user1_id` 和 `user2_id`，其中必须满足 `user1_id < user2_id`。返回顺序不限。

**示例 1：**

```
输入：
Relations 表：
+---------+-------------+
| user_id | follower_id |
+---------+-------------+
| 1       | 3           |
| 2       | 3           |
| 7       | 3           |
| 1       | 4           |
| 2       | 4           |
| 7       | 4           |
| 1       | 5           |
| 2       | 6           |
| 7       | 5           |
+---------+-------------+

输出：
+----------+----------+
| user1_id | user2_id |
+----------+----------+
| 1        | 7        |
+----------+----------+

解释：
用户 1 和用户 2 有 2 个共同关注者（3 和 4）；
用户 1 和用户 7 有 3 个共同关注者（3、4 和 5）；
用户 2 和用户 7 有 2 个共同关注者（3 和 4）。
最大共同关注者数量是 3，只有 (1, 7) 这一对满足，且输出时保持 user1_id < user2_id。
```

## 题解

::: details 点击查看题解

### 思路

共同关注者的本质是：同一个 follower_id 同时出现在两个用户的行里。把 Relations 自连接、只按 follower_id 相等配对，每一对匹配就代表「这个关注者同时关注了这一对用户」，按用户对计数即可。

必须加上 r1.user_id < r2.user_id 这个条件：一方面避免 (1,7) 和 (7,1) 各算一次，另一方面排除用户和自己配对（自己和自己当然有全部共同关注者）。

题目要的是「所有并列最大值」，用 RANK() OVER (ORDER BY COUNT(*) DESC) 给用户对排名后筛 rk = 1 最直观，还能省掉 HAVING COUNT(*) = (SELECT MAX(...)) 那种需要重复扫描子查询的写法。

### SQL 实现

```sql
WITH Pairs AS (
    SELECT r1.user_id AS user1_id,
           r2.user_id AS user2_id,
           RANK() OVER (ORDER BY COUNT(*) DESC) AS rk
    FROM Relations AS r1
    JOIN Relations AS r2
      ON r1.follower_id = r2.follower_id
     AND r1.user_id < r2.user_id
    GROUP BY r1.user_id, r2.user_id
)
SELECT user1_id, user2_id
FROM Pairs
WHERE rk = 1;
```

### 复杂度分析

- 时间复杂度：O(f)，f 为自连接产出的行数，最坏 O(r²)，r 为关系行数
- 空间复杂度：O(p)，p 为出现过的用户对数量

:::
