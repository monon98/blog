# 换座位

> 难度：中等 | 标签：条件表达式、子查询 | [LeetCode 原题](https://leetcode.cn/problems/exchange-seats/)

## 题目描述

表: `Seat`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| student     | varchar |
+-------------+---------+
id 是该表的主键（唯一值）列。
该表的每一行都表示学生的姓名和 ID。
ID 序列始终从 1 开始并连续增加。
```

编写解决方案来交换每两个连续的学生的座位号。如果学生的数量是奇数，则最后一个学生的id不交换。

按 `id` **升序** 返回结果表。

查询结果格式如下所示。

**示例 1:**

```
输入:
Seat 表:
+----+---------+
| id | student |
+----+---------+
| 1  | Abbot   |
| 2  | Doris   |
| 3  | Emerson |
| 4  | Green   |
| 5  | Jeames  |
+----+---------+
输出:
+----+---------+
| id | student |
+----+---------+
| 1  | Doris   |
| 2  | Abbot   |
| 3  | Green   |
| 4  | Emerson |
| 5  | Jeames  |
+----+---------+
解释:
请注意，如果学生人数为奇数，则不需要更换最后一名学生的座位。
```

## 题解

::: details 点击查看题解

### 思路

交换相邻两人的座位，本质是给每一行重新编号：偶数 id 的学生坐到 `id - 1`，奇数 id 的学生坐到 `id + 1`；但当奇数 id 正好是全表最大 id（人数为奇数时的最后一行）时不能 +1，否则越界，此时 id 原样保留。所以核心就是一个 CASE：`id % 2 = 0 → id - 1`，`id % 2 = 1 且 id < MAX(id) → id + 1`，否则 `id`。

`MAX(id)` 只有一个标量值，在 SELECT 中用子查询 `(SELECT MAX(id) FROM Seat)` 取即可（MySQL 允许标量子查询出现在表达式里）。由于 id 连续从 1 递增，「最后一个奇数位」等价于 `id = MAX(id)`。

易错点一：排序必须按**输出的新 id** 升序——本写法每行输出自己的 student 配新 id，直接 `ORDER BY id` 在 MySQL 中有歧义（可能解析成原表列），稳妥做法是包一层派生表后按外层 id 排。易错点二：漏掉最后一行的特判，5 人的例子会产出 id=6 的越界行。替代写法：用窗口函数 `LEAD(student) OVER (ORDER BY id)` 取下一位同学，奇数末行取自身，也能做，代码略长。

### SQL 实现

```sql
SELECT id, student
FROM (
    SELECT CASE
               WHEN id % 2 = 0 THEN id - 1
               WHEN id < (SELECT MAX(id) FROM Seat) THEN id + 1
               ELSE id
           END AS id,
           student
    FROM Seat
) t
ORDER BY id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为座位数，排序主导（标量子查询仅计算一次）。
- 空间复杂度：O(n)，派生表暂存全部行。

:::
