# 班级表现

> 难度：中等 | 标签：分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/class-performance/)

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

## 题目描述

表：`Scores`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| student_id   | int     |
| student_name | varchar |
| assignment1  | int     |
| assignment2  | int     |
| assignment3  | int     |
+--------------+---------+
student_id 是这张表的唯一主键。
这张表包含学生的 ID、姓名以及三次作业的成绩。
```

编写一个解决方案，计算学生 **总分**（三次作业之和）中的 **最高总分** 与 **最低总分** 之间的 **差值**。

返回结果表 **无顺序要求**。

结果格式如下所示。

示例：

**输入：**

Scores 表：

+------------+--------------+-------------+-------------+-------------+
| student_id | student_name | assignment1 | assignment2 | assignment3 |
+------------+--------------+-------------+-------------+-------------+
| 309        | Owen         | 88          | 47          | 87          |
| 321        | Claire       | 98          | 95          | 37          |
| 338        | Julian       | 100         | 64          | 43          |
| 423        | Peyton       | 60          | 44          | 47          |
| 896        | David        | 32          | 37          | 50          |
| 235        | Camila       | 31          | 53          | 69          |
+------------+--------------+-------------+-------------+-------------+

**输出：**

+---------------------+
| difference_in_score |
+---------------------+
| 111                 |
+---------------------+

**解释：**

	- student_id 309 总分 88 + 47 + 87 = 222

	- student_id 321 总分 98 + 95 + 37 = 230

	- student_id 338 总分 100 + 64 + 43 = 207

	- student_id 423 总分 60 + 44 + 47 = 151

	- student_id 896 总分 32 + 37 + 50 = 119

	- student_id 235 总分 31 + 53 + 69 = 153

student_id 321 总分最高（230），student_id 896 总分最低（119），二者之差为 111。

## 题解

::: details 点击查看题解

### 思路

结果只有一行一个数，不需要 `GROUP BY`：把每行的总分视为一个表达式 `assignment1 + assignment2 + assignment3`，对它分别求 `MAX` 与 `MIN` 再相减即可。两个聚合函数作用在同一个表达式上，一次全表扫描同时算出，是最直接的写法。

易错点是顺序：先算「每人总分」再取极值，而不是先取各科极值再相加——`MAX(a1) + MAX(a2) + MAX(a3)` 找的是三科各自最高分拼成的「总分」（本例为 100+95+69=264），对应的并不是任何真实学生，结果就错了；`MAX(a1+a2+a3)` 才是学生总分的最大值。

替代写法：用子查询先物化 `total_score` 列再 `MAX - MIN`，语义相同、多一层嵌套；或 `SELECT MAX(t) - MIN(t) FROM (SELECT a1+a2+a3 AS t FROM Scores) x`。列别名 `difference_in_score` 按输出格式给即可。另注意空值语义：聚合函数自动跳过 NULL，若某次作业为 NULL 该表达式结果为 NULL，MAX/MIN 都会忽略这行——本题数据无 NULL，无需额外处理。

### SQL 实现

```sql
SELECT MAX(assignment1 + assignment2 + assignment3)
     - MIN(assignment1 + assignment2 + assignment3) AS difference_in_score
FROM Scores;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为学生数，单次扫描同时维护最大最小值。
- 空间复杂度：O(1)，只输出一行标量。

:::
