# 查找每个州的城市

> 难度：简单 | 标签：分组聚合、字符串函数 | [LeetCode 原题](https://leetcode.cn/problems/find-cities-in-each-state/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `cities`：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| state       | varchar |
| city        | varchar |
+-------------+---------+
(state, city) 是这张表的主键（有不同值的列的组合）。
这张表的每一行包含州名和其中的城市名。
```

编写一个解决方案来 **查找每个州的所有城市**，并将它们组合成 **一个逗号分隔** 的字符串。

返回结果表以 `state` **升序** 排序。

结果格式如下所示。

**示例：**

```
输入：
cities 表：
+-------------+---------------+
| state       | city          |
+-------------+---------------+
| California  | Los Angeles   |
| California  | San Francisco |
| California  | San Diego     |
| Texas       | Houston       |
| Texas       | Austin        |
| Texas       | Dallas        |
| New York    | New York City |
| New York    | Buffalo       |
| New York    | Rochester     |
+-------------+---------------+
输出：
+-------------+---------------------------------------+
| state       | cities                                |
+-------------+---------------------------------------+
| California  | Los Angeles, San Diego, San Francisco |
| New York    | Buffalo, New York City, Rochester     |
| Texas       | Austin, Dallas, Houston               |
+-------------+---------------------------------------+
解释：
- California：所有城市 ("Los Angeles", "San Diego", "San Francisco") 以逗号分隔的字符串列出。
- New York：所有城市 ("Buffalo", "New York City", "Rochester") 以逗号分隔的字符串列出。
- Texas：所有城市 ("Austin", "Dallas", "Houston") 以逗号分隔的字符串列出。
注意：输出表以州名升序排序。
```

## 题解

::: details 点击查看题解

### 思路

「按组把多行收成一个字符串」是聚合函数的经典应用，MySQL 里对应 `GROUP_CONCAT`，而且它支持在**聚合的同时对组内排序**：

```sql
GROUP_CONCAT(city ORDER BY city SEPARATOR ', ')
```

三个子句各司其职：`ORDER BY city` 保证组内按城市名字典序（示例输出 Los Angeles, San Diego, San Francisco 正是字典序，而不是插入顺序），`SEPARATOR ', '` 指定分隔符为「逗号 + 空格」——默认分隔符只有逗号没有空格，不显式写就会和示例输出对不上。外层再 `ORDER BY state` 满足「按州名升序」的要求（`GROUP BY` 本身不保证组间顺序，别指望它）。

两个易错点。其一，`GROUP_CONCAT` 的结果受系统变量 `group_concat_max_len`（默认 1024 字节）限制，城市特别多时字符串会被**静默截断**，生产环境要先 `SET SESSION group_concat_max_len = ...` 放大；面试里主动提一句是加分项。其二，输出列名题面用的是 `cities`，记得 `AS cities`。替代写法：窗口函数 + 外层拼接，或直接返回多行（但题目明确要求拼成一个字符串），都不如 `GROUP_CONCAT` 直接。

### SQL 实现

```sql
SELECT state,
       GROUP_CONCAT(city ORDER BY city SEPARATOR ', ') AS cities
FROM cities
GROUP BY state
ORDER BY state;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为城市数，分组线性扫描，组内拼接前需排序。
- 空间复杂度：O(n)，每个州的字符串与分组哈希表合计与行数同阶。

:::
