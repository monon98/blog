# 每天的领导和合伙人

> 难度：简单 | 标签：分组聚合、COUNT(DISTINCT) | [LeetCode 原题](https://leetcode.cn/problems/daily-leads-and-partners/)

## 题目描述

表：`DailySales`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| date_id     | date    |
| make_name   | varchar |
| lead_id     | int     |
| partner_id  | int     |
+-------------+---------+
该表没有主键(具有唯一值的列)。它可能包含重复项。
该表包含日期、产品的名称，以及售给的领导和合伙人的编号。
名称只包含小写英文字母。
```

对于每一个 `date_id` 和 `make_name`，找出 **不同 **的 `lead_id` 以及 **不同 **的 `partner_id` 的数量。

按 **任意顺序** 返回结果表。

返回结果格式如下示例所示。

**示例 1:**

```
输入：
DailySales 表：
+-----------+-----------+---------+------------+
| date_id   | make_name | lead_id | partner_id |
+-----------+-----------+---------+------------+
| 2020-12-8 | toyota    | 0       | 1          |
| 2020-12-8 | toyota    | 1       | 0          |
| 2020-12-8 | toyota    | 1       | 2          |
| 2020-12-7 | toyota    | 0       | 2          |
| 2020-12-7 | toyota    | 0       | 1          |
| 2020-12-8 | honda     | 1       | 2          |
| 2020-12-8 | honda     | 2       | 1          |
| 2020-12-7 | honda     | 0       | 1          |
| 2020-12-7 | honda     | 1       | 2          |
| 2020-12-7 | honda     | 2       | 1          |
+-----------+-----------+---------+------------+
输出：
+-----------+-----------+--------------+-----------------+
| date_id   | make_name | unique_leads | unique_partners |
+-----------+-----------+--------------+-----------------+
| 2020-12-8 | toyota    | 2            | 3               |
| 2020-12-7 | toyota    | 1            | 2               |
| 2020-12-8 | honda     | 2            | 2               |
| 2020-12-7 | honda     | 3            | 2               |
+-----------+-----------+--------------+-----------------+
解释：
在 2020-12-8，丰田（toyota）有领导者 = [0, 1] 和合伙人 = [0, 1, 2] ，同时本田（honda）有领导者 = [1, 2] 和合伙人 = [1, 2]。
在 2020-12-7，丰田（toyota）有领导者 = [0] 和合伙人 = [1, 2] ，同时本田（honda）有领导者 = [0, 1, 2] 和合伙人 = [1, 2]。
```

## 题解

::: details 点击查看题解

### 思路

分组键是 `date_id + make_name` 两列的组合，组内要分别统计**去重后**的 `lead_id` 与 `partner_id` 个数，这正是 `COUNT(DISTINCT col)` 的标准场景。

最大的坑在于这张表**没有主键、明确说明可能包含重复行**。比如 `2020-12-7 / honda` 的 `partner_id = 1` 出现了两次（`(0,1)` 和 `(2,1)` 两行），用 `COUNT(partner_id)` 会数出 3 而不是 2，必须加 `DISTINCT` 去重。

另一个容易混淆的点：`COUNT(DISTINCT lead_id, partner_id)` 是按**两列组合**去重，语义完全不同；本题两列要各自独立计数，所以必须写成两个独立的聚合表达式，并分别命名为 `unique_leads`、`unique_partners`。分组后的两列都要出现在 `SELECT` 和 `GROUP BY` 中，结果顺序题目说任意，不加 `ORDER BY` 也行。

### SQL 实现

```sql
SELECT date_id,
       make_name,
       COUNT(DISTINCT lead_id) AS unique_leads,
       COUNT(DISTINCT partner_id) AS unique_partners
FROM DailySales
GROUP BY date_id, make_name;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为表行数，分组与去重计数一次扫描完成（每组内部哈希去重）。
- 空间复杂度：O(g + k)，g 为分组数，k 为组内不同编号的个数。

:::
