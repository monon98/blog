# 计算税后工资

> 难度：中等 | 标签：子查询、CASE WHEN | [LeetCode 原题](https://leetcode.cn/problems/calculate-salaries/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Salaries` 表：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| company_id    | int     |
| employee_id   | int     |
| employee_name | varchar |
| salary        | int     |
+---------------+---------+
在 SQL 中，(company_id, employee_id) 是这个表的主键。
这个表包括每个员工的 company id、id、name 和 salary。
```

查找出每个员工的税后工资。

每个公司的税率计算依照以下规则：

	- 如果这个公司员工最高工资不到 1000，税率为 0%

	- 如果这个公司员工最高工资在 [1000, 10000] 之间，税率为 24%

	- 如果这个公司员工最高工资大于 10000，税率为 49%

薪资扣除税后的金额计算公式为：薪资 - (税率百分比 / 100) * 薪资，结果 **四舍五入取整**。

按 **任意顺序** 返回结果。

返回结果的格式如下例所示。

**示例 1：**

```
输入：
Salaries 表：
+------------+-------------+---------------+--------+
| company_id | employee_id | employee_name | salary |
+------------+-------------+---------------+--------+
| 1          | 1           | Tony          | 2000   |
| 1          | 2           | Pronub        | 21300  |
| 1          | 3           | Tyrrox        | 10800  |
| 2          | 1           | Pam           | 300    |
| 2          | 7           | Bassem        | 450    |
| 2          | 9           | Hermione      | 700    |
| 3          | 7           | Bocaben       | 100    |
| 3          | 2           | Ognjen        | 2200   |
| 3          | 13          | Nyancat       | 3300   |
| 3          | 15          | Morninngcat   | 7777   |
+------------+-------------+---------------+--------+
输出：
+------------+-------------+---------------+--------+
| company_id | employee_id | employee_name | salary |
+------------+-------------+---------------+--------+
| 1          | 1           | Tony          | 1020   |
| 1          | 2           | Pronub        | 10863  |
| 1          | 3           | Tyrrox        | 5508   |
| 2          | 1           | Pam           | 300    |

+------------+-------------+---------------+--------+
解释：
对于公司 1，最高薪资为 21300，公司 1 的员工税率为 49%。
对于公司 2，最高薪资为 700，公司 2 的员工税率为 0%。
对于公司 3，最高薪资为 7777，公司 3 的员工税率为 24%。
例如，Morninngcat（薪资 7777）扣除税后为 7777 - 7777 * 24 / 100 = 7777 - 1866.48 = 5910.52，四舍五入为 5911。
```

## 题解

::: details 点击查看题解

### 思路

**税率由公司决定，不是由员工自己的工资决定**——这是本题最大的陷阱。比如公司 1 的 Tony 工资只有 2000（本身落在 24% 档），但公司最高薪 21300 超过 10000，全公司都按 49% 交税，所以 Tony 税后是 2000 × 0.51 = 1020。因此第一步必须先按 `company_id` 分组求 `MAX(salary)`，得到「公司 → 最高薪」，再把它带回每名员工。

结构上是分组子查询（或 `JOIN` 后 `GROUP BY`）+ 条件表达式：子查询 `SELECT company_id, MAX(salary) AS top FROM Salaries GROUP BY company_id`，与原表按 `company_id` 连接；然后 `CASE WHEN top < 1000 THEN salary WHEN top <= 10000 THEN salary * 0.76 ELSE salary * 0.51 END`，0% / 24% / 49% 三档分别对应乘 1、0.76、0.51。

两个细节：阈值区间是 **闭区间** `[1000, 10000]` 落 24%，所以第二个分支要 `>= 1000 AND <= 10000`（由于 `CASE` 自上而下求值，写成 `WHEN top <= 10000` 也对）；结果要用 `ROUND` 四舍五入取整，否则 `7777 * 0.76 = 5910.52` 会以小数形式输出。替代写法：用相关子查询 `(SELECT MAX(salary) FROM Salaries s2 WHERE s2.company_id = s1.company_id)` 直接在 `CASE` 里取最高薪，不必显式连接，但每个员工都查一次，数据量大时更慢。

### SQL 实现

```sql
SELECT
    s.company_id,
    s.employee_id,
    s.employee_name,
    ROUND(
        CASE
            WHEN t.top_salary < 1000 THEN s.salary
            WHEN t.top_salary <= 10000 THEN s.salary * 0.76
            ELSE s.salary * 0.51
        END
    ) AS salary
FROM Salaries s
JOIN (
    SELECT company_id, MAX(salary) AS top_salary
    FROM Salaries
    GROUP BY company_id
) t ON s.company_id = t.company_id;
```

### 复杂度分析

- 时间复杂度：O(n)，一次分组聚合加一次等值连接，n 为员工数。
- 空间复杂度：O(m)，m 为公司数（子查询结果）。
