# 评分为 NULL 的图书

> 难度：简单 | 标签：空值处理、条件筛选 | [LeetCode 原题](https://leetcode.cn/problems/books-with-null-ratings/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `books`：

```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| book_id        | int     |
| title          | varchar |
| author         | varchar |
| published_year | int     |
| rating         | decimal |
+----------------+---------+
book_id 是这张表的唯一主键。
这张表的每一行包含关于一本书的唯一 ID，题目，作者，出版年份以及评分的信息。
评分可能为 NULL，表示这本书还没有被评分。
```

编写一个解决方案来找到所有还没有被评分的图书（即评分为 `NULL`）。

返回结果表以 `book_id` **升序** 排序。

结果格式如下所示。

**示例：**

```
输入：
books 表：
+---------+------------------------+------------------+----------------+--------+
| book_id | title                  | author           | published_year | rating |
+---------+------------------------+------------------+----------------+--------+
| 1       | The Great Gatsby       | F. Scott         | 1925           | 4.5    |
| 2       | To Kill a Mockingbird  | Harper Lee       | 1960           | NULL   |
| 3       | Pride and Prejudice    | Jane Austen      | 1813           | 4.8    |
| 4       | The Catcher in the Rye | J.D. Salinger    | 1951           | NULL   |
| 5       | Animal Farm            | George Orwell    | 1945           | 4.2    |
| 6       | Lord of the Flies      | William Golding  | 1954           | NULL   |
+---------+------------------------+------------------+----------------+--------+
输出：
+---------+------------------------+------------------+----------------+
| book_id | title                  | author           | published_year |
+---------+------------------------+------------------+----------------+
| 2       | To Kill a Mockingbird  | Harper Lee       | 1960           |
| 4       | The Catcher in the Rye | J.D. Salinger    | 1951           |
| 6       | Lord of the Flies      | William Golding  | 1954           |
+---------+------------------------+------------------+----------------+
解释：
- book_id 为 2，4，6 的书评分为 NULL。
- 这些书被包含在结果表中。
- 其它书（book_id 为 1，3，5）有评分并且没有被包含。
结果以 book_id 升序排序。
```

## 题解

::: details 点击查看题解

### 思路

筛 `NULL` 有一条铁律：**`NULL` 不能用 `=` 或 `!=` 比较**。写 `WHERE rating = NULL` 或 `WHERE rating <> NULL` 的结果永远是 `NULL`（三值逻辑里不为真），一条行都查不出来；必须写成 `WHERE rating IS NULL`。同理，`WHERE NOT (rating = 4.5)` 也筛不出未评分的书——`rating` 为 `NULL` 时整个表达式是 `NULL`，不通过过滤。这是本题唯一的实质考点，也是数据库面试的高频陷阱。

第二个细节是**输出列**：结果里不要 `rating` 列（它全是 `NULL`），题面示例只给了 `book_id, title, author, published_year` 四列，`SELECT *` 在严格判题下会因列数/列序不匹配被判错。最后按 `book_id` 升序，别漏 `ORDER BY`。

替代写法：`WHERE rating IS NOT NULL` 取反是错的（那筛的是已评分的）；`WHERE IFNULL(rating, -1) = -1` 或 `COALESCE` 技巧虽然也能跑，但会把 `NULL` 转成具体值、可读性更差，直接 `IS NULL` 永远是最优解。

### SQL 实现

```sql
SELECT book_id, title, author, published_year
FROM books
WHERE rating IS NULL
ORDER BY book_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为图书数，过滤 O(n)，排序 O(n log n)。
- 空间复杂度：O(1)，除结果集外只需常数额外空间。

:::

## 建表与测试数据

```sql
Create table books (
    book_id int,
    title varchar(255),
    author varchar(100),
    published_year int,
    rating decimal(3,1)
);
Truncate table books;
insert into books (book_id, title, author, published_year, rating) values ('1', 'The Great Gatsby', 'F. Scott', '1925', '4.5');
insert into books (book_id, title, author, published_year, rating) values ('2', 'To Kill a Mockingbird', 'Harper Lee', '1960', NULL);
insert into books (book_id, title, author, published_year, rating) values ('3', 'Pride and Prejudice', 'Jane Austen', '1813', '4.8');
insert into books (book_id, title, author, published_year, rating) values ('4', 'The Catcher in the Rye', 'J.D. Salinger', '1951', NULL);
insert into books (book_id, title, author, published_year, rating) values ('5', 'Animal Farm', 'George Orwell', '1945', '4.2');
insert into books (book_id, title, author, published_year, rating) values ('6', 'Lord of the Flies', 'William Golding', '1954', NULL);
```
