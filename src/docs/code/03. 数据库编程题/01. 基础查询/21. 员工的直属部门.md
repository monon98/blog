# 员工的直属部门

> 难度：简单 | 标签：分组聚合、UNION | [LeetCode 原题](https://leetcode.cn/problems/primary-department-for-each-employee/)

## 题目描述

表：`Employee`

```
+---------------+---------+
| Column Name   |  Type   |
+---------------+---------+
| employee_id   | int     |
| department_id | int     |
| primary_flag  | varchar |
+---------------+---------+
这张表的主键为 employee_id, department_id (具有唯一值的列的组合)
employee_id 是员工的ID
department_id 是部门的ID，表示员工与该部门有关系
primary_flag 是一个枚举类型，值分别为('Y', 'N'). 如果值为'Y',表示该部门是员工的直属部门。 如果值是'N',则否
```

一个员工可以属于多个部门。当一个员工加入**超过一个部门**的时候，他需要决定哪个部门是他的直属部门。请注意，当员工只加入一个部门的时候，那这个部门将默认为他的直属部门，虽然表记录的值为`'N'`.

请编写解决方案，查出员工所属的直属部门。

返回结果 **没有顺序要求** 。

返回结果格式如下例子所示：

**示例 1：**

```
输入：
Employee table:
+-------------+---------------+--------------+
| employee_id | department_id | primary_flag |
+-------------+---------------+--------------+
| 1           | 1             | N            |
| 2           | 1             | Y            |
| 2           | 2             | N            |
| 3           | 3             | N            |
| 4           | 2             | N            |
| 4           | 3             | Y            |
| 4           | 4             | N            |
+-------------+---------------+--------------+
输出：
+-------------+---------------+
| employee_id | department_id |
+-------------+---------------+
| 1           | 1             |
| 2           | 1             |
| 3           | 3             |
| 4           | 3             |
+-------------+---------------+
解释：
- 员工 1 的直属部门是 1
- 员工 2 的直属部门是 1
- 员工 3 的直属部门是 3
- 员工 4 的直属部门是 3
```

## 题解

::: details 点击查看题解

### 思路

题目的核心是**两种情况取并集**，直接一个 `WHERE` 是写不出来的：

1. 员工有 `primary_flag = 'Y'` 的部门记录 → 那一行的 `department_id` 就是直属部门；
2. 员工**只有一条**记录（哪怕标记是 `'N'`）→ 这条记录的部门默认为直属部门。

所以最经典的写法是 `UNION` 把两支查询拼起来：第一支筛出所有 `Y` 行，第二支按 `employee_id` 分组、`HAVING COUNT(*) = 1` 找出只属于一个部门的员工。`UNION` 自带去重，两支结果即使有重叠也不会出现重复行。

第二个分支有个容易踩的坑：`SELECT employee_id, department_id ... GROUP BY employee_id` 在 MySQL 8 默认的 `ONLY_FULL_GROUP_BY` 模式下**会报错**——表的主键是 `(employee_id, department_id)` 两列的组合，`employee_id` 单独并不能函数决定 `department_id`。解决办法是把 `department_id` 包成聚合函数 `MIN(department_id)`（组里本来就只有一行），或者像下面提到的替代写法那样用子查询只取 `employee_id`。

替代写法还有两种：`WHERE primary_flag = 'Y' OR employee_id IN (SELECT employee_id FROM Employee GROUP BY employee_id HAVING COUNT(*) = 1)`，一条语句搞定；或者用窗口函数 `COUNT(*) OVER (PARTITION BY employee_id)` 先打标再过滤，都能通过。

### SQL 实现

```sql
SELECT employee_id, department_id
FROM Employee
WHERE primary_flag = 'Y'

UNION

SELECT employee_id, MIN(department_id) AS department_id
FROM Employee
GROUP BY employee_id
HAVING COUNT(*) = 1;
```

### 复杂度分析

- 时间复杂度：O(n)，两支查询各扫一遍表，分组开销 O(n)。
- 空间复杂度：O(g)，g 为员工数，分组哈希表 + 结果去重集合。
