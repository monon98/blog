# 第二高的薪水

> 难度：中等 | 标签：子查询、聚合函数 | [LeetCode 原题](https://leetcode.cn/problems/second-highest-salary/)

## 题目描述

`Employee` 表：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| salary      | int  |
+-------------+------+
id 是这个表的主键。
表的每一行包含员工的工资信息。
```

查询并返回 `Employee` 表中第二高的 **不同** 薪水 。如果不存在第二高的薪水，查询应该返回 `null(Pandas 则返回 None)` 。

查询结果如下例所示。

**示例 1：**

```
输入：
Employee 表：
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
| 2  | 200    |
| 3  | 300    |
+----+--------+
输出：
+---------------------+
| SecondHighestSalary |
+---------------------+
| 200                 |
+---------------------+
```

**示例 2：**

```
输入：
Employee 表：
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
+----+--------+
输出：
+---------------------+
| SecondHighestSalary |
+---------------------+
| null                |
+---------------------+
```

## 题解

::: details 点击查看题解

### 思路

题目有两个关键限定：一是「不同的薪水」，二是「不存在时返回 null 而不是空结果集」。经典的写法是把去重、排序、取第二名全部放进标量子查询：`SELECT DISTINCT salary` 先去掉重复工资，`ORDER BY salary DESC` 从高到低排，`LIMIT 1 OFFSET 1` 跳过第一名取第二名。外层再包一层 `SELECT`，这样即使内层查不到任何行，标量子查询也会以 `NULL` 填充，列名正好是 `SecondHighestSalary`。

易错点有两个。其一，如果直接写 `SELECT DISTINCT salary ... ORDER BY ... LIMIT 1 OFFSET 1` 而不套外层 `SELECT`，当表中只有一条记录时结果是空集而不是一行 `null`，无法通过「示例 2」的校验。其二，忘记 `DISTINCT`：比如数据为 `[100, 100, 200]` 时，不加去重会把第二个 100 当成第二高薪水，而题目明确要求不同的薪水。

替代写法：用窗口函数 `DENSE_RANK()` 给去重后的薪水编号再筛 `rk = 2`；或者用 `SELECT MAX(salary) FROM Employee WHERE salary < (SELECT MAX(salary) FROM Employee)`，这个子查询在无第二高时同样返回 `NULL`。

### SQL 实现

```sql
SELECT (
    SELECT DISTINCT salary
    FROM Employee
    ORDER BY salary DESC
    LIMIT 1 OFFSET 1
) AS SecondHighestSalary;
```

### 复杂度分析

- 时间复杂度：O(n log n)，排序主导，n 为员工数。
- 空间复杂度：O(n)，去重与排序的额外开销。

:::
