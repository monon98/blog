# 判断三角形

> 难度：简单 | 标签：CASE WHEN、条件过滤 | [LeetCode 原题](https://leetcode.cn/problems/triangle-judgement/)

## 题目描述

表: `Triangle`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| x           | int  |
| y           | int  |
| z           | int  |
+-------------+------+
在 SQL 中，(x, y, z)是该表的主键列。
该表的每一行包含三个线段的长度。
```

对每三个线段报告它们是否可以形成一个三角形。

以 **任意顺序 **返回结果表。

查询结果格式如下所示。

**示例 1:**

```
输入:
Triangle 表:
+----+----+----+
| x  | y  | z  |
+----+----+----+
| 13 | 15 | 30 |
| 10 | 20 | 15 |
+----+----+----+
输出:
+----+----+----+----------+
| x  | y  | z  | triangle |
+----+----+----+----------+
| 13 | 15 | 30 | No       |
| 10 | 20 | 15 | Yes      |
+----+----+----+----------+
```

## 题解

::: details 点击查看题解

### 思路

三角形判定的几何条件是「任意两边之和大于第三边」，即三个不等式必须 **同时** 成立：`x + y > z`、`x + z > y`、`y + z > x`。本题边长为正整数，写这三条即可；若允许浮点或零长边，还要额外保证三边为正。示例里 `13 + 15 = 28 < 30`，第一条就失败，输出 `No`；`10 + 15 = 25 > 20` 三条全过，输出 `Yes`。

本题要求对每行输出 `Yes/No` 而不是过滤行，所以要用条件表达式而不是 `WHERE`：`CASE WHEN 三个条件 THEN 'Yes' ELSE 'No' END AS triangle`，一条都不能省——只判断两组会把 `13, 15, 30` 这种「一组不成立但另一组成立」的情况误判。

替代写法：`IF(x + y > z AND x + z > y AND y + z > x, 'Yes', 'No')`，或判断「最长边小于另两边之和」，语义等价但要先求最值，不如三条并列直观。

### SQL 实现

```sql
SELECT
    x,
    y,
    z,
    CASE
        WHEN x + y > z AND x + z > y AND y + z > x THEN 'Yes'
        ELSE 'No'
    END AS triangle
FROM Triangle;
```

### 复杂度分析

- 时间复杂度：O(n)，逐行判断，n 为记录数。
- 空间复杂度：O(1)，仅输出不额外占空间。

:::
