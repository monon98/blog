# 树节点

> 难度：中等 | 标签：多表连接、CASE WHEN | [LeetCode 原题](https://leetcode.cn/problems/tree-node/)

## 题目描述

表：`Tree`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| p_id        | int  |
+-------------+------+
id 是该表中具有唯一值的列。
该表的每行包含树中节点的 id 及其父节点的 id 信息。
给定的结构总是一个有效的树。
```

树中的每个节点可以是以下三种类型之一：

	- "Leaf"：节点是叶子节点。

	- "Root"：节点是树的根节点。

	- "Inner"：节点既不是叶子节点也不是根节点。

编写一个解决方案来报告树中每个节点的类型。

以 **任意顺序** 返回结果表。

结果格式如下所示。

示例 1：

![img](https://assets.leetcode.com/uploads/2021/10/22/tree1.jpg)

```
输入：
Tree table:
+----+------+
| id | p_id |
+----+------+
| 1  | null |
| 2  | 1    |
| 3  | 1    |
| 4  | 2    |
| 5  | 2    |
+----+------+
输出：
+----+-------+
| id | type  |
+----+-------+
| 1  | Root  |
| 2  | Inner |
| 3  | Leaf  |
| 4  | Leaf  |
| 5  | Leaf  |
+----+-------+
解释：
节点 1 是根节点，因为它的父节点为空，并且它有子节点 2 和 3。
节点 2 是一个内部节点，因为它有父节点 1 和子节点 4 和 5。
节点 3、4 和 5 是叶子节点，因为它们有父节点而没有子节点。
```

示例 2：

![img](https://assets.leetcode.com/uploads/2021/10/22/tree2.jpg)

```
输入：
Tree table:
+----+------+
| id | p_id |
+----+------+
| 1  | null |
+----+------+
输出：
+----+-------+
| id | type  |
+----+-------+
| 1  | Root  |
+----+-------+
解释：如果树中只有一个节点，则只需要输出其根属性。
```

**注意：**本题与 3054. 二叉树节点 一致。

## 题解

::: details 点击查看题解

### 思路

三种类型的判定依据来自两个信息：`p_id` 是否为空（有没有父）、有没有别的行把自己当成父（有没有子）。判定顺序很重要，应先判根再判叶子：

1. `p_id IS NULL` → `Root`；
2. 否则若没有任何节点的 `p_id` 等于它 → `Leaf`；
3. 否则 → `Inner`。

「有没有子」需要把表自连接：`LEFT JOIN Tree c ON t.id = c.p_id`，左表是节点本身，右表是它的孩子。对左表每个节点 `GROUP BY t.id, t.p_id` 后，`COUNT(c.id)` 就是孩子数——叶子节点匹配不到右表行，`c.id` 全是 `NULL`，`COUNT` 恰好为 0（注意 `COUNT(c.id)` 会忽略 `NULL`，`COUNT(*)` 则会算成 1，这是最容易写错的地方）。

单节点树（示例 2）只有 `Root` 一个分支命中，不会被误判成叶子；判断顺序把 `Root` 放最前正是为此。替代写法：不连接，直接用相关子查询 `NOT EXISTS (SELECT 1 FROM Tree c WHERE c.p_id = t.id)` 判断是否叶子。

### SQL 实现

```sql
SELECT
    t.id,
    CASE
        WHEN t.p_id IS NULL THEN 'Root'
        WHEN COUNT(c.id) = 0 THEN 'Leaf'
        ELSE 'Inner'
    END AS type
FROM Tree t
LEFT JOIN Tree c ON t.id = c.p_id
GROUP BY t.id, t.p_id;
```

### 复杂度分析

- 时间复杂度：O(n)，自连接与分组各扫一遍，n 为节点数。
- 空间复杂度：O(n)，连接与分组的哈希开销。

:::
