# 根据长度分类三角形

> 难度：简单 | 标签：CASE WHEN、条件筛选 | [LeetCode 原题](https://leetcode.cn/problems/classifying-triangles-by-lengths/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Triangles`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| A           | int  |
| B           | int  |
| C           | int  |
+-------------+------+
(A, B, C) 是这张表的主键。
每一行包含三角形三边的长度。
```

编写一个查询来找到 **三角形** 的类型。对于每一行输出下面的其中一个：

- **Equilateral**：`3` 边长度相同的三角形。
- **Isosceles**：`2` 边长度相同的三角形。
- **Scalene**：`3` 边长度不同的三角形。
- **Not A Triangle**：给定的 `A`，`B`，`C` 的值不能形成三角形。

以 **任何顺序** 返回结果表。

结果格式如下所示。

**示例 1：**

```
输入：
Triangles 表：
+----+----+----+
| A  | B  | C  |
+----+----+----+
| 20 | 20 | 23 |
| 20 | 20 | 20 |
| 20 | 21 | 22 |
| 13 | 14 | 30 |
+----+----+----+
输出：
+----------------+
| triangle_type  |
+----------------+
| Isosceles      |
| Equilateral    |
| Scalene        |
| Not A Triangle |
+----------------+
解释：
- 第一行的值形成了等腰三角形，因为 A = B。
- 第二行的值形成了等边三角形，因为 A = B = C。
- 第三行的值形成了斜三角形，因为 A != B != C。
- 第四行中的值不能形成三角形，因为边 A 和边 B 的和不大于边 C。
```

## 题解

::: details 点击查看题解

### 思路

三边在同一行里，用一条 `CASE WHEN` 按**优先级**自上而下判断即可，关键是分支顺序不能乱。

第一优先级必须是「能不能构成三角形」：三角形不等式要求**任意两边之和大于第三边**，取反即 `A + B <= C OR A + C <= B OR B + C <= A` → `Not A Triangle`。注意是 `<=` 而不是 `<`——两边之和**等于**第三边时三点共线（退化三角形），同样不算，示例里 13 + 14 = 27 < 30 恰好是严格不满足，别因为只盯着这个例子就把 `<=` 写成 `<`。

第二、三分支的顺序同样重要：先判等边（`A = B AND B = C`），再判等腰（`A = B OR B = C OR A = C`）。如果把等腰放前面，等边行会被提前拦截输出 `Isosceles`（等边本质上也是等腰，但题目要求归为 Equilateral），20/20/20 那行就错了。

最后一类三边全不等即 `ELSE 'Scalene'`。输出列名题面给的是 `triangle_type`。替代写法：用 `(A = B) + (B = C) + (A = C)` 的布尔和来区分「恰好两边相等」，或拆成子查询逐层过滤，都不如单条 `CASE` 清晰。

### SQL 实现

```sql
SELECT CASE
           WHEN A + B <= C OR A + C <= B OR B + C <= A THEN 'Not A Triangle'
           WHEN A = B AND B = C THEN 'Equilateral'
           WHEN A = B OR B = C OR A = C THEN 'Isosceles'
           ELSE 'Scalene'
       END AS triangle_type
FROM Triangles;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为三角形个数，每行常数次比较。
- 空间复杂度：O(1)，除结果集外只需常数额外空间。

:::
