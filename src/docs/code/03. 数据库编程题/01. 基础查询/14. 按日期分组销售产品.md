# 按日期分组销售产品

> 难度：简单 | 标签：分组聚合、字符串函数 | [LeetCode 原题](https://leetcode.cn/problems/group-sold-products-by-the-date/)

## 题目描述

表 `Activities`：

```
+-------------+---------+
| 列名         | 类型    |
+-------------+---------+
| sell_date   | date    |
| product     | varchar |
+-------------+---------+
该表没有主键(具有唯一值的列)。它可能包含重复项。
此表的每一行都包含产品名称和在市场上销售的日期。
```

编写解决方案找出每个日期、销售的不同产品的数量及其名称。

每个日期的销售产品名称应按词典序排列。

返回按 `sell_date` 排序的结果表。

结果表结果格式如下例所示。

**示例 1:**

```
输入：
Activities 表：
+------------+-------------+
| sell_date  | product     |
+------------+-------------+
| 2020-05-30 | Headphone   |
| 2020-06-01 | Pencil      |
| 2020-06-02 | Mask        |
| 2020-05-30 | Basketball  |
| 2020-06-01 | Bible       |
| 2020-06-02 | Mask        |
| 2020-05-30 | T-Shirt     |
+------------+-------------+
输出：
+------------+----------+------------------------------+
| sell_date  | num_sold | products                     |
+------------+----------+------------------------------+
| 2020-05-30 | 3        | Basketball,Headphone,T-shirt |
| 2020-06-01 | 2        | Bible,Pencil                 |
| 2020-06-02 | 1        | Mask                         |
+------------+----------+------------------------------+
解释：
对于2020-05-30，出售的物品是 (Headphone, Basketball, T-shirt)，按词典序排列，并用逗号 ',' 分隔。
对于2020-06-01，出售的物品是 (Pencil, Bible)，按词典序排列，并用逗号分隔。
对于2020-06-02，出售的物品是 (Mask)，只需返回该物品名。
```

## 题解

::: details 点击查看题解

### 思路

按 `sell_date` 分组后要产出两样东西：**去重计数** 和 **去重拼接**。

表明确说可能有重复行，示例里 `2020-06-02 | Mask` 出现两次，因此计数必须写 `COUNT(DISTINCT product)`，写成 `COUNT(product)` 会得到 2；拼接同理要用 `GROUP_CONCAT(DISTINCT product ...)`。

名称要求「按词典序排列、逗号分隔」，`GROUP_CONCAT` 的语法正好能一步到位：`GROUP_CONCAT(DISTINCT product ORDER BY product SEPARATOR ',') AS products`。`SEPARATOR ','` 其实是默认值，可以省略，但写出来更清楚。`ORDER BY product` 不能省——不写则拼接顺序按底层读取顺序，示例里 `2020-05-30` 会拼成 `Headphone,Basketball,T-Shirt`。

最后外层 `ORDER BY sell_date` 按日期升序返回。两个易错点：一是漏 `DISTINCT`（数量和名称都会重复）；二是 `GROUP_CONCAT` 有 `group_concat_max_len` 长度上限（默认 1024 字节），日期多、产品名长时截断，判题数据虽远够不着，工程上要知道这个坑。

### SQL 实现

```sql
SELECT
    sell_date,
    COUNT(DISTINCT product) AS num_sold,
    GROUP_CONCAT(DISTINCT product ORDER BY product SEPARATOR ',') AS products
FROM Activities
GROUP BY sell_date
ORDER BY sell_date;
```

### 复杂度分析

- 时间复杂度：O(n log n)，分组聚合 O(n)，组内按产品排序主导。
- 空间复杂度：O(d × k)，d 为日期数，k 为该日去重后的产品数。

:::
