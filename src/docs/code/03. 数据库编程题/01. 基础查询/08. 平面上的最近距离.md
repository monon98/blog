# 平面上的最近距离

> 难度：中等 | 标签：多表连接、聚合函数 | [LeetCode 原题](https://leetcode.cn/problems/shortest-distance-in-a-plane/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Point2D` 表：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| x           | int  |
| y           | int  |
+-------------+------+
x 和 y 是该表的主键列。
该表的每一行表示平面上的一个点。
```

写一个 SQL 查询，报告 `Point2D` 表中 **任意两点之间的最短距离**，结果四舍五入保留两位小数。

保证表中至少包含两行数据。

查询结果如下例所示。

**示例 1：**

```
输入：
Point2D 表：
+----+----+
| x  | y  |
+----+----+
| -1 | -1 |
| 0  | 0  |
| -1 | -2 |
+----+----+
输出：
+----------+
| shortest |
+----------+
| 1.00     |
+----------+
解释：
(-1, -1) 与 (0, 0) 的距离约为 1.41；
(-1, -1) 与 (-1, -2) 的距离为 1；
(0, 0) 与 (-1, -2) 的距离约为 2.24；
因此最短距离为 1，保留两位小数为 1.00。
```

## 题解

::: details 点击查看题解

### 思路

平面两点距离用勾股定理：`SQRT(POW(x1 - x2, 2) + POW(y1 - y2, 2))`（MySQL 里也可写成 `SQRT((p1.x - p2.x) * (p1.x - p2.x) + ...)`，`POW` 与 `*` 等价）。把表自连接成所有点对，算出每对的距离，再用 `MIN` 取最小值，最后 `ROUND(..., 2)` 四舍五入保留两位小数——注意 `ROUND` 要包在 `MIN` 外面，先取最小再舍入，结果才对。

自连接必须排除「自己和自己」配对：连接条件写 `p1.x <> p2.x OR p1.y <> p2.y`，只要坐标不完全相同就是两个不同的点。若不加条件，每个点会和自己连出距离 0，`MIN` 永远是 0。重复计算（A-B 和 B-A 各算一次）不影响 `MIN` 结果，只是浪费一半计算；想省一半可以把条件换成 `p1.x < p2.x OR (p1.x = p2.x AND p1.y < p2.y)`。

### SQL 实现

```sql
SELECT ROUND(
    MIN(SQRT(POW(p1.x - p2.x, 2) + POW(p1.y - p2.y, 2))),
    2
) AS shortest
FROM Point2D p1
JOIN Point2D p2 ON (p1.x <> p2.x OR p1.y <> p2.y);
```

### 复杂度分析

- 时间复杂度：O(n²)，点对数量为两两组合级别，n 为点数。
- 空间复杂度：O(1)，只保留一个最小值。

:::
