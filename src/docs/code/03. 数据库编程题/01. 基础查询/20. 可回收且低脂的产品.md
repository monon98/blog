# 可回收且低脂的产品

> 难度：简单 | 标签：条件筛选、逻辑运算 | [LeetCode 原题](https://leetcode.cn/problems/recyclable-and-low-fat-products/)

## 题目描述

表：`Products`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| low_fats    | enum    |
| recyclable  | enum    |
+-------------+---------+
product_id 是该表的主键（具有唯一值的列）。
low_fats 是枚举类型，取值为以下两种 ('Y', 'N')，其中 'Y' 表示该产品是低脂产品，'N' 表示不是低脂产品。
recyclable 是枚举类型，取值为以下两种 ('Y', 'N')，其中 'Y' 表示该产品可回收，而 'N' 表示不可回收。
```

编写解决方案找出既是低脂又是可回收的产品编号。

返回结果 **无顺序要求** 。

返回结果格式如下例所示：

**示例 1：**

```
输入：
Products 表：
+-------------+----------+------------+
| product_id  | low_fats | recyclable |
+-------------+----------+------------+
| 0           | Y        | N          |
| 1           | Y        | Y          |
| 2           | N        | Y          |
| 3           | Y        | Y          |
| 4           | N        | N          |
+-------------+----------+------------+
输出：
+-------------+
| product_id  |
+-------------+
| 1           |
| 3           |
+-------------+
解释：
只有产品 id 为 1 和 3 的产品，既是低脂又是可回收的产品。
```

## 题解

::: details 点击查看题解

### 思路

最基础的多条件过滤题，但有几个小坑值得说清楚。

第一，「既是……又是……」是**逻辑与**，必须用 `AND` 连接两个条件；写成 `OR` 会把「低脂但不可回收」和「可回收但不低脂」的行也捞进来，结果多出 0、2 两个 id。

第二，`low_fats`、`recyclable` 是 **ENUM 枚举列**，取值 `'Y'` / `'N'`，比较时是字符串字面量，必须加单引号。写成 `low_fats = Y` 会被 MySQL 当成列名/别名解析而报错。另外不要因为列名叫 `recyclable` 就误以为「可回收」对应数值 1——枚举值就是两个大写字母，认值不认名。

第三，`product_id` 是主键，结果天然去重，不需要 `DISTINCT`；题目也说明结果无顺序要求，不必加 `ORDER BY`。替代写法：`WHERE low_fats = 'Y' AND recyclable = 'Y'` 等价于 `WHERE low_fats = 'Y' & recyclable = 'Y'`（按位与，不推荐，可读性差），或先 `SELECT` 全部列再人工过滤，没有必要。

### SQL 实现

```sql
SELECT product_id
FROM Products
WHERE low_fats = 'Y'
  AND recyclable = 'Y';
```

### 复杂度分析

- 时间复杂度：O(n)，n 为产品数，逐行判断两个条件。
- 空间复杂度：O(1)，除结果集外只需常数额外空间。

:::
