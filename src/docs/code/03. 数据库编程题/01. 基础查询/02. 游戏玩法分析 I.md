# 游戏玩法分析 I

> 难度：简单 | 标签：分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/game-play-analysis-i/)

## 题目描述

活动表 `Activity`：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| player_id    | int     |
| device_id    | int     |
| event_date   | date    |
| games_played | int     |
+--------------+---------+
在 SQL 中，表的主键是 (player_id, event_date)。
这张表展示了一些游戏玩家在游戏平台上的行为活动。
每行数据记录了一名玩家在退出平台之前，当天使用同一台设备登录平台后打开的游戏的数目（可能是 0 个）。
```

查询每位玩家 **第一次登录平台的日期**。

查询结果的格式如下所示：

```
Activity 表：
+-----------+-----------+------------+--------------+
| player_id | device_id | event_date | games_played |
+-----------+-----------+------------+--------------+
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-05-02 | 6            |
| 2         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |
+-----------+-----------+------------+--------------+

Result 表：
+-----------+-------------+
| player_id | first_login |
+-----------+-------------+
| 1         | 2016-03-01  |
| 2         | 2017-06-25  |
| 3         | 2016-03-02  |
+-----------+-------------+
```

## 题解

::: details 点击查看题解

### 思路

「每个玩家第一次登录的日期」是典型的按人分组求最小值：`GROUP BY player_id` 把同一名玩家的所有登录记录聚成一行，`MIN(event_date)` 取其中最早的日期，结果天然一人一行，与主键 `(player_id, event_date)` 的语义一致。

要注意别名：题目要求输出列名叫 `first_login`，直接写 `MIN(event_date)` 列名会是 `MIN(event_date)`，必须显式 `AS first_login`。另外 `MIN` 作用在 `date` 类型上返回的仍是日期字符串（如 `2016-03-01`），无需再格式化。

替代写法：用窗口函数 `RANK() OVER (PARTITION BY player_id ORDER BY event_date)` 取排名为 1 的行；或相关子查询 `SELECT event_date FROM Activity a2 WHERE a2.player_id = a1.player_id ORDER BY event_date LIMIT 1`。本题数据量下 `GROUP BY` + `MIN` 最直观高效。

### SQL 实现

```sql
SELECT player_id, MIN(event_date) AS first_login
FROM Activity
GROUP BY player_id;
```

### 复杂度分析

- 时间复杂度：O(n)，单次扫描完成分组聚合，n 为记录数。
- 空间复杂度：O(m)，m 为玩家数（分组哈希表大小）。

:::
