# 直线上的最近距离

> 难度：简单 | 标签：多表连接、窗口函数 | [LeetCode 原题](https://leetcode.cn/problems/shortest-distance-in-a-line/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Point`：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| x           | int  |
+-------------+------+
x 是该表的主键列（建表时声明为 NOT NULL）。
该表的每一行表示 X 轴上一个点的位置。
```

找到 `Point` 表中任意两点之间的 **最短距离**。

保证 `Point` 表中 **至少** 包含两行数据。

查询结果格式如下例所示。

**示例 1：**

```
输入：
Point 表：
+----+
| x  |
+----+
| -1 |
| 0  |
| 2  |
+----+
输出：
+----------+
| shortest |
+----------+
| 1        |
+----------+
解释：
点 -1 和 0 之间的最短距离为 |(-1) - 0| = 1。
```

**进阶：** 如果 `Point` 表按 **升序排列**，如何优化你的解决方案？

## 题解

::: details 点击查看题解

### 思路

一维情形比平面简单：距离就是两点坐标差的绝对值，而把所有点按坐标排好序后，**最短距离一定出现在相邻两点之间**——不相邻的点之间还隔着别的点，差值只会更大。

经典写法是自连接：`JOIN Point p2 ON p1.x < p2.x`，保证每对点只连一次且 `p2.x - p1.x` 恒为正，不需要再套 `ABS`；若用 `<>` 连接则必须取 `ABS`，否则负距离会把 `MIN` 带偏（变成负数最小、也就是绝对值最大的那对）。最后 `MIN` 聚合即可，两行数据时也天然成立。

替代写法：窗口函数 `LAG(x) OVER (ORDER BY x)` 取每个点的前驱，`x - LAG(x)` 就是相邻间距，排序后取最小的非空值；这就是进阶问题的答案——表已有序时可以 `O(n)` 扫一遍，不必生成 O(n²) 的点对。

### SQL 实现

```sql
SELECT MIN(p2.x - p1.x) AS shortest
FROM Point p1
JOIN Point p2 ON p1.x < p2.x;
```

### 复杂度分析

- 时间复杂度：O(n²)，自连接生成点对，n 为点数；有序表用 `LAG` 优化后为 O(n log n)（排序）乃至 O(n)。
- 空间复杂度：O(1)，只保留一个最小值。

:::
