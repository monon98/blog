# 没有卖出的卖家

> 难度：简单 | 标签：多表连接、空值处理 | [LeetCode 原题](https://leetcode.cn/problems/sellers-with-no-sales/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Customer`：

```
+----------------+---------+
| Column Name    | Type    |
+----------------+---------+
| customer_id    | int     |
| customer_name  | varchar |
+----------------+---------+
customer_id 是该表的主键。
该表的每一行表示客户的 id 和姓名。
```

表 `Orders`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| order_id      | int     |
| sale_date     | date    |
| order_cost    | int     |
| customer_id   | int     |
| seller_id     | int     |
+---------------+---------+
order_id 是该表的主键。
该表的每一行表示一笔订单：下单日期、金额、客户 id 和负责该单的卖家 id。
```

表 `Seller`：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| seller_id    | int     |
| seller_name  | varchar |
+--------------+---------+
seller_id 是该表的主键。
该表的每一行表示一名卖家的 id 和姓名。
```

编写解决方案，找出所有 **在 2020 年没有任何订单** 的卖家姓名。

以 **任意顺序** 返回结果表。

查询结果格式如下例所示。

**示例 1：**

```
输入：
Customer 表：
+-------------+---------------+
| customer_id | customer_name |
+-------------+---------------+
| 101         | Alice         |
| 102         | Bob           |
| 103         | Charlie       |
+-------------+---------------+
Orders 表：
+----------+------------+------------+-------------+-----------+
| order_id | sale_date  | order_cost | customer_id | seller_id |
+----------+------------+------------+-------------+-----------+
| 1        | 2020-03-01 | 1500       | 101         | 1         |
| 2        | 2020-05-25 | 2400       | 102         | 2         |
| 3        | 2019-05-25 | 800        | 101         | 3         |
| 4        | 2020-09-13 | 1000       | 103         | 2         |
| 5        | 2019-02-11 | 700        | 101         | 2         |
+----------+------------+------------+-------------+-----------+
Seller 表：
+------------+---------------+
| seller_id  | seller_name   |
+------------+---------------+
| 1          | Daniel        |
| 2          | Elizabeth     |
| 3          | Frank         |
+------------+---------------+
输出：
+-------------+
| seller_name |
+-------------+
| Frank       |
+-------------+
解释：
Daniel 在 2020-03-01 有订单；
Elizabeth 在 2020 年有 2 笔订单；

```

## 题解

::: details 点击查看题解

### 思路

求「某集合里没有出现过」的成员，最稳妥的套路是 **左连接 + 判空**：以 `Seller` 为左表，`LEFT JOIN Orders` 时把「2020 年」这个限定写进 `ON` 条件——能连上的说明该卖家 2020 年有单，连不上的行 `Orders` 侧全是 `NULL`，`WHERE o.order_id IS NULL` 筛出的正是全年零单的卖家。

两个关键点。其一，**年份条件必须放 `ON` 而不是 `WHERE`**：如果写 `LEFT JOIN Orders ON ... WHERE YEAR(sale_date) = 2020`，`WHERE` 会作用在左表保留、右表为 `NULL` 的行上，`YEAR(NULL)` 不等于 2020，结果一条都剩不下，全部被误过滤。其二，判空要用 `IS NULL`，不能写 `= NULL`（比较结果仍是 `NULL`，不通过）。

`Customer` 表在本题查询中用不上，是干扰信息。替代写法：`WHERE s.seller_id NOT IN (SELECT seller_id FROM Orders WHERE YEAR(sale_date) = 2020)`，注意子查询结果若含 `NULL` 会让 `NOT IN` 整体失效，本题 `seller_id` 非空所以安全；`NOT EXISTS` 相关子查询同样可写且语义最清晰。

### SQL 实现

```sql
SELECT s.seller_name
FROM Seller s
LEFT JOIN Orders o
    ON s.seller_id = o.seller_id AND YEAR(o.sale_date) = 2020
WHERE o.order_id IS NULL;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为订单数，连接与过滤各扫一遍。
- 空间复杂度：O(k)，k 为卖家数。

:::
