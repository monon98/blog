# 有趣的电影

> 难度：简单 | 标签：条件过滤、排序 | [LeetCode 原题](https://leetcode.cn/problems/not-boring-movies/)

## 题目描述

表：`cinema`

```
+----------------+----------+
| Column Name    | Type     |
+----------------+----------+
| id             | int      |
| movie          | varchar  |
| description    | varchar  |
| rating         | float    |
+----------------+----------+
id 是该表的主键(具有唯一值的列)。
每行包含有关电影名称、类型和评级的信息。
评级为 [0,10] 范围内的小数点后 2 位浮点数。
```

编写解决方案，找出所有影片描述为 **非** `boring` (不无聊) 的并且** id 为奇数 **的影片。

返回结果按 `rating` **降序排列**。

结果格式如下示例。

**示例 1：**

```
输入：
+---------+-----------+--------------+-----------+
|   id    | movie     |  description |  rating   |
+---------+-----------+--------------+-----------+
|   1     | War       |   great 3D   |   8.9     |
|   2     | Science   |   fiction    |   8.5     |
|   3     | irish     |   boring     |   6.2     |
|   4     | Ice song  |   Fantacy    |   8.6     |
|   5     | House card|   Interesting|   9.1     |
+---------+-----------+--------------+-----------+
输出：
+---------+-----------+--------------+-----------+
|   id    | movie     |  description |  rating   |
+---------+-----------+--------------+-----------+
|   5     | House card|   Interesting|   9.1     |
|   1     | War       |   great 3D   |   8.9     |
+---------+-----------+--------------+-----------+
解释：
我们有三部电影，它们的 id 是奇数:1、3 和 5。id = 3 的电影是 boring 的，所以我们不把它包括在答案中。
```

## 题解

::: details 点击查看题解

### 思路

两个过滤条件用 `AND` 串起来：描述不等于 `boring`，且 `id` 是奇数。奇数判断用取模 `id % 2 = 1`（或 `MOD(id, 2) = 1`、按位与 `id & 1 = 1`），因为 `id` 是正整数所以 `= 1` 与 `<> 0` 等价；描述比较用 `description <> 'boring'`。

易错点有三处。第一，`rating` 要 **降序** 排，`ORDER BY rating DESC` 写反方向结果就错。第二，过滤条件必须写在 `WHERE` 里而不是 `SELECT` 里或 `HAVING` 后——本题没有分组，`HAVING` 虽能跑但语义不对。第三，`description` 是精确字符串比较，`boring` 外没有空格，别多写字符；本题数据 `id = 3` 的电影同时满足奇数但描述是 `boring`，两个条件缺一不可。

替代写法：`WHERE id = 1 OR id = 3 OR ...` 这种硬编码显然不行；若描述可能含 `boring` 单词，可用 `NOT LIKE`，但本题是全等比较，`<>` 即可且能走索引。

### SQL 实现

```sql
SELECT *
FROM cinema
WHERE id % 2 = 1 AND description <> 'boring'
ORDER BY rating DESC;
```

### 复杂度分析

- 时间复杂度：O(n log n)，过滤为 O(n)，排序主导。
- 空间复杂度：O(1)，未用额外结构（不计结果集）。

:::
