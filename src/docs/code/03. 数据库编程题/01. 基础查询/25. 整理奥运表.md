# 整理奥运表

> 难度：简单 | 标签：多列排序、ORDER BY | [LeetCode 原题](https://leetcode.cn/problems/sort-the-olympic-table/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表 `Olympic`：

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| country       | varchar |
| gold_medals   | int     |
| silver_medals | int     |
| bronze_medals | int     |
+---------------+---------+
在 SQL 中，country 是该表的主键。
该表中的每一行都显示了一个国家的名称以及它在奥运会上获得的金、银、铜牌的数量。
```

奥运名次表的排序规则如下：

- 金牌越多的国家排名第一。
- 如果金牌数持平，银牌多的国家排名第一。
- 如果银牌数量持平，铜牌数量最多的国家排名第一。
- 如果铜牌中出现并列，那么并列的国家将按照字典的升序进行排序。

写一个解决方案对奥运表进行排序。

返回结果格式示例如下。

**示例 1：**

```
输入：
Olympic 表:
+-------------+-------------+---------------+---------------+
| country     | gold_medals | silver_medals | bronze_medals |
+-------------+-------------+---------------+---------------+
| China       | 10          | 10            | 20            |
| South Sudan | 0           | 0             | 1             |
| USA         | 10          | 10            | 20            |
| Israel      | 2           | 2             | 3             |
| Egypt       | 2           | 2             | 2             |
+-------------+-------------+---------------+---------------+
输出：
+-------------+-------------+---------------+---------------+
| country     | gold_medals | silver_medals | bronze_medals |
+-------------+-------------+---------------+---------------+
| China       | 10          | 10            | 20            |
| USA         | 10          | 10            | 20            |
| Israel      | 2           | 2             | 3             |
| Egypt       | 2           | 2             | 2             |
| South Sudan | 0           | 0             | 1             |
+-------------+-------------+---------------+---------------+
解释：
（当奖牌数相同时）中国与美国的排名先后依据两国名称的字母顺序决定。由于“China”在字母顺序上排在“USA”之前，因此中国位列在前。
以色列排在埃及之前，因为它的铜牌更多。
```

## 题解

::: details 点击查看题解

### 思路

纯排序题：四级排序键，前三级**降序**、最后一级**升序**，把题面的排序规则逐条翻译成 `ORDER BY gold_medals DESC, silver_medals DESC, bronze_medals DESC, country ASC` 即可。

最容易出错的是最后一级：金、银、铜全是「多者靠前」用 `DESC`，但完全并列时要按**国家名字典序升序**——方向相反，必须显式写 `ASC`（或者至少别把 `DESC` 继承下来）。示例中 China 排在 USA 前、Israel 排在 Egypt 前，就是这一级在起作用。

写法上建议用**列名**而不是列序号：`ORDER BY 2 DESC, 3 DESC, 4 DESC, 1` 虽然更短，但表结构一变（比如调整列顺序）就会悄悄排错，列名写法自文档化、可读性也好。另外本题是全表排序、无过滤，不需要 `WHERE`，也不需要去重（`country` 是主键）。替代写法：用列序号的紧凑写法，或先 `SELECT *` 再排序，本质相同。

### SQL 实现

```sql
SELECT country, gold_medals, silver_medals, bronze_medals
FROM Olympic
ORDER BY gold_medals DESC,
         silver_medals DESC,
         bronze_medals DESC,
         country ASC;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为国家数，比较排序。
- 空间复杂度：O(log n)，排序所需栈空间（不含结果集）。

:::
