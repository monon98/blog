# 计算特殊奖金

> 难度：简单 | 标签：CASE WHEN、字符串函数 | [LeetCode 原题](https://leetcode.cn/problems/calculate-special-bonus/)

## 题目描述

表: `Employees`

```
+-------------+---------+
| 列名        | 类型     |
+-------------+---------+
| employee_id | int     |
| name        | varchar |
| salary      | int     |
+-------------+---------+
employee_id 是这个表的主键(具有唯一值的列)。
此表的每一行给出了雇员id ，名字和薪水。
```

编写解决方案，计算每个雇员的奖金。如果一个雇员的 id 是 **奇数** 并且他的名字不是以 `'M'` **开头**，那么他的奖金是他工资的 `100%` ，否则奖金为 `0` 。

返回的结果按照 `employee_id` 排序。

返回结果格式如下面的例子所示。

示例 1:

```
输入：
Employees 表:
+-------------+---------+--------+
| employee_id | name    | salary |
+-------------+---------+--------+
| 2           | Meir    | 3000   |
| 3           | Michael | 3800   |
| 7           | Addilyn | 7400   |
| 8           | Juan    | 6100   |
| 9           | Kannon  | 7700   |
+-------------+---------+--------+
输出：
+-------------+-------+
| employee_id | bonus |
+-------------+-------+
| 2           | 0     |
| 3           | 0     |
| 7           | 7400  |
| 8           | 0     |
| 9           | 7700  |
+-------------+-------+
解释：
因为雇员id是偶数，所以雇员id 是2和8的两个雇员得到的奖金是0。
雇员id为3的因为他的名字以'M'开头，所以，奖金是0。
其他的雇员得到了百分之百的奖金。
```

## 题解

::: details 点击查看题解

### 思路

这是一道「按行计算派生列」的题：每一行要根据条件输出不同结果，标准工具就是 `CASE WHEN ... THEN ... ELSE ... END`。

两个条件是**并且**关系，必须同时满足才发奖金：`employee_id` 为奇数（`employee_id % 2 = 1`）**且**名字不以 `M` 开头（`name NOT LIKE 'M%'`）。注意示例里 id 为 3 的 Michael 两条都踩了坑——既是奇数、又以 `M` 开头，所以奖金为 0，这正好说明两个条件缺一不可，写成 `OR` 结果就全错了。

易错点有三处。其一，`%` 是取模运算符，负数 id 或 0 在本题数据里不会出现，但严谨写法也可用 `MOD(employee_id, 2) = 1`。其二，`LIKE 'M%'` 中 `%` 是通配符（匹配任意多个字符），而 id 判断里的 `%` 是取模——两个符号含义完全不同，别混淆；若要考虑大小写不敏感排序规则下 `m` 开头也算，多数判题环境按题意只认大写 `M`，本题数据也都是大写。其三，奖金列要命名为 `bonus`，且最后必须 `ORDER BY employee_id` 排序。

替代写法：`IF(employee_id % 2 = 1 AND name NOT LIKE 'M%', salary, 0)`，MySQL 特有的两参数/三参数 `IF` 更短；`IFNULL` 之类的函数在本题用不上。

### SQL 实现

```sql
SELECT employee_id,
       CASE
           WHEN employee_id % 2 = 1 AND name NOT LIKE 'M%' THEN salary
           ELSE 0
       END AS bonus
FROM Employees
ORDER BY employee_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为员工数，逐行计算需 O(n)，排序需 O(n log n)。
- 空间复杂度：O(1)，除结果集外只需常数额外空间。
