# 给定数字的频率查询中位数

> 难度：困难 | 标签：窗口函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/find-median-given-frequency-of-numbers/)

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

## 题目描述

表：`Numbers`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| num         | int  |
| frequency   | int  |
+-------------+------+
num 是这张表的主键（具有唯一值的列）。
每一行表示某个数字在数据库中出现的频率。
```

中位数是将数据样本分为上下两半的值。编写一个解决方案，在 **解压（decompress）** `Numbers` 表之后报告所有数字的 **中位数**，并将中位数 **四舍五入保留一位小数**。

结果格式如下所示。

示例：

**输入：**

Numbers 表：

+-----+-----------+
| num | frequency |
+-----+-----------+
| 0   | 7         |
| 1   | 1         |
| 2   | 3         |
| 3   | 1         |
+-----+-----------+

**输出：**

+--------+
| median |
+--------+
| 0.0    |
+--------+

**解释：**

	- 解压 Numbers 表后得到 [0, 0, 0, 0, 0, 0, 0, 1, 2, 2, 2, 3]，共 12 个数。

	- 中位数为第 6、7 个数的平均值，即 (0 + 0) / 2 = 0，保留一位小数为 0.0。

## 题解

::: details 点击查看题解

### 思路

表存的是**压缩形式**（数字 + 出现次数），逐个展开成 12 行再取中间值在 SQL 里既麻烦又低效。正确思路是只用累加频率定位中位数位置：设总数 `s = SUM(frequency)`，从低到高的前缀和 `rk1 = SUM(frequency) OVER (ORDER BY num)`，从高到低的后缀和 `rk2 = SUM(frequency) OVER (ORDER BY num DESC)`。中位数位置 `s / 2`（以及对称的另一半）落在「前缀和刚覆盖该位置」的数字上——`rk1 >= s/2 AND rk2 >= s/2` 的行正是跨越中点的那（些）个数字：个数为奇数时只命中一个数字，偶数时命中两个，`AVG(num)` 取平均恰好就是中位数，最后 `ROUND(..., 1)` 保留一位小数。

代入样例：`s = 12`，`s/2 = 6`。num=0 的 `rk1=7 >= 6`、`rk2=12 >= 6` 入选；num=1 的 `rk2=5 < 6` 落选；num=2 的 `rk2=4 < 6`、num=3 的 `rk2=1 < 6` 均落选。只剩 num=0，`AVG = 0` → `0.0` ✓。

易错点一：只写 `rk1 >= s/2` 会把 1、2、3 全部带上（前缀和都 ≥ 6），后缀条件是配对必须的——两个条件合起来等价于「该数字的频段压住中点」。易错点二：`AVG` 在这里是对**入选数字**求均值，不是按频率加权，这正是中位数偶数长度时「两个中点值取平均」的定义。易错点三：除法 `s / 2` 在 MySQL 中是精确小数除法，若担心 `s` 为奇数时 `s/2` 落在 `.5`，可改成 `rk1 * 2 >= s AND rk2 * 2 >= s` 的整数比较，语义相同更稳妥。替代写法：累加到 `rk1 BETWEEN (s+1)/2 AND (s+2)/2` 之类的位置区间，等价变换。

### SQL 实现

```sql
WITH t AS (
    SELECT num, frequency,
           SUM(frequency) OVER (ORDER BY num ASC)  AS rk1,
           SUM(frequency) OVER (ORDER BY num DESC) AS rk2,
           SUM(frequency) OVER () AS s
    FROM Numbers
)
SELECT ROUND(AVG(num), 1) AS median
FROM t
WHERE rk1 * 2 >= s
  AND rk2 * 2 >= s;
```

### 复杂度分析

- 时间复杂度：O(m log m)，m 为不同数字的个数（窗口排序主导）。
- 空间复杂度：O(m)，累加中间结果与最终的一行输出。

:::
