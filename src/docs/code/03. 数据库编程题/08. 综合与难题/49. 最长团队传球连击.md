# 最长团队传球连击

> 难度：困难 | 标签：窗口函数、多表连接 | [LeetCode 原题](https://leetcode.cn/problems/longest-team-pass-streak/)

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

## 题目描述

表：`Teams`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| player_id   | int     |
| team_name   | varchar |
+-------------+---------+
player_id 是该表的唯一键。
该表的每一行都包含球员的唯一标识以及参加本场比赛的球队名称之一。
```

表：`Passes`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| pass_from   | int     |
| time_stamp  | varchar |
| pass_to     | int     |
+-------------+---------+
(pass_from, time_stamp) 是该表的唯一键。
pass_from 是指向 `Teams.player_id` 的外键。
该表的每一行代表比赛中的一次传球，`time_stamp` 表示传球发生的分钟时刻（00:00-90:00），`pass_to` 是接球球员的 player_id。
```

编写一个查询，找出比赛中每支球队的**最长成功传球连击**。规则如下：

- 成功连击由连续的成功传球组成，要求 `pass_from` 与 `pass_to` 属于**同一支球队**；
- 一旦传球被对方球员截获（接收方属于对方球队），连击即中断。

结果按 `team_name` 升序排列。

**示例：**

输入：

```
Teams 表：

+-----------+-----------+
| player_id | team_name |
+-----------+-----------+
| 1         | Arsenal   |
| 2         | Arsenal   |
| 3         | Arsenal   |
| 4         | Arsenal   |
| 5         | Chelsea   |
| 6         | Chelsea   |
| 7         | Chelsea   |
| 8         | Chelsea   |
+-----------+-----------+

Passes 表：

+-----------+------------+---------+
| pass_from | time_stamp | pass_to |
+-----------+------------+---------+
| 1         | 00:05      | 2       |
| 2         | 00:07      | 3       |
| 3         | 00:08      | 4       |
| 4         | 00:10      | 5       |
| 6         | 00:15      | 7       |
| 7         | 00:17      | 8       |
| 8         | 00:20      | 6       |
| 6         | 00:22      | 5       |
| 1         | 00:25      | 2       |
| 2         | 00:27      | 3       |
+-----------+------------+---------+
```

输出：

```
+-----------+----------------+
| team_name | longest_streak |
+-----------+----------------+
| Arsenal   | 3              |
| Chelsea   | 4              |
+-----------+----------------+
```

解释：

- Arsenal 的连击：第一段连击 3 次（1→2→3→4），随后 4 把球传给 Chelsea 的 5 号而中断；第二段连击 2 次（1→2→3）。最长为 3。
- Chelsea 的连击：一段连击 4 次（6→7→8→6→5），最长为 4。

## 题解

::: details 点击查看题解

### 思路

「连击」是被**中断事件**切开的连续段，典型的「岛屿问题」：

1. **标注每次传球**：把 `Passes` 分别按 `pass_from`、`pass_to` 连接 `Teams` 两次，得到发起方与接收方球队，`same_team_flag = IF(t1.team_name = t2.team_name, 1, 0)`；
2. **给连续段编号**：按发起方球队分区、`time_stamp` 排序，对「中断」（`same_team_flag = 0`）做累计求和
   `SUM(CASE WHEN flag = 0 THEN 1 ELSE 0 END) OVER (...)` 作为 `group_id`——每出现一次中断组号加 1，同一段连击内的传球组号相同；
3. **只保留成功传球**（`WHERE same_team_flag = 1`，中断那一脚本身不计入连击），按 `(team_name, group_id)` 计数即每段连击长度；
4. 按球队取 `MAX` 得最长连击，最后按 `team_name` 排序。

用累计和切段比递归 CTE 更简洁，也不受连击长度限制。


### SQL 实现

```sql
WITH PassesWithTeams AS (
    SELECT t1.team_name AS team_from,
           IF(t1.team_name = t2.team_name, 1, 0) AS same_team_flag,
           p.time_stamp
    FROM Passes p
    JOIN Teams t1 ON p.pass_from = t1.player_id
    JOIN Teams t2 ON p.pass_to = t2.player_id
),
StreakGroups AS (
    SELECT team_from AS team_name,
           same_team_flag,
           SUM(CASE WHEN same_team_flag = 0 THEN 1 ELSE 0 END)
               OVER (PARTITION BY team_from ORDER BY time_stamp) AS group_id
    FROM PassesWithTeams
),
StreakLengths AS (
    SELECT team_name,
           group_id,
           COUNT(*) AS streak_length
    FROM StreakGroups
    WHERE same_team_flag = 1
    GROUP BY team_name, group_id
)
SELECT team_name,
       MAX(streak_length) AS longest_streak
FROM StreakLengths
GROUP BY team_name
ORDER BY team_name;
```

### 复杂度分析

- **时间复杂度**：`O(p log p)`，两次连接为线性，窗口排序与分组聚合带排序开销（`p` 为传球数）。
- **空间复杂度**：`O(p)`，窗口与分组的中间结果。
:::
