# 查找重叠的班次 II

> 难度：困难 | 标签：窗口函数、自连接 | [LeetCode 原题](https://leetcode.cn/problems/find-overlapping-shifts-ii/)

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

## 题目描述

表：`EmployeeShifts`

```
+------------------+----------+
| Column Name      | Type     |
+------------------+----------+
| employee_id      | int      |
| start_time       | datetime |
| end_time         | datetime |
+------------------+----------+
(employee_id, start_time) 是该表的唯一键。
该表记录了员工班次的开始与结束时间。
```

编写一个查询分析每位员工的重叠班次。如果两个班次发生在**同一天**，且一个班次的 `end_time` 晚于另一个班次的 `start_time`，则认为这两个班次重叠。

对每位员工计算：

- 任意时刻同时重叠的班次**最大数量**；
- 所有重叠部分的**总时长（分钟）**——两两班次的重叠时长之和。

结果按 `employee_id` 升序排列。

**示例：**

输入：

```
EmployeeShifts 表：

+-------------+---------------------+---------------------+
| employee_id | start_time          | end_time            |
+-------------+---------------------+---------------------+
| 1           | 2023-10-01 09:00:00 | 2023-10-01 17:00:00 |
| 1           | 2023-10-01 15:00:00 | 2023-10-01 23:00:00 |
| 1           | 2023-10-01 16:00:00 | 2023-10-02 00:00:00 |
| 2           | 2023-10-01 09:00:00 | 2023-10-01 17:00:00 |
| 2           | 2023-10-01 11:00:00 | 2023-10-01 19:00:00 |
| 3           | 2023-10-01 09:00:00 | 2023-10-01 17:00:00 |
+-------------+---------------------+---------------------+
```

输出：

```
+-------------+---------------------------+------------------------+
| employee_id | max_overlapping_shifts    | total_overlap_duration |
+-------------+---------------------------+------------------------+
| 1           | 3                         | 600                    |
| 2           | 2                         | 360                    |
| 3           | 1                         | 0                      |
+-------------+---------------------------+------------------------+
```

解释：

- 员工 1 有三个班次：09:00–17:00、15:00–23:00、16:00–次日 00:00。16:00–17:00 期间三个班次同时进行，故最大重叠数为 3。重叠总时长 = 2 小时（1、2 班次）+ 1 小时（1、3 班次）+ 7 小时（2、3 班次）= 10 小时 = 600 分钟。
- 员工 2 有两个班次：09:00–17:00 与 11:00–19:00，重叠 11:00–17:00 共 6 小时 = 360 分钟，最大重叠数为 2。
- 员工 3 只有一个班次，没有重叠，最大重叠数为 1，总重叠时长为 0。

注意：结果按 `employee_id` 升序排列。

## 题解

::: details 点击查看题解

### 思路

两个指标分别处理：

1. **最大同时重叠数**：端点扫描。把每位员工所有班次的 `start_time`、`end_time` 去重合并，用 `LEAD` 把相邻端点切成一段段区间；区间回连 `EmployeeShifts`（`st >= start_time AND ed <= end_time`），`COUNT(*)` 即该区间的并发班次数。每个区间内并发数恒定，取 `MAX` 即为答案。任务之间的空档匹配不到任何班次，会被自动过滤。

2. **重叠总时长**：对并发数为 `c` 的区间，其中任意两两班次都重叠，重叠对数为 `C(c, 2) = c*(c-1)/2`，每一对在该区间内都贡献整段时长。因此
   `SUM(C(c, 2) * 区间分钟数)` 恰好等于「所有两两重叠时长之和」——这与逐对自连接求 `LEAST(end1, end2) - MAX(start1, start2)` 的结果一致，但只需一次扫描。

   用 `DIV` 做整数除法避免结果带小数位；`c*(c-1)` 一定是偶数，整除没有精度损失。

   单班次员工只会产生并发数为 1 的区间，`C(1,2)=0`，最大重叠数为 1、总时长为 0，与官方输出一致。


### SQL 实现

```sql
WITH endpoints AS (
    SELECT DISTINCT employee_id, start_time AS st
    FROM EmployeeShifts
    UNION DISTINCT
    SELECT DISTINCT employee_id, end_time AS st
    FROM EmployeeShifts
),
segments AS (
    SELECT employee_id,
           st,
           LEAD(st) OVER (PARTITION BY employee_id ORDER BY st) AS ed
    FROM endpoints
),
covered AS (
    SELECT s.employee_id,
           s.st,
           s.ed,
           COUNT(*) AS concurrent_count
    FROM segments s
    INNER JOIN EmployeeShifts e USING (employee_id)
    WHERE s.st >= e.start_time
      AND s.ed <= e.end_time
    GROUP BY s.employee_id, s.st, s.ed
)
SELECT employee_id,
       MAX(concurrent_count) AS max_overlapping_shifts,
       SUM(concurrent_count * (concurrent_count - 1) DIV 2
           * TIMESTAMPDIFF(MINUTE, st, ed)) AS total_overlap_duration
FROM covered
GROUP BY employee_id
ORDER BY employee_id;
```

### 复杂度分析

- **时间复杂度**：`O(n log n)`，端点排序 + 回连近似线性（`n` 为班次数）。
- **空间复杂度**：`O(n)`，端点与区间的中间结果。
:::
