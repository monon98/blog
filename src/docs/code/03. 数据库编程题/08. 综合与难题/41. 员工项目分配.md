# 员工项目分配

> 难度：困难 | 标签：多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/employees-project-allocation/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Project` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| project_id  | int     |
| employee_id | int     |
| workload    | int     |
+-------------+---------+
employee_id 是该表的主键，同时是 Employees 表的外键。
每一行表示该员工参与某个项目及其在该项目上的工作量。
```

`Employees` 表：

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| employee_id      | int     |
| name             | varchar |
| team             | varchar |
+------------------+---------+
employee_id 是该表的主键。
每一行包含一名员工的 ID、姓名和所属团队。
```

编写一个解决方案，找出**在某个项目上的工作量超过其所在团队平均工作量**的员工。

- 团队平均工作量 = 该团队**所有员工的项目工作量**（即 `Project` 与 `Employees` 连接后）的平均值。
- 返回 `employee_id`、`project_id`、`employee_name`、`project_workload`，按 `employee_id`、`project_id` 升序排序。

**示例 1：**

输入：

```
Project 表：
+-------------+-------------+----------+
| project_id  | employee_id | workload |
+-------------+-------------+----------+
| 1           | 1           | 45       |
| 1           | 2           | 90       |
| 2           | 3           | 12       |
| 2           | 4           | 68       |
+-------------+-------------+----------+

Employees 表：
+-------------+--------+------+
| employee_id | name   | team |
+-------------+--------+------+
| 1           | Khaled | A    |
| 2           | Ali    | B    |
| 3           | John   | B    |
| 4           | Doe    | A    |
+-------------+--------+------+
```

输出：

```
+-------------+------------+---------------+------------------+
| employee_id | project_id | employee_name | project_workload |
+-------------+------------+---------------+------------------+
| 2           | 1          | Ali           | 90               |
| 4           | 2          | Doe           | 68               |
+-------------+------------+---------------+------------------+
```

解释：

- 团队 A 的平均工作量 = (45 + 68) / 2 = 56.50：Khaled 的 45 不超过 56.50，排除；Doe 的 68 超过，入选。
- 团队 B 的平均工作量 = (90 + 12) / 2 = 51.00：Ali 的 90 超过 51.00，入选；John 的 12 不超过，排除。

## 题解

::: details 点击查看题解

### 思路

「与团队平均值比较」是典型的**先聚合、再回连**模式：团队平均值不在任何一张表里，必须先算出来。

具体分两步：先把 `Project` 和 `Employees` 按 `employee_id` 连接，这样每一行既有工作量又有团队；接着按 `team` 分组求 `AVG(workload)` 得到团队均值表 `T`；最后把 `T` 按 `team` 再连接回去，用 `WHERE workload > avg_workload` 过滤。注意均值必须基于「连接后的项目工作量」计算，而不是对 `Employees` 或 `Project` 单表聚合——单表里拿不到「团队 + 工作量」这两个字段。

窗口函数是等价的替代写法：连接后直接 `AVG(workload) OVER (PARTITION BY team)`，一行搞定均值列，省掉一次连接，可读性更好。两种写法都注意比较是**严格大于**（`>`），等于团队均值的员工要排除。

易错点：一是把平均值算在 `Project` 表上（没有 team 列，会得到全局均值）；二是均值用整数除法（`SUM/COUNT` 在某些方言下取整）导致边界判断失真——`AVG()` 本身返回小数，直接用即可；三是忘了输出要的是**项目行**（一个员工参与多个项目就有多行），按 `employee_id, project_id` 双重排序。

### SQL 实现

```sql
WITH team_avg AS (
    SELECT e.team,
           AVG(p.workload) AS avg_workload
    FROM Project AS p
    JOIN Employees AS e USING (employee_id)
    GROUP BY e.team
)
SELECT p.employee_id,
       p.project_id,
       e.name AS employee_name,
       p.workload AS project_workload
FROM Project AS p
JOIN Employees AS e USING (employee_id)
JOIN team_avg AS t USING (team)
WHERE p.workload > t.avg_workload
ORDER BY p.employee_id, p.project_id;
```

### 复杂度分析

- 时间复杂度：O(n + m + g log g)，n 为项目行数、m 为员工数、g 为团队数（分组求均值需要排序）。
- 空间复杂度：O(g)，保存每个团队一个均值。
