# 最多连胜的次数

> 难度：困难 | 标签：窗口函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/longest-winning-streak/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Matches`

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| player_id   | int  |
| match_day   | date |
| result      | enum |
+-------------+------+
(player_id, match_day) 是该表的主键（具有唯一值的列的组合）。
每一行包括了参赛选手 id、比赛时间、比赛结果。
比赛结果（result）的枚举类型为 ('Win', 'Draw', 'Lose')。
```

选手的**连胜数**是指连续获胜的次数，且没有被平局或输球中断（按比赛的先后顺序计算，与两场比赛之间隔了多少天无关）。编写解决方案来计算每个参赛选手最多的连胜数，返回列 `player_id`、`longest_streak`，结果可以以任意顺序返回。

**示例 1：**

输入：

```
Matches 表：
+-----------+------------+--------+
| player_id | match_day  | result |
+-----------+------------+--------+
| 1         | 2022-01-17 | Win    |
| 1         | 2022-01-18 | Win    |
| 1         | 2022-01-25 | Win    |
| 1         | 2022-01-31 | Draw   |
| 1         | 2022-02-08 | Win    |
| 2         | 2022-02-06 | Lose   |
| 2         | 2022-02-08 | Lose   |
| 3         | 2022-03-30 | Win    |
+-----------+------------+--------+
```

输出：

```
+-----------+----------------+
| player_id | longest_streak |
+-----------+----------------+
| 1         | 3              |
| 2         | 0              |
| 3         | 1              |
+-----------+----------------+
```

解释：

- 选手 1：从 2022-01-17 到 2022-01-25 连赢三场（注意 01-18 到 01-25 之间隔了 7 天，仍算连续获胜），01-31 平局中断，02-08 又赢一场，所以最长连胜是 3。
- 选手 2：连输两场，最长连胜为 0。
- 选手 3：只赢了一场，最长连胜为 1。

## 题解

::: details 点击查看题解

### 思路

先明确口径：连胜是**按比赛场次顺序**的连续获胜，与日历天是否连续无关——示例里 01-17、01-18、01-25 三场胜利就构成长度 3 的连胜。所以只需要按 `match_day` 排序后识别「连续相同结果的段」，不要写 `DATEDIFF = 1` 之类的日期连续判断，否则选手 1 会算成 2 而错。

「连续相同值分组」是窗口函数经典技巧：同一选手内按日期的**总行号**减去按（选手、结果）分组的**行号**，在一段连续相同结果中差值恒定，且不同段的差值互不相同。例如选手 1 的行号为 1,2,3,4,5，Win 段内行号为 1,2,3 和 5，Draw 行号为 1，差值依次是 0,0,0,3,1——两段 Win 被 3 隔开，分属不同组。有了分组键，`SUM(result = 'Win')` 就是该段的连胜长度（非 Win 段自然为 0），外层按选手取 `MAX` 即得答案。

注意两点：其一，没有胜场的选手（如选手 2）也必须出现在结果里、连赢单为 0——因为分组来自 `Matches` 全表，只要该选手有任意比赛记录，分组就存在，`MAX` 得 0；其二，输出列名是 `longest_streak`。替代写法：`LAG` 标记段首（上一行不是 Win）再累加段号，或自连接计数，但「行号差」写法最短且一趟窗口完成。

### SQL 实现

```sql
WITH S AS (
    SELECT
        player_id,
        result,
        ROW_NUMBER() OVER (PARTITION BY player_id ORDER BY match_day)
            - ROW_NUMBER() OVER (PARTITION BY player_id, result ORDER BY match_day) AS rk
    FROM Matches
),
T AS (
    SELECT player_id, SUM(result = 'Win') AS streak
    FROM S
    GROUP BY player_id, rk
)
SELECT player_id, MAX(streak) AS longest_streak
FROM T
GROUP BY player_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，两次窗口排序，n 为比赛场次数。
- 空间复杂度：O(n)，窗口中间结果与分组结果。
