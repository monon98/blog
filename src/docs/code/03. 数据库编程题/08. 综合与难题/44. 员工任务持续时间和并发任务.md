# 员工任务持续时间和并发任务

> 难度：困难 | 标签：窗口函数、聚合函数 | [LeetCode 原题](https://leetcode.cn/problems/employee-task-duration-and-concurrent-tasks/)

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

## 题目描述

表：`Tasks`

```
+---------------+----------+
| Column Name   | Type     |
+---------------+----------+
| task_id       | int      |
| employee_id   | int      |
| start_time    | datetime |
| end_time      | datetime |
+---------------+----------+
(task_id, employee_id) 是该表的主键。
该表的每一行都包含任务标识、员工标识以及任务的开始和结束时间。
```

编写一个查询，找出每位员工的总任务时长（**重叠部分只计一次**，并向下取整到完整小时）以及任意时刻同时进行的最大任务数。

结果按 `employee_id` 升序排列。

**示例：**

输入：

```
Tasks 表：

+---------+-------------+---------------------+---------------------+
| task_id | employee_id | start_time          | end_time            |
+---------+-------------+---------------------+---------------------+
| 1       | 1001        | 2023-05-01 08:00:00 | 2023-05-01 09:00:00 |
| 2       | 1001        | 2023-05-01 08:30:00 | 2023-05-01 10:30:00 |
| 3       | 1001        | 2023-05-01 11:00:00 | 2023-05-01 12:00:00 |
| 7       | 1001        | 2023-05-01 13:00:00 | 2023-05-01 15:30:00 |
| 4       | 1002        | 2023-05-01 09:00:00 | 2023-05-01 10:00:00 |
| 5       | 1002        | 2023-05-01 09:30:00 | 2023-05-01 11:30:00 |
| 6       | 1003        | 2023-05-01 14:00:00 | 2023-05-01 16:00:00 |
+---------+-------------+---------------------+---------------------+
```

输出：

```
+-------------+------------------+----------------------+
| employee_id | total_task_hours | max_concurrent_tasks |
+-------------+------------------+----------------------+
| 1001        | 6                | 2                    |
| 1002        | 2                | 2                    |
| 1003        | 2                | 1                    |
+-------------+------------------+----------------------+
```

解释：

- 对于员工 1001：任务 1 和任务 2 在 08:30 到 09:00 之间重叠（30 分钟）；任务 7 持续 150 分钟。总时长 = 60 + 120 + 60 + 150 - 30（重叠）= 360 分钟 = 6 小时，最大并发数为 2。
- 对于员工 1002：任务 4 和任务 5 在 09:30 到 10:00 之间重叠（30 分钟）；总时长 = 60 + 120 - 30 = 150 分钟，向下取整为 2 小时，最大并发数为 2。
- 对于员工 1003：没有重叠任务，总时长 120 分钟 = 2 小时，最大并发数为 1。

## 题解

::: details 点击查看题解

### 思路

两个指标都要先解决「重叠去重」：

- **总时长**：把每位员工的所有任务拆成不重叠的时间片段再求和，重叠区间自然只算一次。
- **最大并发数**：每个「片段」内并发数不变，取片段并发数的最大值即可。

用端点扫描（line sweep）实现：

1. `UNION DISTINCT` 取出每位员工所有任务的起点与终点作为端点集合；
2. `LEAD(st)` 得到每个端点之后的下一个端点，从而把时间轴切成一段段连续区间；
3. 用区间回连 `Tasks`：若某个区间完全落在某个任务内（`st >= start_time AND ed <= end_time`），则该区间属于该任务的覆盖范围，`COUNT(*)` 即该区间的并发任务数；
4. 最后按员工聚合：`FLOOR(SUM(区间秒数) / 3600)` 得到去重后的总小时数，`MAX(并发数)` 即峰值并发。

任务之间的空档（如 10:30–11:00）回连时匹配不到任何任务，会被自然过滤掉，不会计入时长。


### SQL 实现

```sql
WITH endpoints AS (
    SELECT DISTINCT employee_id, start_time AS st
    FROM Tasks
    UNION DISTINCT
    SELECT DISTINCT employee_id, end_time AS st
    FROM Tasks
),
segments AS (
    SELECT employee_id,
           st,
           LEAD(st) OVER (PARTITION BY employee_id ORDER BY st) AS ed
    FROM endpoints
),
covered AS (
    SELECT s.employee_id,
           s.st,
           s.ed,
           COUNT(*) AS concurrent_count
    FROM segments s
    INNER JOIN Tasks t USING (employee_id)
    WHERE s.st >= t.start_time
      AND s.ed <= t.end_time
    GROUP BY s.employee_id, s.st, s.ed
)
SELECT employee_id,
       FLOOR(SUM(TIMESTAMPDIFF(SECOND, st, ed) / 3600)) AS total_task_hours,
       MAX(concurrent_count) AS max_concurrent_tasks
FROM covered
GROUP BY employee_id
ORDER BY employee_id;
```

### 复杂度分析

- **时间复杂度**：`O(n log n)`，端点排序来自窗口排序，回连与聚合近似线性。
- **空间复杂度**：`O(n)`，端点与片段的中间结果。
:::
