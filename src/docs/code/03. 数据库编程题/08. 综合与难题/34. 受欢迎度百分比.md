# 受欢迎度百分比

> 难度：困难 | 标签：并集去重、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/popularity-percentage/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Friends`

```
+-------------+------+
| 列名        | 类型  |
+-------------+------+
| user1       | int  |
| user2       | int  |
+-------------+------+
```

`(user1, user2)` 是该表的主键（具有唯一值的列）。每一行表示一条好友关系，即 `user1` 与 `user2` 是朋友。

编写一条 SQL 查询，找出 Meta/Facebook 平台上每个用户的**受欢迎度百分比**。受欢迎度百分比定义为：该用户的朋友总数 ÷ 平台上的总用户数 × 100，并**四舍五入保留 2 位小数**。按 `user1` 升序返回结果表。

**示例 1：**

输入：

```
Friends 表:
+-------+-------+
| user1 | user2 |
+-------+-------+
| 2     | 1     |
| 1     | 3     |
| 4     | 1     |
| 1     | 5     |
| 1     | 6     |
| 2     | 6     |
| 7     | 2     |
| 8     | 3     |
| 3     | 9     |
+-------+-------+
```

输出：

```
+-------+-----------------------+
| user1 | percentage_popularity |
+-------+-----------------------+
| 1     | 55.56                 |
| 2     | 33.33                 |
| 3     | 33.33                 |
| 4     | 11.11                 |
| 5     | 11.11                 |
| 6     | 22.22                 |
| 7     | 11.11                 |
| 8     | 11.11                 |
| 9     | 11.11                 |
+-------+-----------------------+
```

解释：

- 平台上总共有 9 个用户。
- 用户 1 与 2、3、4、5、6 是朋友，受欢迎度为 (5 / 9) × 100 = 55.56。
- 用户 2 与 1、6、7 是朋友，受欢迎度为 (3 / 9) × 100 = 33.33。
- 用户 3 与 1、8、9 是朋友，受欢迎度为 (3 / 9) × 100 = 33.33。
- 用户 6 与 1、2 是朋友，受欢迎度为 (2 / 9) × 100 = 22.22。
- 其余用户各只有 1 个朋友，受欢迎度为 (1 / 9) × 100 = 11.11。

## 题解

::: details 点击查看题解

### 思路

好友表只存**单向**的一条边，但好友关系是无向的：`(2, 1)` 出现过，`(1, 2)` 就不应该再算一次。直接按 `user1` 分组统计会漏掉那些只以 `user2` 身份出现的用户，所以第一步用 `UNION` 把反向边 `(user2, user1)` 并进来，得到无向好友表 `F`。`UNION` 自带去重，即使极端情况下同一对好友两个方向都存了，也只会保留一条，避免重复计数。

分母是**平台总用户数**，即 `F` 中出现过的不同用户个数 `COUNT(DISTINCT user1)`，用标量子查询取出，与分子的分组互不干扰。分子是每个用户在 `F` 中的度数（好友数），按 `user1` 分组 `COUNT` 即可。

四舍五入保留两位小数用 `ROUND(x, 2)`。注意分母要用浮点除法语义：`COUNT(...) * 100 / cnt` 中 `100` 是整数、`cnt` 是整数，MySQL 的 `/` 本身返回十进制小数，不会发生整数截断，但若写成 `FLOOR`/`DIV` 就会丢掉小数位——这题必须用 `/`。最后按 `user1` 升序排列（`ORDER BY user1`）。

### SQL 实现

```sql
WITH F AS (
    SELECT user1, user2 FROM Friends
    UNION
    SELECT user2 AS user1, user1 AS user2 FROM Friends
)
SELECT
    user1,
    ROUND(COUNT(DISTINCT user2) * 100 / (SELECT COUNT(DISTINCT user1) FROM F), 2) AS percentage_popularity
FROM F
GROUP BY user1
ORDER BY user1;
```

### 复杂度分析

- 时间复杂度：O(n log n)，`UNION` 去重与分组排序，n 为好友关系条数。
- 空间复杂度：O(n)，并集结果的中间存储。
