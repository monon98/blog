# 最好的三家酒庄

> 难度：困难 | 标签：分组聚合、窗口函数 | [LeetCode 原题](https://leetcode.cn/problems/top-three-wineries/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Wineries` 表：

```
+-------------+----------+
| Column Name | Type     |
+-------------+----------+
| id          | int      |
| country     | varchar  |
| points      | int      |
| winery      | varchar  |
+-------------+----------+
id 是这张表的唯一主键。
每一行表示某国某酒庄获得的一次评分。
```

编写一个解决方案，找出**每个国家总分最高的三家酒庄**：

- 先按 `country`、`winery` 汇总，得到每个酒庄在该国家的累计总分。
- 在每个国家内部按总分降序排名；总分相同时按酒庄名字典序升序排在前面。
- 返回 `country`、`top_winery`、`second_winery`、`third_winery`，酒庄统一格式化为 `酒庄名 (总分)`。
- 如果某个国家不足三家酒庄，第二、第三名分别用字符串 `No second winery`、`No third winery` 填充。

结果按 `country` 升序排序。

**示例 1：**

输入：

```
Wineries 表：
+-----+-----------+--------+-----------------+
| id  | country   | points | winery          |
+-----+-----------+--------+-----------------+
| 103 | Australia | 84     | WhisperingPines |
| 737 | Australia | 85     | GrapesGalore    |
| 848 | Australia | 100    | HarmonyHill     |
| 222 | Hungary   | 60     | MoonlitCellars  |
| 116 | USA       | 47     | RoyalVines      |
| 124 | USA       | 45     | Eagle'sNest     |
| 648 | India     | 69     | SunsetVines     |
| 894 | USA       | 39     | RoyalVines      |
| 677 | USA       | 9      | PacificCrest    |
+-----+-----------+--------+-----------------+
```

输出：

```
+-----------+---------------------+-------------------+----------------------+
| country   | top_winery          | second_winery     | third_winery         |
+-----------+---------------------+-------------------+----------------------+
| Australia | HarmonyHill (100)   | GrapesGalore (85) | WhisperingPines (84) |
| Hungary   | MoonlitCellars (60) | No second winery  | No third winery      |
| India     | SunsetVines (69)    | No second winery  | No third winery      |
| USA       | RoyalVines (86)     | Eagle'sNest (45)  | PacificCrest (9)     |
+-----------+---------------------+-------------------+----------------------+
```

解释：

- 澳大利亚：HarmonyHill 100 分居首，GrapesGalore 85 分第二，WhisperingPines 84 分第三。
- 匈牙利、印度：各自只有一家酒庄，第二、第三名用占位字符串填充。
- 美国：RoyalVines 有两条记录（47 + 39 = 86），先汇总后以 86 分排名第一；Eagle'sNest 45 分第二，PacificCrest 9 分第三。
- 注意同分时按酒庄名字典序排序，所以排名与国家内部的行顺序无关。

## 题解

::: details 点击查看题解

### 思路

关键点是「先汇总、再排名、最后行转列」。同一酒庄在一个国家可能有多条评分行（比如美国的 RoyalVines 出现两次），直接对原始行排名会把一家酒庄算成两个名次，所以第一步必须 `GROUP BY country, winery` 求 `SUM(points)`。

排名用窗口函数 `ROW_NUMBER() OVER (PARTITION BY country ORDER BY total_points DESC, winery ASC)`。排序键里加上 `winery` 是为了满足「同分按酒庄名字典序」的平局规则；正因为这个 tie-break 让顺序完全确定，用 `ROW_NUMBER()` 或 `RANK()` 效果一致。注意 MySQL 8 里 `RANK` 是保留字，如果用它做列名要加反引号，取别名 `rn` 可以直接绕开。

行转列的常见写法有两种：三次 `LEFT JOIN`（分别取名次 1、2、3），或者过滤 `rn <= 3` 后按国家分组、用 `MAX(CASE WHEN rn = k THEN ... END)` 把每个名次摊成一列。本题采用后者，一条语句就能完成；占位串用 `IFNULL(..., 'No second winery')` 补齐。由于 `rn = 1` 的行在每个国家必然存在，`top_winery` 不会为 NULL，而第二、三名在不足三家时是 NULL，正好被 `IFNULL` 捕获。

易错点：一是忘记先按酒庄汇总就排名；二是排序时只按 `points DESC`，同分时结果不稳定；三是 `WHERE rn <= 3` 必须放在分组之前过滤（只保留前三名的行），若放在聚合之后就没有意义了。

### SQL 实现

```sql
WITH ranked AS (
    SELECT country,
           CONCAT(winery, ' (', total_points, ')') AS winery_info,
           ROW_NUMBER() OVER (
               PARTITION BY country
               ORDER BY total_points DESC, winery ASC
           ) AS rn
    FROM (
        SELECT country, winery, SUM(points) AS total_points
        FROM Wineries
        GROUP BY country, winery
    ) AS t
)
SELECT country,
       MAX(CASE WHEN rn = 1 THEN winery_info END) AS top_winery,
       IFNULL(MAX(CASE WHEN rn = 2 THEN winery_info END), 'No second winery') AS second_winery,
       IFNULL(MAX(CASE WHEN rn = 3 THEN winery_info END), 'No third winery') AS third_winery
FROM ranked
WHERE rn <= 3
GROUP BY country
ORDER BY country;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为「国家 × 酒庄」的去重行数，分组求和与窗口排序都在这个规模上完成。
- 空间复杂度：O(n)，窗口函数需要按国家保存排名后的中间结果。
