# 查找得分最高的学生 II

> 难度：困难 | 标签：多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/find-top-scoring-students-ii/)

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

## 题目描述

表：`students`

```
+-------------+-------------------+
| Column Name | Type              |
+-------------+-------------------+
| student_id  | int               |
| name        | varchar(255)      |
| major       | varchar(255)      |
+-------------+-------------------+
student_id 是该表的主键。
该表的每一行都包含学生 ID、姓名和专业。
```

表：`courses`

```
+-------------+-------------------+
| Column Name | Type              |
+-------------+-------------------+
| course_id   | int               |
| name        | varchar(255)      |
| credits     | int               |
| major       | varchar(255)      |
| mandatory   | enum('Yes', 'No') |
+-------------+-------------------+
course_id 是该表的主键。
该表的每一行都包含课程 ID、课程名称、学分、所属专业，以及该课程是否为必修课。
```

表：`enrollments`

```
+-------------+---------------+
| Column Name | Type          |
+-------------+---------------+
| student_id  | int           |
| course_id   | int           |
| semester    | varchar(255)  |
| grade       | varchar(10)   |
| GPA         | decimal(3,2)  |
+-------------+---------------+
(student_id, course_id, semester) 是该表的主键。
该表的每一行都包含学生 ID、课程 ID、学期以及该次选课的成绩与 GPA。
```

编写一个查询，找出满足以下**所有**条件的学生：

- 修完了其专业开设的全部必修课，并且至少选修了其专业的两门选修课；
- 所有必修课成绩均为 `A`，选修课成绩至少为 `B`；
- 所有课程（**包括非本专业的课程**）的平均 `GPA` 不低于 `2.5`。

结果按 `student_id` 升序排列。

## 题解

::: details 点击查看题解

### 思路

条件分两层：

1. **GPA 门槛**：先用子查询/CTE 按学生聚合 `AVG(GPA) >= 2.5` 筛出候选（GPA 要算全部课程，包括外专业）。
2. **必修 / 选修校验**：把候选学生与 `students`、`courses`（按 `major` 关联，得到该专业的**全部**课程清单）相连，再 `LEFT JOIN enrollments`。这样「没修的必修课」会以 `grade IS NULL` 的形式出现在结果里，配合条件聚合即可识别：
   - `SUM(mandatory = 'yes' AND grade = 'A') = SUM(mandatory = 'yes')`：专业所有必修课都修了且都是 `A`（漏修的行 `grade` 为空，两边同时少计，仍能发现漏修）；
   - `SUM(mandatory = 'no' AND grade IS NOT NULL) = SUM(mandatory = 'no' AND grade IN ('A','B'))`：已选的选修课成绩全部不低于 `B`；
   - `SUM(mandatory = 'no' AND grade IS NOT NULL) >= 2`：至少选修了两门选修课。

最后按 `student_id` 分组、`HAVING` 过滤并排序。`LEFT JOIN` 是关键——若用 `INNER JOIN`，漏修的必修课会被静默丢掉，导致误判。


### SQL 实现

```sql
WITH T AS (
    SELECT student_id
    FROM enrollments
    GROUP BY student_id
    HAVING AVG(GPA) >= 2.5
)
SELECT T.student_id
FROM T
JOIN students USING (student_id)
JOIN courses USING (major)
LEFT JOIN enrollments USING (student_id, course_id)
GROUP BY T.student_id
HAVING SUM(mandatory = 'yes' AND grade = 'A') = SUM(mandatory = 'yes')
   AND SUM(mandatory = 'no' AND grade IS NOT NULL) = SUM(mandatory = 'no' AND grade IN ('A', 'B'))
   AND SUM(mandatory = 'no' AND grade IS NOT NULL) >= 2
ORDER BY T.student_id;
```

### 复杂度分析

- **时间复杂度**：`O(m log m + n)`，`m` 为选课记录数（分组排序），`n` 为学生数 × 专业课程数。
- **空间复杂度**：`O(m)`，GPA 聚合与连接的中间结果。
:::
