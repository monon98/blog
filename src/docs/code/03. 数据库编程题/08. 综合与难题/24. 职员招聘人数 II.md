# 职员招聘人数 II

> 难度：困难 | 标签：窗口函数、子查询、UNION | [LeetCode 原题](https://leetcode.cn/problems/the-number-of-seniors-and-juniors-to-join-the-company-ii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Candidates`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| employee_id | int     |
| experience  | enum    |
| salary      | int     |
+-------------+---------+
employee_id 是该表中具有唯一值的列。
experience 是一个枚举，包含 'Senior'、'Junior' 两个值。
此表的每一行都显示候选人的 id、月薪和经验。
每个候选人的工资保证是唯一的。
```

一家公司想雇佣新员工，公司的工资预算是 **70000 美元**。招聘标准是：

- 持续雇佣薪水最低的高级职员，直到不能再雇佣更多高级职员为止；
- 用剩下的预算雇佣薪水最低的初级职员，持续雇佣直到不能再雇佣更多初级职员为止。

编写一个解决方案，查找按上述条件雇用的职员 ID。按任意顺序返回结果表。

**示例 1：**

输入：

```
Candidates 表：
+-------------+------------+--------+
| employee_id | experience | salary |
+-------------+------------+--------+
| 1           | Junior     | 10000  |
| 9           | Junior     | 15000  |
| 2           | Senior     | 20000  |
| 11          | Senior     | 16000  |
| 13          | Senior     | 50000  |
| 4           | Junior     | 40000  |
+-------------+------------+--------+
```

输出：

```
+-------------+
| employee_id |
+-------------+
| 11          |
| 2           |
| 1           |
| 9           |
+-------------+
```

解释：

- 高级员工按薪水升序为 16000（ID 11）、20000（ID 2）、50000（ID 13）。前两人工资合计 36000，预算还剩 34000，不足以雇佣 ID 13，因此录用 (11, 2)。
- 剩余 34000 预算下，初级员工按薪水升序为 10000（ID 1）、15000（ID 9）、40000（ID 4）。前两人合计 25000，还剩 9000，不足以雇佣 ID 4，因此录用 (1, 9)。

## 题解

::: details 点击查看题解

### 思路

规则与 2004 完全相同（预算 70000、Senior 优先、同类按薪水升序贪心），差别只在**输出被录取的具体 employee_id**，而不是两个计数；另外本题保证工资唯一，不存在并列工资的歧义。整体框架仍然照搬：两个 CTE 分别对 Senior、Junior 求薪水升序的累计工资，筛掉「录到此人时累计超过预算」的行，再 `UNION` 合并编号。

两个细节值得注意。第一，Junior 的累计支出必须**叠加 Senior 已花掉的钱**（`MAX(cur) WHERE cur <= 70000`），否则 10000 的初级生会被误判为在预算内——实际预算已被 Senior 占去 36000。用 `IFNULL(..., 0)` 处理「没有任何 Senior 被录取 / 表中无 Senior」的场景，此时 Junior 的起点为 0。第二，虽然题目保证工资唯一，写成 `ROWS UNBOUNDED PRECEDING` 显式指定行框架仍是好习惯：默认 `RANGE` 框架在并列工资下会把多人算成同一累计值，换到 2004 那种有并列数据的题上就错了，两种写法在本题数据下等价，但 `ROWS` 更稳健。

两段结果用 `UNION`（而非 `UNION ALL`）合并即可，员工编号天然不重叠；输出顺序题目不作要求。

### SQL 实现

```sql
WITH s AS (
    SELECT
        employee_id,
        SUM(salary) OVER (ORDER BY salary ROWS UNBOUNDED PRECEDING) AS cur
    FROM Candidates
    WHERE experience = 'Senior'
),
senior_used AS (
    SELECT IFNULL(MAX(cur), 0) AS used FROM s WHERE cur <= 70000
),
j AS (
    SELECT
        c.employee_id,
        su.used + SUM(c.salary) OVER (ORDER BY c.salary ROWS UNBOUNDED PRECEDING) AS cur
    FROM Candidates AS c
    CROSS JOIN senior_used AS su
    WHERE c.experience = 'Junior'
)
SELECT employee_id FROM s WHERE cur <= 70000
UNION
SELECT employee_id FROM j WHERE cur <= 70000;
```

### 复杂度分析

- 时间复杂度：O(n log n)，两段窗口排序求前缀和。
- 空间复杂度：O(n)，窗口中间结果。
