# 周内每天的销售情况

> 难度：困难 | 标签：分组聚合、日期函数 | [LeetCode 原题](https://leetcode.cn/problems/sales-by-day-of-the-week/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Orders`

| 列名 | 类型 |
| --- | --- |
| order_id | int |
| customer_id | int |
| order_date | date |
| item_id | varchar |
| quantity | int |

`(order_id, item_id)` 是该表的主键。该表记录订单信息：`order_date` 是客户 `customer_id` 下单购买 `item_id` 的日期，`quantity` 为购买数量。

表：`Items`

| 列名 | 类型 |
| --- | --- |
| item_id | varchar |
| item_name | varchar |
| item_category | varchar |

`item_id` 是该表的主键，`item_name` 是商品名称，`item_category` 是商品分类。

你是店家，希望得到一份"按商品分类 × 一周内各天"的销售报表。

编写一个查询，统计每个商品分类在周一到周日每一天售出的商品件数（`quantity` 之和），结果按分类（`item_category`）升序排列。某分类在某天没有售出时输出 0。

示例：

输入 `Orders` 表：

| order_id | customer_id | order_date | item_id | quantity |
| --- | --- | --- | --- | --- |
| 1 | 1 | 2020-06-01 | 1 | 10 |
| 2 | 1 | 2020-06-08 | 2 | 10 |
| 3 | 2 | 2020-06-02 | 1 | 5 |
| 4 | 3 | 2020-06-03 | 3 | 5 |
| 5 | 4 | 2020-06-04 | 4 | 1 |
| 6 | 4 | 2020-06-05 | 5 | 5 |
| 7 | 5 | 2020-06-05 | 1 | 10 |
| 8 | 5 | 2020-06-14 | 4 | 5 |
| 9 | 5 | 2020-06-21 | 3 | 5 |

输入 `Items` 表：

| item_id | item_name | item_category |
| --- | --- | --- |
| 1 | LC Alg. Book | Book |
| 2 | LC DB. Book | Book |
| 3 | LC SmarthPhone | Phone |
| 4 | LC Phone 2020 | Phone |
| 5 | LC SmartGlass | Glasses |
| 6 | LC T-Shirt XL | T-shirt |

输出：

| Category | Monday | Tuesday | Wednesday | Thursday | Friday | Saturday | Sunday |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Book | 20 | 5 | 0 | 0 | 10 | 0 | 0 |
| Glasses | 0 | 0 | 0 | 0 | 5 | 0 | 0 |
| Phone | 0 | 0 | 5 | 1 | 0 | 0 | 10 |
| T-shirt | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

解释：

- 周一（2020-06-01、2020-06-08）Book 分类共售出 20 件（10 + 10）；
- 周二（2020-06-02）Book 售出 5 件；周三（2020-06-03）Phone 售出 5 件；周四（2020-06-04）Phone 售出 1 件；
- 周五（2020-06-05）Book 售出 10 件、Glasses 售出 5 件；
- 周六没有任何销售；周日（2020-06-14、2020-06-21）Phone 共售出 10 件（5 + 5）；
- T-shirt 没有任何订单，整行输出 0。

## 题解

::: details 点击查看题解

### 思路

结果的行集合来自**商品分类**而不是订单，因此以 `Items` 为左表左连接 `Orders`：从未售出的分类（如 T-shirt）也能保留下来，连接不上的订单字段为 NULL，`SUM(CASE ...)` 走 ELSE 分支取 0，天然补齐零行。

列的展开用条件聚合：MySQL 的 `DAYOFWEEK()` 返回 1 = 周日、2 = 周一 …… 7 = 周六，所以为周一到周日各写一个 `SUM(CASE WHEN DAYOFWEEK(order_date) = k THEN quantity ELSE 0 END)`，列顺序按官方示例为 Monday 到 Sunday。

易错点：

- `DAYOFWEEK` 的 1 是**周日**，映射写错一格整列都会串位；也可用 `DAYNAME()`（'Monday' 等）做条件，但要注意其返回值依赖字符集排序规则；
- 分母是"件数"（`quantity`）而不是订单行数，要 `SUM(quantity)`；
- 以 `Items` 为左表是关键，若以 `Orders` 为左表，零订单的分类会整个消失。

### SQL 实现

```sql
SELECT i.item_category AS Category,
       SUM(CASE WHEN DAYOFWEEK(o.order_date) = 2 THEN o.quantity ELSE 0 END) AS Monday,
       SUM(CASE WHEN DAYOFWEEK(o.order_date) = 3 THEN o.quantity ELSE 0 END) AS Tuesday,
       SUM(CASE WHEN DAYOFWEEK(o.order_date) = 4 THEN o.quantity ELSE 0 END) AS Wednesday,
       SUM(CASE WHEN DAYOFWEEK(o.order_date) = 5 THEN o.quantity ELSE 0 END) AS Thursday,
       SUM(CASE WHEN DAYOFWEEK(o.order_date) = 6 THEN o.quantity ELSE 0 END) AS Friday,
       SUM(CASE WHEN DAYOFWEEK(o.order_date) = 7 THEN o.quantity ELSE 0 END) AS Saturday,
       SUM(CASE WHEN DAYOFWEEK(o.order_date) = 1 THEN o.quantity ELSE 0 END) AS Sunday
FROM Items i
LEFT JOIN Orders o ON o.item_id = i.item_id
GROUP BY i.item_category
ORDER BY i.item_category;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为订单数，分组聚合主导。
- 空间复杂度：O(c)，c 为商品分类数，用于存放分组结果。
