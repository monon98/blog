# 球队传球成功的优势得分

> 难度：困难 | 标签：多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/team-dominance-by-pass-success/)

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

## 题目描述

表：`Teams`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| player_id   | int     |
| team_name   | varchar |
+-------------+---------+
player_id 是该表的唯一键。
该表的每一行都包含球员的唯一标识以及参加本场比赛的球队名称之一。
```

表：`Passes`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| pass_from   | int     |
| time_stamp  | varchar |
| pass_to     | int     |
+-------------+---------+
(pass_from, time_stamp) 是该表的主键。
pass_from 是指向 `Teams.player_id` 的外键。
该表的每一行代表比赛中的一次传球，`time_stamp` 表示传球发生的分钟时刻（00:00-90:00），`pass_to` 是接球球员的 player_id。
```

编写一个查询，计算每支球队在**上下半场**的优势得分。规则如下：

- 比赛分为两个半场：上半场（`00:00`-`45:00` 分钟）和下半场（`45:01`-`90:00` 分钟）；
- 优势得分根据成功传球与被截获传球计算：
  - 当 `pass_to` 是**同队**球员时：`+1` 分；
  - 当 `pass_to` 是**对方**球员（被截获）时：`-1` 分。

结果按 `team_name`、`half_number` 升序排列。

**示例：**

输入：

```
Teams 表：

+------------+-----------+
| player_id  | team_name |
+------------+-----------+
| 1          | Arsenal   |
| 2          | Arsenal   |
| 3          | Arsenal   |
| 4          | Chelsea   |
| 5          | Chelsea   |
| 6          | Chelsea   |
| 7          | Chelsea   |
| 8          | Chelsea   |
+------------+-----------+

Passes 表：

+-----------+------------+---------+
| pass_from | time_stamp | pass_to |
+-----------+------------+---------+
| 1         | 00:15      | 2       |
| 2         | 00:45      | 3       |
| 3         | 01:15      | 1       |
| 4         | 00:30      | 1       |
| 2         | 46:00      | 3       |
| 3         | 46:15      | 4       |
| 1         | 46:45      | 2       |
| 5         | 46:30      | 6       |
+-----------+------------+---------+
```

输出：

```
+-----------+-------------+-----------+
| team_name | half_number | dominance |
+-----------+-------------+-----------+
| Arsenal   | 1           | 3         |
| Arsenal   | 2           | 1         |
| Chelsea   | 1           | -1        |
| Chelsea   | 2           | 1         |
+-----------+-------------+-----------+
```

解释：

- **上半场（00:00-45:00）**：Arsenal 的 1→2、2→3、3→1 均为同队成功传球，合计 `+3`；Chelsea 的 4→1 被 Arsenal 截获，记 `-1`。
- **下半场（45:01-90:00）**：Arsenal 的 2→3（+1）、1→2（+1）成功，3→4 被 Chelsea 截获（-1），合计 `+1`；Chelsea 的 5→6 成功传球 `+1`。

结果按 `team_name`、`half_number` 升序排列。

## 题解

::: details 点击查看题解

### 思路

关键是要同时拿到**传球发起方**和**接收方**的球队，才能判断这次传球是同队配合还是被对手截获。因此把 `Passes` 分别按 `pass_from`、`pass_to` 与 `Teams` 连接两次（等值连接 `t1`、`t2`）。

接着两步计算：

1. **半场**：`time_stamp` 是 `MM:SS` 格式的字符串，字典序比较即为时间比较，`time_stamp <= '45:00'` 为上半场（`1`），否则下半场（`2`）；
2. **单次得分**：`IF(t1.team_name = t2.team_name, 1, -1)`，同队 `+1`、跨队 `-1`。

最后按**发起方球队**（`t1.team_name`）与半场分组求和，即该队该半场的优势得分。注意分组必须用发起方球队——被截获的球计入发起方（失误方），而不是接球方。


### SQL 实现

```sql
SELECT t1.team_name,
       IF(p.time_stamp <= '45:00', 1, 2) AS half_number,
       SUM(IF(t1.team_name = t2.team_name, 1, -1)) AS dominance
FROM Passes p
JOIN Teams t1 ON p.pass_from = t1.player_id
JOIN Teams t2 ON p.pass_to = t2.player_id
GROUP BY t1.team_name, IF(p.time_stamp <= '45:00', 1, 2)
ORDER BY t1.team_name, half_number;
```

### 复杂度分析

- **时间复杂度**：`O(p + p log p)`，两次哈希连接为线性，分组聚合带排序开销（`p` 为传球数）。
- **空间复杂度**：`O(t + k)`，`t` 为球队表大小，`k` 为「球队 × 半场」组合数。
:::
