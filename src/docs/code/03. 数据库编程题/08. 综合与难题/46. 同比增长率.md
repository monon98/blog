# 同比增长率

> 难度：困难 | 标签：窗口函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/year-on-year-growth-rate/)

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

## 题目描述

表：`user_transactions`

```
+------------------+----------+
| Column Name      | Type     |
+------------------+----------+
| transaction_id   | integer  |
| product_id       | integer  |
| spend            | decimal  |
| transaction_date | datetime |
+------------------+----------+
transaction_id 列是该表的唯一标识。
该表的每一行都包含交易 ID、产品 ID、消费金额和交易日期。
```

编写一个查询，计算每个产品总消费额的**同比增长率**。结果表应包含以下列：

- `year`：交易发生的年份；
- `product_id`：产品 ID；
- `curr_year_spend`：当年的总消费额；
- `prev_year_spend`：上一年的总消费额；
- `yoy_rate`：同比增长率百分比，保留 2 位小数。

增长率公式为：`((curr_year_spend - prev_year_spend) / prev_year_spend) * 100`。

结果按 `product_id`、`year` 升序排列。

**示例：**

输入：

```
+----------------+------------+---------+---------------------+
| transaction_id | product_id | spend   | transaction_date    |
+----------------+------------+---------+---------------------+
| 1341           | 123424     | 1500.60 | 2019-12-31 12:00:00 |
| 1423           | 123424     | 1000.20 | 2020-12-31 12:00:00 |
| 1623           | 123424     | 1246.44 | 2021-12-31 12:00:00 |
| 1322           | 123424     | 2145.32 | 2022-12-31 12:00:00 |
+----------------+------------+---------+---------------------+
```

输出：

```
+------+------------+----------------+----------------+----------+
| year | product_id | curr_year_spend| prev_year_spend| yoy_rate |
+------+------------+----------------+----------------+----------+
| 2019 | 123424     | 1500.60        | NULL           | NULL     |
| 2020 | 123424     | 1000.20        | 1500.60        | -33.35   |
| 2021 | 123424     | 1246.44        | 1000.20        | 24.62    |
| 2022 | 123424     | 2145.32        | 1246.44        | 72.12    |
+------+------------+----------------+----------------+----------+
```

解释：

- 2019 年：没有上一年数据，`prev_year_spend` 与 `yoy_rate` 均为 `NULL`；
- 2020 年：`(1000.20 - 1500.60) / 1500.60 * 100 = -33.35`；
- 2021 年：`(1246.44 - 1000.20) / 1000.20 * 100 = 24.62`；
- 2022 年：`(2145.32 - 1246.44) / 1246.44 * 100 = 72.12`。

注意：结果按 `product_id`、`year` 升序排列。

## 题解

::: details 点击查看题解

### 思路

分三步：

1. **按产品 × 年聚合**：`GROUP BY product_id, YEAR(transaction_date)` 得到每年总消费 `curr_year_spend`；
2. **取上一年消费**：在同一份年度汇总上做自连接（`t2.year = t1.year - 1`）或用 `LAG(curr_year_spend) OVER (PARTITION BY product_id ORDER BY year)`，都能把「今年」和「去年」对齐。首年没有上一年，连接/窗口自然产生 `NULL`；
3. **计算增长率**：`ROUND((curr - prev) / prev * 100, 2)`，`prev` 为 `NULL` 时整个表达式为 `NULL`，正好符合要求。

两种写法等价，自连接写法不依赖窗口函数执行顺序，`LAG` 写法更直观。


### SQL 实现

```sql
WITH yearly AS (
    SELECT product_id,
           YEAR(transaction_date) AS year,
           SUM(spend) AS curr_year_spend
    FROM user_transactions
    GROUP BY product_id, YEAR(transaction_date)
),
growth AS (
    SELECT year,
           product_id,
           curr_year_spend,
           LAG(curr_year_spend) OVER (PARTITION BY product_id ORDER BY year) AS prev_year_spend
    FROM yearly
)
SELECT year,
       product_id,
       curr_year_spend,
       prev_year_spend,
       ROUND((curr_year_spend - prev_year_spend) / prev_year_spend * 100, 2) AS yoy_rate
FROM growth
ORDER BY product_id, year;
```

### 复杂度分析

- **时间复杂度**：`O(n log n)`，聚合与窗口排序。
- **空间复杂度**：`O(k)`，`k` 为「产品 × 年」组合数。
:::
