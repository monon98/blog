# 建立方程

> 难度：困难 | 标签：字符串函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/build-the-equation/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Terms`

```
+-------+--------+
| Column Name | Type |
+-------+--------+
| power       | int  |
| factor      | int  |
+-------+--------+
power 是该表具有唯一值的列。
该表的每一行包含关于方程一项的信息。
power 是范围为 [0, 100] 的整数。
factor 是范围为 [-100, 100] 的整数，且不能为零。
```

你有一个非常强大的程序，可以解出世界上任何单变量方程。传递给程序的方程必须按如下格式：

- 左边（LHS）包含所有的项，右边（RHS）必须是 0；
- LHS 的每一项遵循 `<sign><fact>X^<pow>` 的格式，其中：
  - `<sign>` 是 `+` 或者 `-`；
  - `<fact>` 是 factor 的**绝对值**；
  - `<pow>` 是 power 的值；
- 如果幂是 1，不要写 `^<pow>`。例如 `power = 1`、`factor = 3`，该项为 `+3X`；
- 如果幂是 0，不要写 `X` 和 `^<pow>`。例如 `power = 0`、`factor = -3`，该项为 `-3`；
- LHS 中的项按**幂次降序**排列。

编写一个解决方案来构建方程，返回单列 `equation`。

**示例 1：**

输入：

```
Terms 表：
+-------+--------+
| power | factor |
+-------+--------+
| 2     | 1      |
| 1     | -4     |
| 0     | 2      |
+-------+--------+
```

输出：

```
+--------------+
| equation     |
+--------------+
| +1X^2-4X+2=0 |
+--------------+
```

**示例 2：**（仅说明格式，不在本页测试数据中）

```
输入：power = 4, factor = -4；power = 2, factor = 1；power = 1, factor = -1
输出：-4X^4+1X^2-1X=0
```

## 题解

::: details 点击查看题解

### 思路

本质是「分项拼串 + 按幂次降序聚合」，一条 `GROUP_CONCAT` 就能完成，难点全在格式细节：

1. **符号**：正系数要补显式 `+`（如 `+1X^2`、`+2`），负系数直接用原值（`-4` 就自带负号）。所以统一写成 `IF(factor > 0, CONCAT('+', factor), ...)`。注意 `<fact>` 是绝对值——正数补 `+` 后本身就是绝对值，负数的字符串表示已带 `-` 号、其后跟的数字即绝对值，无需再 `ABS`。
2. **幂次分支**：`power = 0` 只写系数（`+2`）；`power = 1` 写 `系数X`（`-4X`）；其余写 `系数X^power`（`+1X^2`）。用 `CASE` 三分支即可。
3. **排序与拼接**：`GROUP_CONCAT(... ORDER BY power DESC SEPARATOR '')` 把各项按幂降序连成串，外层再 `CONCAT` 上 `=0`。

两个易错点：一是 `GROUP_CONCAT` 默认分隔符是 `,`、默认长度上限 `group_concat_max_len = 1024`——power 最多 100 项，极端情况接近或超过上限会被**静默截断**，所以先 `SET group_concat_max_len = 10000;` 保险；二是 `ORDER BY power DESC` 必须写在 `GROUP_CONCAT` 内部而不是外层 `ORDER BY`（外层排序发生在聚合之后，已经无从改变串内顺序）。替代写法：用 `XML` 函数或应用层拼接，但 SQL 内一步到位最干净。

### SQL 实现

```sql
SET group_concat_max_len = 10000;
SELECT CONCAT(
    GROUP_CONCAT(
        CASE
            WHEN power = 0 THEN IF(factor > 0, CONCAT('+', factor), CAST(factor AS CHAR))
            WHEN power = 1 THEN CONCAT(IF(factor > 0, CONCAT('+', factor), CAST(factor AS CHAR)), 'X')
            ELSE CONCAT(IF(factor > 0, CONCAT('+', factor), CAST(factor AS CHAR)), 'X^', power)
        END
        ORDER BY power DESC SEPARATOR ''
    ),
    '=0'
) AS equation
FROM Terms;
```

### 复杂度分析

- 时间复杂度：O(n log n)，聚合时按 power 排序，n 为项数（不超过 101）。
- 空间复杂度：O(n)，拼接结果串长度与项数线性相关。

:::
