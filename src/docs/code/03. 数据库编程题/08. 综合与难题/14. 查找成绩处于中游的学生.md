# 查找成绩处于中游的学生

> 难度：困难 | 标签：窗口函数、子查询 | [LeetCode 原题](https://leetcode.cn/problems/find-the-quiet-students-in-all-exams/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Student`

| 列名 | 类型 |
| --- | --- |
| student_id | int |
| student_name | varchar |

`student_id` 是该表的主键，`student_name` 是学生姓名。

表：`Exam`

| 列名 | 类型 |
| --- | --- |
| exam_id | int |
| student_id | int |
| score | int |

`(exam_id, student_id)` 是该表的主键。该表表示学生 `student_id` 在考试 `exam_id` 中取得了 `score` 分。

如果一名学生**参加过至少一次考试**，并且**在所有参加过的考试中从未获得过最高分或最低分**，则称该学生为"中游学生（quiet student）"。

编写一个查询，找出在**所有考试中**都处于中游的学生（`student_id`、`student_name`），不要返回从未参加过任何考试的学生，结果按 `student_id` 升序排列。

示例：

输入 `Student` 表：

| student_id | student_name |
| --- | --- |
| 1 | Daniel |
| 2 | Jade |
| 3 | Stella |
| 4 | Jonathan |
| 5 | Will |

输入 `Exam` 表：

| exam_id | student_id | score |
| --- | --- | --- |
| 10 | 1 | 70 |
| 10 | 2 | 80 |
| 10 | 3 | 90 |
| 20 | 1 | 80 |
| 30 | 1 | 70 |
| 30 | 3 | 80 |
| 30 | 4 | 90 |
| 40 | 1 | 60 |
| 40 | 2 | 70 |
| 40 | 4 | 80 |

输出：

| student_id | student_name |
| --- | --- |
| 2 | Jade |

解释：

- 考试 10：1 号和 3 号分别拿了最低分和最高分；
- 考试 20：只有 1 号一人，他同时是最高分和最低分；
- 考试 30、40：1 号和 4 号分别拿了最低分和最高分；
- 2 号从未拿过最高分或最低分，5 号没参加任何考试被排除，因此只返回 2 号。

## 题解

::: details 点击查看题解

### 思路

判断"中游"需要按考试维度看：每次考试内部用 `RANK()` 分别按分数降序、升序排名，`rk_desc = 1` 即最高分，`rk_asc = 1` 即最低分。对学生而言，只要他在**任何一次**考试中出现过任一排名为 1，就不满足条件；反之，`MIN(rk_desc) > 1 AND MIN(rk_asc) > 1` 的学生才是中游。

两个易错点：

- 用 `RANK` 而不是 `ROW_NUMBER`：同一场考试可能出现并列最高分，`ROW_NUMBER` 会给其中一人编出 2，导致误判；`RANK` 让并列者并列第 1，语义才是"是否拿了最高/最低分"；
- 必须要求"至少参加过一次考试"：在 `Exam` 上做统计天然满足这一点，从未考试的学生不会出现在分组里；但要以 `Student` 表左连接输出姓名，保证返回的是全部合格学生并按 `student_id` 排序。

先在子查询里按学生分组、对两个 `MIN` 加 `HAVING` 过滤，再回 `Student` 取姓名，是最直接的结构。

### SQL 实现

```sql
SELECT s.student_id, s.student_name
FROM Student s
JOIN (
    SELECT student_id
    FROM (
        SELECT student_id,
               RANK() OVER (PARTITION BY exam_id ORDER BY score DESC) AS rk_desc,
               RANK() OVER (PARTITION BY exam_id ORDER BY score ASC)  AS rk_asc
        FROM Exam
    ) e
    GROUP BY student_id
    HAVING MIN(rk_desc) > 1 AND MIN(rk_asc) > 1
) q ON q.student_id = s.student_id
ORDER BY s.student_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为考试记录数，两次窗口排序主导。
- 空间复杂度：O(n)，用于存放窗口计算结果。
