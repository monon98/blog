# 锦标赛优胜者

> 难度：困难 | 标签：窗口函数、多表连接 | [LeetCode 原题](https://leetcode.cn/problems/tournament-winners/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Players`

| 列名 | 类型 |
| --- | --- |
| player_id | int |
| group_id | int |

`player_id` 是该表的主键。该表的每一行表示一名选手所属的组。

表：`Matches`

| 列名 | 类型 |
| --- | --- |
| match_id | int |
| first_player | int |
| second_player | int |
| first_score | int |
| second_score | int |

`match_id` 是该表的主键。该表的每一行记录一场比赛：`first_player` 与 `second_player` 是对阵双方的 `player_id`，`first_score` 与 `second_score` 分别是两人的得分。可以假设每场比赛的两名选手属于同一个组。

每个组的优胜者是**组内总得分最高**的选手；如果总得分相同，则 `player_id` 最小的选手获胜。注意：一名选手的总得分是他参加的所有比赛中自己得分的累加（输掉的比赛也可能有得分，例如 1:1 平局双方各得 1 分）。

编写一个查询，找出每个组的优胜者。

示例：

输入 `Players` 表：

| player_id | group_id |
| --- | --- |
| 10 | 2 |
| 15 | 1 |
| 20 | 3 |
| 25 | 1 |
| 30 | 1 |
| 35 | 2 |
| 40 | 3 |
| 45 | 1 |
| 50 | 2 |

输入 `Matches` 表：

| match_id | first_player | second_player | first_score | second_score |
| --- | --- | --- | --- | --- |
| 1 | 15 | 45 | 3 | 0 |
| 2 | 30 | 25 | 1 | 2 |
| 3 | 30 | 15 | 2 | 0 |
| 4 | 40 | 20 | 5 | 2 |
| 5 | 35 | 50 | 1 | 1 |

输出：

| group_id | player_id |
| --- | --- |
| 1 | 15 |
| 2 | 35 |
| 3 | 40 |

解释：

- 第 1 组：15 号总得分 3（3 + 0），30 号总得分 3（1 + 2），25 号 2 分，45 号 0 分；最高分 3 分出现并列，`player_id` 较小的 15 号获胜。
- 第 2 组：35 号与 50 号在第 5 场打成 1:1，各得 1 分，10 号没有参赛得 0 分；并列最高分时取 `player_id` 最小的 35 号。
- 第 3 组：40 号得 5 分，20 号得 2 分，40 号获胜。

## 题解

::: details 点击查看题解

### 思路

第一步要把 `Matches` 的宽表拆成"每名选手一行得分"的长表：`first_player/first_score` 与 `second_player/second_score` 各取一半，用 `UNION ALL` 纵向拼接，再按 `player_id` 求和得到每人的总得分。

第二步要注意**不能直接从得分表出发**：组内可能有人一场比赛都没打（如样例中的 10 号），他没有任何得分记录，却是总得分并列 0 分时的合法优胜者。因此要以 `Players` 为左表左连接得分，`COALESCE(total_score, 0)` 把无记录者补成 0 分。

最后用 `ROW_NUMBER() OVER (PARTITION BY group_id ORDER BY total_score DESC, player_id ASC)` 组内排名，取 `rk = 1`。并列时的规则是"取 `player_id` 最小的"，把 `player_id ASC` 放进排序即可，注意是 `ROW_NUMBER` 而不是 `RANK`——`RANK` 在并列时会给出相同的名次，可能一次返回多人。

一个容易想当然的点：平局比赛（1:1）双方各得自己的分数，两人都要计入总得分，不能只统计"获胜场次"。

### SQL 实现

```sql
WITH scores AS (
    SELECT player_id, SUM(score) AS total_score
    FROM (
        SELECT first_player AS player_id, first_score AS score
        FROM Matches
        UNION ALL
        SELECT second_player AS player_id, second_score AS score
        FROM Matches
    ) t
    GROUP BY player_id
),
ranked AS (
    SELECT p.group_id,
           p.player_id,
           ROW_NUMBER() OVER (PARTITION BY p.group_id
                              ORDER BY COALESCE(s.total_score, 0) DESC,
                                       p.player_id ASC) AS rk
    FROM Players p
    LEFT JOIN scores s ON s.player_id = p.player_id
)
SELECT group_id, player_id
FROM ranked
WHERE rk = 1
ORDER BY group_id;
```

### 复杂度分析

- 时间复杂度：O(m log m)，m 为选手数与比赛数之和，`UNION ALL` 后的排序/聚合主导。
- 空间复杂度：O(p)，p 为选手数，用于存放总得分与排名。
