# Hopper 公司查询 II

> 难度：困难 | 标签：递归 CTE、日期函数 | [LeetCode 原题](https://leetcode.cn/problems/hopper-company-queries-ii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

表：`Drivers`

| 列名 | 类型 |
| --- | --- |
| driver_id | int |
| join_date | date |

`driver_id` 是该表的主键。该表每一行表示一名司机的 ID 及其加入 Hopper 公司的日期。

表：`Rides`

| 列名 | 类型 |
| --- | --- |
| ride_id | int |
| user_id | int |
| requested_at | date |

`ride_id` 是该表的主键。该表每一行表示一次行程请求的 ID、发起用户的 ID 以及请求日期。表中可能存在未被接受的行程请求。

表：`AcceptedRides`

| 列名 | 类型 |
| --- | --- |
| ride_id | int |
| driver_id | int |
| ride_distance | int |
| ride_duration | int |

`ride_id` 是该表的主键。该表每一行表示一次被接受的行程及其接单司机、行驶距离与时长。可以保证每条被接受的行程都存在于 `Rides` 表中。

编写一个查询，报告 2020 年**每个月**的**工作司机百分比**（`working_percentage`）：

- 分母：截至该月月底仍在公司的司机人数（`join_date` 不晚于该月最后一天）；
- `working_percentage` = **该月被接受的行程数 ÷ 截至月底的司机人数 × 100**；
- 如果某月月底司机人数为 0，则 `working_percentage` 记为 0；
- 结果保留两位小数，按 `month`（1 表示一月，2 表示二月……）升序排列。

示例：

输入 `Drivers` 表：

| driver_id | join_date |
| --- | --- |
| 10 | 2019-12-10 |
| 8 | 2020-1-13 |
| 5 | 2020-2-16 |
| 7 | 2020-3-8 |
| 4 | 2020-5-17 |
| 1 | 2020-10-24 |
| 6 | 2021-1-5 |

输入 `Rides` 表与 `AcceptedRides` 表同「Hopper 公司查询 I」。

输出：

| month | working_percentage |
| --- | --- |
| 1 | 0.00 |
| 2 | 0.00 |
| 3 | 25.00 |
| 4 | 0.00 |
| 5 | 0.00 |
| 6 | 20.00 |
| 7 | 20.00 |
| 8 | 20.00 |
| 9 | 0.00 |
| 10 | 0.00 |
| 11 | 33.33 |
| 12 | 16.67 |

解释：

- 截至 1 月底有 2 名司机（10、8），当月无被接受行程，百分比 0%；
- 截至 3 月底有 4 名司机（10、8、5、7），当月 1 单被接受，(1 / 4) × 100 = 25%；
- 截至 6 月底有 5 名司机，当月 1 单被接受，(1 / 5) × 100 = 20%；
- 截至 11 月底有 6 名司机（10、8、5、7、4、1），当月 2 单被接受，(2 / 6) × 100 = 33.33%；
- 截至 12 月底有 6 名司机，当月 1 单被接受，(1 / 6) × 100 = 16.67%。

## 题解

::: details 点击查看题解

### 思路

结构上与「Hopper 公司查询 I」完全一致：先用递归 CTE 生成 2020 年 1 ~ 12 月的月份骨架（带月初日期），再分别准备分子与分母：

- **分母**是"截至月底的司机累计人数"，用相关子查询 `COUNT(*) FROM Drivers WHERE join_date <= LAST_DAY(month_start)`，与 I 题的 `active_drivers` 同口径；
- **分子**是"当月被接受的行程数"，`AcceptedRides` 没有日期，要回连 `Rides` 取 `requested_at`，按月聚合后左连接到骨架上补 0。

最后 `ROUND(100 * 分子 / 分母, 2)`。易错点：

- 分母可能为 0（某月月底尚无司机入职），直接除会产生 `NULL` 或除零告警，用 `NULLIF(分母, 0)` 转成 NULL 后再 `COALESCE(..., 0)` 兜底，输出 0 而不是 NULL；
- 百分比要乘 100 并 `ROUND(..., 2)`，样例中 33.33、16.67 都是四舍五入的结果；
- 分子是**行程单数**而不是接单司机人数（题目口径为"被接受的行程数 ÷ 司机数"），不要 COUNT DISTINCT 司机。

### SQL 实现

```sql
WITH RECURSIVE months AS (
    SELECT 1 AS m, DATE('2020-01-01') AS month_start
    UNION ALL
    SELECT m + 1, DATE_ADD(month_start, INTERVAL 1 MONTH)
    FROM months
    WHERE m < 12
),
ride_stats AS (
    SELECT MONTH(r.requested_at) AS m,
           COUNT(*) AS accepted_rides
    FROM Rides r
    JOIN AcceptedRides a ON a.ride_id = r.ride_id
    WHERE YEAR(r.requested_at) = 2020
    GROUP BY MONTH(r.requested_at)
)
SELECT mo.m AS month,
       COALESCE(
           ROUND(100 * COALESCE(rs.accepted_rides, 0) /
                 NULLIF((SELECT COUNT(*)
                         FROM Drivers d
                         WHERE d.join_date <= LAST_DAY(mo.month_start)), 0),
                 2),
           0) AS working_percentage
FROM months mo
LEFT JOIN ride_stats rs ON rs.m = mo.m
ORDER BY mo.m;
```

### 复杂度分析

- 时间复杂度：O(d + r log r)，d 为司机数、r 为被接受行程数。
- 空间复杂度：O(12 + m)，m 为 2020 年有行程的月份数。
