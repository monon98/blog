# 计算滞留雨水

> 难度：困难 | 标签：窗口函数、聚合函数 | [LeetCode 原题](https://leetcode.cn/problems/calculate-trapping-rain-water/)

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

## 题目描述

给定一张表示直方图的表 `Heights`，每一行 `id` 表示一根柱子的位置（从左到右递增），`height` 表示该柱子的高度。

下雨后，柱子之间可以积水。求整幅直方图一共能滞留多少水。

提示：

- 假定柱子的宽度都是 1。
- 第 `i` 根柱子能滞留的水量为 `min(左侧最高柱高, 右侧最高柱高) - height_i`（若结果为负则记为 0）。

**示例：**

输入：

```
+----+--------+
| id | height |
+----+--------+
| 1  | 0      |
| 2  | 1      |
| 3  | 0      |
| 4  | 2      |
| 5  | 1      |
| 6  | 0      |
| 7  | 1      |
| 8  | 3      |
| 9  | 2      |
| 10 | 1      |
| 11 | 2      |
| 12 | 1      |
+----+--------+
```

输出：

```
+-------------------+
| total_trapped_water |
+-------------------+
| 6                 |
+-------------------+
```

## 题解

::: details 点击查看题解

### 思路

单柱能积水的高度由「左边最高」和「右边最高」中的较小者决定：水会被两侧中较矮的那侧挡住。

用窗口函数一次算出两列边界最大值：

- `MAX(height) OVER (ORDER BY id ROWS UNBOUNDED PRECEDING)`：含当前行及左侧所有柱子的最大高度（左侧最高）；
- `MAX(height) OVER (ORDER BY id DESC ROWS UNBOUNDED PRECEDING)`：倒序看时含当前行及右侧所有柱子的最大高度（右侧最高）。注意 MySQL 不支持 `ROWS UNBOUNDED FOLLOWING` 这种单侧写法，必须用「倒序 + `ROWS UNBOUNDED PRECEDING`」等价表达。

由于两侧最大值都包含当前柱自身，`LEAST(max_left, max_right) - height` 一定非负，直接逐行相减后求和即可得到总滞留水量。


### SQL 实现

```sql
WITH bounds AS (
    SELECT id,
           height,
           MAX(height) OVER (ORDER BY id ROWS UNBOUNDED PRECEDING) AS max_left,
           MAX(height) OVER (ORDER BY id DESC ROWS UNBOUNDED PRECEDING) AS max_right
    FROM Heights
)
SELECT SUM(LEAST(max_left, max_right) - height) AS total_trapped_water
FROM bounds;
```

### 复杂度分析

- **时间复杂度**：`O(n)`，两个窗口各扫一遍，再做一次聚合。
- **空间复杂度**：`O(n)`，窗口结果的中间表。
:::
