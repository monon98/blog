# 查找具有螺旋学习模式的学生

> 难度：困难 | 标签：窗口函数、自连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/find-students-with-study-spiral-pattern/)

## 题目描述

表：`students`

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| student_id   | int     |
| student_name | varchar |
| major        | varchar |
+--------------+---------+
student_id 是这张表的唯一主键。
每一行包含有关学生及其学术专业的信息。
```

表：`study_sessions`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| session_id    | int     |
| student_id    | int     |
| subject       | varchar |
| session_date  | date    |
| hours_studied | decimal |
+---------------+---------+
session_id 是这张表的唯一主键。
每一行代表一个学生针对特定学科的学习时段。
```

编写一个解决方案来找出遵循 **螺旋学习模式** 的学生——即那些持续学习多个学科并按循环周期进行学习的学生。

	- 螺旋学习模式意味着学生以重复的顺序学习至少 3 个 不同的学科。

	- 模式必须重复 至少 2 个完整周期（最少 6 次学习记录）。

	- 两次学习记录必须是间隔不超过 2 天的 连续日期。

	- 计算 循环长度（模式中不同的学科数量）。

	- 计算模式中所有学习记录的 总学习时长。

	- 仅包含循环长度 至少为  3 门学科 的学生。

返回结果表按循环长度 **降序** 排序，然后按总学习时间 **降序** 排序。

结果格式如下所示。

## 题解

::: details 点击查看题解

### 思路

把四个条件逐个翻译成 SQL：

1. **排序与间隔**：窗口 `ROW_NUMBER() OVER (PARTITION BY student_id ORDER BY session_date, session_id)` 给每次学习编号 `rn`；`DATEDIFF(session_date, LAG(session_date) ...)` 得到与上一次学习的间隔天数，`MAX(gap) <= 2` 即「连续日期间隔不超过 2 天」（`MAX` 自动忽略首行的 `NULL`）。
2. **统计量**：按学生聚合出 `subject_cnt`（不同学科数 = 循环长度）、`session_cnt`（学习次数）、`total_study_hours`；条件为 `subject_cnt >= 3` 且 `session_cnt >= 2 * subject_cnt`（至少 2 个完整周期）。
3. **周期性校验**：这是最关键的一条——学科数对、次数够不代表真的按循环重复。把有序表**自连接**：`o2.rn = o1.rn + subject_cnt`，即让「第 k 次」与「第 k + 循环长度次」配对；若所有配对的 `subject` 都相等（`mismatch_cnt = 0`），说明序列确实以 `subject_cnt` 为周期循环。用 `LEFT JOIN` 保证每个应配对的行都被检查（`checked_cnt = session_cnt - subject_cnt`），避免漏检。
4. 最终 `JOIN students` 取姓名专业，按 `cycle_length DESC, total_study_hours DESC` 排序。

学生 5 没有学习记录，不会出现在 `study_sessions` 的聚合中，自然被排除。


### SQL 实现

```sql
WITH ordered AS (
    SELECT student_id,
           subject,
           session_date,
           hours_studied,
           ROW_NUMBER() OVER (PARTITION BY student_id
                              ORDER BY session_date, session_id) AS rn,
           DATEDIFF(session_date,
                    LAG(session_date) OVER (PARTITION BY student_id
                                            ORDER BY session_date, session_id)) AS gap_days
    FROM study_sessions
),
stats AS (
    SELECT student_id,
           COUNT(DISTINCT subject) AS subject_cnt,
           COUNT(*) AS session_cnt,
           MAX(gap_days) AS max_gap,
           ROUND(SUM(hours_studied), 1) AS total_study_hours
    FROM ordered
    GROUP BY student_id
),
checked AS (
    SELECT o.student_id,
           st.subject_cnt,
           SUM(CASE WHEN o2.subject IS NOT NULL AND o.subject <> o2.subject
                    THEN 1 ELSE 0 END) AS mismatch_cnt,
           COUNT(o2.rn) AS checked_cnt
    FROM ordered o
    JOIN stats st ON st.student_id = o.student_id
    LEFT JOIN ordered o2
        ON o2.student_id = o.student_id
       AND o2.rn = o.rn + st.subject_cnt
    GROUP BY o.student_id, st.subject_cnt
)
SELECT s.student_id,
       s.student_name,
       s.major,
       st.subject_cnt AS cycle_length,
       st.total_study_hours
FROM stats st
JOIN students s ON s.student_id = st.student_id
JOIN checked c ON c.student_id = st.student_id
WHERE st.subject_cnt >= 3
  AND st.session_cnt >= 2 * st.subject_cnt
  AND (st.max_gap IS NULL OR st.max_gap <= 2)
  AND c.mismatch_cnt = 0
  AND c.checked_cnt = st.session_cnt - st.subject_cnt
ORDER BY cycle_length DESC, total_study_hours DESC;
```

### 复杂度分析

- **时间复杂度**：`O(n log n)`，窗口排序 + 分组聚合，自连接规模为每学生 `O(m)`（`m` 为学习次数，仅需与「隔一个周期」的那一行配对）。
- **空间复杂度**：`O(n)`，窗口与分组的中间结果。
