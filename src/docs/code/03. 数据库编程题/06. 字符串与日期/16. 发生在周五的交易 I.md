# 发生在周五的交易 I

> 难度：中等 | 标签：日期函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/friday-purchases-i/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Purchases` 表：

```
+---------------+------+
| Column Name   | Type |
+---------------+------+
| user_id       | int  |
| purchase_date | date |
| amount_spend  | int  |
+---------------+------+
(user_id, purchase_date, amount_spend) 是该表的联合主键。
purchase_date 的范围是 2023 年 11 月 1 日到 2023 年 11 月 30 日。
每一行记录一个用户在某天的消费金额。
```

编写一个查询，计算 2023 年 11 月**每个周**里**周五**的消费总额。只输出那些在周五至少有一笔交易记录的周。

返回列：`week_of_month`（当月第几周，从 1 开始）、`purchase_date`（该周五的日期）、`total_amount`（当天消费总额），按 `week_of_month` 升序排列。

**示例 1：**

输入：

```
Purchases 表：
+---------+---------------+--------------+
| user_id | purchase_date | amount_spend |
+---------+---------------+--------------+
| 11      | 2023-11-07    | 1126         |
| 15      | 2023-11-30    | 7473         |
| 17      | 2023-11-14    | 2414         |
| 12      | 2023-11-24    | 9692         |
| 8       | 2023-11-03    | 5117         |
| 1       | 2023-11-16    | 5241         |
| 10      | 2023-11-12    | 8266         |
| 13      | 2023-11-24    | 12000        |
+---------+---------------+--------------+
```

输出：

```
+---------------+---------------+--------------+
| week_of_month | purchase_date | total_amount |
+---------------+---------------+--------------+
| 1             | 2023-11-03    | 5117         |
| 4             | 2023-11-24    | 21692        |
+---------------+---------------+--------------+
```

解释：

- 11 月第 1 周的周五是 2023-11-03，当天只有一笔 5117 的消费。
- 11 月第 2 周的周五 2023-11-10、第 3 周的周五 2023-11-17 都没有交易，因此不出现在结果里。
- 11 月第 4 周的周五是 2023-11-24，两笔消费 9692 + 12000 = 21692。
- 2023-11-30 是周四，不属于周五。

## 题解

::: details 点击查看题解

### 思路

这道题本质上是"按日期过滤 + 按日期分组"两步。先筛出 11 月的周五：月份用 `YEAR()`/`MONTH()`（或 `DATE_FORMAT(purchase_date, '%Y%m') = '202311'`）限定，星期用 `DAYOFWEEK()` 判断，注意它把**周日当作 1**，所以周五是 6。

周内序号用 `CEIL(DAYOFMONTH(purchase_date) / 7)` 就能得到：3 号落在第 1 周（0.43 上取整为 1），10 号第 2 周，17 号第 3 周，24 号第 4 周，正好符合"每月 1—7 日为第 1 周"的定义。随后按 `purchase_date` 分组求和即可；题目只要求"有交易才输出"，所以不需要补齐空周。

易错点：一是把 `DAYOFWEEK()` 和 `WEEKDAY()` 搞混，`WEEKDAY()` 里周一才是 0、周五是 4；二是用 `WEEK()` 函数求周数，它是 ISO 周（跨年、跨月都会出问题），不是"当月第几周"；三是分组必须按日期（或按日期算出的周数）而不是按用户，否则会把不同周五的数据混在一起。

替代写法：把周五判断换成 `DAYNAME(purchase_date) = 'Friday'`，可读性更好但会受 `lc_time_names` 语言设置影响。

### SQL 实现

```sql
SELECT CEIL(DAYOFMONTH(purchase_date) / 7) AS week_of_month,
       purchase_date,
       SUM(amount_spend) AS total_amount
FROM Purchases
WHERE YEAR(purchase_date) = 2023
  AND MONTH(purchase_date) = 11
  AND DAYOFWEEK(purchase_date) = 6
GROUP BY purchase_date
ORDER BY week_of_month;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为交易行数，一次全表扫描 + 分组排序。
- 空间复杂度：O(k)，k 为结果中的周五个数。

:::
