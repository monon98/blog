# 查找具有三个连续数字的产品

> 难度：简单 | 标签：正则匹配、字符串函数 | [LeetCode 原题](https://leetcode.cn/problems/find-products-with-three-consecutive-digits/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`products` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| product_id  | int     |
| name        | varchar |
+-------------+---------+
product_id 是该表具有唯一值的列。
每一行包含产品 ID 和产品名称。
```

编写一个查询，找出名称中包含**恰好三个连续数字**的产品。名称中可能有多段这样的数字，但每一段都必须是三位。

返回列：`product_id`、`name`，按 `product_id` 升序排列。

**示例 1：**

输入：

```
products 表：
+-------------+--------------------+
| product_id  | name               |
+-------------+--------------------+
| 1           | ABC123XYZ          |
| 2           | A12B34C            |
| 3           | Product56789       |
| 4           | NoDigitsHere       |
| 5           | 789Product         |
| 6           | Item003Description |
| 7           | Product12X34       |
+-------------+--------------------+
```

输出：

```
+-------------+--------------------+
| product_id  | name               |
+-------------+--------------------+
| 1           | ABC123XYZ          |
| 5           | 789Product         |
| 6           | Item003Description |
+-------------+--------------------+
```

解释：

- `ABC123XYZ` 含连续的 `123`；`789Product` 含 `789`；`Item003Description` 含 `003`（前导零也算数字），都符合。
- `Product56789` 是五位数字，其中任何三位都紧邻着其他数字，不算"恰好三位"，排除。
- `A12B34C`、`Product12X34` 只有两位数字；`NoDigitsHere` 没有数字。

## 题解

::: details 点击查看题解

### 思路

用一条正则就能表达"三位数字且前后不能还是数字"：`(^|[^0-9])[0-9]{3}([^0-9]|$)`。前面的 `(^|[^0-9])` 表示三位数字要么在串首、要么前面是非数字；后面的 `([^0-9]|$)` 同理。这样 `56789` 里的任何三位都因为相邻位置是数字而无法匹配，天然排除了更长的数字段。

MySQL 8 的 `REGEXP` 使用 ICU 正则引擎，支持 `{3}` 量词、`^`/`$` 锚点和字符组取反，这条表达式可以直接用；5.7 的旧正则只支持 POSIX 扩展语法，`{3}` 会退化成字面量，所以必须用 MySQL 8。

易错点：一是只写 `[0-9]{3}` 会把 `56789` 也算命中（它的子串 `567` 满足三位）；二是 `LIKE '%[0-9][0-9][0-9]%'` 完全行不通，`LIKE` 只有 `%` 和 `_` 两个通配符，没有字符组；三是 `[^0-9]` 不能写成 `\D`——ICU 支持 `\d`，但反斜杠在 SQL 字符串里还要转义，容易出错；四是别忘了 `ORDER BY product_id`。

替代写法：用 `REGEXP_REPLACE(name, '[0-9]+', '')` 之外还得判断数字段长度，反而更绕；也可以把字符串按非数字切段后判断是否存在长度为 3 的段，需要递归 CTE。

### SQL 实现

```sql
SELECT product_id, name
FROM products
WHERE name REGEXP '(^|[^0-9])[0-9]{3}([^0-9]|$)'
ORDER BY product_id;
```

### 复杂度分析

- 时间复杂度：O(n·L)，n 为产品数、L 为名称长度，每行做一次正则匹配。
- 空间复杂度：O(1)，只输出命中的行。
