# 周末任务计数

> 难度：中等 | 标签：日期函数、条件聚合 | [LeetCode 原题](https://leetcode.cn/problems/tasks-count-in-the-weekend/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Tasks` 表：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| task_id     | int  |
| assignee_id | int  |
| submit_date | date |
+-------------+------+
task_id 是该表的主键，每一行记录一次任务的提交：承办人（assignee_id）与提交日期（submit_date）。
```

编写一个解决方案，报告：

- `weekend_cnt`：在周末（周六、周日）提交的任务数量；
- `working_cnt`：在工作日（周一至周五）提交的任务数量。

结果只有一行，顺序不限。

**示例 1：**

```
输入：
Tasks 表：
+---------+-------------+-------------+
| task_id | assignee_id | submit_date |
+---------+-------------+-------------+
| 1       | 1           | 2022-06-13  |
| 2       | 6           | 2022-06-14  |
| 3       | 6           | 2022-06-15  |
| 4       | 3           | 2022-06-18  |
| 5       | 5           | 2022-06-19  |
| 6       | 7           | 2022-06-19  |
+---------+-------------+-------------+
输出：
+-------------+-------------+
| weekend_cnt | working_cnt |
+-------------+-------------+
| 3           | 3           |
+-------------+-------------+
解释：
2022-06-13 / 14 / 15 分别是周一、周二、周三，属于工作日，共 3 个任务。
2022-06-18 是周六，2022-06-19 是周日，共 3 个任务提交在周末。
```

## 题解

::: details 点击查看题解

### 思路

统计分两类但只需要一行结果，所以是「没有 `GROUP BY` 的全局聚合」：对整张表用一次 `SUM(条件)` 就能同时得到两个数，完全不需要 `CASE` 之外的分组，也不需要 `UNION` 两段查询。

判断周末有两条路：`WEEKDAY(submit_date) >= 5` 或 `DAYOFWEEK(submit_date) IN (1, 7)`。这两套编号方式极易混淆——`WEEKDAY` 以**周一为 0**（周六 5、周日 6），`DAYOFWEEK` 以**周日为 1**（周日 1、周六 7）。用错函数、或者把 `WEEKDAY` 当成「周日为 1」来写 `IN (6, 7)`，就会把周五也算成周末。本题示例里正好有周一至周三与周六周日，一旦错位结果立刻变成 2 / 4。

另一个坑是「求和的表达式必须返回布尔」。`SUM(WEEKDAY(submit_date) >= 5)` 里条件成立为 1、不成立为 0，求和即计数；如果写成 `SUM(submit_date)` 就变成对日期做数值求和，毫无意义。若担心可读性，可写成 `SUM(CASE WHEN WEEKDAY(submit_date) >= 5 THEN 1 ELSE 0 END)`，两者等价。

还有一点：两个计数互补，其实可以用 `COUNT(*) - weekend_cnt` 得到 `working_cnt`，但一条语句里不能引用同层别名，所以还是分别 `SUM` 最直接。

### SQL 实现

```sql
SELECT SUM(WEEKDAY(submit_date) >= 5) AS weekend_cnt,
       SUM(WEEKDAY(submit_date) < 5)  AS working_cnt
FROM Tasks;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为任务数，全表扫描一次。
- 空间复杂度：O(1)，聚合过程与结果都只有一个状态。
