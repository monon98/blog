# 列出指定时间段内所有的下单产品

> 难度：简单 | 标签：多表连接、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/list-the-products-ordered-in-a-period/)

## 题目描述

表: `Products`

```
+------------------+---------+
| Column Name      | Type    |
+------------------+---------+
| product_id       | int     |
| product_name     | varchar |
| product_category | varchar |
+------------------+---------+
product_id 是该表主键(具有唯一值的列)。
该表包含该公司产品的数据。
```

表: `Orders`

```
+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| product_id    | int     |
| order_date    | date    |
| unit          | int     |
+---------------+---------+
该表可能包含重复行。
product_id 是表单 Products 的外键（reference 列）。
unit 是在日期 order_date 内下单产品的数目。
```

写一个解决方案，要求获取在 2020 年 2 月份下单的数量不少于 100 的产品的名字和数目。

返回结果表单的 **顺序无要求 **。

查询结果的格式如下。

**示例 1:**

```
输入：
Products 表:
+-------------+-----------------------+------------------+
| product_id  | product_name          | product_category |
+-------------+-----------------------+------------------+
| 1           | Leetcode Solutions    | Book             |
| 2           | Jewels of Stringology | Book             |
| 3           | HP                    | Laptop           |
| 4           | Lenovo                | Laptop           |
| 5           | Leetcode Kit          | T-shirt          |
+-------------+-----------------------+------------------+
Orders 表:
+--------------+--------------+----------+
| product_id   | order_date   | unit     |
+--------------+--------------+----------+
| 1            | 2020-02-05   | 60       |
| 1            | 2020-02-10   | 70       |
| 2            | 2020-01-18   | 30       |
| 2            | 2020-02-11   | 80       |
| 3            | 2020-02-17   | 2        |
| 3            | 2020-02-24   | 3        |
| 4            | 2020-03-01   | 20       |
| 4            | 2020-03-04   | 30       |
| 4            | 2020-03-04   | 60       |
| 5            | 2020-02-25   | 50       |
| 5            | 2020-02-27   | 50       |
| 5            | 2020-03-01   | 50       |
+--------------+--------------+----------+
输出：
+--------------------+---------+
| product_name       | unit    |
+--------------------+---------+
| Leetcode Solutions | 130     |
| Leetcode Kit       | 100     |
+--------------------+---------+
解释：
2020 年 2 月份下单 product_id = 1 的产品的数目总和为 (60 + 70) = 130 。
2020 年 2 月份下单 product_id = 2 的产品的数目总和为 80 。
2020 年 2 月份下单 product_id = 3 的产品的数目总和为 (2 + 3) = 5 。
2020 年 2 月份 product_id = 4 的产品并没有下单。
2020 年 2 月份下单 product_id = 5 的产品的数目总和为 (50 + 50) = 100 。
```

## 题解

::: details 点击查看题解

### 思路

`Orders` 里同一产品在 2 月可能有多笔订单（甚至有同一天的多行），题目要的是**求和**而不是计数，所以聚合用 `SUM(unit)`，不能写成 `COUNT(*)`——product_id = 5 有两行各 50，计数只有 2，求和才是 100，刚好卡在阈值上。

筛选顺序很关键：月份条件必须放在 `WHERE` 里（先过滤再聚合），阈值 `>= 100` 放在 `HAVING` 里（过滤聚合结果）。如果误把 `SUM(unit) >= 100` 写进 `WHERE`，MySQL 会直接报「Invalid use of group function」。日期范围建议写 `order_date >= '2020-02-01' AND order_date < '2020-03-01'`（左闭右开），比 `BETWEEN '2020-02-01' AND '2020-02-29'` 更安全——闰年时 2 月有 29 日，而 2020 恰好是闰年，两种写法在这题都能过，但闭区间写法碰上 `datetime` 类型的列会漏掉最后一天的时间部分。

由于 `Products` 与 `Orders` 是多对一关系，连接后按 `product_id` 分组即可，`product_name` 依赖主键、可以直接取。用 `JOIN` 而非 `LEFT JOIN`：2 月没有订单的产品本来就不该出现。

### SQL 实现

```sql
SELECT p.product_name,
       SUM(o.unit) AS unit
FROM Products p
JOIN Orders o ON o.product_id = p.product_id
WHERE o.order_date >= '2020-02-01'
  AND o.order_date < '2020-03-01'
GROUP BY p.product_id, p.product_name
HAVING SUM(o.unit) >= 100;
```

### 复杂度分析

- 时间复杂度：O(n + m)，n、m 分别为两表行数，连接后一次分组聚合。
- 空间复杂度：O(k)，k 为 2 月有订单的产品数。
