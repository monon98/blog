# 产品名称格式修复

> 难度：简单 | 标签：字符串函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/fix-product-name-format/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Sales` 表：

```
+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| sale_id      | int     |
| product_name | varchar |
| sale_date    | date    |
+--------------+---------+
sale_id 是该表具有唯一值的列，每一行代表一次销售记录：产品名称与销售日期。
```

`Sales` 表是 2000 年手工录入的，`product_name` 大小写混乱，还可能带前后空格，同一个产品会以 `LCPHONE`、`LCPhone`、`LcPhOnE` 等多种写法出现。

编写一个解决方案，按月汇总销售情况，要求：

- `product_name` 统一为**小写字母**，并且不含前后空格；
- `sale_date` 只保留到月，格式为 `YYYY-MM`；
- `total` 为该产品在该月的销售次数。

结果按 `product_name` **升序** 排列；若 `product_name` 相同，再按 `sale_date` **升序** 排列。

**示例 1：**

```
输入：
Sales 表：
+---------+--------------+------------+
| sale_id | product_name | sale_date  |
+---------+--------------+------------+
| 1       | LCPHONE      | 2000-01-16 |
| 2       | LCPhone      | 2000-01-17 |
| 3       | LcPhOnE      | 2000-02-18 |
| 4       | LCKeyCHAiN   | 2000-02-19 |
| 5       | LCKeyChain   | 2000-02-28 |
| 6       | Matryoshka   | 2000-03-31 |
+---------+--------------+------------+
输出：
+--------------+-----------+-------+
| product_name | sale_date | total |
+--------------+-----------+-------+
| lckeychain   | 2000-02   | 2     |
| lcphone      | 2000-01   | 2     |
| lcphone      | 2000-02   | 1     |
| matryoshka   | 2000-03   | 1     |
+--------------+-----------+-------+
解释：
一月份售出 2 部手机（LCPHONE 与 LCPhone 视为同一产品）。
二月份售出 2 个钥匙扣（LCKeyCHAiN 与 LCKeyChain 视为同一产品）和 1 部手机。
三月份售出 1 个 Matryoshka。
```

## 题解

::: details 点击查看题解

### 思路

这题的核心是「先规范化，再聚合」。`LCPHONE`、`LCPhone`、`LcPhOnE` 在原始数据里是三行不同字符串，如果直接 `GROUP BY product_name`，它们会被拆成三组，`total` 全是 1，结果就完全错了。所以必须先把 `LOWER(TRIM(product_name))` 落成同一份文本，再按月聚合。

`TRIM` 不能省：题目明确说 2000 年的数据是手工录入的、可能带前后空格，`'lcphone'` 与 `'lcphone '` 一旦漏掉 `TRIM` 就分不到一组。同理 `LOWER` 与 `TRIM` 的顺序无所谓（`TRIM` 不影响大小写），但两者都要在 `GROUP BY` **之前**生效——所以最稳的写法是用 CTE 或派生表先把规范化结果算出来，外层只做分组；直接在 `GROUP BY LOWER(TRIM(product_name))` 里写表达式也行，可读性差一些，而且 `SELECT` 列表必须重复同一表达式。

日期侧用 `DATE_FORMAT(sale_date, '%Y-%m')` 截断到月，同一天的多笔销售自然归入同组；`total` 用 `COUNT(*)` 或 `COUNT(1)` 都可以（`sale_id` 唯一，不存在重复计数问题）。最后别忘两个排序键都要写，只按 `product_name` 排序时 `lcphone` 的两个月份顺序是不确定的。

### SQL 实现

```sql
WITH t AS (
    SELECT LOWER(TRIM(product_name)) AS product_name,
           DATE_FORMAT(sale_date, '%Y-%m') AS sale_date
    FROM Sales
)
SELECT product_name,
       sale_date,
       COUNT(*) AS total
FROM t
GROUP BY product_name, sale_date
ORDER BY product_name ASC, sale_date ASC;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为销售记录数，分组后需要排序。
- 空间复杂度：O(g)，g 为「产品 × 月份」分组数。

:::
