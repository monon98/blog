# 计算停车费与时长

> 难度：中等 | 标签：分组聚合、窗口函数、日期时间函数 | [LeetCode 原题](https://leetcode.cn/problems/calculate-parking-fees-and-duration/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`ParkingTransactions` 表：

```
+--------------+-----------+
| Column Name  | Type      |
+--------------+-----------+
| lot_id       | int       |
| car_id       | int       |
| entry_time   | datetime  |
| exit_time    | datetime  |
| fee_paid     | decimal   |
+--------------+-----------+
(lot_id, car_id, entry_time) 是该表的联合主键。
每一行记录某辆车在某个停车场的入场时间、出场时间和缴费金额。
```

编写一个查询，按车统计：在**所有停车场**累计支付的总费用、平均每小时的费用（四舍五入到 2 位小数），以及这辆车**累计停留时间最长**的停车场。

返回列：`car_id`、`total_fee_paid`、`avg_hourly_fee`、`most_time_lot`，按 `car_id` 升序排列。

题目保证同一辆车不会同时停在多个停车场。

**示例 1：**

输入：

```
ParkingTransactions 表：
+--------+--------+---------------------+---------------------+----------+
| lot_id | car_id | entry_time          | exit_time           | fee_paid |
+--------+--------+---------------------+---------------------+----------+
| 1      | 1001   | 2023-06-01 08:00:00 | 2023-06-01 10:30:00 | 5.00     |
| 1      | 1001   | 2023-06-02 11:00:00 | 2023-06-02 12:45:00 | 3.00     |
| 2      | 1001   | 2023-06-01 10:45:00 | 2023-06-01 12:00:00 | 6.00     |
| 2      | 1002   | 2023-06-01 09:00:00 | 2023-06-01 11:30:00 | 4.00     |
| 3      | 1001   | 2023-06-03 07:00:00 | 2023-06-03 09:00:00 | 4.00     |
| 3      | 1002   | 2023-06-02 12:00:00 | 2023-06-02 14:00:00 | 2.00     |
+--------+--------+---------------------+---------------------+----------+
```

输出：

```
+--------+----------------+----------------+---------------+
| car_id | total_fee_paid | avg_hourly_fee | most_time_lot |
+--------+----------------+----------------+---------------+
| 1001   | 18.00          | 2.40           | 1             |
| 1002   | 6.00           | 1.33           | 2             |
+--------+----------------+----------------+---------------+
```

解释：

- 车 1001：总费用 5 + 3 + 6 + 4 = 18.00；总时长 2.5 + 1.75 + 1.25 + 2 = 7.5 小时，平均每小时 18 / 7.5 = 2.40；停车场 1 累计 4.25 小时、停车场 2 累计 1.25 小时、停车场 3 累计 2 小时，最久的是 1 号。
- 车 1002：总费用 4 + 2 = 6.00；总时长 4.5 小时，平均每小时 1.33；停车场 2 累计 2.5 小时、停车场 3 累计 2 小时，最久的是 2 号。

## 题解

::: details 点击查看题解

### 思路

三个输出指标需要两级粒度：总费用和平均每小时费用是"按车"聚合，而最久停车场要先"按车 + 按停车场"聚合出停留时长再排名。所以分两步走，第一层 CTE 按 `(car_id, lot_id)` 汇总秒数，再用 `ROW_NUMBER() OVER (PARTITION BY car_id ORDER BY secs DESC)` 取 rn = 1 得到最久的停车场。

第二层 CTE 直接对原表按 `car_id` 汇总总费用和总秒数，平均每小时费用 = `总费用 / (总秒数 / 3600)`，最后 `ROUND(..., 2)`。

易错点：一是平均费用是"总费用 ÷ 总时长"，不是各次单价的算术平均（示例里车 1001 若按单价平均会得到 4.5 而不是 2.40）；二是 `TIMESTAMPDIFF` 的单位选 `SECOND`，用 `HOUR` 会把不足一小时的零头截断，示例中的 1.75、1.25 小时都会算错；三是 `ROW_NUMBER()` 必须按秒数降序，否则取到的是最先去过的停车场；四是 `DECIMAL` 相除要注意精度，`ROUND` 放在最后一步。

替代写法：最久停车场也可以用 `ORDER BY ... LIMIT 1` 的相关子查询，但每辆车都要执行一次子查询；或者用 `GROUP_CONCAT(lot_id ORDER BY secs DESC)` 取第一个值，可读性稍差。

### SQL 实现

```sql
WITH lot_time AS (
    SELECT car_id,
           lot_id,
           SUM(TIMESTAMPDIFF(SECOND, entry_time, exit_time)) AS secs
    FROM ParkingTransactions
    GROUP BY car_id, lot_id
),
best_lot AS (
    SELECT car_id,
           lot_id,
           ROW_NUMBER() OVER (PARTITION BY car_id ORDER BY secs DESC) AS rn
    FROM lot_time
),
total AS (
    SELECT car_id,
           SUM(fee_paid) AS total_fee_paid,
           SUM(TIMESTAMPDIFF(SECOND, entry_time, exit_time)) AS total_secs
    FROM ParkingTransactions
    GROUP BY car_id
)
SELECT t.car_id,
       ROUND(t.total_fee_paid, 2) AS total_fee_paid,
       ROUND(t.total_fee_paid / (t.total_secs / 3600), 2) AS avg_hourly_fee,
       b.lot_id AS most_time_lot
FROM total AS t
JOIN best_lot AS b
    ON b.car_id = t.car_id
   AND b.rn = 1
ORDER BY t.car_id;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为交易行数，两次分组 + 一次窗口排序。
- 空间复杂度：O(n)，两个 CTE 分别物化了按停车场聚合和按车聚合的结果。
