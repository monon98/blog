# 找到所有不同的邮件域名

> 难度：简单 | 标签：字符串函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/find-all-unique-email-domains/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Emails` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| email       | varchar |
+-------------+---------+
id 是该表具有唯一值的列。
每一行包含一个邮箱地址，邮箱中不含大写字母。
```

编写一个查询，找出所有不同的邮箱域名，并统计每个域名下有多少个邮箱。**只考虑以 `.com` 结尾**的域名。

返回列：`email_domain`、`count`，按 `email_domain` 升序排列。

**示例 1：**

输入：

```
Emails 表：
+-----+-----------------------+
| id  | email                 |
+-----+-----------------------+
| 336 | hwkiy@test.edu        |
| 489 | adcmaf@outlook.com    |
| 449 | vrzmwyum@yahoo.com    |
| 95  | tof@test.edu          |
| 320 | jxhbagkpm@example.org |
| 411 | zxcf@outlook.com      |
+-----+-----------------------+
```

输出：

```
+--------------+-------+
| email_domain | count |
+--------------+-------+
| outlook.com  | 2     |
| yahoo.com    | 1     |
+--------------+-------+
```

解释：以 `.com` 结尾的域名只有 `outlook.com` 和 `yahoo.com`，分别对应 2 个和 1 个邮箱；`test.edu`、`example.org` 不以 `.com` 结尾，被排除。

## 题解

::: details 点击查看题解

### 思路

域名就是 `@` 之后的部分。`SUBSTRING_INDEX(email, '@', -1)` 表示"按 `@` 切分后取最后一段"，正好拿到域名；如果需要支持 `a@b@c.com` 这种脏数据，取最后一段也是更稳妥的语义。

过滤条件用 `email LIKE '%.com'`，题目只要求统计以 `.com` 结尾的域名，`.edu`、`.org` 一律排除。然后按域名分组计数，最后按域名升序输出。

易错点：一是 `SUBSTRING_INDEX(email, '@', 1)` 取的是 `@` **前面**的部分（本地名），方向写反就全错了；二是排序依据是 `email_domain`（字符串序），不是 `count`，题目明确要求按域名升序；三是如果只写 `LIKE '%com'`，`abc@x.comm` 之类的也会被算进来，用 `'%.com'` 更准确。

替代写法：`RIGHT(email, 4) = '.com'` 做过滤、`MID(email, LOCATE('@', email) + 1)` 取域名，效果一样，只是可读性略差。

### SQL 实现

```sql
SELECT SUBSTRING_INDEX(email, '@', -1) AS email_domain,
       COUNT(*) AS `count`
FROM Emails
WHERE email LIKE '%.com'
GROUP BY email_domain
ORDER BY email_domain;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为邮箱数量，分组后需要排序。
- 空间复杂度：O(d)，d 为不同域名的个数。

:::
