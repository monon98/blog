# 查找热门话题标签 II

> 难度：困难 | 标签：递归 CTE、字符串函数、分组聚合 | [LeetCode 原题](https://leetcode.cn/problems/find-trending-hashtags-ii/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Tweets` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| tweet_id    | int     |
| tweet_date  | date    |
| tweet       | varchar |
+-------------+---------+
tweet_id 是该表具有唯一值的列。
每一行包含用户 ID、推文 ID、发布日期和推文内容，所有 tweet_date 都是 2024 年 2 月的合法日期。
```

与上一题不同，这次**每条推文可能包含多个**话题标签。编写一个查询，找出 2024 年 2 月最热门的 3 个话题标签。

返回列：`hashtag`（带 `#`）、`count`，按 `count` 降序、`hashtag` 降序排列，只输出前 3 行。

**示例 1：**

输入：

```
Tweets 表：
+---------+----------+------------------------------------------------------------+------------+
| user_id | tweet_id | tweet                                                      | tweet_date |
+---------+----------+------------------------------------------------------------+------------+
| 135     | 13       | Enjoying a great start to the day. #HappyDay #MorningVibes | 2024-02-01 |
| 136     | 14       | Another #HappyDay with good vibes! #FeelGood               | 2024-02-03 |
| 137     | 15       | Productivity peaks! #WorkLife #ProductiveDay               | 2024-02-04 |
| 138     | 16       | Exploring new tech frontiers. #TechLife #Innovation        | 2024-02-04 |
| 139     | 17       | Gratitude for today's moments. #HappyDay #Thankful         | 2024-02-05 |
| 140     | 18       | Innovation drives us. #TechLife #FutureTech                | 2024-02-07 |
| 141     | 19       | Connecting with nature's serenity. #Nature #Peaceful       | 2024-02-09 |
+---------+----------+------------------------------------------------------------+------------+
```

输出：

```
+-----------+-------+
| hashtag   | count |
+-----------+-------+
| #HappyDay | 3     |
| #TechLife | 2     |
| #WorkLife | 1     |
+-----------+-------+
```

解释：

- `#HappyDay` 出现在 tweet_id 13、14、17 中，共 3 次。
- `#TechLife` 出现在 tweet_id 16、18 中，共 2 次。
- 其余标签都只出现 1 次，按标签名降序时 `#WorkLife` 最大，因此排在第三位。

## 题解

::: details 点击查看题解

### 思路

难点在于一条推文里有多个标签，而 SQL 没有"把一个字符串按分隔符炸成多行"的内置函数，所以要用递归 CTE 手工拆。思路是：先算出每条推文里 `#` 的个数（`LENGTH(tweet) - LENGTH(REPLACE(tweet, '#', ''))`），再为每个标签生成一个序号 1..n，每行取第 idx 个标签。

取第 idx 个标签分三层 `SUBSTRING_INDEX`：最内层 `SUBSTRING_INDEX(tweet, '#', idx + 1)` 从左边数到第 idx 个 `#` 的末尾，中间层 `SUBSTRING_INDEX(..., '#', -1)` 取这段里最后一个 `#` 之后的内容（即标签本体加上它后面的文字），最外层 `SUBSTRING_INDEX(..., ' ', 1)` 截到第一个空格，把"标签后面跟着的文字"去掉。标签在句末时，最外层不会截掉任何字符。

展开后就是一个"标签 → 一行"的中间表，`GROUP BY` 计数、按 `count DESC, hashtag DESC` 排序、`LIMIT 3` 即可。注意并列是常态（示例里 1 次的标签一大堆），第二个排序键决定了谁是第三名。

易错点：递归的终止条件必须写 `idx < tag_cnt`，写成 `<=` 会多拆出一行空标签；`GROUP BY` 时直接用外层别名在 MySQL 里可行但要注意别名不能出现在 `WHERE`；`count` 是保留的聚合函数名，做列名要加反引号。

替代写法：MySQL 8 的 `REGEXP_REPLACE` + 数字表做正则拆分；或者因为标签总在 `#` 之后、以空格结束，也可以先用 `REPLACE(tweet, '#', ' #')` 规整再按空格用递归拆分，思路类似。

### SQL 实现

```sql
WITH RECURSIVE split AS (
    SELECT tweet_id,
           tweet,
           1 AS idx,
           LENGTH(tweet) - LENGTH(REPLACE(tweet, '#', '')) AS tag_cnt
    FROM Tweets
    WHERE tweet_date >= '2024-02-01'
      AND tweet_date < '2024-03-01'
    UNION ALL
    SELECT tweet_id,
           tweet,
           idx + 1,
           tag_cnt
    FROM split
    WHERE idx < tag_cnt
)
SELECT CONCAT(
           '#',
           SUBSTRING_INDEX(
               SUBSTRING_INDEX(SUBSTRING_INDEX(tweet, '#', idx + 1), '#', -1),
               ' ', 1
           )
       ) AS hashtag,
       COUNT(*) AS `count`
FROM split
GROUP BY hashtag
ORDER BY `count` DESC, hashtag DESC
LIMIT 3;
```

### 复杂度分析

- 时间复杂度：O(n·k)，n 为推文数、k 为每条推文的平均标签数，递归展开后还要一次分组排序。
- 空间复杂度：O(n·k)，递归中间结果的行数。
