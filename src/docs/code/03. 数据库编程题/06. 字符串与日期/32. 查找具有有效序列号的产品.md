# 查找具有有效序列号的产品

> 难度：简单 | 标签：正则匹配、字符串函数 | [LeetCode 原题](https://leetcode.cn/problems/find-products-with-valid-serial-numbers/)

## 题目描述

表：`products`

```
+--------------+------------+
| Column Name  | Type       |
+--------------+------------+
| product_id   | int        |
| product_name | varchar    |
| description  | varchar    |
+--------------+------------+
(product_id) 是这张表的唯一主键。
这张表的每一行表示一个产品的唯一 ID，名字和描述。
```

编写一个解决方案来找到所有描述中 **包含一个有效序列号** 模式的产品。一个有效序列号符合下述规则：

	- 以 SN 字母开头（区分大小写）。

	- 后面有恰好 4 位数字。

	- 接着是一个短横（-）， 短横后面还有另一组 4 位数字

	- 序列号必须在描述内（可能不在描述的开头）

返回结果表以 `product_id` **升序** 排序。

结果格式如下所示。

示例：

**输入：**

products 表：

+------------+--------------+------------------------------------------------------+
| product_id | product_name | description                                          |
+------------+--------------+------------------------------------------------------+
| 1          | Widget A     | This is a sample product with SN1234-5678            |
| 2          | Widget B     | A product with serial SN9876-1234 in the description |
| 3          | Widget C     | Product SN1234-56789 is available now                |
| 4          | Widget D     | No serial number here                                |
| 5          | Widget E     | Check out SN4321-8765 in this description            |
+------------+--------------+------------------------------------------------------+

**输出：**

+------------+--------------+------------------------------------------------------+
| product_id | product_name | description                                          |
+------------+--------------+------------------------------------------------------+
| 1          | Widget A     | This is a sample product with SN1234-5678            |
| 2          | Widget B     | A product with serial SN9876-1234 in the description |
| 5          | Widget E     | Check out SN4321-8765 in this description            |
+------------+--------------+------------------------------------------------------+

**解释：**

	- 产品 1：有效的序列号 SN1234-5678

	- 产品 2：有效的序列号 SN9876-1234

	- 产品 3：无效的序列号 SN1234-56789（短横后包含 5 位数字）

	- 产品 4：描述中没有序列号

	- 产品 5：有效的序列号 SN4321-8765

结果表以 product_id 升序排序。

## 题解

::: details 点击查看题解

### 思路

匹配核心是一条正则：`SN[0-9]{4}-[0-9]{4}`，再给末尾加一个「非数字或串尾」的边界 `([^0-9]|$)`。这一步是本题的关键——产品 3 的 `SN1234-56789` 中，`SN1234-5678` 本身就满足前缀模式，如果不加边界约束，它会被误判为有效；加上 `[^0-9]` 后，紧跟 5 位数字的情况就匹配不上了。同理，`SN` 前多出数字的场景由题意（序列号以 SN 开头）保证不会出现，故前边界可省略。

第二个易错点是大小写：题目要求 `SN` 区分大小写，而 MySQL 8 的 `REGEXP` 在默认排序规则下是大小写不敏感的，`sn1234-5678` 也会被匹配。必须改用 `REGEXP_LIKE(description, pattern, 'c')`，`c` 标志表示 case-sensitive。

注意 `{4}` 是精确重复次数，`SN12345-6789`（短横前 5 位）中 `[0-9]{4}` 吃掉 `1234` 后遇到的不是 `-`，回溯也救不回来，因此无需额外写前边界。最后按 `product_id` 升序输出即可。

### SQL 实现

```sql
SELECT product_id, product_name, description
FROM products
WHERE REGEXP_LIKE(description, 'SN[0-9]{4}-[0-9]{4}([^0-9]|$)', 'c')
ORDER BY product_id;
```

### 复杂度分析

- 时间复杂度：O(n·L)，n 为产品数、L 为描述平均长度，每行一次正则匹配。
- 空间复杂度：O(1)，仅输出命中的行。

:::
