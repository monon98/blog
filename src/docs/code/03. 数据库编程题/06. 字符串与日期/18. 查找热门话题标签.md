# 查找热门话题标签

> 难度：中等 | 标签：字符串函数、分组聚合、LIMIT 取前 N | [LeetCode 原题](https://leetcode.cn/problems/find-trending-hashtags/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Tweets` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| user_id     | int     |
| tweet_id    | int     |
| tweet_date  | date    |
| tweet       | varchar |
+-------------+---------+
tweet_id 是该表具有唯一值的列。
每一行包含用户 ID、推文 ID、发布日期和推文内容。
```

每条推文**只包含一个**话题标签（hashtag，以 `#` 开头）。编写一个查询，找出 2024 年 2 月最热门的 3 个话题标签。

返回列：`hashtag`（带 `#`）、`hashtag_count`，按 `hashtag_count` 降序、`hashtag` 降序排列，只输出前 3 行。

**示例 1：**

输入：

```
Tweets 表：
+---------+----------+----------------------------------------------+------------+
| user_id | tweet_id | tweet                                        | tweet_date |
+---------+----------+----------------------------------------------+------------+
| 135     | 13       | Enjoying a great start to the day. #HappyDay | 2024-02-01 |
| 136     | 14       | Another #HappyDay with good                   | 2024-02-03 |
| 137     | 15       | Productivity peaks! #WorkLife                 | 2024-02-04 |
| 138     | 16       | Exploring new tech frontiers. #TechLife       | 2024-02-04 |
| 139     | 17       | Gratitude for today's moments. #HappyDay      | 2024-02-05 |
| 140     | 18       | Innovation drives us. #TechLife               | 2024-02-07 |
| 141     | 19       | Connecting with nature's serenity. #Nature    | 2024-02-09 |
+---------+----------+----------------------------------------------+------------+
```

输出：

```
+-----------+---------------+
| hashtag   | hashtag_count |
+-----------+---------------+
| #HappyDay | 3             |
| #TechLife | 2             |
| #WorkLife | 1             |
+-----------+---------------+
```

解释：

- `#HappyDay` 出现在 tweet_id 13、14、17 中，共 3 次。
- `#TechLife` 出现在 tweet_id 16、18 中，共 2 次。
- `#WorkLife` 与 `#Nature` 都是 1 次，按标签降序时 `#WorkLife` 更大，因此排在第三位。

## 题解

::: details 点击查看题解

### 思路

因为每条推文最多一个标签，抽取标签可以分两步走：先用 `SUBSTRING_INDEX(tweet, '#', -1)` 取"最后一个 `#` 之后的所有内容"，再用 `SUBSTRING_INDEX(..., ' ', 1)` 截到第一个空格为止。这样 `Another #HappyDay with good` 会先变成 `HappyDay with good`，再变成 `HappyDay`；而标签在句末时（如 `#TechLife`）第二步不会截掉任何东西。

抽出来的是不带 `#` 的裸标签，统计时最好先补回 `#`（`CONCAT('#', ...)`）再分组，这样输出格式和分组键都是最终形态，避免同一条 SQL 里出现两种写法。

排序是本题唯一容易丢分的地方：`ORDER BY hashtag_count DESC, hashtag DESC` 两个字段都要写，题目要求并列时按标签降序；然后 `LIMIT 3` 取前三。示例里 `#WorkLife` 和 `#Nature` 都是 1 次，正是靠第二个排序键才定出第三名。

易错点：直接 `GROUP BY tweet` 会把不同用户发的相同标签当成不同组；忘了过滤 2 月（`tweet_date` 的取值范围）会把其它月份算进来；只写 `LIMIT 3` 而不写排序，结果取决于执行计划，完全不可靠。

### SQL 实现

```sql
SELECT CONCAT('#', SUBSTRING_INDEX(SUBSTRING_INDEX(tweet, '#', -1), ' ', 1)) AS hashtag,
       COUNT(*) AS hashtag_count
FROM Tweets
WHERE tweet_date >= '2024-02-01'
  AND tweet_date < '2024-03-01'
GROUP BY hashtag
ORDER BY hashtag_count DESC, hashtag DESC
LIMIT 3;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为推文数，分组后排序取前 3。
- 空间复杂度：O(m)，m 为不同标签的数量。

:::
