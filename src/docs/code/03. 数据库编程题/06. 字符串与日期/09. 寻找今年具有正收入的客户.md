# 寻找今年具有正收入的客户

> 难度：简单 | 标签：WHERE 过滤 | [LeetCode 原题](https://leetcode.cn/problems/find-customers-with-positive-revenue-this-year/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Customers` 表：

```
+--------------+------+
| Column Name  | Type |
+--------------+------+
| customer_id  | int  |
| year         | int  |
| revenue      | int  |
+--------------+------+
(customer_id, year) 是该表的主键（具有唯一值的列的组合）。
这张表记录了每个客户在不同年份的收入，收入可能为负数。
```

编写一个解决方案，报告 **2021 年** 收入为 **正数** 的客户。可以按任意顺序返回结果。

**示例 1：**

```
输入：
Customers 表：
+-------------+------+---------+
| customer_id | year | revenue |
+-------------+------+---------+
| 1           | 2018 | 50      |
| 1           | 2021 | 30      |
| 1           | 2020 | 70      |
| 2           | 2021 | -50     |
| 3           | 2018 | 10      |
| 3           | 2016 | 50      |
| 4           | 2021 | 20      |
+-------------+------+---------+
输出：
+-------------+
| customer_id |
+-------------+
| 1           |
| 4           |
+-------------+
解释：
客户 1 在 2021 年的收入为 30；
客户 2 在 2021 年的收入为 -50；
客户 3 在 2021 年没有记录；
客户 4 在 2021 年的收入为 20。
因此只有客户 1 和客户 4 在 2021 年有正收入。
```

## 题解

::: details 点击查看题解

### 思路

这题不需要任何聚合或连接：`(customer_id, year)` 是主键，每个客户每年最多一行，所以「2021 年收入为正」就是对单行做两个谓词的过滤，直接 `WHERE year = 2021 AND revenue > 0` 即可。

易错点有三个。第一，条件是 `revenue > 0` 而**不是** `>= 0`：客户 2 的 -50 不符合，若数据里出现 0 元收入也不该算「正收入」。第二，不能漏掉年份条件——客户 1 在 2018、2020 年也有正收入，但只能凭 2021 那一行入选；反过来客户 3 有正收入却全在 2021 年之外，必须被排除。第三，别想着用 `GROUP BY customer_id` + `SUM(revenue) > 0` 去算「总正收入」，本题只看当年这一行，用聚合反而会引入 0 行客户的 NULL 问题。

`year` 的类型是 `int`，写 `year = 2021` 和 `year = '2021'` 都能命中（MySQL 会做隐式转换），建议写数字字面量避免类型转换。若需要稳定输出顺序，补一个 `ORDER BY customer_id`，虽然题目说顺序不限。

### SQL 实现

```sql
SELECT customer_id
FROM Customers
WHERE year = 2021
  AND revenue > 0;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为表行数，全表扫描一次过滤。
- 空间复杂度：O(1)，不需要额外存储（结果集除外）。

:::
