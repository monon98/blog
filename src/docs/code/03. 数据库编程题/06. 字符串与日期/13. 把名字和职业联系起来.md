# 把名字和职业联系起来

> 难度：简单 | 标签：字符串函数、CONCAT | [LeetCode 原题](https://leetcode.cn/problems/concatenate-the-name-and-the-profession/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Person` 表：

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| person_id   | int     |
| name        | varchar |
| profession  | ENUM    |
+-------------+---------+
person_id 是该表的主键（具有唯一值的列）。
profession 是 ENUM 类型，取值为 ('Doctor', 'Singer', 'Actor', 'Player', 'Engineer', 'Lawyer') 之一。
```

编写一个解决方案，报告每个人的名字，后面紧跟其职业的**第一个字母**，并用括号括起来。返回按 `person_id` **降序** 排列的结果表，列名为 `person_id`、`name`。

**示例 1：**

```
输入：
Person 表：
+-----------+-------+------------+
| person_id | name  | profession |
+-----------+-------+------------+
| 1         | Alex  | Singer     |
| 3         | Alice | Actor      |
| 2         | Bob   | Player     |
| 4         | Messi | Doctor     |
| 6         | Tyson | Engineer   |
| 5         | Meir  | Lawyer     |
+-----------+-------+------------+
输出：
+-----------+----------+
| person_id | name     |
+-----------+----------+
| 6         | Tyson(E) |
| 5         | Meir(L)  |
| 4         | Messi(D) |
| 3         | Alice(A) |
| 2         | Bob(P)   |
| 1         | Alex(S)  |
+-----------+----------+
解释：名字与括号之间、括号与字母之间都不应有任何空格。
```

## 题解

::: details 点击查看题解

### 思路

就是把三个片段拼起来：`name`、字面量括号、职业首字母。取首字母用 `LEFT(profession, 1)`（或 `SUBSTRING(profession, 1, 1)`），再 `CONCAT`。

三个容易踩的点。第一，括号是**字符串字面量**，必须加引号：`CONCAT(name, '(', ...)`。MySQL 里双引号也默认可用于字符串（除非开了 `ANSI_QUOTES`），但用单引号更稳。第二，题目强调「不应该有任何空白」，所以千万不要写成 `CONCAT(name, ' (', LEFT(profession, 1), ')')`——多一个空格在肉眼比对时很容易漏掉。第三，输出列名是 `name`（覆盖了原来的名字列），所以要给表达式起别名 `AS name`，否则列名会是整串表达式，比对报错。

`profession` 是 `ENUM`，`LEFT()` 会把它当作字符串处理（ENUM 在表达式中按字符串值参与运算），所以不需要额外 `CAST`；如果字段是自定义排序的 `SET` 类型才需要留意。排序是 `person_id DESC`，注意是降序，不是升序。

替代写法：`CONCAT_WS('', name, '(', LEFT(profession, 1), ')')` 只是换了个拼接函数，没有实质差别；也可以直接用 `REPLACE` 之类的技巧，但可读性更差。

### SQL 实现

```sql
SELECT person_id,
       CONCAT(name, '(', LEFT(profession, 1), ')') AS name
FROM Person
ORDER BY person_id DESC;
```

### 复杂度分析

- 时间复杂度：O(n log n)，n 为人数，拼接为常数开销，排序为主。
- 空间复杂度：O(1)，不引入额外结构（结果集除外）。
