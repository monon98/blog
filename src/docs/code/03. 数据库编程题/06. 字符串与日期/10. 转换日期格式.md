# 转换日期格式

> 难度：简单 | 标签：日期函数 | [LeetCode 原题](https://leetcode.cn/problems/convert-date-format/)

## 题目描述

> 本题为 LeetCode VIP 专属题，题面根据表结构与测试数据整理。

`Days` 表：

```
+-------------+------+
| Column Name | Type |
+-------------+------+
| day         | date |
+-------------+------+
day 是该表的主键，每一行是一个日期。
```

编写一个查询，把 `Days` 表中的每个日期转换成 `"day_name, month_name day, year"` 格式的字符串，例如 `Tuesday, April 12, 2022`。结果列名为 `day`，顺序不限，**大小写敏感**。

**示例 1：**

```
输入：
Days 表：
+------------+
| day        |
+------------+
| 2022-04-12 |
| 2021-08-09 |
| 2020-06-26 |
+------------+
输出：
+-------------------------+
| day                     |
+-------------------------+
| Tuesday, April 12, 2022 |
| Monday, August 9, 2021  |
| Friday, June 26, 2020   |
+-------------------------+
解释：请注意，输出对大小写敏感，星期与月份都必须是首字母大写的英文全称。
```

## 题解

::: details 点击查看题解

### 思路

这是纯粹的日期格式化题，`DATE_FORMAT` 的格式串一次就能拼完，不需要 `CONCAT` 分段。关键是四个占位符各选对：

- `%W`：星期全称（`Tuesday`），`%a`、`%w`、`%j` 之类分别是缩写、数字和年内天数，都不符合要求；
- `%M`：月份全称（`April`），`%m` 是两位数月份（`04`），拼出来会是 `Tuesday, 04 12, 2022`；
- `%e`：不补零的日（`9` 而不是 `09`）。这是本题最容易错的地方——`%d` 会输出 `August 09, 2021`，与示例的 `August 9, 2021` 不一致；
- `%Y`：四位年份（`%y` 只有两位）。

标点也要照抄：星期后是 `, `（逗号加空格），月份后是空格，日后面又是 `, `，一共两个逗号。MySQL 的 `DATE_FORMAT` 会按服务器的 `lc_time_names` 输出星期与月份名，默认 `en_US` 正是题目要的英文；如果环境被改成其他语言，需要先 `SET lc_time_names = 'en_US'`，否则会输出本地化的名字。

替代写法：`CONCAT_WS(' ', DAYNAME(day) ...)` 拼字符串，但月份全称还得靠 `MONTHNAME`，日期的「不补零」还要再处理，反而不如一条格式串干净。

### SQL 实现

```sql
SELECT DATE_FORMAT(day, '%W, %M %e, %Y') AS day
FROM Days;
```

### 复杂度分析

- 时间复杂度：O(n)，n 为表行数，逐行做一次格式化。
- 空间复杂度：O(1)，不引入额外结构（结果集除外）。

:::
