Promise 链式调用演示

观察 resolve / reject 时值在链上的流转与各步骤的执行顺序

new Promise((resolve) => { ... }) Promise 状态由 pending 变为 fulfilled / rejected，只能变一次 pending
.then(value => { return next }) fulfilled 时执行，返回值（含 Promise）会传给下一环 pending
.then(value => { ... }) 拿到上一环返回的值继续处理，形成链式调用 pending
.catch(err => { ... }) 链上任一环节 reject 都会跳到这里 pending
.finally(() => { ... }) 无论成功失败都会执行，常用于关闭 loading pending
