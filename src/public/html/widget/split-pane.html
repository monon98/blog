左侧栏

拖动分隔条即可改变宽度，右栏会自动伸缩（flex: 1）。

实现要点：监听 divider 的 mousedown，在 document 上绑定 mousemove / mouseup，避免拖出容器后丢失事件。

拖拽期间给 body 加 class 禁用选中，提升手感。

右侧内容区

右侧使用 flex: 1，宽度 = 容器宽度 − 左栏 − 分隔条，无需手动计算。

键盘可用性：divider 支持 tabindex，聚焦后 ← → 方向键每次调整 2%，Home 回到 45%。

宽度变化通过 aria-valuenow 同步给无障碍树。

本例同时支持鼠标拖拽与触摸事件，可直接复制到任意项目中作为可复用的分栏组件基础。
