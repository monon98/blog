# 通用开发技能

## 描述

该技能涵盖了适用于各种开发项目的通用开发实践，包括代码组织、版本控制、性能优化、测试策略、团队协作和项目管理等方面。通过应用这些技能，可以提高代码质量、开发效率和项目成功率。

## 使用场景

- 当需要规范项目代码结构时
- 当需要优化代码质量和性能时
- 当需要建立有效的版本控制流程时
- 当需要实现自动化测试和部署时
- 当需要改善团队协作和项目管理时
- 当需要解决跨平台兼容性问题时

## 指令

### 1. 代码组织与规范

1. **目录结构设计**
   - 按功能模块组织代码目录
   - 使用清晰、一致的命名约定
   - 避免过深的目录嵌套
   - 分离关注点，如将业务逻辑与UI分离

2. **代码风格规范**
   - 制定并遵循团队代码风格指南
   - 使用代码格式化工具（如Prettier、ESLint）
   - 保持代码缩进和命名一致性
   - 编写清晰、简洁的代码注释

3. **模块化设计**
   - 采用模块化编程思想
   - 遵循单一职责原则
   - 使用适当的设计模式
   - 确保模块间的低耦合高内聚

### 2. 版本控制最佳实践

1. **Git工作流**
   - 选择适合团队的Git工作流（如Git Flow、GitHub Flow）
   - 保持分支管理的清晰性
   - 定期合并和清理分支

2. **提交规范**
   - 使用清晰、描述性的提交信息
   - 遵循提交信息规范（如Conventional Commits）
   - 保持提交的原子性，每个提交只包含一个逻辑变更

3. **代码审查**
   - 建立代码审查流程
   - 使用Pull Request/Merge Request进行代码审查
   - 提供建设性的反馈
   - 确保代码质量和一致性

### 3. 性能优化策略

1. **前端性能优化**
   - 资源压缩和合并
   - 图片优化和懒加载
   - 代码分割和按需加载
   - 缓存策略优化
   - 减少重排和重绘

2. **后端性能优化**
   - 数据库查询优化
   - 缓存机制设计
   - 并发处理优化
   - 代码执行效率优化

3. **系统性能监控**
   - 建立性能监控体系
   - 识别性能瓶颈
   - 持续优化系统性能

### 4. 测试策略

1. **测试类型**
   - 单元测试
   - 集成测试
   - 端到端测试
   - 性能测试

2. **测试工具**
   - 选择适合项目的测试框架
   - 使用测试覆盖率工具
   - 自动化测试流程

3. **测试最佳实践**
   - 编写可测试的代码
   - 测试边界情况和异常场景
   - 定期运行测试套件
   - 持续集成中的测试策略

### 5. 团队协作与项目管理

1. **协作工具**
   - 选择适合团队的协作工具
   - 建立有效的沟通渠道
   - 使用项目管理工具（如JIRA、Trello）

2. **开发流程**
   - 敏捷开发实践
   - 迭代规划和执行
   - 持续集成和部署

3. **文档管理**
   - 项目文档的编写和维护
   - API文档的自动生成
   - 技术决策记录（ADR）

### 6. 跨平台兼容性

1. **浏览器兼容性**
   - 制定浏览器支持策略
   - 使用Polyfill和降级方案
   - 跨浏览器测试

2. **设备兼容性**
   - 响应式设计
   - 移动设备适配
   - 不同屏幕尺寸的测试

3. **环境一致性**
   - 使用容器化技术（如Docker）
   - 环境配置的版本控制
   - 开发、测试和生产环境的一致性

### 7. 安全性最佳实践

1. **代码安全**
   - 常见安全漏洞的防范
   - 输入验证和 sanitization
   - 安全的密码存储

2. **依赖管理**
   - 定期更新依赖包
   - 漏洞扫描
   - 依赖版本锁定

3. **部署安全**
   - 环境变量管理
   - 敏感信息保护
   - 安全的部署流程

## 示例

### 输入：
需要优化一个前端项目的性能，包括加载速度和运行效率。

### 输出：
1. **资源优化**
   - 压缩和合并CSS/JavaScript文件
   - 优化图片资源，使用适当的格式和大小
   - 实现图片懒加载

2. **代码优化**
   - 代码分割，实现按需加载
   - 减少不必要的DOM操作
   - 优化重排和重绘

3. **缓存策略**
   - 合理设置HTTP缓存头
   - 使用Service Worker进行离线缓存
   - 实现资源预加载

4. **性能监控**
   - 集成性能监控工具
   - 分析性能瓶颈
   - 持续优化和测试

5. **构建优化**
   - 优化构建配置
   - 减少构建产物大小
   - 实现增量构建

### 输入：
需要建立一个团队的Git工作流和代码审查流程。

### 输出：
1. **Git工作流设计**
   - 选择适合团队的Git工作流（如GitHub Flow）
   - 定义分支命名规范和用途
   - 建立分支管理策略

2. **提交规范**
   - 制定提交信息规范
   - 使用Conventional Commits格式
   - 确保提交的原子性

3. **代码审查流程**
   - 建立Pull Request/Merge Request流程
   - 定义代码审查的标准和要点
   - 分配审查人员和审查时间

4. **工具集成**
   - 集成代码质量检查工具
   - 配置CI/CD流程
   - 自动化测试和部署

5. **团队培训**
   - 培训团队成员了解新的工作流
   - 提供Git和代码审查的最佳实践指南
   - 定期回顾和改进流程
