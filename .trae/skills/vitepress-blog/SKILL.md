# VitePress 博客项目技能

## 描述

该技能用于 VitePress 博客项目的开发和维护，包括项目结构优化、配置管理、链接处理和构建优化等方面。通过使用该技能，可以确保 VitePress 博客项目的代码质量和构建效率。

## 使用场景

- 当需要重新规划 VitePress 博客项目结构时
- 当需要优化 VitePress 配置文件时
- 当需要修复链接跳转问题时
- 当需要解决服务端渲染错误时
- 当需要优化构建过程时

## 指令

### 1. 项目结构优化

1. 分析现有项目结构，识别问题和改进空间
2. 设计新的目录结构，使用英文目录名，避免使用中文或特殊字符
3. 重新组织文档内容，按功能和类型分类
4. 统一文件和目录命名，使用小写字母和连字符，避免使用空格

### 2. 配置文件优化

1. 简化 VitePress 配置文件，只包含必要的设置
2. 更新导航和侧边栏配置，使其与新的目录结构匹配
3. 使用自动生成的侧边栏，根据目录结构自动生成导航
4. 确保配置文件中的路径设置正确

### 3. 链接处理

1. 确保链接使用相对路径，不包含 .md 扩展名
2. 处理链接中的空格，将空格转义为 %20
3. 验证链接指向的文件路径是否正确
4. 确保所有链接都能正确跳转

### 4. 服务端渲染错误修复

1. 识别服务端渲染错误，特别是与浏览器特有对象相关的错误
2. 在使用浏览器特有对象（如 window、navigator、performance）时，添加条件判断
3. 确保在服务端渲染时使用默认值，避免构建错误
4. 测试修复后的构建过程，确保没有错误

### 5. 构建优化

1. 处理构建过程中的警告，特别是关于未加载的语言标记的警告
2. 优化图片和其他静态资源，减少构建产物大小
3. 考虑使用动态导入（dynamic import）来分割代码，减少 chunk 大小
4. 测试构建过程，确保项目能够成功构建

### 6. 工具使用技巧

1. 在 Windows 环境下，使用 PowerShell 命令时要注意语法差异
2. 使用 Move-Item 命令移动文件，使用 Remove-Item 命令删除文件
3. 在处理包含空格的路径时，使用双引号包裹路径
4. 使用相对路径，避免使用绝对路径，提高项目的可移植性
