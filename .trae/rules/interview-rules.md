# 面试题管理与优化规则

## 目录结构

- 使用清晰的目录结构组织面试题
- 按技术类别（如 JavaScript、CSS、HTML 等）分类
- 每个类别下使用数字前缀排序，便于导航
- 文件名使用中文描述，清晰明了

## 文件命名

- 使用数字前缀 + 空格 + 中文标题的格式
- 例如：`01. 基础概念.md`、`02. 类型系统与转换.md`
- 确保文件名与内容一致

## 内容组织

- 每个文件包含一个主题的面试题
- 使用 Markdown 格式，结构清晰
- 使用 `::: details` 标签创建可折叠的内容块
- 每个问题包含详细的解答和代码示例
- 按技术类型分类面试题，如 CSS、JavaScript、TypeScript、React、Vue、浏览器等
- 确保面试题内容全面，涵盖核心知识点
- 定期更新面试题内容，保持时效性

## 代码格式

- 代码块使用 2 空格缩进
- 保持代码风格一致
- 提供完整的示例代码
- 代码注释清晰明了

## 链接管理

- 确保面试题之间的链接正确，使用相对路径
- 处理链接中的空格，将空格转义为 %20

## 问题排序

- 使用排序脚本对面试题进行优先级排序，确保重要的问题排在前面
- 排序脚本路径：`scripts/sort-css-questions.js`
- 运行方式：`node scripts/sort-css-questions.js`
- 排序后会生成新文件：`src/docs/interview/01. CSS-sorted.md`

## 脚本使用流程

1. 确保原始面试题文件存在：`src/docs/interview/01. CSS.md`
2. 运行排序脚本：`node scripts/sort-css-questions.js`
3. 脚本会自动提取所有问题，根据优先级排序，并生成新文件
4. 检查生成的新文件，确认排序结果
5. 构建项目，确保没有错误

## 重复问题处理

### 处理目标

从源文件中提取面试题，识别并汇总整合重复的问题和答案到目标文件，确保内容完整且无重复。

### 处理步骤

1. **分析源文件和目标文件**：
   - 读取源文件和目标文件中的所有面试题和答案
   - 识别文件中的问题标题和答案内容（通常使用 `##` 标记问题，`::: details` 标记答案）

2. **识别重复问题**：
   - 提取问题标题并标准化（如去除编号、统一格式）
   - 比较问题标题，识别重复的问题
   - 对于重复问题，分析其答案内容

3. **汇总整合答案**：
   - 比较重复问题的不同答案，提取核心内容
   - 保留更全面、详细的答案
   - 合并不同答案的关键信息
   - 确保整合后的答案逻辑清晰、结构完整

4. **分段处理**：
   - 将面试题按主题分类
   - 处理每个主题下的问题
   - 确保同一主题的问题集中在一起
   - 维持问题编号的连续性

5. **写入目标文件**：
   - 确保目标文件的结构清晰，问题编号连续
   - 替换重复问题的答案为整合后的版本
   - 添加源文件中独有的新问题
   - 保持文件格式一致（如标题层级、代码块格式）

### 技术实现

- **读取文件**：使用 `Read` 工具读取源文件和目标文件内容
- **分析内容**：通过字符串处理识别问题标题和答案
- **写入文件**：使用 `Write` 工具将整合后的内容写入目标文件

### 识别重复的方法

1. **标题匹配**：比较问题标题的文本内容
2. **内容相似度**：对于标题相似但不完全相同的问题，分析答案内容的相似度
3. **标准化处理**：
   - 去除标题中的编号（如 "## 1. "）
   - 统一标题格式（如大小写、标点符号）

### 汇总整合的技巧

1. **答案结构**：保持答案的层次结构（如使用 `###` 子标题）
2. **代码示例**：保留关键的代码示例，确保代码格式正确
3. **内容去重**：删除重复的解释和示例
4. **逻辑顺序**：确保整合后的答案逻辑清晰，从基础到进阶

## 验证步骤

1. **内容检查**：确保所有问题都已处理，无遗漏
2. **格式检查**：确保文件格式一致，无语法错误
3. **构建测试**：运行构建命令，确保无构建错误
4. **内容验证**：验证整合后的答案是否准确、完整

## 编码规范

- 使用 UTF-8 编码，避免 BOM 问题
- 保持文件编码一致
- 避免使用特殊字符和非法字符

## 版本控制

- 定期提交更改
- 提交信息清晰明了
- 保持代码库的整洁

## 审核与测试

- 定期审核内容的准确性
- 测试代码示例的正确性
- 确保内容的可读性和实用性

- **难度评级**：为面试题添加难度评级，便于分类和筛选
